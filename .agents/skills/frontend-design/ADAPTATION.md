# 项目适配：视频画面

上游是一份面向新 UI 与改版的视觉设计指导。本文件把它接到 material2video 的视频制作语境；上游正文仍是视觉方向、字体、结构与自我批评的来源，本文件只负责翻译、限定边界和指出不可用部分。

## 什么时候读

| 场景 | 读取内容 |
|---|---|
| 方案确定：确定视觉方向、字体气质、构图与配色 | `SKILL.md` 的「Ground your designs in the subject matter」与「Design principles」 |
| 逐场设计：安排开场、信息层级与版式 | `SKILL.md` 的「Visual structure is information」与「Process」 |
| 静帧或片段复核 | `SKILL.md` 的「Restraint and self-critique」；配合实际帧与手机尺寸帧 |
| 画面显得模板化、像通用 AI 生成 | `SKILL.md` 的 AI-generated design 特征清单，逐条对照但不机械否决 |

## 视频语境映射

| 上游说法 | 本项目含义 |
|---|---|
| page / screen | 单帧、镜头、场景或完整序列 |
| hero / first screen | 开场首 3–5 秒的**有序帧**，不是单张静帧；不要与镜头等级 `hero` 混用 |
| responsive / mobile | 作品声明的画幅与手机观看尺寸；不是网页断点，也不要求所有作品竖屏 |
| typography | 画面文字层级、字阶与行宽；项目字体、令牌、字幕安全区和手机可读性优先 |
| layout / structure | 构图、信息层级、跨镜头对齐、安全区与留白 |
| color palette | 主色、墨色、强调色的比例与语义；风格包和作品设计目标优先 |
| copy | 画面文字、字幕与旁白；项目文案、信息单元预算和自然中文规则优先 |
| self-critique with screenshots | 用实际帧、声明手机尺寸帧和有序帧序列复核；不以源码或设计文档代替画面 |
| motion | 以 `motion-design` 为权威；上游运动段落只作“克制、单一编排”的静态品味补充 |
| CTA / button / form / error / empty state | 不适用；视频没有交互状态 |
| keyboard focus / reduced motion / CSS specificity | 不适用；这些是 Web 工程规则，项目有自己的确定性与可读性契约 |

## 在视频中的使用顺序

沿用上游“计划—对照—构建—批评”的结构：

1. **从题材出发**：先写清主体、受众、作品要观众理解或感受到什么，以及题材自身的材料、行业、地点、历史或器物。视觉方向必须能从这些内容里说出来，不能只写“高级”“干净”“有冲击力”。
2. **计划**：用颜色、字体、版式与原则四项写一个紧凑的视觉计划；版式用一句话和 ASCII 草图比较，不先写代码。
3. **对照**：把计划拿回主题检查：如果换一个同类题材也成立，它大概率是通用默认，需要改。记录改了什么、为什么。
4. **构建后批评**：看实际画面，不看源码。先记录第一眼落点、眯眼后的层次、主体是否只属于这个题材、左边缘是否稳定、留白是否有用途、字阶是否决断、颜色比例是否集中、真实素材是否足够、相邻镜头是否同构、手机尺寸下是否仍成立、画面是否欠构建。然后只修最影响观感的三处。
5. **克制**：把胆量花在一个地方。一个记忆点，其余保持安静；每轮删掉一个不服务表达的装饰。

## 与项目契约的关系

- 上游的 AI-generated 特征清单是**审慎起点**，不是本项目的否决清单。风格包、作品设计目标、用户明确要求和题材需要可以合法使用被点名的形式；采用时记录理由，不按形式标签否决。
- 不把上游的审美判断变成项目门禁、评分、CLI 判据或新审核轮次；本 skill 不新增门禁，也不改变项目的证据、问题分级与完成条件。
- 评审者可以读取本 skill 作为观察词汇，但仍须先盲看落盘、再对照中性条件；不得读取 `DESIGN.md` 或作者理由。
- 设计文档不能替代成片证据；审美判断必须绑定实际画面、时间码和显示尺寸。
- 项目既有的实际表达判断、问题分级、证据有效性和独立评审隔离仍然优先。
- 运动设计、时长、缓动、编排和采集模式边界以 `motion-design` 为准；本 skill 只补“视觉上是否克制、是否只有一个记忆点”。

## 不适用内容

- Web 响应式断点、组件代码、CSS 选择器优先级与浏览器兼容；
- CTA、按钮、表单、错误/空状态、键盘焦点、`prefers-reduced-motion` 等交互与可访问性规则；
- 把具体网页符号、组件或示例当成视频模板；
- 用固定像素字号或固定版式替代按题材、画幅和手机尺寸的设计判断。
