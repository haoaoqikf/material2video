# 逐场细节设计与落实

general 每场在对象、变化与目标认识确定后、动态实现前完成细节设计；这是方案阶段内部工作，不新增制作阶段。运动方法只维护在[运动设计适配：逐场细节](../../motion-design/ADAPTATION.md#逐场细节设计)，构图与焦点判断读[Frontend Design](../../frontend-design/SKILL.md)。

## 记录在同一份设计中

在 `DESIGN.md` 的[逐场表](visual-creative-direction.md#逐场设计表)中简写或链接同文档细节小节，不新增 `DETAILS.md` 或平行运动表。每场同时考虑主体、文字、图标/配角、光影点缀、镜头剪辑与声音，记录适用选择、触发关系、主次、阅读窗口和收势；不适用项合并说明取舍。每项说明表达用途，不只写“加回弹”“加粒子”。普通场景可用一段完成，复杂依赖才展开；方法见[整场六部分编排](../../motion-design/ADAPTATION.md#整场六部分编排)。

执行帧、曲线与参数引用唯一的分镜或代码事件源；设计描述关系与稳定窗口，不复制维护另一份精确时间表。下列写法是记录示例，不是必选动效：

> 球沿同一支撑面跳向下一条件，落地触发该柱从共同零基准增长。起跳前镜头停稳；球、地影与尾光从同一轨迹求值，接触声和闪释绑定真实落点，柱高稳定后保留准确比例与读数。事件与参数引用本场代码；无角色表情与环境层。

对象运动与图表增长联动时，先画清实际支撑面、球心路径和图表零基准，再确定是谁触发谁。若球不站在柱顶，就不让柱高参与球的竖直位置；镜头移动与球飞行分时，避免投影造成额外滑行。检查落点前后一帧的球、影、光、声音、条件文字和结果，避免新条件先于新结果出现后与旧结果短暂错配；再看完整窗口的自然运动与阅读空间。本段只是设计检查方法，不指定所有柱图都必须用球或跳跃。

复杂文字图标场景同时记录“触发者 → 配角/文字反应 → 点缀跟随 → 阅读 → 收势或切镜”，各层共用命名事件。只写主体已经回弹，不代表该场文字、图标与周边反应已设计完成。

## 先确定本场怎样值得看

每场用一句具体描述确定表现目标：观众先看哪里、哪个变化带动视线、最终停在哪里。目标可以是数量感、反差、触感、期待或从容比较，不只列“加粒子、加回弹”。例如“新记录落定时计数增加，角色随节拍起落，失败与命中颜色保留”，可以分别检查记录、计数与角色；“让表格更丰富”不能指导实现。

无旁白时，先用实际文案排主次、尺度与完整阅读窗口，再安排图形和配角。承担讲解的文字按主体信息设计，先减少同屏重复标题与说明，再放大；不能以数字巨大或解释文字勉强可辨代替讲解层级充分。字号由画幅、字体、字数和声明观看尺寸共同决定，不复用跨作品固定像素值。必要注释仍按项目约定保持次要。

配角逐项说明用途：帮助理解、带视线、组织节拍或传递情绪均可。箭头必须指向可解释的方向/变化，图标须能认回对象或状态，角色可陪伴计数但不能伪造数据因果；只有“占空位、增加丰富度”时舍弃。颜色也要有可追踪的职责，不能把低数值随意染成失败。

明确参考时，按本轮受影响的观看任务逐场配对完整窗口，如计数、区域变化、节点比较、公式解释；记录实际借鉴的尺度、颜色、路径、强弱和阅读组织。没有直接对应项时说明只迁移哪些方法，不硬配。一个文字图标说明段不能代表其他数据段；原参考用于核对采用目标，自己的旧版用于判断修订收益，两者分别回答。

## 实现与复核顺序

1. 选择本轮最弱或未决的完整关系及必要衔接作为试制，不只选择已经成立、方便实现的段落。在完整试制窗口中先实现主体关系与跨场承接，再落实选定细节；用实际主体、文字、字体及必要声音，细节不留待整片生成后统一补。
2. 复核完整起势、动作、反馈、落定与退出，核对对象依赖和稳定结果窗口；原生与声明的手机尺寸均检查。动态证据按既有事件与采样要求采集，不能只用起终静帧证明联动或回弹。
3. 在既有 G4、G5 与 G6 适用范围内检查，不新增轮次、人数、门禁或自动审美校验。独立评审仍先盲看落盘再对照中性条件，不投喂设计理由或预期答案。
4. 失败沿[唯一问题与返工循环](production-workflow.md#检查与返工循环)处理；修改后复查本场及相邻衔接，技术通过或终态正确不能关闭过程缺陷。

实际复核分开记录关系/动作成立与预先声明的表现目标是否兑现：文字图标是否参与、周边反馈是否有用、释放强弱是否有变化、相邻几拍是否重复配方。明确参考或重制时，在同轮适用观察中对照同用途片段和保留基线，分别记录理解、表现及改善/无改善/退步/证据不足；不能用无缺陷或主体动作正确代替丰富度目标。沿用既有轮次与隔离规则，不新增自动审美分数。先以包含上述关系的完整核心段试制，成立后原位扩展。

观察说明实际显示尺寸、窗口和观看方式：有序帧能核对先后、接触与稳定阅读，正常速度播放可补充实际节奏和等待体验；未覆盖的实时体验或听感如实保留，不自动记为通过或缺陷，也不强制新增播放/试听步骤。对照后仍须回答本场声明的变化是否突出，不能只确认某种效果存在。

已有成片不因本页追溯重渲；后续制作与明确启动的修订按受影响范围执行。示例补写须核对真实源码并说明证据边界，文档补写不等于重新制作或验收通过。
