# 电影级（cinematic）制作档位

本页配合[节奏、美术、声音与制作阶段](creative-production.md)执行：先整片粗预演、风险优先，再按阶段完成条件精制与复查；不增加用户确认或 CLI 人工门禁。

cinematic 同样先明确核心体验验收条目；时长预算由内容与运动共同决定。4K 静帧不证明连续运动自然，镜头内部及完整风险过程按[自主视觉复核](visual-review-rubric.md)检查，核心体验缺陷未关闭不标记制作完成。

通用作品（`general`）区分两个制作档位：**standard** 与 **cinematic**。standard 是默认档，
保持现有的快速链路与自动验收；cinematic 是显式选择的电影级档位，把参考板、look bible、
镜头清单、材质、后期与声音设计变成可执行、可留证的步骤。

用户明确要求「电影级 / 极致 / 惊艳 / 发布级 / 品牌片」时**必须**使用 cinematic，
不得静默按 standard 交付后再声称是电影级。

## 实现状态

档位声明、镜头/look/claims 字段、准备指纹与电影级共享套件（`CameraRig`、`PostFX` 与深空元件）
已经落地，并通过真实浏览器验证了同帧可复现与标准画面不受影响。
`lookdev` / `qa` / `assets audit` 已接线；lookdev 静帧从源码按原生 2× 像素绘制，
PNG 合成字幕与转场，有声作品的样片复用准备片段，无声作品生成无音轨样片，详见[代码场景运行契约](code-scene-runtime.md#lookdev-原生关键帧)。
太阳系一镜到底参考片保留旧版135秒的历史记录；当前重制预算与实际状态见示例设计及验证文档；旧用户确认不授权当前版本完成。跨幕录制的片段无法拼接成真正的一镜到底，相关约束见[分镜结构](storyboard-schema.md#一镜到底)。
cinematic 不另出母版，成片仍是普通 H.264 MP4。本节与
[代码场景运行契约](code-scene-runtime.md)、[渲染引擎](render-engine.md)、
[分镜结构](storyboard-schema.md) 描述的是**当前支持**的能力。

## 档位对照

| 项 | standard | cinematic |
|---|---|---|
| look-dev | 可选 | 必须：3–5 张 4K 静帧（可覆盖四张基准） + 20–30 秒样片（无声作品为无声样片） |
| 镜头 | 作品自由 | 必须提交 shot list；hero ≥ 3 |
| 资产 | 2K 可用 | hero ≥ 4K，normal/roughness/emissive 齐全；二维档案（`role: other`）按原生尺寸与许可审计，不要求表面贴图 |
| 后期 | 无 | Bloom / DOF / grain / vignette / CA / LUT |
| 声音 | TTS + 可选音床与音效 | 配乐 + 音效 + 混音与响度；无声作品为空旁白、无 soundtrack，最终 PCM 峰值为 0 |
| 编码 | H.264 CRF18、8bit、44.1k/128k | 普通 H.264 MP4（不另出母版） |
| 质检 | 自动字幕量测 + 基础视觉复核 + 全片帧序列与自动音频复核 | 技术 QA + hero 风险帧序列/量测 + 最终全片帧序列与自动音频复核 |
| 门禁 | 自动验收 | 全片 QA；look-dev 只产出检查产物，不设人工门禁 |
| 成本 | 1× | 2–4× |

cinematic 取消所有阶段用户确认。look-dev 的静帧与样片用于对照参考、帧序列复核和返工；助手关闭必改项后再铺全片。记录不参与 CLI 导出门禁；完整流程、版本与问题模板见[自主视觉复核](visual-review-rubric.md)。

档位在 `project.json` 的 `productionProfile` 声明（`"standard"` 或 `"cinematic"`，缺省 standard），
也可用 `m2v prepare --profile cinematic` 临时覆盖；分镜不重复声明档位。准备记录、候选与
成片溯源自上而下继承实际生效的档位与来源。

## 参考板（reference board）

开拍前由助手自行搜索至少 3–5 张关键静帧、1–2 段运动及 1 段声音参考（无声作品不适用声音参考），写进作品 `DESIGN.md` 的「参考板」小节，每张注明**它参考的是什么**（光比、色温、材质、构图、节奏），记录来源与访问日期，而不是笼统的「好看」。两个美术方向使用同一内容片段作比较；逐项写出参考与实际方案的差距及落实后的画面决定。四张基准为开场、核心、普通信息镜头与结尾，可复用在3–5张关键静帧中；每张在原始、手机和缩略图尺寸检查。参考板按四类各选 2–3 张：

| 类别 | 要看的东西 |
|---|---|
| 光影 | 主光方向与光比、轮廓光、逆光边缘、暗部是否有细节 |
| 材质 | 表面粗糙度与反射、磨损与噪声、次表面感 |
| 构图 | 主体占比、留白、前后景关系、视线引导 |
| 节奏 | 镜头时长分布、硬切与匹配剪辑、留白与静默 |

参考板是**创作依据**，不参与运行时；它必须落实成 `scenes/` 下的代码与 shot list 才会改变画面。

## Look bible

look bible 是整片唯一的光色与质感基准，写在作品 `DESIGN.md`，并在 `content.props.look` 里
落成代码可读的参数。至少固定下面六项，全片不得逐幕漂移：

- **色温与色调**：主光色温（例如 5600K 冷白 + 2700K 暖补），阴影色调，允许的色相范围。
- **光比**：主光与补光的比值（深空场景常用 8:1 以上），暗部保留的细节底线。
- **曝光策略**：基准 EV、逆光镜头的过曝容忍上限、暗部提亮手段。
- **材质基准**：金属度/粗糙度的取值区间，是否允许镜面高光，噪声颗粒的频率与强度。
- **景深**：哪些镜头深景深（总览）、哪些浅景深（hero 特写），允许的散景形状。
- **后期基线**：Bloom 阈值、grain 强度、vignette 强度、调色档（`lut`）与其强度。

`look.profile` 是这份基准的名字；`look` 里的每一项都要能被 shot 级 `post` 覆盖，
但覆盖必须写进 shot list，不允许在作品代码里散落魔法数字。

## 镜头语法（shot grammar）

镜头是**数据**，写在分镜 `content.props.shots` 里，由准备阶段校验并写入准备指纹与代码片段
缓存键。每个 shot 至少声明：

```json
{
  "shots": [
    {
      "id": "earth-hero",
      "target": "earth",
      "tier": "hero",
      "segment": "home-0",
      "startFrame": 960,
      "endFrame": 1440,
      "camera": {
        "path": [[0, 1.2, 9], [2.4, 0.6, 5], [0.4, -0.8, 3.2]],
        "fov": 32,
        "roll": -2,
        "easing": "quintInOut",
        "keyframes": [{"frame": 960, "position": [0, 1.2, 9]}, {"frame": 1440, "position": [0.4, -0.8, 3.2]}]
      },
      "focus": {"target": "earth", "distance": 3.2, "aperture": 2.8},
      "exposure": {"ev": -0.3},
      "post": {"bloom": 0.7, "dof": 0.6, "grain": 0.35, "vignette": 0.45, "chromaticAberration": 0.12}
    }
  ]
}
```

- `tier` 取 `hero`、`major`、`minor`：hero 可以按 `look.motion` 取 2–4 个子帧做运动模糊并
  按 2× SSAA 采集后降采样，其余镜头保持 1 帧、1×。
- `startFrame` / `endFrame` 是**幕内相对帧**（与作品代码看到的 `segmentWindows` 同一原点），
  必须落在本幕时长内。声明 `segment` 的镜头必须**完整覆盖**该旁白段的窗口——这是作者对
  「这个镜头讲的就是这段旁白」的承诺；没有声明的镜头只查幕时长，因为 8–12 秒的 hero 通常
  要跨过留白与相邻旁白。越界或未覆盖直接失败并指出具体镜头。
- 整片至少 3 个 hero，每个 hero 是一段 **8–12 秒（480–720 帧）的连续镜头**；其余章节按内容与运动需求安排，不机械压缩为固定长度。
- 镜头路径优先单程推进；只有章节转折才回望，不允许每段回到同一个总览机位。
- 相邻镜头默认**共用路径点**（连续运镜）；声明 `cut: true` 的镜头改为**硬切**：路径直接跳到本章
  的建立机位，只能向前跳、不能退回上一个镜头之前。整片的出口半径必须保持单调向外。
- 相机穿球（穿过天体网格）与背景裁切在准备阶段检查，命中即失败。
- 镜头 `id` 在整片内唯一，错误信息按 `scenes[<幕>].content.props.shots[<镜头 id>]` 定位。

镜头语法与 [设计令牌](design-tokens.md) 的动效约定一致：运动只出现在承载信息的地方，
时长与缓动是设计决定，不是随手填的数字。

## 材质与资产清单

hero 资产按**屏幕像素 / 纹素比**审计，不按「文件看着挺大」判断：

- 颜色贴图 hero ≥ 4K（4096 宽以上），major ≥ 2K；不得把 2K 放大冒充 4K。
- `normal` / `roughness` / `emissive` 齐全；有大气或云层的天体额外提供 alpha 或遮罩。
- 环系径向纹理 ≥ 4K×512，保证从侧刃展开到正面时不出现径向拉伸。
- 色彩空间与 alpha 必须显式声明；`useMediaAsset(id)` 返回 `colorSpace`、`alpha` 与登记许可，
  作品据此设置材质并生成片尾署名。
- 许可优先 NASA / USGS / ESA / CC BY；hero 资产许可未知时**阻断**，standard 资产保留
  「未知」记录但不阻断。新增素材同步写进作品 `SOURCES.md`。

## 后期清单

后期只作用于 canvas，不影响共享字幕 DOM 层；所有参数必须由 `elapsedSeconds` / 帧号驱动：

| 效果 | 作用 | 注意事项 |
|---|---|---|
| Bloom | 高光溢出，太阳、环逆光、城市灯光 | 阈值先定，避免整片发灰 |
| DOF | 浅景深与前景虚化 | 总览保持深景深，不做 DOF |
| grain | 细颗粒，压暗部 banding | 用「帧号 + shot id」确定性种子 |
| vignette | 收边、聚焦主体 | 强度上限写进 look bible |
| CA | 边缘色散，镜头感 | 只在 hero 轻微使用 |
| LUT | 统一色调 | 内置调色档名与强度都进指纹 |

禁止挂钟、`Math.random`、CSS animation 或组件计时器驱动后期参数；源码闸门继续拒绝这些写法。
同帧重复渲染的 PSNR 必须 ≥ 60dB。

## 声音清单

cinematic 的声音设计分四层，全部写进分镜顶层 `soundtrack` 或作品音频设置：

1. **配乐**：本地素材或确定性程序化音床，60–70 BPM 环境底、低频 drone；不接入第三方音乐服务。
2. **环境层**：风声、深空底噪、冰裂等持续层，随镜头淡入淡出。
3. **音效层**：飞近 whoosh、环 shimmer、硬切点等，按 `sceneId` / `segmentId` / `offsetMs` 定位。
4. **旁白**：真实 TTS，保持清晰。

混音目标：旁白 −16 LUFS，音乐 −28 至 −32 dB，音效 −24 dB（默认 −18 dB 声明值由作品决定），
成片 **−14 LUFS / −1 dBTP**；保留旁白闪避与真峰值限制。cinematic 不另出 48kHz/24bit 母版，
声音随普通 MP4 交付。字段与验收见[文章媒体与音效](article-media-and-sound.md)与
[配音音色与节奏](voice-and-rhythm.md)。

## 助手阶段复核（不新增 CLI 门禁）

cinematic 按五个阶段推进，每个阶段有明确产出与放行条件：

| 阶段 | 产出 | 放行条件 |
|---|---|---|
| Brief | 参考板 + look bible + shot list 草案 | 参考依据具体到「参考什么」 |
| Look-dev | 3–5 张 4K 静帧 + 时间标注风险帧序列 + 20–30 秒样片（无声作品为无声样片） | 用帧序列、屏幕量测和自动音频报告记录版本与问题；必改项关闭后铺全片 |
| Hero | 3 个 hero 连续镜头 | 每个 8–12 秒镜头均采集起始/中间/结束与运动峰值帧，并记录时间码及量测 |
| Full film | 全片预演 | 时长落在验收范围、旁白与画面 claims 对齐 |
| QA / 自主复核 | `m2v qa` + hero 风险帧序列/量测 + 最终全片帧序列与自动音频复核 | 技术通过、当前记录有效、必改项关闭，自主交付 |

## 20 项检查表

look-dev 与出片前逐项自查，逐条给出结论与证据（时间码、文件名或实测数值）：

1. 参考板每张都写明参考的具体维度。
2. look bible 六项齐全，全片没有逐幕漂移。
3. shot list 时间窗全部落在旁白段内（无声作品无旁白段，按幕时长检查）。
4. 至少 3 个 hero，且每个 hero 有 8–12 秒连续镜头。
5. 镜头单程推进，没有每段回到同一总览机位。
6. 无相机穿球、无背景裁切、无突兀 FOV 跳变。
7. hero 资产 ≥ 4K，normal/roughness/emissive 齐全；二维档案（`role: other`）按原生尺寸与许可审计，不要求表面贴图。
8. 环系径向纹理分辨率达标，展开时不糊。
9. 色彩空间与 alpha 显式声明，许可已留证。
10. 后期参数全部帧驱动，同帧 PSNR ≥ 60dB。
11. 暗部无 banding，高光无溢出死白。
12. 字幕对比度 ≥ 4.5:1，且不与主体、读数重叠。
13. 片头/片尾免责声明只出现一次，不长期同屏。
14. 导航是章节进度轨，不是常驻左栏。
15. 旁白 claims 在对应时间窗内确实可见。
16. 音画同步，硬切点与音效起点对齐。
17. 响度与真峰值达标（成片 −14 LUFS / −1 dBTP）。
18. 成片参数、帧数、时长核对一致。
19. hero 镜头与样片有完整时间标注帧序列、运动量测记录（帧号 + 问题 + 复查）；不要求播放镜头。
20. 溯源记录含 profile / look / post / audio 参数。

## 自主完成

cinematic 不设数字评分卡或用户确认，也不要求播放视频、连续收听音频或试听音色。助手按文本与服务元数据选择音色，对最终文件执行全片帧序列、屏幕量测与自动音频信号复核，按手机观看尺寸检查主体、文字与平台遮挡风险，技术验收通过、当前替代复核记录有效、必改项关闭后自主交付。可选问题随交付披露；帧序列、自动音频及异常复查齐全即可自主完成；不对主观音色感受作结论。

准备指纹及最终 MP4 摘要绑定、前后对照、连续两轮无改善后的方法调整、证据保留及记录模板统一见[自主视觉复核](visual-review-rubric.md)。`m2v render` 不因缺少播放或试听记录而阻断。

## 反模式

- 把「能导出」当成「够好」：自动验收通过不等于画面好看。
- 用后期掩盖构图问题：Bloom 拉满、grain 糊住细节、暗部一片死黑。
- 每段回到同一总览机位再飞近：像目录，不像旅程。
- 后期参数写死在作品代码里，改一处要看半天。
- 用挂钟或随机数驱动粒子，导致同帧不可复现。
- 把 2K 贴图放大冒充 4K，或省略 normal/roughness 只留颜色图。
- 字幕、导航、免责声明长期同屏，画面被 UI 占满。
- 旁白提到的特征在画面上看不到（没有 claims 检查）。
- 没有当前有效的全片帧序列与自动音频复核与必改项复查就宣称完成；用技术通过或历史用户确认代替真实复核。

## 成本表

| 环节 | 相对 standard | 说明 |
|---|---|---|
| 录制 | 1× | 逐帧采集成本与档位无关 |
| hero 镜头 | 2–4× | 2× SSAA + 2–4 子帧运动模糊（`look.motion`） |
| 其他镜头 | 1–1.5× | 仅后期开销 |
| 编码 | 1× | 普通 H.264 MP4，与 standard 同一交付格式 |
| 音频 | 1.5× | 配乐、环境与音效混音 |
| 迭代 | 2–4× | look-dev 帧序列/量测与全片复核带来的返工 |

按镜头分级渲染，不承诺全片同等开销；在 look-dev 阶段先量一次单帧成本，避免整片渲完才发现
预算失控。交通拥堵波示例保持 standard；美国科学里程碑为无声 cinematic。

## 无声档案片

用户明确要求无声时，不执行配音、配乐、音效及声音参考清单；关键帧、20–30秒样片、全片帧序列和视觉复核仍须完成。空旁白且无soundtrack的作品须验证最终无音轨或全片PCM峰值为0，不套用−14 LUFS目标。

照片和视频登记 `role: "other"` 并关联镜头目标，按实际尺寸、许可和画面清晰度审计；三维颜色贴图仍执行4K与配套贴图要求。历史低清素材保留档案质感和留边，不放大后声称原生4K。
