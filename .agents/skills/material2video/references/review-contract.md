# 技术 QA 与独立评审政策

本页唯一维护审核职责、采用、失败闭环和总代理责任。观察标准见[世界级视觉复核](visual-review-rubric.md)，执行见[隔离评审](subagent-review.md)，字段与命令按需读[工具协议](review-protocol.md)。

## 审核策略

| 对象 | 审核或核验 | 证明范围 |
|---|---|---|
| 试制关键帧 | 新上下文盲审，同一评审者同轮实际标杆对照 | [必要信息、核心形象与可指导制作的艺术方向成立](visual-review-rubric.md#试制关键帧的通过标准) |
| 正式关键帧 | 新上下文盲审，同一评审者同轮实际标杆对照 | 所选风格的世界级成片完成度、表达及适用字幕可读性 |
| 试制动态样片 | 总代理使用完整解码、有序帧及适用信号核验 | 完整动作、因果、身份连续、空间及阅读窗口 |
| 正式必审关键片段 | 默认独立过程对照 | 完整动作、因果、身份连续、节奏、衔接、声画及字幕时序 |
| 当前完整候选 | 总代理用当前候选的抽帧、时间轴与适用信号复核整片，并核对技术 QA | 全片结构、节奏、声画、字幕及局部证据未覆盖的风险 |

所有作品须正式关键帧独立双通过。研究按目标时长规划，正式验收用当前准备记录的总帧数和帧率判定。**总帧数不超过 30 × 帧率时豁免关键样片**，直接从实际全片工程取帧，总代理在整片证据复核中加密核查密集口播、快速切镜、复杂动效等动态风险。缺少有效准备时门槛待判定。

超过门槛时先在总设计写清要回答的问题，再选能覆盖完整起因、变化、结果或前后衔接的局部窗口。通过范围只授权当前实际观察。必要窗口按[工具协议](review-protocol.md#正式窗口与整片复核)登记，全部获得有效通过才可报告完成。核心创意依赖悬念、错觉、连续变形或剪辑反转时，以具体 blindReason 触发过程盲审及同轮对照。实质争议由新代理按原目标复核。

正式候选先由总代理初筛。关键帧覆盖代表状态和风险状态。有字幕时从实际合成取证，关键帧检查字号、断行、层级、让位、手机尺寸与明暗极端，关键样片核对同步、停留、换句和运动及转场中的遮挡与对比。字幕调整沿[场景检查](scene-design.md#渐进设计与开发循环)复查受影响范围。

正式完成须有关键帧双评、适用样片独立通过、当前技术 QA、与候选摘要绑定的整片复核和已关闭的必改。候选可先生成。复核按[制作与验收](stage-production.md#验收交付)执行。

## 明确结论与采用

每项及整体均明确采用或不采用：仅 pass 对应 adopt；fail 与 insufficient 一律 reject。证据不足必须说明缺证范围与补证办法。不得以“大体可以”“基本达到”“有潜力”等措辞代替结论，不用排名、总分、技术成功或投入成本放行。实际判断与证据要求由[视觉复核](visual-review-rubric.md)维护。

正式 items 仅放当前待验证范围，每项均受失败闭环约束；备选或历史画面可在 references 中中性注明比较用途，不冒充已盲审通过或整体品质标杆。按需探索性匿名观察仍须真实隔离记录，但不冒充正式导入或授权采用。

## 总代理品质责任

总代理必须送审前用静帧、有序帧和适用信号初筛实际媒体，核对用户要求、具体标杆、关键状态及技术来源；独立审查不能成为首次自查。任何阶段都不以播放视频观看或实际试听为前提，证据缺口按具体窗口及指标说明。

收到报告后核对其实际覆盖、美术表现、参考差距与结论依据。仅写可读、无遮挡、技术正常的报告不足以确认美术通过，须补足真实独立观察。总代理明确决定采用、修复或淘汰，记录依据、保留项、必修项、打磨项和范围；独立 pass 不免除已知问题，也不能直接等同阶段完成。

决定写入 DESIGN.md 和相关场景，问题沿 outputs/visual-notes.md，不新增审批或总代理报告。交付前确认当前媒体与有效证据一致；总代理不能单方关闭独立失败。

## 采用边界与选案责任

原始用户要求优先于作者转化。DESIGN.md 保存相关原话、选中媒体及限定范围；对照条件去身份但不删减要求，原要求和中性转化分开，选中和赞许不提示应通过。整体风格未限定单场时覆盖受影响画面，不能自行缩为结果页。对照先核忠实性再核实际兑现，缺原要求或范围依据则保持未验证。

送审前在设计和对照条件里明确各帧的职责、共用艺术目标、参考采用范围及在相关观看尺寸下可观察的通过效果。同轮对照按实际职责检查整体艺术效果与专项表达。核心表达、整体美术或必要读取实质受损必须阻断。达到相应阶段目标后，局部改善可随 pass 保留。试制返工与恢复按[暂停送审规则](production-workflow.md#试制暂停送审与重新选案)执行。

用户指出旧通过偏离真实要求时，记录偏离与未完成，修订设计及后续条件，保留旧包、报告和状态原件；历史 pass 不代替当前要求，也不伪造独立 fail。

## 抽象表达与信息职责

按完整画面的实际职责判断。形体、叠层、空间或动作可承担意象、关系、量级和情绪，文字／读数可承担精确事实；不默认要求每层字形或每个抽象局部逐一可辨认。影响判断的分工进入现有场景与中性条件，不增加运行时字段或画面标签。

关键帧在正常观看尺寸核对相应阶段的艺术效果，在小屏核对核心形象、关键关系和必要信息。抽象细节的从宽条件与取证见[不同观看尺寸的职责](visual-review-rubric.md#不同观看尺寸的职责)。

遮挡唯一必要读数、关键误导、组别或因果不明、核心形象失效、偏离用户选定整体风格仍阻断。不能事后把失败的信息对象改称装饰，也不能因有辅助读数就免除整体表现要求。

## 问题与独立复查

独立 fail 自动登记必改。修复后由当前、同用途、同范围的独立通过及适用目标对照关闭。保留原条件、参考、显示尺寸、失败和真实调用。政策调整前的原生试制过程问题留在历史记录，退出当前审核门禁。自审、技术量测、淘汰候选、改放 references 或重开周期不能关闭适用的独立失败。insufficient 明确不可采用，补证后再评审。

事实、来源、许可和用户硬约束由总代理核验。评审不阻断候选生成，但缺有效评审不得报告完成；降级自审必须披露且不能关闭独立项。活动证据受保护，损坏或未知引用停止清理，详见[协议](review-protocol.md#问题状态与记录)。

## 用户明确变更目标

已绑定独立失败的目标只能在用户明确变更后，按[retarget 协议](review-protocol.md#用户明确变更目标)登记原话、旧失败和新目标摘要。原周期、范围、失败及历史保留，登记不关闭问题；登记后重新完成对应用途的独立观察与适用对照，不能借用旧通过。

## 完整媒体相同的 trial 视觉复用

仅同周期、同用途、完整源媒体字节、窗口、显示尺寸、参考和条件相同的 trial 双通过可按[视觉复用协议](review-protocol.md#完整媒体相同的-trial-视觉复用)显式复用。当前来源仍重新核验，原报告与观察时间不改；损坏历史、未解决失败或目标变化均拒绝。
