### 示例与反例

| 情形 | 事件设计或判断 |
|---|---|
| 完整揭示事件 | 行业：五个光点并排同速 → 跑道坡度分化 → 近景看起来差距不大 → 拉远公开整体高差 → 观众认识到同速不等于相近结果。镜头先隐藏整体差距，再公开全貌；行业高低只作有边界的情境示意，不冒充固定排名。 |
| 无反转直接因果 | 学习：主路受限 → 先前学习形成的连接亮起 → 光点换轨 → 到达可继续前进的路。预期与独立揭示不适用：直接观察因果，以换路前后对比获得认识，不刻意制造错误判断。 |
| 静态文字表达 | 同屏保留两份规则原文，观众依次比较可获得权利的差异。持续运动与独立反转不适用：依靠对照和观察窗口推进认识，不为填模板移动文档或伪造原文。 |
| 有运动但无认识推进 | 光点持续移动、节点不断增加，却未呈现设计声称的关系或结果；不能因为「有动画」就判事件成立。按完整窗口验证，先修因果、信息顺序或删去无用途重复。 |

## 12. 七段式输出模板

## 15. 判断演练

| 情形 | 应得出的结论 |
|---|---|
| 漂亮卡片逐页替换，但没有信息、关系或体验推进 | 失败；按版式重复必改 |
| 文字对照、重组或图表关系产生新意义 | 通过；不因文字主导或信息图形式否决 |
| 单次连续旅程，没有重复母题 | 通过；记录替代组织方式 |
| 没有传统高潮，但强度曲线有理由 | 通过；记录替代记忆点，不强制添加高潮 |
| 竖屏没有使用左→右时间语法 | 记录转译方式，不判失败 |
| 声音承担关键线索，关声后信息不完整 | 记录原因，按完整声画验收；不因静音诊断自动判必改 |
| 数据图、档案、静止人物有真实信息变化 | 通过；形式本身不构成失败 |
| 设计文档写了母题，成片每幕仍是同构卡片 | 设计未兑现；按实际缺陷或证据不足处理 |

这些是规则推导，不是实际样片或观众验证；作品仍须提供真实版本与证据。

## 16. 紧凑示例：复利

以 `examples/compound-interest` 的29秒复利作品说明写法：

- **核心表达**：收益再投入，使收益也产生收益。
- **核心视觉母题**：把资金设计成1枚=1,000元的圆片；金色是本轮刚赚到、尚未再投入的收益，米白是已进入下一轮、会继续生息的资本，暗金是已取走、离开增长系统的收益。
- **视觉风格**：黑底与克制的米白/金色；圆片只用平面圆、高光弧与暗投影，不用滤镜和装饰粒子；面积编码金额，规模靠圆片数量而不是放大字号。
- **分镜**：全屏主题卡“复利的力量”→等起点两柱→第一年收益→第二年收益回吸变资本、同时产生1.0+0.1金→取出/再投入分叉（只演第3年）→30年丘与40枚/约174.5枚、结果屏“30 年后的总资产”→S6 金顶归队、结论与片名。
- **核心镜头**：S3的0.1金片（机制）、S5的40枚整块/158.631米白+15.863金丘（规模与结果）与S6的丘顶特写（金片归队）；各有独立目标静帧与盲评。
- **结尾**：结果屏在24.8秒结束，硬切到丘顶2.0×特写；16枚金片逐枚沉入白堆并变白，26.2–26.9秒拉回全景，只剩175枚全白本金；26.9秒结论“让收益，也成为本金。”、27.1秒片名“复利”，29秒收尾。
- **声音**：8.0秒进入的无旋律环境床（前8秒数字静音）+同步事件音；无旁白、无旋律配乐。
- **禁止项**：不等起点、偷偷追加本金、用账户余额对比累计总额、把分数圆片并入整枚导致一枚>1,000元、用非同比例图形夸大差距或暗示保证收益。
- **直接采用**：用户给出详细圆片方案时按“用户详细方案直接采用”落实，不伪称做过三机制比较；按相应风险评估独立目标图或核心样片，G5 做内部粗片检查，G6 做最终独立评审。

示例只作写法示范，不替代作品自身方案；当前制作状态以作品 `DESIGN.md` 与 `VERIFICATION.md` 为准。
