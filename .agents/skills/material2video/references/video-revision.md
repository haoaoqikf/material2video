# 已有视频的修订入口

本入口整理已有制作规则与命令，供助手处理“改一下这支视频”。影响分析由助手完成，缓存复用与证据有效性以现有工具结果为准；没有新增 `m2v revise` 命令、自动差异分析器或完成凭据。

## 接收修改意图

用户只需说明作品、修改位置或现象、期望结果，例如：“把结尾最后一句换掉，再多停留两秒，其他内容保持原样。”先从会话、作品目录和成片定位，不要求用户提供文件清单或命令。只有无法定位作品、要求相互冲突或歧义影响结果且材料无法消解时才询问；范围明确后直接执行常规修改与检查。

读取 `project.json`、总设计及受影响的[场景设计](scene-design.md)、可编辑材料、当前交付和已有记录，核对成片是否对应这些材料。只有 MP4 而缺少可编辑源时，说明缺失内容与可恢复范围，不能声称可以完整复用原制作链路。五类作品共用 review/baseline 和制作验收；引用 financial-series 等结构化来源时，再展开对应来源契约。旧类型作品按当前 project v2、分镜 v9 重新编排到 `videos/<类型>/<作品名>/`，保留原目录与历史证据，不自动迁移或继承通过。

五类作品在现有 `DESIGN.md` 的重制启动记录中写本轮目标、保留约束、旧版时间范围、受影响场景/镜头/旁白/声音、重入阶段与理由、基线位置；问题仍使用 `outputs/visual-notes.md` 的唯一问题表。记录要求见[重制启动](production-workflow.md)，不另建平行问题表或合同。存量作品不因使用本入口追溯升级合同、补造历史证据。重制切换制作周期时，已关闭独立问题保持原周期闭环并继续核验历史证据摘要；不把旧源码与当前源码比较，也不把旧闭环算作新版通过。历史未关闭项保留未完成，不得借新周期的报告直接关闭。

## 按影响选择最短路径

| 修改 | 重入与检查范围 |
|---|---|
| 局部文字、布局、素材替换 | 沿用有效方案；检查本场完整事件窗口、手机可读性及相邻衔接；目标画面变化时补相关静态评审 |
| 旁白、镜头时长、删段、声音调整 | 更新分镜和声音窗口，重新准备时间轴；检查配音预算、字幕、同步、后续时间偏移与跨场节奏 |
| 开场承诺、核心事件、揭示顺序、章节结构变化 | 回到相关研究、试制与设计，重新验证表达和全片结构 |

按实际依赖扩大范围，不按字数或文件数判断：换图可能改变布局与许可，改一句话可能改变时长、事实和字幕，共享组件修改可能影响多个场景。不能因为用户说“小改”而跳过连带检查；也不因局部问题重做无关选案。

涉及实质性视听重设计时，先按[设计前深度研究](stage-research.md)核对既有研究的覆盖与补查范围，再形成新方案或展示型 HTML 草稿；用户反馈暴露的新设计问题不能以“只改材质／颜色”跳过研究。研究复用原记录并说明覆盖依据，只将本轮缺口补入 RESEARCH.md，不补造历史研究；纯实现修复沿用有效方案与研究。

局部修订先核对当前制作周期及有效证据，不因新增请求例行重启周期、重做整套研究或追溯补造旧记录；实际过期或覆盖不足的项按绑定重取，新版完成条件仍适用。

风格未兑现的反馈先回到具体参考、深入拆解和本片转化，查清目标效果形成机制与当前差距，再做代表性实际画面并独立对照；不能直接换色、换字体后继续铺满全片。用户只要求方案和图片时，交付参考与本片画面的对应展示、关键拆解及未覆盖范围，不擅自制作完整新版。

增加或修改注释时，先核对[项目约定](../../../../AGENTS.md#修改规则)允许的注释范围，再按完整出现窗口检查字号层级与位置：从紧、小字、次要位置、不遮挡主体；主题、对象名称、结论和正常字幕不归为注释，不设跨画幅统一像素字号。

局部实现、视觉、字幕与声音修订进入[制作与验收](stage-production.md)，核心目标或主线改变先返回[研究与创意试制](stage-research.md)，当前候选的验收与交付问题进入[验收交付](stage-production.md)。

## 执行顺序与已有命令

1. **保护旧版**：在改材料与覆盖输出前核验旧片，记录 SHA-256 和来源。当前类型的局部修复用候选基线，整体重置才创建重置基线。基线不包含完整可编辑源码；需要恢复编辑状态时，同时保留受影响材料的修改前副本到作品内容目录，记录位置，不把作品内容强行加入 Git。基线规则见[基线保留与清理](review-contract.md)。

   存量作品若因旧评审格式无法创建基线，先在内容目录复制旧片、旁车、可编辑材料和原始评审记录并核验摘要，再运行 `review start` 显式新建周期，随后创建基线。新周期不转换旧通过；不得为绕过格式错误删除或改写旧记录。
2. **修改可编辑材料**：回写分镜、场景、旁白与声音时间窗。未变的表达目标和用户约束继续沿用，旁白未变时沿用音色选择；旁白变化按[配音契约](voice-and-rhythm.md#配音音色与语速)重新判断并更新记录。不要只修改最终 MP4。
3. **准备与局部检查**：直接执行 prepare（已包含校验；validate仅作独立排错）；按问题采集并实际查看修改后的帧或完整动作短窗口，覆盖事件起止和相邻衔接。按[检查与返工循环](production-workflow.md)在原问题正文区分待复查与效果已确认；多个不连续风险分别检查，不能用接近全片的 preview 替代 render。
4. **处理证据**：查看当前状态，保留仍有效的证据，重做实际过期、受影响或覆盖不足的项。工具若因更广依赖将证据判过期，按实际绑定重新取证，不能手改指纹、复制旧通过或承诺所有未改场景均可复用。适用的独立审核轮按[隔离流程](subagent-review.md)执行，降级自审不得关闭独立项；实际依赖未变的场景证据继续有效。
5. **生成与收口**：按[收敛判断](production-workflow.md)先汇总本批修改、效果证据与仍需全片判断的事项，再 render 生成完整候选；不每修一处就生成全片。全局变化或局部无法验证的问题按影响扩大检查。自动技术验收并交付同一文件；已有摘要有效候选的验收/交付重试复用该候选，不重复编码。最终完整复核和独立终审按[导演审查](visual-review-rubric.md)及当前制作依据执行，保留重开权。失败时保留旧有效交付，报告原因。

以下是五类作品局部修订的命令示意，由助手替换作品路径、实际旧片名称和新版检查窗口；不是要求用户逐条操作。基线的 `--files` 相对输出根，先确认文件存在。这里的 20–25 秒仅示意一个局部窗口。

```powershell
uv run m2v status --project videos/<类型>/<slug> --history --json
# 修改材料之前保护旧交付；整体重置时去掉 --candidate
uv run m2v baseline create --project videos/<类型>/<slug> --candidate --reason "结尾局部修订" --files video.mp4
# 此处修改作品材料，并记录影响范围
uv run m2v prepare --project videos/<类型>/<slug>
uv run m2v preview --project videos/<类型>/<slug> --start-seconds 20 --end-seconds 25
uv run m2v status --project videos/<类型>/<slug> --history --json
# 按影响补做检查、评审与问题复查后生成完整候选
uv run m2v render --project videos/<类型>/<slug>
# 对当前候选执行最终复核、登记证据后核对完成状态
uv run m2v status --project videos/<类型>/<slug> --history --json
```

录制区间、配音和其他缓存按实际依赖与命中结果复用，不保证仅重新渲染某个场景。命令与交付细则见[命令](../../../../README.md#命令)和[交付与溯源](delivery-and-provenance.md)。

## 修订交付

沿用[当前版本完成汇总](visual-review-rubric.md)，简要补充：修改前后差异、保留项、受影响及实际复查范围、旧版基线与材料副本位置。技术交付与制作复核分别报告，并共同绑定新版文件 SHA-256；列出未关闭问题与未覆盖范围。不能以局部检查通过替代最终全片复核，也不能以基线中的旧通过证明新版完成。

## 操作判断演练

以下为文档演练，不代表实际制作或独立评审完成：

| 请求或状态 | 预期处理 |
|---|---|
| 修复第三场标签裁切，旁白和时长不变 | 候选基线，修复本场，复查完整窗口和衔接，沿用有效音色，不重开选案；最终仍复核全片 |
| 最后一句替换并延长两秒 | 核对音色记录、旁白预算、字幕和音轨末端；重新 prepare，以新版时间定位窗口，不沿用旧结束时间 |
| 重排中间两章 | 按结构修改检查因果、指代、时间轴及全片节奏，返回研究与创意试制或制作与验收的受影响活动 |
| 修改共享场景组件 | 检查所有实际引用者，不仅检查用户最先指出的场景 |
| 局部评审仍有效 | 按实际依赖保留，优先补足未覆盖的范围 |
| 工具判旧证据过期，助手认为画面没变 | 不改写旧摘要强行通过，按绑定与覆盖要求补取当前证据 |
| 存量作品只有旧片和不完整记录 | 如实保留缺失状态，不补造旧通过；先解决本轮所需来源与材料，未满足项明确报告 |
