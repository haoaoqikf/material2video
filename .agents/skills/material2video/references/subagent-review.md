# 独立子代理评审

本页只维护隔离执行。职责、轮次与失败关闭见[审核策略](review-contract.md#审核策略)，审美判断见[视觉复核](visual-review-rubric.md)，机器字段见[工具协议](review-protocol.md)。

## 隔离输入与执行

两类独立评审均使用新建上下文代理，只提供当前只读隔离包及工具生成的任务与空白报告模板，不提供源码、DESIGN.md、RESEARCH.md、作者解释、推荐、成本、身份、其他代理观察或历史结论。

关键帧的一轮审核包含盲审和同轮对照。盲审先核对清单登记的帧与适用信号并落盘观察，导入后用 review compare 自动派生同轮目标包。同一评审者继续对照，只读当前隔离包及自身绑定盲报告。目标包在这一步揭示去身份的相关原要求、实际参考及每帧对应的职责与预期效果。先核对目标转化是否忠实，再看实际画面。修订交接中的具体问题、前后比较和选案依据由制作方使用；复查的盲审从新上下文按相同隔离范围开始。

收到当前报告后先导入封存，再动当前采集绑定的源码、参数和素材，让已完成的独立观察对应当时的实际版本。

正式关键片段默认直接创建 process 包，提供实际过程、参考与中性条件。先记录实际变化及可辨因果，再核目标。需例外盲审时遵循已登记的具体时间机制依据。研究试制仅送同源关键帧，动态全程由总代理按审核策略核验。

## 真实观察与记录

代理只读取清单登记文件，记录实际读取的路径、窗口、显示尺寸和限制。以静帧、有序时间码帧、完整解码、适用帧差／场景切分、主体区域和音频信号量测判断；不要求播放或试听，也不声称实时播放或主观听感。按实际机制补证，不给静态、无声或 cut 强加无关指标。

每项明确通过或不通过。先记录整体画面的注意力、形象和艺术处理，再按[视觉复核](visual-review-rubric.md#世界级品质与风格开放)说明阶段目标、实际表现和代表性。疑问留待同轮对照按画面职责核对。未达到适用目标的影响写在否决理由中，非阻断打磨可随通过保留。

同轮对照使用逐项 observations 回传阻断、可复查的问题和符合原目标的可观察答案。目标或参考用途仍无法确认时，明确缺失的对应关系，由制作方核对原登记。同轮作者说明与前后内比只供制作方按[返工交接](production-workflow.md#返工交接)使用。

任务目录位于 production/<周期>/review-tasks/<包ID>/。复制工具生成的 report-template.json 填写真实观察，invocation-template.json 仅是结构提示，不是真实调用。必须使用实际独立执行的身份、起止时间、读取文件及报告，计算真实调用记录摘要后绑定报告；不得手写 pass 或捏造调用。模板默认 insufficient/reject，未填写不能导入。

`inputPaths` 以 `outputs` 为根，列出实际读取的包内登记文件及清单。任务和空白模板属于记录辅助材料，同轮对照读取的本人盲报告使用 `readReportIds` 记录。格式修正保留原稿及修正原因，不改观察结论、不另造调用时间。报告 ID 由导入工具生成，不预填。完整类型、路径、时间和封存约束见[报告格式](review-protocol.md#媒体与报告格式)。

## 争议、探索与降级

实质争议由新代理按原目标独立复核，不读旧结论、不投票挑宽松结果。试制争议复核、暂停和重新选案按[暂停送审规则](production-workflow.md#试制暂停送审与重新选案)执行。内部比较中精度差异影响判断时才补齐，不凑固定候选数量。

按需探索观察使用匿名只读媒体、清单和真实调用，记录于现有研究／问题并标明探索性质，不冒充正式导入通过。随后正式验证使用未看过目标与探索结论的新上下文，保留具体缺陷及额外成本。

自审和外部意见可补充，但降级必须显著披露，不能关闭独立项或据此交付。来源与 AI 整图包装由作者技术核查，仍不进入视觉盲包。
