# 独立子代理评审

原生样品仍使用本页的隔离包和真实调用记录；静帧与完整局部过程须来自同一次采集。源码、素材来源和 AI 整图包装由作者另作技术审查，不送入盲包。未通过、证据不足或失效则继续打磨，不得降级自审交付；具体完成条件见[网页原生样品](design-samples.md)。

适用性与机器格式见[评审契约](review-contract.md)，本页只规定隔离执行。试制与终审均使用新建上下文子代理，只给当前隔离包；不提供 DESIGN.md、研究理由、源码、作者身份、旧结论或匿名映射。

先盲看并落盘观察，再在独立对照包中提供中性原条件和实际目标媒体。对照只能读取同一评审者自身同轮盲看，先前报告不能污染新盲看。时间、输入文件与阅读报告 ID 由真实调用记录保存，不伪造工具执行。

有选定视觉目标时，对照必须实际读取登记参考与采用特征，按对应画面/过程观察品质兑现、具体差距与限制；不把作者研究理由或“应通过”的解释送入包。盲看仍可发现作品自身美术问题，目标与采用范围留到对照。只有事实条件而无目标媒体的报告不能充当风格通过。

对照条件须包含去身份后的相关原始要求、实际媒体对应关系及用户限定范围，和作者转化明确分开。先核对转化是否擅自限缩，再核对兑现；发现“整体风格”被改成“仅终态使用”等例外时，不按放宽条件确认风格通过。原始要求缺失时说明对应目标未验证；不把选中、赞许或旧通过当作应通过的提示。执行依据见[采用边界](review-contract.md#采用边界与选案责任)。

抽象主体的局部辨认不默认成为精确读取门槛。盲看按完整画面判断可见职责与整体表达，对照再核原条件；按[信息职责](review-contract.md#抽象表达与信息职责)区分真实关键缺陷与次要打磨，不要求所有纸层字形逐字可读，也不因“抽象”声明自动通过。

终审使用未参与该作品前期试制的代理；常规一名综合终审，具体风险妨碍单人覆盖时显式分为结构、视觉文案两名互相隔离的终审者。时长、等级或追求高级本身不能作为增加人数理由。

## 执行与降级

代理只读取清单登记文件，按窗口、显示条件记录实际看见的帧、量测与限制。完整过程以完整解码、有序时间码帧、帧差/场景切分和主体区域量测核对；声音以响度、真峰值、静音、起音、频谱和同步量测核对。代理不声称实时观看或收听；指标缺失记 insufficient，不达设计预期记 fail。自审/外部意见可补充，但不能授权独立项关闭。

实质争议交给新代理先盲看后核对原条件，不读旧结论、不投票挑宽松结果；重复失败比较匿名的不同机制，精度差异妨碍判断时才补齐，分别记录收益和损失，不凑固定候选数量。

按需探索性比较同样使用只读匿名媒体目录、清单与真实调用记录：先落盘盲看，再给中性原条件及实际参考；不给作者推荐、解释或制作成本。观察记于现有研究/问题记录并标明探索性质，不伪造 review import、通过或关闭。若随后正式验证，使用未看过目标与探索结论的新上下文，保留具体缺陷和额外观察成本；不能称只有一次观察。默认正式 trial 的比较参照方式见[评审契约](review-contract.md)。

## 评审输出模板

报告 version=2，round 为 trial/final，reviewType 为 blind/consistency。每个 coverage 项与包内 id/window 完全一致，分别保存理解、表现、代表性的状态与观察，limitations 说明窗口、抽样、信号覆盖等限制。pass 必须全部覆盖通过，fail 必须有具体失败项。评审包与报告字段详见[媒体格式](review-contract.md#媒体与报告格式)。

盲看代表性仅判断当前所给局部的实际主体、排版、材质光影和完整过程是否充分、是否占位；不因盲包隔离未见目标而自动 insufficient。目标风格兑现留在同轮对照，不把两阶段职责混成盲看前置条件。

fail 须说明具体窗口、显示条件、违反的实际采用目标及阻断影响；整体目标成立后的次要改善写入 pass 的 limitations。该判断以实际观察为据，不把用户选案或作者期望送入盲包，也不新增字段、打分或审批。详见[采用边界与选案责任](review-contract.md#采用边界与选案责任)。

调用记录严格只含 id、reviewerId、freshContext、startedAt、completedAt、inputPaths、readReportIds；不添加 version 或 observationMethod 等扩展字段，观察方法写入报告。时间有时区且晚于包创建，输入只来自包内已登记文件。盲看 readReportIds=[]，对照仅包含自身同轮盲看报告 ID。

`freshContext` 记录评审代理最初创建时与作者上下文的隔离；同一隔离代理继续同轮对照时保持 `true`，不要求更换评审者。`inputPaths` 只列本次包内登记文件，自身盲看报告通过 `readReportIds` 单独追溯，不把包外报告路径再次放入 `inputPaths`。这两个字段的归类不改变实际读取范围、观察与结论；更正元数据须保留原件和原因，不补造调用。

## 评审包

只读包位于 outputs/review-pack/<id>/，manifest.json 维护净化媒体、原生与手机帧、时间码与摘要；实际源路径、源码依赖和采用目标留在包外私有绑定。盲看不包含目标媒体；有采用目标时对照在盲看导入之后建立。已投喂包不得修改，问题应重建新包。
