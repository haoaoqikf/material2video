# 独立子代理评审

本页只维护隔离执行。职责、轮次与失败关闭见[审核策略](review-contract.md#审核策略)，审美判断见[视觉复核](visual-review-rubric.md)，机器字段见[工具协议](review-protocol.md)。

## 隔离输入与执行

两类独立评审均使用新建上下文代理，只提供当前只读隔离包及工具生成的任务与空白报告模板，不提供源码、DESIGN.md、RESEARCH.md、作者解释、推荐、成本、身份、其他代理观察或历史结论。

盲审先核对清单登记的帧与适用信号并落盘观察，导入后用 review compare 自动派生同轮目标包。由同一评审者继续对照，只可读取自身绑定盲报告，不要求重新创建代理。目标包提供去身份的相关原要求、实际参考、中性采用范围；先核目标转化忠实性，再核实际画面。

正式关键片段默认直接创建 process 包，提供实际过程、参考与中性条件。先记录实际变化及可辨因果，再核目标。需例外盲审时遵循已登记的具体时间机制依据。研究试制仅送同源关键帧，动态全程由总代理按审核策略核验。

## 真实观察与记录

代理只读取清单登记文件，记录实际读取的路径、窗口、显示尺寸和限制。以静帧、有序时间码帧、完整解码、适用帧差／场景切分、主体区域和音频信号量测判断；不要求播放或试听，也不声称实时播放或主观听感。按实际机制补证，不给静态、无声或 cut 强加无关指标。

每项明确通过或不通过；具体观察要支持理解、实际表现和代表性判断，按[世界级标准](visual-review-rubric.md#世界级品质与风格开放)说明美术表现，不能只检查文字与技术。未知意图先保存疑问，在同轮对照核对，不臆定新要求。

任务目录位于 production/<周期>/review-tasks/<包ID>/。复制工具生成的 report-template.json 填写真实观察，invocation-template.json 仅是结构提示，不是真实调用。必须使用实际独立执行的身份、起止时间、读取文件及报告，计算真实调用记录摘要后绑定报告；不得手写 pass 或捏造调用。模板默认 insufficient/reject，未填写不能导入。

格式修正保留原稿及修正原因，不改观察结论、不另造调用时间。报告 ID 由导入工具生成，不预填。完整类型、路径、时间和封存约束见[报告格式](review-protocol.md#媒体与报告格式)。

## 争议、探索与降级

实质争议由新代理按原目标独立复核，不读旧结论、不投票挑宽松结果；重复失败比较实质不同机制，精度差异影响判断时才补齐，不凑固定候选数量。

按需探索观察使用匿名只读媒体、清单和真实调用，记录于现有研究／问题并标明探索性质，不冒充正式导入通过。随后正式验证使用未看过目标与探索结论的新上下文，保留具体缺陷及额外成本。

自审和外部意见可补充，但降级必须显著披露，不能关闭独立项或据此交付。来源与 AI 整图包装由作者技术核查，仍不进入视觉盲包。
