# 看图诊断与形象判据

本页回答两个问题：看画面发现问题时，它出在哪一层、怎么改；一个形象画到什么程度才算真的画了。

本页用于定位与返工，不新增验收门禁，也不替代独立评审对实际画面的观察。判据与诊断表只说明"这一处是否成立"，不判定整段合格。

## 一、症状 → 成因 → 改法

看图时逐条对。改法分三层：**形象**（美术方向与对象选择）、**取景**（事件、构图、相机与时间）、**实现**（参数、绘制方式、性能）。先判层级再动手；层级判错，改参数只会反复。

| 看图时发现 | 多半是因为 | 改法 | 层级 |
|---|---|---|---|
| 主体小小缩在中间，像一撮点或一段虚线 | 尺寸按"画得下"定的，没有先定屏幕占比 | 先定主体占画面宽度的目标比例与内部最小可辨单元，再反推缩放、排法与相机距离 | 取景 |
| 遮住字幕与标签，认不出画的是什么 | 画成了记号：只有轮廓或只有点线 | 加体积与材质（明暗、高光、厚度、遮挡）；仍不行就从一个观众认得的画面推进去；再不行回形象层 | 形象 |
| 字幕里的名词，屏上找不到 | 分镜阶段漏了这个名词，尤其开场 | 补画，或改句子。开场最常漏：台词说"你的血里"，画面却没有血 | 形象／取景 |
| 一大片发白、发糊 | 实心大色块吃了辉光 | 把实心物体画进不看辉光的底层，或在该段压低辉光强度 | 实现 |
| 小字压在主体上，读不清 | 标注直接放在东西旁边 | 移到主体外，用一根细线连过去；一镜最多一条小字 | 取景 |
| 有线或物体伸进字幕区 | 推近后别的东西被带了进来 | 退到暗处的东西连线条一起压暗；纵向字幕区保持清空 | 取景 |
| 字幕压在亮底上看不清 | 镜头钻进了亮的东西里面 | 这一段把那个东西压暗，或让字幕落到暗底上 | 取景 |
| 推拉镜头先平移、后猛冲 | 缩放与焦点都在线性空间里插值 | 缩放在对数空间走，焦点按缩放的倒数走 | 实现 |
| 一句字幕里画面变了好几处 | 贪多 | 拆成两句，或删掉次要变化 | 取景 |
| 连着几句画面没变 | 没给每句找到"那一处变化" | 回分镜表，每句写清改哪一处；确实该停的地方标为不画 | 取景 |
| 转场中间有几帧说不清在干什么 | 两个状态之间直接插值 | 换成一个说得出名字的动作（钻进去、卷起来、卡上去、倒放回去），或压到半秒以内 | 取景 |
| 与参考并排一看，自己又暗又空 | 主体不够亮、不够大，或只有线没有面 | 主体放大，给它颜色与体积；背景可以暗，主体不能暗 | 形象 |
| 颜色用满全片，每处都在抢 | 没有给颜色定单一含义 | 定一张颜色表，每种颜色全片只表达一个意思，从第一次出现到最后不变 | 取景 |
| 亮处都糊成一片 | 辉光范围盖过了主体结构 | 减少同时发亮的元素；把需要看清结构的物体放在辉光之外 | 实现 |

改的时候守三条：

- **看图，不看代码。** "代码应该没问题"不算数。改完重截同样的时刻，确认毛病没了、别的没坏。
- **动的地方要看动的。** 静帧好看不等于转场说得清。转场前后各抽几帧看。
- **拿别人的片子当尺子。** 把自己的静帧和参考帧并排：主体有那么大吗？认得出吗？有那么干净吗？

## 二、画得像它本身

形象选择的六问（见[讲解设计](explainer-design.md#找一个形象)）决定画什么；本节决定画到什么程度才算画了。

1. **有体积、有材质。** 明暗、高光、厚度、遮挡或接触关系至少具备其一。**在形状旁加一个名称标签，不算画出了这个物体。**
2. **从观众认得的地方进场。** 先给一个人人见过的画面，再推进到要讲的东西。把对象直接摆在无参照的底上，观众不知道它在哪、有多大、跟自己有什么关系。
3. **记号只当小字用。** 箭头、虚线框、代表分子的圆点、柱子可以贴在东西旁边做说明，**不能自己当主体**。
4. **载体由题材决定，不是只能画线。** 题材是文字、数轴、表格时，字与数就是合法主体；题材是器物、身体、场景时，就该有体积和材质。判断标准不是"用了什么画法"，而是"认不认得出来"。

三种情形的结论：

| 情形 | 结论 |
|---|---|
| 一个圆圈加标签"红细胞" | 没有画出红细胞。补厚度、中间凹陷与高光，或从血管推进去 |
| 全片主体是一串光点或几条连线，换给另一段文案同样成立 | 这是记号不是形象。回形象层重选，不是加装饰或换颜色 |
| 题材本身是文字或数学，主体确实是字与数 | 不因"不是实物"判失败；但字与数仍须有可辨的大小、位置与关系 |

## 三、主体尺度的起点

尺寸不要按"画得下"定，先定屏幕上的大小再反推。

- **主体占画面宽度**按可辨认需要确定。开场与核心揭示镜头通常需要明显更大，让观众一眼认出这是什么。
- **主体内部的最小可辨单元**（一颗珠子、一个字、一根刻度）须达到在目标观看尺寸下可辨的下限。
- 由这两项反推缩放、排法与相机距离，而不是先摆满细节再看效果。

这是**设计期起点**，与[参考风格契约](reference-style.md)里的事后量测分工不同：起点用于设计，量测用于核对。成片量测低于起点时，回到取景或形象层修订，**不通过调低阈值放行**。

比例与最小单元按题材与画幅说明适用性，不设所有画幅通用的固定像素值。

## 四、与既有检查表的分工

[讲解设计的看图改图检查表](explainer-design.md#看图改图检查表)回答"查什么"——遮住字幕还读得懂吗、名词都在屏上吗、不画的比例对不对。本页回答"看到问题之后"——它出在哪个层级、怎么改。

两者一起用：先按检查表逐项过一遍找出问题，再用本页的因果表定位层级与改法。检查表通过不代表画面对，因果表命中也不代表整段失败——是否成立按完整段落判断，由独立评审对实际画面观察。
