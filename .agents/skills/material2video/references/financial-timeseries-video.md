# 金融时间序列视频专题

本文定义金融视频的离线制作规范。专题入口独立于文章字数、口播和有声评审流程，行为以 [OpenSpec 专题规格](../../../../openspec/specs/financial-timeseries-video/spec.md) 为准。

## 制作与数据

请求由标的、日期范围及可选投资年份/买入日期、本金构成。股票与指数投资年份默认为展示区间首年，本金默认为 100,000，仅作为数值计算基数，不指定现实币种。crypto 可指定日历日期和 CNY 本金。制作准备阶段核验公开行情来源，项目代码不联网抓取行情。股票默认采用仅拆股、合股调整的日收盘价，不计分红再投资；指数采用来源明确的官方点位；crypto 使用 USD 日收盘价及独立 USD/CNY 汇率材料。保存原始响应快照、来源清单及 SHA-256；股票/指数预期交易日清单必须与实际价格日期逐项相同，crypto 必须完整覆盖每个 UTC 日历日。汇率周末或假日沿用此前最近的有效观测，不得向未来填充。

作品画面不展示资产报价。股票以投资年份首个真实交易日的拆股调整收盘价作为基准；指数以投资起始点位为基准。crypto 投资价值为“CNY 本金 × 当前 BTC/USD 收盘价 ÷ 买入日收盘价 × 当日或此前最近 USD/CNY 汇率 ÷ 买入日可用 USD/CNY 汇率”。因此买入日价值等于本金，后续同时反映币价与汇率变化。折线及纵轴显示组合价值，顶部显示投资标题、年份与当前市值；投资起点前不展示曲线或报价。所有模拟不计手续费及税费；股票不计分红再投资，指数按点位比例模拟且需注明指数不可直接持有。crypto 可通过 `investment.startRationale` 展示最多两行 18px 起点说明，与统计口径和风险提示共同参与手机安全区布局检查。可选的 `investment.legalStatusNotice` 用于配置该 crypto 作品的法律地位说明；配置后底部只显示起点说明（若提供）及法律说明，替代该作品估值口径和通用风险提示。法律说明同样纳入手机安全区布局检查，未配置时行为不变。作品不搜索、保存或展示事件，也不包含 K 线或周期选择。价格、汇率点和计划材料使用 `{date, close}` 日线。渲染仅读取本地材料，不联网。

## 材料与编排

作品使用三份材料：`request.json` schema v1、股票/指数 `prices.json` schema v3、crypto `prices.json` schema v4、`animation-plan.json` schema v8（兼容 v7）。crypto v4 另含 `fx`（`pair: "USD/CNY"`、`unit: "CNY per USD"`、汇率日期、点、来源和原始快照）。BTC 行情与 FX 来源覆盖、快照 SHA-256 和逐日日期完整性在离线校验时验证。请求标的可选 `instrument.displayName` 作为画面短名称；缺省时显示正式名称，正式名称和代码仍用于标的识别。材料目录不使用 `storyboard.json`，也不进入文章校验入口。

计划明确 `chartType: "line"`、`axis.dateScale: "staged-expanding"` 和 `axis.valueScale: "revealed-linear"`，不接受滚动窗口或固定纵轴范围。新计划默认 1080×1920、30 fps、无音轨，开场 1 秒、推进 57 秒、终幕静止 2 秒，总长固定为 60 秒，不随展示跨度变化；`--duration-seconds` 可显式指定其他时长，至少 4 秒。此默认只用于新生成计划，既有 v8 计划保留已保存的分段与日期映射；v7 保留原有 90 帧开场、120 帧结尾和匀速映射（30 fps 下分别为 3 秒与 4 秒）。横轴按覆盖自然年份数取 ceil(N / 6) 年步长生成不超过六个阶段，开场显示第一阶段；播放日期将在 15 帧内越过阶段边界时，以 smoothstep 扩展到下一边界。起始日期固定在左侧，曲线、网格和刻度使用同一映射，历史点持续保留。横轴标签按完整日期范围确定不超过四个、不重叠的固定锚点，随着可视范围扩展逐个显现并保持至片尾；后半段保留较晚年份，终幕显示结束年份，避免逐帧重算造成标签闪烁。单年范围直接显示完整日期范围，终幕保持完整横轴和曲线。休市日市值沿用最近真实收盘价推导的组合值，不插值也不提前显示未来价格。

纵轴根据投资起点至当前日期已展示的全部组合价值极值线性自适应，上下各留白 8%。采用六帧因果加权范围并以当前范围包络，保证新极值不裁切；终幕冻结最后推进帧的坐标。历史曲线始终完整，随机寻帧与顺序播放一致。

绘图区裁剪采用 x=224～924、y=490～1260 的局部坐标，裁剪与折线随同一前景变换移动，禁止在裁剪矩形坐标中再次叠加整体居中位移。每帧检查有效裁剪边界与可见绘图区一致，并检查未经裁剪的全部历史折线包围盒；历史峰值或低谷越过有效裁剪边界时阻断预演及正式导出，错误消息包含绘图区、裁剪和折线边界。不能用最新端点在安全区内代替历史曲线完整性检查。

画面使用项目布局边界 x=140～940、y=180～1740，纵轴刻度使用同一边界；该默认边界不代表抖音官方安全区规范。字体必须使用注册的 `M2V Inter` 与 `M2V Sans`，数字使用等宽数字样式。标题、指标、坐标轴、折线、端点和底部说明组成同一前景层；渲染时测量实际可视元素的整体包围盒，将其垂直中心自动对齐 1080×1920 画布中线 y=960，背景与画布不变。边界探针必须检查应用变换后的整体、文字和端点；内容高于布局可用高度或元素越界时阻断，不扩大边界、不缩字或裁切。统计口径换行或其他内容边界变化时重新计算居中位置。顶部不再显示独立大年份；单行投资标题左对齐、40 px、字重 700、字距约 -0.02em，股票标题格式为“假如你2020年买入10万元苹果”，即假如你＋年份＋买入＋本金（含元）＋标的，标的优先使用 displayName，否则使用 name，不自动追加“公司”；指数标题保留按比例投资表述，本金同样以元结尾。当前市值作为右对齐 hero 金额，从 72 px 起按 72/64/56 固定档位适配右侧宽度，不逐帧按字符串反推字号；金额下方以 24 px 次文字显示“当前市值 · 最近实际收盘日期”。投资起点前隐藏市值和日期。推进阶段不显示收益金额和收益率。结尾冻结完整曲线和坐标，沿用最后推进帧的当前市值及实际收盘日期并静止停留；不显示本金到最终市值总结或收益率，也不进行淡入。市值使用中文数量级（万、亿、万亿）并以“元”结尾，数字与单位之间不加空格，金额与纵轴刻度不使用千分位分隔，不显示美元等具体币种名称；底层仍使用原始计价单位，不换汇。正收益时市值和折线为红色 `#FF5A4E`，负收益为绿色 `#4BD39A`，持平时为中性暖白 `#D8D4CC`，市值与曲线同色。投资价值端点圆点继续跟随最新真实收盘点；当前金额和日期已在画面顶部同步显示，图表内不重复绘制金额标签、文字或底板，避免覆盖历史曲线。历史折线保持完整可见，端点圆点绘制在折线上方，并由边界探针验证其绘制顺序和布局边界。投资价值以双层呈现：主曲线按自然月取最后一个真实收盘点并以单调三次插值连接，线宽 3 px；全量真实日线以 2 px、0.26 透明度作为波动纹理；主曲线叠加 12 px、0.08 透明度的外描边光晕，不绘制面积填充。端点半径 7 px，外侧增加 14 px 同心外环和淡竖向参考线；推进段外环可轻微呼吸，结尾冻结段停止。本金落在当前纵轴范围内时绘制 1.5 px 虚线基准线，并在右侧空间允许时以 20 px 小字标注“本金”；基准线距绘图区底部不足 28 px 时只保留虚线，不显示收益金额或收益率。背景使用近黑 `#0A0A0B` 径向光晕并叠加极细噪点，光晕位置可随帧缓慢移动；网格、日线、主曲线和端点按由弱到强的明度分层。纵轴只显示 3 个刻度（底、中、顶），字号 24 px，右对齐于 x=188，数量级单位只在轴顶标注一次，刻度只显示数字并按当前刻度间距决定统一小数位，不得出现重复刻度值；超宽标签水平压缩，保持字号。网格只保留 3 条约 9% 透明度的横线，不绘制竖网格或坐标轴线。横轴只显示已到达的年份，字号 28 px。绘图区范围为 x=200～920、y=500～1280。底部统计口径不大于 24 px，风险提示不大于 22 px。底部说明区不显示来源标签或来源网站名称，仅显示统计口径（仅拆合股调整、不计分红再投资、手续费或税费）以及最多两行风险提示“过往业绩不代表未来表现。本视频仅作信息展示，不构成投资建议。”；完整来源仍保存在作品材料中（sources 字段当前不渲染），来源核验要求不变。

正式导出前必须通过完整静音预演自动验收。预演记录绑定当前准备指纹、全部材料和构建资产摘要、完整帧数及视频 SHA-256。`labelsReadable` 必须实际检查 360×640 缩放画面、安全区以及顶部市值日期和图表端点圆点，并确认图内没有遮盖历史线的重复金额标签或底板；纵轴刻度在该缩放下不得低于约 7 px 实际高度（1080 px 宽画布上 22 px 字号），只看原尺寸不能通过。预演和正式渲染逐帧检查画布布局边界、仅圆点端点标记和完整历史裁剪；历史峰谷或连接线越界、旧版或短预演、摘要不匹配均阻断正式导出。

## 波动节奏与计划锚点

v8 的 `pacing` 必须声明 `mode: "volatility" | "uniform"` 和 `anchors: [{frame, date}, ...]`，frame 是全片绝对帧。锚点至少两个，帧严格递增、日期单调，首末必须精确绑定推进首帧和末帧及展示起止日；相邻锚点线性插值，日历日期向下取整，报价只取已到达真实收盘数据。uniform 仅接受首末两个锚点。

新计划默认 volatility：按自然月统计绝对对数收益累计量及组合市值绝对变化累计量，分别除以全区间月最大值，以 40%/60% 组合；权重为 1+2×组合分数，限制为 1～3，按覆盖日数加权分配推进帧。涨跌均可放慢，投资起点前权重为 1，平盘退化为匀速。月边界分配为整数帧，重复帧合并，准确保留首末锚点。节奏可使用全区间行情作为剪辑依据，画面报价及纵轴仍不提前显示未来值。渲染只读取已保存锚点；Python、前端和横轴扩展使用同一映射。不保证每个交易日均有单独画面。

## 显式迁移

v7 仍可读取及渲染，保持旧日期映射和 120 帧结尾；不能用 plan 静默覆盖。已有统一作品使用 `uv run m2v financial migrate-line --project <目录> --duration-seconds 60` 备份后升级 v8；尚无 project.json 的历史作品先使用 `m2v migrate --from financial` 进入统一作品契约，旧 v1～v6 会同时升级 v8，v7/v8 保留原计划。v8 重复升级被拒绝。

迁移前备份请求、价格、计划、旧事件及评审/预演记录；保留 date/close、来源、快照、交易日与截止日，清理过期金融评审。失败恢复活动材料，已有成片不变。升级后必须重新 prepare，再 render 一次生成并验收候选。

## 命令

```powershell
uv run m2v init --type financial-timeseries --project <slug>
uv run m2v validate --project videos/financial-timeseries/<slug>
uv run m2v financial plan --project videos/financial-timeseries/<slug> --duration-seconds 60
uv run m2v prepare --project videos/financial-timeseries/<slug>
# 可选片段检查，默认前十秒且严格短于全片
uv run m2v preview --project videos/financial-timeseries/<slug>
uv run m2v render --project videos/financial-timeseries/<slug>
# 旧金融材料的迁移使用显式、备份优先的操作；先按当前材料契约核对迁移来源版本
uv run m2v migrate --project videos/financial-timeseries/<slug> --from financial
```

`init` 仅创建待填模板。价格来源、真实行情、来源快照和日期清单核验完成后再生成计划并运行 `validate`。`--period` 和 `--window-months` 已移除，旧 v1–v6 计划或旧材料必须先运行 `migrate-line` 显式备份迁移。`preview` 默认只生成前十秒，支持起止时间与限帧，拒绝全片，不登记旧预演门禁。`render` 要求有效统一作品与准备记录，完整候选只生成一次，验收后复制交付；重复执行复用候选，失败不覆盖旧成片。金融视频材料和生成媒体均位于忽略的作品目录或外部内容根中；共享制作方法和规范纳入版本控制。成片与预演经临时目录中转，Windows 上会带上临时目录那份「关闭继承」的 ACL，因此落盘后统一用 `icacls /reset` 重新继承所在目录的权限（必须搬运之后执行，在临时目录里修复只会再套一遍那份收紧的 ACL）；否则以标准权限运行的打包播放器打开交付视频时报 `0x80070005`。预演同样是给人打开的文件，也一并修复。

## 专用图表审美复核

金融作品沿用金融专用画幅、曲线、标题、数值和声音契约。设计记录补充核心感受、视觉主体、情绪或节奏变化、审美禁区及可观察目标。用代表帧对照同一数据段的两个视觉方向，并覆盖开场、整体趋势、关键转折和终幕；在原始画布、声明的手机尺寸及缩略图尺寸检查趋势辨识、转折强调、文字层级与留白。粗预演标注信息、曲线推进和视觉强度的变化理由，先删冗余信息或调整叙事节奏，再改速度。精修依次检查视觉重心、信息层级、色彩与材质、运动、细节；金融图表惯例与数值事实优先，不能套用 general 代码场景或电影化运镜。把差距、修改与同一帧前后对照写入作品 DESIGN.md 和 visual-notes.md，不新增材料字段或导出门禁。
