# 百万播放潜力检查与预估报告

本页把「百万播放潜力」作为全程创作目标，而不是发布后的承诺。所有作品在策划、场景设计、
制作、逐场检查、全片检查和最终完成阶段都要检查同一组传播因素，区分未实现假设与实际证据；
最终在 `outputs/reach-potential-report.md` 形成绑定当前成片的定性预估。

判断不新增运行时字段、审美评分、概率预测、平台接入、用户审批或导出机器门禁。报告与作品
检查记录一样属于作品产物，不进版本控制；制作完成后由 `outputs/visual-notes.md` 直接链接，
使其在成功交付后的清理中保留。

## 检查因素

每个阶段都检查下列因素，但只写当前确实知道的：

| 因素 | 要回答的问题 |
|---|---|
| 目标平台与受众 | 面向谁、在哪种观看情境下播放，画幅与时长是否匹配 |
| 题材需求 | 观众是否已经关心这个问题，或有足够强的生活经验触发点 |
| 开场吸引 | 前两秒能否看见主题、主体或有效动作，是否有继续看的理由 |
| 理解成本 | 关键概念、名称和数字是否需要额外背景；是否先给现象再给术语；标题是否像日常中文、是否避开“十大 XX 事件”“XX 权益”这类名词堆叠与公文式表达；无背景观众能否复述每项事件 |
| 持续观看 | 中段是否有新信息、新变化或新的问题推动，而不是重复解释 |
| 核心发现 | 看完后能说出的那一句新认识是什么，是否足够意外又可信 |
| 视觉记忆点 | 是否有可截图、可复述的具体画面，而不是只有文字结论 |
| 分享讨论动机 | 观众为什么愿意转给别人，或拿它解释自己的经历 |

每场均须说明传播贡献与流失风险，按其解释、蓄势或高潮等作用判断；不要求每场都强刺激，
也不把安静的解释场判为失败。

## 阶段检查表

| 阶段 | 记录内容 | 允许的结论 |
|---|---|---|
| 策划 | 平台、受众、题材需求假设；要回答的生活问题；预估核心发现 | 假设；尚未有作品证据 |
| 场景设计 | 每场传播贡献、记忆点设计、流失风险；主线与补充的分工 | 设计假设；标注待验证 |
| 制作 | 实际实现的画面、节奏与声音是否兑现设计；实现差距 | 假设 / 已有局部证据 |
| 逐场检查 | 每场在真实帧序列中的可辨性、信息推进与风险 | 实际证据；问题闭环 |
| 全片检查 | 开场、中段、高潮、结尾与整体记忆点；重复或长等待 | 实际证据；必改项 |
| 最终完成 | 绑定最终文件与准备指纹的定性预估与反面依据 | 支持具备潜力 / 证据不足 / 当前未达到 |

阶段记录写在 `DESIGN.md` 与 `outputs/visual-notes.md`，只引用当前版本的有效证据。准备指纹或
成片摘要变化后，旧结论失效。

## 最终报告

报告路径固定为 `outputs/reach-potential-report.md`，使用中文，必须包含：

| 部分 | 内容 |
|---|---|
| 绑定信息 | 最终 `video.mp4` 的 SHA-256、准备指纹、时长、画幅与报告生成时间 |
| 预估结论 | 「支持具备潜力」「证据不足」或「当前未达到」之一；不使用概率或代理分数 |
| 支持依据 | 具体时间码、画面行为、逐场贡献与视觉记忆点 |
| 反面依据 | 已有的流失风险、理解门槛、表现差距或未覆盖范围；由独立子代理按[独立子代理评审](subagent-review.md)专门生成至少 3 条，不得由制作助手自拟 |
| 逐场贡献 | 每场承担的解释、蓄势、高潮或记忆点，以及风险 |
| 阻碍因素 | 内容、表现或分发层面的可改进项；可修改项须说明是否返工 |
| 平台与账号条件 | 已知条件；未知的账号基础、推荐机制或发布时间如实写「未知」 |
| 发布后验证 | 若获得真实数据，用哪些指标和对照验证或推翻本预估 |

结论允许否定。不得保证播放量、虚构概率或平台指标、用审美分数替代判断，也不得把设计阶段
的正面假设复制成最终结论；最终结论必须基于当前成片的实际证据。

可修改的内容或表现不足触发相应回退；连续两轮没有改善必须换方法或方案。发布条件未知或缺少
真实数据时列为不确定性，不以未知分发结果无限返工，也不因此伪造「有潜力」的肯定判断。

## 判断演练

> 以下为演练，不是某支作品真实发生的失败。演练记录只用于验证规则可执行，不写入交付证据链。

| 情形 | 输入 | 必须得出的结论与动作 |
|---|---|---|
| 无证据肯定 | 报告写「画面精美、节奏紧凑，必过百万」，没有时间码、逐场贡献或反面依据 | 报告未完成；结论降为「证据不足」，补真实帧序列证据后才能重判 |
| 未知账号 | 已完成内容评估，但没有账号粉丝、平台推荐或发布数据 | 给出有条件的定性预估，账号与分发因素写「未知」，列出发布后验证方法；不编造播放概率 |
| 实际效果不足 | 证据显示中段连续 20 秒无新信息，核心发现只在旁白中出现 | 结论写「当前未达到」或回退返工；可修改的表现问题必须修复，不能以未知分发为由放行 |

## 与清理的关系

成功交付后的清理只保留当前成片、候选、准备与评审记录，以及 `visual-notes.md` 直接引用的
本地证据。因此 `visual-notes.md` 必须直接链接报告与报告中引用的关键证据文件；不要只链接目录、
符号链接或作品输出目录之外的文件。报告本身是 Markdown，不会被媒体清理删除，但其引用的图片、
帧或样片只有在 `visual-notes.md` 中出现直接链接时才会保留。
