# 营销号式口播剪辑制作指南

## 1. 适用范围与表达目标

本指南适用于以口播带主线、用实拍及外部素材组织画面的知识解释、故事解说、观点表达和热点解读，归入 `documentary-edit`，不新增类型。“营销号式”在这里指面向短视频观看的吸引、推进与回报方式，不等于商业广告，也不要求夸张标题、机械配音或高频切镜。

本页补充编导操作，不替代技术契约，不新增制作阶段、审批、审核轮次、材料表单、分镜字段或数值门槛。四类口播结构、下文表格和演练都是可选方法，不是需要逐项填满的合同。

开始时用简短创作任务明确：给谁看、只讲清楚什么、为什么值得继续看、看完得到什么，以及用户的原始要求、内容立场、目标画幅与时长。把事实、观点、建议和假设分开；助手自拟内容注明作者身份，不能当成用户观点或真实采访。无需另建任务表，沿用[全片与场景设计的记录分工](scene-design.md#分工与对应)。

### 接入现有三阶段

| 阶段 | 本类作品的工作 | 权威入口 |
|---|---|---|
| 研究与创意试制 | 实际查看具体标杆并转为本片方案。为主要段落查找动态片段，涉及社媒发言时查找原帖截图。按适用时长规则验证方向 | [研究与创意试制](stage-research.md) |
| 正式设计 | 组织口播主线、镜头任务、共同视听语言；以实际旁白时长细排视频片段、证据和字幕，检查全片推进 | [完整设计与预演](stage-design.md) |
| 制作与验收 | 实现并检查完整表达，修复文画错位、节奏和技术问题，完成适用的独立评审、技术 QA 与整片复核 | [制作与验收](stage-production.md) |

样片适用范围按[审核策略](review-contract.md#审核策略)判断。研究和验收分别沿[研究入口](stage-research.md)与[验收交付](stage-production.md#验收交付)执行。

## 2. 选题与内容角度

先缩小问题，再写文案。宽泛主题只能提供题材，不能自动提供一条视频的主线。

- 从观众能认出的具体情境切入：谁遇到了什么，哪里与直觉不同，或者哪个结果值得解释。
- 明确结尾能兑现的收获：解释一个现象、理解一次选择、知道一个故事结果，或获得一种可尝试的方法。不要把多个平行主题塞进一条短片。
- 区分“值得讨论”与“已经证实”：经验建议不包装成普遍规律；情绪共鸣不替代事实依据；个人经历不代表所有人。
- 在锁定依赖特定画面的论点前，检查关键证据和过程素材是否可得。不可得时调整角度，不让随机搜到的素材反过来决定事实。

例如，“提高效率”过宽；“写东西时总想起别的任务，可以怎样接住这些念头”更容易落到具体动作和可执行建议。它可以是自拟生活观点，不必伪装成心理学实验结论。

删除一段时若不影响观众的理解、情绪或结果，该段可能只是重复；补入一段时先说明它增加了什么，再决定是否保留。无需强制制造争议、反转或焦虑。

## 3. 标杆研究与本片转化

创作前完整阅读[创作总纲与灵感](visual-expression-inspiration.md)，按[具体标杆与深入拆解](reference-video-analysis.md#选择具体标杆)研究实际可查看的作品。参考可以来自同题材口播，也可以来自广告、电影、采访或其他领域；风格名称用于拓展探索，不作为美术验收条件。

围绕当前决策查看开场、推进、转折和收束的适用窗口，不按固定数量搜集链接：

- 开场靠什么让观众进入：具体动作、未解问题、人物处境，还是先给一个有价值的结果？首个画面与首句有什么关系？
- 正文如何提供增量：补背景、展示动作、举例、引入障碍还是改变判断？哪一次切镜真的公开了新信息？
- 整体品质如何形成：主体比例、取景、光色、档案与新素材的关系、字体层级和画面密度怎样共同建立感受？不能只写“大字、快切、有冲击力”。
- 声画如何配合：哪里人声主导，哪里动作或环境承担表达，哪里留白；只有静帧时不补写听感或运动观察。
- 本片换成自己的内容后，哪些机制仍适用，哪些需改构图、画幅、节奏或载体？用什么实际窗口核对？

研究按“实际观察 → 效果解释／推断 → 本片应用 → 验证办法”关联起来，记录实际查看范围与限制，沿用[研究记录](stage-research.md#记录)，不另建一套营销号研究表。已有有效研究按未知补查；下文教学演练不能替代某部实际作品的标杆研究。

参考的传播数据若可核实，只能说明对应作品的已知表现，不能证明某种处理必然带来完播率或转化。没有数据不编造“爆款验证”。研究用途与素材入片用途分开，见[参考素材使用边界](reference-video-analysis.md#素材使用边界)。

## 4. 口播文案编写

### 按内容选择四类结构

| 口播结构 | 适合内容 | 一种可选推进方式 | 容易失效的地方 |
|---|---|---|---|
| 问题解答型 | 知识、生活现象、行业解释 | 现象 → 问题 → 解释或方法 → 回答开场 | 只抛问题不回答，或把相关性当因果 |
| 故事推进型 | 人物、事件、商业故事 | 处境 → 冲突 → 行动 → 结果及影响 | 编造对白、内心和转折，或用结论替代行动 |
| 观点论证型 | 社会观察、生活观点、情绪表达 | 观点 → 具体场景或例子 → 分析与边界 → 收束 | 反复换词表达立场，没有新依据；把自拟例子当实事 |
| 热点解读型 | 新闻、公共事件、产品动态 | 发生了什么 → 必要背景 → 已知影响 → 未知与判断 | 旧素材冒充现场，把传闻和推测说成已确认事实 |

可以混合结构，不要求每条都有反转或高潮。热点型要说明事实对应的日期、对象与版本，不把背景解释写成后续结果已发生。

### 把书面材料变成能说清楚的话

1. 保留原文必要立场与事实限定，提取这条视频的主判断；改写不能悄悄扩大结论。
2. 开场直接给场景、问题、冲突或结果，删去无信息的自我介绍与空泛铺垫。热点解读先用一个具体动作或冲突点明核心人物与事件，再紧接必要的时间、背景和影响。
3. 每个段落承担新的叙事工作：建立、解释、举例、反证、转折或回报。让指代能认回，因果有依据。
4. 把长定语、抽象名词和并列结论拆成口语短句；必要数字、单位、专名保留准确含义。使用本地中文配音时按[后端限制](voice-and-rhythm.md#口播合成与混音)整理为可合成文本，不让工具偷偷改写事实。
5. 结尾回答开场承诺，必要时给适用边界或可尝试动作，不在最后突然补入尚未论证的重大主张。
6. 按实际合成的旁白与停顿调整篇幅，再细排镜头。超时先删重复、缩小主题或改写，不截断人声、吞掉限定词或一味加速。

不固定字数、句长、开场秒数、钩子间隔或口播速度。是否清晰、有起伏，须看当前文本、实际时间与画面组织。

## 5. 文案转镜头：对象、动作、身份与时间窗

先明确观众在这一段要看懂什么，再找素材。逐段在既有场景设计里写清以下关系即可，无需增加表单：

- **对象**：画面必须出现谁或什么，哪些只是环境。
- **动作**：对象正在做什么，建立、动作、结果中哪些必须看见；单纯“有人办公”不能替代“被消息打断后重新找回位置”。
- **身份限定**：是否必须是指定人物、公司、产品型号、地点、年代或事件；若是泛生活情境，说明不指代具体当事人。
- **时间窗**：需要覆盖哪个完整过程、前后哪些上下文；拿到素材后核对真实源片区间，成片窗口按实际旁白细排。源视频时间与成片时间不可混用。
- **表达职责**：承担证据、解释、对象识别、情境建立还是情绪承接；一段可兼任，但不能用情绪画面冒充事实证据。

例如“消息一来，他又忘了刚才写到哪里”，需要让工作位置、干扰和返回后的重新寻找形成可认关系。若来自不同人物、不同房间的零散镜头，就不能装作一件连续发生的真实事件；可改成不特指某人的情境组接，或使用明确的界面示意说明关系。

切换时保留必要的对象线索和方向，构图为动作及字幕留空间。精确入出点在分镜／代码维护，设计只写编排与引用，不手抄另一份全片时间表。深化方法见[从五维意图到场景决策](scene-design.md#从五维意图到场景决策)，载体职责见[素材叙事任务](visual-material-selection.md#先确定素材的叙事任务)。

## 6. 素材检索、采用与缺口回退

### 按镜头缺口找，而不是按旁白名词贴图

营销号式口播默认以实际播放的实拍、采访和动态档案片段剪成全片主体，覆盖大部分叙事时长。排镜时为各主要段落选择能承担叙事任务的具体片段，照片优先用于封面、人物识别和适合停留的静态证据。代码合成主要承担时间线、读数、高亮、字幕和转场等辅助表达。检查整体素材比例时，静态照片的推拉和代码动画按各自载体计算。

通用口播画面先查 Pexels 和 Pixabay；具体人物、企业、事件与过程先查对应原始发布者、官网／官方账号及可追溯档案，再按缺口扩展新闻、行业或其他公开来源。对象、动作、身份限定可以换语言和别名组合，详见[按用途选择来源](material-sourcing.md#2-按用途与对象选择来源)与[检索词写法](material-sourcing.md#3-检索词怎么写)。

当前内置图库 API 搜索仅启用 Pixabay，Pexels 走网页选材及公开媒体直链导入；实际参数见[可选图库检索](article-media-and-sound.md#可选图库检索)。本页不表示通用网页下载、自动长视频选段、自动转录、视觉语义检索或跨作品素材库已经实现，不提供规划中工具的伪命令。

面对长视频，可以利用实际存在的章节、说明或字幕缩小人工检查范围，再核对真实画面。字幕说到某物不等于画面出现该物，出现该物不等于发生所需动作，切镜点也不等于动作完整。接触表用于快速筛候选，最终按[实际可用片段](visual-material-selection.md#检查实际可用片段)核对使用窗口与相邻边界，不把单帧当连续性证据。

### 真实来源与采用边界

- 口播引用 X／Twitter 或其他社交平台发言时，优先查找并展示原帖截图或平台官方嵌入截图，按[社媒截图与引用媒体](material-sourcing.md#51-社媒截图与引用媒体)核对、留证与回退。
- 图库人物可承担泛生活情境，不能暗示其就是文案中的具体当事人；图库工厂不能证明指定公司的产线，其他日期的活动不能冒充本次事件。
- 自拟场景、代码示意不冒充采访、历史记录、实验或真实产品状态；引用不歪曲原意，裁切与重排不改变事实。AI 图片用途沿用[载体边界](visual-material-selection.md#载体选择)，不能补造证据。
- 来源、作者、许可及检查范围如实记录，未知不补造。采用政策统一见[采用与署名](material-sourcing.md#5-采用政策与署名)，不增加逐件审批、授权前置或额外素材禁用规则；可下载不等于已获授权，下载失败也不自动意味着禁止使用。
- 普通人物照片和视频直接出画，身份优先用口播交代。仅在画面与叙事提到的时间、地点、事件或现场关系容易混淆时，按[采用与署名](material-sourcing.md#5-采用政策与署名)用小字标「资料画面」，并写清必要的年份或场合。证据来源和示意边界按用途标明，必要注释避开主体与字幕。
- 外部媒体统一按[媒体导入契约](article-media-and-sound.md#媒体进入作品的唯一路径)进入作品；准备和渲染读本地登记文件，不在渲染时临时联网找图。`usableSegment` 仅是候选检查窗口，当前不渲染、不自动裁切，见[来源字段](article-media-and-sound.md#来源与采用依据字段)。

### 缺素材时怎么继续

| 当前缺口 | 可执行的回退 | 不应做的替代 |
|---|---|---|
| 缺通用动作视频 | 换动作同义词、景别或来源；仍缺时判断代码能否解释过程，再决定静态载体或改稿 | 用同题材无关动态凑数 |
| 缺具体事件原件 | 找可追溯原始记录；若仍缺，收窄主张、改表达或删去无法支撑的部分 | 用图库、代码或生成内容假造现场 |
| 只有静态原件 | 原件本身是阅读对象时直接展示；为上下文和必要细节留观察时间 | 推拉照片伪装为真实动作 |
| 动作窗口过短或裁切丢主体 | 换片段、调整布局，或缩小旁白所承诺的过程 | 循环、倒放或拼接伪造一次完整过程 |
| 页面能看但未取得文件 | 如实保留获取状态，换可得原始来源、公开直链或已有本地文件；必要时改镜头 | 把网页缩略图或参考分析目录冒充已导入媒体 |

载体回退顺序与静态任务例外以[视频优先与代码适用场景](visual-material-selection.md#视频优先与代码适用场景)为准。回退原因简记在受影响场景，未知与失败沿既有记录处理，不增加检索次数配额或等待“完美素材”的无限循环。

## 7. 配音、字幕与声音

### 先判断表达，再调声音参数

营销号式口播默认使用 Qwen3-TTS 的「真人播客女」，即《黄仁勋辞职》短片使用的 `clone_screenrecorder-20261114-174828`。用户明确指定其他音色时按指定执行。开工时按音色 ID 查找同一份已登记档案，在作品内登记参考音频、参考文本及来源，按其授权范围使用。后端、音色查询和实际合成沿[配音音色与语速](voice-and-rhythm.md#配音音色与语速)。

语气、停顿和语速按完整旁白调整。生活建议可以亲近而克制，故事可以随处境变化，热点解释应让观众听清已知事实和判断。

拿到实际旁白时长后，查看句间停顿是否服务于理解、观察、转折或回味。单纯拉长所有停顿会拖慢，单纯加速会丢层次；先改文本，再按需调整语速与[停顿整形](voice-and-rhythm.md#停顿节奏韵律整形)。改稿、换音或调整时间后重新准备并检查受影响镜头，不用估计字速代替真实音轨。

### 字幕承担听懂与读懂，不抢第二条主线

- 按语义组织口语，字幕时间与断句使用[真实词边界](prepared-and-subtitles.md#时间戳字幕与缓存)，不手填猜测时间。
- 让句子中的否定、条件和对象关系完整，不能靠分屏或断行改变意思。长句难读先改稿并重新准备，不堆更多强调字救场。
- 主体、原件文字、字幕与必要来源标记分主次；在实际画幅及声明的手机尺寸检查换行、对比、遮挡和停留。字号不照搬另一条视频，见[字幕字号](prepared-and-subtitles.md#作品级字幕字号)。
- 只有需要时用双语次行，沿[双语字幕契约](prepared-and-subtitles.md#双语字幕与自适应柔光)；不默认添加逐字跳动、同步大字或附加小字解释。

### 配乐、原声和音效按职责取舍

先保证旁白承担的信息可辨，再决定是否需要配乐、环境或动作声。原素材画面可用不等于原声也自动采用；第三方音频、字体与画面素材分别遵循自身契约。声音可以建立干扰、动作或情绪对比，也可以不用；不要求每次切镜有音效。

提示音、拟音与配乐的变化须与表达节点对应，不能用更响的音乐代替论证或情绪铺垫。检查使用窗口、起音、层级与旁白压低／恢复，按[声音设计与排查](voice-and-rhythm.md#声音设计与排查)及[声音契约](article-media-and-sound.md#声音)执行；自动响度合格不等于听觉层次已经成立，不凭无音频依据的静帧写听感结论。

## 8. 剪辑与节奏

剪辑的单位是信息、动作和感受的变化，不是固定秒数。

1. 先用口播与必要画面组成全片骨架，确认开场的问题在结尾被回答；暂未取得素材的地方保留未验证状态，不用占位证明成片成立。
2. 以新信息、动作阶段、视角变化或情绪转折决定切点。动作值得看完就保留完整过程，原件需要理解就让它稳定，不因“必须动起来”强行运镜。
3. 对齐讲解节点与可见变化：不要在讲结果时动作还未发生，也不要在字幕尚未读完时切掉关键证据。旁白与画面可以有意错开，但错开须有明确承接作用。
4. 用景别、运动／静止、声音／留静和信息密度形成强弱。要加快先删无增量内容；要停留先说明观众此时在看什么，不以空等填时长。
5. 转场先考虑问题、对象、动作方向与声音能否接续，再决定硬切、匹配或其他手法；不用特效也可以成立。避免不同来源的人物、空间、产品版本被误认作连续实录。
6. 以当前有序帧、帧差／场景切分和适用音频信号核对过程、跨场衔接及整片疲劳；按[全片预演](stage-design.md#全片预演)迭代，不新开例行审核阶段。

不规定每隔多少秒切镜、反转、换音乐或放大字幕。效果失败先定位文案、设计、素材或实现的问题，按[返工循环](production-workflow.md#检查与返工循环)修复，不用堆转场掩盖主线空洞。

## 9. 标题、封面与发布文案

包装和正文应共同设计：**标题提出承诺，封面帮助认题，开场建立问题，正文完成兑现，结尾收束回报。**

- 标题可以用具体问题、冲突、反差或结果，但其强度不能超过正文依据。正文只有建议，就不要包装为“实验已证明”“唯一答案”或保证见效。
- 封面选与正文一致的对象和视觉关系，主文案聚焦一个可识别的主题。不用无关人物、伪截图或拼接画面暗示不存在的事件与代言。
- 开场尽快让观众知道正在看什么、为什么值得继续；无需机械重复标题全文，也不能一直拖延兑现。
- 片尾直接落在正文结论，沿用[采用与署名](material-sourcing.md#5-采用政策与署名)的片尾规则。
- 发布文案补充必要背景、事实日期及实际内容边界；有商业推广时如实交代，不把宣传立场伪装成中立事实。公开署名和完整素材记录按[采用与署名](material-sourcing.md#5-采用政策与署名)执行。
- 互动问题应来自正文，例如请观众分享自己的处理方式，而不是捏造群体对立。是否需要关注、购买或其他行动引导随用户目标决定，不设每片必有的结尾模板。

复核包装时，沿正文逐句找兑现位置：是否真给出了所承诺的原因、故事结果、方法或比较；若没有，补足内容或降低包装承诺。没有实际发布数据，不宣称本片已经提高点击、留存或转化。

## 10. 完整文内演练与问题修正

### 演练范围与状态

以下是**助手自拟的生活观点与假设编排**，不是用户立场、真实个人经历、心理学研究、实验结论或已完成作品。没有为本演练实际搜集标杆、取得素材、合成声音、渲染或评审；表中均是待执行设计，不是观看记录。演练只示范从内容到镜头的思路，不新增仓库视频示例，也不能代替实际制作所需的研究。

### 从原始材料到角度

- **自拟材料**：准备写一段文字时，想起回消息、找资料和别的待办；每次临时切走，回来还要找自己刚才写到哪里。希望给这些念头一个存放位置，而不立刻逐一处理。
- **受众与目标**：面向有相似日常困扰的观众，提出一种可尝试的整理方式，不诊断注意力障碍，不保证提高效率。
- **主角度**：不是否定临时任务的价值，而是把“记下来”和“现在处理”分开。
- **结构选择**：观点论证型，兼用问题解答；由具体生活情境进入，给出动作建议，再限制承诺。
- **拟用时长范围**：目标不超过 60 秒。尚未合成，不能声称实际时长已满足；后续依据真实旁白删改，不能仅凭字数套用短片规则。若目标调整，重新按实际目标适用阶段指南。

### 包装及正文承诺

- **标题**：写东西总想切走？先把念头放到一边。
- **封面文案**：先记下，不急着切走。
- **封面构图设想**：一边是正在写的正文，一边是一张记有临时任务的纸条，让“主任务与暂存”成为焦点，而不是夸张的崩溃表情。素材与字体尚待选择和验证。
- **发布文案草稿**：临时想起别的事，可以先记下，等当前这一段告一段落再决定要不要处理。这是一条自拟生活建议，适用范围取决于手头的任务。
- **兑现位置**：正文给出纸条暂存的具体动作；结尾明确它是可尝试建议，不以无法证明的效果吸引点击。

### 完整口播草稿

> 刚坐下来写东西，你又想起一件别的事。
>
> 回条消息，查个资料，再回来，先得找找自己刚才写到哪儿。
>
> 如果你也有这种时候，可以试着在旁边放张纸。
>
> 临时想起的事，先写下来，不急着切过去。
>
> 等眼前这一段写完，再决定要不要处理。
>
> 这不是保证高效的办法，只是一种可以尝试的安排：先接住念头，再决定什么时候行动。

这份稿子只承诺“给出一种安排方法”，不承诺医学效果、具体节省时间或普遍适用。若需改成科学解释型，须另找可支撑对应主张的真实依据，不能给本稿附上虚构研究。

### 由文案落到镜头需求与编排

下表仅为本演练的编排说明，不要求实际作品另建同款表格。各段不是固定幕数，后续按真实场景组织；这里的时间窗指要覆盖的动作过程，不是已测得的源片或成片秒数。

| 口播节点 | 对象、动作及身份限定 | 所需窗口与构图 | 镜头职责、声画配合及观察预期 |
|---|---|---|---|
| 刚坐下来写东西，又想起别的事 | 泛生活人物在桌前写作；不指代具体当事人、公司或职业 | 从正在写的状态到注意力转向另一任务，正文位置和手部可认 | 建立情境；以纸面／键盘为锚点，不仅配忙碌人群。观察能否认出“原本在做什么” |
| 回消息、查资料，再找位置 | 同一工作界面的切出与返回；若代码实现，仅作自拟界面示意，不仿造真实私人聊天 | 覆盖离开、返回和重新寻找当前位置，必要时分镜展示而不冒充连续实录 | 解释切换关系；若有提示音，只强调明确的干扰节点。字幕不遮住返回后需要寻找的位置 |
| 在旁边放张纸 | 纸张进入原有工作空间，主任务仍保持可见 | 手将纸放下并稳定的完整窗口，纸与主任务在空间上可区分 | 提出方法；不切成另一个无法认回的房间。画面从分散转向较稳定的组织是待验证方向，不是已观察效果 |
| 想起的事先写下来 | 手写下一个临时任务，再回到原任务；笔记内容为自拟，不使用真实个人消息 | 书写、任务被存放及返回都需可认；若真实素材文字不符，不篡改原件充当实录 | 展示建议的关键动作；可用“记下”和“处理”的关系说明，但不靠新增解释小字补足看不见的过程 |
| 当前段落写完，再决定处理 | 当前文字完成一个可认单元，随后看向暂存纸条 | 先完成、后查看的顺序可见；不需要把所有任务都打勾 | 兑现“稍后决定”，不是证明任务完成更多。留足识别先后关系的时间，不按固定节拍切走 |
| 先接住念头，再决定行动 | 纸条与主任务共同保留，或以与前文锚点相连的结论画面收束 | 结论完整出现后保持实际阅读窗口；不新增待办洪流或其他论点 | 回答标题。旁白保留“不保证高效”的边界，配乐可收束或不用；不能剪掉限定只留下效果承诺 |

### 研究、选材与回退如何执行

1. 实际制作时先按第 3 节寻找可查看的具体标杆，重点研究“连续日常动作如何建立”“界面与手部如何交接注意力”“建议段如何由分散转为稳定”。这些是研究问题，不是已经观察到某部参考的结论。将实际观察、采用与限制写入既有研究记录。
2. 通用情境素材可从 `person writing at desk`、`hand writing task on paper` 等对象动作组合开始，优先核对写作、放纸和返回动作是否存在。这里仅给检索示意，未执行搜索，不代表有对应可用候选。
3. 具体身份、地点、年代在本例不是论点所必需，不强加“某职业真实案例”身份。不同来源的人物和空间若不能连贯，就组织成不特指某人的情境段落，不能声称跟拍了一个人。
4. 若只有打字空镜，缺少切换过程，可按既有载体规则用自拟界面示意表达切出、暂存和返回；不能伪造手机实录、真实聊天或实验界面。若仍表达不清，改写为仅讲纸条暂存的方法，放弃未兑现的过程承诺。
5. 若缺合格手写视频，先判断代码示意是否能清楚表达任务被暂存；不适合时再按载体规则调整为静态阅读或改稿，并记录回退。不能用静帧推拉代替“正在写”。
6. 取得素材后核对真实源片入出点、裁切及来源，走现有导入；本演练没有可预填的素材 ID、许可结论或下载成功状态。

### 配音、字幕与剪辑落地

- 配音方向先设为亲近、克制的建议口吻，不采用训斥式“你就是不自律”。实际选音依可用候选及全文判断，不在未合成时声称某音色已通过。
- “先写下来”与“不急着切过去”形成动作顺序；“这不是保证高效的办法”保留为正常口播与字幕，不缩成不易察觉的小字免责声明。字幕断句与时间按真实词边界生成。
- 前段可以用切出与返回表现打断，建议段以更完整动作和稳定构图形成对比；这是本例假设，不推广为所有营销号必须前快后慢。
- 配乐可选轻量且不盖住人声的方向，也可不用；动作或提示音仅在有叙事作用时采用，按既有音频来源契约留证，不把艺术拟音说成现场原声。
- 实际旁白若超出目标，先删重复情境或缩小主题，不裁掉最后的适用边界。完成具体研究与转化后，本例先按不超过 60 秒的目标编排，准备后按实际时长选择适用评审。

### 常见失败及修正

| 发现的问题 | 先查什么 | 本例的修正方向 |
|---|---|---|
| 看起来只是办公素材拼贴 | 每段是否真的显示所说动作 | 保留原任务锚点，补切出／返回关系；缺过程则收窄文案 |
| 不同人被误认作同一人 | 人物、桌面、光线和动作接续 | 换连续素材，或明确按泛情境组接，取消跟拍式指代 |
| 方法看懂了，但包装夸大 | 标题和结尾是否承诺效果 | 不用“彻底治好分心”等标题，保留“可以尝试”的定位 |
| 语速快而字幕难读 | 文本重复、实际音色与阅读窗口 | 精简稿件、重新准备并检查；不只缩字或继续加速 |
| 提示音和音乐盖过建议 | 当前混音、起音与旁白窗口 | 减少无职责声音、调整现有层级，按信号核对而非直接提高总音量 |
| 纸条出现了，但“稍后处理”没表现 | 暂存、返回和再查看是否有顺序 | 补完整关系或改成仅介绍暂存动作，不用结论文字冒充已演示 |

### 制作后的复核与交付

按现有[制作迭代](stage-production.md#制作迭代)核对开场、各段增量、关键动作、字幕及声音，并将实际结果与上述预期分开回写：没有看到的过程仍未验证，不用作者解释替代画面。

当前完整候选仍须按[验收交付](stage-production.md#验收交付)完成技术 QA、适用独立评审、整片复核及失败复查。本例文稿、标题或表格写完，不代表素材已取得、研究充分、技术通过、独立通过或作品已经完成；交付说明只报告实际制作、查看与验证范围。
