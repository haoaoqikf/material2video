# 按需参考：subagent-review-template

仅在相应创作、填写或排错任务触发时读取；本页不新增门禁或审核轮次。

## 输出模板

评审者必须**先描述后判定**，按顺序填写，第一段写完才能看第二段：

```markdown
## 第一段：只看评审包
- 主体尺度：
- 光源方向与数量：
- 画面密度与留白：
- 文字层级与可读性：
- 事件与关系：
- 我的第一印象：
- 完整窗口中的疑问、误解、回报时刻与有效表达：
- 减法压力测试（问题触发时选填）：若只保留 70%，按顺序删哪些具体场景／镜头／时间范围
- 唯一画面／瞬间（问题触发时选填）：时间码、镜头 ID、画面内容与不可替代理由；过程型作品写完整窗口

## 第二段：对照
- 结论：通过 / 不通过 / 同族 / 不同族 / 证据不足 / 非缺陷取舍
- 具体差异项：
- 性质：实际缺陷 / 创意风险 / 审美偏好 / 证据不足
- 适用诊断、时间位置、显示尺寸、受影响目标及前后文证据：
- 重要返工收益与表达损失（非返工记不适用）：
- 执行方式：独立子代理 / 外部评审 / 角色分离自审（降级）
- 隔离条件：未读取 <文件列表>
```

「不通过」「不同族」必须写出具体差异与位置；不接受「感觉不对」「不够高级」这类无法复查的表述。
