# v7 讲解视频评审

本量表为可选画面评审工具，不作为导出必经环节。主动评审时，依据真实观察填写 outputs/review.json，每项提供具体幕或时间位置；不自动生成审美通过结论。完整预演自动验收通过即可正式导出。

| 维度 | 通过依据 |
|---|---|
| informationClarity | 核心观点明确，旁白忠实于源文（主题输入时忠实于主题），屏幕摘要简洁 |
| templateLayout | 手机可读，标题、内容和字幕分区，图片与视频不变形 |
| graphicRelation | 对比准确、步骤有序、因果关系明确，素材支撑例子且来源留证 |
| narrationSync | 元素按对应旁白出现，字幕准确，声音无截断或重叠 |
| readingRhythm | 每幕有稳定阅读时间，无旁白镜头长度合理，转场自然，完整视频最多 600 秒 |

可选评审发现问题后可修改材料、重新 prepare 和 preview；旧评审不可用于主动 review，但不阻断导出。
