# 视觉复核

样品须判断实际整体品质与代表性，关键帧审核前移，漂亮静帧不自动证明连续变化、空间关系或声音。依赖过程的设计必须覆盖完整局部过程；静态作品只授权实际静态范围。失败或不足继续迭代，交付规则见[网页原生样品](design-samples.md)。

判断实际效果，不按风格、方法或装饰数量验收。技术 QA 不能证明表达和审美成立。

## 世界级品质与风格开放

正式关键帧以所选风格的世界级创意、表达和制作完成度审核。苹果官网仅说明品质高度，不是指定风格或每部作品的必选参考。手绘、纪实、拼贴、抽象、极繁、极简、三维及原创融合都可成立；每片选择实际可查看、适合方向的优秀作品，明确整体品质和专项采用范围。

| 方面 | 必须实际判断 |
|---|---|
| 创意与表达 | 视觉想法是否有力量，准确承载内容，摆脱普通模板感 |
| 整体形象 | 主体、构图、文字及细节是否共同形成鲜明完整的画面 |
| 构图与注意力 | 比例、疏密、焦点、留白或密集组织及阅读顺序是否充分设计 |
| 排版与色彩 | 字体、尺度、字距断行、明暗和色彩是否有明确作用并统一受控 |
| 实现与细节 | 素材、形体、边缘、遮挡、合成、纹理及适用光影是否达到当前阶段所需完成度 |
| 风格一致性 | 各种处理是否形成完整语言，变化是否有意并服务表达 |
| 标杆对照 | 与实际优秀参考相比，是否仍有明显创意、表现或完成度差距 |

按所选风格解释这些关系：笔触、颗粒、不规则边缘、粗粝或极繁可有意采用，但须实际受控且形成出色整体效果。不以缺少写实材质、苹果式留白或特定字形否决，也不以风格标签免除实际缺陷。关键帧覆盖代表状态及易出问题的中间状态，不能只选漂亮终态。

每个正式观察项和整体均明确通过或不通过，机器记录仅 pass/adopt 可以采用，fail/insufficient 必须 reject。证据不足须说缺什么、补什么；不将不确定判断伪装为已知缺陷或通过。不接受“大体可以”“基本达到”“有潜力”等替代结论，也不以总分、排名、技术无错放行。

通过须说明实际达到的具体表现；不通过须给画面位置或帧窗、显示条件、现象、目标、阻断影响及复查需要的结果。“高级感不足”本身不是完整理由。所有候选均可不通过。非阻断打磨建议可随通过保留，核心差距不能后置。

## 试制关键帧的通过标准

试制通过须同时看到以下三种效果。先在完整画面观察整体，再按实际观看尺寸定位细节及其影响。

- **信息清楚。** 观众在对应画幅能读到必要文字、数据和关系，画面焦点与这帧承担的内容一致。
- **核心形象成立。** 所选主体、构图和适用材质或光影能让观众辨认并感受到这帧承担的艺术效果。按[不同观看尺寸的职责](#不同观看尺寸的职责)判断。
- **能指导制作。** 当前实绘的主体、空间、色彩和排版已经形成有吸引力且可延续的整体方向。观察得到的效果可作为后续基线，适用的过程另以动态证据核对。

同轮对照依据送审前登记的逐帧职责、参考用途和可观察的通过效果，说明哪些已经成立、哪些实质阻断、哪些可留到正式制作打磨。比如琥珀玻璃是核心载体时，主体普遍被读成金属可构成阻断。若已经看得出玻璃体量和透光，局部边缘锐度或与标杆不同的光纹复杂度可以记入打磨建议。证据不足时明确缺哪些画面或尺寸，保留该项未验证。

## 不同观看尺寸的职责

先看各登记尺寸的完整画面，再用局部裁图定位现象。正常观看尺寸按当前阶段核对整体艺术效果，包括构图、抽象造型、材质和光影。手机等小屏核对主体轮廓和焦点，能否看出承担讲解的分组、量级、前后变化或因果。标题、金额、公式、组别标签、结论和其他承担必要信息的文字，应在各适用尺寸的出现窗口内读得清。

正常尺寸的艺术目标成立、小屏的核心表达清楚时，手机上弱化的细微纹理、局部折射和非必要层缝，可随通过记录。正常尺寸下主体材质无法支撑艺术表达，或小屏下主体消失、关系失真、必要读数难辨，仍按原职责判断阻断。例：两座抽象玻璃塔在手机上可以省略细缝，但两塔须可分、量级关系须清楚，必要的组别标签仍须可读。

盲审先记录实际所见。封存盲审后，同轮对照用逐帧中性条件和实际参考说明每个尺寸哪些效果应保住，并记录已兑现的效果、阻断与随通过记录的限制。

## 缺陷、风险、偏好与证据不足

实际缺陷须有位置、窗口、显示条件、现象和受影响目标；创意风险通过试制或比较验证；纯偏好不单独否决；无法确认的关系保持 insufficient，不以作者解释补全。

判 fail 时说明画面位置、实际观看尺寸、违反的必要目标及实质影响，例如关键读数错误、核心形象失效或适用阶段的整体艺术效果受损。局部裁切可诊断现象，严重性仍按其在完整画面中的实际影响判断。整体效果和目标成立时，次要层间亮度、细节精度等改善可随 pass 记入 limitations。选案责任见[评审契约](review-contract.md#采用边界与选案责任)。

## 讲解关系的观察

先区分实际意象与精确信息的职责，详见[抽象表达与信息职责](review-contract.md#抽象表达与信息职责)。抽象主体可以与清晰读数协作，不默认承担逐层字形读取或逐物具象辨认；主体难逐字辨认本身不等于整体表达失败。核对完整画面是否建立形象、空间、关系及适用节奏，必要金额、单位、组别与结论是否可读；有关键误导、唯一读数不可读或核心形象失效仍阻断。未知职责留作对照问题，不自行增加用户未要求的具象精度。

先盲看完整窗口，记录看见的对象、变化、结果、疑问何时解答、画面和字幕各自贡献，再核对中性原条件。延迟揭示按完整过程判断，不要求开场立即泄露答案。

分别判断 understanding（理解）、presentation（实际表现）与 representativeness（主体、字体、光效及合成是否代表当前目标、是否占位）。理解通过不能覆盖表现失败，占位不能授权正式视觉效果；目标兑现通过后续同轮对照判断。

盲看具体记录吸引力、主体形象、构图张力、排版层级及适用材质／光影。对照时按事先登记的画面职责使用实际参考及中性采用特征，说明整体艺术目标与专项任务各自怎样兑现，记录仍存在的关键差距及当前选择的收益与代价。整体方向覆盖受影响画面，造型、光色与实现方式可随画面职责变化。缺少实际目标媒体或所需过程时保持对应目标未验证。

试制关键帧的对照逐项写出所用参考、采用的艺术效果和完整画面的实际证据。一轮报告汇总所看范围内已经发现的核心阻断。每条写清具体帧位、画面位置、观看尺寸、看到的现象、受损的画面职责和复查时应看到的效果。已经成立的表达写明保留依据，实施手段由制作方选择。成片精修余量和参考自身的形式差异保留为观察。静帧中的代表性指实绘主体及取帧状态能否证明其静态职责，完整动作由实际过程证据核验。

整体品质须看主体、构图、层次与细节共同形成的效果，不能因已有相似形状、颜色或阴影就判成立。试制分别回答“哪里值得保留、哪里仍普通、最大目标差距是什么”，再说明值得继续打磨还是足以作为后续标准；候选相对最佳仍可能不足，允许全部淘汰。指出具体位置及影响，不用抽象“高级感不足”或总分代替判断。

## 视觉与运动

对照场景承诺观察注意力如何建立和转移、触发与响应是否可对应、停留是否支持识别、主体是否有吸引力，以及构图、层次、材质和细节共同形成的整体效果。给出具体窗口和现象；不能把「可读、无遮挡」的结论扩大为因果、节奏或美术通过。观察预期来自设计，实际结果来自当前媒体，两者分开记录。

按有序帧与静帧查看焦点、主体尺度、构图、材质、光影、空间关系、关键过程与阅读窗口；按帧差/场景切分、主体区域量测和音频信号量测核对变化、转场与声画组织。必要文字在手机尺寸可辨；示意/实拍边界小标按项目约定处理。画面注释从紧，不能遮挡主体或争夺焦点。

查看工具中的大图疑似出现局部缺块、截字或闪烁时，可用源图局部裁切、同一区域像素计数及相邻帧对照核实，区分媒体缺陷与工具显示异常。报告保留实际核对范围，不能把未经核实的显示异常直接写成媒体失败；裁图只作诊断，不替代原生显示及完整过程观察。

已发现单帧亮度突变时，可流式解码全部帧，在缩小的量测图上记录亮度及相邻绝对帧差，定位异常后回看原尺寸邻帧；这样无需把全部原图常驻内存，也能补足稀疏取样之间的风险。保留实际分辨率、阈值、帧号及已知失败的检出结果，按内容区分正常变化；无异常峰值不等于局部细节、审美或所有闪烁已自动通过，也不把某次作品的阈值设为通用门禁。

动态以完整解码、有序时间码帧、帧差/场景切分和主体区域量测核对状态切换、停留、转场与回退；声音以响度、真峰值、静音、起音、频谱和同步量测核对事件、层级与留静设计。接触表用于导航；静帧和终态不能证明连续过程；适用关键证据缺失记 insufficient，不达设计预期记 fail；量测按实际机制选择，不给静态或无声场景强加无关指标。具体关系无法确认则补证。

## 全片理解与结构

全片预演及粗片按有序帧、帧差/场景切分和音频信号检查，总代理再按[验收交付](stage-production.md#验收交付)从当前完整候选取证；不要求播放观看或试听。检查开场承诺、信息推进、跨场衔接、重复、强弱、节奏和结尾回报。局部精彩不能替代全片成立。

## 诊断测试与适用性

### 看图诊断与形象判据

按症状判断形象（对象与呈现）、取景（空间、镜头、注意力）或实现问题；这是排错方向，不是逐镜必填表。

| 症状 | 需核对的缺口与处理方向 |
|---|---|
| 主体过小，只剩无法识别的点线 | 从最终显示尺寸和必要最小单元反推占比、轮廓、参照或构图；抽象关系成立时不强制具象化 |
| 核心对象、动作或结果缺失 | 对照原承诺查编排和身份线索，不要求每个名词配图；缺因果时回场景设计 |
| 同时变化太多，阅读/因果混乱 | 查主导者、辅助响应、安静者及注意力交接，调整顺序与窗口 |
| 连续等待无信息或体验变化 | 删短、重排或改变表达；有效静止和阅读窗口保留 |
| 转场后认不回对象或不明白反转 | 查形状、位置、方向、问题和情绪的接续，覆盖两侧及中段 |
| 主体冲白、线条发糊、推拉突然猛冲 | 先确认源媒体现象，再按[实现排错](code-scene-runtime.md#按需排错)查辉光分层、空间插值等 |
| 文字/对象侵入字幕区或对比不足 | 查完整运动窗口的布局、裁切和字幕准备样式，不只看终帧 |
| 颜色或尺度变化造成数值/状态误读 | 核对编码与模型一致性，不能靠视觉放大伪造变化 |
| 比明确参考更暗、更空或主体普通 | 对应窗口核对实际采用的尺度、明暗与整体形象，不强制增亮或填满每一场 |

目标要求识别具体对象时，查轮廓、厚度、遮挡、接触、材质或必要名称；不以「只有圆圈」或没有三维体积单独判失败。修复后核对当前同一窗口及必要前后文，动作问题不能只凭起终静帧关闭。

手机、缩略图、静音或去文字只按问题选用，不形成所有作品必跑清单。静止允许服务阅读、观察或情绪；运动与细节都应服务表达。

## 版本与问题闭环

证据绑定当前媒体及来源，改动按实际依赖使报告失效。独立必改按[评审契约](review-contract.md)复查关闭，保留原失败；不得降目标、改称偏好或挑选宽松报告消除问题。
