# v5 讲解视频评审

自动量测只能检查技术布局，人工需实际观看完整有声预演后填写 outputs/review.json，每项均提供具体幕或时间位置与观察依据。

| 维度 | 通过依据 |
|---|---|
| informationClarity | 核心观点明确，旁白忠实于源文，屏幕摘要简洁 |
| templateLayout | 手机可读，标题、内容和字幕分区，图片不失真 |
| graphicRelation | 对比准确、步骤有序、因果关系明确，图片支撑例子 |
| narrationSync | 元素按对应旁白出现，字幕准确，声音无截断或重叠 |
| readingRhythm | 每幕有稳定阅读时间，转场自然，完整视频最多 60 秒 |

失败需修改材料、重新 prepare 和 preview，不能沿用旧评审。旧单世界身份、状态继承、镜头连续性五项不再是文章类型门禁。
