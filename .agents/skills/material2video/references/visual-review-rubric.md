# 通用作品自主视觉复核

本页配合[节奏、美术、声音与制作阶段](creative-production.md)执行：先整片粗预演、风险优先，再按阶段完成条件精制与复查；不增加用户确认或 CLI 人工门禁。

本流程适用于所有 general 作品。CLI 自动验收控制是否允许导出；助手必须完成本页的真实检查，才能标记制作完成。standard 与 cinematic 均取消 look-dev、中间阶段及最终成片的用户确认，不要求用户提供参考或替助手找问题。用户主动反馈仍按问题闭环处理。

## 目标、参考与风险样片

用户未指定时，默认发布抖音、1920×1080 横屏、60 fps；显式平台和画幅优先，金融/住宅专用画幅不变。作品 DESIGN.md 记录受众、手机观看方式、表达重点、时长目标和主要风险。开场尽快表达主题，不统一强制 60 秒。

助手自行搜索事实资料与视觉参考，记录链接、访问日期、用途和参考维度（光比、材质、主体占比、字阶、运镜或声音）。参考与实际画面并排比较，不仅检查“有什么”，还要检查表现差距。资料不能访问时记录缺失并扩大检索或调整方案，不虚构搜索或观看；入片素材另行按[媒体契约](article-media-and-sound.md)导入留证，参考不等于使用授权。

standard 至少测试开场、核心难点、结尾和主要风险，可合并为代表片段；cinematic 另外保留原生 4K 静帧、20–30 秒有声样片和 hero 专项。未被样片覆盖的暗景、高亮、材质、转场或结尾风险补独立短片。用于判断交付的样片采用最终画幅、字幕、后期与编码参数，4K 静帧不代替 1080p 动态检查。必改项关闭后再铺全片，无需用户批准。

## 检查方法与完成条件

| 维度 | 真实检查依据 |
|---|---|
| 信息与主张 | 内容忠实于源文或主题，旁白提到的特征在对应时间窗能辨认 |
| 构图与材质 | 对照参考检查主体占比、暗部细节、高光、表面质感和重复构图 |
| 空间关系 | 多对象场景对照设计意图，确认应分离的对象没有挤靠、应邻近的对象仍表达从属关系 |
| 可读性 | 手机观看尺寸下文字和主体可辨，避让共享字幕及平台界面 |
| 动态与节奏 | 连续观看全片与风险片段，检查过快掠过、过慢等待、重复运镜、位置/尺度/朝向/曝光与承接 |
| 声音信号与时序 | 自动检测交付音轨的响度、真峰值、削波/静音候选及长度，结合旁白时间戳检查分段边界 |

静帧用于构图、材质和多对象的屏幕空间关系，路径量测用于技术风险，连续播放用于判断等待感和整体节奏；动态文件已生成、接触表已查看、视频已连续观看是三种不同状态，逐项记录真实执行的方法、版本和时间范围。自动 QA 只证明已声明的技术范围；总响度不证明听感。静态关键帧和稀疏接触表不能独立证明运动自然或节奏合适。

设计阶段须为多对象画面写出关系意图，例如“行星之间保持视觉分离，卫星邻近母星”。检查屏幕尺度与构图表达，不能仅凭三维世界坐标、相机路径无碰撞或最小距离阈值判断。节奏检查须双向覆盖：发现急冲、急转、短停留等过快问题，也发现缺少信息的长等待与重复拉远；每段预算关联到路径、信息或观察目的，不以统一时长纠偏全片。

运动风险覆盖最长移动、最大尺度变化、显著转向、最短停留、开场和收尾，可由同一片段覆盖多项。检查整个离场—飞行—转向—抵达—观察过程，包含镜头内部的速度峰值、加减速、方向、FOV、主体屏幕尺度、空间参照与重新定位时间，不只看边界前后数帧。数值须来自实际测量，不把本规范写成已实现的自动检测器，也不制定脱离作品的统一速度阈值。

无法连续播放时，加密范围必须覆盖风险全过程，而非只覆盖交界附近；明确帧间运动与连续节奏的覆盖限制。继续可执行的技术检查与导出，但对已知连续节奏问题保持待验证，相关必改项和依赖它的制作完成结论不能关闭；不新增 CLI 导出门禁、用户审批或强制用户接手。用户针对当前具体问题和片段的实际观看反馈可作为补充证据，须记录版本与范围；笼统认可不能代替问题复查。上述要求针对连续节奏问题，自动音频替代验收和其他视觉检查沿用各自现有证据规则。不能用端点相同、边界速度接近、接触表或技术通过关闭节奏问题。

最终文件执行覆盖全片的帧序列与自动音频替代验收，不要求连续播放或实际试听。使用 m2v qa 生成逐秒采样、首尾帧、逐镜头起中末帧、交界前后0.5秒的0.1秒加密帧及hero/异常区间加密帧。长片接触表分页至片尾，逐项查看清单与图像，不以少量关键帧冒充覆盖。图像含时间标签，检查手机观看尺寸，必要时从原视频补提全分辨率帧。

黑帧、突变、削波和静音均为候选，需对照设计、旁白分段与加密帧记录处置；正常黑底、静止、淡入淡出、硬切或设计停顿可记录符合设计。检测执行失败不能写成零异常；有声作品缺音轨须修复，无音轨且契约允许时写不适用。语音与背景音乐混合后可能掩盖缺声，自动检测不能证明口播文字正确或语义同步。

技术验收通过、当前检查记录有效、替代检查覆盖完整、候选处置完毕且全部必改项关闭后，助手自主标记完成。可选项与覆盖限制随交付披露。准确写“通过帧序列与自动音频检查”，不声称完整播放、实际试听或配音自然度达标。配音误读、音乐感染力和采样间瞬时异常属于覆盖有限项，不重新设为播放门禁；必要图像或检测确实缺失时报告未完成。

## 版本与问题闭环

沿用 outputs/visual-notes.md，不新增审批文件或机器视觉通过字段。每次检查绑定 preparedFingerprint、检查文件 SHA-256、时间范围、方式和实际观察。最终复核额外绑定交付 MP4 SHA-256；准备指纹改变或文件被替换后，相关结论失效，旧用户确认只作历史。记录可按 Markdown 模板手工填写，不由程序自动生成“通过”。

必改项包括影响理解、主体识别、文字阅读、旁白主张可见性或明显视听异常的问题；其余为可选。状态为未解决 → 待复查 → 已关闭。必须在修改后的有效版本上记录复查依据才可关闭，重新渲染不会自动关闭。同一问题连续两轮无明显改善时更换素材或实现方法，保留前后对照；替代方案仍失败则停止无效循环并报告未完成。

用户核心体验未达成的已知缺陷属于必改；不能把「接近/拉远偏快」改名为可选或覆盖限制后完成。覆盖限制描述未验证项目，不消除已经观察到的问题。

```markdown
# 实际观看与返工记录
```

## QA 的能力边界

qa.json 的 scope 为 technical-only：自动判定与 measurement 测量提示分开，observation 为 not-evaluated，需另行查看帧序列和复核音频候选。inspection 登记交付摘要、完整采样清单、分页接触表、黑场/突变及音频信号候选；自动报告不会生成制作完成的审美结论。claims 自动检查只是 shot-window-coverage，其 visibility 为 not-evaluated，不表示特征可见。字幕配色对比度不表示字号可读，音轨时长一致不表示语义同步，资产规格达标不表示真实质感。可选 review.json 仍是独立工具，不参与 CLI 导出门禁。

## 发布平台依据

2026-10-18 检索并访问[抖音创作者中心](https://creator.douyin.com/)，公开页面未提供可读取的横屏界面遮挡尺寸；搜索到的创作者视频不作为平台官方规范。因此本流程不写死抖音像素安全区，也不声称完成平台实测。实际制作应重新核对当时可用的官方资料或本机平台预览，记录来源和日期；无法核验时披露遮挡检查的限制。共享字幕安全区仍按现有画幅契约执行。

## 判断演练

| 输入情形 | 必须得出的结论 |
|---|---|
| 记录的准备指纹或 MP4 摘要与当前产物不同 | 旧结论失效，重新复核后才能完成 |
| 必改项已经改代码但还没复查 | 待复查，不能因为导出成功自动关闭 |
| 没有播放接口，但采样覆盖全片、自动音频检查齐全且候选及必改项已复查关闭 | 可以自主完成，准确披露采样和听感覆盖限制 |
| 太阳系路径相接、交界速度接近，但镜头中间猛加速 | 必改；检查整段运动，边界通过不能关闭问题 |
| 太阳系已记录接近偏快，只有稀疏静帧证明 | 保持待复查，补风险全过程证据，不作为普通限制放行 |
| 独立行星路径安全，但在画面中像彼此紧挨 | 空间表达必改；检查构图与屏幕关系，运动量测不能关闭 |
| 运动平滑，但连续观看发现无信息等待过长 | 节奏必改；逐段缩减预算并复查，同时回归过快风险 |
| 只生成视频并查看接触表，没有连续观看 | 记录生成与接触表检查已完成；连续节奏保持待验证 |
| 技术 QA 通过但已知等待问题没有体验复核 | CLI可导出；问题及整体制作完成状态保持未关闭 |
| 用户笼统确认视频通过，未明确复查当前节奏问题 | 保留该问题状态；笼统确认不等价于问题级观看证据 |
| 任务要求工作流修订和太阳系重制，目前仅规范完成 | 整体未完成，继续按新流程重制和复核作品 |

## 固定检测参数与边界

当前使用 blackdetect（持续0.1秒、像素黑阈值0.10、黑像素占比0.98）、scene突变参考阈值0.3、silencedetect（-45dB、持续0.5秒）及原采样率/声道绝对幅值≥0.9999的削波候选。这些不是审美失败阈值，不能把深空黑底或设计停顿自动判坏。交付音轨响度与真峰值沿用现有档位目标；自动信号检查明确使用交付文件。旁白时间戳不足时按分段边界检查并披露粒度，不虚构逐字对齐结果。

横屏共享字幕按手机观看采用40px（竖屏仍40px），安全区位置不变；作品正文也应按手机尺寸复核。参数唯一来源为 web/src/frames.json，不在作品内另画一份重复字幕。
