# 通用讲解视频评审

本量表为可选画面评审工具，不作为导出必经环节。主动评审时依据真实观察填写 outputs/review.json，
每项给出具体幕或时间位置；不自动生成审美通过结论。完整预演自动验收通过即可正式导出。

| 维度 | 通过依据 |
|---|---|
| informationClarity | 核心观点明确，旁白忠实于源文（主题输入时忠实于主题） |
| visualDesign | 该画幅下的构图、配色与字阶在目标设备上可读，重要文字与主体避开字幕安全区 |
| graphicRelation | 关键画面与动画确实帮助说明观点，示意数据明确标注 |
| narrationSync | 画面推进与旁白时间窗一致，字幕准确，声音无截断或重叠 |
| readingRhythm | 镜头节奏与转场连贯，无旁白镜头长度合理，完整视频最多 600 秒 |

自动检查只覆盖字幕（安全区、换行与可见性）；作品正文在录制的片段里，需要 reviewer 实际观看
代表片段。发现问题后修改材料、重新 prepare 与 preview；旧评审不可用于主动 review，但不阻断导出。
