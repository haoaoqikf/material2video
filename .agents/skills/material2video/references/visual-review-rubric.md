# 通用作品自主视觉复核

本页配合[节奏、美术、声音与制作阶段](creative-production.md)执行：先整片粗预演、风险优先，再按阶段完成条件精制与复查；不增加用户确认或 CLI 人工门禁。

逐场设计与验收使用[逐场设计与独立验收](scene-design-and-acceptance.md)的设计表与验收表；本页负责全片复核方法。四张全片基准与技术 QA 不能代替逐场验收；每场在批量独立审查中先复述问题、事件与新增认识，再核对中性条件，按维度分栏引用唯一问题表。逐场之外还要按[全片导演审查与剪辑重组](director-review-and-edit.md)在粗预演后与最终候选形成后各做一次独立子代理的全片审查（不具备时降级为角色分离自审并披露），全片否决权不被逐场或技术通过覆盖。传播表现按[传播表现评估](reach-potential.md)检查，最终报告绑定当前成片。

本流程适用于所有 general 作品。CLI 自动验收控制是否允许导出；助手必须完成本页的真实检查，才能标记制作完成。所有 general 均取消 look-dev、中间阶段及最终成片的用户确认，不要求用户提供参考或替助手找问题。用户主动反馈仍按问题闭环处理。

## 目标、参考与风险样片

所有作品默认面向手机观看；这不自动决定横竖方向。general 未指定发布平台时，默认抖音；未指定画幅时仍为 1920×1080 横屏、默认30 fps（可显式60 fps）；用户显式平台和画幅优先，金融/住宅专用画幅不变。作品 DESIGN.md 记录受众、手机观看方向与检查尺寸、表达重点、时长目标和主要风险。开场尽快表达主题，不统一强制 60 秒。降低前两秒观众流失贯穿制作前/中/后的审美考虑：前期挑选代表主题的主体与信息，制作时避免冗长铺垫，后期检查前两秒在手机尺寸下是否清楚、有吸引力并兑现后续主题；没有真实发布数据时不推算实际跳出率、不填代理分数、不设机器门禁。

助手自行搜索事实资料与视觉参考，记录链接、访问日期、用途和参考维度（光比、材质、主体占比、字阶、运镜或声音）。参考分析还应简记作品的观看钩子、主体/关系变化、关键揭示及节奏/声音作用，并标明依据是完整成片、片段、静态示意还是作者描述；静态示意不能作为动态或节奏效果的证据。常规选案路径下，两个美术方向基于同一内容片段比较，并把参考差异转化为具体构图、资产、排版或运动决策；若用户已给出足以执行的美术方向，则直接采用，不重新选案，仍按画面基准及最终复核检查实际呈现。仅有风格形容词不算完成。资料不能访问时记录缺失并扩大检索或调整方案，不虚构搜索或观看；入片素材另行按[媒体契约](article-media-and-sound.md)导入留证，参考不等于使用授权。

DESIGN.md 记录核心感受、视觉主体、情绪变化、审美禁区及可观察目标。general 四张基准分别为开场、核心、普通信息镜头与结尾，均带实际素材和正式文案；有旁白时包含真实字幕，无旁白时核对所有画面文字。按原始尺寸、声明的手机观看尺寸和缩略图尺寸复核，记录实际显示尺寸与最重要差距。四张基准可以复用按风险选出的代表静帧，不必重复产出。

逐镜说明观众问题、画面主体、可见变化、信息落点、观察窗口与承接方式；三案需呈现不同的讲述机制，不能只换美术表层。粗预演同时标注信息、运动、视觉、声音强度及变化目的；声音变化应能对应具体叙事/情绪作用，音效只用于有意图的事件，无声作品声音项记为不适用。固定时长不足时先删减重复信息或重组镜头，再调整速度。

至少测试开场、核心难点、结尾和主要风险，可合并为代表片段；另外保留按风险选择尺寸的代表静帧与按风险确定长度的有声样片（无声作品为无声样片）和 hero 专项。未被样片覆盖的暗景、高亮、材质、转场或结尾风险补独立短片。用于判断交付的样片采用最终画幅、字幕、后期与编码参数，静态检查不代替最终画幅的动态检查。必改项关闭后再铺全片，无需用户批准。

## 核心事件的最小动态证据

检查前，在 `DESIGN.md` 事件说明或原验收条件中声明目标、完整窗口、手机显示条件和失败现象；取证后在现有唯一问题表与证据索引记录实际检查范围、采样与量测方法，以及证据是否足够。不设统一采样频率，按关键事件和速度变化加密；不新建状态字段或自动审美阈值。

| 事件 | 必须覆盖的过程 | 不足以支持通过的证据 |
|---|---|---|
| 同速建立 | 同一时间窗内各主体的位置变化、可辨认轨迹；注明比较的是世界速度还是画面速度，并核对透视与相机运动的影响 | 源码设定相同速度或一张并排静帧；世界速度相同不保证画面速度相同，更不保证观众感知同速 |
| 尺度揭示 | 局部观察、新信息进入、全貌稳定与结果观察窗口；注明新信息何时可辨 | 只有揭示前后两张图或相机位移参数，看不见信息公开过程 |
| 实际换轨 | 跟踪同一主体进入连接、经过连接、离开并在新路继续前进，避免切换主体冒充换路 | 只有连接亮起、网络变密，或采样跨过主体经过连接的过程 |
| 分支展开 | 主路径身份可认回，分叉来源、层级显现与整体观察均有过程证据 | 只有大量暗线的全貌，无法关联主路或分叉来源 |

时间标注帧序列、风险加密采样和量测互相补足：世界参数只能证明设定，投影及实际帧用于核对画面；客观位移也不能独自证明观看感受。动态独立评审包还须包含覆盖完整事件窗口的有序时间码帧序列，呈现建立、关键变化、停留和结果；按转折风险加密，不设统一采样频率。视频文件可附上，但不能假设评审端能播放。无法播放时，评审者应区分帧序列直接支持的观察与无法验证的帧间连续性；接触、路径连续等关键目标若不能由序列辨认，应保持证据不足并补证，不能以稀疏抽帧或披露限制判通过。无法辨认关键过程时补证并保持待验证，在问题表沿用未解决或待复查等原状态，不增加「待验证」枚举。补证后仍不足时如实保持未完成；不能仅披露采样限制便判通过，也不能把已知缺陷降为覆盖限制。动态目标不适用于静态观察时写明原因，仍按其实际信息或关系目标取证。

### 连续采样与文字竞争的最小检查

本节记录由重制验证成立的可复用取证方法；它规定怎么检查，不规定路径数量、分支层数、镜头秒数或观察时长。那些数值属于作品目标，不成为所有题材的统一门禁。

- **连续采样**：运动由离散轨迹驱动时，先建立累计弧长表，再按世界距离取样；明确处理零长度段与端点钳制，并用可执行数值测试检查中间点连续、端点精确与重复求值一致。反例：按 `floor(u × 点数)` 取最近点，参数相同但画面出现阶梯。
- **世界速度与画面速度分开**：同一世界距离不等于同一屏幕位移，路径长度、透视与相机运动都会改变观感。同速目标须同时记录世界距离与实际帧的屏幕位移；只比较参数、只给并排静帧或只看缩放幅度，都不足以证明同速。
- **揭示不是缩放**：局部取景可以暂时隐藏整体差距，但拉远时必须公开新的关系或数值，而不是只缩小同一图形。反例：近景已看全高度差，拉远只改变尺度。
- **文字与揭示竞争**：遮罩、淡出与结论文字必须在完整揭示窗口之后进入；文字可读不能替代全貌观察。反例：结论句清楚，但分支全貌已被压暗或退出画面。
- **换轨看主体全过程**：跟踪同一主体进入连接、经过连接、离开并在新路继续；连接亮起或网络变密不等于换轨。反例：采样跨过主体经过连接的帧，只留下两端。
- **适用边界**：以上检查用于核对声明的事件是否真的发生；作品专属的秒数、运动密度、路径数量与树形布局不得升级为通用阈值。

图形主导高潮的手机、去结论句、灰度与前后对照按[视觉力量诊断](visual-impact-design.md#代表画面与诊断)执行并记录适用边界；完整窗口和当前版本证据优先，不设统一强度或审美分数。

## 检查方法与完成条件

| 维度 | 真实检查依据 |
|---|---|
| 信息与主张 | 内容忠实于源文或主题，旁白提到的特征在对应时间窗能辨认 |
| 前两秒注意力与理解 | 查看前两秒有序帧与手机尺寸：主题、主体或有效动作是否尽早清楚；是否存在值得继续看的信息/视觉理由；开场承诺是否由后续内容兑现；不要求立即揭示全部主题或答案，延迟目标按完整窗口检查。记录具体观察与帧证据，不推断真实平台跳出率 |
| 目标受众理解 | 检查名称、术语、字幕和信息密度是否匹配目标观众；中文受众作品的中文名称与贡献先传达，陌生英文缩写只能辅助识别 |
| 叙事结构与版式重复 | 全片镜头次序、主体动作与信息发展；是否由重复的静态卡片或同构文字板逐页替换主导；按母题重复与版式重复分别判定 |
| 观众可见文案 | 片头、每幕、固定叠字、字幕与片尾文案清单；无内部文件名/路径/制作文档指引，署名与版权说明仅有一处 |
| 构图与材质 | 对照参考检查主体占比、暗部细节、高光、表面质感和重复构图 |
| 空间关系 | 多对象场景对照设计意图，确认应分离的对象没有挤靠、应邻近的对象仍表达从属关系 |
| 可读性 | 手机观看尺寸下文字和主体可辨，避让共享字幕及平台界面 |
| 动态与节奏 | 用全片高密度时间标注帧序列、风险区间加密帧和逐帧路径/屏幕投影量测，检查过快掠过、过慢等待、重复运镜、位置/尺度/朝向/曝光与承接 |
| 声音信号与时序 | 自动检测交付音轨的响度、真峰值、削波/静音候选及长度，结合旁白时间戳检查分段边界；用 `inspection.rhythm` 核对字数、窗口平均字速、声明留白与未知静音，测量不是审美阈值（口径见[配音音色与节奏](voice-and-rhythm.md#节奏测量qa)） |

静帧用于构图、材质和多对象的屏幕空间关系；以全片每0.5秒至少一帧覆盖、镜头交界前后0.5秒按0.1秒间隔加密的时间标注帧序列，替代播放视频检查。相机轨迹、角速度、加速度、视场变化、主体屏幕占比、相邻帧位移和停留时长使用作品实际帧率的路径/画面采样量测；按目标尺度变化和路径阶段标记等待区间，判断是否存在长时间无新信息。接触表仅作导航索引，单张静帧或稀疏抽帧不能证明运动自然。记录帧覆盖、间隔、量测指标、版本与范围，不声称已经播放。自动 QA 只证明已声明的技术范围；总响度不证明音色听感。

复核幻灯片式观感须查看完整有序帧序列或分段时间标注图像，而非只看少量 hero 静帧。标记相邻信息段是否沿用同一文字位置、卡片边界和相同背景处理；确认镜头中存在有意的主体动作、摄影机变化、空间关系或信息变化。若完整段落只有机械换字，且无信息、关系或体验推进，登记必改项并在新版本重新检查；文字本身的语义、节奏和构形变化也可承担叙事。合理的章节识别、类型图表惯例和短片尾署名本身不构成失败。

### 母题重复与版式重复

复核以完整表达段落及前后文区分两类重复：

- **母题重复**：相似主体或构图再次出现，状态、关系、情绪或语境含义产生新作用；包括增长、循环、倒退、消失、恢复以及原画面的重新理解。不要求外形改变、单调递增或固定背景像素差。
- **版式重复**：反复套用布局却没有信息、关系或体验推进。确认完整段落实际失效后才登记必改，不因相同构图或文字主导直接否决。

记录关键各次出现的时间位置、必要前后文、实际新增作用与证据。首末两帧或作者声称“这是母题”都不足以单独定性；数据参数可作证据，不是母题成立的必要条件。文字对照、档案并列和图表惯例按其真实表达判断，不强制每段换构图。

**核心视觉母题（单数）与母题重复不同**：前者是整片的组织载体，不要求重复出现；后者是同一载体多次出现并产生新作用。复核先确认设计中的核心母题是否在成片可辨，再按上述两类判断；设计文档写了母题，不能替成片证明它成立。

手机尺寸检查按设计声明的播放方向等比例缩放画面，记录显示尺寸和最小关键正文；未使用实体平台预览或缺少官方 UI 数据时，明确记录仅验证了画面可读性，未验证真实平台遮挡。横屏视频仍按横屏比例缩放，不能为迎合手机观看而擅自裁成竖屏。

观众可见文案清单应从分镜、场景源码、字幕文稿与全片帧序列互相核对。源码搜索只能帮助发现，不能代替对画面实际文字的复核；图形文字、动态文字、字幕和画面内素材自带的文字都需纳入。任何内部文件名、仓库路径、制作文件或“详见内部资料”的提示均为必改。完整素材来源信息保存在作品材料；成片只保留一份片尾署名/版权说明，逐项确认许可要求后用尽可能短且可读的文字集中呈现。

设计阶段须为多对象画面写出关系意图，例如“行星之间保持视觉分离，卫星邻近母星”。检查屏幕尺度与构图表达，不能仅凭三维世界坐标、相机路径无碰撞或最小距离阈值判断。节奏检查须双向覆盖：发现急冲、急转、短停留等过快问题，也发现缺少信息的长等待与重复拉远；每段预算关联到路径、信息或观察目的，不以统一时长纠偏全片。

运动风险覆盖最长移动、最大尺度变化、显著转向、最短停留、开场和收尾，可由同一片段覆盖多项。检查整个离场—飞行—转向—抵达—观察过程，包含镜头内部的速度峰值、加减速、方向、FOV、主体屏幕尺度、空间参照与重新定位时间，不只看边界前后数帧。数值须来自实际测量，不把本规范写成已实现的自动检测器，也不制定脱离作品的统一速度阈值。

不要求连续播放，也不要求用户接手。已知连续节奏问题必须用上述全片高密度帧序列和量测复核；覆盖不足时补采样，数据无法判断的部分明确披露，不得仅凭端点相同、边界速度接近、稀疏接触表或技术 QA 关闭问题。声音音色按服务返回的类别/风格元数据与完整旁白文本匹配，结合采样率、响度、时长、静音/削波及旁白时间窗做自动信号检查；不要求试听，不把元数据或信号指标描述为主观听感结论。自动音频替代验收保持已有技术边界。

最终文件执行覆盖全片的帧序列与自动音频替代验收，不要求连续播放或实际试听。使用 m2v qa 生成至少每0.5秒一帧的全片基线采样、首尾帧、逐镜头起中末帧、交界前后0.5秒的0.1秒加密帧及hero/异常区间加密帧。长片接触表分页至片尾，逐项查看清单与图像，不以少量关键帧冒充覆盖。图像含时间标签，检查手机观看尺寸，必要时从原视频补提全分辨率帧。

黑帧、突变、削波和静音均为候选，需对照设计、旁白分段与加密帧记录处置；正常黑底、静止、淡入淡出、硬切或设计停顿可记录符合设计。检测执行失败不能写成零异常；有声作品缺音轨须修复，无音轨且契约允许时写不适用。语音与背景音乐混合后可能掩盖缺声，自动检测不能证明口播文字正确或语义同步。

技术验收通过、当前检查记录有效、替代检查覆盖完整、候选处置完毕、全部必改项关闭且核心创意风险已核实后，助手自主标记完成。逐场设计与验收必须覆盖实际场景与镜头集合，最终报告须绑定成片并通过证据检查；任一项缺失都保持未完成。可选项与覆盖限制随交付披露。准确写“通过帧序列与自动音频检查”，不声称完整播放、实际试听或配音自然度达标。配音误读、音乐感染力和采样间瞬时异常属于覆盖有限项，不重新设为播放门禁；必要图像或检测确实缺失时报告未完成。

## 视觉创意方案复核

按[视觉创意导演方法](visual-creative-direction.md)检查设计是否在成片中兑现，不新增评分或门禁：

- 七段是否齐全、具体、可观察；不适用项是否有原因与替代做法。
- 核心表达是否说清变化/冲突/规律，而不是复述标题。
- 核心视觉母题是否可变化并在成片可辨；删掉它，影片是否失去组织。
- 每个抽象观点是否至少有空间、数量、速度、高度、距离、明暗或分叉中的一种可见变化。
- 镜头是否有可辨认的行为，而不只是页面切换；转场是否优先形态变换或连续承接，例外是否有叙事作用。
- 画面文字是否按镜头/信息单元围绕一个核心信息；标签、轴、数据、事实、口径、许可与示意标注不计。
- 禁止项是否作为默认清单使用，而不是形式否决清单。
- 设计文档与成片不一致时以成片为准；文档不能关闭设计未兑现的问题。

## 版本与问题闭环

沿用 outputs/visual-notes.md，不新增审批文件或机器视觉通过字段。每次检查绑定 preparedFingerprint、检查文件 SHA-256、时间范围、方式和实际观察。最终复核额外绑定交付 MP4 SHA-256；依赖变化使相关观察失效，未变观察仅附来源与依赖证明引用，当前最终文件仍须完整检查，旧用户确认只作历史。记录可按 Markdown 模板手工填写，不由程序自动生成“通过”。

必改项须符合[问题分类与否决依据](#缺陷风险偏好与证据不足)，包括实际影响核心理解、关键主体识别、必要文字阅读、旁白主张表达或明显视听异常的问题；创意风险先取证，审美偏好为建议。状态为未解决、待复查、已关闭、接受保留；只有已关闭计入解决，接受保留必须记录依据与未消失的影响，不能算作已解决，影响核心理解或用户明确提出的核心缺陷不得降级放行。每条问题必须写原验收条件、手机显示尺寸、失败现象、影响、处理结果、复查条件与有效版本。必须在修改后的有效版本上、用回应原问题的证据记录复查依据才可关闭，重新渲染不会自动关闭。审美精修依次检查视觉重心、信息层级、色彩材质、运动与细节。每遍记录主要改动，或说明无需修改的证据；不为凑轮次重复全片渲染。问题记录区分可见缺陷、表现差距与覆盖限制，写明位置、观察、影响、修改及复查方法。前后画面保持同显示尺寸；未重剪片段按相同时间码比较，重剪片段按同一事件对应并保留各版本时间码，并绑定当前有效版本。帧序列与自动信号只支撑其覆盖范围内的判断，不把技术通过描述为主观观感或音乐感染力通过。同一问题的两轮无改善升级按[创作流程](creative-production.md#信息推进与返工升级)执行；保留同一 ID 与原条件，停止同类微调，比较剪辑候选，仍失败回退上一级并报告未完成。

返工先按问题分流：

| 原问题 | 首选处理 | 不能单独用于关闭问题的修改 |
|---|---|---|
| 重复或无合理用途的等待 | 删除、缩短、合并、重排 | 推近、扫光、粒子等装饰运动 |
| 对象或关系不清 | 调整主体、位置与视觉映射 | 增加解释文字 |
| 关键发现不突出 | 调整揭示顺序、对比与停留 | 单纯加大发光 |
| 字小、碰撞或裁切 | 修改布局与字阶 | 依赖旁白补救 |

先写修改假设，分别记录修改动作与独立复查结果；未改善保持未解决，已修改但证据不足保持待复查，只有当前有效版本满足原条件才可关闭；重要返工还须比较收益与表达损失，损害核心体验时重新找解法。

用户核心体验未达成的已知缺陷属于必改；不能把「接近/拉远偏快」改名为可选或覆盖限制后完成。覆盖限制描述未验证项目，不消除已经观察到的问题。

## QA 的能力边界

qa.json 的 scope 为 technical-only：自动判定与 measurement 测量提示分开，observation 为 not-evaluated，需另行查看帧序列和复核音频候选。inspection 登记交付摘要、完整采样清单、分页接触表、黑场/突变及音频信号候选；自动报告不会生成制作完成的审美结论。claims 自动检查只是 shot-window-coverage，其 visibility 为 not-evaluated，不表示特征可见。字幕配色对比度不表示字号可读，音轨时长一致不表示语义同步，资产规格达标不表示真实质感。可选 review.json 仍是独立工具，不参与 CLI 导出门禁。

## 发布平台依据

2026-10-18 检索并访问[抖音创作者中心](https://creator.douyin.com/)，公开页面未提供可读取的横屏界面遮挡尺寸；搜索到的创作者视频不作为平台官方规范。因此本流程不写死抖音像素安全区，也不声称完成平台实测。实际制作应重新核对当时可用的官方资料或本机平台预览，记录来源和日期；无法核验时披露遮挡检查的限制。共享字幕安全区仍按现有画幅契约执行。

## 判断演练

| 返工情形（演练，非真实成片验证） | 必须得出的结论 |
|---|---|
| 增加光点后仍无新增认识或体验 | 原问题未解决，画面有运动不能关闭信息推进问题 |
| 停顿有证据证明承担必要阅读或情绪落点 | 记录用途与时间码，允许保留，不机械删掉 |
| 同一等待问题连续两轮无改善 | 停止同类微调，匿名独立比较原版与剪辑候选，仍失败回退上一级 |
| 技术检查通过但必要评审为空表 | 技术交付可完成，制作复核仍未完成 |


| 输入情形 | 必须得出的结论 |
|---|---|
| 记录的准备指纹或 MP4 摘要与当前产物不同 | 相关观察按依赖复查，当前最终文件仍完整检查 |
| 必改项已经改代码但还没复查 | 待复查，不能因为导出成功自动关闭 |
| 不进行连续播放，但高密度帧序列、风险加密帧、量测及自动音频检查齐全，候选和必改项已复核 | 可依据替代证据自主完成；披露帧间运动及主观听感不覆盖，不要求用户观看或试听 |
| 太阳系路径相接、交界速度接近，但镜头中间猛加速 | 必改；检查整段运动，边界通过不能关闭问题 |
| 太阳系已记录接近偏快，只有稀疏静帧证明 | 保持待复查，补风险全过程证据，不作为普通限制放行 |
| 独立行星路径安全，但在画面中像彼此紧挨 | 空间表达必改；检查构图与屏幕关系，运动量测不能关闭 |
| 高密度帧序列与尺度量测显示无信息等待过长 | 节奏必改；逐段缩减预算并复查，同时回归过快风险 |
| 十个段落都使用相同静态信息卡，只替换年份、标题和说明 | 幻灯片式版式重复为必改；重构画面和信息推进，不能以文字可读或 QA 通过放行 |
| 镜头构图相似，但主体动作或空间关系持续推进 | 不因单一构图相似判失败；记录实际信息推进证据，并检查全片是否仍由静态卡片主导 |
| 全片依靠相似主体回扣，外形不变但语境改变含义 | 检查关键各次出现与前后文的新作用；不要求单调递增、背景像素差或换构图 |
| 同一构图仅换标题说明，完整段落没有信息或体验推进 | 判版式重复必改；若文字关系本身产生表达，按实际作用判断 |
| 片尾出现 `SOURCES.md`、仓库路径或文档查阅提示 | 文案必改；移除内部指引，在唯一片尾署名中保留许可所需信息并复查全部可见文案 |
| 只生成视频并查看稀疏接触表，没有全片高密度帧和量测 | 接触表仅作导航；节奏证据不足，需补全替代检查 |
| 技术 QA 通过但已知等待问题没有高密度帧/量测复核 | QA范围不能关闭体验问题；补做对应替代检查 |
| 未试听音色，但已有声音元数据匹配和自动信号检查 | 符合本流程；如实记录技术证据，不声称主观听感通过 |
| 核心场景已通过，但某个普通场景只有“沿用风格”，没有独立设计与验收 | 该阶段未完成；补齐详细设计、试制及验收后才能完成 |
| 潜力报告声称有百万潜力，但没有成片时间码、逐场贡献或反面证据 | 报告未完成；结论降为证据不足，补真实检查后才能重判 |
| 任务要求工作流修订和太阳系重制，目前仅规范完成 | 整体未完成，继续按新流程重制和复核作品 |
| 手机尺寸下关键车辆动作仍不可辨，只是把标签放大 | 动作理解未解决，保持待复查；标签清楚不能关闭原条件 |
| 结尾偏长只以首尾呼应或设计停顿解释 | 必须比较原版与精简版时间线与帧序列、检查等待用途；否则不得关闭 |
| 静音符合分镜声明，于是判定节奏合适 | 设计停顿只解释来源；仍须说明观察、理解或情绪用途，不能关闭节奏问题 |
| 非核心差距实际比较后保留，却计入已解决 | 只能记接受保留并写剩余影响，不计入解决 |
| 已生成全片采样但只查看部分页面 | 记录实际页码与时间范围，补齐其余页面和风险量测后才算全片复核完成 |
| 最终候选形成后才补写第一次导演审查 | 缺少精制前阶段证据，该审查未完成；补做低成本审查与必要重组后复验最终候选 |

### 低机位细线、零厚度与保持段

- 黄道面内的平面细线在低机位下的屏幕厚度约等于 `世界宽度 × sin(仰角)`，容易退化成 1 像素断续线。可见性不要只由平面前缘承担：前缘需要随相机距离缩放的极薄垂直亮幕，画缘需要薄侧壁；最终仰角按“1080p 线宽下限约 8 像素”反推，并检查 699×393 下的可读性。
- 侧视合同至少复核三处：低机位经过主体时的前缘、俯视转向侧视的中间帧、最终侧视的两个端点是否仍在画面内。端点被裁切时，观众会把画缘误读为接缝。
- 相机关键帧的保持段必须显式让切线归零；只复制两帧相同位置仍可能被相邻段切线拖出漂移，复核时用同一段内的连续帧比对。

## 固定检测参数与边界

当前使用 blackdetect（持续0.1秒、像素黑阈值0.10、黑像素占比0.98）、scene突变参考阈值0.3、silencedetect（-45dB、持续0.5秒）及原采样率/声道绝对幅值≥0.9999的削波候选。这些不是审美失败阈值，不能把深空黑底或设计停顿自动判坏。交付音轨响度与真峰值统一为 −14 LUFS、−1 dBTP；自动信号检查明确使用交付文件。旁白时间戳不足时按分段边界检查并披露粒度，不虚构逐字对齐结果。

横屏共享字幕按手机观看采用40px（竖屏仍40px），安全区位置不变；作品正文也应按手机尺寸复核。参数唯一来源为 web/src/frames.json，不在作品内另画一份重复字幕。手机观看是默认设备目标，不代表所有作品必须采用竖屏。

## 反目标、冷审与 animatic 门禁

自审只能证明“符合自己的设计”，不能证明“像作品”。以下门禁不依赖用户确认，由独立子代理与可判定的失败条件承担。执行方式、评审包与降级规则见[独立子代理评审](subagent-review.md)：优先新建上下文子代理并只投喂评审包；环境不具备时降级为角色分离自审，标注并披露，不得据此声称通过。

### 反目标（写进 DESIGN.md，按题材检查）

- 防止与内容无关的装饰、无用途等待及无信息／体验推进的模板替换；不禁止平面、文字、信息图、档案或广告式表达。
- 视觉创意方案的禁止项是默认模板清单，不是形式否决清单；采用例外须记录理由与替代做法。
- 画面注释从紧：除外部素材署名、口径／方法解释与用户明确要求外，不增加注释；主题、对象名称与结论仍可成为主要表达。
- 运动、静止、光影和材质按表达需要选择，不设每镜必备项和连续静止时限。
- 镜头数量、硬切、并列或连续运动按叙事选择；不用“电影画面”作为唯一审美。

### 三道冷审（合并职责，不逐项派代理）

1. **冷观众**：先看前 3 秒记录开场期待，再看包含揭示前后的完整表达段落，记录疑问、误解及获得回报的时刻；只看开场不能否决后续核心理解。
2. **美术指导**：对照实际可访问且适用的参考，描述构图、字阶、光材质、运动／静止与题材表达的差距及有效之处。参考类型按作品选择，不强制三个立体／电影参考，不强凑缺陷。
3. **平台编辑**：按声明手机尺寸与适用诊断观察观看入口、阅读负担和完整段落作用。形式标签如“广告”“信息图”“模板”不能单独产生必改项。

冷观众并入粗片审查，美术与平台编辑并入视觉审查，独立性与降级按[独立评审职责](subagent-review.md)。先盲看落盘，再单独接收中性可观察目标；不得提供预期答案或作者辩护。有效缺陷不能被技术通过或制作者意图覆盖；创意风险、偏好与证据不足按下节处理，不统称为冷审否决。

### 缺陷、风险、偏好与证据不足

| 性质 | 判据与处理 |
|---|---|
| 实际缺陷 | 事实／许可／技术错误，或完整表达窗口后核心目标仍失败；给出时间位置、显示尺寸、现象、受影响目标及前后文证据。核心缺陷必改，其他差距按影响分级 |
| 创意风险 | 延迟揭示、抽象、静止、重复或声画反差可能失效；补完整窗口或匿名候选比较，核实后转实际缺陷或有依据的取舍。未验证核心风险保持未完成 |
| 审美偏好 | 目标成立但评审不喜欢其风格；记录建议及原因，不直接升级必改 |
| 证据不足 | 缺上下文、采样不足或方法无法判断主观体验；补证或披露限制，不冒充缺陷，也不自动判通过 |

立即理解与延迟理解目标在设计阶段预先声明，不能事后改口豁免失败。延迟理解检查完整窗口的揭示是否消除错误认识、兑现期待；抽象表达不要求唯一口头答案，但仍应检查预先声明的可观察目标。作者解释不能代替画面效果。

实质分歧按[争议独立复核](subagent-review.md)处理：新评审先盲看前后文，再核对原条件，允许结论为证据不足或非缺陷取舍；不投票，不挑宽松报告。有证据的核心缺陷仍须关闭。

### 诊断测试与适用性

核心事件按[视觉事件设计](visual-creative-direction.md#视觉事件设计)检查完整表达窗口与新增认识；遮去结论句时保留必要标签，分析画面与文字职责，不作所有题材的通用否决条件。

测试首先产生观察，不自动产生必改项。记录适用原因、完整段落观察与证据边界；最终仍检查原始完整表达，不能用拆掉媒介后的失败代替成片判断。

| 测试 | 用途与边界 |
|---|---|
| 去文字 | 查看文字和非文字分别承担什么；文字主导时用于职责分析，不要求遮字后事件完整成立 |
| 缩略图 | 200px 宽观察重心与主体轮廓；必要文字阅读按声明手机尺寸，不要求缩略图读全信息或辨清所有关系 |
| 静音 | 查看声音承担的叙事作用；有声作品不要求拆掉声音后完整成立，无声作品按无声目标检查。视觉创意方案把「关声能大致看懂」作为设计目标，不是新的拆声验收门禁；声音承担必要线索时记录原因 |
| 运动／静止 | 按风险加密采样，结合前后文检查观察、期待、情绪与变化；不设固定运动密度或静止时限 |

这些测试不能证明实际播放听感；帧序列与自动音频仍按既有替代证据边界记录。未覆盖的声画感染力不得声称已通过。

### 门禁位置

- 粗片阶段先验证核心表达及适用风险，再扩展全片；不强制固定秒数、空间主体或最终材质。
- 最终两名隔离代理按职责覆盖；实际必改项未关闭、核心风险未验证时不得标记制作复核完成。
- `visual-notes.md` 沿用唯一问题表，记录性质、证据及重要返工收益／表达损失；评审者只报告，不修改作品。
- 评审包不是新增审批或机器门禁；缺少评审包与独立性记录，仍视为未执行。

### 创意保护判断演练（非成片评审）

下表是规则情景推演，不代表实际看过样片或完成独立评审。两列都应能正确处理，不能只验证“不误伤”而遗漏真实失败。

| 表达 | 应保护的情形 | 仍须处理的情形 |
|---|---|---|
| 静止 | 揭示后保持画面供观察，前后文有明确消化作用，不因超过1.5秒失败 | 完整段落没有观察、期待或情绪用途，仍需删短或重设计 |
| 延迟揭示 | 局部先制造疑问，后续窗口清楚揭示并形成回报 | 完整窗口后仍形成核心误解，作者称“故意留白”也不能豁免 |
| 动态文字 | 文字对照、重组或节奏产生意义，去文字失败不直接否决 | 文字机械换页且无信息、关系或体验推进，仍属实际问题 |
| 声画协作 | 声音承担线索或反差，静音后不完整不直接失败 | 核心听觉线索缺失或时序错误须核实修复；方法不能验证感染力时记证据不足 |
| 母题 | 原画面因后续语境改变含义，不要求外形增长或背景像素差 | 重复没有新的作用，只靠作者宣称“统一”不能通过 |
| 核心视觉母题 | 只出现一次也能组织全片，不要求重复三次或持续变形 | 设计写了母题，但成片没有对应可见事件，按未兑现处理 |
| 无传统高潮 | 强度曲线、替代记忆点与原因成立时可保留 | 机械要求传统高潮，或全片强度单调且无理由，仍须处理 |
| 横屏/竖屏空间 | 竖屏按纵向推进转译，不要求左→右时间语法 | 竖屏硬套横向时间导致关系误读，仍属实际缺陷 |
| 画面文字预算 | 主句、辅助句与标签层级清楚时成立 | 文字互相竞争导致核心信息不可读，仍须修复 |
| 信息图 | 图表或平面关系有效解释内容，形式标签不构成否决 | 图形映射让观众形成错误因果，仍是核心缺陷 |
| 缩略图 | 200px下主体重心清楚、细字不可读，转到手机尺寸核对必要文字 | 声明手机尺寸下关键正文仍不可读，必须修复 |
| 减法 | 删去不损知识却破坏情绪收束，比较后可保留 | 既无理解又无体验作用的重复，不能用“氛围”直接保留 |
| 重要返工 | 更直白版本泄露发现，记录收益与损失后继续找解法 | 原版确有核心误读，不能以保留创意为由拒绝修复 |
| 抽象表达 | 可观察目标成立，允许不同感受，不要求唯一复述 | 缺证或目标未成立，不能用“审美偏好”改名为通过 |

文档维护时按本表核对规则推导；作品制作时仍须提供真实版本与证据，不能把演练结论复制为作品通过记录。
