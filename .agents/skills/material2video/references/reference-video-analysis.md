# 参考视频逆向拆解与可迁移规则

用户提供一条或多条「效果很好」的参考视频，要求学习、拆解或借鉴时，按本文执行。本文回答**它为什么让人愿意继续看、哪些能力可以迁移**；外观如何对齐见[参考风格契约](reference-style.md)。两者可以叠加：先拆解机制，再按需转译外观。

本文只规定分析与落点证据，不新增 CLI 命令、运行时字段、分镜 JSON 字段或自动审美阈值。

## 什么时候触发

- 用户说「学习这个视频」「拆解它为什么有效」「这种表达怎么做到的」，或给出一条或多条参考并要求「像它一样好看／好看得有道理」。
- 用户只要求复用参考音轨时，不属于本文范围，按[复用参考音轨](article-media-and-sound.md#复用参考音轨受控例外)执行。
- 用户明确要求外观相似时，在本文之后继续执行[参考风格契约](reference-style.md)。只做外观量测而说不出观看驱动力，视为拆解未完成。

## 证据类型与能支持的判断

| 证据 | 能支持 | 不能支持 |
|---|---|---|
| 完整成片（可播放） | 时间轴、节奏、运动、转场、声音、完整事件 | — |
| 片段 | 片段内的机制与节奏 | 全片结构、结尾回报、前后铺垫 |
| 静帧 / 接触表 | 构图、尺度、光影、材质、文字层级 | 运动曲线、剪辑节奏、声音；不得据单帧断言「固定机位」 |
| 作者描述 / 二手评论 | 意图与背景线索 | 画面事实；必须标注为描述而非观察 |

- 每个结论标注证据类型。无音频证据时，声音一节写「不适用」并说明，不虚构 BGM、音效或静音设计。
- 关键运动与转场必须用连续帧或原片核对；1 秒连续帧优先于多张分散截图。

## 产物写在哪

- 单条参考：写入作品 `DESIGN.md` 的「参考拆解」区块。
- 多条参考或逐镜时间轴较长：允许写入 `outputs/reference-analysis.md`，`DESIGN.md` 只保留摘要、采用结论与链接，不复制整份分析。
- 采用外观层时，另按[参考风格契约](reference-style.md)写 `outputs/style-reference.md`；两份文档分工不同，不能互相替代。
- 拆解结论、作者意图与旧结论不进入独立盲审包；盲审仍按[独立评审](subagent-review.md)只收中性可观察目标与证据。

拆解时分清外观、讲解机制、镜头组织与声画节奏；每项关键机制写明“看见什么变化、因此理解什么”，
附来源时间窗与证据类型，再决定采用、不采用或待验证。不能只保留色板与风格词，也不要求四类全选。
采用讲解机制后，按[四种讲解机制](explainer-design.md#四种讲解机制的执行方法)转成作品设计与验证窗口；
不把参考结论或预期答案投喂盲审者。

## 第一步：一句话观看驱动力

先回答：**这个视频最核心的观看驱动力是什么？** 只保留 1–3 条，不罗列全部优点。

必须写成「机制 + 画面证据」，不能写「节奏好」「画面高级」「很有质感」。

| 不成立 | 成立 |
|---|---|
| 节奏很好 | 每 3–5 秒用一次尺度跳变更新同一对象的认识：近景只看到坡道，拉远才看到高度差 |
| 信息逐步揭示 | 前 40 秒只让观众跟随局部，直到结尾才第一次看到全貌，前面的局部线索在此刻重组成整体 |
| 视觉冲击强 | 同一主体从占画高 60% 缩到 4%，观众被迫用新尺度重新理解它 |

自检：删掉这条驱动力，观众还会继续看吗？如果不会，它才是真驱动力；如果删掉后视频仍成立，它只是优点。

## 第二步：按时间轴拆解

按镜头或重要事件分段，覆盖全片；信息密度低的段落可以合并，但不能跳过。

| 时间码 | 观众看到什么 | 视觉事件（进入／消失／变形／揭示／镜头／空间／注意力） | 观众预期 | 满足／延迟／打破 | 这段的作用 | 证据 |
|---|---|---|---|---|---|---|
| 00:00–00:03 |  |  |  |  |  |  |

写作要求：

- 「视觉事件」用动词描述状态变化，不写「出现文字」「画面漂亮」；文字淡入、图标弹出、简单缩放不算强事件，除非它改变了信息关系。
- 「这段的作用」从这些里选：建立悬念、解释概念、制造反差、提供信息、情绪升级、建立空间关系、完成转场、埋伏笔、兑现回报。
- 「观众预期」写观众此刻在等什么；「满足／延迟／打破」写视频实际怎么处理，并说明是否有意。
- 只有静帧证据时，时间码标为估计区间，并注明不能判断运动与节奏。

## 第三步：挑出真正的视觉事件

强视觉事件 = **画面状态发生明显变化，并让观众获得新的认识**。装饰运动、无信息增量的转场、只换文字都不算。

对每个候选事件回答：

| 问题 | 要写出的内容 |
|---|---|
| 初始画面 | 观众先看到什么，哪些关系可见 |
| 为什么以为会这样 | 前文建立了什么判断或期待 |
| 实际发生了什么 | 状态、空间、尺度、材质、因果怎样改变 |
| 之前隐藏了什么 | 哪条信息被遮蔽、延迟或只给了局部 |
| 何时公开 | 具体时间码与触发画面 |
| 变化维度 | 空间／数量／速度／高度／距离／明暗／分叉／状态／关系 |
| 为什么值得看 | 新认识是什么，为什么必须用画面而不是文字获得 |
| 删除测试 | 删掉它，视频损失哪条理解或哪种体验 |

可选评分（仅用于同一参考内部的投入排序）：视觉冲击、信息价值、意外程度、记忆程度、制作成本，各 1–10。评分不是验收条件，不跨参考比较，不推算留存，也不替代画面证据；没有证据的项不填。

## 第四步：导演设计

拆导演在控制什么，而不是只描述画面。

- **注意力**：每个时刻希望观众看哪里？用什么手段——明暗、大小、运动、景深、构图、遮挡、色彩、运镜、留白、声音。写出具体画面证据。
- **信息揭示**：一开始没有告诉观众什么？为什么不能一开始全给？在哪个时间点、由哪个画面变化公开？
- **预期管理**：何时建立预期、延迟兑现、满足或打破；打破预期必须有前面建立判断的画面依据，不能只在结尾放一个全貌就声称反转。
- **节奏**：分开写信息节奏、镜头节奏、动画节奏、情绪节奏。不要只说「快」或「慢」，要说明这一段为什么快、那一段为什么慢，以及快慢改变了什么。
- **高潮**：全片视觉力量最大的时刻在哪？之前做了哪些铺垫（尺度、数量、信息缺口、声音蓄力）？为什么这一刻有效？删掉铺垫后还成立吗？

## 第五步：视觉语法

| 维度 | 要记录的内容 |
|---|---|
| 构图 | 中心还是偏置；留白比例；主体尺寸；前中后景关系 |
| 镜头 | 固定、推进、拉远、环绕、跟随、俯视、微距或第一人称；运镜速度与目的 |
| 空间 | 2D、2.5D 或 3D；平面空间、无限空间、微缩世界或巨物尺度 |
| 材质 | 真实、极简、玻璃、金属、塑料、纸张、UI 或数据可视化 |
| 动态 | 快速启动、缓慢减速、弹性、惯性、重力感、机械感、流体感；用连续帧判断，不用静帧猜 |
| 转场 | 只是连接镜头，还是前一个镜头的对象、运动或空间变化生成了下一个镜头 |

**转场单独标记**：前镜运动自然生成下镜的，标为「生成式转场」，并写出是哪个对象、运动或空间变化生成了下一幕。这是高价值机制，优先考虑迁移；单纯淡入淡出通常只是连接。

## 第六步：视觉母题

判断全片是否存在一个贯穿的视觉母题，例如时间→道路、增长→高度、选择→分叉、信息→粒子、复杂性→空间展开、风险→裂缝。

- 存在时：用「把 ___ 设计成 ___」写出母题，并解释它为什么适合主题、在哪些时刻改变含义。
- 不存在时：说明视频靠什么维持统一（构图、材质、运动、声音或文字），不要用「统一风格」四个字了事。

## 第七步：声音（仅有声作品）

按需分析 BGM、环境音、Foley、UI 音效、Impact、Whoosh、转场音、Riser、Bass Hit、静音段落。

重点回答：

- 声音是否早于视觉出现，提前预告画面变化？
- 声音是否帮助制造视觉事件（撞击、显现、断裂、拉远）？
- 高潮是否通过声音提前蓄力，视觉到达时声音已完成铺垫？
- 静音段落是否被主动使用，用在哪里、为什么？

无声作品写「不适用：无音频证据」，不补写声音设计，也不据此评价节奏。

## 第八步：表面风格与底层机制分开

必须建立两栏，避免把某条作品的成品特征当成方法。

| 不应该直接模仿（表面风格） | 应该学习（底层机制） |
|---|---|
| 某个字体、配色、图标风格 | 信息分阶段揭示 |
| 某个具体物体、角色、场景 | 每隔一段用状态变化更新认识 |
| 某种建模或渲染质感 | 视觉对象承担逻辑关系，而不是当装饰 |
| 某个具体镜头或运镜参数 | 前一个动作自然生成下一幕 |
| 参考的文案、分镜、构图 | 高潮前降低信息密度、蓄力 |
| 参考的秒数、镜头数量 | 用尺度变化改变观众对同一对象的理解 |
| 参考的音效采样 | 先建立认知，再用画面推翻或补全认知 |

表面项写入[不借清单](reference-style.md#第一步借鉴分层)，只借语法不借符号；底层机制才进入第九步。

## 第九步：提炼可迁移规则

单条参考至少提炼 10 条候选规则。每条必须可执行，写清四件事：

| 字段 | 要求 |
|---|---|
| 规则 | 对象 + 时机 + 动作，一句话可照做 |
| 机制 | 为什么有效，改变观众哪条认识 |
| 可观察判据 | 成片里看到什么算做到，在哪个环节检查 |
| 失败现象 | 做不到时画面会出现什么 |
| 适用边界 | 哪些题材、画幅或声音条件不适用 |

反例：「画面要有冲击力」「节奏要紧凑」「善用留白」——没有对象、时机和判据，不算规则。

正例：

- 规则 01：每个核心段落至少设计一个不能被文字淡入替代的视觉事件；静帧或安静段落写明理由与替代组织方式。
- 规则 02：关键结论不在镜头开始时给出；先建立旧认知，再用画面变化公开新信息。
- 规则 03：连续镜头优先让前一个镜头的对象、运动或空间变化生成下一镜头；使用淡入淡出时说明叙事理由。
- 规则 04：高潮前降低信息密度或公开范围，让观众先形成判断，再由揭示改变判断。
- 规则 05：用同一对象的尺度变化更新认识，不用新增标签解释它变重要了。

不要把「每隔固定 X 秒必须变化」写成通用门禁：本项目允许静止、观察和安静收束，是否有变化按段落职责判断。

提炼完成后做采用筛选：通常选 3–5 条进入本片，逐条写到具体场景／镜头与验证方式；超过时说明为什么不造成堆砌。未采用的规则保留在分析里，标注原因。

## 第十步：反推制作模板

根据参考的真实结构总结一个时间模板，例如：

> Hook → 建立视觉世界 → 提出问题 → 第一次状态变化 → 增加复杂度 → 制造错误预期 → 关键视觉事件 → 尺度升级 → 高潮 → 最终揭示 → 余韵

模板只是从这条参考反推的结构，不得机械套用到本片：

- 写明每一步对应参考的哪些时间码与视觉事件。
- 本片采用时，映射到[四阶段主线](production-workflow.md#四阶段主线)的「方案确定」与「粗片验证」；不新增制作阶段或文件。
- 参考没有传统高潮、反转或母题时，按实际结构写，不为填模板制造段落。

## 多条参考：共同规律与不同实现

分析多条参考时，不要分别总结完就结束：

| 观察 | 写法 |
|---|---|
| 共同规律 | 同一机制在几条参考里出现，是否有独立画面证据；重复次数与证据强度分开记 |
| 不同实现 | 同一个导演目的，各自用什么不同方法达到（例如「揭示全貌」分别用拉远、翻页、视角切换） |
| 高价值共性 | 在不少于三分之二的参考中出现（且至少涉及两条参考）、并有独立画面证据的机制，优先进入本片；只在一条出现的，视为可选风格 |

最后按重要性排序，形成本片的《优秀视频共同设计规律》：每条写机制、出现次数、参考证据、适用边界与本片落点。不按「好看程度」排序，也不把单条作品的偏好写成通用规律。

## 写进本片

拆解结论必须落到现有文档，不新建平行报告或新字段：

| 结论 | 落到哪里 |
|---|---|
| 观看驱动力、核心表达 | `DESIGN.md` 立意六项 |
| 视觉母题 | `DESIGN.md`「表达载体」 |
| 视觉事件与时间结构 | 逐场设计表、核心事件五段式与导演卡，见[视觉创意导演](visual-creative-direction.md#视觉事件设计) |
| 核心高潮机制 | [视觉力量设计](visual-impact-design.md)：按未决风险比较机制，不固定候选数量 |
| 外观层 | [参考风格契约](reference-style.md) 的 L1／L2／L3 与八项指标 |
| 不借项 | `DESIGN.md` 禁止项与不借清单 |

采用一条规则的最低证据：写清它落在哪个场景／镜头、看什么判据、失败时长什么样。只写「采用了延迟揭示」但没有对应画面与检查点，不算采用。

边界不变：参考画面、字幕、贴图不进入成片，渲染链路不读取 `refs/`；参考音轨复用只覆盖音频。规则不得覆盖事实、必要可读性、作品画幅或声音契约。

## 只能偷走三个能力

分析结束时回答：**如果只能从这个视频偷走 3 个能力，而不是 3 个视觉元素，是哪三个？**

- 必须写成能力：例如「延迟公开全貌，让局部线索在结尾重组成整体」「让前一镜的运动生成下一幕」「用同一对象的尺度变化代替新增标签」。
- 不写字体、配色、物体、镜头参数或某段分镜。
- 每条写为什么能迁移到本片、迁移后在哪一场验证。

## 制作前自检

- [ ] 观看驱动力写成机制 + 证据，不是形容词。
- [ ] 时间轴覆盖全片；只有静帧的地方标明了限制。
- [ ] 至少一个视觉事件通过删除测试；文字淡入没有被当作事件。
- [ ] 导演设计分别写了注意力、隐藏信息、预期与四类节奏。
- [ ] 转场区分了「连接」与「生成」。
- [ ] 母题存在或替代统一方式已写明。
- [ ] 声音结论有音频证据，或明确不适用。
- [ ] 表面风格与底层机制分栏完成，不借清单已写。
- [ ] 候选规则不少于 10 条，每条有判据与失败现象。
- [ ] 采用规则 3–5 条，落到场景／镜头并有检查点。
- [ ] 反推模板不是机械套用，已映射到本片阶段。
- [ ] 多条参考已找共同规律，没有只做分别总结。
- [ ] 参考素材不进入渲染链路，不进入盲审包。

## 常见失败模式

| 失败模式 | 表现 | 正确做法 |
|---|---|---|
| 写成内容摘要 | 复述视频讲了什么，没有机制 | 回答为什么继续看、何时获得新认识 |
| 空泛评价 | 「画面高级」「节奏很好」 | 换成机制 + 时间码 + 画面证据 |
| 把弱变化当事件 | 文字淡入、图标弹出、简单缩放 | 要求状态变化并带来新认识 |
| 只借表面 | 抄配色、字体、镜头、文案 | 分栏后只迁移底层机制 |
| 单帧推断运动 | 一张静帧写「固定机位」 | 看连续帧；跨帧比对结构元素位移 |
| 无音频写声音 | 凭印象补 BGM、音效、静音 | 标记不适用或补证据 |
| 多条参考各写各的 | 没有共同规律与排序 | 按 2/3 出现率找高价值共性 |
| 规则不可执行 | 「要有冲击力」 | 写对象、时机、判据、失败现象 |
| 采用项没有落点 | 只说「用了延迟揭示」 | 写到场景／镜头与检查点 |
| 把参考当临摹 | 复现参考分镜、符号、构图 | 只借语法，符号与分镜另起 |
| 把分析喂给盲审 | 评审者读到作者意图与旧结论 | 盲审只收中性目标与证据 |
| 把评分当验收 | 用 1–10 分决定通过 | 评分只做投入排序，验收看画面证据 |
