# 参考视频分析与借鉴

开展[设计前深度研究](stage-research.md)，或用户要求学习、拆解或借鉴参考时，围绕实际需求分析：可以只研究配色、字体与构图，也可以学习镜头、节奏或讲解机制。研究不以采用参考为前提，不要求固定步骤、规则数量、分层指标、风格报告或同族判定。

## 记录采用范围

研究问题、来源、实际查看范围、证据观察与综合发现统一保存在 `RESEARCH.md`，记录方式按研究指南执行。实际采用参考时，在 `DESIGN.md` 引用研究结论，记录用户要求或最终采用特征、本片落点与必要对照。普通采用记录一段即可；采用分析较长时可链接 `outputs/reference-analysis.md`，不复制研究报告或维护第二份研究证据表。未采用的方法无须逐项列出或说明理由。

需要外观相似时，针对关键差异选择并排图或具体量测；需要借鉴运动与叙事时，查看相应完整窗口。不设统一采样数、固定样片时长或八项指标。画幅不同则按本片构图、安全区与实际显示尺寸调整，不照搬源像素或硬裁。

用户点名已登记的外部项目时，另读[外部参考项目登记](external-reference-projects.md)，核对固定版本、许可与受限资产。

## 证据边界

说明实际获取和查看的材料：完整成片、局部片段、有序帧、静帧或二手描述。静帧只支持其显示的构图与外观，不据此推断运动曲线、全片节奏或声音；片段结论不扩大为全片。未访问、未观看或无音频依据的部分如实说明，不补写观察。

关键运动、接触与转场用覆盖完整窗口的过程证据核对；记录实际显示尺寸、时间位置与未覆盖范围。具体取证要求见[视觉复核](visual-review-rubric.md)，不另立分析检查表。

## 关键目标与复核

用户明确要求的关键特征写入现有设计与适用风险，`reason` 和 `requiredEvidence` 可引用同一采用记录。未决项沿[审核策略](checkpoint-gates.md#审核计划与风险触发)验证，不追加固定风格轮次或同族结论。

在既有评审中核对实际采用目标，参考原作与旧版分别用于判断目标兑现和修订收益。比旧版更好、技术通过或增加效果均不能代替关键目标成立；纯偏好不单独否决，关键失败不得事后改称有意偏离。

RESEARCH.md 中的研究者推理、方向推荐、作者分析、设计理由与旧结论不进入独立盲审包。评审先记录实际观察，再核对中性可观察目标，执行见[独立评审](subagent-review.md)。

## 素材使用边界

允许学习外观和表达方法，不把通用配色、字体气质、符号或构图一律列为禁止借鉴。参考画面、字幕与贴图不得直接进入成片，渲染链路不读取 `refs/`；实际素材的来源、许可和导入仍按[媒体契约](article-media-and-sound.md)处理。

只复用参考音频时，按[复用参考音轨](article-media-and-sound.md#复用参考音轨受控例外)执行，不扩大为画面资产授权，也不因此强制分析视觉。
