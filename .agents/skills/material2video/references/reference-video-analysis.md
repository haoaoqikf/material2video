# 优秀案例调研（Visual Reference Research）

这是[研究与创意试制](stage-research.md#优秀案例调研)中的独立环节。先把表达目标变成研究问题，再搜索、查看、拆解和转化案例，交付能试制的镜头方案。实质性视听修订复用仍有依据的结论，按出现的新表达问题补查。

## 选择具体标杆

先写清观众要看懂什么、应当感受到什么、哪一步容易看不明白。把「有电影感」换成可研究的问题，例如「镜头怎样先让观众注意两组数据接近，再看清差距从哪里开始扩大？」用中英文组合题材、对象、预期效果和表达方式，例如「产品结构 分阶段揭示 动态分镜」或 `product reveal motion graphics storyboard`。同题材帮助理解内容，跨题材可对比相似的揭示、构图和节奏。用户提供参考时先查看并核对用途。

| 研究问题 | 优先查找 |
|---|---|
| 构图、配色、关键帧与分镜怎样组织 | [Behance Motion Graphics](https://www.behance.net/galleries/motion/motion-graphics) |
| 导演如何形成表达方向，工作室如何试验和制作 | [Motionographer](https://motionographer.com/) |
| 完整片段怎样安排镜头运动、节奏、转场和声画配合 | [Vimeo Staff Picks](https://vimeo.com/channels/staffpicks) |
| 程序化作品怎样讲解数据、科技或软件操作 | [Remotion Showcase](https://www.remotion.dev/showcase) 和 [Prompt Showcase](https://www.remotion.dev/prompts) |

可先筛出 3～5 个与问题相关的候选，再按待决定的构图、动作或节奏选择值得深入的作品。初筛数量是建议，研究深度以能支持决策为准。优先打开作品或创作者项目页，检查实际可看的成片、片段、分镜或风格帧。遇到页面或视频访问限制时，先找创作者原页或官方发布，再找能回答同一问题的其他作品。仍缺证据时标明缺口。

区分参考用途，允许一部作品兼具多种用途：

| 用途 | 决策依据 |
|---|---|
| 整体视觉品质 | 主体、构图、层次、细节怎样共同形成目标感受 |
| 专项表现 | 某种排版、材质、光照、图形、镜头或运动怎样成立 |
| 信息表达 | 数据、对象关系和阅读顺序怎样清楚呈现 |

图表规范可以支持读数和布局，不自动证明商业美术、材质或电影感。保存实际查看的参考图/窗口与来源，便于后续对应展示；不能用网页摘要和链接列表代替观看。

### 记录实际查看范围

记录作品来源 URL、参考用途、实际看到的画面或时间窗，以及素材是否包含音轨。动态案例查看关键变化的建立、经过与落点，按需要补看遮挡、焦点交接和转场。可取得媒体时按研究问题提取有序帧或保留短窗口，用于后续对照。取帧集中在能验证结论的位置，例如动作前、最难辨认的中段和结果稳定处。

已采用的整体品质参考持续作为比较依据。拆成薄片、亮边、阴影等局部特征只是寻找实现办法，特征齐全不代表主体吸引力、构图组织与完成度成立。更换参考或目标须记录原因并重新比较，不能为迁就现有实现而缩窄原承诺。

## 深入拆解与本片转化

围绕会改变当前设计的问题分析，不机械填满所有维度：

| 维度 | 要研究的关系 |
|---|---|
| 构图比例 | 主体占比、位置、留白、平衡、视觉张力、焦点顺序 |
| 字体排版 | 字形、字重、字号关系、行距字距、文字与主体的组织 |
| 色彩层次 | 明暗分配、强调色用途、背景与主体分离 |
| 图形空间 | 轮廓语言、尺度、透视、前后关系与形体辨识 |
| 材质光影 | 表面、光向、反射、阴影、体积及合成细节 |
| 动效 | 触发、起止状态、速度变化、路径、主体身份与反馈 |
| 节奏 | 信息揭示顺序，变化与停顿如何交替，哪次切换带来新信息 |
| 视觉表达 | 文字、对象、镜头与图形怎样分工，观众何时看懂关键关系 |
| 声音与转场 | 动作、镜头和声音怎样接续，重点与留白落在哪个窗口 |

研究时追问观众先看哪里、为什么主体在这个位置、元素怎样进入和离开、哪次停顿给了识别时间、哪次镜头变化提供了新信息。把每个解释连回实际画面。多个案例能回答同一问题时，比较它们对本片内容、画幅、阅读时间及相邻镜头的适用性。不能将“高级极简”“暗底加大字”当成效果形成机制；静帧不能直接证明运动或声音，但可以据此提出待验证的推导。

把结论落实为“参考中的具体处理 → 本片采用方式/适应性调整 → 实际验证办法”。例如研究已经观察到透明外壳依靠薄亮边与较暗腹部形成体积，本片采用该特征时，需要明确壳体与内核、背景、光向关系，用当前真实主体和文字生成代表帧，再核对轮廓、体积和焦点；只改变背景色不能验证该效果。此例是方法示意，不要求其他风格具有玻璃材质。

在 RESEARCH.md 按「实际观察 → 效果解释 → 可借鉴的设计方法 → 本片关键帧与动作安排 → 验证预期」写清采用依据。实际观察须定位证据，解释含推断时须标明。本片方案写明构图、主体身份、关键状态及信息揭示顺序。验证预期写明观察窗口、画面里应该看到什么，以及什么现象说明效果未成立。

把镜头方案所需的能力交给[成熟组件调研](visual-components.md#成熟组件调研)，例如按统一坐标逐步揭示两条曲线、结尾展开全局时保持主体可辨。先明确动作和效果，再据此筛选实现。能影响核心方向的证据缺口先补查。能用小试判断的未知写清依据、假设和验证预期后进入试制。

### 只有静帧时的推导

静帧不足以证明运动或声音，但可以作为推导起点。从材质厚度、曲率、光向、阴影软硬、主体尺度、层间空气、色彩层级、字体重量与留白，推导动作速度/缓动、镜头、转场类型和声音材质。每条按“依据 → 推断 → 置信度 → 验证指标”记录，标为假设；用过程样片的有序帧、帧差/场景切分和音频信号量测核对，不写成已观察事实。仅对本片实际采用、承诺或影响判断的过程做必要推导；静止、无声或硬切不强加无关假设。

| 静帧证据 | 可推导维度 | 例子 |
|---|---|---|
| 厚纸、薄边、软接触阴影 | 表达/动态/声音 | 实物隐喻、缓慢落定、纸质拟音 |
| 弯曲曲面、层间空气 | 动态/转场 | 形态展开、遮挡或匹配剪辑 |
| 同一对象反复出现 | 表达/转场 | 对比叙事、匹配剪辑 |
| 巨型字面、层级分明 | 动态/声音 | 字面重组、节奏型敲击 |
| 暖光、留白、色彩层级 | 表达/声音/转场 | 电影化、氛围床、渐变转场 |

验证按实际采用机制选择可观察预期和必要量测，不要求每维填满所有指标。例如：状态切换帧、最长无变化窗口、非 cut 转场帧数与类型、匹配剪辑主体位置/颜色容差、声音事件与起音容差、响度/真峰值/静音段。

## 示例：30 年复利增长

**研究问题**是怎么让观众先认出两条曲线在前十年接近，再看清差距从哪里开始扩大，最后感受到 30 年的整体规模。可用「复利增长 动态图表」「指数曲线 数据叙事」和 `compound interest motion graphics`、`exponential growth animation explainer`、`line chart cinematic animation` 查同题材和跨题材案例。比较不同作品如何交代初始基准、把注意力移到分离区间、在展示全局时保持对象可辨。

下表只示意本片转化与试制预期。正式采用前补入实际查看的案例、时间窗和观察依据，并用本片数据确认分离区间。

| 镜头阶段 | 关键帧与动作 | 试制时看什么 |
|---|---|---|
| 建立对比 | 同一坐标系中揭示前十年，稳定两组数据的名称和颜色，留出辨认窗口。 | 不靠旁白也能认出两组对象，并看出初期差距较小。 |
| 揭示分离 | 按实际年份继续展开，在数据开始明显分离的区间留出阅读时间。 | 观众还能认出原来的两组对象，并能指出差距开始明显的区间。 |
| 展示规模 | 逐步展示完整 30 年范围，保留坐标依据，突出终值和差额。 | 最终窗口可读出规模，并区分数据变化和镜头拉远造成的视觉变化。 |

交给组件调研的需求包括两条曲线共享同一坐标与时间输入、稳定颜色和标签、可控揭示与停留、全局镜头过渡及读数对齐。用本片数据检查前十年、实际分离区间和最终读数，核对镜头变化中谁在移动、数据对应的位置是否正确。

## 记录采用范围

研究问题、用途、来源、实际查看范围、观察/解释/应用、限制与比较统一保存在 `RESEARCH.md`。围绕实际采用、承诺或影响判断的处理深入记录；只有静帧时按上节推导必要过程，写清依据、置信度与验证指标。在 `DESIGN.md` 引用结论，记录原要求、全片采用范围、共同语言与有效基线；本场落点、适应性调整、节拍、配合、声音、衔接与验证办法按[场景设计](scene-design.md)记录。普通采用记录可简短，但须能指导制作；采用分析较长时可链接 `outputs/reference-analysis.md`，不复制研究报告或维护第二份证据表。未采用的方法无须逐项列出理由。

需要外观相似时，针对关键差异选择并排图或具体量测；需要借鉴运动与叙事时，以参考的有序帧与音轨信号对照，并标注推断。不设统一采样数、固定样片时长或八项指标。画幅不同则按本片构图、安全区与实际显示尺寸调整，不照搬源像素或硬裁。

同内容候选的筛选与投入按[研究与试制](stage-research.md)执行。概念画用于探索，正式基线须在拟用制作链路中重现关键效果，精确文字、数据与几何另按实际内容核对；不能用生图证明正式动态，也不能把“能实现”代替实际重现。效果未成立前不批量展开全片。

引用外部项目时记录实际来源 URL、固定版本或抓取时间、许可和使用范围。代码、媒体、字体与第三方资产分别核验；方法研究不等于素材授权，固定来源保留在采用作品或示例的材料中，不维护额外项目清单。

## 证据边界

说明实际获取和查看的材料：完整成片、局部片段、有序帧、静帧或二手描述。静帧只支持其显示的构图与外观；可以据此推导运动、节奏或声音方向，但必须标为假设并用过程样片核对，不得写成已观察事实。片段结论不扩大为全片。未访问、未观看或无音频依据的部分如实说明，不补写观察。

关键运动、接触与转场用有序帧、帧差/场景切分和音频信号量测核对；记录实际显示尺寸、时间位置与未覆盖范围。具体取证要求见[视觉复核](visual-review-rubric.md)，不另立分析检查表。

## 关键目标与复核

用户明确或助手主动采用并承诺的关键特征写入现有设计与适用风险，`reason` 和 `requiredEvidence` 可引用同一采用记录。未决项沿[审核策略](review-contract.md)验证，不追加固定风格轮次或同族结论。独立盲看只观察作品自身；同轮对照提供实际目标媒体及中性可观察采用特征，按对应画面、窗口和显示条件核对兑现与差距。缺少参考或覆盖不足时保持该目标未验证。

在既有评审中核对实际采用目标，区分整体品质标杆、专项参考和备选/历史比较。整体标杆看主体、构图与细节共同形成的效果，备选和旧版看相对优劣及修订收益，不能互相替代。比旧版更好、清楚可读、技术通过或增加效果均不能代替目标成立；纯偏好不单独否决，关键失败不得事后改称有意偏离。原创融合不要求复制全部特征。

RESEARCH.md 中的研究者推理、方向推荐、作者分析、设计理由与旧结论不进入独立盲审包。评审先记录实际观察，再核对中性可观察目标，执行见[独立评审](subagent-review.md)。

## 素材使用边界

允许学习外观和表达方法，不把通用配色、字体气质、符号或构图一律列为禁止借鉴。参考画面、字幕与贴图不得直接进入成片，渲染链路不读取 `refs/`；实际素材的来源、许可和导入仍按[媒体契约](article-media-and-sound.md)处理。

只复用参考音频时，按[复用参考音轨](article-media-and-sound.md#复用参考音轨受控例外)执行，不扩大为画面资产授权，也不因此强制分析视觉。
