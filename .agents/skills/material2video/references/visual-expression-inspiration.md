# 顶级视觉创意与设计指导

目标是探索具有世界一流商业视觉作品追求的方向，以实际效果判断品质，不保证流程本身能产出顶级作品。创作或实质性视听修订前完整阅读，本任务已读则不重复。

## 创作原则

- 释放创造力：探索不同隐喻、构图、空间、材质、光影、动态与声音，不满足于第一个合理方案，也不因容易实现而优先选它。
- 追求卓越：研究优秀发布会、广告与电影如何建立焦点、情绪、细节和记忆，避免机械模仿表面风格。
- 发挥审美判断：比较实际方向，识别套路和无潜力方案，必要时推翻，不在平庸创意上持续堆细节。
- 落实具体决策：构图、比例、色彩、材质、光照、空间、镜头、运动、转场与节奏共同服务表达，兼顾独特性、清晰度和完成度。
- 依靠视觉反馈：通过真实关键帧、动态试制和渲染检验；优先解决最影响品质的问题，核心机制失败重新构思。

风格、案例与方法是启发，允许融合、自创或完全跳出列表。事实、许可、用户硬约束与真实证据仍须成立。研究按[研究与试制](stage-research.md)达到支撑当前试验的深度即可推进，未知触发补查；不设候选数量、样片时长、审美分数或搜索配额。

风格名称只作为检索入口。创作或实质性视听修订须按[具体视觉标杆与深入拆解](reference-video-analysis.md)实际查看作品，研究效果如何形成并转成本片设计，再用代表性画面和实际参考对照。整体品质、专项表现、信息表达参考各有用途，图表规范不能自动证明美术目标；暗底、强调色和大字不足以说明已理解一种风格。自主选择、融合和原创也适用；列表自由与已选视觉目标必须兑现同时成立。

## 一、视觉风格（14 种）

1. **Linear**：深色科技感、精密线条、克制动效。
2. **Apple**：高级极简、精致光影、突出主体。
3. **Stripe**：柔和渐变、几何图形、空间层次。
4. **Vercel**：黑白极简、精准排版、强烈对比。
5. **Swiss**：巨型字体、网格布局、平面构成。
6. **Bento Grid**：模块卡片、信息分区、结构清晰。
7. **Neo-Brutalism**：粗边框、硬阴影、大胆配色。
8. **Editorial**：杂志排版、摄影素材、图文叙事。
9. **Cinematic 3D**：三维空间、真实材质、电影镜头。
10. **Glassmorphism**：半透明玻璃、背景模糊、层次叠加。
11. **Material Design**：清晰层级、卡片组件、自然动效。
12. **Retro / Y2K**：复古科技、像素元素、怀旧未来感。
13. **Playful / Illustrative**：趣味插画、卡通角色、活泼配色。
14. **Neumorphism**：柔和阴影、凹凸质感、立体界面。

## 二、视频表达模式（6 种）

1. **Motion Typography（动态文字）**：通过文字的运动、变化和节奏传递信息。
2. **Kinetic Infographics（动态信息图）**：利用图表、数字和图形变化解释概念。
3. **Scrollytelling（连续推进叙事）**：通过连续的视觉推进，逐步揭示信息。
4. **Object Metaphor（实物隐喻）**：通过具体物体及其变化表达抽象概念。
5. **Cinematic Storytelling（电影化叙事）**：通过场景、人物、镜头和情绪讲述故事。
6. **Documentary Montage（纪录片蒙太奇）**：通过真实素材、档案影像和剪辑组织叙事。

## 三、动态风格（12 种）

动态风格启发元素如何运动，以及运动带给观众什么感觉。以下不是行业统一分类，而是一套供 AI 视频创作联想的参考，不代表新增动画引擎或实现能力。

| 动态风格 | 核心特点 | 适用场景 |
|---|---|---|
| 1. Minimal Motion 极简克制 | 轻微位移、淡入淡出、节奏舒缓 | 高级产品、科技介绍 |
| 2. Smooth Motion 丝滑流畅 | 平滑过渡、连续运动、自然缓动 | UI 演示、品牌宣传 |
| 3. Spring Motion 弹性动效 | 回弹、过冲、弹簧运动 | 趣味科普、活泼内容 |
| 4. Dynamic Motion 高能冲击 | 快速缩放、急停、强烈转场 | 短视频、情绪强化 |
| 5. Cinematic Motion 电影化运动 | 镜头推拉、运镜、速度变化 | 叙事、情绪表达 |
| 6. Mechanical Motion 机械精密 | 规律运动、精准同步、几何变换 | 工业、科技原理 |
| 7. Physics-Based Motion 物理模拟 | 重力、惯性、碰撞、真实运动 | 物理科普、实物隐喻 |
| 8. Fluid Motion 流体有机 | 流动、融合、形态变换 | 抽象概念、艺术表达 |
| 9. Spatial Motion 三维空间 | 旋转、视差、景深、空间穿梭 | 3D 产品、空间叙事 |
| 10. Glitch Motion 数字故障 | 抖动、错位、闪烁、信号干扰 | 赛博科技、实验视觉 |
| 11. Frame-by-Frame 逐帧动画 | 手绘变化、夸张形变、个性化运动 | 插画、故事动画 |
| 12. Rhythmic Motion 节奏驱动 | 音画同步、重复循环、节拍切换 | 音乐短片、动态排版 |

## 四、音效风格（12 种）

音效风格启发视频的听觉感受，以及声音如何强化画面动作、节奏和情绪。以下提供听觉灵感，不是固定声音模板；音效、配乐和旁白是不同的设计层面，本表不等同于背景音乐风格。

| 音效风格 | 核心特点 | 适用场景 |
|---|---|---|
| 1. Minimalist 极简音效 | 轻柔提示、少量声音、适当留白 | 高级产品、极简视频 |
| 2. Cinematic 电影化音效 | 低频冲击、渐强、宏大空间感 | 电影叙事、情绪高潮 |
| 3. Realistic Foley 真实拟音 | 脚步、碰撞、摩擦、真实物体声音 | 实物隐喻、真实场景 |
| 4. Digital UI 数字交互音效 | 点击、提示、扫描、电子反馈 | UI 演示、数据可视化 |
| 5. Mechanical 机械音效 | 齿轮、金属、精密运转、规律节拍 | 工业科技、机械原理 |
| 6. Organic 自然有机音效 | 水流、风声、生长、柔和自然变化 | 自然科普、抽象隐喻 |
| 7. Ambient 氛围音效 | 环境底噪、空间回响、持续声场 | 沉浸叙事、情绪营造 |
| 8. Rhythmic 节奏型音效 | 鼓点、重复敲击、音画同步 | 快节奏短视频、动态排版 |
| 9. Sci-Fi 科幻未来音效 | 合成器、能量脉冲、未来机械声 | AI、未来科技、太空 |
| 10. Cartoon 卡通夸张音效 | 弹跳、滑动、夸张碰撞、趣味反馈 | 趣味科普、轻松叙事 |
| 11. Glitch 数字故障音效 | 电流、失真、断续、数据干扰 | 赛博朋克、故障表现 |
| 12. ASMR / Tactile 细腻触感音效 | 微小摩擦、清脆碰触、细节放大 | 材质展示、精致产品 |

## 五、转场风格（12 种）

以下是一套用于 AI 视频创作的参考分类，不是行业统一标准。

| 转场风格 | 核心特点 | 适用场景 |
|---|---|---|
| 1. Hard Cut 直接切换 | 瞬间切换画面，干净利落 | 纪录片、快节奏叙事 |
| 2. Match Cut 匹配剪辑 | 利用形状、构图或动作相似性衔接 | 创意广告、视觉隐喻 |
| 3. Morph Transition 形态变换 | 物体连续变形为另一个物体 | 抽象概念、科技演进 |
| 4. Whip Pan 甩镜转场 | 快速横摇、运动模糊衔接场景 | 高能短视频、运动展示 |
| 5. Zoom Transition 缩放转场 | 快速推进、拉远或尺度变化 | 数据探索、空间穿梭 |
| 6. Mask / Wipe 遮挡转场 | 利用物体、边缘或形状遮盖切换 | 产品展示、创意叙事 |
| 7. Spatial Transition 空间转场 | 镜头穿越物体或空间进入新场景 | 3D 动画、电影化叙事 |
| 8. Graphic Transition 图形转场 | 线条、图形、排版重组形成新画面 | 信息图、品牌宣传 |
| 9. Dissolve / Fade 渐变转场 | 画面渐隐、渐显或交叠融合 | 情绪表达、时间流逝 |
| 10. Light Transition 光影转场 | 闪光、光扫、明暗变化衔接 | 科技广告、情绪高潮 |
| 11. Glitch Transition 故障转场 | 像素错位、信号干扰、画面撕裂 | 赛博科技、数字主题 |
| 12. Rhythmic / Audio Transition 节奏与声音转场 | 音效先导、节拍切换、音画同步 | 音乐短片、快节奏剪辑 |

## 六、使用原则

**14 种视觉风格启发外观，6 种表达模式启发叙事方式，12 种动态风格启发运动体验，12 种音效风格启发听觉表达，12 种转场风格启发场景衔接。**

以上内容仅供参考，并非完整分类或固定模板。

AI 应从视频主题和核心表达出发，自主探索最合适的视觉方案。

依据当前研究与实际试制，五个维度仍可自由选择、组合、融合或改造，也可以完全跳出这些参考，自主创作或借鉴其他风格，创造新的表现形式。不要求每个维度选定一种风格，也不要求同时使用音效、配乐和旁白。

参考只有静帧时，可从静帧的构图、材质、光影、尺度与层次推导表达模式、动态、声音与转场方向；推导须标为假设，写明置信度和验证指标，并用过程样片的帧序列与音频信号量测核对，不能写成已观察事实。

AI 可以根据画面动作、叙事节奏和情绪变化自由选择、融合或创造音效风格。声音可以强调动作、建立因果、制造节奏、烘托情绪，也可以通过静音形成对比；优先追求音画配合与表达效果，而不是声音的数量和复杂度。可以按目标选择无声，用户明确的声音要求仍须遵守。

转场风格启发场景之间的衔接方式；转场应服务因果、时间或情绪变化，可以自由组合、自创或不用，不要求每片套用转场特效。

**以表达效果为目标，而不是以遵循风格为目标。**

从灵感到具体设计，沿[场景设计](scene-design.md#从五维意图到场景决策)明确对象关系、关键状态、注意力和观察预期；按实际机制深化，不以风格标签或装饰数量替代设计。

这份文档的核心价值是：给 AI 更多可供联想的方向，但不替 AI 做创意决策。
