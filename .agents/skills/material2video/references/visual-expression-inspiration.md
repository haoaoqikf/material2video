# 视频视觉与表达参考

本文档为 AI 提供视觉设计与视频表达灵感，不构成强制设计规范。

视频创作或视觉表达修订前必须完整阅读本文档。同一任务已完整阅读后，无需逐场或逐阶段重复阅读。必读不等于必须采用：可以不使用下列风格与模式，也可以自主创作，或搜索、参考其他风格。

## 一、视觉风格（14 种）

1. **Linear**：深色科技感、精密线条、克制动效。
2. **Apple**：高级极简、精致光影、突出主体。
3. **Stripe**：柔和渐变、几何图形、空间层次。
4. **Vercel**：黑白极简、精准排版、强烈对比。
5. **Swiss**：巨型字体、网格布局、平面构成。
6. **Bento Grid**：模块卡片、信息分区、结构清晰。
7. **Neo-Brutalism**：粗边框、硬阴影、大胆配色。
8. **Editorial**：杂志排版、摄影素材、图文叙事。
9. **Cinematic 3D**：三维空间、真实材质、电影镜头。
10. **Glassmorphism**：半透明玻璃、背景模糊、层次叠加。
11. **Material Design**：清晰层级、卡片组件、自然动效。
12. **Retro / Y2K**：复古科技、像素元素、怀旧未来感。
13. **Playful / Illustrative**：趣味插画、卡通角色、活泼配色。
14. **Neumorphism**：柔和阴影、凹凸质感、立体界面。

## 二、视频表达模式（6 种）

1. **Motion Typography（动态文字）**：通过文字的运动、变化和节奏传递信息。
2. **Kinetic Infographics（动态信息图）**：利用图表、数字和图形变化解释概念。
3. **Scrollytelling（连续推进叙事）**：通过连续的视觉推进，逐步揭示信息。
4. **Object Metaphor（实物隐喻）**：通过具体物体及其变化表达抽象概念。
5. **Cinematic Storytelling（电影化叙事）**：通过场景、人物、镜头和情绪讲述故事。
6. **Documentary Montage（纪录片蒙太奇）**：通过真实素材、档案影像和剪辑组织叙事。

## 三、动态风格（12 种）

动态风格启发元素如何运动，以及运动带给观众什么感觉。以下不是行业统一分类，而是一套供 AI 视频创作联想的参考，不代表新增动画引擎或实现能力。

| 动态风格 | 核心特点 | 适用场景 |
|---|---|---|
| 1. Minimal Motion 极简克制 | 轻微位移、淡入淡出、节奏舒缓 | 高级产品、科技介绍 |
| 2. Smooth Motion 丝滑流畅 | 平滑过渡、连续运动、自然缓动 | UI 演示、品牌宣传 |
| 3. Spring Motion 弹性动效 | 回弹、过冲、弹簧运动 | 趣味科普、活泼内容 |
| 4. Dynamic Motion 高能冲击 | 快速缩放、急停、强烈转场 | 短视频、情绪强化 |
| 5. Cinematic Motion 电影化运动 | 镜头推拉、运镜、速度变化 | 叙事、情绪表达 |
| 6. Mechanical Motion 机械精密 | 规律运动、精准同步、几何变换 | 工业、科技原理 |
| 7. Physics-Based Motion 物理模拟 | 重力、惯性、碰撞、真实运动 | 物理科普、实物隐喻 |
| 8. Fluid Motion 流体有机 | 流动、融合、形态变换 | 抽象概念、艺术表达 |
| 9. Spatial Motion 三维空间 | 旋转、视差、景深、空间穿梭 | 3D 产品、空间叙事 |
| 10. Glitch Motion 数字故障 | 抖动、错位、闪烁、信号干扰 | 赛博科技、实验视觉 |
| 11. Frame-by-Frame 逐帧动画 | 手绘变化、夸张形变、个性化运动 | 插画、故事动画 |
| 12. Rhythmic Motion 节奏驱动 | 音画同步、重复循环、节拍切换 | 音乐短片、动态排版 |

## 四、使用原则

**14 种视觉风格启发外观，6 种表达模式启发叙事方式，12 种动态风格启发运动体验。**

以上内容仅供参考，并非完整分类或固定模板。

AI 应从视频主题和核心表达出发，自主探索最合适的视觉方案。

三个维度可以自由选择、组合、融合或改造，也可以完全跳出这些参考，自主创作或搜索、参考其他风格，创造新的表现形式。

**以表达效果为目标，而不是以遵循风格为目标。**

这份文档的核心价值是：给 AI 更多可供联想的方向，但不替 AI 做创意决策。
