# 制作示例与判断演练


仅在相应创作、填写或排错任务触发时读取；本页不新增门禁或审核轮次。

### 示例与反例

| 情形 | 事件设计或判断 |
|---|---|
| 完整揭示事件 | 行业：五个光点并排同速 → 跑道坡度分化 → 近景看起来差距不大 → 拉远公开整体高差 → 观众认识到同速不等于相近结果。镜头先隐藏整体差距，再公开全貌；行业高低只作有边界的情境示意，不冒充固定排名。 |
| 无反转直接因果 | 学习：主路受限 → 先前学习形成的连接亮起 → 光点换轨 → 到达可继续前进的路。预期与独立揭示不适用：直接观察因果，以换路前后对比获得认识，不刻意制造错误判断。 |
| 静态文字表达 | 同屏保留两份规则原文，观众依次比较可获得权利的差异。持续运动与独立反转不适用：依靠对照和观察窗口推进认识，不为填模板移动文档或伪造原文。 |
| 有运动但无认识推进 | 光点持续移动、节点不断增加，却未呈现设计声称的关系或结果；不能因为「有动画」就判事件成立。按完整窗口验证，先修因果、信息顺序或删去无用途重复。 |

## 15. 判断演练

| 情形 | 应得出的结论 |
|---|---|
| 漂亮卡片逐页替换，但没有信息、关系或体验推进 | 失败；按版式重复必改 |
| 文字对照、重组或图表关系产生新意义 | 通过；不因文字主导或信息图形式否决 |
| 单次连续旅程，没有重复母题 | 通过；记录替代组织方式 |
| 没有传统高潮，但强度曲线有理由 | 通过；记录替代记忆点，不强制添加高潮 |
| 竖屏没有使用左→右时间语法 | 记录转译方式，不判失败 |
| 声音承担关键线索，关声后信息不完整 | 记录原因，按完整声画验收；不因静音诊断自动判必改 |
| 数据图、档案、静止人物有真实信息变化 | 通过；形式本身不构成失败 |
| 设计文档写了母题，成片每幕仍是同构卡片 | 设计未兑现；按实际缺陷或证据不足处理 |

这些是规则推导，不是实际样片或观众验证；作品仍须提供真实版本与证据。

## 16. 紧凑示例：复利

以 `styles/examples/count-ledger/compound-interest` 的29秒复利作品说明写法：

- **核心表达**：收益再投入，使收益也产生收益。
- **核心视觉母题**：把资金设计成1枚=1,000元的圆片；金色是本轮刚赚到、尚未再投入的收益，米白是已进入下一轮、会继续生息的资本，暗金是已取走、离开增长系统的收益。
- **视觉风格**：黑底与克制的米白/金色；圆片只用平面圆、高光弧与暗投影，不用滤镜和装饰粒子；面积编码金额，规模靠圆片数量而不是放大字号。
- **分镜**：全屏主题卡“复利的力量”→等起点两柱→第一年收益→第二年收益回吸变资本、同时产生1.0+0.1金→取出/再投入分叉（只演第3年）→30年丘与40枚/约174.5枚、结果屏“30 年后的总资产”→S6 金顶归队、结论与片名。
- **核心镜头**：S3的0.1金片（机制）、S5的40枚整块/158.631米白+15.863金丘（规模与结果）与S6的丘顶特写（金片归队）；各有独立目标静帧与盲评。
- **结尾**：结果屏在24.8秒结束，硬切到丘顶2.0×特写；16枚金片逐枚沉入白堆并变白，26.2–26.9秒拉回全景，只剩175枚全白本金；26.9秒结论“让收益，也成为本金。”、27.1秒片名“复利”，29秒收尾。
- **声音**：8.0秒进入的无旋律环境床（前8秒数字静音）+同步事件音；无旁白、无旋律配乐。
- **禁止项**：不等起点、偷偷追加本金、用账户余额对比累计总额、把分数圆片并入整枚导致一枚>1,000元、用非同比例图形夸大差距或暗示保证收益。
- **直接采用**：用户给出详细圆片方案时按“用户详细方案直接采用”落实，不伪称做过三机制比较；按相应风险评估独立目标图或核心样片，G5 做内部粗片检查，G6 做最终独立评审。

示例只作写法示范，不替代作品自身方案；当前制作状态以作品 `DESIGN.md` 与 `VERIFICATION.md` 为准。

| 同一等待问题连续两轮无改善 | 停止同类微调，匿名独立比较原版与剪辑候选，仍失败回退上一级 |
| 技术检查通过但必要评审为空表 | 技术交付可完成，制作复核仍未完成 |


| 输入情形 | 必须得出的结论 |
|---|---|
| 记录的准备指纹或 MP4 摘要与当前产物不同 | 相关观察按依赖复查，当前最终文件仍完整检查 |
| 必改项已经改代码但还没复查 | 待复查，不能因为导出成功自动关闭 |
| 不进行连续播放，但高密度帧序列、风险加密帧、量测及自动音频检查齐全，候选和必改项已复核 | 可依据替代证据自主完成；披露帧间运动及主观听感不覆盖，不要求用户观看或试听 |
| 太阳系路径相接、交界速度接近，但镜头中间猛加速 | 必改；检查整段运动，边界通过不能关闭问题 |
| 太阳系已记录接近偏快，只有稀疏静帧证明 | 保持待复查，补风险全过程证据，不作为普通限制放行 |
| 独立行星路径安全，但在画面中像彼此紧挨 | 空间表达必改；检查构图与屏幕关系，运动量测不能关闭 |
| 高密度帧序列与尺度量测显示无信息等待过长 | 节奏必改；逐段缩减预算并复查，同时回归过快风险 |
| 十个段落都使用相同静态信息卡，只替换年份、标题和说明 | 幻灯片式版式重复为必改；重构画面和信息推进，不能以文字可读或 QA 通过放行 |
| 镜头构图相似，但主体动作或空间关系持续推进 | 不因单一构图相似判失败；记录实际信息推进证据，并检查全片是否仍由静态卡片主导 |
| 全片依靠相似主体回扣，外形不变但语境改变含义 | 检查关键各次出现与前后文的新作用；不要求单调递增、背景像素差或换构图 |
| 同一构图仅换标题说明，完整段落没有信息或体验推进 | 判版式重复必改；若文字关系本身产生表达，按实际作用判断 |
| 片尾出现 `SOURCES.md`、仓库路径或文档查阅提示 | 文案必改；移除内部指引，在唯一片尾署名中保留许可所需信息并复查全部可见文案 |
| 只生成视频并查看稀疏接触表，没有全片高密度帧和量测 | 接触表仅作导航；节奏证据不足，需补全替代检查 |
| 技术 QA 通过但已知等待问题没有高密度帧/量测复核 | QA范围不能关闭体验问题；补做对应替代检查 |
| 未试听音色，但已有声音元数据匹配和自动信号检查 | 符合本流程；如实记录技术证据，不声称主观听感通过 |
| 核心场景已通过，但某个普通场景只有“沿用风格”，没有独立设计与验收 | 该阶段未完成；补齐详细设计、试制及验收后才能完成 |
| 潜力报告声称有百万潜力，但没有成片时间码、逐场贡献或反面证据 | 报告未完成；结论降为证据不足，补真实检查后才能重判 |
| 任务要求工作流修订和太阳系重制，目前仅规范完成 | 整体未完成，继续按新流程重制和复核作品 |
| 手机尺寸下关键车辆动作仍不可辨，只是把标签放大 | 动作理解未解决，保持待复查；标签清楚不能关闭原条件 |
| 结尾偏长只以首尾呼应或设计停顿解释 | 必须比较原版与精简版时间线与帧序列、检查等待用途；否则不得关闭 |
| 静音符合分镜声明，于是判定节奏合适 | 设计停顿只解释来源；仍须说明观察、理解或情绪用途，不能关闭节奏问题 |
| 非核心差距实际比较后保留，却计入已解决 | 只能记接受保留并写剩余影响，不计入解决 |
| 已生成全片采样但只查看部分页面 | 记录实际页码与时间范围，补齐其余页面和风险量测后才算全片复核完成 |
| 最终候选形成后才补写 G5 检查 | 不得补造早期观察；用当前有效证据执行并标记实际检查时间，再完成当前候选终审 |

### 低机位细线、零厚度与保持段

- 黄道面内的平面细线在低机位下的屏幕厚度约等于 `世界宽度 × sin(仰角)`，容易退化成 1 像素断续线。可见性不要只由平面前缘承担：前缘需要随相机距离缩放的极薄垂直亮幕，画缘需要薄侧壁；最终仰角按“1080p 线宽下限约 8 像素”反推，并检查 699×393 下的可读性。
- 侧视合同至少复核三处：低机位经过主体时的前缘、俯视转向侧视的中间帧、最终侧视的两个端点是否仍在画面内。端点被裁切时，观众会把画缘误读为接缝。
- 相机关键帧的保持段必须显式让切线归零；只复制两帧相同位置仍可能被相邻段切线拖出漂移，复核时用同一段内的连续帧比对。

### 共面轨道、开场主体与关键道具

- 轨道线是否与天体同一平面、太阳是否在椭圆焦点、行星是否落在线上；同心圆、竖直圆环、逐行星不同倾角都应可判为缺陷。
- 开场“全貌”按 699×393 量外圈轨道与八颗行星的屏幕占比；系统只占画面宽度一半以下时不视为建立完成。同时复核 9/11 秒盘缘是否仍完整，避免为了开场拉近而把后段主体推出画框。
- 关键运动道具按完整入画窗口的连续帧与手机尺寸复核：入画、接近、消失三处都可辨；大范围光晕导致彗星／飞碟误读时记为缺陷或创意风险，不只看单帧亮斑。
- 镜头单向：逐帧检查距离、仰角、方位，确认没有无信息理由的推近再拉远；采样帧只能提示，不能单独证明运动连续性。

### 创意保护判断演练（非成片评审）

下表是规则情景推演，不代表实际看过样片或完成独立评审。两列都应能正确处理，不能只验证“不误伤”而遗漏真实失败。

| 表达 | 应保护的情形 | 仍须处理的情形 |
|---|---|---|
| 静止 | 揭示后保持画面供观察，前后文有明确消化作用，不因超过1.5秒失败 | 完整段落没有观察、期待或情绪用途，仍需删短或重设计 |
| 延迟揭示 | 局部先制造疑问，后续窗口清楚揭示并形成回报 | 完整窗口后仍形成核心误解，作者称“故意留白”也不能豁免 |
| 动态文字 | 文字对照、重组或节奏产生意义，去文字失败不直接否决 | 文字机械换页且无信息、关系或体验推进，仍属实际问题 |
| 声画协作 | 声音承担线索或反差，静音后不完整不直接失败 | 核心听觉线索缺失或时序错误须核实修复；方法不能验证感染力时记证据不足 |
| 母题 | 原画面因后续语境改变含义，不要求外形增长或背景像素差 | 重复没有新的作用，只靠作者宣称“统一”不能通过 |
| 核心视觉母题 | 只出现一次也能组织全片，不要求重复三次或持续变形 | 设计写了母题，但成片没有对应可见事件，按未兑现处理 |
| 无传统高潮 | 强度曲线、替代记忆点与原因成立时可保留 | 机械要求传统高潮，或全片强度单调且无理由，仍须处理 |
| 横屏/竖屏空间 | 竖屏按纵向推进转译，不要求左→右时间语法 | 竖屏硬套横向时间导致关系误读，仍属实际缺陷 |
| 画面文字预算 | 主句、辅助句与标签层级清楚时成立 | 文字互相竞争导致核心信息不可读，仍须修复 |
| 信息图 | 图表或平面关系有效解释内容，形式标签不构成否决 | 图形映射让观众形成错误因果，仍是核心缺陷 |
| 缩略图 | 200px下主体重心清楚、细字不可读，转到手机尺寸核对必要文字 | 声明手机尺寸下关键正文仍不可读，必须修复 |
| 减法 | 删去不损知识却破坏情绪收束，比较后可保留 | 既无理解又无体验作用的重复，不能用“氛围”直接保留 |
