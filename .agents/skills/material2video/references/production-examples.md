# 制作示例与判断演练

本页只给判断校准，不设置新的门禁或固定镜头模板。作品是否完成，仍以当前成片、制作合同和独立审核证据为准。

### 示例与反例

| 情形 | 判断 |
|---|---|
| 光点同速前进，拉远后公开不同坡度与整体高差 | 揭示补全了局部观察；行业高低只作有边界的情境示意。 |
| 学习连接亮起，光点从受限主路换轨 | 直接因果成立，无需硬造错误预期或反转。 |
| 两份规则原文并列，观众比较权利差异 | 静态对照有效，无需为填模板移动文档。 |
| 节点和粒子持续增加，关系却没有变化 | 运动不等于认识推进，应修因果或删重复。 |

## 13. 判断演练

- 相似构图仍可成立，条件是主体动作、关系或语境确实变化；只换标题和卡片颜色则不成立。
- 文字、图表、静止人物和声音都可以承担关键表达；按实际新增认识判断，不按形式否决。
- 首尾呼应、停顿、延迟揭示和无传统高潮均需说明用途；无用途等待或长期缺少信息推进须修订。
- 技术 QA、稀疏接触表或作者说明不能证明理解、节奏、听感与独立审核通过。已修改但未复查的问题保持待复查。

## 14. 紧凑示例：复利

[《复利》](../../../../styles/count-ledger/examples/compound-interest/README.md)用可数圆片区分本金、新收益和取出收益；同起点比较两种做法，结尾让金片归队，画面动作直接解释“收益也成为本金”。具体金额、时序和证据只读该作品的 `DESIGN.md` 与 `VERIFICATION.md`，不在通用指南复制。

## 15. 视觉复核判断演练

| 观察 | 处理 |
|---|---|
| 主体在手机尺寸不可辨，或新运动没有带来认识 | 回到构图、动作与表达机制，不能只放大标签或再加粒子。 |
| 关键过渡在中间帧丢失对象，即使首尾正确 | 检查完整窗口的出发、移动、落定与认回。 |
| 细线、相机或空间关系只在目标静帧成立 | 用连续帧和量测检查最不利角度；不靠静帧或放宽阈值关闭。 |
| 停顿有明确观察或情绪作用 | 保留并记录用途，不按统一秒数删去。 |
| 同一问题连续两轮无改善 | 按[回退决策](production-workflow.md#核心样片与全片粗片的回退决策)比较机制或剪辑。 |
| 当前候选与审核所用摘要不一致 | 旧观察按依赖复查；最终文件仍须完整检查。 |

### 创意保护判断演练（非成片评审）

允许安静停留、延迟揭示、文字主导、抽象母题与声画分工；需要在完整窗口里看见它们的作用。若观众必须靠作者解释才能理解核心关系，或作者用“审美选择”掩盖可证实误读，仍须修订。该判断不替代真实样片和独立审核。
