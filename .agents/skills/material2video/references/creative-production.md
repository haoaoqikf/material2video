# 循环创作、美术、声音与制作阶段

所有 general 使用统一制作标准。金融与住宅采用相同的目标、比较和迭代原则，以趋势、转折与图表表达为对象，保持专用画幅及声音契约，不强加讲解镜头结构。创作阶段由助手自主完成，不新增用户确认或 CLI 人工门禁。

## 循环创作与回退

1. **创作目标**：在 DESIGN.md 明确受众、设备、原有认识、预期新认识、观看理由、核心感受及可观察验收条目。先明确观众会经历什么，再展开完整旁白；源文语义审查照常执行。同时记录目标平台与受众、题材需求、开场吸引、理解成本、持续观看、核心发现、视觉记忆点和分享讨论动机的初始假设，按[百万播放潜力](reach-potential.md)区分假设与证据。
2. **方案循环**：每轮默认3个叙事结构不同的候选，逐项写出具体开场、悬念、可见核心事件、递进与结尾回报。禁止以“震撼运镜”等形容词代替对象、动作和结果。只有主题没有事件、答案耗尽后反复解释、画面可随意替换或结尾仅复述时，退回重构。允许整批全部淘汰并继续提出新方案；下一轮针对失败原因改变角度、事件或表现，不只改标题、颜色或措辞。
3. **逐场设计**：结构选定后，为每个场景及内部镜头按[逐场设计与独立验收](scene-design-and-acceptance.md)写出叙事任务、核心可见事件、美术方向、技术方案、动态时间、文案声音、可观察验收条件和传播贡献。共享规则可以引用，但每场必须落实本场的主体尺度、构图、色彩光影材质、文字层级、关键状态与观察窗口；多镜头单场要列出镜头窗口、交界和承接。普通场景与核心场景同等检查，不能只写“沿用风格”。
4. **核心试制循环**：先用简单模型、必要标记和临时声音验证最值得看的完整事件。候选难分时以同等精度分别试制。检查解释文字撤去后是否仍可辨现象、手机尺寸注意力、变化前后及因果、开场承诺兑现；不把撤字检验机械用作所有题材的失败判定。表现弱则改构图/尺度/运动，核心创意不成立则退回选案，停止全片精制。
5. **整片预演循环**：核心试制成立后用简化资产与实测/临时配音串起所有章节，逐段标明观众问题、新发现及继续看的理由，标注信息/运动/视觉/声音强弱与观察窗口。删减重复解释，检查高潮位置、承接与结尾回报。局部精彩但全片不成立时重组结构，必要时退回试制或选案。
6. **美术与声音定稿**：对同一内容实际制作两个视觉方向比较，使用正式文案与素材形成开场、核心、普通信息镜头、结尾四张基准，检查原尺寸、手机与缩略图。设计声音时间表，先记录需要声音的事件和留白，再选择配乐、音效或静默。无声作品保持无声。
7. **精制与复核循环**：优先强化开场、核心事件与结尾，按风险做最终参数样片。技术问题返精制，表现问题返试制，结构问题返预演，观看理由不成立返选案。每轮集中解决最重要的少数问题，连续两轮同问题无明显改善必须换方法或方案。每场及内部镜头按[逐场设计与独立验收](scene-design-and-acceptance.md)独立验收：先不看设计结论，仅凭作品复述问题、事件与新增认识，再对照设计分别记录叙事、审美、动态、文案声音、技术、衔接与传播结论。
8. **交付与复盘**：全片帧序列、量测和自动声音信号复核，分别记录创作与技术结论；技术通过不能替代体验成立。实际获得发布数据时再核对创作假设，不虚构流失率或爆款评分，不承诺播放量。最终按[百万播放潜力](reach-potential.md)输出绑定成片的定性预估与发布后验证方法。

不设总轮数上限，也不强制执行无意义轮次。不得因已有代码或素材投入而放行不成立方案；遇到事实、素材或实现限制应明确报告，不能降低标准后宣称完成。外部观众反馈有条件时用于复述检验，不作为新增用户接手或审批要求。

每轮复用 DESIGN.md 与 outputs/visual-notes.md，记录：轮次及阶段、候选/版本、问题与证据、淘汰原因、保留内容、下一轮改变、回退位置与复查结果。演练必须标为演练，不能虚构为真实制作失败。完整粗预演后与最终候选形成后，还要按[全片导演审查与剪辑重组](director-review-and-edit.md)做两次角色分离的全片审查；局部通过不能覆盖全片否决，结构问题先做低成本剪辑比较。

## 从内容到完整粗预演

短视频从 Brief 阶段就把“希望目标观众在前两秒看到什么、理解什么、为什么愿意继续看”纳入创作考虑；选择最能代表主题的清楚主体/信息作为开场起点，避免无主题的片头、装饰性空镜和长铺垫。这里的“2秒跳出率”是降低开场流失的设计因素，不是无数据时可以推算的真实指标；没有发布数据时不填写数字、不设代理评分或机器门禁。若后来实际取得平台数据，可作为后续版本复盘依据。

受众语言也影响镜头和时长预算：中文观众优先接收中文名称与贡献说明，必要英文缩写只在首次作为辅助标识；专有名词准确不代表普通观众可以立即理解。若一段无法在当前时长中读懂，先删除重复说明、调整信息层级或重组镜头，再考虑速度和总时长。

先在 DESIGN.md 写出核心体验的验收条目：用户要求、可观察目标、失败现象、检查范围、证据方法与当前结果。例如「一镜到底」要看清离场—穿行—转向—抵达—观察，单幕、无硬切与端点相接只是实现条件。条目贯穿粗预演、风险样片与最终复核，不能只用技术 QA 证明完成。

1. 在 DESIGN.md 确定受众与设备、核心感受、视觉主体、情绪变化、审美禁区和可观察验收目标。多对象场景明确邻近/分离关系；入门导览每个对象默认只讲身份与一个具体印象，主张必须有资料及画面支撑。
2. 用同一内容片段比较两个美术方向，记录参考来源、采用理由及构图、主体大小、留白、光影、材质、色彩、字体和运动上的具体决策。制作开场、核心、普通信息镜头、结尾四张基准，使用实际素材、正式文案和字幕（无旁白时检查画面内文字）。在原始尺寸、声明的手机观看尺寸和缩略图尺寸检查并记录实际尺寸与差距。
3. 建立观众可见文案清单，覆盖片头、逐幕文字、固定叠字、字幕和片尾。排除仓库文件名/路径、制作文档名和内部查阅指引；全片只设计一处片尾简短署名与版权说明。详细来源、作者、许可与改编记录只存作品材料；精简署名仍须逐项满足素材许可义务。
4. 逐镜记录观众问题、画面主体、可见变化、信息落点、观察窗口与承接方式；另列入场、介绍、观察、离场预算和声音意图。旁白长度不能独占视觉时间。每个主体有独立可辨认窗口，讲话结束仍可观察。逐段说明过场承担的信息或体验作用，检查过快掠过与过慢等待。
5. 用简化场景和粗运镜串起覆盖所有章节的动态粗预演，并生成带时间码的全片高密度帧序列；在时间线上标注信息、运动、视觉及声音强度（无声作品声音项记为不适用）及变化目的。按镜头、转场和速度峰值加密采样，用主体屏幕占比、相邻帧位移、相机速度/加速度和停留时长复核节奏。时间不足时先删重复信息或重组镜头，再调速度。并排检查全片镜头结构；重复静态信息卡片主导全片是必改项。记录输入摘要、文件摘要、帧间隔和问题；单张静帧不能代替全片覆盖。
6. 风险优先制作跨尺度、复杂转场、多主体、文字竞争和声音交接样片，未覆盖风险补查。位置相接不等于连续，分别检查视线、速度、FOV、运动方向、到达减速与重新定位时间。风险必改项关闭后再扩展全片。

内容、运动与旁白共同决定预算，粗预演和实测配音应能反向改变方案。无硬时长约束时保留必要视觉时间；有明确上限时先删减信息、减少对象或重构镜头，不靠急冲、急转和缩短观察塞满时间线。跨对象与跨尺度移动按路径、转向和辨识需求分配时间，不把所有过场统一若干秒作为充分依据。整片重复推近—拉远和没有新信息的长等待也要在粗预演中修订；不能因上一轮反馈偏快，就把全片过场统一放慢。

预算演练：无硬时长、远距离移动赶时，调整路径或延长预算后复查；固定时长容不下内容时，重构内容与镜头，不机械加速。若预算变化触及已有作品规格，先同步增量规格与相关校验、示例、文档。

## 用当前 v8 表达视觉时间

每个对象可独立一幕：`leadInFrames` 留定位时间，实际 TTS 决定讲话窗，`tailFrames` 与 `readingHoldFrames` 保留观察。无需讲话的镜头使用空 `narrationSegments` 和显式 `durationFrames`。不设固定时长时，配音变长使整幕自然增长；声明固定时长不足以容纳讲话、留白、阅读和转场时 prepare 拒绝，不截断或加速。

`targetSeconds` 不是给所有有旁白幕自动补齐的最短长度。只有无旁白且未显式声明时长的幕才分配目标剩余时间。`shots` 仍是幕内帧号，不会自动跟随 TTS 改写；必须实测后重排镜头。不要让标签或焦点靠旧全片帧号切换。以上字段当前均参与渲染；粗预演、风险清单和阶段结论是助手记录，不新增运行时字段。

## 声音设计和排查

分镜阶段记录时间窗、情绪、音乐角色、讲话/观察中的层级变化、淡入淡出和关键音效。配音介绍、音乐承接情绪、环境提供空间感、音效强调少数重要事件；避免每次转场重复 whoosh。宇宙环境声注明艺术设计。音乐/音效必须留来源与许可。

收到音乐不明显反馈，先查最终文件是否混入、素材覆盖/循环、增益、淡化和旁白压低/恢复，对照独立音乐和旁白轨，再查低频及单声道/小扬声器损失，不直接拉高总音量。音乐可在开头先建立气氛、讲话时平缓降低、观察时恢复。不要把固定分贝差当成听感保证。代表样片包含真实配音与音乐，实测配音后同步回填声音时间表。总混音响度合格不能证明音乐存在或可感知。

所有 general 有声作品保持 −14 LUFS / −1 dBTP 目标。按服务风格元数据与完整旁白文本选择音色，并以时长、响度、频谱、静音/削波候选及旁白时间窗做自动复核；不要求收听音色。分别记录技术检查及其边界，不把信号指标描述为主观听感结论。

## 分层精修

正式全片精制后按以下顺序检查，每遍记录最重要的修改及证据；没有问题时写明依据。优先处理每遍最影响观感的少数问题，不为满足记录形式重复渲染。

1. **视觉重心**：主体大小、位置、明暗和留白是否让第一眼落在正确对象上。
2. **信息层级**：标题、年份、说明、标注是否各有层级，是否存在重复信息。
3. **色彩与材质**：素材与图形是否属于同一视觉体系，档案固有层次是否保留。
4. **运动**：启动、移动、减速、停留与承接是否帮助理解，是否存在无目的推拉。
5. **细节**：对齐、边缘、线宽、阴影及效果强度是否克制且一致。

问题记录包含位置、观察、对理解或观感的影响、修改和复查依据；区分可见缺陷、表现差距及未验证范围。修改前后使用相同时间码和显示尺寸比较，绑定当前准备指纹与文件摘要。替代证据不能覆盖的主观感受如实披露，技术通过不等于审美通过。

## 阶段产出与完成条件

每个场景及其内部镜头还要有独立的详细设计与验收：设计表覆盖叙事、美术、技术、动态、文案声音、
传播贡献与可观察条件，验收表保留观察复述、七类结论、必改项、版本证据与回退位置。模板与操作
入口见[逐场设计与独立验收](scene-design-and-acceptance.md)。全过程按[百万播放潜力](reach-potential.md)
记录假设、实现差距与实际证据，最终输出 `outputs/reach-potential-report.md`。

| 阶段 | 产出与放行条件 |
|---|---|
| 内容设计 | 创作目标、文案可见项清单、单一片尾署名、同内容两方向比较、四张视觉基准、逐镜叙事、时间预算和风险清单；无内部文档引用，内容必改项关闭 |
| 整片粗预演 | 完整动态粗时间线、全片高密度时间标注帧序列、逐帧路径/屏幕投影量测及问题记录；复核重复版式与信息推进，幻灯片式必改项和整体节奏必改项关闭 |
| 关键画面/风险样片 | 四张代表画面、高密度风险帧序列及自动声音信号报告；主体关系、运动和声音时序必改项关闭 |
| 全片精制 | 正式资产/配音回填；全片帧序列与自动声音信号复核及修订完成 |
| 交付 | 当前完整候选、技术检测、最终全片帧序列/自动音频复核及回归完成；必改项关闭，限制披露 |

在 `outputs/visual-notes.md` 记录待检查/返工/通过、准备指纹（准备前用输入摘要）、对象摘要、问题及证据。重新渲染不自动通过；助手自主放行，CLI 仍按既有自动门禁运行。

与用户核心体验冲突的已知急冲、急转或主体一闪而过是必改项，不得改列为可选或覆盖限制后放行。未覆盖的检查范围与已观察到的缺陷分别记录；问题修改后仍需有效版本复查，证据不足保持待复查。任务同时包含工作流改进和作品重制时，两者都完成才可交付整体任务，不在仅完成规范时提前归档。

全片精制后独立审美修订：删重复运镜、调效果强度与镜头长短、安排高潮/安静段落、统一色彩文字。文案、节奏、连续性、审美、声音、技术分别记录当前结论。连续两轮同一问题无改善，更换构图、素材或实现方法。

## 改动影响与反馈回归

| 改动 | 最低复查范围 |
|---|---|
| 文案/配音 | 内容主张、预算、主体同步、字幕、音乐交接 |
| 运镜/时长 | 连续性、观察窗口、文字及声音定位 |
| 全局视觉 | 全片一致性、主体辨识、全片帧序列与自动音频 |
| 音乐/混音 | 全片覆盖、层级、首尾与分段衔接、最终音轨 |

组合取并集，未知影响扩大检查。这是创作复查下限，不豁免既有指纹、重新 prepare、候选及最终文件摘要变化后的复查。仅复用未受影响且依赖有效的结果。

用户反馈记录稳定 ID、位置/出现条件、原因（未知写待定位）、改法、复查方法与当前证据。把可复用规则留在共享指导，作品明细与生成物留在忽略的作品输出。导览固定回归：主体是否一闪而过、介绍是否赶、文案是否有带路趣味、音乐是否接住留白。

```markdown
## 阶段与回归
- 阶段：<名称>；状态：<待检查/返工/通过>
- 版本与对象摘要：<实际值>
- 产出与风险：<直接文件链接及范围>
- 核心体验条目：<目标、失败现象、范围、证据方法、当前结果>
- 观众可见文案清单：<片头、逐幕、固定叠字、字幕、片尾；确认无内部文件名/路径/指引，片尾署名仅一处>
- 版式重复与信息推进：<涉及段落、结构/动作/主体变化，重复卡片是否主导，问题与复查证据>
- 文案 / 节奏 / 连续性 / 审美 / 声音信号 / 技术：<分别记录帧序列、量测、自动检测证据与覆盖限制>
- 反馈：<ID、条件、原因状态、改法、复查方法、当前结果>
- 改动影响：<本轮改动、失效结论、复查范围与依据>
```

无声作品按用户声音意图执行：无旁白、音乐、音效及素材原声；样片同样无声。电影级视觉阶段保持不变，静音验收替代响度目标。参见[无声作品](cinematic-video.md#无声作品)。
