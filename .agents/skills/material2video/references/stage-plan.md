# 方案确定

首要问题：让谁理解或感受什么，实际用什么表达？

## 设计记录

作品 `DESIGN.md` 只维护以下最简结构，普通场景一行或一段足够：

| 内容 | 记录什么 |
|---|---|
| 全片目标与表达方向 | 主题、受众、用户约束、视觉与声音方向、事实和真实／示意边界 |
| 逐场对象与变化 | 场景用途、主要对象或信息、实际变化与必要阅读／观察窗口；素材来源与验收目标引用现有材料 |
| 必要风险附件 | 仅为复杂未决风险补充说明，引用唯一制作合同、分镜或代码事件，不复制时间表 |

不要求母题、高潮、六类元素、独立运动表、逐镜问答或不采用某种手法的解释。设计前必读[视频视觉与表达参考](visual-expression-inspiration.md)，本任务已完整阅读则不重复；完成下述研究后，风格仍可自选、融合或自创。[讲解手法](explainer-design.md)按需选用。

## 设计前搜索研究

新制作或实质性视听重设计形成方案前，必须完成针对当前问题的外部搜索、实际查看与分析；展示方案的 HTML 草稿和低成本视觉原型同样适用。无论是否采用灵感文档中的风格，都不能跳过研究。先明确主题、受众、硬约束和待解决问题，再研究并形成方案；题面整理不等于提前设计。

- **研究范围**：按当前需要选择构图、色彩、材质、信息编码、讲解、运动或声音等维度；不要求每片覆盖所有维度。已有代码、风格名称或凭印象描述不能替代外部研究。
- **实际查看**：访问来源并查看对应材料；搜索摘要、链接列表不算完成。静帧只支持外观与构图，运动须查看过程，声音结论须有对应声音依据；未观察部分如实说明。边界见[参考分析](reference-video-analysis.md#证据边界)。
- **简短留证**：在现有 `DESIGN.md` 简记来源地址、访问日期、实际查看范围、具体观察和对本次设计的启发。不要求采用参考或解释每种未采用风格，不另建研究报告。
- **复用与补查**：同一任务已有真实可追溯且覆盖当前问题的研究可说明覆盖依据后复用；方向变化、新对象或用户反馈暴露未覆盖问题时，先补查再重设计。仅修错字、裁切或已验证方案的实现偏差，不重做整套风格研究。
- **停止与失败**：已有足够依据支持当前判断即可停止，不设搜索次数或案例数量。来源不可访问时换检索词或来源；仍无法实际查看且无有效既有研究时，记录前置未满足，停止依赖它的新设计，可继续无关整理，不自行豁免或伪造完成。

这是制作助手的操作前置要求，不新增阶段、审核轮、CLI 门禁或材料字段。研究完成不等于设计成立、素材入片授权或制作评审通过。

## 必做

1. 确认受众、画幅、主题、用户约束、事实边界与来源。用户方案足够时直接作为初始基线；按实际目标调整未成立的表达，不重开无关选案。
2. 按[设计前搜索研究](#设计前搜索研究)取得并记录当前问题的参考依据，再形成方案。
3. 在同一设计记录中形成足以执行的全片方向与逐场内容。研究完成、核心对象和试验问题明确后可做局部草样；说明试验范围、素材精度和结论边界，不用原型结论代替全片验证。
4. 在 `DESIGN.md` 声明 v2 制作合同及适用风险，映射场景／镜头与检查窗。时点、人数、轮次和完成条件只读[审核策略](checkpoint-gates.md#审核计划与风险触发)。
5. 选择未决核心问题的最小完整试制窗口，按风险选择静态目标、时序试验或实际动态原型，执行见[完整段落试制](production-workflow.md#完整段落试制与逐段扩展)。

复杂对象联动、时间换算与缓动边界见[运动实现约定](code-scene-runtime.md#运动实现约定)。执行帧、曲线与参数引用分镜或代码事件，设计记录不重复维护。

## 触发时展开

- 首次写分镜：读[分镜契约](storyboard-schema.md)。
- 搜集或入片素材／声音：读[素材声音契约](article-media-and-sound.md)和[载体选择](visual-material-selection.md)。
- 开展设计前研究或借鉴参考：读[参考分析与借鉴](reference-video-analysis.md)。
- 首次实现场景／相机／字体：读[运行时契约](code-scene-runtime.md)。
- 首次实现运动、转场或缓动：读[运动实现约定](code-scene-runtime.md#运动实现约定)，曲线按表达目标选择，不要求统一入场／离场方向或例外说明。
- 开始有旁白制作：读[配音契约](voice-and-rhythm.md#配音音色与语速)，按全文和服务信息选音；无旁白跳过。

## 源文审查

先在作品内保存非空 `article.md`；采用稿存在时使用 `article.accepted.md`，也可由 `project.materials.article` 显式指定。

```powershell
uv run m2v author input-review --storyboard videos/<类型>/<slug>/storyboard.json
```

命令生成 `outputs/input-review.json`，记录源文相对路径、SHA-256 和正文计数。阅读原文后填写 `status`、`claim`、`rationale`、`reviewer`、`problemSpans`；通过时 `status` 为 pass、依据非空且 `problemSpans` 为空。工具不会自动判定语义通过。源文或候选变化须重新生成；采用不等于审查通过。`input.kind` 为 `topic` 时跳过本审查。

## 完成与回退

事实边界和核心关系可观察，正式扩展前适用 G0–G3 证据须齐全；完成设计前研究后可提前制作低成本原型，G3 可复用当前有效 G4 过程证据，随后补齐适用独立时序观察。方案的目标或技术根本不成立时回到对应设计层；不以“以后精修”放行。记录与闭环见[制作流程](production-workflow.md#核心样片与全片粗片的回退决策)。
