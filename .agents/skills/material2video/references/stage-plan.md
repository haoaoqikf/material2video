# 方案确定

首要问题：观众要理解什么，靠哪个对象、变化和机制理解？

## 必做

1. 确认受众、画幅、主题、事实边界与来源；用户方案足够时直接采用，否则按未决问题选案。
2. 讲解片在现有逐场表记录主体、变化与不变量、目标关系、完整窗口和可能误读。优先考虑对象连续追踪、相机与尺度、过程与结果联动、回场；按需采用，不凑齐四种。方法见[讲解机制](explainer-design.md#四种讲解机制的执行方法)。
3. 先确定可见事件和观众的信息顺序，再选素材与实现方式。关键镜头按[导演设计](visual-creative-direction.md#导演设计观众按什么顺序看到)组织；普通镜头不额外填完整导演卡。
4. 在 DESIGN.md 声明现有 v2 制作合同及适用风险，映射场景/镜头与检查窗。轮次、人数及完成条件只读[审核策略](checkpoint-gates.md#审核计划与风险触发)。
5. 先做风险最高的目标关键帧或时序试验，不先堆装饰。静态目标通过不替代实际核心片段。

## 触发时展开

- 首次写分镜：读[分镜契约](storyboard-schema.md)与[逐场表](scene-design-and-acceptance.md#逐场设计表)。
- 搜集或入片素材/声音：读[素材声音契约](article-media-and-sound.md)和[载体选择](visual-material-selection.md)。
- 学习参考：读[参考拆解](reference-video-analysis.md)；明确要求像参考时再读[风格契约](reference-style.md)。
- 首次实现场景/相机/字体：读[运行时契约](code-scene-runtime.md)；选择风格时读该包 GUIDE。
- 开始有旁白制作：读[配音契约](voice-and-rhythm.md)，按全文和服务信息选音；无旁白跳过。

## 完成与回退

事实边界和核心关系可观察，适用 G0–G3 证据齐全后进入粗片。方案的目标或技术根本不成立时回到对应设计层；不以“以后精修”放行。记录与闭环见[制作流程](production-workflow.md#核心样片与全片粗片的回退决策)。
