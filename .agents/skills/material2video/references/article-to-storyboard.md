# 通用作品创作

本页配合[节奏、美术、声音与制作阶段](creative-production.md)执行：先整片粗预演、风险优先，再按阶段完成条件精制与复查；不增加用户确认或 CLI 人工门禁。

制作顺序：**确定画幅与视觉设计 → 自主搜索参考 → 完成源文审查与简短导览文案 → 比较两个美术方向 → 逐镜头时间预算与音乐段落表 → 制作开场/核心/结尾关键画面与整片动态粗预演 → 风险样片 → 编排运动 → 助手选择音色并保存 → 时间轴准备 → 按需生成和检查代表片段 → 全片生成一次并自动验收 → 全片帧序列与自动音频复核 → 自主交付**。
实际检查方法、问题闭环及完成条件见[自主视觉复核](visual-review-rubric.md)，所有制作阶段无需用户确认。
选音依据、用户指定优先级及记录见 [制作 Skill](../SKILL.md)。

源文必须非空，没有标准字数限制；改稿用 `m2v general candidate` 提出候选，候选稿须用户明确采用并重新审查后才能制作（`adopt-candidate`）。只想按一个主题成片时改用 `input: {"kind":"topic","topic":"<主题>"}`，跳过源文与源文语义审查，但每幕必须声明 `keywords`。

## 先确定画幅

用户没有指定时默认发布抖音，采用**横屏 1920×1080、60 fps**，并在作品 `DESIGN.md` 里写清依据：横屏适合并排铺开
对照与图表演示，竖屏适合纵向推进、单主体演示。画幅一旦定下就贯穿准备、录制、字幕、预演与导出；
中途改画幅等于重新设计，旧准备与预演全部失效。

## 再写视觉设计

在作品 `DESIGN.md` 记录：参考依据、视觉隐喻、字体配色、开场/核心/结尾三处代表构图、
镜头承接方式与声音意图。它是**创作依据**，不参与运行时，也不是 CLI 必填项；直接改它不会让
画面变化，要落实成 `scenes/` 下的代码后重新准备才会。三处代表构图要具体到「谁在画布哪个位置、
读者先看什么」，只写形容词的设计稿不算依据。

## 制作关键画面

先做开场、核心演示、结尾三张关键画面，确认它们在目标设备上读得懂，再扩展全片。每一幕都是
一个本地 React 组件：`content.entry` 指向作品 `scenes/` 下的 TSX，`content.props` 传这一幕需要
的参数。屏幕只保留一句话能读懂的结论，不复制整段口播。

- 关键画面优先，装饰其次：先确定读者看什么，再决定用什么动效把它送进场。
- 重要文字与主体避让 `subtitleSafeArea`；字幕会盖在那个矩形里，不是浮在画面上方。
- 作品必须自己画满整张画布的不透明背景；录制页不提供任何主题配色。
- 数值、路径与结论图的示意内容要在画面或旁白里标注「示意」，不写成实验数据。

## 编排运动

- 动画由 `useSceneContext()` 的 `elapsedSeconds`/`progress` 或 `segmentWindows` 驱动：
  口播到哪一句，画面走到哪一步，没有一句旁白在讲还没出现的画面。
- 需要素材时用 `useMediaAsset(id)` 按素材 ID 取用；比例不受画幅限制，裁切与摆位由作品决定。
  视频要等到可播放后再调用 `ready()`，素材原声不会进入母版。
- 复杂动画、3D 与动态图表用 `motion`、`gsap`、`echarts`、`three`/`@react-three/fiber`/`drei`；
  运动只出现在承载信息的地方。

## 帧序列与自动信号复核

完成后生成全片时间标注帧序列，并对镜头交界、主体关系变化、速度峰值和文字风险处加密；结合逐帧运动/屏幕投影量测与自动音频信号报告，记录问题位置、修改和复查结果至作品 `outputs/visual-notes.md`。不要求播放视频或试听音色。帧间瞬时运动和主观音色感受不在替代证据覆盖范围内，记录时明确披露。该记录不是导出门禁。

## 旁白与时长

每段旁白给稳定 ID，逐幕收集。全片实际时长不超过 600 秒，包括每幕 24 帧阅读停留和淡化帧数；
超限修改文本或正常语速，不能截断语音。试错目标120～180秒，太阳系按动态粗预演核定120～600秒；无声美国科学里程碑固定120秒。

## 固定示例

固定示例集合为 american-science-milestones、darts-trial-and-error、solar-system-journey，最多3个；用户明确授权才可替换。每个示例提供 project.json、v8 storyboard.json、README.md、DESIGN.md 与 scenes；article 输入另须原文，topic 输入提供事实与素材来源。

- 美国科学里程碑与太阳系使用1920×1080，试错使用1080×1920。
- 合计覆盖 Motion、ECharts、GSAP、Three.js、React Three Fiber 与 Drei。
- 试错、太阳系按实际 segmentWindows 推进；美国科学里程碑采用空旁白、固定帧数及画面中文说明，不生成TTS。
- 美国科学里程碑和太阳系采用cinematic，试错保持standard。档案不冒充4K，原理动画明确标注示意。
- README提供逐幕内容对应，DESIGN记录画幅、配色、构图与声音意图；生成媒体不入库。

详细字段见 [分镜结构](storyboard-schema.md)，操作见 [制作流程](production-workflow.md)。
通用类型只接受 v8 全画布代码场景，旧版本不自动迁移。
