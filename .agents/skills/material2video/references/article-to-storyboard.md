# 通用作品创作

制作顺序：**确定画幅与视觉设计 → 制作关键画面 → 编排运动 → 写旁白 → 按需导入素材 →
助手选择音色并保存 → 准备与录制 → 实际观看代表片段 → 完整预演自动验收 → 渲染**。
选音依据、用户指定优先级及记录见 [制作 Skill](../SKILL.md)。

源文必须非空，没有标准字数限制；改稿用 `m2v general candidate` 提出候选，候选稿须用户明确采用并重新审查后才能制作（`adopt-candidate`）。只想按一个主题成片时改用 `input: {"kind":"topic","topic":"<主题>"}`，跳过源文与源文语义审查，但每幕必须声明 `keywords`。

## 先确定画幅

用户没有指定时采用**横屏 1920×1080**，并在作品 `DESIGN.md` 里写清依据：横屏适合并排铺开
对照与图表演示，竖屏适合纵向推进、单主体演示。画幅一旦定下就贯穿准备、录制、字幕、预演与导出；
中途改画幅等于重新设计，旧准备与预演全部失效。

## 再写视觉设计

在作品 `DESIGN.md` 记录：参考依据、视觉隐喻、字体配色、开场/核心/结尾三处代表构图、
镜头承接方式与声音意图。它是**创作依据**，不参与运行时，也不是 CLI 必填项；直接改它不会让
画面变化，要落实成 `scenes/` 下的代码后重新准备才会。三处代表构图要具体到「谁在画布哪个位置、
读者先看什么」，只写形容词的设计稿不算依据。

## 制作关键画面

先做开场、核心演示、结尾三张关键画面，确认它们在目标设备上读得懂，再扩展全片。每一幕都是
一个本地 React 组件：`content.entry` 指向作品 `scenes/` 下的 TSX，`content.props` 传这一幕需要
的参数。屏幕只保留一句话能读懂的结论，不复制整段口播。

- 关键画面优先，装饰其次：先确定读者看什么，再决定用什么动效把它送进场。
- 重要文字与主体避让 `subtitleSafeArea`；字幕会盖在那个矩形里，不是浮在画面上方。
- 作品必须自己画满整张画布的不透明背景；录制页不提供任何主题配色。
- 数值、路径与结论图的示意内容要在画面或旁白里标注「示意」，不写成实验数据。

## 编排运动

- 动画由 `useSceneContext()` 的 `elapsedSeconds`/`progress` 或 `segmentWindows` 驱动：
  口播到哪一句，画面走到哪一步，没有一句旁白在讲还没出现的画面。
- 需要素材时用 `useMediaAsset(id)` 按素材 ID 取用；比例不受画幅限制，裁切与摆位由作品决定。
  视频要等到可播放后再调用 `ready()`，素材原声不会进入母版。
- 复杂动画、3D 与动态图表用 `motion`、`gsap`、`echarts`、`three`/`@react-three/fiber`/`drei`；
  运动只出现在承载信息的地方。

## 实际观看

做完之后要**真的看**：抽关键帧看静止画面，播放含运动、转场和声音的代表片段看节奏。发现问题的
时间位置、修改内容与复查结果写进作品 `outputs/visual-notes.md`。无法观看时如实报告，不能虚构
「已通过」。这份记录不是导出门禁，缺了它不会阻断导出，但也意味着没有人看过画面。

## 旁白与时长

每段旁白给稳定 ID，逐幕收集。全片实际时长不超过 600 秒，包括每幕 24 帧阅读停留和淡化帧数；
超限修改文本或正常语速，不能截断语音。固定示例中缓冲与试错以 120～180 秒为目标、太阳系之旅以
165～180 秒为目标，时长以实际配音为准。

## 固定示例

固定示例集合为 buffer-smoothing、darts-trial-and-error、solar-system-journey，最多 3 个；不新增、删除或替换目录。每个示例有 `article.md`、`project.json`、`storyboard.json`、`README.md`、`DESIGN.md` 与按需的 `assets/`、`scenes/`。

- buffer-smoothing 与 solar-system-journey 使用 1920×1080，darts-trial-and-error 使用 1080×1920。
- 三片合计覆盖 Motion、ECharts、GSAP、Three.js、React Three Fiber 与 Drei；
  不再要求覆盖旧模板。
- 核心演示包含旁白，通过实际 `segmentWindows` 与录制时钟推进：缓冲演示水位、流动点与流量积压，
  试错演示落点与调整，太阳系演示同一三维模型内相机在总览与各天体之间的连续飞行。
- 数值与路径明确标注示意，文章保留适用边界；示例 README 提供论点、旁白、画面与组件对应表，
  `DESIGN.md` 记录视觉设计依据。

详细字段见 [分镜结构](storyboard-schema.md)，操作见 [制作流程](production-workflow.md)。
通用类型只接受 v8 全画布代码场景，旧版本不自动迁移。
