# 推进与回退记录模板

使用条件：在核心样片或全片粗片节点记录推进/回退决定。规则以[制作流程](production-workflow.md#回退记录与重新放行)为准。

```markdown
### 推进／回退决策：<原问题 ID；通过且无问题时引用评审报告 ID>
- 节点与版本：<核心样片 / 全片粗片；周期、准备指纹、证据摘要>
- 决策：<四种决策之一；独立报告、时间窗和依据>
- 根因与回退层级：<为什么局部修补不足；局部修复或补证写对应理由>
- 技术依据：<试制、限制、投入边界、已尝试路径；不适用时说明>
- 暂停范围／可继续范围：<场景、机制与依赖；不以单段通过授权全部>
- 设计调整：<保留目标、替代方案、收益与损失；链接 DESIGN.md>
- 基线及证据：<保留版本、失效证据、仍可复用证据及依据>
- 重新放行条件：<需重做的验证范围、独立复查及当前证据引用>
```
