# 正式设计：完整设计与预演

目标：将已验证方向组织成完整作品。设计、实现、观察和修订在同一循环推进，不增加交接审批。

## 设计记录

RESEARCH.md 保存研究，DESIGN.md 保存全片目标、原始要求、选案范围、结构、共同语言、贯穿对象及场景索引。每个正式场景固定保留 design/scenes/<scene-id>.md。默认四问、复杂度展开与对应检查由[场景设计](scene-design.md)唯一维护。研究、参数、问题和原报告分别维护，不复制。

以已通过独立评审的实际画面为静态基线，适用过程另验。先组织骨架，再深化能改变方向判断的新内容、复杂动作和跨场关系。总设计记录全片共用字幕规则及适用样片要回答的问题，场景按[场景设计](scene-design.md#场景模板)落实字幕和镜头配合。

## 全片预演

预演、粗片与精制使用同一循环：找最大未知 → 生成足以判断的静帧、局部过程或完整候选 → 核查抽帧、时间轴和适用信号 → 修复并回写。无需按名称依次产出一套中间版本。全片结构、开场、推进、衔接、重复、强弱和结尾回报仍须在足够的全片依据上验证；占位只证明实际覆盖范围。

新场景优先复用已验证成熟方案，保持用户所选的整体视觉机制。构图随内容变化，但同色同字体不授权另一套核心载体。先验证最容易暴露风格迁移的内容，只补足能推翻当前判断的未知，不提前精修所有场景。

制作口播时，按[观点旁白与意境素材](visual-material-selection.md#观点旁白与意境素材)提取对象、动作和转折，以实际旁白时长细排镜头。

## 场景循环

按[渐进设计](scene-design.md#渐进设计与开发循环)明确目标、关键关系、状态、衔接和未知，再局部实现、观察与回写。适用目标有具体窗口和预期；精确时点、坐标、曲线和声音偏移留在分镜／代码，文档引用。

共同问题修总设计，局部问题修本场，跨场问题联动相邻场，核心机制失败回[研究](stage-research.md)。问题沿[唯一返工记录](production-workflow.md)，评审和采用按[审核政策](review-contract.md)，不另建逐场独立门禁。

首次编排读[分镜契约](storyboard-schema.md)，首次实现读[运行时](code-scene-runtime.md)，有旁白读[声音节奏](voice-and-rhythm.md)。全片依据明确后沿[制作与验收](stage-production.md)完成交付。
