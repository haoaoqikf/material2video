# 正式设计：完整设计与预演

目标：将已验证方向组织成完整作品。设计、实现、观察和修订在同一循环推进，不增加交接审批。

## 设计记录

以已通过独立评审的实际画面为静态基线，适用过程另验。沿[总设计模板](scene-design.md#总设计模板)先组织全片骨架，使信息顺序、场次作用、衔接与结尾回报可判断。优先深化最可能改变全片组织或暴露风格迁移问题的场景。

## 全片预演

按全片骨架串查开场、推进、衔接、重复、强弱和结尾回报。用新内容核对选定风格能否跨场迁移。占位只支持实际覆盖的判断；需要理解相邻段落的节奏或信息交接时，把相关段落连起来看。

制作口播时，按[观点旁白与意境素材](visual-material-selection.md#观点旁白与意境素材)提取对象、动作和转折，以实际旁白时长细排镜头；密集口播或阅读紧凑的段落尽早用实际旁白与字幕核对切点和阅读时间。

## 场景循环

各场进入开发时，用[场景模板](scene-design.md#场景模板)和[逐场循环](scene-design.md#渐进设计与开发循环)落实已验证方向。

首次编排读[分镜契约](storyboard-schema.md)，首次实现读[运行时](code-scene-runtime.md)，有旁白读[声音节奏](voice-and-rhythm.md)。全片依据明确后沿[制作与验收](stage-production.md)完成交付。
