# 正式设计：完整设计与预演

目标：将已验证方向发展成完整、连贯、可执行的作品方案。

在同一设计循环中统筹全片结构、视觉、分镜、动态与声音；随设计做全片预演、实际观察并修订，不拆成多个交接子阶段。

以研究阶段确认“可作为后续标准”、并经[原生样品交付检查](design-samples.md)的实际网页画面为视觉基线，再展开全片；相对最佳或值得打磨仍不足以展开。核对整体品质如何适应每场内容、构图和信息层级；新构图、高信息密度、材质或运动只补足可能推翻当前判断的证据，不提前精修所有场景。研究与选案要求见[研究与试制](stage-research.md)。

## 设计记录

DESIGN.md 仅维护：

- 全片目标、受众、用户硬约束、事实与真实/示意边界、视觉与声音方向。
- 逐场用途、对象、变化、必要观察窗口及衔接，引用研究、素材与有效试制；采用特征、本片落点/适应性调整、验证办法及实际视觉基线。
- 必要的实现依据、未决风险和验证办法。时点与执行参数维护在分镜或场景中，不重复抄写。

制作合同是上述供人和代理阅读的制作依据，不设置可解析画面断言块。RESEARCH.md 保留研究全文，设计只引用结论；不复制独立报告或再建问题表。

## 全片预演

用动态分镜或实际场景时间线检查开场、推进、跨场衔接、重复疲劳与结尾回报。可用 `m2v review timeline --project <作品>` 复用当前准备材料与正式 composition；缺少代表性美术的预演只支持其实际覆盖的判断。

预演是内部制作活动，不另开例行独立评审或登记门。检查新场景的字体、形体、适用材质光影、空间与运动是否延续所选目标，构图随内容变化并形成强弱，不以每页同布局代替一致性。引入新核心机制或实质改变已验证方向时，回到相关[研究与试制](stage-research.md)。视觉基线可继续发展；调整目标须记录原因并重新验证，不能因实现困难悄悄降标。最终材质、合成与混音可继续完善，但占位预演只支持实际覆盖部分。

全片表达连贯、关键衔接成立、制作依据明确后进入[制作与验收](stage-production.md)。首次编排读[分镜契约](storyboard-schema.md)，首次实现读[代码场景](code-scene-runtime.md)，有旁白读[声音节奏](voice-and-rhythm.md)。
