# 正式设计：完整设计与预演

目标：将已验证方向组织成完整作品。设计、实现、观察和修订在同一循环推进，不增加交接审批。

## 设计记录

以已通过独立评审的实际画面为静态基线，适用过程另验。沿[总设计模板](scene-design.md#总设计模板)先组织全片骨架，使信息顺序、场次作用、衔接与结尾回报可判断。优先深化最可能改变全片组织或暴露风格迁移问题的场景。

## 全片预演

预演、粗片与精制使用同一循环：找最大未知 → 生成足以判断的静帧、局部过程或完整候选 → 核查抽帧、时间轴和适用信号 → 修复并回写。无需按名称依次产出一套中间版本。全片结构、开场、推进、衔接、重复、强弱和结尾回报仍须在足够的全片依据上验证；占位只证明实际覆盖范围。

以新内容核对已验证方案的适用性，重点观察用户选定的视觉机制能否承载不同场景。

制作口播时，按[观点旁白与意境素材](visual-material-selection.md#观点旁白与意境素材)提取对象、动作和转折，以实际旁白时长细排镜头。

## 场景循环

各场进入开发时，用[场景模板](scene-design.md#场景模板)展开必要细节，按[逐场循环](scene-design.md#渐进设计与开发循环)试验和回写。涉及核心机制的失败回到[研究](stage-research.md)，问题和采用沿[返工记录](production-workflow.md)与[审核政策](review-contract.md)处理。

首次编排读[分镜契约](storyboard-schema.md)，首次实现读[运行时](code-scene-runtime.md)，有旁白读[声音节奏](voice-and-rhythm.md)。全片依据明确后沿[制作与验收](stage-production.md)完成交付。
