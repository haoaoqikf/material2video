# 最终验收

首要问题：当前候选是否有完整有效证据，适用评审和必改项是否真正关闭？

## 必做

1. 修改材料后重新 prepare，按[再次全片生成前的收敛判断](production-workflow.md#再次全片生成前的收敛判断)先确认可局部验证的修复效果，再 render 汇总为新全片候选；首次生成沿用制作阶段完成条件。preview 不代替全片；`lookdev`、`qa`、`assets audit` 与 `review` 是按需检查工具，不是 CLI 渲染的必跑前置。技术 QA 与制作复核分别报告。
2. 核对当前候选、准备指纹、媒体摘要和完整全片证据；旧片或过期报告不得授权当前版本。
3. 按[审核策略](checkpoint-gates.md#审核计划与风险触发)执行 G6 终审；使用未参与前期评审的新代理，适用 split-final 才分职责。读[隔离执行](subagent-review.md)，不给设计理由或旧结论。
4. 覆盖当前候选的全片理解、结构、节奏、视觉、文案与必要文字手机可读性；适用目标图在盲看落盘后同轮对照。实际表达判断按[视觉复核](visual-review-rubric.md#讲解关系的观察)。
5. 沿[关闭规则](checkpoint-gates.md#讲解机制与关键采用项的关闭)核对全部必改项；自审、技术通过、相同状态或目标图一致不能替代适用独立复查。

## 终检门槛表

渲染完成后按类别逐项自查，用于定位问题，**不替代独立评审与既有证据条件**。强制条件与按问题选用的诊断须分开：事实、许可、技术、核心理解、必要可读性及实际必改缺陷必须满足；回场、去文字等设计手段按用途选择。完成条件以[检查点契约](checkpoint-gates.md)为准。

| 类别 | 门槛 |
|---|---|
| 讲解 | 成片与当前分镜一致；按场景用途核对对象、变化与认识，不能以抽五处替代全片覆盖；数值与口径一致；回场和共同尺度仅在设计采用时核对 |
| 画与不画 | 提问、命名、结论不硬配图；连续静止须有阅读、观察或情绪用途，不因没有运动直接否决 |
| 结构 | 片名位置合理；结尾兑现开头承诺并完成收束；是否回到开场画面按表达需要判断 |
| 字幕 | 有旁白共享字幕按[准备与字幕契约](prepared-and-subtitles.md)核对时间和排版；无旁白屏幕字幕按[屏幕字幕约定](explainer-design.md#无旁白字幕稿)检查单行与长度上限；必要文字在声明手机尺寸可辨，强调服务信息层级 |
| 画面 | 字幕区与主体、必要文字不互相遮挡；主体运动关系和注意力清楚；必要注释不争夺焦点；颜色含义全片一致；画面承担其设计的表达职责 |
| 节奏 | 没有说不清的转场；阅读、动作和结果观察窗口协调，允许有依据的重叠；动效与停留服务表达 |
| 事实 | 屏上每个数字与事实表一致；每个概念有出处；示意的地方写明 |
| 技术 | 帧率与画幅符合声明；无水印与多余制作说明；必要素材署名保留；适用确定性检查通过 |

不合格时集中列出问题 ID、具体时间点与类别，按[检查与返工循环](production-workflow.md#检查与返工循环)修复并实际查看受影响范围及衔接；按收敛判断汇总后再生成，不逐项重跑全片。全局或正式文件问题保留相应完整验证范围。

## 完成条件与限制

当前技术 QA、适用独立评审、证据范围与摘要都有效，相关必改关闭，才能报告制作复核完成。坏动态证据不能支持完成，但不会阻止候选生成。工具对时长的检查不证明内容或审美成立。

降级、未覆盖声音、帧间连续性或平台遮挡等限制如实披露，不能写成已通过。交付同一候选并报告验证、未完成项及来源边界，规则见[交付与溯源](delivery-and-provenance.md)。作品与生成媒体不入库；共享代码/文档验证后按项目约定提交。
