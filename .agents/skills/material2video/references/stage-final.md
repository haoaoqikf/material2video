# 最终验收

首要问题：当前候选是否有完整有效证据，适用评审和必改项是否真正关闭？

## 必做

1. 修改材料后重新 prepare，正式 render 一次生成全片候选；preview 只用于局部检查，不代替全片。技术 QA 与制作复核分别报告。
2. 核对当前候选、准备指纹、媒体摘要和完整全片证据；旧片或过期报告不得授权当前版本。
3. 按[审核策略](checkpoint-gates.md#审核计划与风险触发)执行终审；使用未参与前期评审的新代理，适用 split-final 才分职责。读[隔离执行](subagent-review.md)，不给设计理由或旧结论。
4. 覆盖全片理解、结构、节奏、视觉、文案与必要文字手机可读性，适用目标图在盲看落盘后同轮对照。实际表达判断按[视觉复核](visual-review-rubric.md#讲解关系的观察)。
5. 沿[关闭规则](checkpoint-gates.md#讲解机制与关键采用项的关闭)核对全部必改项；自审、技术通过、相同状态或目标图一致不能替代独立复查。

## 终检门槛表

渲染完成后按类别逐项自查，用于定位问题，**不替代独立评审与既有证据条件**。与[检查点契约](checkpoint-gates.md)表述不一致时，以契约为准。

| 类别 | 门槛 |
|---|---|
| 讲解 | 成片与分镜对得上；抽五处能答出「这是什么、在干什么、明白了什么」；没有只是配图的画面；屏上的数前后一致；尺子与道具回过场 |
| 画与不画 | 提问、命名、结论没有硬配图；也没有连着几句画面不变 |
| 结构 | 片名位置合理；结尾回到开场的画面；收束兑现开头的承诺 |
| 字幕 | 每句一行；停留时长够读完；一句最多强调一处；必要文字在手机尺寸可辨 |
| 画面 | 字幕区没有别的东西；任何一刻只有一个主体在动；一镜最多一条小字；颜色含义全片一致；遮住文字仍认得出主体 |
| 节奏 | 没有说不清的转场；主体出完之后停住让人读；不过度堆叠动效 |
| 事实 | 屏上每个数字与事实表一致；每个概念有出处；示意的地方写明 |
| 技术 | 帧率与画幅符合声明；无水印与多余署名；适用确定性检查通过 |

不合格时列出具体时间点与类别，改完只重采受影响范围确认，再跑全片。

## 完成条件与限制

当前技术 QA、适用独立评审、证据范围与摘要都有效，相关必改关闭，才能报告制作复核完成。坏动态证据不能支持完成，但不会阻止候选生成。工具对时长的检查不证明内容或审美成立。

降级、未覆盖声音、帧间连续性或平台遮挡等限制如实披露，不能写成已通过。交付同一候选并报告验证、未完成项及来源边界，规则见[交付与溯源](delivery-and-provenance.md)。作品与生成媒体不入库；共享代码/文档验证后按项目约定提交。
