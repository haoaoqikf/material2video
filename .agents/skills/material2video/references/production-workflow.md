# 返工、回退与记录

片段制作按[逐场循环](scene-design.md#渐进设计与开发循环)执行。本页维护跨阶段回退、修订和问题闭环。

## 推进与回退

核对帧和适用信号后选择通过、局部修复、补证或重设计。根本失败立即回退。同一问题两轮修复无改善时，比较实质不同机制、删短或重排，按原范围独立复核。试制关键帧按下文的[暂停送审规则](#试制暂停送审与重新选案)执行。偏好差异不单独构成失败。

从最早受影响的一层重新进入。实现偏差修实现，全片组织失败修设计，核心机制或基础假设失败回研究试制。混合问题先修设计再修实现。研究依据不足时补查具体缺口。当前构图或动作不适合内容时，在生效风格内重做镜头。更换已绑定的参考目标须有用户明确授权，已进入评审的目标按[改靶流程](review-contract.md#用户明确变更目标)处理。只回退必要范围，保留无关有效成果。

选案与收敛沿[研究与试制](stage-research.md)执行。每轮针对最影响整体的问题保留前后媒体与实际收益；试制的总体工作时长和尝试次数不设上限。按[审核策略](review-contract.md)决定是否制作关键样片。外部阻塞或中断只保留未完成记录，不交付失败稿；候选相对最好不等于目标通过。作品完成见[验收交付](stage-production.md#验收交付)，单独样品交付见[原生样品](design-samples.md)。

## 检查与返工循环

唯一问题清单放在 outputs/visual-notes.md：发现 → 修改 → 核查证据 → 同范围复查 → 关闭。正文记录当前时间窗、显示条件、观察、收益与损失，链接媒体及报告。机器块使用[评审契约](review-contract.md)的新格式。

“已修改待复查”仅表示材料变动；“实际效果已确认”须有当前版本的帧或信号依据。证据范围按[逐场循环](scene-design.md#从粗排到精修)选择。

独立失败按原条件、同范围由当前独立报告复查；制作解释、自审或技术量测不能代替。报告只引用，不复制到问题记录。正常通过不填空模板。

## 返工交接

对照报告回传原目标和参考用途、具体帧位、观看尺寸、画面位置、实际影响及通过时应看到的现象。制作方把可直接观察的复查问题写入 `outputs/visual-notes.md` 正文，引用原报告。比如，正常尺寸完整画面中能否从主塔正面看出透光，并在转向侧面时读出厚度。

复送前，主代理在同一问题下分别写出改前和改后的实际答案，链接同帧位或等价窗口、原观看尺寸的完整实绘，并记录已保住的效果和剩余差距。局部裁图用于定位。改后证据应支持原核心效果达到可复查的通过表现，才进入独立复查。若问题仍可直接看到，继续内部比较或重选。原报告、参考、观看条件和验收标准继续适用。

## 试制暂停送审与重新选案

1. **按核心问题比较。** 用[返工交接](#返工交接)中的同一问题和证据判断。核心效果出现可辨且保住其他核心效果的进步，才算明显改善。缺可比证据时先补证，该次修改暂不计入无改善次数。
2. **连续两次无明显改善就暂停。** 同一个视觉问题跨帧或跨候选时，在现有 `outputs/visual-notes.md` 正文沿同一问题串联两次修改的实绘与原报告，记下暂停依据。保留各观察项和原结论，换版本、方案名或新建评审包都不清零。暂停当前方案的正式送审，以及仅为这个问题发起的整段重渲，内部小试和不受影响的工作可以继续。
3. **重选后凭证据恢复。** 围绕原核心问题，在小范围比较实质不同的主体造型、构图、布光或表达机制。从内比中选出原核心效果有明确改善、已经成立的关键效果可保住的候选，记录依据后再按原适用范围提交新版本的同源关键帧，继续独立盲审和同轮对照。未选出满足条件的候选就保持暂停。恢复送审后，仍需按[审核策略](review-contract.md#问题与独立复查)用有效独立证据关闭原失败。
4. **对通过门槛有实质争议时核对原证据。** 同一个问题最多安排一次独立复核，使用相同媒体、原目标、原范围和实际观看条件，以[独立评审的隔离规则](subagent-review.md#争议探索与降级)执行。复核用于判断差距是否实质阻断，保留原报告，也不自动结束暂停。用户明确调整目标时按现有[目标变更流程](review-contract.md#用户明确变更目标)执行。

## 修订与当前交付

修改先核对用户硬约束及来源、历史可调整选择、目标、当前成片和受影响范围。局部文字或数据修复复用仍有效的研究与评审证据，不重开无关选案；新反馈暴露美术目标缺口则补相关研究，新核心机制重新试制，全片结构改变重做全片预演。明确目标未兑现须保留原条件并按参考复查，不能事后降为偏好差异。

旧版本基线保留数量为 0。按[修订入口](video-revision.md)直接更新当前工程，当前交付经新版验证成功后替换。旧版相关副本成组清理。独立评审原件和失败历史继续保留，已清理的旧媒体缺少同摘要原件时记录不可复核，仍适用的问题继续按原条件复查。

## 记录分工

全片研究、总设计和各场实现按[文档分工](scene-design.md#分工与对应)记录。outputs/visual-notes.md 保存唯一问题及实际复查，独立报告保存原始观察。作品与媒体不入库。

在现有制作记录中简要复盘已确认的流程收益与损失，时间估计注明，不增加总结文件或阶段审批。
