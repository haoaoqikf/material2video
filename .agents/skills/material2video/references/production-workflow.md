# 返工、回退与记录

三阶段入口为[研究与试制](stage-research.md)、[正式设计](stage-design.md)、[制作与验收](stage-production.md)。本页只维护跨阶段修订、基线和问题循环。

## 推进与回退

实际观察后选择通过、局部修复、补证或重设计。根本失败立即回退，不必等两轮；同一问题两轮修复无改善时停止参数微调，比较实质不同机制、删短或重排，按原范围独立复核。偏好差异不单独构成失败。

实现偏差修实现，全片组织失败修设计，核心机制或基础假设失败回研究试制；混合问题先修设计再修实现。风格差距按缺乏研究依据、已理解目标但实现偏差、参考与内容不适合分别补查、修制作或重选方向。未知原因继续补证，不能以改目标或重渲染关闭问题。只回退必要范围，保留无关有效成果。

选案与收敛沿[研究与试制](stage-research.md)执行。每轮针对最影响整体的问题保留前后媒体与实际收益；试制不设主动工作时长或尝试次数上限；两轮无改善是换路径继续的触发条件。外部阻塞或中断只保留未完成记录，不交付失败稿；候选相对最好不等于目标通过。完成条件见[原生样品](design-samples.md)。

## 检查与返工循环

唯一问题清单放在 outputs/visual-notes.md：发现 → 修改 → 实际查看 → 同范围复查 → 关闭。正文记录当前时间窗、显示条件、观察、收益与损失，链接媒体及报告。机器块使用[评审契约](review-contract.md)的新格式。

“已修改待复查”仅表示材料变动；“实际效果已确认”必须有当前版本的实际查看依据。动作检查完整过程与相邻衔接，静态修改可用 lookdev 定点检查，跨场结构扩大到全片。无需每修一处就重跑全片。

独立失败按原条件、同范围由当前独立报告复查；制作解释、自审或技术量测不能代替。报告只引用，不复制到问题记录。正常通过不填空模板。

## 修订与基线

修改先核对用户硬约束及来源、历史可调整选择、目标、旧版和受影响范围，保留必要比较基线。局部文字或数据修复复用仍有效的研究与实际视觉基线，不重开无关选案；新反馈暴露美术目标缺口则补相关研究，新核心机制重新试制，全片结构改变重做全片预演。明确目标未兑现须保留原条件并按参考复查，不能事后降为偏好差异。

`m2v baseline create` 保护当前媒体和记录；源码另在内容目录保留修改前副本。活动问题与比较引用保护优先于默认三个完整版本目标，只有未引用媒体才可降级清理，损坏或未知引用停止清理。旧记录不转换为新通过，显式新周期保留旧文件和失败历史。

Windows 基线读写使用扩展路径处理深层评审记录，manifest 仍保存原有相对路径；无需修改系统长路径策略。创建和后续校验、降级清理使用相同路径处理。

## 记录分工

RESEARCH.md 保存研究证据和方向比较；DESIGN.md 保存设计与制作依据；outputs/visual-notes.md 保存唯一问题及实际复查；独立报告保存原始观察。作品与媒体不入库。

在现有制作记录中简要复盘已确认的流程收益与损失，时间估计注明，不增加总结文件或阶段审批。
