# 通用作品制作流程

本页是阶段与记录的唯一入口；创作细节见[创作流程](creative-production.md)，评审职责见[独立子代理评审](subagent-review.md)。新流程仅用于后续启动任务，不迁移正在制作的作品；金融与住宅保留专用画幅、声音和材料契约。

## 立意六项（方案确定前）

提出叙事候选之前，先在作品 `DESIGN.md` 写下六项。任一项缺失不得进入叙事候选；六项是必须回答的问题，不是质量评分，也不转为用户确认、运行时字段或 CLI 门禁。它们要求动手前回答问题，不保证答案成立。

1. **一句话命题**：观众看完能用自己的话复述的主张。
2. **核心体验**：希望观众经历发现、震撼、好奇、紧张、共鸣或秩序美感中的什么，以及由哪个具体段落承载；“高级”“震撼”必须落实到可观察的表达。
3. **表达载体**：文字、图形、空间、档案素材、静态构图与声音如何分工，并写清**载体来源政策**：本片是档案证据型、解释型还是混合型；哪些内容必须由真实素材承担，哪些只能由代码解释；真实与示意的边界如何标注；素材许可与可得性风险如何回退。逐场只决定具体实例，不另立一套来源政策。采用重复母题时写各次出现的作用；不采用时写替代组织方式，不强制全片重复同一对象。
4. **揭示与记忆**：先看到什么、何时形成理解、最后记住什么；分别声明必须立即清楚与允许延迟理解的内容，以及揭示的完整时间窗口。
5. **可验算骨架**：片中定量主张及其验算方式；没有定量主张时明确写明。
6. **重点投入**：最值得投入的具体段落、预计秒数与工时，以及对理解、感受和记忆的贡献；数量按作品需要，不限定唯一一处，也不要求其理解贡献接近零。

母题可以通过状态、关系、情绪或后续语境改变含义，不要求单调增长或三次外形变化；实际作用须在完整段落中验证，不能只靠作者解释。允许不用母题，不强制反转、高潮、持续运动或额外装饰。金融住宅仅执行适用项并记录不适用原因，专用画幅、材料与声音契约不变。

立意六项是 `DESIGN.md` 的区块，不新增阶段名，不改变状态查询、CLI 或四阶段入口。

## 视觉创意方案（选定方案后）

三个叙事候选阶段，各案只提出核心表达与母题候选；**选定方案后、逐场设计与关键画面之前**，按[视觉创意导演方法](visual-creative-direction.md)在 `DESIGN.md` 完成七段式：核心表达、核心视觉母题、整体视觉风格、分镜设计、视觉高潮、结尾视觉揭示、禁止项，并完成十项自我检查。

- 七段是必答问题，不是质量评分、用户确认、运行时字段或 CLI 门禁。题材不适用时写明原因与替代做法（例如不采用统一母题、不设传统高潮或不设独立视觉揭示），不硬造。
- 七段不是平行表单，回填现有区块：核心表达→一句话命题；母题→表达载体；风格→视觉方向；分镜→逐场设计表；高潮/揭示→核心体验与揭示记忆；禁止项→反目标。
- 母题写成「把 ___ 设计成 ___」，载体必须可变化；**核心视觉母题**（整片组织载体，单数，不要求重复）与**母题重复**（同一载体多次出现并产生新作用）是两件事。
- 每个抽象观点至少对应一种可见变化；镜头写行为（推进、跟随、升降、拉远、俯视、环绕、穿越、冲入、微观到宏观），不写页面切换。
- 画面文字按镜头或信息单元计，原则上「一句主句 + 至多一句辅助」；标签、轴、数据、事实边界、口径、许可与示意标注不计。关声可读是设计诊断，不是有声作品的最终门禁。
- 载体来源：整体政策在「表达载体」定稿；分镜按镜头/信息单元写「载体来源与理由」（档案／实拍／图库／代码／混合、为什么、许可与溯源、真实／示意边界）。逐场实例服从整体政策，冲突回退整体，不就地妥协。
- 运行时边界：幕间转场只有 `cut`/`fade`/`crossfade`；`shots[].camera` 由作品代码消费，不新增自动运镜。

七段式属于「方案确定」阶段，不新增阶段名，不改变状态查询、CLI 或四阶段入口。

## 四阶段主线

| 阶段 | 活动 | 完成条件 |
|---|---|---|
| 方案确定 | 立意六项、受众与资料、三个叙事候选、视觉创意七段式、信息及体验预算、文案、两个美术方向、逐场目标 | 立意六项完整，事实边界明确，叙事与美术分别匿名比较，七段式完整或已记录不适用原因，核心表达与手机验收条件可观察；各案含构思、揭示、代表段落、题材关联及风险 |
| 粗片验证 | 核心动态试制、四张基准、风险样片、完整粗预演 | 扩展全片前核心表达盲测通过；风险已验证；一次粗片独立审查覆盖所有场景、信息推进、理解和结构，完成第一次导演审查 |
| 精制修订 | 正式美术与声音、亮点强化、逐场修正、重要返工比较 | 唯一问题表逐项复查；记录有效表达及强化结果；重要返工首次匿名比较收益与表达损失；两轮失败强制剪辑对照；仍失败回退 |
| 最终验收 | 一次完整候选、技术 QA、两名代理全片审查、交付 | 技术检查、第二次导演审查与视觉审查完整，当前文件全片覆盖，核心与其他必改项关闭，限制披露 |

核心试制、lookdev、hero、风险样片是阶段内活动，不另设阶段或审批。无实质问题不强制返工，不为凑满时长填充动效；不增加评分、用户确认或 CLI 门禁。

## 三类记录

1. `DESIGN.md`：立意六项、三案、视觉创意七段式（含十项自检与例外留痕）、全片强弱与表达统一、受众、共享美术规则、逐场目标、必要的特殊技术与动态设计。模板见[视觉创意导演方法](visual-creative-direction.md)与[逐场设计](scene-design-and-acceptance.md)。
2. `outputs/visual-notes.md`：阶段汇总、唯一问题表、证据索引、评审引用、最终传播表现与交付结论。问题模板见[版本与问题闭环](visual-review-rubric.md#版本与问题闭环)。
3. 独立评审原始报告：保存原始观察，不复制全文到主记录；主记录直接链接报告及需要保留的证据文件。

每个问题只登记一次，场景与导演结论引用同一 ID；每个场景和内部镜头仍须覆盖，合并记录不免除验收。信息推进合入粗片逐段观察，传播假设写入设计，最终评估写入主记录，不另建潜力报告。

设计方法见[核心体验与表达设计](creative-production.md#核心体验与表达设计)；评审按[缺陷、风险、偏好与证据不足](visual-review-rubric.md#缺陷风险偏好与证据不足)分类。完整表达窗口是判断单位，开场诊断不自动否决后续揭示；创意风险不得仅凭设计意图放行。

## 技术链路

使用 project.json 与 v8 storyboard.json，源码在 scenes/。命令以[制作 Skill](../SKILL.md)为准：材料审查与选音 → prepare → 按需关键帧/短片检查 → render 保存一次完整候选 → 自动技术验收并交付同一文件。prepare 不录制全片；preview 严格短于全片；关键帧只采所需帧；正式生成复用区间缓存。重试验收或复制不重复编码，失败保留旧有效成片。

源文、素材、场景、旁白、字幕或实现依赖变化须重新 prepare。技术交付与制作复核分别报告；CLI 的状态、可选 review.json 与导出行为保持不变。

## 检查与证据

手机显示尺寸及主体辨认、动作理解、关系理解的适用目标分别声明；无动作表达不强制添加动作目标。检查采用时间标注帧序列、风险加密帧、量测与自动音频信号，不要求播放或试听；主观听感及采样间运动限制如实披露。无声作品保持无声，静音验收替代响度目标。

每个最终交付文件均完整检查。局部变更复查本场及衔接，结构、时长与全局风格变化复查全片；证据复用与隔离见[评审包](subagent-review.md#评审包)。事实、许可、技术 QA 不由代理观感替代。

### 指定时刻的单帧检查

`lookdev` 的静帧按 hero、首尾与等距自动取点，适合概览，不保证落在某一幕的特定时刻。需要核对
某一秒的构图、文字层级或阶段状态时，可在作品目录外建一个临时镜头测试项目：复制当前场景到测试
项目的 `scenes/`，每个场景只保留一个 `mode`，在 `content.props` 里用固定的 `stillT`（秒）覆盖
录制时钟；场景时长仍给足（例如 600 帧）以保留进度计算。`prepare` 后运行
`m2v lookdev --project <测试项目> --stills 1 --still-scale 2 --sample-seconds 1`，逐个改
`stillT` 重采；样片长度收到 1 秒可避免为每张静帧重录一整段样片。

测试目录、`stillT` 与这类覆盖只用于检查，不进入正式分镜；正式作品仍只按 `elapsedSeconds` 与
`segmentWindows` 推进。检查完删除临时项目，避免把测试场景当成作品交付。
