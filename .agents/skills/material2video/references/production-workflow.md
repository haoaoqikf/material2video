# 通用作品制作流程

本页配合[节奏、美术、声音与制作阶段](creative-production.md)执行：先整片粗预演、风险优先，再按阶段完成条件精制与复查；不增加用户确认或 CLI 人工门禁。

核心体验先转为验收条目，并声明手机显示尺寸及关键事件的主体辨认、动作理解、关系理解三类目标；镜头、内容和旁白联合预算并允许粗预演反向修订。按[自主视觉复核](visual-review-rubric.md)检查整段运动，已知急冲、急转与短停留不得作为限制放行；工作流改进与作品重制同时受托时须同时交付。每个场景及内部镜头按[逐场设计与独立验收](scene-design-and-acceptance.md)完成设计、试制、精制和验收，问题按原验收条件闭环；最终候选逐页查看全片时间标注序列。全过程按[百万播放潜力](reach-potential.md)记录假设、证据与最终定性预估。

通用作品使用 project.json 和 v8 storyboard.json。创作顺序为：创作目标 → 多轮候选方案与淘汰 → 核心动态试制与回退 → 整片动态粗预演与结构重组 → 美术与声音定稿 → 精制与复核循环 → 自主交付。每轮默认3个不同讲法，可全部淘汰后继续；不存在必须从当前候选中选一个的要求。具体产出、回退及完成条件以[循环创作流程](creative-production.md)为准。

作品代码在 `scenes/`；`m2v init` 会生成材料模板并按类型目录写入起步场景 `scenes/opening.tsx`，素材按需导入，音色按[自动选音流程](../SKILL.md)保存。粗预演可使用简化画面与临时配音，但须标明版本及限制；不能代替正式成片的全片验收。风险样片包含实际配音及按设计需要的音乐；优先验证复杂转场、多主体与声音交接，必改项关闭后再扩展精制全片。

下列 CLI 是准备/按需片段检查/一次全片生成交付的既有技术链路；命令清单与说明见
[制作 Skill](../SKILL.md) 的统一命令一节，它们不能替代上述创作阶段及真实复核。

prepare 复核全部登记素材并编译实际配音时间轴、母版声音与源码依赖，不录制场景。检查生成时只采集所需帧或片段；正式生成复用区间缓存并补齐缺口。

preview 做字幕量测并生成严格短于全片的有声片段，默认前十秒，可指定起止时间；不授权或阻断正式生成。`m2v general keyframes --storyboard <路径>` 原生采集代表静帧，不录制整幕。

作品正文在栅格片段里，自动检查**不**声称能识别其中的全部正文或主体遮挡。使用关键帧、全片高密度时间标注帧序列、代表风险区间加密帧和屏幕/运动量测覆盖检查，并用自动音频报告复核信号与时序；把时间位置、修改、采样密度和复查写进作品 `outputs/visual-notes.md`。不要求播放视频或试听音色，采样间瞬时异常及主观听感作为覆盖限制披露。这些记录不是导出门禁。

可选的 review.json 绑定当前准备指纹和候选文件摘要，主动评审时填写五项通过依据：信息清晰、
视觉设计、图文关系、旁白同步、阅读节奏。可选工具不等于制作复核可省：A/B 级评审按
[独立子代理评审](subagent-review.md)执行，缺执行方式与隔离条件记录时，对应阶段视为未完成。源文、素材、导入记录、分镜、场景源码与资源、画幅、
字幕几何、输入审查、音轨、渲染代码或字体变化，均要求重新准备并生成当前候选；人工画面评审不阻断导出。

正式生成先保存完整候选及摘要，再核验画布尺寸、帧数与声音，最后复制交付 outputs/video.mp4 并保存溯源；检查失败保留候选，重试不再编码。
失败不覆盖旧成片。旧准备与旧评审不兼容；v7 及更早分镜须重新编排。

CLI 自动门禁仍为材料审查 → 选音 → 准备 → 按需检查生成 → 全片生成一次 → 验收交付；可选评审记录不阻断导出。助手制作另外遵循[自主视觉复核](visual-review-rubric.md)：自主搜集参考、验证风险样片、必改项关闭后铺全片、最终文件全片帧序列与自动音频复核。导出成功不能代替制作完成。

## 统一制作流程

所有 general 作品都走同一套流程，不再声明档位；`productionProfile` 与 `--profile` 会被明确拒绝。
流程为五个阶段，所有阶段均无需用户确认；产出静帧与样片、按帧序列与量测复核并关闭必改项后继续。
命令清单与逐条说明见 [制作 Skill](../SKILL.md) 的统一命令一节；统一流程的要求是：

- 阶段为 **Brief → Look-dev → Hero → Full film → QA/自主复核**；look-dev 只产出检查产物，
  不设人工门禁，`m2v render` 不因缺少替代复核或确认记录而阻断。
- shot list、look、`claims`、`leadInFrames` / `tailFrames` / `readingHoldFrames` 都是分镜的可选
  字段，进入准备指纹与代码片段缓存键；只改 look 或镜头也必须重新 prepare。
- 不执行数字评分卡。技术 QA 与 hero 风险帧序列和量测后全片帧序列与自动音频复核最终文件，关闭必改项再自主交付；模板与版本失效规则见[自主视觉复核](visual-review-rubric.md)。
- 有声样片缺音轨时修复；无声作品验证最终 PCM 峰值为 0。使用全片帧序列与自动音频检测，明确覆盖限制，不要求连续播放或实际试听。

太阳系示例保留历史制作说明，历史确认不授权新版本完成；当前复核状态见示例 VERIFICATION.md。

无声作品按用户声音意图执行：无旁白、音乐、音效及素材原声；样片同样无声。视觉阶段保持不变，静音验收替代响度目标。参见[无声作品](cinematic-video.md#无声作品)。
