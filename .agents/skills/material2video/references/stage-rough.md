# 粗片验证

首要问题：最难的关系真的发生了吗，能否扩展依赖它的实现？

## 必做

1. 读取当前审核计划与有效状态，先验证未决核心风险，不因镜头等级机械增加评审。
2. 讲解片优先验证对象认回、局部整体关系、过程如何带来结果或回场的新认识。按[四种机制](explainer-design.md#四种讲解机制的执行方法)选适用项，用最小完整窗口呈现建立、变化、揭示及观察停留。
3. 用实际主体、字体、文字合成和关键动作做核心试制；占位资产只支持其覆盖的技术判断。
4. 独立评审先看隔离包，落盘“对象、变化、结果、画面与字幕各自提供什么、疑问何时解答”，再对照中性原目标。[隔离执行](subagent-review.md#讲解机制的隔离观察)与[实际表达判断](visual-review-rubric.md#讲解关系的观察)触发时必须展开。
5. 核心通过只授权已验证范围。扩展后用一份全片粗片审查全部场景、衔接、结构、文案与节奏。

## 证据与失败

动态核心须有可探测视频流、正时长，至少一段长度覆盖检查窗，容差一帧；不累加短片段。工具只证明最低容量，不能证明窗口对应或讲解成立。完整有序帧序列、显示尺寸及声音覆盖限制仍须记录。

按[既有回退路径](production-workflow.md#核心样片与全片粗片的回退决策)选择通过、局部修复、补证或重设计。关键关系主要靠字幕而违背原目标时登记必改；证据不足保持未验证。合理延迟揭示要看全窗，纯文字用途按原用途判断。

## 完成条件

适用核心风险逐项通过，G4 当前证据和 G5 全片报告有效，依赖范围的必改关闭，才能进入精制。目标图一致、技术 QA、作者解释都不能覆盖表达失败。状态与关闭规则以[检查点契约](checkpoint-gates.md)为准。
