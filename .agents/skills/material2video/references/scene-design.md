# 全片与场景设计

本页唯一维护分层职责、模板、详细编排与对应检查。五类共用，设计随实际试制修订；设计文档属于制作依据，**当前不渲染**，不新增 project、分镜或评审字段。

## 分工与对应

| 材料 | 唯一职责 |
|---|---|
| RESEARCH.md | 研究来源、实际观察、解释、推断、比较与限制 |
| DESIGN.md | 全片目标、原始要求、选案范围、结构、五维语言、贯穿对象、共同规范与场景索引 |
| design/scenes/<scene-id>.md | 本场详细编排、实现未知、关键状态、验证办法和有效样品引用 |
| 分镜、场景代码 | 正式时点、执行参数与实现，各值保留一个权威来源 |
| 素材台账 | 来源、许可与恢复；设计引用 |
| outputs/visual-notes.md | 唯一问题及修复/复查/关闭记录 |
| 实际媒体、独立报告 | 原始效果和观察；设计只引用适用结论 |

每个正式场景复用既有 `scene.id` 对应 `design/scenes/<id>.md`，总索引的链接文字使用 scene.id，目标为该文档（写法见下方模板）。场景可以共用代码入口，由分镜关联；镜头/节拍复用已有事件或镜头标识。无完整分镜的草案可以先研究试制，不为检查器伪造分镜。

总设计统一贯穿对象的身份、含义、材质和运动特性，场景继承并说明变化。出口场景维护衔接设计，入口引用接入条件，检查窗口覆盖两侧。精确帧数、坐标、曲线与声音偏移在分镜/代码中维护，文档写编排和引用，避免手抄全片时间表。

## 十二方面与细节深度

按复杂度展开，可合并相关方面；不要求十二个空栏目、固定字数或每个对象都有特效。

| 方面 | 要明确的关系 |
|---|---|
| 目标叙事 | 观众进入/离开时知道和感受什么，关键事件及记忆点 |
| 继承要求 | 原要求、采用范围、共同规则、实际基线及本场调整 |
| 对象职责 | 主体、辅助、环境、文字与数据的作用及身份；抽象意象可与精确读数分工 |
| 构图空间 | 重心、占比、留白、景深、遮挡、运动空间及小屏关系，覆盖中间状态 |
| 镜头调度 | 景别、视角、焦点、路径、切换理由；区分相机与对象运动，保护数据比较 |
| 动作 | 准备/启动/变化/接触/稳定，及适用形变、惯性、过冲、回弹、跟随与衰减 |
| 配合反应 | 谁触发谁、响应延迟、同步/错开、影响传播；每节拍谁主导、配合或安静 |
| 材质光影 | 厚度、粗糙、透光、反射、边缘、光向、接触阴影及动作中的变化 |
| 文字数据 | 正式内容、单位、尺度、零点、边界、揭示/阅读窗口及字幕配合 |
| 声音转场 | 声音层与留静的作用和同步；跨场对象、位置、运动与声音的接续 |
| 实现未知 | 路径、成本、画质、许可、假设、候选和替代损失；静态不证明动态可行 |
| 验证依据 | 关键状态、完整过程、实际参考、适用预期、结果、限制与未覆盖范围 |

五维在总设计确定共同语言，在场景落实具体关系。静帧推导按[参考分析](reference-video-analysis.md#只有静帧时的推导)标为假设。静止、无声、cut 均可有意采用。指标按实际机制选择，如连续性/停留、接触响应、转场位置/颜色、声音起音/层级等，不要求每场全部填写。关键承诺缺预期或证据时保持未验证，内部试制继续解决，填表或指标通过不证明整体品质。

## 渐进设计与开发循环

先写全片骨架，深化影响方向判断的代表场景；沿[研究与试制](stage-research.md)验证后展开。每场循环：可执行设计 → 关键部分实现 → 实际观察 → 保留/修复/重设计 → 回写有效方案再展开。开发前明确目标、约束、关键状态/动作关系、衔接与未知，不要求参数预先定稿。

区分已验证、当前假设和可探索细节；允许试制后记录，但成为后续标准或正式评审依据前必须回写。不能把偏离用户目标解释成原计划。局部问题修本场，跨场问题联动相邻场，共同语言问题修总设计，基础假设失败回研究；问题沿[唯一闭环](production-workflow.md#检查与返工循环)，独立失败按原条件复查。

优先检查接触、最大形变、遮挡、镜头切换和文字进入等中间状态，以及最长文字、最小主体、极端数据、高密度和小屏。动态尽早验证连续变化、乱序求帧、材质稳定性与真实成本；按问题选择，不形成每场固定配额。

## 总设计模板

只展示当前有效方案，历史沿原基线、问题和报告引用，不复制研究及制作流水账。

```markdown
# 全片设计
## 目标、事实与硬约束
主题、受众、理解/感受、真实/示意边界与来源。
## 原始要求与选案
相关用户原话、实际媒体、限定范围；作者转化另写。
## 五维共同语言与贯穿对象
视觉/表达/动态/声音/转场的采用、自创或不用；身份和共同规则。
## 结构、节奏与依据
推进、强弱、回报；引用分镜、研究、有效基线和关键未知。
## 场景索引
| scene.id | 叙事作用 | 场景设计 |
|---|---|---|
| opening | 建立问题 | [opening](design/scenes/opening.md) |
```

## 场景模板

复杂场景按镜头和节拍展开，相关方面可合并；示例须换成当前决策。

```markdown
# 场景 opening
## 目标、继承与依据
原始要求/共同规则引用；已验证、假设、可探索范围。
## 对象、构图与视听机制
主体/辅助/环境/文字职责、空间、镜头、动作配合、材质光影。
## 节拍编排
| 节拍/事件引用 | 主体与辅助反应 | 镜头/焦点/光影 | 文字与声音 | 观察预期 |
|---|---|---|---|---|
| 建立 | 对象关系与准备 | 空间和注意力 | 问题/留静 | 可识别关系 |
| 关键事件 | 变化、接触、响应 | 配合与主次 | 揭示/适用同步 | 中间状态 |
| 稳定与离场 | 衰减和观察窗口 | 接入下场 | 阅读/声音延续 | 结果与衔接 |
## 衔接与实现
入口引用前场出口；本场维护出口/下场接入条件。引用分镜事件、代码、台账；成本及未知。
## 验证与有效方案
实际帧/过程/参考、适用量测和结果、限制；问题和原报告只链接。
```

## 结构检查与评审

```powershell
uv run python .agents/skills/material2video/scripts/check_scene_design.py --project <作品>
uv run python .agents/skills/material2video/scripts/check_scene_design.py --project <作品> --scene <scene.id>
```

完整检查对应当前分镜所有场景；局部只要求指定场景及索引，允许已知相邻场景尚未展开，未知或越界链接仍拒绝。检查 ID、文件、非空内容、围栏和 Markdown 内联链接；引用式链接须展开为内联写法，避免未检查却误报通过。拒绝重复、错配与越界，不判断五维语义、阶段完成或审美。检查不接入 prepare/render，纯文档编辑不进入渲染指纹。

完整设计理由留在制作侧，原要求、范围、中性条件与实际参考沿[既有评审](review-contract.md)进入同轮对照，盲包隔离保持。不增逐场独立审核；目标变化更新相关条件与证据，纯文字清理复用有效媒体。静态和局部通过不扩大范围。
