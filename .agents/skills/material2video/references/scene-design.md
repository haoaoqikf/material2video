# 全片与场景设计

本页唯一维护分层职责、模板、详细编排与对应检查。五类共用，设计随实际试制修订；设计文档属于制作依据，**当前不渲染**，不新增 project、分镜或评审字段。

## 分工与对应

| 材料 | 唯一职责 |
|---|---|
| RESEARCH.md | 全片案例的来源、观察与转化，以及全片组件选型、代表试制比较与限制 |
| DESIGN.md | 全片目标、事实与约束、原始要求、选案及基线、信息顺序、共用视听规则、贯穿对象与场景索引。适用时写明关键样片要回答的问题 |
| design/scenes/<scene-id>.md | 本场目标、对象及关键状态、视听配合、衔接、局部实现依据、验证与未知 |
| 分镜、场景代码与准备记录 | 执行时点、参数、实现及实际准备时间轴 |
| 素材台账 | 来源、许可与恢复；设计引用 |
| outputs/visual-notes.md | 唯一问题及修复/复查/关闭记录 |
| 实际媒体、评审窗口与独立报告 | 正式取证范围、原始效果与观察；设计引用适用结论 |

RESEARCH.md、DESIGN.md 和每个正式场景文档固定保留；简化填写和重复记录，不按作品长短省略材料。每个正式场景复用既有 `scene.id` 对应 `design/scenes/<id>.md`，总索引的链接文字使用 scene.id，目标为该文档（写法见下方模板）。场景可以共用代码入口，由分镜关联；镜头/节拍复用已有事件或镜头标识。无完整分镜的草案可以先研究试制，不为检查器伪造分镜。

总设计先写到能判断每场提供的新信息、为何接到下一场、结尾如何回应开头。以已验证视觉方向为依据，标出可能改变全片判断的未知。逐场开发时，再把共用规则和贯穿对象的身份、含义、材质及运动特性落实到画面。前场出口维护具体衔接，后场入口引用接入条件，复查覆盖两侧。正式帧位、坐标、曲线、灯光设置和声音偏移留在执行来源，场景索引用既有 ID 连接各场。

## 从研究到场景决策

引用[全片研究](stage-research.md)中适用的案例结论，落实本场构图、关键状态与衔接。缺少表达依据时，回到同一份全片案例调研补查并标明适用场景。

从本场镜头方案提取实现需求，按[成熟组件调研](visual-components.md#成熟组件调研)核对全片已验证方案和工程内可复用组件。能覆盖本场需求时简短引用并核对实际效果。有具体缺口时补查、试用，在「实现方案」记录查找与取舍，在「验证与未知」记录实际结果。局部结论影响全片选案或跨场复用时，将结论、适用范围和证据链接回写全片研究。

可先画关键状态、列事件或做局部试验，随后回写具体决策。静帧推导按[参考分析](reference-video-analysis.md#只有静帧时的推导)标为假设。

## 按关键机制深化

下列情况触发相应关系的深化，可组合、分镜头或分事件表达；不增加固定章节和创作配额。

| 机制或风险 | 必须解决的设计问题 | 关键观察窗口 |
|---|---|---|
| 因果、隐喻或延迟揭示 | 触发、响应、结果如何对应，变化前后的理解差别；采用延迟揭示时再明确原因先藏在哪里、何时暴露 | 变化前、发生中、结果及识别停留，不能只交终态 |
| 多对象协同或密集场面 | 每个必要对象的职责、当前主导者、响应顺序和安静者；数量如何变成关系、压迫或节奏 | 对象进入、交叠、最密集及注意力交接处 |
| 形变、接触或连续运动 | 形变前后身份线索、约束/连接点、最大变形和遮挡；接触如何传递影响，哪些反应错开 | 接触前后、最大形变、遮挡及身份最易丢失的中段 |
| 材质、光影或运镜承载表达 | 明暗变化由光源、对象、材质还是视角驱动。哪些表面受光、谁遮光、影落在哪，哪个变化揭示轮廓、厚度、反射或空间关系 | 首次揭示、动势或照明最强时、遮挡及光影退去后 |
| 数据演化或比较 | 量由什么编码、基准和尺度是否一致；模型如何驱动图形与读数，何时可以比较 | 极端值、交叉/归队/累加等关键变化及完整阅读窗口 |
| 情绪升级或反转 | 哪个新事件使体验更强，人物/环境怎样响应；释放由什么铺垫和回报支撑 | 转折两侧及必要前文；不能只用夜变昼宣布释然 |
| 跨场连续或风格迁移 | 前场的身份、空间、动作方向、光色或声音如何接入；新内容是否仍由同一视觉机制承载 | 相邻镜头两侧、转场中间及内容最不同的代表场景 |

简单或静态场景可只展开层级、阅读、观察和衔接。没有触发当前机制的方面不必凑内容；已明确的静态任务也不必先增加运动再证明它可省略。

### 什么程度足以指导制作

设计应让实现者知道关键关系怎样发生，让观察者知道何时看哪里、什么现象支持或推翻预期。对照下列不足写法寻找当前缺口，不以关键词和栏目数量判完成：

| 不足写法 | 尚缺的决策 |
|---|---|
| 「压迫感成立」「情绪释放」 | 哪个可见事件改变感受，尺度/空间/姿态/节奏如何配合，前后差别是什么 |
| 「手与影子同步」「数字与图形联动」 | 哪部分对应哪部分，谁驱动谁，中间状态和识别线索是什么；同组平移不证明形变因果 |
| 「缓慢推近」「保持后切走」 | 运镜公开或强化了什么，观察/阅读何时完成，为什么在此切换 |
| 「加材质、尘埃和更多道具」 | 主体、核心过程和构图问题是否已解决；装饰不能补足机制或替代主体吸引力 |
| 「每场建立—关键—稳定三行」 | 事件是否真实改变信息或体验，是否跳过生成过程和关键响应 |
| 「检查因果可读」 | 具体窗口、可观察现象和失败边界是什么；这仍是计划，不是观察结果 |

开发前应明确目标、必要对象关系、关键状态、衔接和待试验的未知；允许对未决技术路径做比较试制，不要求先证明所有假设。准备展开或采用为标准时，须已有相应实际依据。不能把未实现的核心承诺改名为探索细节，也不能靠扩写环境和材质掩盖它。

## 可选讲解机制

按主题可采用具体对象、最小过程、观众尝试、并排比较、可数数量、图表、文字或混合表达。长片可用编年、论证链或问题探索；没有统一章节结构和必须出现的高潮。

| 方向 | 设计落点 | 常见误判 |
|---|---|---|
| 同一对象连续追踪 | 保留轮廓、位置、状态或其他身份线索，让观众认回变化前后 | 同一 ID 不等于画面可认回 |
| 相机与尺度变化 | 从局部到整体公开新关系，区分世界中的变化与相机变化 | 缩小画面不自动产生新认识 |
| 过程与结果联动 | 用共同模型/事件驱动输入、过程和结果，并设计可读的对应关系 | 共用变量不自动证明因果可读 |
| 回场 | 在新语境下认回前面的对象或构图，产生不同理解 | 重放同一张图不自动构成回报 |

实现入口见[讲解机制与已有能力的映射](code-scene-runtime.md#讲解机制与已有能力的映射)。机制可以融合、改造或不用，不新增运行时字段。文字和抽象符号可承担主体；不把去文字测试或具象化设为所有作品的要求。无旁白字幕稿的字段与时间轴见[语音与字幕](prepared-and-subtitles.md#语音与字幕)，示例自绘字幕是作品实现，不是新增共享字段。

## 渐进设计与开发循环

有字幕时，静态检查覆盖实际合成中的最长句、拥挤构图、最亮与最暗背景和手机尺寸。字号、位置、断行变更后复查受影响关键帧，共用样式变化重查上述代表状态。切句时点、停留和口播节奏变更后用有序帧、字幕时序和适用音频信号核查实际动态窗口，按[审核策略](review-contract.md#审核策略)执行适用独立复查。临时字幕仅覆盖试制范围，正式字幕合成后补证。

以[研究与试制](stage-research.md)验证的方向组织全片骨架，优先展开最可能改变方向或跨场组织的场景。逐场明确目标、约束、对象关系、衔接和待试问题，再实现关键部分。根据实绘核对、保留或重做方案，回写结论后继续深化。全片结构或衔接有疑问时，把相关段落串起来预演，覆盖要判断的节奏和连接关系。

区分已验证、当前假设和可探索细节；允许试制后记录，但成为后续标准或正式评审依据前必须回写。局部问题修本场，跨场问题联动相邻场，共同语言问题修总设计，基础假设失败回研究；问题沿[唯一闭环](production-workflow.md#检查与返工循环)。

优先检查接触、最大形变、遮挡、镜头切换和文字进入等中间状态，以及最长文字、最小主体、极端数据、高密度和小屏。动态尽早验证连续变化、乱序求帧、材质稳定性与真实成本；按问题选择，不形成每场固定配额。

### 计划、结果与回写

验证计划写本次要检验的承诺、窗口、显示条件、观察预期和失败边界；实际结果另写当前版本媒体、真实查看范围、现象、兑现部分、方案调整及仍未验证部分。用现有媒体/采集标识和链接追溯，不新增合同或第二份台账。

完成试制后逐一核对影响方向判断的承诺：实现了什么，哪些过程没有发生，哪些构图或实现改变了原判断，下一试验解决什么。把有效对象关系与编排回写本场，共同变化回写总设计，研究推断仍留研究文档。缺失证据写未验证，观察失败沿问题闭环，不用未来检查计划填充「有效方案」。

例如原承诺是手指张开驱动影子下颌，而当前只有手和影子同框并共同平移：可记录同框构图已观察，关节/下颌联动尚未实现或未验证；不能写成因果动作已通过，也不能为迁就实现把原承诺回写成只需平移。

## 总设计模板

只展示当前有效方案，历史沿原基线、问题和报告引用，不复制研究及制作流水账。

```markdown
# 全片设计
## 目标、事实与硬约束
主题、受众、希望观众理解和感受到什么，事实及真实/示意边界。
## 原始要求与选案
相关用户原话、实际媒体、限定范围；作者转化另写。
## 共同视听语言与贯穿对象
记录会影响制作和复核的共同视听决策、贯穿对象身份和规范。
有字幕时写共用字号、位置、单双语层级、安全区和自适应柔光，链接实际配置。
适用关键样片时写待回答的问题，引用必审窗口。
## 结构、节奏与依据
开场问题、信息推进、强弱和结尾回报。引用研究、有效基线和时间轴，标明哪些未知可能改变全片判断。
## 场景索引
| 场景设计 | 叙事作用与新增信息 | 关键事件或交接意图 |
|---|---|---|
| [opening](design/scenes/opening.md) | 提出要回答的问题 | 由开场疑问引入下一场的第一个线索 |
```

## 场景模板

每个正式场景用四问组织。简单场景每问可用一小段，复杂场景把相关模块展开。独立运动或承担叙事的对象逐个写，同规律的对象可合组。按节拍写变化，按对象补单体的完整路径或约束。一个共同事件驱动多项反应时引用同一事件，有接触、延迟或完成条件时写出依赖。

```markdown
# <scene-id> · <场景名称>

## 目标与感受

本场的叙事职责，观众入场和离场的理解或感受，以及继承的要求和参考。

## 画面与注意力变化

入场状态、关键构图和视线顺序。写明出场留给下一场的对象、方向、动作、声音或疑问。

### 对象表（按需）

| 对象或组 | 表达职责 | 初始状态与位置 | 可变属性 | 识别线索或空间约束 |
|---|---|---|---|---|

### 节拍表（按需）

| 节拍或分镜事件 | 触发 | 主导对象变化 | 其他对象的响应或保持 | 镜头、光影、文字与声音 | 观众应看见什么 |
|---|---|---|---|---|---|

### 单对象变化（按需）

| 对象及相关节拍 | 起始 → 关键中间状态 → 结束 | 运动、形变、接触或跟随约束 |
|---|---|---|

### 光影变化（按需）

| 相关节拍 | 光源、对象、材质或视角的变化 | 受光、遮光与投影位置 | 可见效果与表达用途 |
|---|---|---|---|

## 实现方案

引用组件、分镜事件、代码和资源。说明共同驱动或依赖条件，以及要先试的缺口与取舍。

## 验证与未知

- 计划写本次承诺、窗口、显示条件、可观察现象和失败边界。
- 结果写实际版本、查看范围、兑现或调整的部分及证据链接。
- 待确认事项写影响和下一步，已观察问题链接唯一问题记录。
```

构图和镜头部分按需要写景别、焦点、留白、运动空间和遮挡，指明哪些变化来自机位。文字、读数与字幕在相关节拍交代主次、单位或零基准、让位、断句与阅读窗口。声音写起音、让位、同步或留静的作用。单对象变化重点展开路径、速度、接触、最大形变、停稳或余动中影响表达的环节。光影表中的高光、阴影、透射或发光按实际用途选写。静止、无声和直接切换都可以承担明确的表达作用。

[《运气》开场](../../../../examples/principle-metaphor/luck-on-stage/design/scenes/hook.md)展示多对象、动作和动态光影的详细编排。[纪实电话场景](../../../../examples/documentary-edit/american-science-milestones/design/scenes/telephone.md)用短段落回答同样的四问。

## 教学演练：不足描述如何深化

以下均是假设案例，用来演示决策深度，不是已实现方案、实际观看记录或独立通过。各例的过程和工具按当前项目实际验证；不能复制演练的预期当结果。

### 隐喻因果：纸片与墙影

- **不足描述**：「小纸片投出巨大影子，纸片收拢，影子同步消失，恐惧解除。」
- **缺失决策**：光源、纸片与墙的位置关系；纸片哪段轮廓对应墙影；收拢期间发生什么；观众何时识别原因；消失是否只是硬切后的另一张图。
- **充分设计**：先让巨影主导，纸片在次要位置保留可认线索；机位转到能同时看到纸片、光向与墙影的角度，再由纸片的一处折边先移动，墙影相应轮廓变化，其他对象安静。纸片收拢使投影面积缩小，灯和墙保留为空间锚点；收拢后留出对照窗口，最后才给结论。是几何投影还是风格化映射须在实现选择中说明，不能以独立淡出代替承诺的对应变化。
- **验证办法**：核对覆盖揭示前后及完整收拢过程的有序帧，核对具体折边与影子轮廓是否对应、中段是否脱离来源、收拢后空间是否仍可认回。分别观察未出结论文字时的因果和实际整体表现。若只能靠文字知道同源，或中段只有整组平移，核心过程仍未成立。

### 数据关系：收益如何重新参与增长

- **不足描述**：「两组柱子一起长，复利更高，数字同步滚动。」
- **缺失决策**：柱长编码什么、两组基准与单位是否一致；新增收益怎样成为下期基数；观众何时比较；动画与数学模型是否同源。
- **充分设计**：固定同一本金、周期和比较尺度，明确两组的计息口径；先让观众识别本期基数，再显示本期新增收益。复利组用颜色/位置连续性把新增部分纳入下一期基数，单利组保留原基数；对应计算事件驱动柱段与读数，完成归队后才推进下一期。相机在比较窗口保持，必要数值承担精确量，色块承担组成关系；不能用缩放视觉制造更高收益。
- **验证办法**：核对一个完整计息—新增—归队—下一期窗口及相同尺度下的比较，检查模型结果、累计/增量身份、颜色含义、最长读数和阅读停留。读数正确而归队不可见，只支持数值结论，不支持已演示再投入机制。

### 静态文字：一句判断的收束

- **不足描述**：「高级极简标题，淡入后停三秒，留白。」
- **缺失决策**：哪句承担结论、与前场的关系、文字主次、实际阅读负担和切出理由。
- **充分设计**：承接前场已完成的揭示，用一条主判断收束，不在片尾新增论证；如对象名称有必要，放次级层。文字与前场的视觉锚点保持联系，按实际画幅和最终显示尺寸确定版面，完整文字稳定后留够阅读与回味。可直接切入、静止、无声；若采用淡入，阅读窗口从完整可见时计算。
- **验证办法**：看实际字体、最长文案、声明的小屏尺寸及前后衔接，确认层级、完整可见和阅读窗口；不要求去掉文字仍能理解，不为了增加复杂度加入角色或音效。具体停留随文案和体验判断，不照抄固定秒数。

方法参考：[Adobe 动画原则](https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html)关于场面调度、动作准备与跟随；[Pixar Story and Art](https://sciencebehindpixar.org/pipeline/story-and-art)关于叙事分镜、概念美术与动作材料的分工；[IBM 动画原则](https://www.ibm.com/design/language/animation/classic-principles/)关于注意力和动作主次。仅借方法，不将品牌特定的曲线、风格或禁用偏好设为本项目通则。
