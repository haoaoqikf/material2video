# 制作与验收

目标：兑现设计品质，完成当前整片验证并交付。

## 制作迭代

从总设计和当前场景页进入[逐场循环](scene-design.md#渐进设计与开发循环)。材料变化后重新 prepare，复用依赖仍有效的产物和证据。

## 验收交付

合并经局部复查确认的改动，生成整片候选。按[审核策略](review-contract.md#审核策略)核对正式关键帧、适用关键样片及当前技术 QA，优先复用绑定有效的实际合成预演或持久候选证据。

总代理从当前完整候选按全片范围取代表帧，结合时间轴检查开场、推进、跨场节奏、信息重复、结尾及字幕。密集口播、复杂动效、明暗切换、字幕换句和样片未覆盖的高风险窗口用有序帧加密取证；有声时按需要核对 AAC 解码后的响度、真峰值、静音、起音及声画同步等信号。复用 `m2v qa` 证据，必要时用 `m2v assets contact-sheet --input <候选.mp4> --times <秒数列表>` 从同一候选补帧。无需播放观看或试听；按实际证据写明验证范围和限制，不能据此保证主观听感或实时观感。

通过后用[整片复核登记](review-protocol.md#正式窗口与整片复核)记录当前候选摘要、核查帧窗及具体结论。候选换版后重做整片复核，已审局部按影响保留或复查。总代理核对独立证据的覆盖、目标忠实性和具体差距。独立失败按同用途、同范围独立复查关闭。事实、来源、许可及必要可读性由总代理核验，素材重复与必要回放按[素材使用](material-sourcing.md#同一成片内的素材使用)核查。

交付同一已验候选，报告覆盖、限制与来源，见[交付与溯源](delivery-and-provenance.md)。
