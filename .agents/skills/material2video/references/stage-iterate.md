# 制作与迭代

首要问题：核心关系是否成立，当前问题如何修复，能否扩展到完整作品？

## 必做

1. 读取当前审核计划、问题清单与有效证据，先验证未决核心风险。修订先按[修订入口](video-revision.md)定位影响范围与基线，不重开无关选案；不因镜头等级机械增加评审。
2. 按[完整段落试制与逐段扩展](production-workflow.md#完整段落试制与逐段扩展)，同一段材料依次完善连续构图、动态实现、检查修订与适用独立复查；以实际主体、字体、文字、关键动作及必要声音试制最难关系；优先验证对象认回、局部整体、过程结果与回场，按[四种机制](explainer-design.md#四种讲解机制的执行方法)选用。窗口覆盖建立、变化、揭示与停留；占位资产只支持其覆盖的技术判断。
3. 核心独立评审按[隔离执行](subagent-review.md#讲解机制的隔离观察)先落盘对象、变化、结果、画面与字幕各自贡献及疑问何时解答，再对照中性目标；按[实际表达](visual-review-rubric.md#讲解关系的观察)判断。核心通过只授权已验证范围。
4. 铺开前把开场连续一段做成实际画面并留存帧，按[看图诊断](explainer-design.md#一症状--成因--改法)核对主体可辨、字幕后对应动作、字幕区清空与场景连续承接；未过不进入其余段落正式实现。能与核心风险同窗覆盖时复用同一试制，覆盖不足分别补足；不新增用户审批或审核轮次。
5. 通过的试制保留为作品的一部分；逐段按[内容边界与时间线安排](production-workflow.md#每段完成一个关系)实现并修订构图、尺度、时序、正式美术、文字、资产与声音；按[贯穿对象与完整动作](explainer-design.md#贯穿对象事件和完整动作)检查关联事件、连续行为及观察窗口，改时刻时复核受影响画面、读数和声音。保持事实、许可、模型和画面一致。修改落在可编辑材料，生成产物不能代替源码或用改后 MP4 冒充修订；材料变化后重新 prepare。
6. 扩展后由制作助手完成 G5 全片内部检查，记录实际检查范围、问题 ID 和未覆盖限制；不提交逐检查点的重复通过说明，也不派独立代理。它是本阶段内部节点，不再交接到精制阶段。结构或核心表达存在未决风险时按审核计划补充针对性独立评审。
7. 按[检查与返工循环](production-workflow.md#检查与返工循环)用实际画面修订设计，沿唯一问题清单记录时间范围、修改目标、修复收益及表达损失；正文区分已修改待复查与效果已确认，实际查看修改后的证据再推进。按问题选工具，不例行运行全部预览；有效且满足范围、依赖与隔离要求的证据可复用，不抄写多份报告。再次生成按[收敛判断](production-workflow.md#再次全片生成前的收敛判断)汇总；逐段检查强度按[每段完成一个关系](production-workflow.md#每段完成一个关系)执行。
8. 同一完整窗口与显示条件下复查本窗及相邻衔接；有目标图先盲看后同轮对照。连续两轮同类修复无改善按既有策略比较不同机制或剪辑；目标或主线变化按[回退路径](production-workflow.md#核心样片与全片粗片的回退决策)重做受影响独立验证，保留失败历史。

## 证据与完成

动态核心须有可探测视频流、正时长，至少一段覆盖检查窗，容差一帧，不累加短片；记录有序帧、显示尺寸及声音覆盖限制。工具只证明最低容量，不证明窗口对应或讲解成立。

全部场景、字幕与适用声音完成；适用核心风险、G4 检查和 G5 全片内部检查已覆盖；设计目标兑现、阶段必改项已复查关闭，才进入最终验收。G4/G5/G6、人数、轮次和关闭规则只按[检查点契约](checkpoint-gates.md)。自审、技术通过、同一状态或目标图一致不能替代适用独立复查，排错成功不等于制作完成。

## 排查按需展开

- 场景、字体、ready、时钟、相机：[运行时](code-scene-runtime.md)；细线、轨道或保持段见同页按需排错。
- 源文、分镜、时间轴：[材料](stage-plan.md)与[分镜](storyboard-schema.md)。
- 素材、声音、许可：[素材声音](article-media-and-sound.md)；旁白变化另读[配音](voice-and-rhythm.md)。
- 证据、评审和问题关闭：[检查点](checkpoint-gates.md)与[独立评审](subagent-review.md)。命令查 README 和实际 --help。
- 运动设计、转场、入场退场与缓动：[运动设计](../../motion-design/SKILL.md)与[视频适配](../../motion-design/ADAPTATION.md)。
- 构图、色彩、字体、留白与视觉重心：[Frontend Design](../../frontend-design/SKILL.md)与[视频适配](../../frontend-design/ADAPTATION.md)。
