# 制作与迭代

首要问题：核心关系是否成立，当前问题如何修复，能否扩展到完整作品？

本阶段只做四类决定；方法读 skill，项目文档只保留证据与完成条件。

| 验证什么 | 用什么证据 | 何时读 skill | 失败怎么办 |
|---|---|---|---|
| 核心关系与完整事件窗 | 有序帧序列、风险加密帧、路径/屏幕量测、适用声音 | [运动设计](../../motion-design/SKILL.md) 看运动，[Frontend Design](../../frontend-design/SKILL.md) 看构图与层级 | 补证、局部修复或退回设计；不以技术通过关闭 |
| 开场与主体可辨 | 首三秒有序帧、手机尺寸帧、实际素材与正式文案 | Frontend Design 的观察顺序 | 重做开场主体、动作或疑问 |
| 信息推进与节奏 | 全片粗预演、时间标注帧序列、等待用途 | 项目[视觉创意导演方法](visual-creative-direction.md)与运动 skill | 删短、重排、换机制；不用装饰运动填充 |
| 问题是否真正关闭 | 当前版本、原条件、同范围复查、唯一问题 ID | — | 未复查保持待复查；两轮无改善升级 |

## 必做

1. 读取当前审核计划、问题清单与有效证据，每周期先验证完整试制窗口及未决核心风险。修订先按[修订入口](video-revision.md)定位影响范围与基线，不重开无关选案；不因镜头等级机械增加评审。
2. 按下方[核心试制与逐段扩展](#核心试制与逐段扩展)，同一段材料依次完善连续构图、动态实现、检查修订与适用独立复查；以实际主体、字体、文字、关键动作及必要声音试制最难关系。优先验证对象认回、局部整体、过程结果与回场，按[四种机制](explainer-design.md#四种讲解机制的执行方法)选用。
3. 试制固定独立评审按[隔离执行](subagent-review.md#讲解机制的隔离观察)先落盘对象、变化、结果、画面与字幕各自贡献及疑问何时解答，再对照中性目标；按[实际表达](visual-review-rubric.md#讲解关系的观察)判断。核心通过只授权已验证范围。
4. 铺开前把开场连续一段做成实际画面并留存帧，按[看图诊断](explainer-design.md#一症状--成因--改法)核对主体可辨、字幕后对应动作、字幕区清空与场景连续承接；未过不进入其余段落正式实现。
5. 通过的试制保留为作品的一部分；逐段按下方试制方法实现并修订构图、尺度、时序、正式美术、文字、资产与声音。修改落在可编辑材料，生成产物不能代替源码；材料变化后重新 prepare。
6. 扩展后由制作助手完成 G5 全片内部检查，记录实际检查范围、问题 ID 和未覆盖限制；不提交逐检查点的重复通过说明，也不派独立代理。结构或核心表达存在未决风险时按审核计划补充针对性独立评审。
7. 按[检查与返工循环](production-workflow.md#检查与返工循环)用实际画面修订设计，沿唯一问题清单记录时间范围、修改目标、修复收益及表达损失；正文区分已修改待复查与效果已确认。连续两轮同类修复无改善按既有策略比较不同机制或剪辑；目标或主线变化按[回退路径](production-workflow.md#核心样片与全片粗片的回退决策)重做受影响独立验证。

逐段落实[整场细节](scene-detail-design.md)，同窗分看关系与表现：文字图标、点缀回应、强弱及重复配方；参考/重制比较同用途片段与基线，不新增轮次。

## 证据与完成

动态核心须有覆盖检查窗的过程片段，容量与探测口径见[独立评审](subagent-review.md#评审包)；记录有序帧、显示尺寸及声音覆盖限制。关键运动节拍（入场、离场、减速与落点、转场衔接）须按幕内事件登记，采样步长不得大于最短待判断运动节拍；`look.motion` 的子帧与 SSAA 只影响采集质量，不构成运动设计证据。工具只证明最低容量，不证明窗口对应或讲解成立。

全部场景、字幕与适用声音完成；适用核心风险、G4 检查和 G5 全片内部检查已覆盖；设计目标兑现、阶段必改项已复查关闭，才进入最终验收。G4/G5/G6、人数、轮次和关闭规则只按[检查点契约](checkpoint-gates.md)。自审、技术通过、同一状态或目标图一致不能替代适用独立复查。

## 核心试制与逐段扩展

先选最高风险完整窗口，明确初态、原因、变化、结果、手机尺寸与理解/表现失败条件；按实际需要写关键时点和容差，不固定秒数。同一段材料依次完善连续构图、动态实现、检查与修订，试制通过后留在作品中继续完善。优先兼顾开场；无法兼顾时分别验证。实际资产、字体、文字、关键动作与必要声音用于正式放行；占位只证明已覆盖的技术范围。适用独立目标图按[目标图契约](checkpoint-gates.md#独立目标关键帧)，不能用代码截图冒充。

每段围绕一个关系安排画面、字幕、声音与观察时间，可画面先演、字幕后揭示或合理重叠，不设固定延迟或空白比例。各段与前后镜头承接，原型不是另一份同用途样片。先处理重心/层级，再处理材质构图、运动和细节；正常通过只链接报告，不为记录而修两轮。G5 检查跨场主线、开场承诺、重复、节奏与结尾回报，局部通过不能代替全片检查。

## 返工升级

沿原问题 ID 写修改假设，局部修复后实际查看本窗与衔接；核心风险关闭前不扩展依赖实现。重要返工记录收益与表达损失。同一问题连续两轮无改善时，停止参数微调，匿名比较不同机制、删短或重排；根本失败立即按[回退规则](production-workflow.md#核心样片与全片粗片的回退决策)处理，不等两轮。没有用途的等待优先删短，不加装饰填充。

## 排查按需展开

- 场景、字体、ready、时钟、相机：[运行时](code-scene-runtime.md)；细线、轨道或保持段见同页按需排错。
- 源文、分镜、时间轴：[材料](stage-plan.md)与[分镜](storyboard-schema.md)。
- 素材、声音、许可：[素材声音](article-media-and-sound.md)；旁白变化另读[配音](voice-and-rhythm.md)。
- 证据、评审和问题关闭：[检查点](checkpoint-gates.md)与[独立评审](subagent-review.md)。命令查 README 和实际 `--help`。
- 运动设计、转场、入场退场与缓动：[运动设计](../../motion-design/SKILL.md)与[视频适配](../../motion-design/ADAPTATION.md)。
- 构图、色彩、字体、留白与视觉重心：[Frontend Design](../../frontend-design/SKILL.md)与[视频适配](../../frontend-design/ADAPTATION.md)。
