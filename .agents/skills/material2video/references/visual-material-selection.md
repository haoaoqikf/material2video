# 视觉素材选择与使用

本页是视觉素材选择与使用的权威入口：说明选什么、为什么选、怎样用于表达，以及何时替换。主要用于 general 的外部素材、代码与混合画面；金融沿用各自专用材料和画面契约。本页整理既有制作规则并补充操作指导，不新增制作阶段、分镜字段、素材配额或 CLI 门禁。

技术操作见[媒体导入、来源与声音契约](article-media-and-sound.md)，整体叙事与美术设计见[视觉创意导演方法](visual-creative-direction.md)，评审方法见[视觉复核](visual-review-rubric.md)，已有作品的修改见[视频修订入口](video-revision.md)。检索词、候选评估卡、许可决策与台账工具的具体操作见[素材检索与台账](material-sourcing.md)。

## 先确定素材的叙事任务

逐场先用一句话说明观众要看懂什么，再选载体。不要仅按旁白名词寻找装饰画面。

| 任务 | 选择时要回答的问题 |
|---|---|
| 事实证据 | 是否为对应人物、地点、年代和事件的原始记录？画面能支持多大范围的结论？ |
| 对象识别 | 观众能否迅速认出讲述对象？是否需要展示实物、界面或静态原件？ |
| 过程展示 | 哪个动作、变化与结果必须实际可见？候选片段是否包含完整过程？ |
| 机制与关系 | 真实画面是否足够解释？是否需要代码呈现不可见的结构、数量或因果？ |
| 情绪与过渡 | 素材怎样改变感受或承接上下段？若删掉它，是否损失信息或体验推进？ |

## 载体选择

整体先定政策，逐场再选实例；整体叙事与构图仍按[视觉创意导演方法](visual-creative-direction.md)执行，具体载体判断以本页为准。

- **用外部素材**：观众需要相信「这是真实的人、事、物、地点或数据原件」，或真实质感就是记忆点；所需变化在素材里看得见；许可、来源、原生尺寸与时长满足。
- **用代码**：对象不可见、不存在、过大过小、危险或昂贵；重点是机制、数量、关系、时间或反事实；需要精确控制镜头、运动与时间。
- **混合**：真实素材做锚点，代码揭示看不见的机制；真实与示意的边界只声明一次，不逐幕堆注释。
- **硬边界**：不得用图库素材冒充真实事件、人物或地点；不得用代码动画伪造证据或实验结果；明确禁止当前用途或使用条件未满足时更换素材；档案不冒充 4K，原理动画明确标注示意。许可未知如实记录，不单独排除，采用政策按[素材操作手册](material-sourcing.md#5-采用政策与署名)。

整体政策写进 `DESIGN.md` 的「表达载体」，逐场实例写进逐场设计表的「载体来源与理由」。无论选哪种来源，外部素材进入作品仍只走[媒体导入契约](article-media-and-sound.md#媒体进入作品的唯一路径)。

### 视频优先与代码适用场景

先按表达目的选择外部素材、代码或混合载体。默认运动载体顺序是**真实视频 → 代码动画/示意 → 静态图片**；图片不是缺省的运动替代品：

1. **外部素材先找视频**：真实人物、地点、历史事件、生产过程或自然景象等需要外部素材时，优先检索合适的视频。合适意味着内容支持具体叙事、关键动作可见、画质与时长满足、实际裁切后构图可用，且来源与采用依据已检查；不能只因题材相近就采用无关动态。
2. **图片只作最后手段**：视频检索未找到满足上述条件的素材时，先判断能否用代码动画/示意表达；仍不适合时才使用图片，并在现有「载体来源与理由」中简记回退原因。静态图片只承担静态原件、识别或质感，**不得用推拉、缩放或轻微位移把静帧伪装成视频**；需要可见运动时改用视频或代码。
3. **静态原件可直接用图片**：照片、文献、海报等静态原件本身就是表达对象时，直接采用对应图片，无需机械地先找视频；仍不得把静帧包装成动作事件。
4. **适合代码的场景直接合成**：界面交互、操作过程、数据变化、机制、关系或时间演变，需要精确控制动作与反馈时，可直接代码合成，无需先检索外部视频。例如代表谷歌搜索，可用「搜索框出现 → 输入关键词 → 点击搜索 → 展示结果」推动叙事；若讲述某次真实搜索结果或产品的具体历史状态，则必须有对应真实材料依据，示意不得冒充证据。
5. **按需要混合**：真实素材提供锚点，代码揭示机制或关系，共同服从本片视觉语言；真实与示意边界沿用上文规则。

通用素材用于公司、产品或产业段落时，以持续可见的「示意」次要边界标注说明非实拍性质，不得冒充实拍事件、公司自有产线或具体型号；该标注按[项目约定](../../../../AGENTS.md#修改规则)以手机横屏不可辨、大屏可辨为目标。不设置视频占比；逐场按表达效果判断。既有制作评审检查素材是否支撑表达、图片替代是否合理、代码是否呈现必要过程，结合实际完整表达窗口验证；自动校验器不判断载体的审美适用性，不新增分镜字段或 CLI 门禁。

## 检索与停止条件

先列出所需对象、动作、年代、地点及可接受的替代表达，优先查找原始发布者、档案机构、研究机构或对象的官方来源；图库可用于适当的示意画面。来源身份不能代替逐项核对内容与使用许可。

检索词写法、来源层级与候选评估卡见[素材检索与台账](material-sourcing.md#3-检索词怎么写)；接触表命令用于一次看完候选的建立、动作与结果。

检索词从具体对象与动作组合开始，按候选缺口调整别名、语言、年代、地点或来源范围。只看标题和缩略图不能证明素材适用；检索结果页也不能代替来源页与实际媒体。

调整检索后仍不能满足叙事、质量或许可条件时，按上文载体规则选择替代表达，必要时回到设计修改；不为凑视频采用无关片段，也不无限检索等待完美素材。证据型内容拿不到对应原件时，不能以图库或代码伪造证据。没有实际访问或检索就如实记录缺失，不编造候选、观看或许可结论；不规定固定检索次数。

## 检查实际可用片段

采用前检查实际使用区间与前后边界，而非只看单帧：主体和关键动作是否清楚，建立、动作、结果是否完整，片段内部有无突然切镜、遮挡、黑帧或不适合本片的文字。按项目既有方式检查时间标注帧序列，动态风险处加密取帧；静帧证据不能证明动作连续或节奏成立，证据不足就继续检查或换素材。

核对原生尺寸、帧率与时长是否足够实际用途，检查水印、烧录字幕、台标和素材自带文字是否影响构图、阅读或使用条件；不要移除来源标记来掩盖来源，也不要把放大后的档案宣称为原生高清。低分辨率档案是否适用由实际显示效果判断，不强制统一尺寸。

素材声音单独判断：环境声、对白或音乐是否有表达作用，是否已有适当来源和使用依据。不要因为采用画面就默认采用原声；实际声音声明、导入和混音沿用[声音契约](article-media-and-sound.md#声音)。

## 画幅与裁切

素材比例不必匹配成片画幅。先在目标构图中检查主体、动作路径、必要原件文字和字幕空间，再决定裁切、留边、局部布局或换素材。不能只因素材横竖比例不同而淘汰，也不能强行铺满造成主体变形或关键动作出框。

在原始尺寸与声明的手机观看尺寸检查实际使用窗口：画面变化后主体仍应可辨，必要细节不能只在某一帧可见。裁切后的原件若可能改变理解，应保留足够上下文或改用完整原件与局部细节的组合；不能用裁切改变事实含义。比例与取用技术见[素材比例](article-media-and-sound.md#素材比例)。

## 素材与时间编排

把关键动作或信息揭示对齐对应讲解节点；有旁白时按旁白推进，无旁白时按画面文字与事件节奏推进。为观众保留识别对象、看清变化和理解结果的时间，不能为了卡时长切掉关键因果，也不靠无用途等待填满窗口。

变速、倒放、循环和重排都可能改变观众对事实的理解。需要采用时核对事件含义、动作连续性、声音和相邻衔接，不把重复播放表达为多次真实发生，不用倒放或重排伪造过程。素材自身切镜与本片切镜一并检查，避免突兀跳切或主体重复出现造成误解。

## 图片的使用

图片承担静态原件、对象识别或质感时，应让观众看清具体对象与必要细节。完整原件与局部放大可以组织阅读顺序；局部裁切应可追溯到原件，不增改证据内容。

需要真实动作或可见过程时，按载体规则选择视频或代码。图片的展示和阅读引导不能被当作图中对象实际运动的证据，不为追求“有动效”而添加无叙事作用的运动。

## 混合表达与视觉统一

真实素材建立对象与情境，代码补充不可见机制、关系或数量；交接时保持主体、空间关系或问题的连续，让观众知道动画解释的是哪一部分。代码标识、图形与素材应服从同一焦点与观看顺序，不遮挡关键证据或动作。

色彩、清晰度、文字、镜头运动和转场按整片视觉语言协调；允许历史档案保留颗粒、黑白与原始比例，不为统一风格过度处理而损坏细节。真实与示意边界必须清楚，不用真实素材给虚构结论背书；边界标注与片尾署名遵循[项目画面注释规则](../../../../AGENTS.md#修改规则)，不逐幕堆叠解释文字。

## 事实、来源与许可

逐项核对人物、地点、年代、事件和产品版本，区分对应事件实录、通用图库示意、重建和生成内容。代表某类产业的画面不能自动证明某家公司拥有该产线；界面示意也不能证明某次真实搜索结果或历史产品行为。

采用前检查来源页与适用条款，按[采用政策](material-sourcing.md#5-采用政策与署名)记录当前用途、改编与署名条件。未知字段如实登记；检查后未发现明确禁止可采用，不能写成已获授权。原始素材、页面依据、作者、许可与改动按既有导入契约留证。参考作品用于分析不等于获得入片授权，其中独立素材应追溯原始发布者再评估；参考素材与受控例外见[媒体契约](article-media-and-sound.md)。

完整来源保存在作品材料，成片沿用一份简短片尾署名及必要的示意边界标注。来源记录与实际采用文件须一致，不通过修改摘要或来源信息来接受漂移。

## 选择记录与替换复核

整体政策写进现有 `DESIGN.md`「表达载体」：证据型、解释型或混合型，哪些必须真实、哪些需要解释，真实与示意如何区分，以及可得性、许可与视觉语言。按未决问题比较叙事候选时，各案分别说明载体组合、哪些必须真实、哪些需要解释，以及可得性与许可风险；用户方案足以执行时不因此重开选案。

逐场在「载体来源与理由」简记叙事任务、采用来源与素材 ID、选择依据、所需变化是否可见、许可与实际用途；按载体规则记录图片回退原因。整体政策与逐场选择冲突时回到设计调整，不就地放宽要求，不新增独立表单或 JSON 字段。素材较多时用 `m2v assets report` 核对三处台账，用 `m2v assets contact-sheet` 复核候选窗口；两者只报告，不替代 prepare 与审计。

替换素材前按[修订入口](video-revision.md)保护旧版并定位影响；替换后核对来源许可、裁切布局、关键动作、入出点、时长、字幕／文字、声音和相邻衔接。素材与映射变化后重新导入或准备，按现有状态与指纹重做实际过期的证据；不能因为只换一个文件就声称其他证据全部有效，也不重开无关选案。

既有制作评审先盲看完整表达窗口，再按既定隔离流程核对中性目标和素材记录。检查采用素材是否支持表达、图片替代是否合理、代码是否呈现必要过程；未访问的素材或未覆盖的区间如实记为证据不足，不以作者解释代替画面。独立性、技术检查与最终复核继续按[视觉复核](visual-review-rubric.md)和[导演审查](visual-review-rubric.md)执行。

## 典型场景选型

以下为选型演练，不代表素材已取得、导入或通过评审。

| 场景 | 合适的载体与检查重点 |
|---|---|
| 代表谷歌搜索 | 代码呈现搜索框、输入、点击与反馈；具体真实结果或历史界面须有原始依据 |
| 讲某次真实发布会 | 对应事件的视频；核对人物、日期及所用片段，不用其他活动代替 |
| 分析历史报纸 | 直接用原件图片，先建立完整原件再引导阅读相关局部，保留语境 |
| 解释工厂生产 | 视频展示实际工序，代码补内部机制；通用产线不得冒充指定公司实录 |
| 比较数据变化 | 代码按有依据的数据呈现变化，必要时以真实素材建立对象感 |
| 跨尺度天体旅程 | 代码呈现尺度、路径与关系；观测原件可直接使用图片，模拟运动不冒充实拍 |

## 常见错误与替代做法

| 常见错误 | 替代做法 |
|---|---|
| 按名词贴无关视频凑动态 | 明确本场动作或结论，换能支持表达的片段，或按载体规则调整方案 |
| 反复推拉静帧代替过程 | 静态原件按阅读需要展示；动作与过程用合适视频或代码表达 |
| 动作、字幕与旁白错位 | 以关键事件重新安排入出点和停留，复查完整窗口及相邻段落 |
| 任意循环、倒放或变速改变事实 | 保留过程含义；不能成立就换片段或改表达，不靠剪辑伪造事件 |
| 代码界面冒充真实记录 | 区分示意与证据，涉及真实状态时使用对应原始材料 |
| 只凭许可标签、缩略图或技术通过采用 | 核对来源与实际片段，并完成既有画面、动态和许可复核 |
