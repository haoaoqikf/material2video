# 参考风格契约与同族复核

用户明确要求某个作品借鉴一条参考视频的**风格**时，按本文执行。本文只规定创作流程与证据，不新增 CLI 命令、运行时字段或自动审美阈值。

## 什么时候触发

- 用户说「借鉴这个视频的风格」「做成这种质感」「参考它的画面」，或给出参考作品并要求「像它」。
- 用户要求「拆解」「学习」「为什么有效」但未要求外观相同时，按[参考视频逆向拆解](reference-video-analysis.md)执行；本文只在需要量测外观时叠加。
- 用户只要求复用参考音频时，不属于风格借鉴，按[复用参考音轨](article-media-and-sound.md#复用参考音轨受控例外)执行。

## 已登记的外部参考项目

用户点名 material2video 已登记的外部参考项目（当前为 `vibe-knowledge-film` 的夜曲/寓言）时，先读[外部参考项目登记](external-reference-projects.md)确认来源、固定 commit、许可与受限项，再读对应的[项目制作指引](external-reference-projects.md#vibe-knowledge-film-项目使用指引)。

这些登记**不是风格包**：不通过 `project.json` 的 `style.id` 选择，`m2v styles` 不显示，渲染链路不读取；外观仍按本文的 L1/L2/L3、八项指标与画幅转译执行。参考画面、字幕、贴图不得进入成片，受限资产不得复制。

## 两条边界不能混

| 边界 | 规则 |
| --- | --- |
| 素材边界 | 参考画面、字幕、贴图不得进入成片；渲染链路不读取 `refs/`。这条不因任何授权改变。 |
| 创作边界 | 参考的视觉语言必须被拆解、量化并转译。画面原创不等于画面不参考。 |

音轨复用授权只覆盖音频，不扩大画面授权。

## 第零步：先拆解，再量测

用户要求借鉴或学习参考时，先按[参考视频逆向拆解](reference-video-analysis.md)提炼观看驱动力、视觉事件与可迁移规则，再用本文的三层与八项指标把外观转译成本片目标。用户只要求「看起来像」、不涉及机制学习时，可以直接执行本文，但契约中仍要写明采用的底层机制，或明确写「仅外观，不采用机制层」。

八项指标回答「像不像」，不回答「为什么有效」。只对齐外观而没有机制结论，视为拆解未完成；只写机制而没有数值与差值，视为风格契约未完成。

关键采用项还要区分外观、讲解机制、镜头组织与声画节奏，记录实际采用和不采用的范围；
不要求四类全选。在现有借鉴范围与 DESIGN.md 逐场记录中关联完整证据窗口，方法见
[四种讲解机制](explainer-design.md#四种讲解机制的执行方法)。只借外观时明确声明，不默认继承机制。
方法写进指导、外观指标接近，都不证明机制已兑现；承诺采用却未实现的核心项按
[关闭规则](checkpoint-gates.md#讲解机制与关键采用项的关闭)处理，不能仅披露为风险后继续视为完成。

## 第一步：借鉴分层

「风格」至少包含三层。开始制作前选定采用层，最多三项，并逐项写理由。

| 层 | 内容 | 证据形式 |
| --- | --- | --- |
| L1 视觉语言 | 主体尺度、留白、光源、线条与材质、背景质感、机位与运动、文字位置 | 八项指标数值与并排基准 |
| L2 节奏结构 | 段落长度、信息释放顺序、剪辑点密度、动作快慢 | 剪辑点表与 2 秒样片 |
| L3 情绪调性 | 安静/紧张、克制/热烈、距离感 | 冷审描述与反目标清单 |

选定 L1 就必须产出八项指标；只写「气质一致」不算完成。

同时写**不借清单**：参考中的具体符号、场景、文案、分镜一律列出，明确替换方案。借语法不借符号。

## 第二步：拆出八项指标

按叙事段的首、中、尾各取一帧，总数不少于 8 帧；涉及运动时另取连续 1 秒帧。判断线宽、字号、材质时必须看原尺寸帧，不能用缩略接触表代替。

| 指标 | 定义 | 测量方法 | 记录项 |
| --- | --- | --- | --- |
| 主体尺度 | 主要对象的可见高度占画高 | 对象包围盒高度 / 画面高度 | 百分比，手机尺寸下复核 |
| 空场率 | 无主体、无文字的区域占比 | 取四角中位数为主色，与主色距离超过 ΔRGB 24 的像素视为内容 | 百分比 |
| 线宽 | 主要轮廓的笔画宽度 | 原尺寸帧量取，再按最终显示宽度折算 | 源 px、显示 px |
| 光源 | 数量、面积、方向、色相 | 暖色相（HSL 20°–60°）且高亮像素占比；标注光源位置 | 个数、面积百分比、方向 |
| 背景质感 | 纯色、渐变、云纹或颗粒 | 背景区域局部亮度标准差；纯色 < 2，云纹约 2–8 | 类型与强度 |
| 机位与运动 | 固定还是推拉摇移；主体位移速度 | 逐段标注运镜；连续帧主体位移 / 时间 | 类型、速度 px/s |
| 剪辑节奏 | 剪辑点数量、间隔、段长 | 场景切换检测或逐帧查看 | 剪辑点数、平均段长 |
| 文字 | 层级数、字号、位置、停留时长 | 原尺寸帧量取字号与基线；逐条记录停留 | 层数、字号/画高、基线位置、秒数 |

八项之外（材质细节、色彩微差、字体气质）归入 L3 冷审描述，不做数值契约。

## 第三步：画幅转译

横屏参考转竖屏成片（或反向）时，不能按源文件像素照搬，也不能把横屏构图直接裁切。

1. **占比类指标**（主体尺度、空场率、光源面积）按占画面的比例转译。允许 ±3 个百分点的观感补偿；补偿要写理由。
2. **厚度类指标**（线宽、字号）先按比例折算，再用最终手机显示尺寸复核可读性。线宽低于编码稳定下限时允许加粗，并在契约中记为补偿项。
3. **位置类指标**（文字基线、主体位置）按安全区与画面分区重新安置，不沿用源画幅坐标。
4. 转译后在 393 宽（或作品声明的手机显示尺寸）下复核：主体可辨、文字可读、光源方向一致。

示例：参考为 1920×1080、主体占画高 12%；成片为 1080×1920。主体目标取 14%–16%（竖屏补偿，画面更窄，同比例下主体观感偏大）；文字若参考为 3.7% 画高，成片取 3%–3.5% 并落在 `subtitleSafeArea` 上方。

## 第四步：写风格契约

在作品 `outputs/style-reference.md` 建立契约。模板：

```markdown
# 参考风格契约

## 借鉴范围
- 参考作品：<平台 / 作者 / 链接 / 抓取时间>
- 采用层：L1 视觉语言（主）、L2 节奏（次）
- 采用的底层机制：<来自参考拆解的规则与本片落点>
- 不借：<符号、场景、文案、分镜>
- 参考采样帧：<文件与时间码>

## 八项指标
| 指标 | 参考值 | 本片目标 | 实际 | 差值 | 例外说明 |
| --- | --- | --- | --- | --- | --- |
| 主体尺度 | | | | | |
| 空场率 | | | | | |
| 线宽 | | | | | |
| 光源 | | | | | |
| 背景质感 | | | | | |
| 机位与运动 | | | | | |
| 剪辑节奏 | | | | | |
| 文字 | | | | | |

## 画幅转译
- 源画幅 / 成片画幅：
- 折算基准（手机显示尺寸）：
- 补偿项与理由：

## 风格基准
- 并排图：<outputs/style-reference/compare-*.jpg>
- 2 秒样片：<路径>
- 冷审结论：同族 / 不同族
- 差异项与处理：
```

「实际」与「差值」两列必须回填。缺这两列，契约只是愿望清单。

## 第五步：按风险计划安排验证

风格契约、基准、样片与同族判断的适用性、时点及评审人员，均按作品风险计划和[检查点策略](checkpoint-gates.md#审核计划与风险触发)安排，不在本页另设固定轮次或全片门禁。采用项须事先区分关键要求与允许偏离项；尚未验证的关键项通过 `reviewPlan.risks` 的 `reason/requiredEvidence` 引用本契约。不同族结论须逐项核对关键要求：违反关键采用项保持未完成，非关键偏好不自动否决；不能由制作者事后把核心失败改称“有意偏离”直接关闭。代表样片、失败分流及两轮无改善处理见[制作流程](production-workflow.md#核心样片放行与失败处理)。


## 第六步：按适用评审方式判断同族

只有审核计划要求同族判定或相关独立评审时，才按[审核策略](checkpoint-gates.md#审核计划与风险触发)安排人员与时点，并遵守[独立子代理评审](subagent-review.md)的隔离要求；本节不额外增加评审轮次。适用时，评审者只接收并排图与显示尺寸，不接收 `DESIGN.md`、风格契约和旧结论。结论按[自主视觉复核](visual-review-rubric.md)的证据要求记录：

1. 冷审者先只看并排图，不看 DESIGN.md 与风格契约。
2. 先描述：两边的主体多大、光从哪来、画面密度如何、文字几层。
3. 再判断：是否属于同一视觉族。
4. 不同族时列出具体差异项（尺度差多少、光差在哪、文字层差几级）与处理方式；不接受「感觉不像」。

适用评审的结论写入 `outputs/visual-notes.md` 的「独立评审记录」区块，含并排图链接、显示尺寸、执行方式、评审者、投喂文件、隔离条件、结论与差异项；是否影响阶段完成只按对应检查点合同判定。

## 常见失败模式

| 失败模式 | 表现 | 正确做法 |
| --- | --- | --- |
| 只抄配色 | 深蓝底、同色点缀，但尺度、光、运动全不同 | 按八项指标逐项对齐 |
| 把「气质一致」当完成 | 契约只有形容词 | 必须填数值与差值 |
| 横屏构图硬裁竖屏 | 主体被切、留白消失 | 按画幅转译规则重新安置 |
| 用缩略图判断细节 | 线宽、字号、材质全看不准 | 看原尺寸帧 |
| 照搬参考的信息量 | 参考只有 6 句字幕，本片塞 10 个标签 | 借观看方式，不借信息密度；文字层 ≤3 |
| 把「画面原创」当「画面不参考」 | 只复用音频，视觉另起一套 | 素材不入片，视觉语言必须转译 |
| 用一帧判断机位 | 只看一张图就写「固定机位」，参考其实有缓慢推近 | 跨帧比对同一结构元素的横坐标：首尾帧差值超过 3% 画宽即视为有运镜，再量推近倍数 |
| 并排图不对阶段、不含文字 | 开场帧还没出字幕，冷审记录「MINE 无字幕」这类伪差异 | 三张并排图各取叙事同一阶段（开场 / 堆积 / 收束），且都带字幕；无字幕作品在评审包里注明 |
| 自审代替冷审 | 制作者自己看并排图说「像」 | 换独立子代理，先描述后判定；不具备时降级并披露 |
| 为凑指标牺牲可读性 | 竖屏主体缩到看不清铭牌 | 写例外与补偿，核心理解问题不得降级 |
