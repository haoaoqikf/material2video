# 全片导演审查与剪辑重组

本页配合[逐场设计与独立验收](visual-creative-direction.md)与[自主视觉复核](visual-review-rubric.md)
执行。逐场检查回答「每一场是否成立」，G5 内部粗片检查回答「整片结构是否成立」，G6 独立终审回答
「当前成片是否成立」。只有按风险计划适用的核心评审和 G6 终审由[独立子代理评审](subagent-review.md)
执行；不把 G5 内部检查记成独立审查。任何情况下都不声称真实观众试映，也不新增用户审批或 CLI 门禁。

核心图形高潮同时按[视觉力量设计](visual-creative-direction.md)观察尺度、层级、冲击与具体画面记忆潜力；G5 内部检查和 G6 终审分别核对结构与交付表现，未达原目标退回方案或试制，不用技术通过或更易复述代替。记忆潜力不等同真实记忆测试。

## 两个检查点

| 检查点 | 时点 | 主要问题 | 结论 |
|---|---|---|---|
| G5 内部粗片检查 | 完整粗预演后、阶段问题收敛前 | 主线、核心事件、信息推进、节奏、跨场衔接和已知问题 | 按推进／回退规则记录通过、局部修复、补证或退回重设计 |
| G6 独立终审 | 当前候选技术 QA 后、标记完成前 | 全片理解、结构、节奏、视觉、文案与必要文字可读性 | 交付 / 退回剪辑 / 局部返工 |

G5 与 G6 分担内部制作检查和独立交付审查，不另立审核轮。
终审人员资格与拆分条件统一见[审核策略](checkpoint-gates.md#审核计划与风险触发)，隔离执行见[独立评审流程](subagent-review.md)。

G5 检查后、阶段问题收敛前，制作助手按[推进与回退决策](production-workflow.md#核心样片与全片粗片的回退决策)记录决策、回退层级及暂停／可继续范围。主线、跨场组织、核心机制推广或整体技术可行性出现根本失败时，直接退回对应设计层，不以局部修补或「精修后会好」放行。尚未精制本身不证明设计失败；技术路线失败须另有试制及限制依据。修改全片结构后重新完成 G5 内部检查，相关必改关闭后才恢复受影响精制。

G5 与 G6 的记录写入作品 `outputs/visual-notes.md` 的「全片导演审查」章节，绑定检查点、准备
指纹、成片摘要、时间范围和实际查看方式，并在「独立评审记录」区块写明执行方式（独立子代理 /
外部评审 / 角色分离自审）、投喂文件与隔离条件。最终审查必须绑定最终文件摘要；摘要变化后
旧最终结论不能授权新文件；未变局部观察仅附来源和依赖证明引用，当前最终文件仍完整检查。

**时点不可倒填。** 第一次审查必须在完整粗预演形成后、阶段问题收敛前执行并保存；第二次审查
必须在最终精制候选形成后、标记完成前执行并保存。只有当时实际查看的版本和观察才算阶段证据；
在最终候选之后凭记忆整理、用设计文档反推或只写结论，都不能冒充已执行的审查。

### 全片逐页检查

最终审查前必须逐页实际查看带时间标注的全片帧序列（`m2v qa` 的分页接触表），并记录：

- 实际查看的页码，以及每页覆盖的时间范围；
- 每页看到的主体、动作、信息推进或异常，以及异常处的加密帧复核；
- 未查看的页面。**生成采样不等于实际检查**；只看少数代表页或只看接触表索引时，
  未覆盖部分保持未完成，不能写「全片已复核」。

逐页查看不能替代路径量测、字幕核对和音频候选处置；它们也不能替代逐页查看。全片检查
完成后，交付分别报告技术结果、体验结果和未验证范围，并绑定准备指纹与成片摘要。

## 先观察，后对照

第一遍**不要**先读设计理由、实现说明和逐场通过结论。只依据当前全片帧序列、旁白字幕、
声音时间窗和适用量测，按时间顺序记录：

- 一句主问题：看完前 10 秒，我认为片子要我回答什么。
- 观看动机：我为什么继续看，下一段想确认什么。
- 核心事件：哪一个可见事件真正推动了理解。
- 答案：核心答案首次完整出现的时间码是什么，能否用自己的话复述。
- 答案后：后续各段有什么新增回报，哪些段落删除后不影响理解与必要收束。
- 结尾回报：结尾是否回扣开场，是否留下可转述的认识或可记住的体验。

然后逐段写「观众已知 — 尚有疑问 — 眼前表达 — 新增发现或体验」。按完整揭示窗口区分延迟理解和持续误读，开场局部不能替代全段判断；抽象、文字或静态表达不强制改成具象动作。保存观察后，再核对单独提供的中性目标检查（不提供作者理由或预期答案）：
信息递进、重复解释、提前泄底、理解断层、无意义等待、视觉高潮与强弱、声音意图、开场承诺
是否兑现；[视觉创意方案](visual-creative-direction.md)兑现：核心表达、母题、可见变化、镜头行为、高潮与结尾揭示在成片中是否成立；[导演卡](visual-creative-direction.md#导演设计观众按什么顺序看到)兑现：观众是否按设计顺序先建立预期、再获得新信息、最后改变认识，相机动作是否真正改变观察关系或注意力。设计文档不作为成立证据。

## 不可替代性两问（按问题选用的诊断）

删 30% 与唯一画面是诊断工具，不是每片必答的完成条件。出现无用途重复、等待、收束或视觉核心问题时使用；使用时在盲看并落盘观察后作答，不能先读设计理由或旧结论。答案写入 `outputs/visual-notes.md` 的「全片导演审查（第二次）」区块，并保留评审者的原始表述。金融与住宅按适用性执行，保持各自专用契约。

1. **删 30% 问**：如果成片只能保留 70%，按什么顺序删除哪些具体场景、镜头或时间范围？
   - 必须给出具体位置、删除顺序和保留部分的不可替代理由，不能只写「压缩解释」「去掉重复」「节奏更紧」。
   - 认为不需要实际删 30% 时，仍要列出最先会删的 30% 及各自损失；这是优先级测试，不是删除任务。
   - 三种可接受的删除对象：纯解释且不影响因果；与其他段落重复的信息；缩短后仍保留观察、事实或情绪用途的时间段。必要观察、事实交代和情绪收束不能只因「没有新知识」列为可删。
   - 答不出具体位置说明尚未建立优先级，登记为结构问题，不得以「都很重要」通过。
2. **唯一画面问**：如果整片只能留下一个画面，留哪个？
   - 必须给时间码、镜头 ID、画面内容与不可替代理由：它承载哪条核心关系、变化或认识，去掉后影片失去什么。
   - 以连续过程、对照或并置为记忆单位的作品，可以回答一个完整瞬间或窗口而不是单帧；但仍要具体到时间码与镜头，并说明为何不能压缩为静帧。
   - 指不出任何画面或瞬间时，登记「视觉核心缺失」，退回方案、关键帧或 A 级镜头设计。主题复述、形容词或「每个画面都重要」不算回答。

两问由执行最终综合轮的独立评审者回答，制作助手另行记录自己的答案与分歧；分歧不得以作者意图直接覆盖，须按实际画面证据记录处理结果。降级自审须标注并披露。它们是诊断工具，不表示必须实际删除 30%，不改变[减法复核](creative-production.md#减法复核全片精制后)「不设删除比例」的规则，也不新增 CLI 门禁或自动评分。未使用诊断本身不阻断；使用时用形容词代替具体位置或答案，不能作为该问题的关闭证据。

## 第一次导演审查记录模板

```markdown
## 全片导演审查（第一次）
- 检查点：完整粗预演后 / 阶段问题收敛前（记录保存时间：<…>）
- 版本：preparedFingerprint <…>；对象摘要 <…>
- 查看范围：<全片帧序列 / 粗预演样片 / 时间码；页码或分段清单>
- 观察方式：<帧序列 / 自动音频 / 量测；未播放或未试听时如实写明>
- 主问题复述：<一句>
- 观看动机：<为什么继续看>
- 核心事件与答案：<事件、首次完整出现的时间码、答案>
- 答案后检查：<后续各段新增回报；删除后不损理解与收束的段落>
- 结尾回报：<是否回扣、可转述句>
- 视觉创意方案与导演卡兑现：<核心表达/母题/可见变化/镜头行为/高潮/结尾揭示的实际观察与时间码；关键镜头的建立、公开、停留窗口与最终认识是否按设计发生；未兑现项>

| 段落/时间码 | 观众已知 | 尚有疑问 | 眼前表达 | 新增认识或体验 | 停留用途与证据 | 删除后的理解／体验损失与修改收益／损失 |
|---|---|---|---|---|---|---|

- 问题：<只引用唯一问题表 ID，核心问题按原条件逐项核对，不复制处理历史>

- 减法复核：<逐段时间范围、回答“删除后理解、感受、期待和记忆分别失去什么”、修改结果；保留阅读、事实或情绪用途的时间码>
- 减法压力测试（问题触发时选填）：<若只保留 70%，删除顺序、具体场景／镜头／时间码与保留理由；诊断用，不设实际删除比例>
- 唯一画面／瞬间（问题触发时选填）：<时间码、镜头 ID、画面内容与不可替代理由；过程型作品写完整瞬间或窗口>
- 逐页查看：<页码与时间范围；未查看页>
- 制作推进决策（第一次审查后由制作助手填写）：通过，允许扩展 / 局部修复，复查后放行 / 证据不足，补充试制 / 退回重设计
- 回退与放行记录：<引用原问题 ID 下的决策记录；回退层级、暂停／可继续范围、失效证据、重新验证条件；无回退说明通过依据>
- 最终结论（第二次审查）：交付 / 退回剪辑 / 局部返工
- 覆盖限制：<未覆盖的听感、瞬时运动、平台条件>
```

逐段表的“删除后的理解／体验损失”列在全片精制后填写，与[减法复核](creative-production.md#减法复核全片精制后)同一口径：理解、感受、期待和记忆均没有损失的段落删除或缩短，并在当前版本复查衔接与节奏；保留段记录实际用途与时间码。该列是交付结论证据，不新增问题 ID，也不设删除比例。

状态沿用[逐场验收](visual-creative-direction.md#四种问题状态)的四种取值：未解决、
待复查、已关闭、接受保留。已关闭必须回应原验收条件并有当前有效版本证据；接受保留不计入
已解决，影响核心理解的问题不得用该状态放行。

第二次导演审查复用上述观察、问题与逐段模板，补充最终成片 SHA-256；使用减法或唯一画面诊断时保留具体回答。两次均回答答案首次完整出现时间及答案后检查，不设统一时长阈值。返工记录使用[视觉复核问题模板](visual-review-rubric.md#版本与问题闭环)，保留修改假设、动作和独立复查结论。

## 剪辑重组

G5 内部检查后、阶段问题收敛前执行剪辑决策。允许删场、重排、压缩或延长时间、改变视点与声画
关系、补场或补镜头；不受原分镜顺序和已投入实现约束。必须保持事实边界、必要机制、类型、
画幅、声音与许可约束。**无实质问题时不强制无意义重剪**，但要记录保留结构的依据。

先定义问题与目标，不限定代码改法。用低成本版本比较（简化时间线、帧序列、试制片段），
在完整简化时间线上检查问题是否建立、理解是否连续、节奏与结尾回报是否成立；不以「更短」
自动判优。比较后才决定采用或否决。重复与等待先做删短或重排版本；连续两轮无改善按[返工升级](creative-production.md#信息推进与返工升级)执行。

```markdown
## 剪辑重组
- 对应导演问题：D01 / D02
- 原段落：<场景/镜头/时间码>
- 操作：删减 / 重排 / 时长 / 视点 / 声画关系 / 补场或补镜头 / 保持原结构
- 目标：<要解决的问题及必须保留的核心体验>
- 受影响：<场景、镜头、旁白、声音时间窗>
- 低成本比较：<前后版本摘要与证据>
- 修复收益与表达损失：<理解、悬念、节奏、情绪、记忆或独特性；非重要返工注明不适用>
- 采用/否决原因：<实际观察，不写形容词；若损害核心体验继续找解法>
- 复查：<受影响场景、相邻衔接、全片导演结论>
```

采用的修改必须回写可编辑分镜、场景、旁白与声音时间窗，重新 `prepare`，复查配音预算、
字幕、声音定位、受影响场景、相邻衔接和全片导演结论。不能把交付 MP4 当作唯一编辑源，
也不能因为改剪已执行就自动关闭问题。

## 第二次导演审查

最终精制候选形成后再次独立查看。绑定最终成片 SHA-256、准备指纹与证据；结构必改项退回
剪辑重组，局部问题精修并复查。逐项关闭必改项后完成最终传播评估；实质分歧交新代理复核，不以总体交付意见关闭问题。
最终审查保留退回剪辑的权力，不因逐场通过、技术通过或潜力正面结论而放弃。

第二次审查必须包含全片逐页检查记录：实际查看的页码、每页时间范围、异常与处置，以及
未查看页。只生成全片采样、只查看代表页或只检查风险区间时，全片体验复核保持未完成。

交付时分别陈述：

- **技术结果**：技术 QA 的状态、范围与已知限制；
- **体验结果**：逐场、全片导演审查与逐页检查的结论及原条件闭环；
- **未验证范围**：未播放、未试听、未做真实设备/平台实测等覆盖限制。

## 判断演练（演练，非真实失败）

| 情形 | 构造输入 | 必须得出的结论 |
|---|---|---|
| 局部全通过但全片失败 | 六场都有通过记录，但主问题在 30 秒后消失、结尾未回扣 | 全片必改项成立，退回剪辑或预演，不能标记完成 |
| 因已投入拒绝删场 | 某场已精制但打断主线，助手以「已经做了」为由保留 | 已投入不是保留理由；做低成本比较后决定删减/后移 |
| 重剪未回写材料 | 改剪只存在于交付 MP4，分镜、旁白和声音窗口未更新 | 新候选不得用于问题关闭或交付；先回写并重新 prepare |
| 最终结构回退 | 最终审查发现开场承诺未兑现，局部修饰不能解决 | 退回剪辑重组与必要试制，完成新版本复验 |
| 自审冒充试映 | 同一助手切换角色后写「观众测试通过」 | 只能写角色分离自审，不声称外部导演或真实观众 |
| 没派子代理却写独立评审 | 记录写「独立子代理」，但无投喂文件清单与隔离条件 | 视为未完成；补做独立评审或改记降级自审并披露 |
| 只查看部分接触表 | 已生成全片采样但只实际查看第 1、4、8 页 | 记录实际范围，补齐其余页面及风险量测后才能标记全片体验复核完成 |
| 最终候选之后补写首次审查 | 缺少阶段问题收敛前实际审查与比较的版本证据 | 不得宣称该阶段已完成；补做低成本全片审查与必要重组，并复验最终候选 |
| 标签替代动作 | 手机尺寸下动作仍不可辨，仅标签变大 | 原条件未满足，保持待复查；不得关闭 |
| 首尾呼应替代时长 | 结尾偏长只以呼应开场或设计停顿解释 | 必须比较原版与精简版时间线、帧序列与等待用途，否则不得关闭 |
| 设计停顿替代节奏 | 静音符合分镜声明，就判定节奏合适 | 必须说明每段停顿的观察、理解或情绪用途；技术声明不能关闭节奏问题 |
| 文档写了母题就判通过 | DESIGN.md 写了核心母题、高潮或视觉揭示，但成片没有对应可见事件 | 按设计未兑现处理，依据实际画面与时间码；设计文档不能替成片证明成立 |
| 导演卡写了顺序但成片先泄底 | 预期建立前已公开全貌，或后续拉远只缩小相同画面、没有新增关系信息 | 导演顺序未兑现，回到导演卡或事件结构修订；不用增亮、换色或轻微调速关闭 |
| 删 30% 只有抽象原则（使用该诊断时） | 回答「压缩解释、去掉重复」，没有具体场景、镜头或时间码 | 视为未完成该诊断；补齐删除顺序与保留理由后才能据此关闭问题 |
| 唯一画面答不出（使用该诊断时） | 回答「每个画面都重要」或复述主题，指不出时间码与镜头 | 登记视觉核心缺失，退回方案、关键帧或镜头设计 |
| 把 70% 当作删除配额 | 助手直接把成片删掉 30%，或称不删就未通过 | 纠正为诊断问题；实际删减按减法复核逐段判断，不设比例门禁 |

## 完成边界

交付明确分别填写：

- **技术交付完成**：当前文件已交付且技术检查通过；失败时报告实际状态。
- **制作复核完成**：绑定当前版本的必要独立评审有效、逐场与全片必改项全部关闭、全片实际复查完整；空白报告、待复查必改项或降级自审均不能支持该结论。未满足时报告未完成及缺失证据。

上述是助手报告口径，不改变 CLI status、导出行为或机器门禁。

最终汇总让上述两项绑定同一个当前交付文件 SHA-256，并列出未关闭问题与未覆盖范围；若核查了其他候选，单列其摘要，不混用。`delivered` 只说明技术交付状态，不授权制作复核完成；旧版本通过与粗样胜出均不能替代当前最终文件的证据。重制还须引用[理解、表现与相对改善](subagent-review.md#重制的理解表现与相对改善)结论。

```markdown
## 当前版本完成汇总
- 交付文件与 SHA-256：<路径与实测摘要；两项结论共同绑定>
- 技术交付完成：<是/否，技术检查及交付记录>
- 制作复核完成：<是/否，独立评审、全片覆盖、原条件闭环>
- 重制比较：<基线摘要、最终比较报告与原问题 ID；非重制注明不适用>
- 未关闭问题：<ID及状态；没有时写明依据>
- 未覆盖范围：<证据限制与尚缺检查>
```

技术通过但制作未完成时必须分别写明，不能以总体「完成」覆盖待复查项。代理评审不等同真实观众试映、留存或传播效果。



- G5 内部检查与 G6 独立终审各记录一次实际观察、剪辑决策、采用修改及复验；无修改时记录保留依据。
- G5 检查在阶段问题收敛前完成，G6 在当前最终候选后完成；时点与版本证据缺失时对应阶段未完成。
- 最终候选必须逐页查看全片时间标注序列并记录页码与范围；缺页时全片复核未完成。
- 减法压力测试与唯一画面／瞬间按问题选用；不适用或未触发时不填写，不单独阻断制作完成。
- 全片与逐场问题使用同一表，以影响范围及问题性质区分，逐场通过不能覆盖有证据的全片否决（核心缺陷）；风险先取证，偏好不直接产生必改。
- 记录不是导出门禁；CLI 仍执行既有技术检查，助手不能以导出成功代替导演结论。
- 未播放、未试听或未做平台实测时如实披露覆盖限制。

## 传播表现评估


传播评估并入 DESIGN.md 与 outputs/visual-notes.md，不另建潜力报告，不预测百万播放，不新增评分或机器门禁。新规则不迁移活跃作品。

## 方案假设

在设计中一次写明受众、平台、生活问题、观看理由、核心发现、视觉记忆点与分享动机。逐场作用直接合入观众问题及新增体验，不单列传播贡献表，不逐阶段重填。

## 最终评估

在 visual-notes.md 的「传播表现评估」章节记录：

| 项目 | 内容 |
|---|---|
| 绑定 | 当前交付 SHA-256、准备指纹、时长、画幅、日期 |
| 结论 | 支持具备潜力 / 证据不足 / 当前未达到；仅指内容表现，不预测播放量 |
| 支持与反面证据 | 时间码、实际事件、理解门槛和重复等待；引用最终轮报告，不强凑条数 |
| 剩余问题 | 唯一问题表 ID、状态、影响与返工决定 |
| 发布条件 | 平台、账号与设备实测的已知条件，未知如实记录 |
| 发布后验证 | 实际获得留存、评论、分享等数据后如何检验假设；无数据不填指标 |

反面观察由独立代理提供或复核；没有发现须给出实际范围和依据，不能编造缺陷。可修改的必改项回退，未知分发条件不导致无限返工。先前设计假设不能复制成成片已实现结论。

## 与清理的关系

主记录直接链接原始报告及需要保留的本地证据文件，不只链接目录；所有作品内容及生成媒体仍不入库。技术交付与制作复核分别报告。
