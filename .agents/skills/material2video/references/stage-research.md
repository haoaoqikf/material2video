# 研究与创意试制

目标：通过深入风格研究和实际试制，找到有辨识度、表达成立且达到所选视觉品质的方向。先验证代表性效果，再展开全片；资源优先用于研究、设计和看图，允许低成本失败。

## 研究、探索与试制循环

1. 用简短创作任务明确主题、受众、希望观众理解和感受什么、事实、硬约束及关键未知，不先写满全片方案锁定首个想法。已有用户方案作为初始基线，局部修订复用有效研究，不重开无关选案。
2. 完整阅读[创作总纲](visual-expression-inspiration.md)，按[具体标杆与深入拆解](reference-video-analysis.md)选择可实际查看的作品或片段，区分整体视觉品质、专项表现和信息表达参考。用户未指定时助手自主选择；自创、融合或不采用列表风格同样需要研究，图表规范不自动充当整体美术标杆。
3. 围绕当前决策深入研究适用的构图比例、排版、色彩层次、图形空间、材质光影及运动声音，区分实际观察、效果解释、本片应用推断和限制。实际访问相关及跨题材来源；静帧只支持外观，过程与听感须实际覆盖。搜索摘要、链接列表和“暗底、大字、强调色”等标签不构成深入研究。
4. 将结论转成局部设计：明确采用特征、本片落点、适应性调整和验证办法，保留整体品质参考，不以特征齐全代替整体效果。研究足以支持当前试验即可试制，未知针对补查。草图、生图、成熟素材/组件和代码按表达需要选用，不让容易编码决定上限；新增组件仍先调研外部方案、优先复用内部成熟实现。展示型 HTML 同样适用。
5. 选择最能检验核心表达的场景，不必从开场开始。先做同一场景、同一核心内容的不同设计，差异来自载体、主构图或表达机制，不能用多个场景或换色代替选案。粗稿先排除明显不成立方向；潜力方向补足足以判断的主体、字体、材质和合成，依赖运动才成立的方向须看过程。仅当精度差异妨碍选择时补齐相近完成度，不精修陪跑、不规定数量。
6. 关键帧验证构图与材质，完整片段验证因果、时间及衔接，必要时加入声音；窗口覆盖完整关系，不固定时长。概念图可用于探索，所承诺效果还须在拟用制作链路中实际重现，不能用生图证明精确数据和正式动态。
7. 实际查看候选并与参考并排或按对应窗口对照，分别判断候选优劣与整体品质是否成立。每轮聚焦最影响整体的一个问题：主体无趣时换表达，材质不足时磨材质；保留前后媒体检验收益，不把意见清单变成装饰任务。缺依据补研究，实现偏差修制作，参考不适合则说明原因后重选并重新比较，不能暗中降标。
8. 有希望的试制按[独立评审](review-contract.md)先盲看后同轮对照，提供实际参考及中性条件。评审说明具体吸引力、普通之处和最大品质差距；主代理据此选择下列行动并承担品质责任，独立 pass 不能代替选案。正式候选、比较参照与按需探索观察的边界沿用该契约，不增加例行审核。

| 人读结论 | 下一步 |
|---|---|
| 都不值得继续 | 全部淘汰，换表达或构图，不强行选赢家 |
| 值得继续打磨 | 集中修复主要差距或补关键证据，暂不展开 |
| 可作为后续标准 | 以拟用链路重现的实际画面为基线，关闭适用必改项后在已验证范围展开 |

## 记录

RESEARCH.md 是唯一研究记录：目标与问题、参考用途及实际查看范围、观察/解释/应用推断、限制、方向比较和未决问题。保留反例、矛盾和许可限制，判断可追溯，不设搜索次数、字数或时长配额。

DESIGN.md 保存采用特征→本片落点→验证办法、选案理由、实际视觉基线及适用范围。主要证据是候选、前后对比和选中画面，文字只解释取舍与下一问题；三种结论写在现有评审 observations 和设计记录，不新增状态字段或台账。研究不复制，问题沿唯一记录闭环。

## 完成与停止

进入正式设计须有：具体视觉目标与可查看依据；能够指导本片并解释差距的深入研究；可执行的采用转化；有吸引力且足以代表目标品质的实际画面；适用核心过程及独立目标对照有效；主要技术、资产和许可可行。注明兑现部分、未决差距与通过范围，一个样片不授权未覆盖机制。

有明确吸引力、主要品质差距已处理、关键实现证据足够即可收敛，不靠总分、投票或文档数量。根本失败立即回退；同一问题连续两轮修复无改善，按[返工循环](production-workflow.md)比较实质不同路径，必要时换参考、载体或工具。达到明确资源边界时交付当前结果与差距；停止不等于通过。

用户只要求先看方案和图片时，同样深入研究，交付具体参考、关键拆解、本片转化和代表性静态画面的对应展示，说明差距与动态/声音未覆盖范围；不擅自进入完整视频制作。常规环节自主推进，不新增阶段审批。

探索草案交付不自动等于正式设计完成。尚未验证的方向明确标为待验证；声称视觉方向已成立时须有对应静态或过程的有效独立目标对照，不为静态请求强行制作无关动态。
