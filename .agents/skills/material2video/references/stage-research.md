# 研究与创意试制

目标：通过深入风格研究和实际试制，找到有辨识度、表达成立且达到所选视觉品质的方向。先验证代表性效果，再展开全片；资源优先用于研究、设计和看图，允许低成本失败。

## 研究、探索与试制循环

1. 澄清主题、受众、希望观众理解和感受什么、硬约束及关键未知。先有简短内容骨架；已有用户方案作为初始基线，局部修订复用有效研究，不重开无关选案。
2. 完整阅读[创作总纲](visual-expression-inspiration.md)，按[具体标杆与深入拆解](reference-video-analysis.md)选择可实际查看的作品或片段，区分整体视觉品质、专项表现和信息表达参考。用户未指定时助手自主选择；自创、融合或不采用列表风格同样需要研究，图表规范不自动充当整体美术标杆。
3. 围绕当前决策深入研究适用的构图比例、排版、色彩层次、图形空间、材质光影及运动声音，区分实际观察、效果解释、本片应用推断和限制。实际访问相关及跨题材来源；静帧只支持外观，过程与听感须实际覆盖。搜索摘要、链接列表和“暗底、大字、强调色”等标签不构成深入研究。
4. 将结论转成局部设计：明确采用的可观察特征、本片落点、适应性调整、验证办法，以及所需实际参考。研究足以支持当前试验即可试制，不等全部专项结束；关键前提缺失则停止依赖它的试验，发现新未知针对补查。最小技术验证可同步进行，工具选择服务于表达目标。展示型 HTML 同样适用。
5. 选择最能代表目标、改变决策的场景，不必从开场开始。实际比较有实质区别的载体、构图或声画机制；存在分歧时用相近完成度画面比较，不以换色凑候选，不设数量。主体、字体、材质和合成达到足以判断承诺品质的精度，使用真实内容；占位只证明实际覆盖部分。
6. 关键帧验证构图与材质，完整片段验证因果、时间及衔接，必要时加入声音；窗口覆盖完整关系，不固定时长。概念图可用于探索，所承诺效果还须在拟用制作链路中验证可实现性，不能用生图证明精确数据和正式动态。
7. 实际查看当前效果并与参考并排或按对应窗口对照，记录具体差距及收益/损失。缺依据补研究，理解目标但实现偏差修制作，参考不适合则重选；方向未成立时不把同一形式铺满全片。根本失败立即换方向。
8. 有希望的试制按[独立评审](review-contract.md)先盲看后目标对照，提供实际参考和中性采用特征；关闭适用必改项后进入正式设计，原试制继续完善。清楚可读或技术通过不能代替美术目标兑现。

## 记录

RESEARCH.md 是唯一研究记录：目标与问题、参考用途及实际查看范围、观察/解释/应用推断、限制、方向比较和未决问题。保留反例、矛盾和许可限制，判断可追溯，不设搜索次数、字数或时长配额。

DESIGN.md 先保存采用特征→本片落点→验证办法及局部试验，引用研究，实际通过的画面成为后续视觉基线。不复制研究全文或报告，不建立机器合同；比较和失败保留必要结论，问题沿唯一记录闭环。

## 完成与停止

进入正式设计须有：具体视觉目标与可查看依据；能够指导本片并解释差距的深入研究；可执行的采用转化；有吸引力且足以代表目标品质的实际画面；适用核心过程及独立目标对照有效；主要技术、资产和许可可行。注明兑现部分、未决差距与通过范围，一个样片不授权未覆盖机制。

已有方向显示清楚优势且关键未知得到验证即可收敛，不以研究时长或文档数量判断。重复试验无改善时重新检查主题、表达载体或技术路线；根本失败立即回退。同一问题连续两轮修复无改善，按[返工循环](production-workflow.md)比较实质不同路径。

用户只要求先看方案和图片时，同样深入研究，交付具体参考、关键拆解、本片转化和代表性静态画面的对应展示，说明差距与动态/声音未覆盖范围；不擅自进入完整视频制作。常规环节自主推进，不新增阶段审批。

探索草案交付不自动等于正式设计完成。尚未验证的方向明确标为待验证；声称视觉方向已成立时须有对应静态或过程的有效独立目标对照，不为静态请求强行制作无关动态。

## 源文与专项

采用原文前按[源文审查](article-media-and-sound.md)核验事实与输入；topic 输入按主题边界研究。素材读[台账](material-sourcing.md)，实际拆解参考读[参考分析](reference-video-analysis.md)。研究与试制不等于全片验收。
