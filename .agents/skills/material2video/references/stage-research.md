# 研究与创意试制

先明确主题、受众、要让观众理解和感受到什么、事实与硬约束，以及最影响方向的未知。已有用户方案可作基线。新作依次明确表达目标 → 从作品绑定选取并核对全片案例 → 形成镜头方案 → 全片组件调研 → 试制代表场景。实质性视听修订先核对有效研究与样品，按受影响的表达或实现问题补查。

## 优秀案例调研

从 `design/style-binding.json` 的生效条目进入原片、截图或有效本地快照。按条目 ID 和实际观察窗口记录本片采用方式，只有影响镜头决定且现有证据无法回答的问题才外搜。以整片为单位调研叙事结构、视听语言和关键镜头。拆解参考如何用构图、动效、节奏或其他视听安排解决表达问题，形成含关键帧、动作和验证预期的本片镜头方案。具体镜头的参考在同一研究中标明用途与适用场景。[检索、拆解与本片转化](reference-video-analysis.md)

## 全片组件调研

从镜头方案提取会影响全片选案的核心效果及需要跨场复用的能力。把选型依据、适用范围和待验证问题交给代表场景试制，并将结果回写全片研究。局部实现需求在[场景设计](scene-design.md#从研究到场景决策)中处理。两级共用[成熟组件调研方法](visual-components.md#成熟组件调研)。

## 代表场景试制

进入试制前，先核对已有依据能否决定构图、关键状态、信息揭示顺序和可观察的成立条件，完成适用的组件选型。影响核心方向的研究缺口先补查。可用小试解决的未知写明假设、验证窗口与预期后进入试制。

1. 选最能检验核心表达的一场，用[场景模板](scene-design.md#场景模板)把调研转成可试制的编排和观察预期。以同一内容比较实质不同的构图、载体或表达机制。材质或运动决定成败时，补足相关证据再比较。
2. 在实际网页链路生成代表状态和高风险中间状态。需要选案时先小范围比较能解决问题的候选，再从选定版本采齐既定关键帧。总代理按[试制通过标准](visual-review-rubric.md#试制关键帧的通过标准)，在现有对照条件中逐帧写明画面职责、适用参考和相关观看尺寸下应成立的效果。按[不同观看尺寸的职责](visual-review-rubric.md#不同观看尺寸的职责)分别核对正常尺寸的艺术效果与小屏核心表达。送同源关键帧做独立盲审及同轮实际标杆对照，条件在盲审封存后揭示。
3. 总代理用完整解码、有序帧及适用信号验证试制中的完整动作、因果、身份、节奏、声音与衔接，核对运动中的材质、空间和实际成本。研究时按拟定的目标时长安排。正式取证以准备时间轴为准，按[审核策略](review-contract.md#审核策略)决定正式关键片段是否必审。
4. 总代理核对证据与独立观察，明确方向采用、待修复或淘汰的依据。试制返工按[推进与回退](production-workflow.md#推进与回退)执行。

## 记录

全片案例、全片组件选型及代表场景试制依据归 RESEARCH.md。正式采用的共同设计、场景组件选型和局部验证按[文档分工](scene-design.md#分工与对应)回写。

## 完成与交付范围

达到目标、适用关键过程有证据且必改关闭后，才在已验证范围展开。用户选定的整体风格覆盖受影响画面，优先验证最易暴露迁移问题的场景。抽象表达按[信息职责](review-contract.md#抽象表达与信息职责)判断。正式基线还须有主要技术、资产及许可可行依据。准备后取正式关键帧与适用关键样片。

只要求先看图片时，交付实际参考、必要拆解、本片转化和通过[原生样品检查](design-samples.md)的同源静帧。承诺动态时另验完整过程。
