# 设计前深度研究

本页是研究操作的唯一权威。研究是「方案确定」内部、正式设计前的独立子阶段：任务澄清 → 深度研究 → 正式设计；不增加第四大阶段、审核轮、例行用户审批、CLI 门禁或运行时字段。

## 进入与研究范围

新制作或实质性视听重设计，在正式编写或实质性改写 `DESIGN.md`、制作展示型 HTML 草稿或低成本视觉原型前，必须完成适用的外部搜索、实际查看、分析与综合研究。先明确主题、受众、用户硬约束、事实边界和关键未知，完整阅读[视觉与表达灵感](visual-expression-inspiration.md)；本任务已完整阅读则不重复。四组列表只扩展联想，不限定搜索范围、必选风格或研究完成条件；自主创作同样需要研究。

按关键问题与风险选择以下研究范围及深度，不要求每片展开全部专项：

| 范围 | 需要形成的认识 |
|---|---|
| 主题与事实 | 核心关系、条件、争议与例外，优先核对原始或权威来源 |
| 受众与理解 | 前置知识、理解难点与潜在误读；缺乏受众证据的判断明确标为假设 |
| 叙事与讲解 | 如何建立问题、展开关系、推进认识及形成回报 |
| 视觉与载体 | 构图、色彩、材质、信息编码及实拍、档案、图表、文字、隐喻、三维的适用条件 |
| 运动与声音 | 对象变化、注意力、揭示时机、节奏与音画配合的作用；允许按目标静止或无声 |
| 素材与实现 | 关键素材可得性、许可风险、已有能力与合理投入边界；新增组件仍按项目外部方案调研要求执行 |

用户已有方案足以作为基线时，围绕其关键前提和缺口研究，不重开无关选案。题面整理和研究问题不等于提前完成设计。

## 研究与综合

1. **从问题出发。** 列出会影响方向的未知及所需证据，避免先确定风格再只寻找支持它的案例。
2. **探索相关与跨题材参考。** 从同题材表达、相似机制、原始资料及素材条件寻找依据；不为扩大范围收集无关材料。
3. **深入实际材料。** 访问来源并查看对应内容，拆解对象、变化、信息顺序、注意力及成立条件。来源、时间位置、实际范围和限制按[参考分析的证据边界](reference-video-analysis.md#证据边界)记录。搜索摘要、链接列表、既有代码、风格名称或印象不能替代实际查看。静帧只支持外观与构图；运动须查看相关完整过程，声音结论须实际听取对应材料。
4. **比较并检验。** 有实质路线分歧时比较表达收益、理解成本、事实风险、素材条件和实现代价；无分歧时不凑候选。关键判断须检查反例、相反证据或适用限制，保留冲突，必要时调整判断或补查。
5. **综合为设计输入。** 提炼关键发现、方向建议、适用边界和待验证问题，说明如何影响后续设计。研究中可提出表达假设与方向，不提前定稿逐场设计或制作展示方案草稿；研究完成后进入[正式设计](stage-plan.md#设计记录)与后续试制。

关键发现应能追溯「研究问题 → 实际证据 → 观察 → 判断 → 设计启发／待验证项」。观察写实际看到或听到什么；推断写判断及依据，缺乏证据的认识写为假设，不把参考效果扩大为本片已验证效果。

## 唯一研究记录

在作品根目录维护 `RESEARCH.md`，普通问题可以简写，复杂问题按需展开；不设置搜索次数、案例数量、候选数量、字数或研究时长配额。

| 内容 | 记录什么 |
|---|---|
| 研究范围 | 任务目标、硬约束、关键问题、需要展开的范围与有效既有研究 |
| 证据与观察 | 来源地址、访问日期、实际查看范围／时间位置、具体观察、来源可靠性与限制 |
| 综合发现 | 可追溯的问题和证据引用、关键认识、矛盾及适用边界，区分事实、推断和假设 |
| 方向建议 | 足以进入设计的表达方向、理由和成立条件；有实质分歧时记录比较 |
| 未决问题 | 设计前必查或后续试制验证、影响范围、验证办法与当前状态 |

`DESIGN.md` 引用研究结论，只记录最终设计、采用落点与必要对照，不复制研究全文或维护第二份证据表。长参考采用分析仍可用[采用附件](reference-video-analysis.md#记录采用范围)，不得复制研究报告。研究属于作品内容，遵守内容不入库规则；当前不参与渲染或准备指纹，也无工具自动判定其语义完成。研究者推理、方向推荐和旧结论不进入[独立盲审包](subagent-review.md)。

## 完成、复用与失败

- **完成依据**：影响方向的关键问题已有可追溯依据；结论与实际查看范围一致，重要矛盾和限制明确；有足以开展设计的方向建议及关键素材、实现条件的初步核查。未决项已分清设计前必查和后续试制验证，并写明验证办法。由制作助手按证据判断，不新增例行用户确认。
- **停止边界**：足以支持当前设计判断即可停止。设计前必查项未成立时，保持研究未完成并停止依赖它的设计；无关整理可以继续。后续试制项不冒充已验证，进入原有风险与试制流程。
- **覆盖复用**：同一任务已有真实可追溯研究时，可引用原记录并说明问题、约束与证据覆盖依据，不机械重搜或复制报告。存量作品不补造历史，也不要求重抄有效旧研究；当前修订只补实际缺口。
- **补查触发**：方向、新对象、关键前提变化或用户反馈暴露未覆盖问题时，先补查相关范围，再重设计。错字、裁切或已验证方案内的实现偏差不重做整套研究。
- **来源失败**：不可访问时换检索词或来源；仍无法实际查看且无有效既有研究时，如实记录前置未满足，不用经验自动豁免，不伪造观察或完成。

研究完成只支持进入正式设计，不代表设计成立、素材已获入片授权或制作评审通过；事实、许可、技术与适用独立评审继续按原契约执行。
