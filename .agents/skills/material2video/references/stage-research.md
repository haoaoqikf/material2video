# 研究与创意试制

先明确主题、受众、要让观众理解和感受到什么、事实与硬约束，以及最影响方向的未知。已有用户方案可作基线。新作依次明确表达目标 → 全片案例调研 → 形成镜头方案 → 全片组件调研 → 试制代表场景。实质性视听修订先核对有效研究与样品，按受影响的表达或实现问题补查。

## 优秀案例调研

以整片为单位调研叙事结构、视听语言和关键镜头。拆解参考如何用构图、动效、节奏或其他视听安排解决表达问题，形成含关键帧、动作和验证预期的本片镜头方案。具体镜头的参考在同一研究中标明用途与适用场景。[检索、拆解与本片转化](reference-video-analysis.md)

## 全片组件调研

从镜头方案提取会影响全片选案的核心效果及需要跨场复用的能力。把选型依据、适用范围和待验证问题交给代表场景试制，并将结果回写全片研究。局部实现需求在[场景设计](scene-design.md#从研究到场景决策)中处理。两级共用[成熟组件调研方法](visual-components.md#成熟组件调研)。

## 代表场景试制

进入试制前，先核对已有依据能否决定构图、关键状态、信息揭示顺序和可观察的成立条件，完成适用的组件选型。影响核心方向的研究缺口先补查。可用小试解决的未知写明假设、验证窗口与预期后进入试制。

1. 把调研转成对象关系、关键状态、注意力顺序和可观察预期，落入[场景设计](scene-design.md)。选最能检验核心表达的一场，以同一内容比较实质不同的构图、载体或表达机制。材质或运动决定成败时，补足相关证据再比较。
2. 在实际网页链路生成代表状态及容易出问题的中间状态。总代理依据关键帧、有序帧和适用信号初筛，正式候选按[审核策略](review-contract.md#审核策略)独立盲审及同轮对照实际参考，按[世界级标准](visual-review-rubric.md#世界级品质与风格开放)判定。风格自由选择，苹果仅说明品质高度。
3. 依目标和审核策略验证适用的完整动作、因果、身份、节奏、声音与衔接，核对运动中的材质、空间和真实成本。适用关键过程默认独立对照，影响理解的时间机制按审核策略处理。研究时按目标时长安排试制。正式取证以准备时间轴为准，不超过 30 秒的短片在全片工程验证过程并取关键帧，超过时取适用关键样片。
4. 每轮处理最影响判断的问题，比较前后媒体。缺依据补研究，实现偏差修实现，核心方向失效就重设计。两轮无改善换实质机制，按[返工循环](production-workflow.md)继续。总代理核对帧与信号证据及独立观察，并明确采用、修复或淘汰及依据。

全片案例、全片组件选型及代表场景试制依据归 RESEARCH.md。正式采用的共同设计、场景组件选型和局部验证按[文档分工](scene-design.md#分工与对应)回写。

## 完成与交付范围

达到目标、适用关键过程有证据且必改关闭后，才在已验证范围展开。用户选定的整体风格覆盖受影响画面，优先验证最易暴露迁移问题的场景。抽象表达按[信息职责](review-contract.md#抽象表达与信息职责)判断。正式基线还须有主要技术、资产及许可可行依据。准备后取正式关键帧与适用关键样片。

只要求先看图片时，交付实际参考、必要拆解、本片转化和通过[原生样品检查](design-samples.md)的同源静帧。承诺动态时另验完整过程。
