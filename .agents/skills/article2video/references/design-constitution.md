# 设计宪法

这份文件是「什么算做对了」的判据。它服务于一个具体目标：让 AI 产出的画面
稳定在**可发布**的水准，而不是每次重新争论审美。

每条规则有编号（C1…）、理由、以及**能不能机检**。机检部分由
`scripts/review.py` 执行；不能机检的部分由 [视觉评审量表](visual-review-rubric.md)
交给人和视觉模型判断。**不要把不能机检的东西写成机检**——假自动判定比没有判定更危险。

## 一、结构与层级

**C1 三层结构**（机检：结构）
画面由「背景 / 表面 / 焦点」三层构成，页面必须有 `[data-a2v-stage]`、
一个常驻背景层与若干 `[data-a2v-scene]`。缺背景层时画面会平，
缺舞台时层级无处安放。
*理由*：高级感的第一来源是层级，不是装饰。

**C2 每幕一个论点**（人工）
每一幕只讲一件事，只用一个图形组件。两个论点挤在一幕里，观众两个都记不住。
*判定*：看这一幕能不能用一句话说清它在讲什么。

**C3 每幕一个挂载点**（机检：结构）
每个场景必须有且只有一个 `[data-a2v-figure]` 挂载点，且能解析出组件。
*理由*：缺挂载点的场景在成片里就是一块空白，而预览时未必看得出来。

## 二、动效

**C4 曲线纪律**（机检：静态）
只允许三条曲线：出场 `outQuint`、双向 `inOutCubic`、逐项门控 `outCubic`，
外加匀速位移用的 `linear`。
*理由*：曲线混用会让整支片子的手感不一致，而这种不一致很难指认、只能感觉到。

**C5 帧驱动**（机检：静态 + 运行时）
画面只由帧号推导。禁止 CSS `animation`/`transition`、`Date.now`、
`performance.now`、`Math.random`。
*理由*：逐帧截图与浏览器时钟无法对齐，成片会出现随机闪烁。

**C6 节奏统一**（机检：分镜字段）
幕内快慢只通过分镜的 `motion`（`calm`/`normal`/`impact`）表达，组件不各自写死节拍。
*理由*：节奏是整幕的属性，散落在组件里就无法整体调整。

**C7 动画服务于理解**（人工）
每个动效都要能回答「它在解释什么」。装饰性位移、无来由的旋转、
为了动而动的缩放一律删掉。
*判定*：能不能用一句话说出这个动作在讲什么；说不出就删。

## 三、视觉

**C8 不用大面积模糊**（机检：静态）
禁止 `filter: blur()` 与 `backdrop-filter`。柔光用 `radial-gradient`
或分层阴影实现。
*理由*：大面积模糊既拖慢逐帧截图（每帧几百毫秒），又容易糊成一片。

**C9 文字可读**（机检：帧量测 + 人工）
正文与背景的对比要够；正文字号不小于规范下限；一行不超过约定字数。
*理由*：竖屏在手机上只有几秒的注意力，读不清就等于没有。

**C10 安全区**（机检：帧量测）
顶部 220px、底部 320px（有字幕时再加 180px）不放重要内容。
*理由*：平台的界面会盖住这两块。

**C11 画面不空**（机检：帧量测）
每一幕都要有实质内容，整帧墨迹覆盖率不得低到接近空白。
*理由*：组件没挂上、文案为空、画面全黑，都不会报错，只会安静地出一段废片。

## 四、内容

**C12 文案单一真源**（机检：静态）
文案只写在 `storyboard.json`。网页源码里不得再出现分镜里的长句。
*理由*：抄一份就会在改文案时两边不一致，而错误只会在成片里被发现。

**C13 组件从目录里选**（机检：分镜校验）
先查 [视觉组件目录](figure-catalog.md)，能选就不新画。新组件必须沉淀回目录。
*理由*：每次从零画一遍既慢又难保持一致；目录是这张体系里真正会增值的资产。

**C14 标注必须真的画出来**（机检：契约探针）
分镜声明的每个标注，都要能在整幕的 DOM 里找到。
*理由*：这是最隐蔽的一类缺陷——组件挂上了、画面也出来了，
只是图上没有一个字。它不报错，只能靠读 DOM 或逐帧看图发现。

## 机检与人工的分工

| 规则 | 谁来查 | 查不出来时的后果 |
| --- | --- | --- |
| C1 / C3 / C4 / C8 / C12 | `review.py` 静态检查 | 结构缺失或手感漂移 |
| C5 / C6 / C13 | 校验器与前置扫描 | 成片闪烁或节奏失控 |
| C10 / C11 / C14 | `review.py` 帧量测与契约探针 | 出废片或标签全空 |
| C2 / C7 / C9 | **人（或视觉模型）** | 片子能播，但没人看完 |

最后一行才是真正决定播放量的部分。机检负责保证「不是废片」，
人工评审负责保证「值得看完」——把后者也交给脚本，等于放弃质量。
