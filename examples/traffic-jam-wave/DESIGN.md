# 拥堵波：循环创作与视觉设计

面向手机竖屏科普观众：车辆始终向前，而拥堵的低速区域向后移动。时长由实测旁白和
完整粗预演决定，不追求固定 75 秒。

## 画幅与观看目标

1080×1920 竖屏、60 fps，默认面向抖音式的手机全屏观看。字幕位于共享安全区，作品
正文止于其上方；标题、结论与被追踪的车辆在 393×852 CSS 像素下仍需可辨。用户显式
指定平台或画幅时以用户要求为准。

## 核心体验

原有认识：堵车前方应有事故或瓶颈。预期新认识：车辆向前，低速区域可以向后传播，
驱车离开低速区后前方可能畅通。观看理由是方向冲突及其成因。画面必须让车与慢区的
反向运动可辨；不能只靠标题和箭头告知。

## 第1轮候选（纸面构思，真实执行）

| 候选 | 开场 / 悬念 / 核心事件 / 递进 / 结尾 | 判断 |
|---|---|---|
| A 城市俯瞰 | 城市车灯 → 为什么堵 → 镜头飞入环路 → 解释密度 → 总结 | 淘汰：城市镜头与机制脱节，主要吸引力依赖精美资产 |
| B 教学实验台 | 无事故提问 → 环路条件 → 一次刹车 → 双密度 → 总结 | 淘汰：与旧版同构，核心揭示偏晚 |
| C 提问快剪 | 三个堵车问题 → 快切模型 → 图表说明 → 金句 | 淘汰：问题多但没有一件贯穿全片的可见事件 |

本轮全部淘汰。保留“方向反常”和“开到前面却空无一物”的生活经验；下一轮改用观众
追踪的具体对象，不换皮重用教学顺序。

## 第2轮候选（纸面构思，真实执行）

| 候选 | 开场 / 悬念 / 核心事件 / 递进 / 结尾 | 处理 |
|---|---|---|
| D 方向对撞 | 首帧车向右，慢区向左 → 谁在倒退 → 区域换车而非车倒行 → 刹车与密度 → 穿过一道波 | 采用：核心试制完成 |
| E 追踪一号车 | 首车减速 → 后面发生什么 → 响应逐车传播 → 密度对照 → 回到首车已走远 | 保留蓝框追踪手法；主结构淘汰：方向反常不够早 |
| F 堵完什么也没有 | 空路疑问 → 倒带找堵点 → 低速区后移 → 密度 → 生活回扣 | 保留结尾；主结构淘汰：空路开场建立现象较慢 |

最终结构 = D 的方向对撞开场 + E 的蓝框追踪 + F 的结尾回扣。核心试制先只做 `opposite`
一幕（同内容动态片段），确认真实轨迹下车辆右行、红带左移在手机尺寸可辨，再扩展其余四幕。

## 美术方向与参考

方向一：纸色实验台（旧版实际帧作为基准），读数完整但视觉重心分散；方向二：深色
道路与明亮车灯，缩减固定文字、单一重点色，主体放大到手机尺寸可辨。同内容核心片段
实际比较见交付 `outputs/visual-review/core/direction-trial.png`：三个方向揭示时机中，
采用“先给运动、再给反向箭头”的第三版，避免第一版的箭头过早泄漏答案。

机制参考：杉山等 2008 环路实验，完整来源及适用边界见 [SOURCES.md](SOURCES.md)。
视觉参考以本作旧版对照和真实试制为依据，不声称已观看外部参考片。无外部画面或音频
资产，所有视觉与声音由代码生成。

## 配色

深色底（`#080f19`）压低界面存在感；道路用蓝灰层级区分路面、边线与车道虚线；车辆
本体为冷白，制动灯与低速区域统一使用橙红（`#ff704b`），前进方向与蓝框追踪使用
青色（`#67e2ec`）。全片只有“红=慢/向后”和“青=快/向前”一组语义色，图表沿用同一
组颜色，观众不需要另记图例。

## 构图

每幕只突出一个问题，不常驻“标题+说明+结论+注释”四层。开场用一条横贯画面的道路，
标题在上、方向箭头在下；环路幕把闭环放在画面中部，标题与结论分别落在上下留白；
密度幕上下两条道路共用同一段采样，曲线放在下方；结尾把“拥堵波”放在环心，来源
说明只出现一次。车辆、制动灯、低速带与曲线共用离线轨迹，不手绘第二条波。

## 声音

无配乐、无音效，只保留中文旁白与烧录字幕；旁白段之间按内容留白。音色按完整旁白与
服务返回元数据选择（云希），未试听，信号检测不代表主观听感。动效与声音不追求固定
配额，按画面事件需要出现。
