# 拥堵波：生活困惑、逐场设计与视觉方向

面向手机竖屏科普观众：先用「堵了半天，前面却什么都没有」建立生活困惑，再展示车辆向前、
低速区域向后，最后回到驶出拥堵却没有障碍的经历。时长由实测旁白与观察时间决定，不设固定
秒数。

## 画幅与观看目标

1080×1920 竖屏、60 fps，默认面向抖音式手机全屏观看。字幕位于共享安全区，作品正文止于
其上方；标题、结论、车辆编号与后视镜内容在 393 宽（内容高约 699 CSS 像素）下仍需可辨。用户显式指定
平台或画幅时以用户要求为准。

## 本轮手机关键事件目标（2026-10-21 重制）

显示尺寸按 1080×1920 等比缩到 393 宽（内容高约 699 CSS 像素）复核；三类目标分开记录，
不以主体可辨替代动作或关系理解。

| 场景 | 主体辨认 | 动作理解 | 关系理解 |
|---|---|---|---|
| `empty` | 蓝框 8 号车、红色慢区、后视镜里的红队 | 8 号车驶出慢区；后视镜红区逐渐后退 | 前方空而后方红，堵点不在前面 |
| `rewind` | 红色慢区、车辆、两个方向箭头 | 车辆向右前进，慢区向左移动 | 同一段时间里两个方向同时发生 |
| `brake` | 1～6 号车、制动灯、反应时间线 | 制动灯从 1 号车向后逐车亮起 | 一次轻刹车沿车队被放大 |
| `relay` | 蓝框 8 号车、红色慢区、环路 | 蓝框车持续前进，慢区换到后车 | 后退的是区域，不是同一批车 |
| `density` | 上下两条道路、第 6 辆车速度曲线 | 密集路跌幅大、稀疏路跌幅小 | 密度决定扰动是否被放大；非实测 |
| `return` | 后视镜红区、空路、片尾声明 | 后视镜红区退向身后 | 你穿过的是一道向后传播的波 |

## 创作目标

- 受众：每天通勤、经历过「堵了半天前面却没事」的手机观众。
- 原有认识：堵车前方一定有事故、路口或封路。
- 预期新认识：车辆始终向前，低速区域可以沿车队向后传播；你驶出拥堵时，波可能还在身后。
- 观看理由：生活困惑与方向冲突；观众想看见「没有堵点，堵从哪来」的可见答案。
- 核心感受：先是困惑，再是「原来如此」，最后把自己的经历对号入座。
- 可观察验收条目：
  - 前两秒能看见「车驶出红色慢区，前方道路通畅」，并看见后视镜里的红色车队。
  - 不看标题也能说出「车在向前、慢区在向后」。
  - 能指出至少一次刹车如何沿车队向后传递，以及环路里换的是车而不是路。
  - 结尾能把开场经历解释为「穿过了一道波」，并知道来源与示意边界。

## 传播假设（策划阶段）

| 因素 | 初始假设 |
|---|---|
| 平台与受众 | 抖音竖屏；通勤人群与经历过莫名拥堵的普通观众 |
| 题材需求 | 强：几乎人人有「堵完却什么都没看见」的经历 |
| 开场吸引 | 空路与后视镜红灯同框，1～2 秒内制造「堵点去哪了」 |
| 理解成本 | 低：先给现象和车，再出现「拥堵波」一词 |
| 持续观看 | 方向反常 → 一次刹车 → 环路换车 → 密度补充，每段回答上一段留下的问题 |
| 核心发现 | 堵点不在前面；你穿过的是向后传播的低速区域 |
| 视觉记忆点 | 「前方空荡 / 后视镜全红」同框，以及红色慢区逆着车流后退 |
| 分享讨论动机 | 「原来如此」式解释，可转给刚堵完车的朋友 |

以上均为假设，最终判断以成片时间码与逐场证据为准，见 `outputs/reach-potential-report.md`。

## 候选方案

### 第 1 轮（纸面，全部淘汰）

| 候选 | 开场 / 悬念 / 核心事件 / 递进 / 结尾 | 淘汰原因 |
|---|---|---|
| A 城市俯瞰 | 城市夜景 → 车流变慢 → 飞入环路 → 密度 → 总结 | 城市镜头与机制脱节，吸引力依赖精美资产 |
| B 教学实验台 | 无事故提问 → 环路条件 → 一次刹车 → 双密度 → 总结 | 与旧版同构，核心揭示偏晚 |
| C 提问快剪 | 三个堵车问题 → 快切模型 → 图表解释 → 金句 | 问题多，没有一件贯穿全片的可见事件 |

### 第 2 轮（纸面 + 试制）

| 候选 | 开场 / 悬念 / 核心事件 / 递进 / 结尾 | 处理 |
|---|---|---|
| D 空路回望 | 驶出拥堵、前方空荡 → 后视镜全红 → 倒回 → 一次刹车 → 环路换车 → 双密度 → 回到空路 | 采用：生活困惑最早、贯穿事件清楚 |
| E 追踪一辆车 | 蓝框车一路向前 → 它经过红色慢区 → 为什么慢区换车 → 环路 → 空路 | 保留蓝框追踪；主结构淘汰：开场先讲车，困惑不够直接 |
| F 没有堵点的路 | 空路航拍 → 寻找堵点 → 时间倒回 → 机制 → 结尾 | 保留空路意象；主结构淘汰：寻找过程容易变成解释说明 |

最终结构 = D 的生活困惑开场与回扣 + E 的蓝框追踪 + F 的空路意象。先做 `empty` 与 `brake`
的核心试制，确认真实轨迹下「前方空 / 后视镜红」与「刹车灯向后传递」在手机尺寸可辨；
`relay` 在最终场景的 lookdev 静帧与全片复核中验证，再扩展全部场景。

## 两个美术方向与选案

同一核心内容（开场空路回望 + 一次刹车沿车队向后传递）分别制作两个实质不同的方向：

| 方向 | 画面语言 | 构图与材料 | 判断 |
|---|---|---|---|
| A 纸面交通实验笔记 | 暖纸、深墨、工程标注、尺寸线、编号车辆 | 横向剖面与大幅留白，像一页可翻阅的交通工程笔记 | 信息清楚，但与「真实通勤经历」有距离，手机尺寸下偏静 |
| B 夜景俯视道路 | 深蓝黑底、冷白车体、橙红制动灯、青色前进标记 | 俯视道路占满画面，车辆与光晕形成纵深，后视镜 inset 同框 | 采用：生活感与方向冲突更强，红色慢区在手机尺寸更醒目 |

方向比较使用同一段真实轨迹、同一组正式文案和实际字幕；两个方向都实际渲染了开场与刹车的
动态片段及手机尺寸缩略图。比较依据与文件见 `videos/examples/traffic-jam-wave/outputs/visual-review/directions/`，
结论记录在 `outputs/visual-notes.md`。

- 方向 A 在 393 宽手机尺寸下标题与图表清楚，但车辆只有约 30 px，红区更像一条标注而不是
  一次经历；连续观看时页面逐步「填满」，缺少道路带来的速度感。
- 方向 B 的道路铺满画面，蓝框车与后视镜同框，红色慢区在车流中形成明确的亮暗对比；手机
  尺寸下仍能看出车在前进而红区在后退。
- 第一轮 B 试制在开场第 8 秒把红区移出画面，且标题与后视镜重叠。修正为收紧取样时间
  （18.0～18.8 秒）并把镜头参照向红区偏移 2.2 个车位；复查 `directions/b/t004.0.png`
  与 `directions/b/t008.0.png` 后红区始终在画面内。
- 淘汰 A 的理由不是「换色后更好看」，而是视角、材料与信息层级都不同：A 是纸面工程图，
  阅读方式是查表；B 是夜景俯视道路，阅读方式是经历一次车流。B 更符合生活困惑开场。

## 逐场详细设计

### `empty`

| 列 | 设计 |
|---|---|
| 位置与作用 | 第 1 场；主线开场，建立生活困惑 |
| 观众问题 | 堵了半天，前面怎么什么都没有？ |
| 核心可见事件 | 蓝框车 8 号从红色慢区驶出，前方是正常行驶的车与空路；后视镜里红色车队逐渐退远 |
| 叙事任务 | 先用经历抓住观众，不给术语；把「堵点在哪」留到下一场 |
| 美术 | 俯视道路占画面主体，道路高 450 px；车辆 2.4 倍、车长约 125 px；蓝框 8 号车居中偏右；后视镜 inset 470×330 位于标题下方右侧；标题 80 px；红/青只用于语义 |
| 技术 | 位置、速度、灯态来自 `traffic.json` 高频组 t=18～19.5 秒采样；后视镜使用同一采样反向取景，镜内车辆 2.6 倍 |
| 动态 | 0～1.5 秒定位；车 8 前进并离开红区；后视镜红区缩小；2 秒内出现「前面什么都没有？」 |
| 文案声音 | 旁白 `e1`/`e2`；画面文案「前面什么都没有？」与「后视镜」；无音乐，1 次轻微转场提示音 |
| 验收条件 | 撤去标题仍能看出车在前行而后视镜仍红；393 宽下能辨认车 8、红灯、后视镜里的车队与空路 |
| 传播贡献 | 最强的生活代入与视觉记忆点；风险是后视镜太小、红灯不够醒目 |
| 内部镜头 | 单镜头连续；后视镜 inset 从右上淡入，不硬切 |

### `rewind`

| 列 | 设计 |
|---|---|
| 位置与作用 | 第 2 场；主线解释，给出方向反常 |
| 观众问题 | 没有事故，拥堵从哪来？ |
| 核心可见事件 | 回放标记出现后，红色慢区沿车队向后移动，车辆仍向右前进 |
| 叙事任务 | 把「堵点」改写成「向后移动的区域」，为一次刹车做铺垫 |
| 美术 | 同一条道路拉远；青色向前箭头与红色向后箭头上下对照；时间标记在左上；标题 76 px |
| 技术 | 高频组 t=7～21 秒；红区由同一速度阈值派生；箭头位置由慢区中心实时计算 |
| 动态 | 回放擦除 0.6 秒；红区从右向左移动；两枚箭头在第二句旁白时出现；末段留 1 秒观察 |
| 文案声音 | 旁白 `w1`/`w2`；画面文案「车 →」「慢区 ←」；无新增音效 |
| 验收条件 | 不看箭头也能看出红区与车辆反向；红区在手机尺寸下连续移动而非跳变 |
| 传播贡献 | 第一次认知冲突；风险是箭头抢在运动之前解释 |
| 内部镜头 | 单镜头连续；回放擦除只是覆盖层，不改变道路构图 |

### `brake`

| 列 | 设计 |
|---|---|
| 位置与作用 | 第 3 场；主线核心事件 |
| 观众问题 | 一次刹车怎么会变成一团拥堵？ |
| 核心可见事件 | 1 号车轻点刹车，2～6 号车依次亮起制动灯，车距箭头缩短 |
| 叙事任务 | 把抽象慢区落到一次可跟踪的减速与反应延迟 |
| 美术 | 局部道路高 460 px；车辆 2.4 倍；1～6 号车与制动灯同框；编号 26 px；制动灯橙红；车距标注在道路下方；标题 68 px |
| 技术 | 高频组 t=7～13 秒；灯态由速度阈值派生；车距由同一弧长采样计算；相机随 1 号车动态取景 |
| 动态 | 0～1 秒定位；首车刹车；约每 0.85 秒向后退一辆车；末段完整车队观察 |
| 文案声音 | 旁白 `b1`/`b2`；画面文案「一次轻刹车」与「1 号车与后车：x.x 车位」；1 次提示音标记首次刹车 |
| 验收条件 | 撤去标题仍能看出灯态向后传递；393 宽下 1～6 号车与制动灯可数、灯态顺序可辨 |
| 传播贡献 | 第一次可见因果；风险是车太小、灯态变化不够显眼 |
| 内部镜头 | `wide` 0～2.2 秒看整段车队；`close` 2.2 秒后推近 1～6 号车，交界处保持同一道路中心线 |

### `relay`

| 列 | 设计 |
|---|---|
| 位置与作用 | 第 4 场；主线机制揭示 |
| 观众问题 | 后退的是同一批车吗？ |
| 核心可见事件 | 无瓶颈环路中，蓝框车 8 号持续前进，红色慢区依次换车并向后退 |
| 叙事任务 | 证明后退的是区域而不是车，回答开场困惑 |
| 美术 | 环路占画面中部，环外只留暗纹；车辆 2.6 倍、车长约 120 px；红区半透明；蓝框车始终可见，不加易重叠的浮动标签；标题 76 px |
| 技术 | 高频组 t=7～22 秒；环路坐标与车辆位置同源；慢区由速度阈值派生；缩放 1.02→1.18 |
| 动态 | 先全景看红区绕环后退；再推近跟拍蓝框车；慢区经过后车时逐车亮灯 |
| 文案声音 | 旁白 `l1`–`l3`；画面文案「同一团拥堵，不同的车」；无新增音效 |
| 验收条件 | 393 宽下能同时跟踪蓝框车前进与红区换车；环路无路口/出口可见 |
| 传播贡献 | 全片认知高潮；风险是环路太小、红区移动不易跟踪 |
| 内部镜头 | `ring-wide` 0～8 秒；`ring-follow` 8 秒后推近，交界不改变环路中心与光源方向 |

### `density`

| 列 | 设计 |
|---|---|
| 位置与作用 | 第 5 场；补充解释，不争夺主线 |
| 观众问题 | 为什么有时越堵越大，有时会散？ |
| 核心可见事件 | 同一扰动下，密集车流速度跌幅更大，稀疏车流逐渐恢复；曲线与道路同源 |
| 叙事任务 | 补充密度条件，明确不是所有堵车都由一次刹车造成 |
| 美术 | 上下两条道路共用采样时间；曲线在下方；红/青语义与全片一致；「补充」徽标；曲线坐标字号 24～26 px |
| 技术 | 高频组与低频组 t=7～18 秒；曲线直接采样第 6 辆车相对速度；不做第二条手工曲线；两条道路共用慢区中心取景 |
| 动态 | 先按 ① 呈现两条车流的密度与响应差异，约 2.6 秒后 ② 再揭示曲线；末段标注「预设模型 · 非实测」 |
| 文案声音 | 旁白 `d1`/`d2`；画面文案「① 先看车流」「② 第 6 辆车 · 相对速度」「补充解释」；无新增音效 |
| 验收条件 | 393 宽下先看出两组密度差异，再看曲线跌幅差异；曲线与道路变化一致；「补充」定位清楚 |
| 传播贡献 | 解释边界与可信度；风险是图表信息过密，手机尺寸读不清 |
| 内部镜头 | `roads` 0～6 秒；`chart` 6 秒后曲线区上移占主位，交界保持同一配色与时间轴 |

### `return`

| 列 | 设计 |
|---|---|
| 位置与作用 | 第 6 场；主线回扣与来源 |
| 观众问题 | 这和我的经历有什么关系？ |
| 核心可见事件 | 蓝框车 8 号继续驶离，后视镜里红色慢区退向身后；空路与「拥堵波」结论同框 |
| 叙事任务 | 把机制收束为「你穿过了一道波」，并给出唯一来源与示意边界 |
| 美术 | 与 `empty` 同一构图和光照，形成首尾呼应；道路高 450 px、车辆 2.4 倍；后视镜 470×330；「拥堵波」大字放在空路留白；片尾来源 26/24 px |
| 技术 | 高频组 t=19～23 秒；后视镜与主画面同源；来源文字静态，口播不再重复来源 |
| 动态 | 主画面继续前进；后视镜红区缩小；结论句在 `f1` 后淡入；尾留 60 帧、阅读停留 30 帧 |
| 文案声音 | 旁白 `f1`/`f2`；画面只保留标题与唯一片尾来源声明，不再重复「车继续向前，波留在身后」；无新增音效 |
| 验收条件 | 393 宽下能回指开场「前面什么都没有」；结尾无重复文案，来源只出现一次且不暴露内部文件 |
| 传播贡献 | 情绪与记忆点收束；风险是结论句重复旁白、片尾过慢 |
| 内部镜头 | `exit` 0～7 秒；`mirror-reveal` 7 秒后后视镜放大并定格，主画面保持前进 |

## 配色

深色底（`#050b13`）压低界面存在感；道路用蓝灰层级区分路面、边线与车道虚线；车辆本体为
冷白，制动灯与低速区域统一使用橙红（`#ff6b4a`），前进方向与蓝框追踪使用青色（`#5ad9f0`）。
全片只有「红=慢/向后」和「青=快/向前」一组语义色，图表沿用同一组颜色。纸面方向 A 使用
暖纸与深墨，已在选案中淘汰，不进入成片。

## 构图

每场只突出一个问题，不常驻「标题+说明+结论+注释」四层。开场与结尾用同一条俯视道路，
后视镜 inset 固定在右上；回放场用拉远道路与上下箭头；刹车场用局部放大与车距标注；环路场
把闭环放在画面中部，城市街区只作暗纹；密度场上方道路、下方曲线，明确标「补充」。车辆、
制动灯、低速带与曲线共用离线轨迹，不手绘第二条波。

## 声音

无配乐；保留中文旁白与烧录字幕，只使用 1～2 次内置提示音标记回放与首次刹车，增益低于
旁白且不影响口播。旁白段之间按内容留白。音色按完整旁白与服务返回元数据选择，未试听，

## 后续设计与评审应用（2026-10-23，非重制记录）

本节仅示范后续采用[核心体验设计](../../.agents/skills/material2video/references/creative-production.md#核心体验与表达设计)和[诊断适用性](../../.agents/skills/material2video/references/visual-review-rubric.md#诊断测试与适用性)的方式；未新增试制、候选比较或成片复核，不改写既有交付结论。

- 设计重点：强化“前方空、后方红”与车辆向前／慢区向后的关系；候选比较视点、揭示次序及声画分工，辅助密度段落不应与核心发现争强度。
- 评审重点：立即辨认车辆与方向，机制允许在完整解释窗口后理解；前3秒的疑问不能直接当作全片误读。图表与文字本身不是失败，但完整窗口后仍把慢区当成同一批车属于核心缺陷。
- 返工取舍：更早给结论可能减少困惑，也可能泄露发现；比较理解收益、悬念与结尾回报，不以更短或更直白自动判优。
