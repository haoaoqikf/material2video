# 每一次尝试都留下反馈

这个示例把“尝试要留下可用于下一次选择的反馈”表达为一个持续的计数仪表世界。一个读数、一把四周刻度尺与“尝试—反馈—下一次”回路贯穿全片，标题、数值、端点和关系状态推动论证。

- `article.md`：145 字的示意型输入；不含标题、标点与空白。
- `storyboard.json`：v4 单一 tree 世界，四个叙事阶段、17 条全局对象状态轨道，声明时长 37 秒。
- `motion-design.md`：持续对象、阶段变化与示意数字口径。
- `review.md`：本轮静态、动态、连续性及范围限制的验收记录。
- `production.template.json`：制作记录模板；本地制作记录和媒体不入 Git。

输入语义审查通过。最终口播 144 字；配音派生总时长 36.07 秒（1082 帧），在 35～45 秒范围内。严格 v4 校验、12 帧真实媒体抽检和确定性随机寻帧检查通过，探针 0 错误、V1–V5 通过、V6 为 4/5。关键阶段、全片静态/动态、连续性五项记录均通过；1080×1920 @30fps 的 H.264 有声 MP4 解码验收通过。

数据 73 次、第 1 周 2 条、第 4 周 14 条均明确标为示意；中间周次缺测，不补造数据。A 系列自动动画论证目前尚未适配 v4 全局时间轴；TTS 音色未做独立听觉评分，观感闸门 K2–K9 也因契约页未提供对应设计语言事实而跳过。完整证据见 `review.md`，产物与带摘要的 AI 制作记录写入忽略 Git 的 `videos/examples/declarative-number/`。
