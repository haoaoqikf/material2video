# 从“连续寓言”到“连续论证”

《让积累，参与下一次》的近期创作复盘。主体记录多寓言版本、40秒V4重设计及R5第10秒修订；R6补记见文末。原68秒版本是另一历史周期，不与本轮混写。

本片最值得借鉴的，是**不断改变观看任务，同时让观众认回正在讨论的同一件事**。数字、大字、插画和图表的变化负责新鲜感；同一问题、模型、颜色与接棒关系负责连续。以下结论来自成片、源码、用户反馈与有序帧观察；并无平台留存实验、首次观看测试或实际试听，不能推导出“观众不会划走”。当前媒体与审核范围见[验证记录](VERIFICATION.md)。

## 1. 先给每种形式分配新的认识

最近一次重设计的起点是用户指出：雪球卷雪、树木再结种、知识再连接，虽然对象不同，本质都是寓言。连续替换题材并没有充分改变阅读方式。V4撤去后两个寓言，改为一个问题逐步走向答案。

| 时间 | 形式 | 观众此刻要做什么 | 为什么这一段值得存在 |
|---|---|---|---|
| 0–3秒 | 滚动数字 | 记住100和1%，想知道100轮后会怎样 | 提出未解问题，暂不公开270.48 |
| 3–7秒 | 大字与运动小球 | 抓住“让过去的成果参与下一次” | 从数值切到命题，文字同时成为球的路径与落点 |
| 7–11秒 | 一个雪球 | 用直觉理解已有体量影响后续积累 | 让抽象关系变得可感，不承担精确计算 |
| 11–17秒 | 表格逐行递推 | 分清总量和本轮新增 | 说明新增为何会进入下一轮基础，而非只说越滚越大 |
| 17–23秒 | 同起点双线 | 看前期接近、后期分离的过程 | 增加时间趋势，不只是重报末值 |
| 23–29秒 | 三组柱形 | 比较10、50、100轮的差值 | 将连续趋势变为三个可对照节点 |
| 29–35秒 | 分步公式与答案 | 把刚看到的关系压缩成模型 | 公式在理解之后出现，回答开头问题 |
| 35–40秒 | 结论回认 | 带走同一句命题 | 收束，不再引入第四个例子或新课程 |

**可迁移做法：**写分镜时，先给每段补一句“这一段比上一段多让观众知道什么”。再决定它该用文字、对象、表格还是图。两段若回答同一问题且没有新的比较，优先合并；不要靠再加一种图表挽救重复内容。

**边界：**并非每条视频都需要七种形式。有些题材靠一个连续对象就足够。本片的多样性成立，来自任务不同；不是因为形式数量达标。

## 2. 用少量不变量承受大量变化

表格、曲线、柱形、公式共用一个数学定义：初始100，每轮按现有总量增加1%；对照固定加1，不追加投入。白色与金色的对照意义维持，数字的来源和轮次不随换图改变。三幕中既有巨型数字，也有较密的表格，但每拍主要焦点仍明确。

这减少了“换一幕就重新学一套规则”的负担。雪球只保留直觉，不强行证明1%的模型；数字段把口径重新公开，避免把自然比喻误写成量化事实。

**可迁移做法：**在允许变化的排版、尺度和载体之外，选出少数必须稳定的东西：对象身份、数值定义、颜色含义或空间方向。复杂信息用相同基础连接，不要求所有画面长得相同。

**边界：**本片固定增速是解释机制的假设，不能迁移成“学习每天进步1%就必然得到某个倍率”的现实承诺。金融题材还需要自己的真实数据和口径。

## 3. 前一幕给出下一幕的入口

几处接棒的价值在于，观众已有一个可以继续跟随的东西：

- 数字的小数点脱离，接成运动小球；小球穿过大字再落向雪面，尺度和阅读方式改变，注意力仍有去向。
- 表格里的103.03离开总量列，接向曲线位置。表格并非结束后被整页抹掉，而是把一个结果交给时间过程。
- 柱形100轮中的“100”抬向公式指数，让轮次和指数建立可见联系。这里是语义与焦点接棒，不是跨字体逐像素同形。
- 公式答案的小数点再次接球，结尾回到最初的命题，使回认有来源。

**可迁移做法：**设计转场前，先找前后两段真正共有的量、对象或问题，再决定谁留下、谁退出、下一段从哪里长出来。过渡应覆盖出发、移动、减速、落定及下幕认回；只检查两端截图会漏掉中间丢失焦点的问题。

**边界：**不要为了统一而让每次都变成小球，也不要把有意义的硬切全部改成形变。接棒承担的是关系，不是转场特效展示。

## 4. 第10秒：把“发生了”改成“能认回”

V4原先在约10.67–11秒内完成雪球突然铺满、球内短暂出现100、再切暗底表格。整个过渡约10帧，数字同时改变位置、大小、格式和背景。用户实看指出“一闪而过，根本不知道发生了什么”；先前技术和独立审核通过并没有排除这个体验问题。

R5把动作重新分配：

| 时点 | 实际变化 | 作用 |
|---|---|---|
| 9.6秒 | 雪球完成增长，局部释放 | 先让寓言结果落定 |
| 10秒起 | 球收小、上移，地线和旧字幕退出 | 清理竞争信息，给下一对象落点 |
| 10.467–10.6秒 | 100.00显现并完全显示 | 公开完整格式，而非只短暂闪出100 |
| 10.6–11秒 | 数字停住 | 给认回窗口，随后继续存在于首行 |
| 11秒 | 表格在同一数字周围出现 | 延续位置、字形、格式、字号和颜色 |

收益不只是多出几帧，而是减少了数字重新定位：观众刚找到的100.00没有再跳走。此处满屏白擦与整屏粒子撤掉，局部接触碎屑仍作为标点。

取舍同样明确：原版近景更有冲击，球体与球内100的直接关联更强，9–10秒持续长大的张力也更明显；新版牺牲这些，优先解决数字认回与表格承接。球退出和数字显现之间有极短的低亮度间隙，不能描述为球体严格形变成数字笔画。

**可迁移做法：**遇到“一闪而过”，先排查是否同时更换了对象、位置、尺度、字形、格式和背景。优先保住一个能认回的锚点，清理竞争信息，再调整动作与阅读时间。不要一律延长，也不要统一压成半秒。

**边界：**本片10.6秒不是通用阈值。真正条件是完成动作后能认回下一段，而不是停留达到了某个秒数。真实速度下的舒适度仍需实际观看反馈。

## 5. 释放制造标点，结果承担信息

R5保留数字锁定、曲线结果、柱形结果和公式答案的四处整屏Impact事件；雪球改为局部接触释放。事件起点不等于粒子面积或亮度的峰值。它们复用已有预设，并不是五种新发明的特效；提案中的窄带扫光没有实现。

较有效的地方是：光效有明确来源，先出现结果再强调，释放时仍能看见关键数字，回落后继续读结果。最后答案承担较强释放，结尾则让粒子收势、文字留下。对比来自强弱和用途，而非全程持续刺激。

**可迁移做法：**为每次强调写出“谁触发、为什么此刻、峰值后读什么”。如果答案只是“这里该切场了”，先重做承接。把光效峰值和文字完整阅读分开核对，可以重叠，但不能抢走唯一焦点。

**边界：**不照搬四次释放，不用连续高频白闪维持注意力。R5已说明：撤掉一次满屏冲击，可能让整段更有用。

## 6. 悬念靠信息顺序，结尾靠回报

开头滚动数字让变化发生，却只展示前几轮，把100轮答案留下。中段先给机制，再给过程与差值，公式到后段才总结。因此270.48既是计算结果，也是开头问题的回报。结尾复现“让积累，参与下一次”，不再新增一个寓言。

**可迁移做法：**区分“必须立即理解的设定”和“可以稍后回答的问题”。悬念期间仍要持续提供进展，不能把关键定义藏到末尾；结尾回答问题后只保留必要收势。

**边界：**公式不必每片都有，也不能替代前面的机制解释。大数字滚动本身不是悬念，必须有观众知道自己在等的答案。

## R6：从《运气到底是什么》借鉴的精修

新并列示例把尝试者留在数字与图形附近，并用更大的主信息、条件逐项改变和少量结果强调保持认回。R6将这些经验转译到复利片自身，不借用水滴造型或概率内容：

| 观察到的差距 | 本片修改 | 预期作用与取舍 |
|---|---|---|
| 手机尺寸下表格与图例弱于主体 | 表格模型说明、列头、数值和图例提高字阶 | 口径与比较不再依赖放大查看；同屏密度上升，需查遮挡 |
| 开场连续滚数与“第 N 轮”错位 | 数值和轮次改由同一离散轮次计算，首帧为第0轮的100.00 | 观众可逐轮核对，少了原本连续插值的流动感 |
| 折线集中在画面中段，终点和读数偏小 | 图区横向扩大，端点读数增大并固定在点左侧 | 避免靠近右边界时突然换位，保留一条可追踪的金色端点 |
| 表格的103.03刚接折线时压住左侧坐标 | 折线读数设安全落点，从左轴右侧平滑接回端点 | 保留接棒窗口的读数，避免裁切与轴标争位 |
| 三组柱形切换时焦点靠碎屑提示 | 同一金色球从折线落到第一柱，再按10/50/100轮逐组跃向柱顶；两柱间距扩大 | 条件比较有连续可认回的引导，数值仍由柱高而非球的位置表达 |
| 字幕提前说出最终差值 | 先只说“差距，正在放大”，待100轮柱落定再公开0.46→70.48 | 让结论由可见比较产生；最后一句阅读时间变短，需复核 |
| 柱形生长时的滚动数字被误读为该轮结果 | 柱体先成长，到达终值才显示轮次和固定终值；模型口径改用更明亮的字色 | 任一可读状态只给出成立的数值，避免100轮暂时小于50轮 |
| 手机尺寸下柱底三组差值难以逐个读出 | 当前完成的差值带轮次在柱组左上方放大，随下一组结果更新；柱底仍保留三组对照 | 每个差值在揭示时成为主体信息，不因固定位置误配到第一组，且不撞柱顶数值 |
| 曲线结果与柱图结果连续使用整屏冲击 | 曲线结果撤去整屏冲击，只保留端点与对应事件音；柱图末值保留释放 | 强弱跟随论证进程，曲线到柱图的阅读更安静；曲线段少一处强标点 |
| 柱顶碎屑与公式粒子容易抢读数 | 减少粒子数量和行程，保留触发位置 | 结果优先，局部触感仍在 |

这些是制作选择，是否达到目标以R6当前成片的原生/手机尺寸检查和独立复核为准；旧R5通过不自动迁移。

## 附录：影响成片的几项制作教训

- **柱图文字重叠：**将差值移到独立行，为柱顶值、轮次及字幕分别留空间；不靠缩小所有文字或增加重叠豁免。数据正确还需要能比较。
- **公式接入跳位：**用phantom保留公式排版宽度，按实际离线KaTeX字形量测上标落点，并等待字体就绪。估计坐标可能在切换那一帧暴露。
- **雪球轮廓：**把旋转放到球内纹理，外轮廓保持稳定，减少抖动及旋转包围盒对字幕的虚碰撞；不通过放宽量测掩盖画面。
- **声音响度：**首个候选略低于目标容差后，调整原创合成强度再测真实AAC封装；总时长相同不能证明听感或音画节奏通过。
- **用户反馈优先于旧通过：**R5保留失败历史、重新覆盖跨场窗口，再做当前独立复查。评审是发现问题的方法，不能当作体验永远正确的保证。

这些经验服务下一条片的判断，不增加新的固定门禁。重建和修改入口见[README](README.md)与[HOWTO](HOWTO.md)。
