# 修改练习

先读[创作复盘](CASE_STUDY.md)。建议只调整一次接棒或一次结果释放，再观察完整窗口，而不是同时增加形式和光效。

1. 在`assets/compose.py`调整一个命名事件，重新运行compose、prepare；画面与拟音应共同引用该事件。不要单独修改生成的分镜。
2. 修改雪球到表格的衔接时，查看9–12秒：对象收束、数字完整显现、稳定、表格出现及下一行推进都要覆盖。数字落点、格式、字体、颜色和尺度须与表格首行共同核对。
3. 修改图表时，从唯一模型取数。表格解释新增进入下一轮，折线解释连续分离，柱形解释指定轮次的差值；若只是重复终值，应先重排用途。
4. 修改光效时，核对来源、建立、峰值、回落和结果阅读。可以牺牲一次满屏冲击换取理解，不把原时长、八节拍或光效数量当成固定标准。

声音参数修改会使原固定摘要失效；须说明改变原因并重新测量登记、独立核对和QA，不能让恢复器自动接受漂移。核心关系或时序改变后按既有风险策略重新试制、独立审核，再生成完整候选。技术检查不代表真实速度感、听感或留存通过。
