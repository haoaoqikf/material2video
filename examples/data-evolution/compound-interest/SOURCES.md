# 《复利》来源与口径

- 数学模型：本金10,000元、固定年收益率10%、按年结算、无追加投入；不计税费及通胀。10%是数学演示参数，不是市场数据或预期收益承诺。
- 取出收益组：取出的收益留存，不消费也不再生息；累计总额为 `10000*(1+0.1*n)`，第30年40,000元。
- 再投入组：每年收益留在原账户共同参与下一年增长，累计总额为 `10000*1.1**n`；只在显示时四舍五入到元，第30年174,494元，拆分为158.631枚米白与15.863枚金。
- 差额：第30年再投入组比取出组多 `174,494 - 40,000 = 134,494` 元；本版结果屏只显示枚数，差额仅作为数学口径与测试依据，不上升为画面文字。
- 圆片：1枚=1,000元，直径按面积（√金额）缩放；0.1、0.631、0.863等分数片按实际金额绘制，低于0.25的尾数不画也不并入整枚。
- 参考片：《重复》，抖音视频ID `7692873023291963558`，用于叙事与视觉机制分析。参考文件不分发，不进入本片素材或声音链路。
- 图形：本例原创SVG与React代码，无第三方图片视频。
- 声音：一条29秒原创确定性合成环境床（前8秒数字静音、8.0秒淡入、28–29秒淡出，无旋律/节拍/和声）与25个原创事件音，无旁白、无旋律配乐、无第三方采样。许可见 [assets/LICENSE.md](assets/LICENSE.md)，完整配方见 [assets/recipe.json](assets/recipe.json)。
- 字体：使用登记的Noto Sans SC与Inter（注册名 `M2V Sans`／`M2V Inter`），来源、摘要与恢复目标见fonts/registry.json；许可文本入库，字体二进制不入库。

恢复：`uv run python examples/data-evolution/compound-interest/assets/fetch.py`。已有文件必须与登记摘要、24kHz、PCM16、单声道及时长一致，否则拒绝覆盖；生成媒体不入库。8秒静音是环境床资产的一部分，不是 `music` 字段的起始偏移。
