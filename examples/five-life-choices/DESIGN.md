# 五种选择，五种人生 · 30秒剪纸版设计

当前目标：30秒 / 900帧 / 1920×1080 / 30fps / 无旁白、有轻节奏音乐与三个动作音。画面以暖白纸张、深墨色主体和单一橙色强调色构成，使用有厚度的剪纸形体与清晰的剪影动作。

制作参考：[视觉创意方向](../../.agents/skills/material2video/references/visual-creative-direction.md) · [视觉力量设计](../../.agents/skills/material2video/references/visual-impact-design.md)

## 核心表达

人生不是沿着一条预先写好的路前进；城市、行业、关系、投资与学习，都会改变一个人可以走的路。

## 美术方向

- 载体：二维剪纸小世界。纸片使用实体色块、干净轮廓和短而柔和的投影；道路、楼群、桥、积木、书页和人物都是可辨认的实体，不以细线网格代替空间。
- 配色：暖白纸面、深墨灰人物与结构、单一暖橙强调色。每一幕用构图与动作区分，不添加第二强调色、无关颗粒、霓虹、网格或装饰性光效。
- 人物：同一位简化的深色纸片人作为行动锚点。姿势清楚、重心落地；配角只在关系段出现。优先保证手机尺寸下人物、道具与接触动作可辨。
- 镜头：以正面或轻俯视的舞台构图为主。段落通过人物出入画、道路横移或直接剪辑连接；不要求连续空间或一镜到底。
- 文字：主句短、清楚、稳定停留，不遮住道具和动作。无旁白时中文主文案与动作共同传达观点。

## 七段与时间预算

帧区间左闭右开，片长固定900帧。

| 段落 | 时间 / 帧 | 画面事件 | 主文案 |
|---|---|---|---|
| 开场 | 0–3秒 / 0–90 | 一个人物从岔路共同起点出发，橙色支路向前展开 | 同样的起点 |
| 城市 | 3–8秒 / 90–240 | 楼群窗格机会密度不同；人物沿橙色上升路径前行 | 城市，改变机会 |
| 行业 | 8–13秒 / 240–390 | 两个人物沿平行路线移动；较快路线迅速前移并抬升，进度差异显现 | 行业，改变速度 |
| 伴侣 | 13–18秒 / 390–540 | 两人各持桥板一端，配合接合后共同通过 | 伴侣，影响方向 |
| 投资 | 18–23秒 / 540–690 | 人物留下一块积木；时间经过，积木逐层形成可走的台阶 | 投资，积累未来 |
| 学习 | 23–27秒 / 690–810 | 面前的书页展开为阶梯，同一人物踏上并通过障碍 | 学习，打开可能 |
| 结尾 | 27–30秒 / 810–900 | 五种道路形状快速回闪，人物继续向前后定格 | 每次选择，都在塑造以后 |

三个重点瞬间：城市橙色机会路径显现、桥板接合、书页展开成阶梯。其余动作简洁有力，完成后给结果留出观察时间。行业只表达路径条件导致的相对进展，不暗示行业排名；投资的积木只是抽象积累示意，不表达收益保证。

## 声音

无旁白。使用轻节奏器乐作为整条音床；城市机会路径显现、桥板落位、翻书各有一个与动作同步的声音。来源、许可、摘要与时间编排登记在 `SOURCES.md` 和材料中。若音效许可要求署名，片尾只集中出现一次简短署名。

## 目标关键帧与盲审门

动画前独立制作七张无文字静态目标图：开场、城市、行业、伴侣、投资、学习、结尾，放在本地 `videos/examples/five-life-choices/outputs/design/keyframes/`。它们是设计目标，不由动画场景截图生成。按1920、852和393宽检查，393宽只要求主题、人物和主要物件可辨，不要求正文小字可读。

每张图的中性评审包只含图像、时间码和“描述你看到了什么”的问题，不含本设计文档、章节名、设计理由或预期答案。先由隔离评审记录观察，再核对目标理解；理解成立仍须单独判断构图、纸张层次、主体比例、动作辨认和吸引力。全片关键帧集合还须检查七段是否只是同一种构图换道具。必改项未关闭时不进入动画。关键帧通过只授权进入动态验证，不授权成片。

静帧门禁最终由 K11 隔离盲审通过：全尺寸主体/动作、连续性和393px单帧均通过，无未关闭必改项。此前盲审推动了城市步道清理、书页阶梯明确踏面、中央连接物和人物脚部留白、独立橙色积木，以及结尾人物放大。K11 偏好项（行业箭头避开人物、学习段书阶接缝可更松）记录为精修观察点，不阻断动画验证。评审包、逐轮意见和图片留存在忽略的 `videos/examples/five-life-choices/outputs/review-packs/` 与 `review-pack/`。

## 最高风险动态

先制作23–27秒学习段的完整四秒动态窗口：建立障碍、书页连续展开成阶梯、同一人物踏上并越过、停留观察结果。评审材料含按动作转折加密的完整帧序列及时间码，明确检查身份连续、折叠关系、脚步接触和结果是否读得清。动态理解与视觉表现分别判断；均成立后再扩展全片。

K14隔离动态盲审确认理解和动作表现通过。多轮动作样片发现并关闭了人物踩到书页、脚底与阶梯描边重叠、立面接触含混、末级站位贴边、台阶初始形状低于地面及障碍方块穿插等问题。最终采用更宽的六级踏面、直立人物剪影和居中停留；结果由帧序列和393px单帧共同复核。可复用的匿名评审包由 `scripts/create_review_pack.py` 生成，按样本编号、间隔和完整 SHA-256 清单留证。

## 边界

- 所有道路、场景与人物均为象征性示意；不规定固定年龄、行业排名、投资回报或唯一成功路径。
- 只保留已确定的短句及五项变量名；片中不出现仓库路径、来源说明小字或制作提示。
- 最终复核覆盖完整30秒、852×479及393宽帧序列，记录实际摘要、时间范围、缺陷关闭状态与覆盖限制。不以“看懂了”替代视觉完成，不宣称真实观众记忆、留存或保证惊艳。
- 作品内容、目标关键帧、渲染候选及评审包均保存在仓库外忽略的 `videos/`，不提交生成媒体。
