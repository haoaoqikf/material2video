# 普通人一生真正重要的 5 个选择

60 秒、1920×1080、30 fps 的无声横屏动态图解。一条 2.5D 人生时间轴从左侧向右侧、同时向远方延伸：x 是年龄，y 是分支高度，z 是纵深。镜头沿轨道持续推进，在城市、行业、伴侣、投资与持续学习五处分岔，结尾后拉成一棵填满横屏的决策树。

无旁白、配乐、音效与素材原声；成片无音轨或全程数字静音。面向抖音式横屏手机观众，按 852×479 CSS 像素复核，另查 393 宽缩略显示。

## 场景

| 场景ID | 时间 | 内容 | 画面推进 |
|---|---:|---|---|
| `life-timeline` | 0–60 秒 | 五个选择与不可逆的时间放大 | 单幕连续录制：开场 → 城市 → 行业 → 伴侣 → 投资 → 持续学习 → 决策树 |

### 段落与画面文字

| 段落 | 时间 | 可见事件 | 画面文字 |
|---|---:|---|---|
| 开场 | 0–7 秒 | 光点拉出轨道，年龄 0/10/18/22/30/40/60/80 依次掠过，镜头沿轨道推进 | 人的一生，看起来有无数个选择。→ 但真正改变人生轨迹的，可能只有几个。→ 普通人一生真正重要的 5 个选择 |
| 城市 | 7–16 秒 | 北京/上海/深圳/杭州/家乡 五条支路展开；进入杭州；抽象城市与工作/公司/人脉/信息/机会/工资/项目 网络变密 | 城市，决定你每天会撞见什么机会。 |
| 行业 | 16–27 秒 | 传统制造/房地产/互联网/新能源/AI 五条跑道坡度分化，镜头拉远看巨大高度差 | 努力决定你跑多快。→ 行业决定你站在哪条跑道上。 |
| 伴侣 | 27–35.5 秒 | 第二颗光点进入；左右分屏：争吵/债务/内耗/焦虑 vs 支持/沟通/储蓄/成长/长期计划 | 伴侣不是人生的配角，而是最大的长期变量之一。 |
| 投资 | 35.5–44 秒 | 25→60 岁两条资产曲线前段重合、后段拉开；图表淡出只剩「时间」 | 时间 → 投资真正强大的地方，是让时间替你工作。 |
| 持续学习 | 44–52 秒 | 镜头升高；上方停止学习的轨道变窄，下方持续学习的知识网络变大 | 城市、行业、伴侣、投资，决定你走哪条路。→ 持续学习，决定你还能不能换路。 |
| 结尾 | 52–60 秒 | 镜头后拉；几十条路径组成决策树，主路径最亮；随后淡出到黑屏 | 一个人的人生，只是无数可能路径中的一条。→ 城市/行业/伴侣/投资/持续学习 → 人生的差距，往往不是一天拉开的。→ 而是几个重要选择，被时间不断放大。→ 选对方向，比一直用力更重要。 |

五项顺序固定为城市、行业、伴侣、投资、持续学习。年龄 22/25/30/35/45 是叙事刻度，不是对所有人的固定时间表；投资曲线只表达时间放大的方向性差异，标注为示意，不构成投资建议。

## 画面与技术

- 画面由 `scenes/life.tsx` 的 Canvas 逐帧同步绘制，`scenes/geometry.ts` 提供确定性世界、相机与投影，`scenes/render.ts` 分七幕绘制。
- 深黑背景、白/灰文字、少量蓝白发光；镜头持续运动，有明显的深度雾化、尺度变化与视差；不使用外部图片或视频。
- 全部动画只由 `elapsedSeconds` 推导；不使用随机、挂钟或 CSS 动画。

## 重建与验收

```powershell
uv run m2v validate --project examples/five-life-choices
uv run m2v prepare --project examples/five-life-choices
uv run m2v lookdev --project examples/five-life-choices --stills 12 --sample-seconds 6
uv run m2v preview --project examples/five-life-choices --start-seconds 52 --end-seconds 60
uv run m2v render --project examples/five-life-choices
uv run m2v qa --project examples/five-life-choices
```

成片位于 `videos/examples/five-life-choices/outputs/video.mp4`，生成媒体、候选与复核图像不入库。分镜为 `topic` 输入，没有原文；可编辑文案与标签在 `storyboard.json` 的 `content.props.copy/labels`。
