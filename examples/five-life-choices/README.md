# 普通人一生真正重要的 5 个选择

约 60 秒、1920×1080、30 fps 的无声横屏动态图解。一条 2.5D 人生时间轴从左侧向右侧、同时向远方延伸：x 是年龄，y 是分支高度，z 是纵深。镜头沿同一条轨道推进，在城市、行业、伴侣、投资与持续学习五处改变路径，结尾展开有层级的决策树。

无旁白、配乐、音效与素材原声；成片无音轨或全程数字静音。面向抖音式横屏手机观众，按 852×479 CSS 像素复核，另查 393 宽缩略显示。

## 场景

| 场景ID | 时间 | 内容 | 画面推进 |
|---|---:|---|---|
| `life-timeline` | 约 60 秒 | 五个选择与不可逆的时间放大 | 单幕连续录制：开场 → 城市 → 行业 → 伴侣 → 投资 → 持续学习 → 决策树 |

### 段落与画面文字

| 段落 | 时间 | 可见事件 | 画面文字 |
|---|---:|---|---|
| 开场 | 0–6.5 秒 | 主体沿轨道前进，在小岔口做出动作；四条淡支路出现，主体走主路；年龄刻度被扫亮 | 人生不是一条直线。→ 真正改道的，只有几个岔口。→ 普通人一生真正重要的 5 个选择（五项是常见视角，不是唯一标准） |
| 城市 | 6.5–15.5 秒 | 北京/上海/杭州/深圳/家乡 五条支路展开；杭州的新入口打开，主体走过入口并经过城市网络 | 城市，会改变哪些门对你打开。 |
| 行业 | 15.5–27 秒 | 传统制造/房地产/互联网/新能源/AI 五条跑道按同一世界距离前进；近景只给局部，拉远后公开完整高度差 | 同样努力，先看起来差不多。→ 行业决定你站在哪条跑道上。→ 拉远才看见：跑道不同，高度不同。＋不构成行业排名 |
| 伴侣 | 27–35.5 秒 | 支撑与牵制两条关系带在同一世界并行；两个主体交叉、分担或被拉开；支撑轨留下的抬升带继续存在 | 两个人一起走，路线会互相改写。→ 关系会改变坡度，也会留下痕迹。 |
| 投资 | 35.5–43.2 秒 | 25–47 岁的有界台地按持续投入垒高；主体沿台地边缘走；两条曲线从重合到分开 | 每天一点，时间会把小投入垒高。→ 同样的时间，留下与不留会分开。＋年龄刻度与示意说明 |
| 持续学习 | 43.2–52 秒 | 主路在 47 岁到头并出现端帽；先前学习线点亮；主体进入连接、经过连接、离开到新路继续走 | 原路会到尽头。→ 学过的东西，会在别处接上。→ 换一条路，继续走。 |
| 结尾 | 52–60 秒 | 镜头后拉，光沿已走路段回扫；五处决策的共享节点与一、二级分支逐层展开；全貌观察后才出现收束文字 | 你走过的，只是其中一条。→ 每一次选择，都长出新的可能。→ 方向会被时间放大，路也可以改。 |

五项顺序固定为城市、行业、伴侣、投资、持续学习。年龄 0/18/22/25/30/38/47/60 只是叙事刻度，不是对所有人的固定时间表；投资曲线只表达时间放大的方向性差异，标注为示意，不构成投资建议；行业高度差为示意，不构成行业排名。

## 画面与技术

- 画面由 `scenes/life.tsx` 的 Canvas 逐帧同步绘制，`scenes/geometry.ts` 提供确定性世界、连续路径、相机与投影，`scenes/render.ts` 分七幕绘制。
- 路径先离散采样，再建立累计弧长表；主体和行业光点按世界距离取样，不按数组下标取点。叙事年龄、主体路径进度与相机控制彼此独立，年龄停留不会冻结事件。
- 深黑背景、白/灰文字、少量蓝白发光；主造型是自发光细线，窄光带只用于行业高度差、学习断头与结尾一级分支。
- 结尾树使用共享节点、父子关系与一、二级分支，不使用大量随机偏移线；主路始终最亮、可认回。
- 全部动画只由 `elapsedSeconds` 推导；不使用随机、挂钟或 CSS 动画。

## 重建与验收

```powershell
uv run m2v validate --project examples/five-life-choices
uv run m2v prepare --project examples/five-life-choices
uv run m2v lookdev --project examples/five-life-choices --stills 12 --sample-seconds 6
uv run m2v preview --project examples/five-life-choices --start-seconds 43.2 --end-seconds 52
uv run m2v render --project examples/five-life-choices
uv run m2v qa --project examples/five-life-choices
```

成片位于 `videos/examples/five-life-choices/outputs/video.mp4`，生成媒体、候选与复核图像不入库。分镜为 `topic` 输入，没有原文；可编辑文案与标签在 `storyboard.json` 的 `content.props.copy/labels`。重制基线、评审包与问题证据保存在 `videos/examples/five-life-choices/outputs/`，由 `outputs/visual-notes.md` 直接链接。
