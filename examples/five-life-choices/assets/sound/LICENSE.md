# 音频素材许可

`score.wav`、`door.wav`、`bridge.wav`、`page.wav` 均由 `generate.py` 原创合成，不含第三方采样，按 CC0 1.0（https://creativecommons.org/publicdomain/zero/1.0/）发布。重新生成：

```powershell
uv run python examples/five-life-choices/assets/sound/generate.py
```

音频为 24kHz 单声道 WAV；音乐长 30 秒，三个短音效分别对应城市机会路径显现、桥板接合与翻页。音效素材不进入 Git，脚本与本许可随示例维护。
