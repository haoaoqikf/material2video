# 媒体素材许可

`assets/media/` 下的三列反馈记录图由 `generate.py` 用仓库已有 Playwright 与字体生成，为本示例原创，无第三方画面素材，按 CC0 1.0 Universal 许可分发，可复制、修改和用于商业作品。字体沿用仓库 Noto Sans SC 的 SIL OFL 许可。

文件以内容摘要命名，来源记录见 `assets/media-sources.json`。素材不是从网页下载的，因此来源页记为「未知」，署名与许可如实记录为示例作者与 CC0。

许可正文：https://creativecommons.org/publicdomain/zero/1.0/legalcode

这些是固定的示例输入，纳入版本控制；配音缓存、混音和成片是生成媒体，不入库。
