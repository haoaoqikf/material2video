# darts-trial-and-error 视觉设计

这份设计稿是**创作依据**，不参与运行时：它不进入分镜、不参与校验，也不是导出门禁。
改它不会让画面变化，要落实成 `scenes/` 下的代码后重新 `prepare` 才会。

## 画幅

1080×1920 竖屏。这一片是三个示例里唯一的竖屏作品：它的叙事是「一次落点 → 又一次落点」
的纵向推进，竖屏允许把三次投掷排成一列而不必缩小靶面。字幕安全区在 y=1580 起、高 200px，
画面内容一律止于 y=1556。

## 参考依据

- **靶场记分牌**：深色木质底、金色靶环、陶土色标记——陌生但可读的体育场馆视觉。
- **实验记录本**：把「假设 / 观察 / 调整」三列写下来的样子，用来接住文章里「把反馈写成
  记录」那一段。

## 视觉隐喻

- **靶面与偏差线**：靶心是目标，落点是结果，两者之间那条虚线就是这一轮的全部信息。
- **三列记录**：一列是打算验证什么，一列是实际发生什么，一列是下次只改什么。三列之间的关系
  比任何单列都重要。
- **反馈链**：三个环节串成一条链，箭头只在下一段旁白开口时亮起——链是一轮，不是一次。

## 字体与配色

| 用途 | 取值 |
| --- | --- |
| 底色 | `#16120e` 深棕黑 |
| 卡片 | `#221b15`，描边 `#3b2f24` |
| 正文 | `#f6efe4`，次要文字 `#b9a58c` |
| 主色 | `#e8a33d` 靶金：靶心、当前环节、结论 |
| 警示 | `#d9603c` 陶土红：偏差线、落点、没有改善的结果 |

字体沿用共享字体栈，字阶：标题 66 / 结论与环节 44 / 正文 32 / 注释 26。

## 代表构图

竖屏分三段：标题带（y 132–330）→ 演示区（y 390–1400）→ 结论带（y 1420–1556）。
演示区左内缩 108px，与字幕安全区的水平内缩一致，画面左右边缘对齐。

- **开场**（`opening.tsx`）：靶面居中，一支还没出手的箭悬在右上——「还没有落点」是这一幕的论点。
- **核心演示**（`aim.tsx`）：同一张靶面，三次落点依次飞入，各自带一条指向靶心的偏差线。
- **素材**（`record.tsx`）：已导入的示意表在左，三列说明在右。

## 镜头衔接

全部 `cut`。三次投掷之间不淡化：观众要能同时看到上一次落点，才能比较偏差有没有缩小。

## 运动

- 落点由 GSAP 驱动，触发条件是它自己那句旁白开口，不是固定时长。
- 落点飞入用 `power3.out`：先快后慢，停住的位置才是要读的信息。
- 底色与卡片是静止的，只有落点在动——运动只出现在承载信息的地方。

## 声音意图

这一片没有音床，只有旁白：试错主题需要的是「安静地把话说完」，垫乐会让「一次尝试」
听上去比实际更轻松。素材原声不进入母版，成片声音全部来自统一音轨。

## 与文章的关系

每幕对应原文的一个论点，旁白逐字来自 `article.md` 的表述。靶面落点、三列记录表都是示意，
画面角标固定写「示意」，`aim.tsx` 与 `record.tsx` 的结论行也各自说明「不是实验数据」。
涉及健康、安全与不可逆损失时，`bounds.tsx` 的第一条边界对此有明确表述。
