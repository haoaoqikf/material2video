## 本轮修掉的问题（首次评审发现）

1. 因果圆环用 `cycle` 原语时，闭环箭头画在轨道正上方、而三格卡片按几何布局落在同一位置，蓝色箭头压住顶部卡片文字 → 改用 `flow`(ttb) 表达因果链、`connector`(rtl) 表达回路：方向箭头是 30×30 内联 SVG，不旋转 160×32 的连接件，几何上不再重叠。
2. 初版把标题放在内容块顶部，顶部安全区墨迹 18.6%（阈值 5%），会被平台界面覆盖 → 标题压缩为单行、420px 高的仪表换成数值读数、链改为紧凑纵向排列，内容块在安全区内居中，安全区提醒消失。
3. 第一次评审时 pan 段结束后的 −22.4px 横向偏移一直保留到末帧，结尾构图与开场差 2.1% → 为 beat-5 增加一段 `pan`(right, 0.4)，末帧精确回到 x 0 与首帧同构图。
4. 作品目录里残留 v3 版本的 `outputs/inspect/review.md`（提到 claim/break/loop/takeoff 五幕与 halo、chain-arrow 等已不存在的节点），v4 体检会把它当人工结论读入 → 按 v4 单场景重写评审文件，只对本版本材料与探针读数下结论。
5. 口播初版只有 132 字（35.77 秒），贴近 35 秒下限 → 按 article.md 的说明句补到 148 字，实际 39.57 秒，与声明一致。

五项都已按当前版本复查（见 `rework` 记录与上面引用的帧证据）。

## 遗留限制

声音听感（TTS 音色、段间衔接）本轮**未做真实试听**：口播结论依据的是分镜中的口播文本、cue 边界与音轨结构（AAC-LC 44.1kHz 立体声、20 条 cue 与 beat 边界逐条对齐），不是听觉结论。另外，动画论证 A 系列尚未适配 v4 全片阶段时间轴（报告里是「待评审」），K2–K9 观感闸门对 v4 契约页不产出元素事实（32 条跳过），本记录的审美结论来自人工逐帧查看与页面探针读数而不是这两项机检。状态切换按 `step-end` 契约在 beat 结束帧瞬间生效（卡片变暗、读数 80→22 都不是渐变），这是声明语义的结果。要作为发布记录使用，仍需人工戴上耳机过一遍 39.6 秒的评审版。
