# 因果链标杆示例

这个例子把「拖延不是难度问题，而是对启动成本的高估」表达为**单场景动态叙事**：同一棵场景树贯穿全片——一条自上而下的因果链、链尾指回起点的回路箭头、以及一个启动成本读数，四阶段只改变对象状态与镜头。产品表达是「一个观点，一个场景，一段动态叙事」。

## 文件

- `article.md`：标准篇幅的观点型输入（正文计 149 字，180 个码点）。
- `storyboard.json`：v4 单一 world（`friction-loop`，renderer `tree`）、四个叙事阶段、六条全局动作、十四条状态轨道与五段镜头声明；场景树 15 个节点（三张卡片 + 两个链内方向箭头 + 一个回路箭头 + 动作卡片 + 数值读数 + 标题与注脚），7 个已声明对象。
- `review.md`：本轮标杆验收记录（材料摘要、结论与本轮修掉的问题）。
- `production-workflow.md`：制作记录、评审材料与返工项的填写流程。
- `production.template.json`：抽象制作记录模板，所有结论为 pending，不构成本作品的通过记录。

本示例不使用作品级代码场景，画面完全由共享的 SceneTree 原语渲染；因此没有 `scenes/*.tsx`。

## 当前验收状态

已通过：Python v4 严格校验（4 个阶段 / 1187 帧 / 39.57 秒声明）、输入语义审查（149 字，`lengthStatus pass`）、语音准备与实际时长（口播计 148 字 / 39.57 秒，`durationStatus pass`）、关键幕（`claim`／`loop`／`turn`）与全片静态/有声动态评审、五项口播内容评审、五项连续性评审、`--check-determinism`（四幕收尾帧同帧重复截图完全一致，阈值 60 dB）、1080×1920 @30fps 正式 MP4 解码验收（1187 帧 / 39.57 秒，H.264 High yuv420p(tv,bt709) + AAC-LC 44.1kHz 立体声，20 条字幕 cue）。计数口径按 `article_text`：不含标题、标点与空白（正文 180 个码点 / 计 149 字），声明时长与实际时长都是 39.57 秒。

验收摘要与材料摘要在 `review.md`；带每项证据的本地制作记录在 `videos/examples/cause-chain/production.json`（不入库）。声音听感本轮未试听，K2–K9 观感闸门对 v4 契约页不产出元素事实，见 `review.md` 的遗留限制。

## 本地制作

从项目根目录运行 `validate.py`，先按 Skill 的输入审查流程检查 `article.md`，通过后再准备媒体和真实评审材料。生成的制作记录、评审材料与 MP4 位于忽略 Git 的 `videos/examples/cause-chain/` 下，不加入仓库。
