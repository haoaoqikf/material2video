# 程序化材质许可与边界

`generate.py` 及其原创输出按 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 分发。
固定解析式在目标分辨率逐像素求值，不包含第三方采样或旧图片放大。

- 法线与粗糙度是微表面艺术参数，不是 NASA/USGS 高程；不据此标注山脉或地形。
- 土卫六颜色图仅表示不透明雾霾，不展示未知地表。
- 不自发光天体的 emissive 为零是物理配置，不用于模拟反照光；地球夜灯和太阳日面来自独立登记素材。
- 原作者日间地图、地球法线、海洋遮罩及当前土星环原图不适用本 CC0 声明，仍保留各自许可，见作品 `SOURCES.md`。旧生成版土星环为CC0艺术示意，已退出当前生成器及恢复配方；当前环层的径向映射、透光和阴影也不宣称实测光深度。
- `saturn.py`是本项目的提取代码；其提取的土星云带原图和数值几何来自NASA VTAD，不适用原创输出的CC0声明。旧土星程序化normal/roughness/emissive已退出当前配方。
