## 本轮修掉的问题（首次评审发现）

1. 代码场景的 ECharts 选项里写了 `animation: false`，静态闸门按源码关键字判为按真实时间推进的 CSS 动画，体检在打开页面前就停下 → 删掉该字段，只依赖 `useFrameChart` 内部强制关帧动画。
2. 首版面板 984×1074 铺满安全区，K1 留白预算在分布与预算两幕实测 0.3942／0.3748（低于 0.4 阈值，2 条提醒）→ 面板收紧到 930×980（四行高度、内边距、图表画布 214、链路画布 168 同步下调），四幕全部通过。
3. 作品目录残留 v3 的 `outputs/inspect/review.md`（提到 icon-card/graph-flow/quarter-chart 等 5 个已不存在的场景与旧评分维度），v4 体检把它的「图形论证 4/5」当成人工结论、定制动画评审报「评分维度与当前契约不一致」→ 按 v4 四幕重写，并补上四幕 × 五维的定制动画动态评审表。
4. 分镜里显式写了 `"soundtrack": null`：Python 校验器按「没有声音素材」接受，但 `prepare.py` 与媒体清单校验崩在 `None` 上、契约页 schema 也拒绝 `null`（页面空白、体检报「等待 window.__A2V__ 定义超时」）→ prepare.py 与 media.py 统一成 `source.get("soundtrack") or {}`，契约页 schema 改 `nullish()`，并加了 Python 与 web 两侧用例。
5. 首版按库名直接引了 `Activity`/`ChartColumn`/`Gauge`/`Network` 四个 Lucide 图标，其中 `Activity` 不在受控图标白名单内，`tests/test_icon_bundle.py` 实测它为「与白名单无关的图标进了包」而失败 → 四个图标换成白名单里的 `Target`/`Clock`/`Link`/`CircleDollarSign`，库技术覆盖不变。

五项都已按当前版本复查（见 `rework` 记录与上面引用的帧证据）。
