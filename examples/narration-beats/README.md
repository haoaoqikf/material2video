# 进度为什么看不见

本例把“看见过程才能判断下一步”表现为同一条工作路径：拆分步骤、比较节奏、验证反馈，再调整下一步。3个叙事阶段沿用同一棵流程树，口播按语义节拍与字幕同步。

- [文章](article.md)：141字，符合130～170字标准。
- [v4分镜](storyboard.json)：3个叙事阶段，1080帧声明时长；媒体实际时长36.80秒。
- [动作设计](motion-design.md)：记录持续路径的对象身份与语义节拍。
- [评审摘要](review.md)：记录静态、动态和连续性评审及量测限制。

评审与成片媒体保存在忽略目录 `videos/examples/narration-beats/`，不进入 Git。
