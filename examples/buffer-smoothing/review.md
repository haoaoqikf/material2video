- 静态：主体尺度、连续构图重复、信息密度、视觉母题、高潮分量全部通过。机检提出的「相邻幕构图与视觉关系复用」（opening/direct、structure/smooth、smooth/overload）已逐幕裁决：同一管路母题下的状态与声明不同（空管 → 排空、近箱空 → 满水、满水 → 溢流），不是模板化复制。六幕 `visualIntent` 也已按各自的信息关系分别声明（contrast / cause / sequence / cause / contrast / collection），`validate.py --strict` 零警告。
- 动态：动作解释力、口播同步、节奏变化、结果停留全部通过。画面活动峰值恰好落在六幕边界（7.5 / 15.5 / 23.5 / 33.6 / 42.6 秒），末秒活动量 0.00–0.14，说明动作跟着 beat 走、结果有停留。
