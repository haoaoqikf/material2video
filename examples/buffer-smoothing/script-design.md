# 缓冲区如何吸收波动：口播设计

观众：无专业背景的普通用户。核心问题：平均输入相同，为什么输出仍会忽快忽慢？认知转折：缓冲用存储换取时间，不会增加长期处理能力。

| 场景 | 段落目的 | 解释职责 |
|---|---|---|
| opening | 前三秒建立问题 | 突发输入与平稳输出的视觉矛盾 |
| direct | 建立没有缓冲的直觉 | 入口一停，出口立即停 |
| structure | 认识水箱结构 | 入口、存储空间和限流出口 |
| smooth | 解释积累和释放 | 高峰存储、低谷补充，输出保持稳定 |
| overload | 揭示边界 | 持续流入超过出流，有限容量最终溢出 |
| conclusion | 回扣开场 | 平滑短期波动，长期仍受处理能力限制 |

最终口播只在 storyboard.json 的 narrationSegments 中。水箱为机制隐喻，流量是示意单位，不代表真实系统性能；缓冲也会引入等待时间。
