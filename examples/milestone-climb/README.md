# 把目标切成台阶

本例把“里程碑让大目标变得可行动”表现为同一条持续向上的台阶路径。开场以整面墙呈现目标压力，中段突出下一阶并将示意计数从2推进到6，高潮在口播说明后将计数推进到11；人物、台阶世界与画面布局持续存在。

- [文章](article.md)：169字，符合130～170字正文要求；计数是解释示意。
- [v4分镜](storyboard.json)：3个叙事阶段，1080帧声明时长（36秒）。
- [动作设计](motion-design.md)：说明同一视觉世界中的阶段推进和状态累计。
- [评审摘要](review.md)：记录当前素材的静态、动态与连续性结论及限制。
