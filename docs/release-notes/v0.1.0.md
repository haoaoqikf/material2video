# Material2Video v0.1.0 首发说明

## 能做什么

Material2Video 把文章、数据和媒体编排成可编辑的分镜。画面可以由代码绘制，也可以剪辑真实素材；代码场景逐帧采集，作品内的 Remotion `SceneFilm` 组合画面、转场与字幕，再按作品配置合成声音。独立工程保存源码、依赖锁和资源恢复入口。

| 五类作品 | 可查看的例子 |
| --- | --- |
| 图文动效 `text-motion` | [快速开始](../../README.md#三分钟做出第一条视频)的三秒标题模板，不占用下列五部随附示例的名额 |
| 数据演化 `data-evolution` | [复利 40 年](../../examples/data-evolution/compound-after-20/README.md)、[全球市值前十](../../examples/data-evolution/global-market-cap-race-portrait/README.md) |
| 原理隐喻 `principle-metaphor` | [运气到底是什么](../../examples/principle-metaphor/luck-on-stage/README.md) |
| 三维空间 `spatial-3d` | [太阳系之旅](../../examples/spatial-3d/solar-system-journey/README.md) |
| 纪实素材剪辑 `documentary-edit` | [从电报到大模型](../../examples/documentary-edit/american-science-milestones/README.md) |

`m2v types` 列出类型，`m2v init` 初始化作品；`validate`、`prepare`、`preview`、`render` 和 `status` 负责验证、准备、预览、导出和查询状态，`sample`、`lookdev`、`qa` 支持样品与核验，`assets` 和 `voices` 分别提供素材和音色相关入口。完整命令面以 `uv run m2v --help` 为准。

仓库按 [OpenSpec 工作流](../../AGENTS.md#openspec-工作流)管理改变能力、材料格式或制作契约的变更。[作品集](../site/README.md)提供五部示例的预览帧和随附静音片段，`docs/site/` 可本地浏览，也由现有工作流部署到 GitHub Pages。

## 怎么开始

从 [README 实测路径](../../README.md#三分钟做出第一条视频)做出第一个视频，再选一个[独立示例](../../examples/README.md)恢复并打开源码。若由编码助手协作，可直接复制[十秒竖屏任务](../agent-quickstart.md)。欢迎按[贡献指南](../../CONTRIBUTING.md)反馈复现问题。

## 已知边界

- 《复利 40 年》的原音色依赖本地参考 WAV 和含参考文本的音色档案。公开模型权重不含这些材料，缺档案无法复现原音色。
- 本项目的 Qwen3-TTS 与 Kokoro 后端目前只接受纯中文旁白，阿拉伯数字和拉丁字母会在合成前被拒绝。
- 本次端到端快速开始只在 Windows 11 实测，Linux 和 macOS 未在此环境验证。没有登记下载地址的模板字体需要预先取得摘要匹配的文件；不会回退为系统字体。

### 英文摘要

Material2Video turns articles, data, and media into editable short videos. Each standalone project keeps its storyboard, source, dependency locks, and asset recovery instructions together. Five video types cover text motion, data evolution, principle metaphors, spatial 3D, and documentary editing. Five examples show compound interest, market capitalization rankings, expected successes, a Solar System journey, and milestones in American science. Code scenes are captured frame by frame and assembled with Remotion. The command line initializes, validates, prepares, previews, and renders projects. OpenSpec tracks changes to project contracts. The Pages gallery offers stills and available clips. The quickstart was tested on Windows only. Local fonts and some voice assets require separate recovery. Two local speech backends currently accept only Chinese narration as input.
