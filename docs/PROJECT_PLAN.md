# 项目规划

Material2Video（材料成片）以统一制作底座承载独立视频类型。发展顺序是：先把金融时间序列等专用视频做扎实，再将多类型共同需要的制作能力沉淀为共享模块，持续完善通用混合媒体讲解。

## 当前落地范围

已落地架构见 [模块化视频制作规格](../openspec/specs/modular-video-production/spec.md)。当前代码状态、可用命令和已验证能力以 README 为准；此处计划内容不代表未完成能力已交付。

当前类型范围（由 `catalog.json` 生成，与 README 和 Skill 的类型清单同源）：

- `financial-timeseries`：保留独立金融材料、投资价值计算、专用画面与确定性技术验收。
- `general`：以六种受控模板与本地 React 代码场景制作 v7 多幕讲解视频，保留真实配音、输入语义审查、完整预演自动验收与可选画面评审。
- `housing-timeseries`：面向住宅年度均价的独立时间序列类型，含材料复算校验、确定性画面与可选画面评审。

- `src/m2v`：将实现从 Skill 脚本目录迁入标准 Python 包，由 `m2v --project` 作为统一制作入口。

以上三项类型均已实现到「校验、准备、完整预演自动验收、正式导出」的完整链路；规划里剩下的不是把它们做出来，而是把制作体验做扎实。

## 扩展原则

新专用类型按“材料契约—业务准备—专用画面—类型评审—注册接入”实现。共享底座不导入类型私有逻辑；只有多个真实类型出现相同需求时才抽取共享能力。

通用类型采用 v7 storyboard 多幕讲解，1080×1920、30 fps，由真实配音与镜头时长编译全片时间轴，支持本地 TSX 代码场景实时录制，不支持旧 general-plan 编排或完整片段嵌入。

准备产物和评审绑定材料、资产与依赖指纹；影响画面、声音或评审依据的变更会让它们过期。正式渲染使用临时输出，经媒体验收后再替换成片。

## 后续路线

1. 持续完善金融专用类型与 v7 文章讲解模板的真实制作体验；文章自动分镜与新模板需另行评估。
2. 持续完善通用混合媒体的导入留证、主题检索及旁白与字幕创作体验。
3. 根据新增专用类型的实际重复需求提取能力；保持每类业务门禁独立。
4. 仅在有明确需求且单独评估后考虑其他尺寸帧率、复杂转场、任意裁切或第二套渲染引擎。

自动行情服务、云端队列、账号、自动发布、自动选曲和第三方插件系统不属于当前路线。
