# 项目规划

Material2Video（材料成片）以统一制作底座承载独立视频类型。发展顺序是：先把金融时间序列等专用视频做扎实，再将多类型共同需要的制作能力沉淀为共享模块，最后扩展通用视频编排。

## 当前落地范围

已落地架构见 [模块化视频制作规格](../openspec/specs/modular-video-production/spec.md)。当前代码状态、可用命令和已验证能力以 README 为准；此处计划内容不代表未完成能力已交付。

## 扩展原则

新专用类型按“材料契约—业务准备—专用画面—类型评审—注册接入”实现。共享底座不导入类型私有逻辑；只有多个真实类型出现相同需求时才抽取共享能力。通用编排不得绕过嵌入类型的校验和评审。

首版通用画布按 1080×1920、30 fps 执行；时间轴在准备阶段一次编译，场景消费只读全片帧与局部帧。嵌入片段保留自身完整时间轴，首版不支持裁切、变速或拉伸。代码场景只允许公开 API、确定性输入和受控依赖；源码检查不是任意不可信代码的沙箱。

准备产物和评审绑定材料、资产与依赖指纹；影响画面、声音或评审依据的变更会让它们过期。正式渲染使用临时输出，经媒体验收后再替换成片。

## 后续路线

1. 验收当前金融和文章类型迁移，包括既有示例、关键帧与媒体时间轴基线。
2. 完成通用图文/代码场景、完整类型片段、时间轴与音画转场的真实导出和评审。
3. 根据新增专用类型的实际重复需求提取能力；保持每类业务门禁独立。
4. 仅在有明确需求且单独评估后考虑其他尺寸帧率、复杂转场、任意裁切或第二套渲染引擎。

自动行情服务、云端队列、账号、自动发布、自动选曲和第三方插件系统不属于当前路线。
