# 可数物证风格包（count-ledger）

## 可用范围与表现验证

- 适用类型：`general`；画幅：1920×1080；旁白：`none`（无旁白作品）。
- 本包只提供表现层：色板、字号、可数对象、相机与文字组件。选择风格不会自动换肤，场景必须显式导入组件。
- 包内不含题材数学、金额、年份、分镜或声音；题材数据留在作品目录。
- 注册成功、组件构建通过不等于成片表达通过；成片仍按现有独立评审与视觉复核验收。

## 1. 什么时候用

适合用**可数对象**解释数量、状态与累积的题材：资金流转、库存、人口、资源、排队、计数型机制。对象必须有稳定的“一枚 = 一个单位”口径，且状态变化能改变颜色或位置。

不适合：没有可数单位、以连续曲线或空间尺度为主的题材；需要真实档案或人物表演的题材。

## 3. 色板与语义

| 颜色 | 语义 |
|---|---|
| `offWhite` `#F1ECDD` | 已进入系统、会继续参与下一轮的资本或主体数量 |
| `gold` `#EBC668` | 本轮新生成、尚未并入的状态 |
| `darkGold` `#8A6E38` | 已离开系统、不再参与下一轮的状态 |
| `muted` `#AAA99E` | 次要文字、刻度与分隔 |
| `ink` `#090B10` | 背景与负形 |

颜色只表示状态，不表示材质。全片最多三种状态色；状态变化必须可解释，不能无来源地出现或消失。

## 4. 版式与数字

- 画面以主体区为主，文字只给对象名、数量、年份与结论。
- 数字使用 `tabular-nums`；同一量级的数字保持同一字号。
- 主体区 `140–940`，标签基线 `1000`；字幕安全区只从场景上下文 `subtitleSafeArea` 取得，不在 tokens 复制。
- 手机横屏复核：主体与关键数量在 393 宽仍可辨。

## 5. 组件

| 组件 | 用途 |
|---|---|
| `disc` | 平面圆片：顶部高光弧 + 偏移暗影；不使用 filter |
| `disc-layout` | 柱、行、网格的通用位置函数；题材专属的丘/架/取出组由作品实现 |
| `world-camera` | 世界坐标 + 缩放关键帧的对数插值；镜头只改变观看范围 |
| `number-text` | SVG 数字文字，等宽数字 |
| `kit` | tokens 类型视图、帧号、缓动、颜色混合 |

组件只接收 props，不内置金额、年份、收益率、分段时长或事件音时序。

## 6. 制作规则

- 不确定性动画一律由帧号或秒数换算，不使用挂钟、`Math.random`、CSS 动画或组件计时器。
- 圆片数量大时只用平面图形，不加 blur/filter；单帧可渲染优先。
- 状态混色用 `mixColor` 连续插值，避免颜色跳变。
- 文字与对象同源：数量变化必须有可见来源（生成、移动、合并、离开）。

## 7. 验收

- 场景显式导入组件，未导入时画面与无风格一致。
- 同帧两次录制字节一致。
- 包指纹变化使准备失效；修改示例不改变包指纹。
- 示例作品 `styles/examples/count-ledger/compound-interest/` 通过 v8 校验、prepare 与代表性 QA。

## 8. 边界

- 不提供题材数学、金额、年份、分镜或声音。
- 不提供通用图表、曲线或 3D 场景；这些属于其他风格或共享能力。
- 不自动换肤，不改变业务计算、制作门或评审职责。
