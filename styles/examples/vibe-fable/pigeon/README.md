# 鸽子的迷信

33 秒无旁白短片，1920×1080、30 fps，使用风格包 `vibe-fable`（B 寓言）。
选题与分镜结构按外部参考项目已登记的 `pigeon_B` 分镜表重写；本示例的鸽子、箱子、计时器与
食槽是独立实现，形体、比例、画法与配色都由本仓库自行决定，不复制上游 `film.js`、GIF/JPG。

## 它讲什么

食物按时间来，可它掉下来的时候鸽子碰巧在转圈，于是它接着转。

- 观众看完应能说出：**它把「碰巧」当成了「我做了什么」。**
- 这 33 秒只讲这一件事。八只鸽子里六只这样、人的「幸运袜」等延伸都留给后面的段落。

## 一个箱子，一台摄影机

箱内是一个固定的房间：墙面、地板、食槽与墙上的计时器各有自己的房间坐标（1920×1080）。
六幕只是这台摄影机的六段行程：

| 幕 | 景别 | 观众看到什么 |
|---|---|---|
| `box` | 箱外全景 | 实验室桌上的木箱、顶灯、箱里的鸽子 |
| `feeder` | 全景 | 墙面、食槽、墙上的计时器同框 |
| `wander` | 中景 | 鸽子的整只身体，食槽与计时器在右侧 |
| `coincide` | 近景 | 鸽子在食槽边啄食，谷子落在盘里 |
| `repeat` | 中景（慢推） | 地面画出转圈轨迹，它一圈一圈走 |
| `again` | 计时器前置 | 指针走到头，谷子再落一次，它越转越快 |

幕内缓动、幕间切；房间不动，动的是镜头。

## 一把尺子：跨幕连续的计时器

全片的计时器按**绝对时间**走：第 15 秒与第 30 秒各掉一次食物，与鸽子做什么无关。

录制是逐幕挂载的，`elapsedSeconds` 是幕内时间，因此每幕在
`content.props.clock.startSeconds` 里声明自己在全片时间轴上的起点（0 / 4 / 9 / 15.6 /
19.2 / 26.5 秒）。场景用它换算全片时间，计时器读数跨幕连续。

本能读数从 32 涨到 142，只在能比较的幕里出现。

## 时间线

| 场景 ID | 帧 | 全片时间 | 内容 | 画面 |
|---|---:|---:|---|---|
| `box` | 0–120 | 0–4s | 1948 年，一只饿着的鸽子被放进箱子 | 实验室桌上的木箱、顶灯、墙上的计时器 |
| `feeder` | 120–270 | 4–9s | 墙上的食槽，每 15 秒打开一次 | 箱内全景，食槽与计时器同框 |
| `wander` | 270–468 | 9–15.6s | 鸽子不知道。它只是饿，到处找吃的 | 它在箱子里走动、啄地 |
| `coincide` | 468–576 | 15.6–19.2s | 食物掉下来那一刻，它碰巧在转圈 | 食槽开启、谷子落下并留在盘里，它走过去啄食 |
| `repeat` | 576–795 | 19.2–26.5s | 于是，它又转了一圈 | 地面画出转圈轨迹，它一圈一圈走 |
| `again` | 795–990 | 26.5–33s | 15 秒到了，食物又来了 | 它越转越快，谷子再落一次 |

每幕都有屏幕字幕；`repeat` 幕的第二句「食物是按时间来的，不是因为它转」是全片唯一
直接点出因果的话，其余留给画面。

## 声音

参考片是声画一体的。本片用既有的 `soundtrack.effects`（`assets/sound-sources.json`
登记的是确定性合成音效），音效帧号直接对准画面动作：

| 事件 | 全片时刻 | 画面 | 音效 |
|---|---|---|---|
| 第一次喂食 | 15.0 s | 挡板收起，谷子落进盘里并留在盘中 | `latch` + `grain` |
| 走过去吃 | 15.7–17.4 s | 从场地中央走向食槽，低头啄食 | 不加音效，留给动作 |
| 再次转圈 | 19.2 s 起 | 地面画出转圈轨迹 | `swish` ×2 |
| 第二次喂食 | 30.0 s | 大计时器指针走到头，谷子再落一次 | `latch` + `grain` |
| 收束 | 32.4 s | 它仍在转，食物已经来了 | `chord` |

计时器滴答只在 `feeder` 幕给满（每 30 帧一声，-32 dB），其余幕不铺，避免变成节拍器。

## 事实与示意

- 年份 1948；间隔 15 秒。出自 B. F. Skinner, "'Superstition' in the pigeon",
  *Journal of Experimental Psychology* 38 (1948)：八只饿着的鸽子各关一个箱子，食槽每
  15 秒打开一次，与鸽子做什么无关；六只练出了各自重复的动作，其中一只是转圈。
- **示意的地方**：箱子、计时器与鸽子的样子都是画的；计时器的环形刻度与读数设计、
  转圈轨迹的画法属于本示例，不是论文插图。片尾不写制作说明，完整来源保留在本文件。

## 制作与校验

```powershell
uv run python fonts/fetch.py
uv run m2v validate --project styles/examples/vibe-fable/pigeon
uv run m2v prepare --project styles/examples/vibe-fable/pigeon
uv run m2v lookdev --project styles/examples/vibe-fable/pigeon --sheet 6
uv run python tests/tools/style_reference.py pigeon
uv run m2v render --project styles/examples/vibe-fable/pigeon
```

产物写在作品目录下的 `outputs/`，该目录已被 `.gitignore` 忽略，不入库。
`outputs/style-reference.md` 是八项指标对照与并排基准的说明。

## 已知限制

- 这是风格示例，不是完整评审过的交付作品：没有核心样片、全片粗片与最终终审记录。
- 鸽子的动作是示意，不追求解剖或行为学意义上的精确复刻。
- 本包不携带字体资产，画面使用宿主已注册的 `M2V Sans`；不随包恢复字体。
- 计时器依赖每幕声明的 `clock.startSeconds`；新增或调整幕时**必须同步这一字段**，
  否则读数会跳回，示例的核心机制随之失效。`lookdev` 的跨幕代表帧是核对它的方式。
- **没有独立的「计时器特写」幕**：参考的第 2 镜是计时器大特写，本片的六幕结构里
  计时器始终与食槽同框。补这一幕需要改分镜（多一幕或少一幕），登记为后续项。
- **不启用规则卡与对照计数**：参考的这 33 秒也没有；不为了用组件而加。
