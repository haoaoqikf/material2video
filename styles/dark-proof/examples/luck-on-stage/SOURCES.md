# 来源与口径

令 `S` 为 `N` 次 0/1 结果之和，若各次成功概率同为 `p`，线性期望为 `E(S)=Np`，无需独立假设。示例比较 `10×0.1=1`、`30×0.1=3`、`30×0.3=9`。预期不是实际命中数，也不是“至少成功一次”的概率；红金记录只是非定量示意。次数增加不自动提高单次概率。

窗口、水滴状尝试者、十等分盘、柱形和面积乘法由本例代码生成，复用仓库 SDK 与 `dark-proof` 组件。字体按 `fonts/registry.json` 恢复。本片不使用外部图片、视频、参考音轨或第三方音源。六个事件音由 `assets/sound-recipe.json` 合成，固定摘要见 `assets/sound-checks.json`，许可为 CC0-1.0。
