# 暗场论证风格包（dark-proof）

## 可用范围与表现验证

- 适用类型：`general`；画幅：1920×1080；旁白：不限。无旁白作品在字幕安全区内自绘屏幕字幕，有旁白作品使用共享字幕层。
- 本包只提供表现层：色板、字阶、舞台、巨型数字、点阵、图表、标题、字幕与手绘线。选择风格不会自动换肤，场景必须显式导入组件。
- 包内不含题材数学、文案、分镜、时长或声音；组件不内置具体作品的数字或事件时刻。
- 包内不登记字体与外部素材资产；中文使用宿主 `M2V Sans`，英文与数字使用宿主 `M2V Inter`。
- 注册成功、组件构建通过不等于成片表达通过；成片仍按现有独立评审与视觉复核验收。

## 1. 什么时候用

适合**用一个数字推完一条论证**的题材：比例、样本与总体、误差、累积、回归、局部与整体。画面必须能稳定回答“现在唯一的主角是什么”，并且关键关系可以用数量、位置或长度核对。

不适合：没有可数对象、主要靠连续镜头或人物表演的题材；需要真实档案、地图或 3D 空间的题材；信息量超出“一个主角 + 一句结论”的题材。

## 2. 选择与加载

场景显式导入需要的组件：

## 3. 色板与语义

| 颜色 | 语义 | 使用边界 |
|---|---|---|
| `ink` `#0A0B0D` | 背景与负形 | 不做文字颜色 |
| `ivory` `#F3EDDC` | 已知、中性、仍在场内的事实 | 主体文字与普通数据 |
| `gold` `#E6BE55` | 被强调的样本、累积结果或揭示 | 一个画面只给一个焦点 |
| `ember` `#C43B2E` | 失败、噪声或被证伪的结论 | 不用于成功、增长或正收益 |
| `muted` `#8B8981` | 刻度、次要标签与方法说明 | 不承载结论 |
| `line` `#3A3A3C` | 坐标轴、分隔与未生效的结构线 | 不做强调 |

颜色语义全片锁死，不引入第四种强调色。颜色变化必须对应状态变化；不能让金色无来源地出现或消失。

## 4. 字阶与版式

- 三级主体文字：巨型数字/结论 220–320 px；中文标题与主讲 60–112 px；英文小字 20–28 px。
- 中文使用 `M2V Sans`，英文与数字使用 `M2V Inter`；数字使用等宽数字（`tabular-nums`）。
- 主体区位于 `140–940`，左右边距 96 px。画面以主体区为主，文字只给对象名、数量与结论。
- 字幕安全区只从场景上下文 `subtitleSafeArea` 取得，tokens 不复制一份几何；主体与结论不得压进字幕安全区。
- 手机横屏复核：关键数字、中文主讲与三个关键点可辨；英文小字作为纹理可辨即可。

## 5. 组件

| 组件 | 用途 |
|---|---|
| `stage` | 近黑舞台：静态柔光暗角，不加动画噪点 |
| `hero-number` | 巨型数字或结论，等宽数字、紧行高 |
| `counter` | 按显式进度在 `from → to` 滚动；数字含义由作品决定 |
| `dot-field` | 归一化坐标的批量圆点；按语义色分组，可带强调点与光环 |
| `proof-chart` | 坐标框、曲线、柱列、箭头与标记；只画给定几何 |
| `bilingual-title` | 中文主讲 + 英文短标签 + 金色落点短线 |
| `screen-subtitle` | 无旁白作品的中英双语屏幕字幕；中文逐字展开、英文延迟、关键词高亮，落在安全区内 |
| `hand-drawn-line` | 外部传入 path 的锥形手绘描线，按进度生长 |
| `light-trail` | 沿外部点列的光轨：锥形尾迹、头部光晕与少量尾尘 |
| `burst` | 径向爆散：粒子、核心光晕与向外扩散的圆环 |
| `shock-ring` | 只画扩散圆环，适合冲击、取样窗打开与结果揭示 |
| `impact` | 整屏粒子冲击：透明 Canvas 层、分层粒子、bokeh、扩散环与短闪光；只接收 preset 与事件 |
| `kit` | tokens 类型视图、帧号、缓动、确定性随机与颜色混合 |

组件只接收数量、状态、几何、缓动与文字等内容无关参数；题材形状、数学与文案留在作品目录。点阵在 1000 点规模下只画圆，不加滤镜；局部光效用径向渐变与加法混合，整屏冲击用预渲染 sprite 的透明 Canvas 层，粒子数、环数与透明度受 tokens 限制。

## 6. 运动与转场语法

- 入场与抵达使用 `easeOutCubic`；画面内移动与状态切换使用 `easeInOutSine`；不做过冲。
- 数字变化可用滚动、重影或溶解表现，但同一时刻只允许一个主运动；数字滚动可用 2–3 层残影，残影不累积上一帧。
- 全片至多使用一次硬切，并把它放在论点转折处。其余转场优先使用**同一对象的形变、位移与光的延续**：前一个对象的状态变化生成下一个画面。整屏透明度交叉淡化只用于次要层，且旧层快速退出、新层稍后进入（旧层 8 帧内降到 0.15 以下，整段 ≤16 帧）；不保留长时间重影，也不用两层全亮叠放。
- 不使用无叙事理由的往返推拉摇移；允许全片缓慢单向推近（约每拍 1%，全片 ≤8%），字幕与方法说明不参与缩放。尺度变化必须改变数量、比例或因果的理解。
- 所有变化由帧号或秒数驱动；不使用挂钟、`Math.random`、CSS 动画或组件计时器。

使用本包的作品须在设计记录中写明自己的唯一硬切时间、前后镜头与论证作用；设计记录不能替代画面核对。

## 6.1 光效语义与克制边界

- 金色光只服务状态变化：被强调的样本、曲线端点、柱顶、冲击与揭示；不作为环境装饰。
- 全爆散只允许出现在论证转折、结果揭示与结尾回扣；整片允许 4 个整屏冲击（线溶解、全象揭示、公式收口、结尾回扣），每拍至多一个整屏焦点，局部微光不计。
- 整屏冲击必须绑定具体对象与事件；粒子从对象中心发出，不能是无来源的全屏装饰。
- 小光点/单环用于评价翻转、柱顶、观测点与取样窗；硬切处只允许单环与局部低透明度闪光，不做全屏闪白，也不放粒子。
- 局部光效用径向渐变、加法混合与 `perfect-freehand` 锥形笔触；整屏冲击用透明 Canvas 与预渲染 sprite，1000 点阵不加滤镜，粒子数、环数与轨迹采样数受 tokens 限制。
- 允许低速 ambient dust 作为连续微动：固定种子、缓慢漂移、低透明度，不做随机闪烁；数量与透明度受 tokens 限制。
- 轨迹光效必须有可见来源：对象移动、线条生长或曲线推进；不做随机环境闪烁。

## 6.2 字幕进出

- 中文逐字错峰展开：未轮到的字保持全透明，文字从左到右长出来，整句不先灰后亮；英文延迟到中文基本展开后再进入。关键词可用金色高亮，高亮不改变文本、换行、字号与安全区。关键词可随 112 BPM 节拍做 ≤3% 的辉光/缩放脉冲，不改变字号与换行。
- 进场可用 `rise` / `settle` / `wipe`，出场可用 `drift` / `dissolve` / `mask`；所有效果由帧号与窗口计算。
- 逐字 span 不设 `role`；外层容器保留 `data-m2v-role="screen-subtitle"` 并只使用 `subtitleSafeArea`。窗口内保留最小可见度供按帧量测，窗口外为 0。

## 6.3 节奏与微拍

- 八段论证的边界可以保持不变；每段内部应拆成 12–16 个微拍，任一主内容停留不得超过约 1.5 秒。
- 112 BPM 是默认节拍网格：金点、点阵呼吸、计数器与关键词脉冲可以对齐到该网格；声音按采样时间精确对齐，画面按帧取整。
- 连续微动包括缓慢单向推近、点阵低速漂移、ambient dust 与节拍脉冲；它们只维持生命感，不替代信息事件。
- 每个微拍至少改变一个可见状态（位置、数量、亮度、标记或文字强调）；不为填满时间加入无信息运动。

## 7. 制作规则

- 每个核心段落只设一个视觉主角；一屏能在 0.5 秒内指出唯一焦点。
- 用可数对象承载抽象比例；总体数量与强调数量要同屏可见。
- 每个数字变化都有可见来源；数字不能自己跳。
- 先让观众形成旧判断，再公开新信息；公式放在观众已经看见关系之后。
- 文化锚点只用一个，并接回同一母题；结尾回到开场的对象或数字，不新增概念。
- 画面注释按[项目约定](../../AGENTS.md#修改规则)：从紧、小字、次要位置，不遮挡主体、关键数据、字幕或关键动作；方法口径必须写清数学假设。
- 本包不提供通用图表库、3D 场景、角色表演或自动换肤。

## 8. 验收

- 场景显式导入组件；未导入时画面与无风格一致。
- 同帧两次录制字节一致。
- 包指纹变化使准备失效；修改示例不改变包指纹。
- 使用本包的作品须通过 v8 校验、prepare、代表性 lookdev 与 QA；注册与组件构建通过不等于成片表达通过。
- 全片硬切不超过一次，且位于论点转折；字幕完整落在 `subtitleSafeArea` 内。
- 参考片只作为并排基准与设计证据，参考画面、音轨、字幕与文案不进入成片。

## 9. 运动人格

- **Analytical**：克制、以元素级变化为主，允许一条缓慢单向推近；抵达用 `easeOutCubic`，场内移动与状态切换用 `easeInOutSine`。
- 签名动作是数字滚动、点阵显隐、曲线生长与手绘线描出；进度由帧号求值，缓动由调用方显式传入。
- 时长按帧换算后写进作品 `DESIGN.md` 的运动计划；通用时长、缓动与编排方法见[运动设计](../../.agents/skills/motion-design/SKILL.md)。
