# vehicle-showcase Specification

## Purpose
提供可离线复现的汽车三维展示视频类型，以明确的本地车辆资产、镜头与效果时间轴完成环绕展示和视觉疾驰，并以小米 SU7 首例验证完整输出及制作质量，区分候选生成、授权依据与实际制作完成。

## Requirements

### Requirement: 独立汽车展示类型

系统 MUST 登记 `vehicle-showcase` 类型，通过统一 init、validate、prepare、preview、render 入口处理作品；首版 MUST 使用 1920×1080、30 fps，拒绝不支持的材料版本和画幅帧率组合，其他类型行为保持不变。

#### Scenario: 初始化并处理汽车作品
- **WHEN** 用户初始化汽车展示作品
- **THEN** 系统在类型所属内容目录创建独立材料模板，可通过统一入口校验和准备，不要求伪装成 general

#### Scenario: 不支持的材料
- **WHEN** 材料版本或画幅帧率不受支持
- **THEN** 系统在准备前明确拒绝并指出错误字段

### Requirement: 本地材料与可追溯资产

系统 MUST 要求本地模型、关联资源清单、车身和车轮节点配置、镜头与效果轨道；材料 MUST 为 `showcase.json` v2，并 MUST 包含必填的 `studio` 对象，登记影棚环境图（`environment`）、车漆 AO（`bodyAo`）、地面法线（`floorNormal`）与地面粗糙度（`floorRoughness`）四张本地贴图的相对路径。清单 MUST 保存来源、作者、许可依据、上游版本和文件摘要。准备及渲染 MUST 离线运行，缺失资源、摘要不符、节点无效、轨道越界或镜头覆盖存在空隙/重叠时 MUST 明确失败，不静默替换模型、贴图或效果。v1 材料 MUST 被明确拒绝并提示升级，不提供兼容分支。作品和媒体 MUST 不进入版本控制。

#### Scenario: 资源不完整
- **WHEN** glTF 关联贴图或缓冲缺失，或任一资产摘要与登记不符
- **THEN** 准备失败并报告具体资源，不输出有效准备记录

#### Scenario: 非法时间轴或节点
- **WHEN** 指定节点不存在，或镜头轨道无法完整覆盖声明时长
- **THEN** 校验失败并定位配置错误

#### Scenario: v1 材料
- **WHEN** `showcase.json` 仍为 `schemaVersion: 1` 或缺少 `studio`
- **THEN** 校验明确失败并指出需升级到 v2、补齐影棚资产，不进入准备

#### Scenario: 影棚贴图缺失
- **WHEN** `studio` 中任一贴图未在清单登记、文件缺失或摘要漂移
- **THEN** 准备失败并报告具体路径，不静默回退到内置环境或系统贴图

### Requirement: 同帧可重复的车辆展示动画

系统 MUST 按帧求取车辆、车轮、镜头、灯光、地面反射、后期与效果状态；相同输入下重复或乱序取样同帧的画面 MUST 在确定性验证容差内一致。车轮 MUST 按 glTF 节点名解析，包括 three.js 清洗后的名称（移除 `[ ] . : /`、空白转为下划线）；解析失败 MUST 明确报错，MUST NOT 静默跳过。车轮角度 MUST 由速度轨道的解析积分给出：环绕阶段静止，启动段加速，疾驰段高速旋转，收束段减速；30 fps 下相邻帧角度增量 MUST 小于轮辐对称周期，避免频闪或倒转错觉。资源及着色器就绪后才允许采集，不依赖用户点击、实时等待或刷新次数。

#### Scenario: 乱序取帧
- **WHEN** 对同一准备记录正序、倒序和重复采集探针帧
- **THEN** 同帧图像 PSNR 至少为 60 dB，不因历史帧不同产生车轮角度、机位、反射或辉光漂移

#### Scenario: 车轮旋转可见
- **WHEN** 播放 16–30 秒的启动与疾驰段
- **THEN** 车轮连续旋转且方向一致，近景可辨轮辐转动，不出现静止或频闪

#### Scenario: 节点名清洗
- **WHEN** `wheelNodes` 声明 `Wheel.001` 这类含点的 glTF 节点名
- **THEN** 运行时按原名或清洗后名称找到节点并旋转，不因名称清洗静默失效

### Requirement: 准备绑定与成片技术验收

系统 MUST 将材料、资源、声音和实现变化绑定准备指纹，过期时要求重新准备；输出 MUST 验证总帧数、尺寸、帧率、时长与声明音轨一致，并保留溯源和性能记录。局部预览 MUST 不替代完整候选验收；无声音声明时 MUST 输出无音轨视频。

#### Scenario: 素材修改后渲染
- **WHEN** 用户在准备后修改模型、贴图或动画配置
- **THEN** 系统拒绝复用过期准备，要求重新 prepare

#### Scenario: 无声输出
- **WHEN** 合法作品未声明任何声音
- **THEN** 输出无音轨视频，按声明的帧数、1920×1080 和 30 fps 验收

### Requirement: SU7 首例与制作完成

首例 MUST 使用指定 `alphardex/su7-replica` 仓库经核实授权的必要代码与资产，制作 30 秒、900 帧的亮灯显现、完整环绕一圈、启动、视觉疾驰与收束。代码和各资产授权未落实时 MUST 标记资源阻塞，不擅换仓库或宣称允许发布。制作完成 MUST 具备当前候选的技术证据和按现有审核策略派生的独立评审，不以技术导出代替观感通过。当前候选 MUST 在车漆与反射层次、影棚背景、车身占比、接地阴影和车轮旋转上达到与参考仓库同一提交一致的观感方向。

#### Scenario: 授权仍不明确
- **WHEN** 指定仓库代码或任一拟使用资产缺少适用授权依据
- **THEN** 首例不得导入该资源用于生产或发布，阻塞原因和所缺依据明确可查

#### Scenario: 当前候选复核
- **WHEN** SU7 全片候选进入制作验收
- **THEN** 复核完整环绕、主体不被意外裁切、车轮轴心和接地、车轮旋转、材质曝光、反射与启动过渡连续性，独立必改项未关闭时不得标记制作完成

### Requirement: 影棚灯光、反射地面与后期呈现

画面 MUST 使用登记在 `studio` 的 HDR 环境图作为车漆、玻璃与金属的环境反射来源，并 MUST 按帧控制环境强度以完成亮灯显现与疾驰增强。背景 MUST 为连贯的暗色影棚：顶部 MUST 有柔光板，地面 MUST 为带平面反射的暗色材质，并 MUST 具备接触阴影；MUST NOT 出现网格、灰色测试地面、可见地面边缘或独立光斑。地面反射 MUST 使用镜像相机渲染的平面反射目标，允许按法线贴图扰动、按粗糙度贴图模糊并按菲涅耳混合。后期 MUST 对发光灯板与灯带应用辉光，并 MUST 随疾驰段增强但不得使车漆大面积过曝。影棚、反射与后期参数 MUST 为时间与材料的纯函数，不依赖上一帧或随机数。

#### Scenario: 亮灯显现
- **WHEN** 播放 0–4 秒
- **THEN** 画面由暗场平滑亮起，灯板、地面光池和车漆反射依次显现，不出现硬切或曝光跳变

#### Scenario: 环绕背景
- **WHEN** 镜头完成整圈环绕
- **THEN** 任一机位都看不到网格、地面边缘或背景断层，地面反射与接触阴影保持连贯

#### Scenario: 疾驰辉光
- **WHEN** 进入 19–26 秒视觉疾驰
- **THEN** 灯板与灯带辉光增强、地面反射随速度变化，车漆高光不溢出为纯白色块
