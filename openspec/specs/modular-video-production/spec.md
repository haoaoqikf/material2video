## Purpose

建立五类视频共用的作品与制作契约，使用户通过统一入口准备、预演、评审和导出，并复核内容与渲染依据。

## Requirements

### Requirement: 准备及评审版本绑定
系统 MUST 在准备后记录输入、资产、源码与准备指纹。render MUST 只读当前准备产物，缺少或过期时要求重新 prepare。正式导出 MUST 不依赖预演，生成一次并验证当前完整候选的准备指纹、文件摘要、完整帧数及媒体技术参数，并执行类型自动门禁；MUST NOT 要求人工画面评审。人工评审工具 SHALL 保留为可选工具，status MUST 标识 required=false，未填写时标识 optional；主动 review 时 MUST 验证当前结论、完整非空依据及候选摘要绑定。

具有专用评审要求的视频类型 MUST 可通过注册接口生成类型评审模板；统一 `review-template` MUST 同时创建通用评审记录和类型专用评审材料，主动执行统一 `review` MUST 验证两者；正式 `render` MUST 只验证自动门禁。

#### Scenario: 材料变化
- **WHEN** 准备或评审后修改数据、源码、字体、声音或候选
- **THEN** 对应记录失效，正式导出阻断

#### Scenario: 类型专用评审
- **WHEN** 金融或文章作品使用统一评审入口
- **THEN** 有人工评审工具的类型可按需生成模板，主动评审在依据缺失或过期时失败，正式导出不受人工记录影响；五类均保留可选人工评审和自动验收

#### Scenario: 自动预演门禁
- **WHEN** 当前准备有效且没有预演
- **THEN** 旧完整预演门禁不再生效，允许生成候选，验收后交付同一文件，不重复编码

### Requirement: 共用渲染及可靠输出
系统 MUST 使用完整缓存键且命中不跳门禁，元数据核验与渲染使用同一浏览器会话；候选生成后 MUST 持久化并绑定摘要，验收失败保留并禁止重试时重渲染；候选通过帧数、尺寸、帧率、音轨验收及输入复核后才替换目标。所有类型 MUST 输出溯源与性能记录。正式成片成功替换并生成旁车后，统一入口 MUST 清理当前作品 `outputs/` 中旧成片及其旁车、预演与已知检查和调试产物；MUST 保留本次成片、其字幕/溯源/性能旁车、准备和评审 JSON、可供重渲使用的准备媒体及当前候选与交付记录。清理不得越出当前作品 `outputs/`，不得清理共享构建缓存。五类作品当前 visual-notes、其引用的当前检查证据及返工前后对照 MUST 保留在作品忽略的输出目录中，作为已知检查产物清理的例外；历史无引用大体积检查产物仍按原规则清理。渲染或验收失败 MUST NOT 触发清理；清理遇到文件错误时 MUST 保留有效新成片、报告失败和遗留路径，且不得声称全部清理完成。

#### Scenario: 元数据不符或输出失败
- **WHEN** composition 元数据不符或渲染期间材料变化
- **THEN** 阻断或丢弃临时产物，不覆盖原有效成片

#### Scenario: 正式渲染成功后清理旧产物
- **WHEN** 任一视频类型的正式渲染通过验收并写好成片旁车
- **THEN** 只保留本次成片和必要旁车、准备及评审记录、准备媒体；清理当前作品输出目录内旧视频、预演与已知检查/调试产物

#### Scenario: 渲染失败不清理
- **WHEN** 正式渲染或成片验收失败
- **THEN** 不执行旧产物清理，已有有效成片及其他产物保持不变

#### Scenario: 清理遇到文件错误
- **WHEN** 新成片已验收，但一个或多个旧产物无法删除
- **THEN** 保留新成片并报告清理失败及未删除路径，不影响新成片交付状态

#### Scenario: 保留当前视觉复核证据
- **WHEN** 任一五类作品渲染成功后清理旧产物
- **THEN** 当前复核记录及其引用的检查依据和前后对照仍可访问，内容与媒体不加入 Git

### Requirement: 类型的单一登记来源

系统 MUST 在唯一一份类型目录中登记五类视频的身份、说明、分镜入口与初始化模板。统一入口的类型清单、说明文案、初始化材料和规范位置 MUST 从该目录派生；目录 MUST 恰好包含五类，不接受类别或旧类型名。作品描述与命令行入口不得另行维护材料映射或初始化模板。

#### Scenario: 五类登记
- **WHEN** 查询目录或初始化任一已登记类型
- **THEN** 只列出五类及其分镜入口，作品直接位于 videos/<type>/<slug>，不经过类别层

#### Scenario: 类别不是可执行类型
- **WHEN** 用户以旧类别或旧类型标识调用初始化
- **THEN** 系统报错并列出可用的五类，不创建作品

#### Scenario: 未登记的类型被拒绝
- **WHEN** 作品描述声明了目录外类型
- **THEN** 系统在渲染前失败并指向 `m2v types`

#### Scenario: 未知类型在渲染前失败
- **WHEN** 作品描述声明了未注册的类型
- **THEN** 系统在渲染前以「未知视频类型」失败并指向 `m2v types`

### Requirement: 初始化材料立即可用

`m2v init` 为已登记类型生成的材料文件 MUST 是该类型自身契约接受的形式，MUST NOT 出现材料内容被外层文件键或其它包装层级包裹的结构偏差。初始化得到的作品在补齐占位内容之前，校验结果 MUST NOT 包含由结构包裹引起的错误。

#### Scenario: 初始化产物的顶层结构

- **WHEN** 对任一已登记类型执行 `m2v init`
- **THEN** 每个生成的材料文件顶层结构与该类型契约一致，不出现被文件名键包裹的内容（五类的 `storyboard.json` 顶层即 v9 分镜字段）

#### Scenario: 初始化后校验不报结构错误

- **WHEN** 对 `m2v init` 得到的作品执行该类型的材料校验
- **THEN** 校验结果不包含结构包裹导致的错误（新版分镜不再误报旧结构错误），只可能报出占位内容待填写的问题

### Requirement: 文档中的类型清单由类型目录生成

README、Skill 与项目规划中描述视频类型的清单 MUST 由类型目录生成，不得手工维护。清单 MUST 只显示五类，且不出现类别分组。仓库 MUST 提供一致性校验，使生成产物与磁盘内容不一致时失败并指出需重新生成的文档。类型目录未变化时重新生成 MUST 幂等。

#### Scenario: 文档与类型目录漂移
- **WHEN** 类型目录中文案变化而对应文档未重新生成
- **THEN** 一致性校验失败并指出需要重新生成的文档

#### Scenario: 按类别分组
- **WHEN** 生成当前五类清单
- **THEN** 三份文档只显示五类，不显示类别或未分类分组

#### Scenario: 幂等重新生成
- **WHEN** 类型目录与文档当前一致时重新运行生成
- **THEN** 文档内容逐字节不变

### Requirement: 交付产物的访问权限

从临时目录搬到最终位置的产物 MUST 在落盘后交回所在目录的继承权限，使以标准权限运行的打包应用（媒体播放器、照片）无需人工修复即可打开；范围包括成片、溯源记录、混音音轨、录制片段、导入素材与缓存条目。搬运与权限修复 MUST 是同一个动作，系统 MUST NOT 存在只搬运不修复的交付路径。修复后 MUST 复核目标本身；仍缺少标准权限进程可用的授权时 MUST 报告目标与所在目录，指出「父目录本身是收紧的」这一根因。非 Windows 平台 MUST 无行为差异。

#### Scenario: 标准权限播放器打开成片
- **WHEN** 成片从渲染临时目录搬到作品目录
- **THEN** 文件继承所在目录权限并含面向普通用户的授权条目，双击即可播放

#### Scenario: 收紧的父目录
- **WHEN** 交付目标所在目录本身只授权给 SYSTEM、Administrators 与 OWNER RIGHTS
- **THEN** 日志报告目标与所在目录，而不是静默交付一个打不开的文件

#### Scenario: 录制片段与导入素材
- **WHEN** 代码录制片段或导入素材从临时目录落地
- **THEN** 与成片同等修复，无需人工处理即可打开

### Requirement: 制作与质检入口

系统 MUST 在统一入口提供制作与质检命令：`m2v lookdev --project <目录>`、`m2v qa --project <目录>`、`m2v assets audit --project <目录>`。正式导出沿用现有 `m2v render`，不新增母版命令。命令 MUST 沿用现有作品路径、内容根、退出码与产物归属规则。

- `lookdev` MUST 只渲染关键静帧与代表片段，MUST NOT 生成完整成片；输出位于作品 `outputs/lookdev/`，包含按风险选择的代表静帧（默认原生像素，可显式 2 倍）、接触表与按风险确定长度的有声样片（无声作品保持无音轨）。帧序列、量测与自动音频信号检查的结论写入作品 `outputs/visual-notes.md`，作为检查与返工依据，MUST NOT 成为导出门禁；MUST NOT 要求播放样片或连续收听声音。
- `lookdev` MUST 额外支持四种取点模式，与默认代表静帧互斥，同一调用 MUST NOT 同时声明：按指定时刻拼图、按时间区间拼图、同帧一致性自检、按幕内事件取证。指定时刻与区间 MUST 接受秒为单位的输入，并按作品实际帧率换算为帧号；拼图 MUST 在每格标注时刻与帧号，标注 MUST 只用不依赖中文字体的字符。
- 事件取证 MUST 接受可重复的 `--event sceneId:eventId`（事件 ID 全片唯一时可省略场景）、显式声明的 `--before` 与 `--after` 整数帧，以及可选 `--hold` 整数帧；MUST NOT 提供未声明的默认窗口，每次调用 MUST 由作者显式声明前后窗口。事件 MUST 从当前准备记录的 `resolvedEvents` 解析并绑定当前 `preparedFingerprint`；准备记录缺少事件表、选择器未知或在多个幕中歧义时 MUST 在启动浏览器前失败。
- 事件取证 MUST 围绕每个事件取 `before`、`at`、`after`、`hold` 四类帧；四类帧 MUST 位于事件所属幕内，越界时 MUST 明确指出事件、阶段、局部帧与合法范围并失败，MUST NOT 静默裁剪。同一帧被多个阶段命中时 MUST 只采一次并合并来源标签；相邻选中事件间隔小于 `before+after` 时 MUST 给出事件簇警告，MUST NOT 静默隐藏。
- 指定时刻与区间的帧号 MUST 在启动浏览器前完成校验：越出全片范围或不落在任何已准备场面窗口内的时刻 MUST 立即失败并指出该时刻，不先执行采集再报错。
- 同帧一致性自检 MUST 对同一批时刻执行两次独立采集，逐帧比较并报告不一致的时刻与实测值；判定阈值 MUST 沿用既有的 PSNR 60 dB，MUST NOT 引入第二套阈值。比较前 MUST 确认两次输出尺寸一致，尺寸不同 MUST 明确失败而不是给出误判结论。
- 四种新增模式的产物 MUST 落在既有 `outputs/lookdev/` 下并由 `outputs/lookdev.json` 记录路径；MUST NOT 写入 `outputs/production/` 下的检查点目录，避免与正式制作证据混淆。产物 MUST NOT 进入准备指纹或缓存键。
- 事件取证是看图预览，MUST NOT 自动关闭或替代 G4 检查点、审核轮次或导出门禁；MUST NOT 把事件窗口自动绑定到检查点合同。新增模式 MUST NOT 改变默认代表静帧、样片长度、采集尺度与既有清单字段的语义；`--stills`、`--sample-seconds`、`--still-scale` 的现有行为 MUST 保持不变。
- `qa` MUST 输出 `outputs/qa.json` 与接触表，覆盖冻结/重复帧、banding、aliasing、字幕对比度、响度/真峰值、音轨时长差与 claims 时间窗覆盖，并提供全片采样清单、交界/异常加密帧、黑帧/突变及交付音轨削波/静音候选，并明确区分技术判定、测量提示和需查看采样图像的项目与自动信号检查的覆盖限制；MUST NOT 将技术通过表述为视觉质量通过；技术失败 MUST 以退出码 1 结束，报告 MUST 可定位到镜头/时间戳。
- `assets audit` MUST 只读素材与导入记录，输出 `outputs/asset-audit.json`；任何登记素材明确禁止当前用途、条件未满足、采用元数据无效、文件缺失或尺寸无效时 MUST 以退出码 1 结束。
- 正式导出 MUST 沿用 `m2v render`，交付普通 H.264 MP4；系统 MUST NOT 提供 `m2v master` 或 ProRes/DNxHR 母版入口。成片旁注文件 MUST 记录交付摘要、音频参数与 QA 指纹，MUST NOT 记录 profile。
- 所有制作阶段均取消用户确认：`m2v render` MUST NOT 因缺少帧序列/量测复核记录、确认文件或 look-dev 产物而阻断。

所有新命令 MUST 遵守离线、素材留证、准备指纹与交付权限规则；缺少准备记录、存在旧 `productionProfile` 声明或依赖缺失时 MUST 在渲染前失败，不产出部分产物。

#### Scenario: look-dev 只出样片

- **WHEN** 对任一五类作品运行 `m2v lookdev`
- **THEN** 只生成关键静帧、接触表与声明长度的样片，不生成全片，不覆盖正式成片

#### Scenario: 按指定时刻拼图

- **WHEN** 以若干秒为参数请求拼图
- **THEN** 按作品帧率换算为帧号，从各自场面起点连续推进到该帧后截图，输出一张带时刻与帧号标注的接触表，不生成全片

#### Scenario: 按区间看转场

- **WHEN** 以起止时段与帧数为参数请求区间拼图
- **THEN** 在该区间内均匀取帧拼成一张，覆盖转场的进入、中间与离开，不生成视频

#### Scenario: 按幕内事件取证

- **WHEN** 以 `sceneId:eventId` 和显式 `--before/--after` 请求事件取证
- **THEN** 从当前准备记录解析事件，围绕事件取 before、at、after、hold 四类帧，输出带 `scene.event.bN/at/aN/hN` 标注的接触表与绑定准备指纹的清单，不生成全片

#### Scenario: 事件选择器歧义

- **WHEN** 只给事件 ID，而该 ID 在多个幕中出现
- **THEN** 在启动浏览器前失败，列出现过的幕并要求使用 `sceneId:eventId`，不擅自选择其中一个

#### Scenario: 事件窗口越界

- **WHEN** `--before`、`--after` 或 `--hold` 使某一阶段落到所属幕之外
- **THEN** 在启动浏览器前失败，指出事件、阶段、局部帧与合法范围，不裁剪窗口，不写产物

#### Scenario: 事件簇

- **WHEN** 同一幕内相邻选中事件的间隔小于 `before+after`
- **THEN** 清单给出事件簇警告；重叠帧只采一次并合并来源标签，不静默隐藏相邻事件

#### Scenario: 事件模式互斥

- **WHEN** 同一次调用中同时声明事件、指定时刻、区间、同帧自检或默认静帧
- **THEN** 明确失败并说明互斥关系，不擅自选择其中一种

#### Scenario: 非法时刻

- **WHEN** 指定时刻为负、超出全片时长，或落在任何场面窗口之外
- **THEN** 在启动浏览器前立即失败并指出该时刻与合法范围，不执行采集，不写产物

#### Scenario: 模式互斥

- **WHEN** 同一次调用中同时声明指定时刻、区间与默认静帧
- **THEN** 明确失败并说明互斥关系，不擅自选择其中一种

#### Scenario: 同帧一致性

- **WHEN** 对同一批时刻执行一致性自检两次独立采集
- **THEN** 逐帧比较 PSNR，≥60 dB 记为一致；低于阈值时报告具体时刻与实测值；两次输出尺寸不一致时明确失败，不给出一致结论

#### Scenario: 产物归属

- **WHEN** 四种新增模式产出图片与清单
- **THEN** 图片位于 `outputs/lookdev/` 且由 `outputs/lookdev.json` 记录；不写入检查点目录，不进入准备指纹；成功交付后按既有清理规则处理

#### Scenario: 事件预览不替代检查点

- **WHEN** 作者用事件模式看过画面后直接进入制作或导出
- **THEN** 系统不把该预览视为 G4 检查点证据，也不自动关闭审核项；正式检查点仍按设计合同执行

#### Scenario: QA 失败定位

- **WHEN** 某镜头出现冻结帧或响度超限
- **THEN** `m2v qa` 以退出码 1 结束，报告指出镜头/时间戳与实测值

#### Scenario: look-dev 之后直接导出

- **WHEN** 跑完 `m2v lookdev` 且作品未记录任何确认或替代复核结论
- **THEN** `m2v render` 正常交付，不因缺少确认而阻断；`lookdev` 产物仍可供观看与返工定位

#### Scenario: 统一命令保持

- **WHEN** 使用现有 validate/prepare/preview/render 处理任一五类作品
- **THEN** 参数、默认输出、退出码与统一成片契约一致

#### Scenario: 原生 4K 关键帧

- **WHEN** 运行 lookdev 生成静帧，作品包含显式低 DPR 的 WebGL 画布或多个代码幕
- **THEN** 从当前源码连续推进至各幕选定帧，按所选择的采样尺度（默认 1 倍，必要时 2 倍）绘制画布，PNG 合成原有字幕与转场；不放大 1080p 缓存视频冒充原生细节，像素不足时明确失败；有声样片流程不变

#### Scenario: 测量项不能冒充通过

- **WHEN** QA 只计算了 banding 或 aliasing 相关数值
- **THEN** 报告标识为测量提示，不据此自动宣称画面无缺陷，也不将测量项当作技术失败

#### Scenario: 导出与完成分离

- **WHEN** render 成功但缺少当前有效的最终替代检查记录
- **THEN** CLI 仍可输出视频，助手报告尚未完成帧序列与自动音频复核，不要求用户确认，不宣称制作完成

#### Scenario: 未知许可提示
- **WHEN** 素材原始许可未知但没有记录禁止或未满足条件
- **THEN** 审计保留许可与采用依据并提示，不因未知许可单独返回失败
