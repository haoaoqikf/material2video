# visual-expression-inspiration Specification

## Purpose

提供追求高品质商业视觉表达的创作总纲与视觉、叙事、运动、声音灵感，鼓励创造力和实际试制反馈；方法风格自由选择，以实际效果与清晰表达判断品质。

## Requirements

### Requirement: 视觉与表达参考必读且采用自选（当前媒体流程）
项目 MUST 提供顶级视觉创意与设计指导，强调探索、审美判断、具体视觉决策及实际效果验证；风格与四组灵感列表可自由采用、融合、自创或跳出。创作或实质性视听修订前 MUST 完整阅读，同一任务无需重读。研究 MUST 足以支撑当前试验，未知触发补查，不等待所有研究完成才试制。不得设风格符合性门禁、候选数量、样片时长或审美评分，不降低事实、许可和用户硬约束。

#### Scenario: 自由创作并及时试制
- **WHEN** 当前关键前提已有依据
- **THEN** 可以局部设计和实际试制，并用真实画面选择、修订或淘汰方向，研究不足的问题继续补查。
