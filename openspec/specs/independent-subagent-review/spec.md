# independent-subagent-review Specification

## Purpose

通过新建上下文、只读隔离媒体包、先盲看后对照和当前范围的独立复查，保留真实观察与问题闭环，区分试制验证、总代理整片复核和降级自审的完成边界。

## Requirements

### Requirement: 媒体范围独立评审
两类独立评审 MUST 使用独立新上下文。关键帧 MUST 先盲看落盘后同轮对照，检查静态构图、层级、风格与可读性。正式关键样片默认做独立过程对照，检查完整动作、因果、节奏、衔接与声画配合。正式关键样片核心表达依赖悬念、错觉、连续变形或剪辑反转时可登记具体依据执行过程盲审。媒体、时间窗、显示条件与实际限制 MUST 绑定当前周期。按明确风险支持争议复核及匿名比较；自审 MUST 显著披露且不得关闭独立项。试制选案 SHALL 使用关键帧盲看与同轮对照以及总代理适用的完整过程证据，评审不得接收作者推荐、解释或制作成本作为品质依据。评审 SHALL 在现有 observations 中分别说明具体吸引力、普通之处、与目标的主要差距及继续打磨或作为后续标准的依据，允许全部淘汰，不强制选赢家、不以总分或投票替代观察。主代理 MUST 依据原目标负责选案与下一试验，不能将独立 pass 等同阶段完成；实质争议按原目标复核，不反复换评审者挑选宽松结果。

#### Scenario: 独立失败复查
- **WHEN** 执行本场景
- **THEN** 失败 MUST 登记必改，只有当前对应范围、同类观察的有效独立通过才可关闭；改目标、重渲染或技术通过不得代替。

#### Scenario: 候选都不足
- **WHEN** 独立观察没有发现足以继续的候选
- **THEN** 评审 MUST 可以明确全部淘汰并给出具体依据，不因提供了多个方案而被迫选优；助手据此调整表达或构图。

#### Scenario: 推荐打磨与正式展开分离
- **WHEN** 某方案有吸引力但仍有整体品质差距或关键实现未知
- **THEN** 评审 MUST 明确当前不通过，并可推荐继续打磨而不支持展开；作者安排相应试验，结论沿既有报告和设计记录保存，不新增轮次、审批或机器 verdict。

#### Scenario: 正式候选与比较参照
- **WHEN** 正式 trial 需要同时比较备选或历史画面
- **THEN** 待验证范围 MUST 放入 items 并全部受失败闭环约束；只作比较的媒体放 references 且说明用途，在对照时展示，不得称其已独立盲看通过，也不得以此解除已导入失败。

#### Scenario: 按需探索性匿名观察
- **WHEN** 方向分歧需要独立同时观察全部早期候选
- **THEN** 助手 SHALL 隔离保存盲看和随后对照的真实探索观察，不冒充正式导入通过、不授权展开；后续正式基线验证使用未看过目标与探索结论的新上下文，保留具体缺陷与额外观察成本，不将此活动变成例行新门禁。

### Requirement: 交付样品验证当前原生实现
设计样品的独立评审 MUST 观察由同一原生场景采集的关键帧，先盲看再同轮实际目标对照，动态用途的完整过程由总代理使用有序帧、完整解码及适用信号核对；纯静态样品无需视频。AI概念图或外部媒体可以用于参考、比较和内部探索，但其pass MUST NOT 转换为原生样品通过。代表性 MUST 按当前单张或局部窗口中主体、字体、材质光影及合成是否实际完成判断，其他镜头、全片与声音未覆盖写入限制，不擅自扩张或缩小当前范围。技术来源检查不进入视觉盲包。

#### Scenario: 静态代表性范围
- **WHEN** 评审单张实际网页静帧或适用局部样片
- **THEN** 评审 MUST 判断本范围的实际完成度，不以缺少全片否定静态，也不以静态通过覆盖尚未验证的核心运动。

#### Scenario: 失败后继续复查
- **WHEN** 当前样品未通过或证据不足
- **THEN** 助手 MUST 按原目标和适用范围持续修订，保留失败及真实调用，不挑选宽松评审或用探索观察关闭独立项。

### Requirement: 代理评审的帧与信号证据

独立评审代理 MUST 以清单登记的有序帧/静帧、完整解码与帧数/时长校验、帧差/场景切分、主体区域量测和音频信号量测为证据。代理 MUST NOT 声称实时观看或收听；MUST NOT 因缺少播放或试听能力把运动、转场或声音判为 insufficient。代理 MUST 按设计声明的可量测预期给出 pass/fail/insufficient，并在 observations 中引用具体帧号、时间窗与量测值。报告 MUST 标注证据类型“帧序列 + 信号量测”；作者不得把帧/信号结论扩写为主观听感或观感保证，也不得因代理未播放而否定已按指标完成的评审。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 只有登记帧与信号
- **WHEN** 评审包只提供有序帧、静帧、完整解码信息和音频信号报告
- **THEN** 评审 MUST 按窗口核对状态变化、转场、静止窗口、主体量测与声音事件，并给出具体结论，不要求额外播放或试听。

#### Scenario: 指标缺失
- **WHEN** 设计声明的可量测预期没有对应证据
- **THEN** 该观察项 MUST 记 insufficient，并指出缺少的指标与窗口，不以“无法播放”概括。

#### Scenario: 结论范围
- **WHEN** 评审据帧差、切分、主体量测或音频信号判定通过
- **THEN** 报告 MUST 写明依据的帧号、时间窗和量测值；不得写“看起来/听起来很好”等无法由证据支持的结论，也不得把该结论扩成未覆盖的场景或维度。

### Requirement: 世界级风格开放品质与明确采用

关键帧评审 MUST 先观察实际整体艺术效果，包括视线、主体形象、创意与表达，以及构图、排版、色彩和适用材质光影如何协作。试制 MUST 判断艺术方向已成立且代表画面足以指导后续制作。正式关键帧 MUST 达到所选风格的世界级创意、整体形象、构图注意力、排版色彩、实现细节、风格一致性与制作完成度。同轮对照 MUST 按事先登记的画面职责和参考采用范围核对用户的整体目标与专项表达，不强制苹果或其他固定品牌风格。

工具 MUST 要求每个观察项及整体给出明确采用结论。仅 pass 可采用，fail 与 insufficient 均不可采用，不用排名、平均分或“基本达到”放行。只有必要信息、核心形象或适用阶段的整体艺术效果实质受损，或违反已确认的目标，才可因视觉表现判 fail。报告 MUST 写出具体位置、实际显示条件、现象、目标与阻断影响。画面已经承担职责时，局部完善建议和偏好不得成为 fail。工具校验记录一致性。

#### Scenario: 证据不足
- **WHEN** 关键帧表现或代表性证据不足
- **THEN** 系统 MUST 明确不可采用及缺证范围，补证后再评审。

#### Scenario: 其他风格达到高水准
- **WHEN** 手绘、纪实或极繁作品达到其所选标杆的实际品质
- **THEN** 评审 MUST 按该风格判断，不因缺少苹果式材质、留白或字体否决。

#### Scenario: 试制与正式分别生成关键帧提问
- **WHEN** 系统生成试制或正式的关键帧盲审或同轮对照包
- **THEN** 包内 MUST 提示对应阶段的品质判据、整体艺术观察和视觉问题的阻断影响。盲审保持目标隔离，对照包使用已登记的职责和参考范围。

#### Scenario: 试制已经建立艺术方向
- **WHEN** 已验证的必要信息和核心形象成立，整体艺术效果足以作为制作基线，局部反光或纹理仍可完善
- **THEN** 评审 MUST 允许 pass 并记录具体打磨建议。若反光遮蔽主体形象或引发必要读数误读，则 MUST 阻断并记录具体影响。

### Requirement: 总代理实际审查与选案责任
总代理 MUST 送审前按静帧、有序抽帧和适用信号初筛实际媒体，无需播放观看或试听；核对独立观察覆盖、美术判断及真实目标对照，明确采用／修复／淘汰和依据，交付前确认当前媒体与有效报告一致。只有可读、无遮挡、技术正常的报告 MUST NOT 作为高品质美术通过。独立 pass 不免除已知问题；实质争议按原目标复核，不挑宽松评审，不单方关闭独立失败。决定 MUST 写入既有设计和唯一问题记录，不增加审批或平行台账。

#### Scenario: 报告只核对技术
- **WHEN** 报告判 pass 却没有实际美术表现及参考差距观察
- **THEN** 总代理 MUST 补足真实独立观察，不据此采用或交付。
