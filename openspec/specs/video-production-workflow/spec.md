# video-production-workflow Specification

## Purpose

以研究与创意试制、正式设计、制作与验收组织五类视频创作，让探索资源优先用于实际视觉验证，并保留完整作品表达、事实来源与独立验收的责任边界。

## Requirements

### Requirement: 三阶段创意试制优先
五类作品 MUST 采用研究与创意试制、正式设计、制作与验收。第一阶段 MUST 在内容目标、具体视觉标杆、深入拆解、本片转化、代表性实际试制和参考对照之间循环；研究须足以支持当前试验，未知触发补查，不等待全部研究结束。正式展开全片前 MUST 验证有吸引力且足以代表目标品质的实际画面及适用核心过程。后两阶段分别为完整设计与预演、制作迭代和验收交付。60/25/15 仅为原创高难度作品起始建议，不设机器预算、候选数量、研究时长或固定样片时长。

#### Scenario: 新作探索
- **WHEN** 开始新作或实质性视听重设计
- **THEN** 助手 MUST 把具体研究转成可执行设计，用代表性实际画面及适用独立对照确认方向，保留有效试制后扩展全片；不能以风格标签、链接数量或技术可行代替效果验证。

#### Scenario: 先看方案和图片
- **WHEN** 用户要求先看方案和图片
- **THEN** 助手 MUST 按同一研究深度交付具体参考、本片转化与代表性静态画面，说明差距和未覆盖范围；不擅自扩展到完整视频制作或声画通过。

#### Scenario: 方向未成立
- **WHEN** 实际试制与明确视觉目标存在关键差距
- **THEN** 助手 MUST 按缺研究依据、实现偏差或方向不适合分别补查、修复或重选，不提前将该形式铺满全片。

### Requirement: 最小设计记录与持续反馈
RESEARCH.md MUST 保存研究证据、解释、应用推断及方向比较；DESIGN.md MUST 引用研究并保存采用特征、本片落点、验证办法和已验证实际视觉基线，不含机器检查点合同。正式设计与制作 MUST 核对新场景和完整作品是否兑现所选目标，目标调整须明确记录并重新验证。问题 MUST 在唯一记录中按发现、修改、实际复查、关闭处理。事实、来源、许可与用户硬约束 MUST 保留。

#### Scenario: 全片设计与制作
- **WHEN** 展开完整设计或逐段制作
- **THEN** 全片预演和粗片检查 MUST 作为内部制作活动，检查整体结构、衔接及视觉基线在新场景中的实际效果；材料改变后重新准备，局部修复先查看实际效果再汇总全片。

#### Scenario: 局部修订复用
- **WHEN** 只修改局部文字或数据且表达和视觉目标未变
- **THEN** 助手 MUST 复用仍有效的研究与视觉基线，按实际影响复查，不重开无关风格探索；新反馈暴露视觉目标缺口时补相关研究。
