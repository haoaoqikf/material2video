# video-production-workflow Specification

## Purpose

以研究与创意试制、正式设计、制作与验收组织五类视频创作，让探索资源优先用于实际视觉验证，并保留完整作品表达、事实来源与独立验收的责任边界。

## Requirements

### Requirement: 三阶段创意试制优先
五类作品 MUST 采用研究与创意试制、正式设计、制作与验收。第一阶段 MUST 在简短内容目标、具体视觉标杆、深入拆解、本片转化、代表性实际试制和参考对照之间循环；研究须足以支持当前试验，未知触发补查，不等待全部研究结束。新方向 MUST 优先比较同一关键场景、同一核心内容的实质不同载体、构图或表达机制，不能以多个场景或换色代替选案。粗稿先筛选，潜力方向按判断所需补足精度；仅当精度差异妨碍选择时才补齐相近完成度。正式展开全片前 MUST 验证有吸引力且足以代表目标整体品质的实际画面及适用核心过程，概念效果须在拟用制作链路中重现。后两阶段分别为完整设计与预演、制作迭代和验收交付。60/25/15 仅为原创高难度作品起始建议，不设机器预算、候选数量、研究时长或固定样片时长。

#### Scenario: 新作探索
- **WHEN** 开始新作或实质性视听重设计
- **THEN** 助手 MUST 用简短任务明确理解、感受、事实和硬约束，将具体研究转成同一关键场景的实际候选，以相同内容比较表达；不能先写满全片方案锁定首稿，或以风格标签、链接数量、技术可行代替效果验证。

#### Scenario: 先看方案和图片
- **WHEN** 用户要求先看方案和图片
- **THEN** 助手 MUST 按同一研究深度交付具体参考、本片转化与代表性静态画面，说明差距和未覆盖范围；不擅自扩展到完整视频制作或声画通过。

#### Scenario: 方向未成立
- **WHEN** 实际试制与明确视觉目标存在关键差距
- **THEN** 助手 MUST 按缺研究依据、实现偏差或方向不适合分别补查、修复或重选，不提前将该形式铺满全片。

#### Scenario: 粗稿完成度不同
- **WHEN** 候选之一依赖材质或运动才能判断吸引力，而粗稿尚未体现该效果
- **THEN** 助手 MUST 补足影响判断的证据，不能因另一稿更精致而提前淘汰它；明显不成立的方向不必同等精修。

### Requirement: 最小设计记录与持续反馈
RESEARCH.md MUST 保存研究证据、解释、应用推断及方向比较；DESIGN.md MUST 引用研究并保存采用特征、本片落点、验证办法、选案理由、实际视觉基线及适用范围，不含机器检查点合同。候选相对优劣与是否足以展开 MUST 分别判断；全部淘汰、值得打磨和可作后续标准作为人读结论沿现有评审 observations 与设计记录保留，不新增机器状态。正式设计与制作 MUST 核对新场景和完整作品是否兑现所选目标，目标调整须明确记录并重新验证。每轮 MUST 聚焦最影响整体的差距，用前后实际媒体检查收益；问题在唯一记录中按发现、修改、实际复查、关闭处理。事实、来源、许可与用户硬约束 MUST 保留。

#### Scenario: 全片设计与制作
- **WHEN** 展开完整设计或逐段制作
- **THEN** 全片预演和粗片检查 MUST 作为内部制作活动，检查整体结构、衔接及视觉基线在新场景中的实际效果；新构图、信息密度或视听机制只补足可能推翻当前判断的证据，一个样片不能授权未覆盖机制；材料改变后重新准备，局部修复先查看实际效果再汇总全片。

#### Scenario: 局部修订复用
- **WHEN** 只修改局部文字或数据且表达和视觉目标未变
- **THEN** 助手 MUST 复用仍有效的研究与视觉基线，按实际影响复查，不重开无关风格探索；新反馈暴露视觉目标缺口时补相关研究。

#### Scenario: 最佳候选仍有关键差距
- **WHEN** 某候选相对最好但整体品质或实现证据不足
- **THEN** 助手 MUST 只安排针对主要差距的打磨或验证，不能凭排名或独立 pass 直接展开；若均无值得保留的方向，允许全部淘汰。

#### Scenario: 无收益或资源边界
- **WHEN** 同一问题连续两轮修复无改善，或执行被动中断、遇到外部阻塞而目标仍未成立
- **THEN** 助手 MUST 分别比较实质不同路线，或保留未完成并说明阻塞后继续；MUST NOT 主动设置资源上限、交付未通过样品，或把停止、增加记录与重复评审解释为通过。

### Requirement: 设计样品未通过持续迭代
设计试制 MUST 持续研究、实现、观察和复查，直到原定美术目标、适用核心过程及网页原生实现证据成立。MUST NOT 设置主动停止的总体时长、轮次或候选数量上限；同一问题连续两轮无改善 MUST 比较实质不同路线。失败、insufficient、失效或缺失评审 MUST NOT 作为样品交付，不能通过探索稿说明、候选排名、技术成功、缩小范围或重开周期结束。被动中断或外部阻塞 MUST 保持未完成，用户明确叫停时停止。

#### Scenario: 用户先看图片
- **WHEN** 用户只要求先看图片
- **THEN** 助手 MUST 从可运行网页场景取帧并完成同源视频验证，独立评审未通过就继续内部迭代，不擅自制作完整视频或交付AI概念图。

#### Scenario: 概念效果尚未重现
- **WHEN** AI概念图有吸引力但网页实现尚未达到目标
- **THEN** 助手 MUST 继续实现或重选载体并按目标比较，MUST NOT 把生成图贴入网页加推拉作为核心造型或动态实现。

### Requirement: 品质驱动实现手段
助手 MUST 允许主动研究、采用、组合、改造或开发合法可用的外部库、组件、模型、材质、Shader、建模与预计算工具；不得把现有SDK、固定依赖名单、熟悉程度或少写代码作为品质上限。采用结果 MUST 本地可恢复、来源与许可可追溯、服从制作时钟并通过实际网页及视频验证。完整AI图片只能作概念参考，不能代替核心网页实现。

#### Scenario: 现有能力不足
- **WHEN** 既有组件不能达到已选目标
- **THEN** 助手 MUST 研究并验证外部方案、适配或自研，不能为迁就已有实现降低目标，也不能仅凭库名或演示好看宣称完成。
