# video-production-workflow Specification

## Purpose

以研究与创意试制、正式设计、制作与验收组织五类视频创作，让探索资源优先用于实际视觉验证，并保留完整作品表达、事实来源与独立验收的责任边界。

## Requirements

### Requirement: 三阶段创意试制优先
五类作品 MUST 采用研究与创意试制、正式设计、制作与验收。优秀案例调研 MUST 作为全片活动统一开展，每个场景引用适用结论。新作 MUST 从表达目标出发，依次搜索和拆解案例、形成镜头方案、开展全片组件调研并试制代表场景。后续可按证据反馈补查或回退，实质性视听修订按当前缺口复用或补充已有研究。新方向 MUST 优先比较同一关键场景、同一核心内容的实质不同载体、构图或表达机制，不能以多个场景或换色代替选案。粗稿先筛选，潜力方向按判断所需补足精度；仅当精度差异妨碍选择时才补齐相近完成度。正式展开全片前 MUST 验证有吸引力且足以代表目标整体品质的实际画面及适用核心过程，概念效果须在拟用制作链路中重现；研究期间按目标时长安排，正式验收 MUST 用当前准备时间轴的总帧数和帧率判定。总帧数不超过 30 × 帧率时只要求关键帧独立评审及整片证据复核，直接在全片工程中迭代。超过门槛 MUST 另有关键样片独立评审。预演、粗片与精制 MUST 统一进入问题驱动制作循环，按当前未知选择静帧、局部过程或完整候选，不强制顺序生成一套中间产物。60/25/15 仅为原创高难度作品起始建议，不设机器预算、候选数量、研究时长或固定样片时长。

#### Scenario: 新作探索
- **WHEN** 开始新作或实质性视听重设计
- **THEN** 助手 MUST 用简短任务明确理解、感受、事实和硬约束，把案例转化与组件选型落到同一关键场景的实际候选，以相同内容比较表达；不能先写满全片方案锁定首稿，或以风格标签、链接数量、技术可行代替效果验证。

#### Scenario: 先看方案和图片
- **WHEN** 用户要求先看方案和图片
- **THEN** 助手 MUST 按同一研究深度交付具体参考、本片转化与代表性静态画面，说明差距和未覆盖范围；不擅自扩展到完整视频制作或声画通过。

#### Scenario: 短片免试制样片
- **WHEN** 当前准备时间轴不超过 30 秒
- **THEN** 助手 MUST 完成全片案例调研与适用的全片组件选型后直接制作全片，MUST NOT 另出局部试制样片或试制片；核心效果在全片制作中验证，未达目标按返工规则修订，关键帧 MUST 从全片工程采集并独立盲审及对照，总代理 MUST 用当前候选的抽帧、有序帧和适用的信号证据核查密集口播、切镜、复杂动效及字幕风险，并核对技术 QA；无需播放观看或试听。

#### Scenario: 方向未成立
- **WHEN** 实际试制与明确视觉目标存在关键差距
- **THEN** 助手 MUST 按缺研究依据、实现偏差或方向不适合分别补查、修复或重选，不提前将该形式铺满全片。

#### Scenario: 粗稿完成度不同
- **WHEN** 候选之一依赖材质或运动才能判断吸引力，而粗稿尚未体现该效果
- **THEN** 助手 MUST 补足影响判断的证据，不能因另一稿更精致而提前淘汰它；明显不成立的方向不必同等精修。

#### Scenario: 优秀案例调研
- **WHEN** 新作或实质性视听重设计需要建立或补查视觉方向
- **THEN** 助手 MUST 按当前表达问题检索具体作品的静帧、抽帧、时间轴或可靠来源资料，说明参考用途和证据范围，无需播放观看或试听，拆解影响本片的构图、动效、节奏和视觉表达，声音和转场按实际需要展开。在 RESEARCH.md 中连接实际观察、效果解释、可借鉴的方法、本片关键帧与动作安排及验证预期；针对具体镜头的案例观察 MUST 在同一研究记录中标明适用场景或镜头。镜头方案 MUST 向组件调研交付实际能力需求。静帧对时间和声音只支持有标记且待验证的推断。

#### Scenario: 案例调研向试制交接
- **WHEN** 准备试制代表场景
- **THEN** 助手 MUST 有依据确定构图、关键状态、信息揭示顺序和可观察的成立条件，并完成适用的组件选型。影响核心方向的研究证据缺口 MUST 先补查，适合小试验证的未知 MUST 以明确假设和验证预期进入试制。

#### Scenario: 实质性视听修订
- **WHEN** 既有作品的部分视觉表达或实现需要重设计
- **THEN** 助手 MUST 核对既有案例结论是否仍覆盖目标，按受影响的表达问题补查，按实现缺口更新组件需求和试制范围。

#### Scenario: 验证动态研究试制样片
- **WHEN** 研究试制提供可运行网页的代表性动态窗口
- **THEN** 助手 MUST 组织同源关键帧独立盲审与同轮对照，由总代理核对完整动作与适用信号。正式成片的关键片段独立审核按正式时长和风险适用。

### Requirement: 最小设计记录与持续反馈
RESEARCH.md MUST 保存全片案例与全片组件调研的证据及方向比较；DESIGN.md MUST 引用研究并保存全片共同目标、采用范围、选案理由、实际视觉基线和场景索引；详细编排与本场验证办法 MUST 放在对应场景文档。设计不含机器检查点合同。候选优劣与足以展开 MUST 分别判断，正式采用结论 MUST 明确通过或不通过，fail 与 insufficient 均不得采用；后续行动沿现有观察与设计保留，不新增状态台账。三阶段 MUST 允许设计、实现、观察往返，不先写满全片细节锁定首稿。正式展开 MUST 核对新内容和完整作品的目标兑现；有效结论在成为后续标准或评审依据前回写。每轮 MUST 聚焦主要差距，用前后实际媒体检查收益；问题沿唯一记录闭环。事实、来源、许可与用户硬约束 MUST 保留。

#### Scenario: 全片设计与制作
- **WHEN** 展开完整设计或逐段制作
- **THEN** 助手 MUST 先组织全片骨架并优先深化关键未知场景，随试制细化其他场景；预演和粗片为内部活动，检查结构、衔接及风格迁移，一个样片不授权未覆盖机制，材料变化后重新准备，局部修复先查看再汇总全片。

#### Scenario: 局部修订复用
- **WHEN** 只修改局部文字或数据且表达与视觉目标未变
- **THEN** 助手 MUST 复用有效研究和基线，只更新受影响场景及必要共同设计；新缺口补查，不重开无关选案或补造旧记录。

#### Scenario: 最佳候选仍有关键差距
- **WHEN** 相对最好候选的整体品质或实现证据不足
- **THEN** 助手 MUST 只安排主要差距的打磨或验证，不能凭排名或独立 pass 展开；均无潜力时允许全部淘汰。

#### Scenario: 无收益或资源边界
- **WHEN** 同一问题两轮修复无改善，或遇到被动中断和外部阻塞
- **THEN** 助手 MUST 换实质路线，或保留未完成并说明阻塞。试制关键帧按暂停和恢复规则执行；不得设置主动总上限、交付未通过样品，或把记录与重复评审当成通过。

### Requirement: 设计样品未通过持续迭代
设计试制 MUST 持续研究、实现、观察和复查，直到原定美术目标、适用核心过程及网页原生实现证据成立。MUST NOT 设置主动停止的总体时长、轮次或候选数量上限。失败、insufficient、失效或缺失评审 MUST NOT 作为样品交付，不能通过探索稿说明、候选排名、技术成功、缩小范围或重开周期结束。被动中断或外部阻塞 MUST 保持未完成，用户明确叫停时停止。

#### Scenario: 用户先看图片
- **WHEN** 用户只要求先看图片
- **THEN** 助手 MUST 从可运行网页场景取帧；纯静态目标无需编码视频，承诺动态时完成同源过程验证，独立评审未通过就继续内部迭代，不擅自制作完整视频或交付AI概念图。

#### Scenario: 概念效果尚未重现
- **WHEN** AI概念图有吸引力但网页实现尚未达到目标
- **THEN** 助手 MUST 继续实现或重选载体并按目标比较，MUST NOT 把生成图贴入网页加推拉作为核心造型或动态实现。

#### Scenario: 判定试制修订有没有改善
- **WHEN** 制作方就同一核心问题修改试制关键帧
- **THEN** 制作方 MUST 在同一帧位或等价观察窗口和原观看条件下对看前后实绘，在现有问题记录写明原目标、可见变化、已有保留项和剩余差距。核心效果出现明确且未以其他核心效果受损换来的进步，才计作改善。复送 MUST 有明显改善的证据；缺少可比证据时先补证，暂不计入无改善次数。换候选、改实现或重新生成评审包不得清零同一问题的记录。

#### Scenario: 两次无明显改善后暂停
- **WHEN** 对同一个核心问题连续两次有针对性的修改，经配对实绘仍看不到明显改善
- **THEN** 制作方 MUST 暂停当前方案的正式送审及仅为该问题发起的整段重渲，在现有问题记录保留原失败、两次对比和暂停依据。制作方 MUST 先在小范围内部比较并重新选择实质不同的方案。

#### Scenario: 实质争议按原目标复核
- **WHEN** 对具体差距是否阻断本阶段采用存在实质分歧
- **THEN** 同一问题 MUST 至多组织一次对相同媒体、原目标、原范围及观看条件的独立复核，依实际证据处理争议。保留原观察和报告，不轮换评审挑选结论，也不因复核自动解除送审暂停。

#### Scenario: 重新选案后恢复送审
- **WHEN** 当前方案已因两次无明显改善而暂停
- **THEN** 制作方 MUST 在实质不同的候选上取得对原核心问题的可见改善并核对相关已有成果后才恢复正式送审。新候选 MUST 按原适用范围完成同源独立盲审及同轮对照，原失败仍按适用的独立证据关闭。用户明确改变目标时沿既有目标变更协议办理。

### Requirement: 品质驱动实现手段
成熟组件调研 MUST 从已选效果和实现需求出发，先查内部组件、原语和示例。内部实现达到目标时 MUST 直接复用并验证。仍有缺口时 MUST 按需检索适用的成熟外部组件、开源实现、模型、材质、Shader、建模或预计算工具，优先采用、组合或改造，只自研必要部分。验证 MUST 用本片实际内容核对效果、逐帧确定性、维护、来源许可、成本、性能、本地恢复和受控采集。全片组件调研 MUST 聚焦决定全片方向的核心效果与跨场复用，使用代表场景验证适用范围。每个场景的实现方案 MUST 核对组件需求和已有实现；满足需求时 MUST 引用适用依据并核对本场效果，仅对具体缺口补查与试验。各自的实际查找、采用决定、外部来源版本与许可（如适用）、试制结果和缺口 MUST 按影响范围归入 RESEARCH.md 或对应场景文档，同一证据保留一份并引用。完整 AI 图片只能作概念参考。

#### Scenario: 现有能力不足
- **WHEN** 既有组件不能达到已选目标
- **THEN** 助手 MUST 研究并验证外部方案、适配或自研，不能为迁就已有实现降低目标，也不能仅凭库名或演示好看宣称完成。

#### Scenario: 内部组件已经满足目标
- **WHEN** 内部成熟实现能达到目标
- **THEN** 助手 MUST 记录复用依据并进入同一场景的小试，外部检索仅在出现未满足的需求时触发。

#### Scenario: 本场存在实现缺口
- **WHEN** 场景镜头方案对现有组件有具体未满足的要求
- **THEN** 助手 MUST 在本场文档记录查找、取舍和验证结果；若发现关系到整片方向或跨场采用，MUST 将适用范围及证据链接回写全片研究。

### Requirement: 适用视听决策与可量测预期
实际采用、承诺或影响判断的全片研究依据与假设 MUST 记录在 RESEARCH.md；局部组件调研依据与假设 MUST 记录在对应场景文档。DESIGN.md MUST 确定适用的视听共同语言，场景文档 MUST 将其落实为可观察的注意力变化、对象关系和关键状态。只有静帧时 MUST 标明推导依据、置信度与验证办法。超过 30 秒的作品 MUST 先在总设计说明关键样片所要回答的问题，再选择能够观察完整起因、变化、结果或前后衔接的窗口。适用关键目标 MUST 有对应观察窗口与可验证预期；量测按机制选择，可包含状态切换、静止窗口、转场、主体区域和声画同步等，不强制所有场景填写全部指标。静止、无声和 cut 可明确采用，不设逐场动作/特效配额。独立媒体评审 MUST 依据帧序列、完整解码和适用信号量测核对，不要求播放或试听；适用关键证据缺失记 insufficient，未达目标记 fail，指标通过不代替整体品质。

#### Scenario: 只有静态参考
- **WHEN** 设计只有静态参考图
- **THEN** 助手 MUST 将必要的表达、运动、声音和转场推导标为假设，按实际采用机制用过程验证；不冒充外部观察，不省略必要设计。

#### Scenario: 场景没有可量测预期
- **WHEN** 关键采用效果没有可验证预期或证据
- **THEN** 助手 MUST 保持该效果未验证，允许内部试制解决未知，但不能作为正式有效基线或通过；不适用的运动、声音或转场指标不阻断静态或无声设计。

#### Scenario: 只有帧与信号证据
- **WHEN** 评审只能读取帧序列与信号量测
- **THEN** 评审 MUST 按适用目标引用帧号、窗口和量测结果，不因缺播放器自动不足，也不扩写为无法量测的主观听感。

### Requirement: 场景承诺贯穿研究与制作
研究 MUST 优先解决影响方向判断的关键未知，将参考研究转成场景关系与试制预期；正式设计 MUST 沿有效基线渐进展开，再组织全片预演。制作与复核 MUST 对照原承诺观察注意力、因果、节奏、主体吸引力及整体效果，回写当前结果；核心机制未解决 MUST 回到设计或研究，不得以装饰、可读性或技术成功替代。选案、返工和独立评审沿各自唯一权威，不增加审批或完成门禁。

#### Scenario: 代表性试制尚未解决关键未知
- **WHEN** 新方向的因果或整体形象尚未成立
- **THEN** 助手 MUST 继续针对关键场景研究试制，不因技术页写全片预演而先铺满整片。

#### Scenario: 制作反馈
- **WHEN** 局部实现与设计的核心承诺不符
- **THEN** 助手 MUST 在相应层级修订并核对实际过程，不能只补装饰或借用旧通过。
