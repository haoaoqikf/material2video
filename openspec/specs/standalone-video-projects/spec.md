# standalone-video-projects Specification

## Purpose

使视频作品拥有完整且可移动的执行工程，主项目只提供制作指导、起步材料、组件参考和可选的制作管理；通过实际脱离仓库的恢复、预览与导出证明独立，避免目录分离掩盖构建和运行依赖。

## Requirements

### Requirement: 作品完整独立运行

作品 MUST 拥有依赖声明与锁文件、构建配置、运行宿主、数据准备、资源恢复、预览、采集、成片合成、视频导出及技术检查入口。使用本地 TTS 后端（Kokoro 或 Qwen3-TTS）的作品 MUST 在自身依赖与恢复入口中声明模型、音色/参考音频、对齐模型与许可，并能脱离主项目恢复与准备。完成声明的环境和资源恢复后，作品 MUST 在主项目未安装且路径不可访问时执行上述操作。运行、编译及类型检查 MUST NOT 读取主项目源码、依赖目录、字体、补丁或缓存；MUST NOT 使用指向主项目的软链接、workspace、file/link依赖或隐式父目录解析。

#### Scenario: 干净目录脱库运行
- **WHEN** 将完整作品源码复制到任意干净目录，主项目不可访问，清空作品构建缓存并按作品说明恢复依赖和资源
- **THEN** 作品独立校验、构建、预览并导出有效完整视频，产物只位于作品输出目录。

#### Scenario: 本地 TTS 模型恢复
- **WHEN** 作品使用 `backend=qwen3-tts` 且主模型、speech tokenizer 或对齐模型尚未恢复
- **THEN** 校验与准备明确失败并给出作品内恢复入口；恢复后断网仍可准备、预览与导出

#### Scenario: 移动与依赖隔离
- **WHEN** 作品更名、移动到含空格路径，或与使用另一依赖版本的作品同机运行
- **THEN** 各自按本地锁文件解析，互不改变依赖或执行结果。

### Requirement: 组件只供选择采用
主项目组件 MUST 作为有用途、依赖、来源、许可与已验证范围的参考或生成材料。作品 MUST 能选择本地实现、复制必要源码或直接依赖合适第三方库；MUST NOT 要求安装主项目SDK。采用的源码与递归本地依赖 MUST 进入作品，后续更新 MUST 为作品显式选择，主项目修改 MUST NOT 自动传播。

#### Scenario: 主项目组件更新
- **WHEN** 主项目组件、模板或全局依赖发生修改
- **THEN** 既有作品的实际渲染输入及已生成媒体保持原绑定，不因主项目修改而重新采集。

### Requirement: 本地执行与可选制作管理
作品 MUST 提供直接调用的准备、预览、构建、导出、原生样品与技术检查入口。主项目命令 MUST 委托作品声明的本地入口，MUST NOT 注入主项目运行时。接入制作管理的作品 MUST 以版本化结果记录声明输入、产物、失败及环境，管理工具 MUST 复核文件与摘要。独立运行 MUST NOT 要求接入主项目管理协议。

作品 MUST 使用 v3 项目清单和独立版本化的参考绑定。本地及委托入口 MUST 使用同一绑定，现有准备输入映射 MUST 记录并核验绑定文件的摘要。旧材料及漏绑旧准备不得作为当前输入。历史报告保留原结论及适用范围。作品可使用本地快照离线核验参考，渲染使用作品本地代码、时序和资源。

#### Scenario: 两种调用同源
- **WHEN** 同一作品直接使用本地入口，或由主项目委托
- **THEN** 工程配置、参考修订、清单摘要与检查结果一致，采集及合成条件一致。

#### Scenario: 参考绑定变化使证据过期
- **WHEN** 已准备工程的参考清单摘要或生效授权范围发生变化
- **THEN** 须重新准备，旧风格结论不得授权当前完成。

### Requirement: 随附示例全部独立
系统 MUST 在 `examples/<type>/<slug>/` 保留 `data-evolution/compound-after-20`、`data-evolution/global-market-cap-race-portrait`、`spatial-3d/solar-system-journey` 三部示例。每部 MUST 包含独立工程、恢复说明及生效的类型默认参考绑定，保持原片主题、场景身份、数学或事实口径、必要视听目标及音轨要求。复利 MUST 保留原克隆音色，由使用者本地提供同一参考 WAV 和音色档案。版本控制 MUST NOT 包含参考录音、参考文本或本地来源路径。每例 MUST 提供脱库构建、真实预演、完整导出的技术证据，逐部执行适用的实际参考对照并复核代表画面和过程，按观察到的差距调整。禁止以空场景、占位或缩减内容替代示例。图文动效继续可独立初始化并制作。

#### Scenario: 独立示例矩阵
- **WHEN** 逐一复制三例到仓库外并恢复运行
- **THEN** 每例可预览与完整导出，按实际使用范围验证三维异步、公式字体、真实媒体、事件音效、旁白、转场及当前参考对照。

#### Scenario: 示例集合与类型独立
- **WHEN** 枚举分发示例并初始化图文动效
- **THEN** 分发目录和示例验证仅包含上述三例，图文动效初始化生成含默认参考绑定的完整独立工程。

#### Scenario: 本地恢复复利示例旁白
- **WHEN** 在仓库外示例副本恢复登记参考 WAV、音色档案、公开权重和字体
- **THEN** 以原音色生成四幕双语字幕成片，媒体属性按示例的作品清单和分镜核验。参考缺失或摘要不符时明确拒绝，并保留已有有效文件。

#### Scenario: 竖屏市值榜独立导出
- **WHEN** 恢复竖屏市值榜示例并完整导出
- **THEN** 使用随附历史快照呈现完整排名及榜首交接，并保留平台叠加窗口的深底隔离和静音要求，媒体属性按示例的作品清单和分镜核验。

### Requirement: 清理不必要的通用实现
改造 MUST 清查通用运行时、视觉组件、类型专用绘制包装、依赖登记、全局配置、测试和文档。失去职责、重复、不可达或无消费者的实现 MUST 删除；有实际采用价值的实现 MUST 收敛到本地模板或明确参考。清理 MUST 有逐项原位置、消费者、处置与验证记录；MUST NOT 建立旧版兼容入口、重复新旧管线或重新打包整个主项目到每部作品。

#### Scenario: 删除前核对消费者
- **WHEN** 删除一个通用组件、包装层或依赖
- **THEN** 实际消费者已本地化或确认不存在，相关测试保留独特覆盖；没有悬空导入和失效文档链接。

### Requirement: 历史与制作完成边界
改造 MUST 保留现有历史研究、报告、问题与来源记录的真实结论，不批量转换被忽略的历史作品。新工程 MUST 明确拒绝旧执行契约和准备记录；旧实现由Git历史追溯。技术导出 MUST 允许生成待评审候选，但 MUST NOT 自动宣布制作完成或关闭独立评审问题。

#### Scenario: 旧证据不冒充新版通过
- **WHEN** 示例改造后重新构建或运行旧作品
- **THEN** 新媒体绑定新的实际输入；旧报告保留原范围，旧工程明确报契约不符，不通过兼容映射静默运行。
