# media-bound-production-review Specification

## Purpose

以实际媒体和观察范围建立轻量、可追溯的独立视觉评审体系，支持全片设计前试制、有效证据复用和当前成片终审，避免声明式画面合同与顺序门禁给创意试验增加前置负担。

## Requirements

### Requirement: 独立媒体契约与显式周期
系统 MUST 提供 review start/pack/import/timeline，拒绝旧检查点合同和旧报告；周期、报告、包均版本化，旧历史保留不迁移。试制包 MUST 不依赖 DESIGN.md、prepared 或全片分镜；本地媒体、来源依赖和观察窗口须摘要绑定。全片播放器 MUST 使用有效准备材料且无视觉门前置。

#### Scenario: 局部试制
- **WHEN** 只有代表性关键帧或核心片段
- **THEN** 可以建立隔离试制包；修改相关依赖使其过期，无关场景不无故使其过期。

### Requirement: 当前候选与完整证据
终审 MUST 绑定当前有效完整候选和技术 QA。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列及显示条件；静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。

#### Scenario: 终审候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得授权新片；无关试制证据按实际依赖保留。

### Requirement: 问题与基线保护
系统 MUST 保存失败及复查历史，问题重开不得丢失原条件与证据。跨周期报告不得关闭旧问题。基线 MUST 保护活动引用，损坏或未知引用阻止媒体清理；只读状态不得修改文件。

#### Scenario: 独立问题关闭
- **WHEN** 当前对应范围的独立复查通过
- **THEN** 可关闭该问题；自审、错误范围或旧周期报告必须拒绝。

### Requirement: 目标参考与可观察特征配套对照
评审请求提供非空 references 时 MUST 同时提供非空 conditions 描述中性可观察目标；缺失或空目标条件 MUST 在创建评审包之前明确拒绝。目标媒体与条件 MUST 在盲包外摘要绑定，在盲看导入后的同轮对照包中才展示；中性条件无参考媒体时仍允许用于事实和表达核对。独立对照 MUST 观察实际目标效果与差距，理解、可读性或技术无错不能替代表现与代表性判断。工具只校验材料与记录完整性，不自动评判风格研究、审美或阶段完成。

#### Scenario: 只有参考媒体
- **WHEN** 请求带有参考媒体但缺少或清空中性采用特征
- **THEN** 请求 MUST 明确失败且不创建媒体包，不把任何图片当成没有范围的默认审美标准。

#### Scenario: 有参考的同轮对照
- **WHEN** 请求同时提供目标媒体和中性采用特征
- **THEN** 盲包 MUST 不泄露目标或特征，对照包 MUST 包含实际净化目标媒体和原条件，并要求观察兑现情况及具体差距。

#### Scenario: 事实条件没有风格参考
- **WHEN** 请求只有中性事实条件而没有参考媒体
- **THEN** 仍可进行同轮事实对照，但助手不得据此声称已验证未提供的风格目标。

#### Scenario: 盲看后追加目标
- **WHEN** 对照请求向原本未登记参考的盲看请求追加目标媒体
- **THEN** 工具 MUST 拒绝绑定不同的同轮对照，助手需重新建立适用盲看与对照，不修改旧包或旧报告。

### Requirement: 用户明确变更目标的登记与重新评审
系统 MUST 提供 `review retarget --file`，在当前周期保存 source=user 的用户原指令、指定独立失败身份和当前有效新盲包目标的不可改写摘要收据。登记 MUST 保留旧周期、问题范围与失败结论，只替换指定问题后续复查使用的参考媒体和中性条件；不自动关闭问题。目标登记阶段包括final均 MUST 保持来源、场景、观察项身份与窗口覆盖；登记后的全片复查仍 MUST 覆盖当前完整候选，不要求维持旧全片时长。助手 MUST 仅在用户明确允许改目标时使用，工具不声称能认证自然语言授权。

#### Scenario: 用户明确重选视觉基准
- **WHEN** 用户明确允许更换基准，新的封存盲包覆盖相同职责、显示尺寸、来源与原窗口
- **THEN** 系统 MUST 登记新目标，保留旧失败；只有变更登记后的当前独立盲看和适用同轮对照通过才能关闭指定问题。

#### Scenario: 无有效授权或缩小复查范围
- **WHEN** 缺少用户指令声明、报告不是当前周期的独立失败、新包过期、目标没有变化或新包缩小结构范围
- **THEN** 系统 MUST 拒绝登记，不改问题和历史。

#### Scenario: 变更记录失效或借用原通过
- **WHEN** 记录摘要损坏、跨周期，或者关闭依据早于目标变更
- **THEN** 系统 MUST 拒绝授权关闭；未登记的问题 MUST 继续按原目标严格匹配。
