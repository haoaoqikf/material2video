# media-bound-production-review Specification

## Purpose

以实际媒体和观察范围建立轻量、可追溯的独立视觉评审体系，支持全片设计前试制、有效证据复用和当前候选复核，避免声明式画面合同与顺序门禁给创意试验增加前置负担。

## Requirements

### Requirement: 独立媒体契约与显式周期
系统 MUST 提供 review start/pack/import/timeline、自动派生对照与结构化报告模板，拒绝旧检查点合同和旧报告；周期、请求、报告、包 MUST 使用 v4；请求 MUST 指定 keyframe 或 process 用途，旧历史保留不迁移且不能授权当前通过；当前 v4 周期有开放必改或损坏历史 MUST 拒绝重开。历史升级 MUST 核对工作流、原周期身份和历史问题，承接未解决的必改，不接受篡改或未知版本。关键帧只展示静态图像，过程只展示完整视频窗口。正式过程默认直接独立目标对照；例外盲审 MUST 提供具体风险依据。试制包 MUST 不依赖 DESIGN.md、prepared 或全片分镜；本地媒体、来源依赖和观察窗口须摘要绑定。全片播放器 MUST 使用有效准备材料且无视觉门前置。

#### Scenario: 局部试制
- **WHEN** 只有代表性关键帧或核心片段
- **THEN** 可以建立隔离试制包；修改相关依赖使其过期，无关场景不无故使其过期。

#### Scenario: 研究试制完整过程退出独立评审
- **WHEN** 过程请求指向原生试制采集或其动态媒体
- **THEN** 工具 MUST 拒绝为该过程生成独立包或提交新报告。已封存记录保留。原生关键帧继续独立盲审及同轮对照。

### Requirement: 当前候选与完整证据

整片复核记录 MUST 绑定当前完整候选摘要、准备指纹和有效技术 QA，并记录总代理用当前候选的抽帧、有序帧、适用信号和时间轴证据得出的全片结论及高风险窗口。制作全程 MUST NOT 要求播放视频观看或实际试听。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列、帧差/场景切分与适用主体区域量测；声音 MUST 有响度、真峰值、静音、起音、频谱与同步等信号量测；不要求播放或试听。评审结论 MUST 引用具体帧号、时间窗和量测值；适用运动、转场或声音目标的关键指标/证据缺失 MUST 记 insufficient，不达预期 MUST 记 fail。静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。trial 完整观察等价复用仅允许旧来源文件当前内容不同，不得忽略封存请求、原来源摘要记录、包 manifest、全部包内观察媒体与参考、条件、报告、调用及账本身份的完整性；任何封存证据缺失或改写 MUST 拒绝。复用授权当前媒体的视觉结论，不恢复旧技术绑定的有效性。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 终审候选变化
- **WHEN** 旧独立终审的候选由新流程的当前候选取代
- **THEN** 原终审结论和引用保留为历史，不能授权新流程完成，尚未解决的必改继续跟踪。

#### Scenario: 当前候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得直接授权新片；无关试制证据按实际依赖保留。可通过完整观察等价收据另行授权当前有效采集。候选变化 MUST 重新完成总代理整片复核。

#### Scenario: 历史封存损坏
- **WHEN** 旧来源当前内容改变但封存身份完整，或封存请求、报告、包内文件任一损坏
- **THEN** 前者可继续核验显式 trial 复用，其当前技术绑定仍失效；后者 MUST 拒绝复用，不以旧来源变化为由跳过历史完整性验证。

#### Scenario: 帧与信号评审
- **WHEN** 待审关键样片只有有序帧、完整解码和音频信号量测可供评审
- **THEN** 评审 MUST 据此核对状态切换、转场、静止窗口、主体量测与声音事件，按设计指标给出结论；MUST NOT 因缺少播放或试听把该范围判为未验证。

### Requirement: 问题与基线保护
系统 MUST 保存独立评审原件及失败和复查历史，问题重开不得丢失原条件与证据。跨周期报告不得关闭旧问题。旧基线媒体清理后，仍需要该媒体而无同摘要原件可用的引用 MUST 标记不可复核。原报告和结论 MUST 保持原样，缺失旧媒体不得关闭问题或授权当前通过。损坏或未知的当前证据引用阻止相关媒体清理。只读状态不得修改文件。

#### Scenario: 独立问题关闭
- **WHEN** 当前对应范围的独立复查通过
- **THEN** 可关闭该问题；自审、错误范围或旧周期报告必须拒绝。

### Requirement: 目标参考与可观察特征配套对照
评审请求提供非空 references 时 MUST 同时提供非空 conditions 描述中性可观察目标；缺失或空目标条件 MUST 在创建评审包之前明确拒绝。目标媒体与条件 MUST 在盲包外摘要绑定，在关键帧或适用过程盲看导入后的同轮对照包中才展示；过程直接对照包 MUST 提供实际参考及中性条件，MUST NOT 伪造盲报告身份；中性条件无参考媒体时仍允许用于事实和表达核对。独立对照 MUST 观察实际目标效果与差距，理解、可读性或技术无错不能替代表现与代表性判断。工具只校验材料与记录完整性，不自动评判风格研究、审美或阶段完成。

#### Scenario: 只有参考媒体
- **WHEN** 请求带有参考媒体但缺少或清空中性采用特征
- **THEN** 请求 MUST 明确失败且不创建媒体包，不把任何图片当成没有范围的默认审美标准。

#### Scenario: 有参考的同轮对照
- **WHEN** 请求同时提供目标媒体和中性采用特征
- **THEN** 盲包 MUST 不泄露目标或特征，对照包 MUST 包含实际净化目标媒体和原条件，并要求观察兑现情况及具体差距。

#### Scenario: 事实条件没有风格参考
- **WHEN** 请求只有中性事实条件而没有参考媒体
- **THEN** 仍可进行同轮事实对照，但助手不得据此声称已验证未提供的风格目标。

#### Scenario: 盲看后追加目标
- **WHEN** 对照请求向原本未登记参考的盲看请求追加目标媒体
- **THEN** 工具 MUST 拒绝绑定不同的同轮对照，助手需重新建立适用盲看与对照，不修改旧包或旧报告。

### Requirement: 用户明确变更目标的登记与重新评审
系统 MUST 提供 `review retarget --file`，在当前周期保存 source=user 的用户原指令、指定独立失败身份和当前有效新盲包目标的不可改写摘要收据。登记 MUST 保留旧周期、问题范围与失败结论，只替换指定问题后续复查使用的参考媒体和中性条件；不自动关闭问题。目标登记 MUST 保持来源、场景、观察项身份与窗口覆盖。助手 MUST 仅在用户明确允许改目标时使用，工具不声称能认证自然语言授权。

#### Scenario: 用户明确重选视觉基准
- **WHEN** 用户明确允许更换基准，新的封存盲包覆盖相同职责、显示尺寸、来源与原窗口
- **THEN** 系统 MUST 登记新目标，保留旧失败；只有变更登记后的当前独立盲看和适用同轮对照通过才能关闭指定问题。

#### Scenario: 无有效授权或缩小复查范围
- **WHEN** 缺少用户指令声明、报告不是当前周期的独立失败、新包过期、目标没有变化或新包缩小结构范围
- **THEN** 系统 MUST 拒绝登记，不改问题和历史。

#### Scenario: 变更记录失效或借用原通过
- **WHEN** 记录摘要损坏、跨周期，或者关闭依据早于目标变更
- **THEN** 系统 MUST 拒绝授权关闭；未登记的问题 MUST 继续按原目标严格匹配。

### Requirement: 采用边界与阻断依据
助手 MUST 在评审条件中明确参考的采用范围，用户选择 MUST 进入作品决策依据。独立评审 MUST 根据实际整体效果及已采用目标判断；fail MUST 指出具体窗口、显示条件、违反目标和阻断影响。无阻断缺陷时，进一步改善 MUST 作为 pass 的 limitations 保留；不能仅因仍可改善、未复制未采用特征或个人偏好而 fail。证据缺失 MUST 保持 insufficient。作者 MUST 明确保留项、必修项和打磨项，不能把独立观察代替选案责任。

#### Scenario: 参考局部特征未采用
- **WHEN** 本片只采用参考的纸质与光照，未采用其品牌色和字形
- **THEN** 评审 MUST 观察实际整体品质，但不能以未复制品牌色或字形单独否决；纸质与光照目标明确失败仍 MUST 阻断。

#### Scenario: 好方案仍有优化空间
- **WHEN** 核心表达、整体美术与已采用目标成立，仅有不影响关键读取的次要层间亮度建议
- **THEN** 评审 MUST 保留具体建议并允许 pass；作者 MUST 记录选用与后续打磨决策，不默认重开风格探索。

#### Scenario: 原失败仍有效
- **WHEN** 历史独立 fail 已导入
- **THEN** 作者 MUST 保留必改状态，不能自行改成建议；真实用户目标变化 MUST 按既有 retarget 登记，再独立复查。

### Requirement: 完整观察相同的视觉结论复用
系统 MUST 允许将历史 trial 独立视觉结论显式绑定到重新验证的当前媒体，同时保留原报告身份、导入与观察时间，不冒充新独立调用。复用 MUST 验证完整源媒体文件字节摘要、全部观察窗口、帧率、显示尺寸、职责、条件及参考均相同，包括视频完整容器及适用音轨；不同编码或容器即使近似相同也 MUST 拒绝。当前采集来源、数据、许可、运行及产物绑定 MUST 单独有效。等价证明 MUST 可追溯并能失效，不能用单帧、缩略图或作者声明替代完整等价。复用 MUST 限于同一周期和同一用途，整片证据复核须由总代理从当前完整候选取证并完成。关闭失败 MUST 使用原报告导入与原调用时间核验晚于原失败及适用 retarget，收据登记时间不得替代。

#### Scenario: 源码变化但观察媒体完全相同
- **WHEN** 当前技术绑定有效，全部观察媒体及目标相同且无未解决的相反结论
- **THEN** 系统 MUST 允许复用原独立视觉结论，重新核验技术证据，原报告本身仍保留原来源绑定。

#### Scenario: 新运动或目标变化
- **WHEN** 任一观察帧、时间、声音覆盖、目标、窗口或显示条件改变
- **THEN** 系统 MUST 拒绝等价复用，要求受影响范围的新独立观察；静态通过不得授权新运动。

#### Scenario: 相同媒体存在相反结论
- **WHEN** 同目标相同媒体已有未解决的独立 pass 与 fail
- **THEN** 系统 MUST 拒绝自动挑选 pass；保留冲突。只有关联 fail 按既有独立关闭规则由晚于失败的新代理实质争议复查关闭，或真实用户变更目标后完成登记及新独立复查关闭，才视为解决；关闭证据失效 MUST 重新阻断，单纯追加 pass 不算解决。

#### Scenario: 收据不能刷新观察时间
- **WHEN** 旧 pass 早于新 fail 或适用 retarget，之后才登记复用收据
- **THEN** 系统 MUST 拒绝用该旧 pass 关闭问题。

### Requirement: 原始视觉要求在转化与对照中保持
助手 MUST 在既有设计记录和同轮对照条件中保留相关原始用户要求、实际选中媒体与用户限定范围，区分原要求与作者转化。用户选择整体风格且未限定单场时，助手 MUST 将其用于当前作品受影响画面，不得自行限定到结果页或以配色字体相同代替整体视觉机制。对照 MUST 先检查条件与原要求是否一致，再判断实际媒体兑现；作者自写例外不构成用户授权。盲看 MUST 继续隔离目标及选案信息，不新增例行审批或评审轮次。

#### Scenario: 作者将整体风格缩成单场
- **WHEN** 原要求选用某整体视觉方向，作者条件却允许其他受影响场景使用另一套核心视觉载体
- **THEN** 对照 MUST 指出目标转化偏离，不得按放宽条件确认风格目标通过；缺失原要求依据时 MUST 保持对应目标未验证。

#### Scenario: 构图随内容变化
- **WHEN** 不同内容采用不同构图，但保留选定的整体形体、材质、空间、光影及适用运动机制
- **THEN** 评审 MUST 按实际效果判断，不要求复制同一布局；展开前 MUST 通过能检验迁移的新内容代表性试制，而非仅以终态页授权未经验证的正文。

#### Scenario: 用户指出旧通过未满足要求
- **WHEN** 工具已记录通过但用户指出真实目标偏离
- **THEN** 助手 MUST 保留旧报告与原目标、记录反馈和未完成状态，修正设计与后续评审依据，不得继续仅以旧通过或工具完成状态宣告完成。

### Requirement: 抽象表达按实际信息职责评审
助手与独立评审 MUST 按完整画面的实际信息职责判断抽象意象和精确事实，允许形体、空间、运动与清晰辅助文字/读数协作。抽象主体 MUST NOT 被默认要求逐层字形可读或逐物具象可辨。必要职责分配 MUST 在既有设计与对照条件中说明并核对用户原要求；作者声明 MUST NOT 替代实际表达或事后解除原有精确信息职责。不新增运行时角色字段或审核轮次；影响判断的对象职责归场景设计，中性必要条件归既有对照。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 抽象意象配清晰读数
- **WHEN** 主体以抽象形体或叠层表达关系与风格，独立读数使关键金额、单位、组别和结论清楚，整体形象成立
- **THEN** 评审 MUST NOT 仅因抽象局部难逐字辨认而 fail；可见的次要读取代价 MUST 作为打磨限制，不以具象信息图的逐字标准强制返工。

#### Scenario: 抽象声明不能掩盖关键缺陷
- **WHEN** 唯一必要读数被遮挡、表达造成关键误读或因果不明、核心形象失效或偏离用户选定整体风格
- **THEN** 评审 MUST 根据具体窗口、显示条件及实际影响阻断，不因抽象标签或辅助文字存在而自动通过。

#### Scenario: 用户放宽已失败的抽象目标
- **WHEN** 用户明确允许适当放宽抽象载体的局部辨认要求
- **THEN** 助手 MUST 沿既有 retarget 登记真实指令及受影响失败，保留旧结论，并在登记后重新独立盲看及同轮对照；不得复用旧通过自动关闭，不免除事实、QA及全片验收。

### Requirement: 评审机械操作自动派生
工具 MUST 从封存隔离包生成绑定版本、用途、窗口、路径、摘要和未完成观察项的报告模板与任务说明。模板 MUST 默认不可采用，不预填 pass 或伪造调用。工具 MUST 从有效当前盲报告自动派生同轮对照，保持原媒体、来源、参考、条件与范围，拒绝目标、帧率、显示尺寸或采样步长漂移；相同媒体 MUST 独立复制既有净化证据并逐文件核验摘要，不重复编码或取帧，也不共享可写文件。评审者、实际读取文件、时间与观察 MUST 来自真实执行。

#### Scenario: 自动对照
- **WHEN** 操作者提供当前盲报告 ID 请求同轮对照
- **THEN** 工具 MUST 自动复用封存请求创建净化目标包，不要求手工复制 JSON。

#### Scenario: 空白模板
- **WHEN** 生成结构化报告模板
- **THEN** 模板 MUST 不包含通过结论，未完成真实调用与观察前不能导入为独立通过。

### Requirement: 评审包内复用原生尺寸 PNG

新建关键帧和过程评审包 MUST 对每个采样帧保留包内净化 PNG，并在请求的展示宽度与原图宽度相同时以同一文件作为原生尺寸展示证据。清单 MUST 维持请求顺序、帧顺序和采样窗口，其他展示宽度继续按原图比例派生。实际证据文件 MUST 在文件清单中登记摘要并由收据绑定。既有评审包的文件、清单和收据 MUST 保持原样。

#### Scenario: 新建关键帧或过程评审包

- **WHEN** 请求尺寸包含某帧的原生宽度和一个不同宽度
- **THEN** 原生尺寸的展示路径指向该帧的净化 PNG，其他尺寸有单独的展示路径，原生 PNG 在文件清单中只登记一次

#### Scenario: 从已封存的旧盲包生成同轮对照

- **WHEN** 新建同轮对照包，且已通过完整性校验的盲包中存在与某帧净化原图摘要一致的展示副本
- **THEN** 新包的对应展示路径指向新包内独立复制的同帧原图，仍登记并核对其实际摘要，其他尺寸保持独立证据文件，原盲包保持原样

#### Scenario: 复用的净化 PNG 丢失或损坏

- **WHEN** 评审包中由原图和原生展示路径共同指向的 PNG 缺失或与封存摘要不符
- **THEN** 评审包证据校验失败

### Requirement: 正式窗口与合成证据
系统 MUST 支持登记实际时间轴上的必审样片窗口，并复用当前正式合成的局部预演或完整候选取证。报告 MUST 可核对窗口身份、实际帧窗和来源。早期原生样品可先验证机制，正式结论须验证实际合成和适用的字幕、转场与音轨。关键帧 MUST 审真实合成图像中的字号、断行、层级、位置、小屏和明暗背景可读性。关键样片 MUST 审实际字幕同步、停留、换句、切镜与运动中的遮挡和对比。无字幕时按实际机制评审。

#### Scenario: 正式样片覆盖不足
- **WHEN** 只通过一个必审窗口，其他窗口缺证，或证据窗口、目标、有关来源已经变动
- **THEN** 系统 MUST 将相应窗口记为缺失或过期。未受影响的有效窗口保持覆盖。

#### Scenario: 真实合成
- **WHEN** 正式窗口取自已合成预演或候选
- **THEN** 工具 MUST 校验来源摘要与时间映射，使用实际合成画面和适用音轨。关键帧评审只接收静态证据。
