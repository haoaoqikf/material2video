# media-bound-production-review Specification

## Purpose

以实际媒体和观察范围建立轻量、可追溯的独立视觉评审体系，支持全片设计前试制、有效证据复用和当前成片终审，避免声明式画面合同与顺序门禁给创意试验增加前置负担。

## Requirements

### Requirement: 独立媒体契约与显式周期
系统 MUST 提供 review start/pack/import/timeline，拒绝旧检查点合同和旧报告；周期、报告、包均版本化，旧历史保留不迁移。试制包 MUST 不依赖 DESIGN.md、prepared 或全片分镜；本地媒体、来源依赖和观察窗口须摘要绑定。全片播放器 MUST 使用有效准备材料且无视觉门前置。

#### Scenario: 局部试制
- **WHEN** 只有代表性关键帧或核心片段
- **THEN** 可以建立隔离试制包；修改相关依赖使其过期，无关场景不无故使其过期。

### Requirement: 当前候选与完整证据
终审 MUST 绑定当前有效完整候选和技术 QA。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列及显示条件；静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。

#### Scenario: 终审候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得授权新片；无关试制证据按实际依赖保留。

### Requirement: 问题与基线保护
系统 MUST 保存失败及复查历史，问题重开不得丢失原条件与证据。跨周期报告不得关闭旧问题。基线 MUST 保护活动引用，损坏或未知引用阻止媒体清理；只读状态不得修改文件。

#### Scenario: 独立问题关闭
- **WHEN** 当前对应范围的独立复查通过
- **THEN** 可关闭该问题；自审、错误范围或旧周期报告必须拒绝。
