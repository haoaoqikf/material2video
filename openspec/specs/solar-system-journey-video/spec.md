# solar-system-journey-video Specification

## Purpose

定义太阳系之旅示例重构后的可观察交付行为：在约两分钟的连续空间旅程中保留十三个站点，突出地球、土星和奥尔特云的不同观看体验，并使画面、声音、来源与当前独立评审证据可复现、可追溯。本规格只约束该部示例。

## Requirements

### Requirement: 两分钟连续旅程
成片 MUST 为1920×1080、60 fps、有旁白及配乐的MP4，总长115至125秒，以120秒为编排目标；MUST 连续经过太阳、水星、金星、地球、月球、火星、谷神星、木星、土星、天王星、海王星、冥王星、柯伊伯带、日球层顶与奥尔特云，不用隐藏跳切替代连续运镜。

#### Scenario: 核对整片与站点
- **WHEN** 检查当前成片的媒体信息、旁白字幕和全片有序帧
- **THEN** 时长与画幅帧率符合要求，十三个站点按向外旅程可辨，路径和朝向连续，普通段落不重复长时间等待

### Requirement: 三个重点段落
地球/月球段 MUST 呈现母星与卫星关系；土星段 MUST 以视角变化揭示固定环带与球体的关系并保留整体观察窗口；奥尔特云段 MUST 区分内侧行星区域、日球层边界与外侧推测性结构，最终太阳成为视觉落点。

#### Scenario: 核对重点完整窗口
- **WHEN** 查看三个段落的完整过程有序帧及主体尺度、速度和方向量测
- **THEN** 三段构图与观看任务有差别，过程提供新的关系信息，主体可认回，无环结构生长误读、卫星从属混淆或外层边界混同

### Requirement: 光影与信息主次
成片 MUST 保持自然天体色与深空背景，地球具有可辨的云层、海陆、昼夜和薄大气层次，土星具有可辨环带层次与遮挡；非当前独立行星和背景星点 MUST 不争夺主体。名称、核心结论和字幕 MUST 清楚，重复信息板和导航 MUST 精简；必要示意标记和素材署名遵守项目注释规则。

#### Scenario: 原生及手机尺寸对照
- **WHEN** 对照实际登记视觉参考与原生和手机显示尺寸的代表画面
- **THEN** 重点主体形体、材质、光影与空间层次成立，必要文字可读，辅助导航和声明不遮挡或争夺焦点

### Requirement: 声音与科学边界
旁白 MUST 精简重复报站并匹配当前可见对象，配乐和少量艺术音效 MUST 随新时间轴组织；MUST 明示艺术示意与奥尔特云推测性质，保留来源和许可，不宣称真实比例、实时位置或太空实录声音。

#### Scenario: 核对时间轴与来源
- **WHEN** 检查旁白字幕、声音起止和响度同步量测，以及来源许可台账
- **THEN** 无截断、错位和削波，重点事件有明确声画窗口，署名完整，事实口径与素材性质清楚；未试听的听感范围如实披露

### Requirement: 当前版本独立验收与可恢复交付
交付 MUST 包含可编辑材料、可恢复媒体配方、当前技术QA、代表性原生关键帧的世界级独立盲审及目标对照、各必审关键样片完整过程的独立对照、总代理使用抽帧和适用信号对当前候选进行的整片证据复核。独立评审原件 MUST 保留，旧版基线依统一清理规则移除。必改未关闭或证据失效时不得声明完成。源码与文本材料 MUST 纳入Git，生成媒体和字体二进制不入库。

#### Scenario: 交付审计
- **WHEN** 检查当前文件摘要、制作状态、评审包与调用、恢复配方和Git暂存
- **THEN** 当前媒体与材料及有效证据绑定，适用必改关闭，媒体和字体可恢复，Git只包含本轮源码及配套文本，旧版记录不被改写为新版通过
