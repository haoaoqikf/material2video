# material-selection-library Specification

## Purpose

为素材候选提供可对回原媒体的预览、选择、精确裁切和导入追溯，并支持显式本地素材库的增量复用与引用保护清理，使作品采用素材后可以脱离共享库独立离线运行，同时保持正式媒体登记、制作记录和既有审核契约不变。

## Requirements

### Requirement: 候选预览入口与源时间关系

系统 MUST 提供 `m2v author assets preview`，为图片、完整短视频或长视频候选区间生成可机读索引、带时间码接触表、按需短预览及静态 HTML 候选页。预览 MUST 显示来源、召回原因、局部时间及有依据的源时间关系，支持候选比较、来源跳转和选择清单导出，不要求常驻服务。预览 MUST 明确采样和画质限制，不将低清预览或单帧作为完整动作、精裁准确性或最终构图已经通过的证明。

#### Scenario: 查看长视频的多个候选窗口
- **WHEN** 同一需求召回多个长视频区间并请求预览
- **THEN** 输出可比较的接触表、短预览和静态候选页，各条能对回实际媒体及其已知时间关系

#### Scenario: 候选源映射未知
- **WHEN** 本地区间可用但无法证明精确源片区间
- **THEN** 预览显示局部时间和源映射未知状态，不把预览零点或请求起点伪装成源时间

### Requirement: 预览页面与媒体边界

候选页 MUST 仅引用本工作目录内经过登记的派生预览或允许跳转的公开来源，外部标题、描述、字幕和地址 MUST 安全转义。系统 MUST 拒绝通过工作材料引用任意宿主路径、路径穿越、符号链接或目录联接来暴露其他文件；预览 MUST 不包含凭据或敏感临时地址。生成预览 MUST 不修改源媒体、正式素材、分镜或准备记录。

#### Scenario: 恶意候选描述或预览路径
- **WHEN** 外部元数据包含脚本，或预览材料指向工作目录外的本地文件
- **THEN** 页面不执行脚本，越界媒体引用被拒绝，合法已有预览和源文件不被修改

### Requirement: 显式选择与非自动观察结论

系统 MUST 提供 `m2v author assets select`，读取带候选身份、媒体摘要、所选区间、用途和操作者决定的选择清单，支持选取图片、整条短视频和长视频片段。选择 MUST 校验绑定字节与合法区间，记录实际观察依据及未验证项，不自动将检索分数、转录、切镜或选择动作写成视觉通过、独立评审通过或事实身份已确认。助手可以基于实际媒体自主选段，MUST 不新增用户逐条确认、授权前置或额外审核门禁。

#### Scenario: 助手依据实际预览选段
- **WHEN** 助手查看候选后提交有效选择及其观察范围
- **THEN** 系统保存选择与依据并继续技术处理，不额外要求用户逐件批准，也不生成虚构的独立通过状态

#### Scenario: 选择引用的媒体被替换
- **WHEN** 候选绑定摘要与当前文件不一致
- **THEN** select 明确拒绝该选择，要求重新校验，不沿用旧观察或静默绑定新字节

### Requirement: 精裁与输出实测

视频精裁 MUST 按已校验本地媒体时间关系执行，支持非零起始时间戳、可变帧率和无音轨素材；需要帧精确的采用片段 MUST 经实际解码和重新编码，不能把非精确直接复制流声明为任意时间点精裁。输出 MUST 实测文件摘要、类型、尺寸、时长、首末帧及音画关系；实际起点和实际终点相对所选本地窗口的误差 MUST 分别不超过一个目标输出帧，视频时长误差 MUST 不超过一个目标输出帧；可变帧率输入 MUST 按真实展示时间戳与声明的输出帧率判定，不以相同输出时长代替位置正确。含音轨验证样本的音画偏移 MUST 不超过 50 毫秒。源映射未知时 MUST 仍如实记录本地裁切并将 `sourceRange` 保持为 null，不编造精确源时间。

#### Scenario: 非关键帧位置开始的选段
- **WHEN** 所选起点不在可直接复制的关键帧位置且要求精确采用窗口
- **THEN** 系统输出经解码精裁并实测的片段，不将包含额外前置画面的直接复制结果宣称为精确裁切

#### Scenario: 无音轨或可变帧率视频
- **WHEN** 选中无音轨或可变帧率媒体的有效区间
- **THEN** 系统按实际媒体时间关系生成非空输出，保留真实音轨状态，不按名义帧率猜源时间或补造音轨

### Requirement: 既有导入衔接与作品内复制

选中素材进入作品 MUST 先以独立文件复制到目标作品内受控暂存区，再生成并通过现有 `import` 清单及校验登记，不得让作品运行时直接读取共享库绝对路径、链接或未登记候选。正式 project v3、分镜 v9、媒体登记 schema、单文件与批次限制 MUST 不改变。导入 MUST 与目标作品既有写操作互斥，并复核来源、采用状态、摘要及实测信息；只有权利人明确禁止当前用途或现有契约规定的技术无效 MUST 按既有行为阻断，不新增授权前置。

#### Scenario: 从共享素材库导入选中片段
- **WHEN** 选中媒体原本位于作品外的显式素材库
- **THEN** 片段被复制到目标作品内并经现有导入登记，正式记录不包含运行时共享库依赖，也不要求扩展项目或媒体 schema

#### Scenario: 选中片段仍超过正式导入限制
- **WHEN** 源长视频允许获取但最终片段仍超过现有正式导入大小限制
- **THEN** 系统明确要求重新选段或编码，或报告限制失败，不悄悄放宽正式限制

### Requirement: 获取与导入凭据

系统 MUST 保存与选择、实际媒体、输出片段和目标登记项绑定的作品内获取凭据，至少包含公开来源、实际输入与输出摘要、所选本地区间、可证明的源区间、时间映射状态、工具身份和操作状态。凭据 MUST 为独立制作追溯材料，不向正式媒体 schema 插入新执行字段，也不在渲染时执行。导入完成后 MUST 复核正式文件和登记摘要再标记完成；若媒体已登记而凭据提交中断，恢复 MUST 能识别已完成效果并补全凭据，不误报完全未发生或重复覆盖。目标素材 ID 冲突 MUST 明确处理，不静默替换不同字节。

#### Scenario: 导入成功但凭据写入中断
- **WHEN** 正式媒体已登记而凭据未完成发布
- **THEN** 重试核对同一操作的正式登记和文件，补全一致凭据，不再次无条件替换素材或丢失来源关系

#### Scenario: 同一素材 ID 已绑定不同文件
- **WHEN** 新选择拟导入的目标 ID 已存在且内容摘要不同
- **THEN** 系统返回明确冲突并要求显式替换决定，不静默覆盖旧媒体与来源记录

### Requirement: 作品离线独立与既有完成条件

素材导入完成后，目标作品 MUST 不依赖共享库、素材工作数据库、在线来源或模型即可按既有契约准备、预览和渲染。工作材料和获取凭据 MUST 不作为新的渲染输入或完成门禁；`usableSegment` MUST 保持候选检查用途，不自动变为裁切执行指令。修改实际登记媒体 MUST 沿用既有 prepare、候选失效及审核规则，工具成功 MUST 不被当作成片完成。

#### Scenario: 移走共享库后运行作品
- **WHEN** 正式采用素材已复制登记，随后移动作品并使原共享素材库不可访问
- **THEN** 作品仍可使用自身登记媒体离线准备、预览和渲染，不尝试在线解析或读取原库

#### Scenario: 仅完成素材选择
- **WHEN** 获取、预览、select 和导入均成功但尚未完成现有成片 QA 与评审
- **THEN** 系统只报告素材操作结果，不宣称成片完成，不新增或绕过独立审核条件

### Requirement: 显式本地库与跨作品复用

系统 MUST 提供 `m2v author assets library`，支持显式本地目录或已有素材目录登记、检索范围选择、核验和复用；不得静默扫描个人文件或所有作品。相同实际文件 MUST 能按摘要复用对象和有效索引，但不同来源、用途、媒体版本和时间区间 MUST 保留独立关系。视觉近似只能提示重复，不得合并为相同事实身份；跨作品采用 MUST 重新保留本次用途和实际采用记录，不能把上次结论自动复制为本次已获授权或已核实。

#### Scenario: 相同字节来自不同公开来源
- **WHEN** 两条来源取得相同媒体字节
- **THEN** 系统可以复用本地对象和相同有效索引，同时保留两条来源关系，不丢失作者、时间或许可差异

#### Scenario: 跨作品复用候选
- **WHEN** 新作品选用库中已有媒体的不同窗口
- **THEN** 复用有效媒体与索引但建立本次选择、用途和导入凭据，不自动继承旧作品的事实或采用结论

### Requirement: 引用保护清理与恢复

library 清理 MUST 先输出待清理对象、占用和引用原因的计划，只能删除明确选中的可回收工作产物。已选媒体、正式作品素材、有效引用、原始来源证据及唯一来源文件 MUST 受保护；引用损坏或未知时 MUST 保留并报告，不猜测无用。中断操作和未引用派生产物 MUST 可核验恢复或清理，且不得删除其他操作的有效结果；作品历史版本保留仍沿用现有约定。

#### Scenario: 缓存达到上限但媒体被选择引用
- **WHEN** 清理候选包含仍被有效选择或追溯证据引用的媒体
- **THEN** 计划标记其受保护并跳过，不为满足缓存上限删除正式或唯一素材

#### Scenario: 引用无法确认
- **WHEN** 某工作对象引用记录损坏或处于未确认的中断状态
- **THEN** 系统保留该对象并报告待核验，不把无法解析等同于没有引用

### Requirement: 流式增量入库与单件失败隔离

本地目录扫描 MUST 逐项遍历，不先收集整棵目录树；每轮新的获取尝试 MUST 有可配置的有限数量。成功项 MUST 保存可验证的增量状态，重复执行 MUST 跳过未变化且库内仍有效的项并继续处理剩余文件；文件字节改变或库内对象失效 MUST 重新获取。单件损坏、不可读或解码失败 MUST 单独报告并继续其他文件；输出 MUST 区分新获取、复用、失败、预算停止与可继续状态。递归遍历 MUST 保持既有链接和显式目录边界。

#### Scenario: 超过一轮预算
- **WHEN** 明确目录内的媒体超过每轮预算且重复执行扫描
- **THEN** 下一轮继续处理尚未成功的媒体，不反复花获取预算处理同一批已成功项

#### Scenario: 一件损坏而其余有效
- **WHEN** 目录包含损坏媒体和有效媒体
- **THEN** 有效媒体仍能入库，失败项有独立原因，命令报告部分成功

#### Scenario: 内容变化而文件大小和时间未变
- **WHEN** 文件内容改变但大小与修改时间保持一致
- **THEN** 系统不复用旧字节身份，而是重新获取并保留旧媒体记录
