# building-construction-video Specification

## Purpose
提供独立的建筑建造示意视频类型，以同一栋建筑的稳定构件身份、可核验阶段顺序和连续镜头展示从基础到完工的变化，并通过离线确定性采集及独立制作复核，使观众看清构件连接与建造阶段，同时明确工程示意的表达边界。

## Requirements

### Requirement: 独立类型与统一入口

系统 MUST 登记 building-construction 类型，通过统一 init、validate、prepare、preview、render 和制作状态/评审入口操作；首版 MUST 支持 1920×1080、30 fps，拒绝不支持的材料版本或输出组合，保持其他类型行为不变。

#### Scenario: 初始化建筑作品
- **WHEN** 用户通过统一入口初始化 building-construction 作品
- **THEN** 系统在类型所属内容目录创建建筑与建造时间轴模板，可独立准备和渲染而无需改用 general

#### Scenario: 不支持的配置
- **WHEN** 作品声明未知建筑材料版本或不支持的画幅帧率
- **THEN** 系统在准备前拒绝并定位错误

### Requirement: 稳定构件与完整建筑材料

系统 MUST 根据首版两层框架住宅材料生成场地、基础、主体、楼梯、墙体开口、屋顶、门窗、饰面与简化庭院；构件 MUST 有唯一稳定 ID、类别、楼层和最终几何位置，重复准备相同材料 MUST 保持身份与几何一致。系统 MUST 拒绝无效尺寸、越界开口、重复 ID 和不受支持的参数组合，不伪称任意建筑模型生成。

#### Scenario: 重复生成
- **WHEN** 对同一建筑材料重复准备
- **THEN** 相同构件保持相同 ID 与最终几何，墙体洞口不会被实体墙封闭

#### Scenario: 非法几何参数
- **WHEN** 尺寸非正、开口超出所属墙体或部件 ID 重复
- **THEN** 校验失败并报告相关构件，不继续生成候选

### Requirement: 建造阶段与可见性分离

系统 MUST 以构件引用、建成事件、无环依赖和动画区间定义建造顺序，支持落位、铺展、分段显现及饰面完成。每个必建构件 MUST 有唯一建成事件；依赖未完成前不得开始后续建造，同一属性不得存在冲突轨道。剖开场地或隐藏墙体 MUST 只影响取景，不回退构件建成状态，最终展示 MUST 恢复应见构件。

#### Scenario: 依赖与轨道错误
- **WHEN** 存在未知构件引用、循环依赖、重复建成事件、先于依赖完成的动作或冲突轨道
- **THEN** 校验失败并定位问题，不静默调整施工顺序

#### Scenario: 观察内部结构
- **WHEN** 镜头临时隐藏已建墙体或剖开场地
- **THEN** 结构保持原位置和完成状态，恢复视图后无需重新建造且完工外观完整

### Requirement: 确定性镜头与离线成片

系统 MUST 直接按帧求取构件、材质、镜头和环境状态，不依赖用户交互、上一帧或挂钟；镜头区间 MUST 完整覆盖全片且不重叠。准备与渲染 MUST 仅使用已登记本地资产，缺失资源、摘要不符或未就绪时明确失败。外部资源 MUST 保存来源、作者、许可依据和摘要；纯程序材质允许空清单。作品、媒体和产物 MUST 不进入版本控制。

#### Scenario: 同帧重复与乱序采集
- **WHEN** 对同一准备记录重复、正序和倒序取样探针帧
- **THEN** 对应同帧图像 PSNR 至少 60 dB，构件显现和镜头不会因取样历史漂移

#### Scenario: 离线资源校验
- **WHEN** 已登记素材缺失或摘要变化，或镜头覆盖有空隙/重叠
- **THEN** 系统明确拒绝准备，不依赖在线补取或静默降级

### Requirement: 准备绑定与技术验收

系统 MUST 将材料、生成实现、资产和声音绑定准备指纹，变化后拒绝过期准备；输出 MUST 验证帧数、尺寸、帧率、时长和音轨，并保留溯源及性能记录。无声音声明时 MUST 输出无音轨；预览 MUST 不替代完整候选验收。

#### Scenario: 修改建筑后导出
- **WHEN** 准备后修改构件、时间轴、外部资源或生成实现
- **THEN** 系统拒绝过期准备并要求重新 prepare

#### Scenario: 首例无声输出
- **WHEN** 首例声明 40 秒、30 fps 且无声音
- **THEN** 输出 1200 帧、1920×1080、30 fps 的无音轨候选并验收技术参数

### Requirement: 住宅首例与表达验收

首例 MUST 展示同一栋两层钢筋混凝土框架住宅，从空地、基础、一层和二层主体到墙体屋顶、门窗饰面与庭院完工，成片 40 秒。施工表达 MUST 有可追溯依据并说明省略范围，必要画面边界标记遵循现有小字规范，不把组装动画当作完整真实工序。制作完成 MUST 具备当前候选技术证据、按现有审核策略派生的适用独立评审及问题复查，不能仅因成功导出宣布通过。

#### Scenario: 首例从结构扩展到全片
- **WHEN** 基础、一层框架和墙体代表片段进入扩展判断
- **THEN** 复核阶段可理解性、支承连接、洞口、遮挡、完整动作与观察窗口，并按现有风险策略完成适用核心评审后才扩展

#### Scenario: 当前候选完成判断
- **WHEN** 住宅首例申请制作完成
- **THEN** 核查全过程身份连贯、错误穿插/悬浮、主体取景、阶段衔接和完工外观，缺少适用独立证据或必改项未关闭时不得标记制作完成
