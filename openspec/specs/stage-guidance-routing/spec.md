# stage-guidance-routing Specification

## Purpose

为五类视频提供研究与创意试制、正式设计、制作与验收三个渐进阅读入口，使助手按当前问题读取唯一权威指导，减少重复规则、阶段交接和无信息增量的记录。

## Requirements

### Requirement: 三阶段唯一阅读入口
阅读路由 MUST 使用 research/design/production 三个唯一主指南；创作总纲保持必读，创作或实质性视听修订的深入风格研究 MUST 可从研究指南进入具体参考拆解，隔离评审按适用活动展开。离线校验 MUST 拒绝缺少或误指研究、参考拆解路由的导航。重复阶段指南及跳转页 MUST 删除，活动链接和 JSON 示例 MUST 有效；保持渐进阅读及现有正文预算。日常主线 MUST 说明动作、输入、结果与回退；审核政策、隔离执行、工具格式各有唯一权威位置，技术协议按需读取，不跨文档复制整套规则。

#### Scenario: 读取当前阶段
- **WHEN** 开始创作、实质性视听修订或已有有效基线的局部修改
- **THEN** 入口 MUST 指向对应阶段与当前问题的研究深度，不要求递归阅读所有参考或重开无关风格选案。

#### Scenario: 研究路由丢失
- **WHEN** 导航缺少研究或具体参考拆解入口，或者将其误指其他指南
- **THEN** 文档离线检查 MUST 明确失败，而不是只凭目标文件存在就通过。

### Requirement: 场景设计单一操作权威
三阶段与修订入口 MUST 指向同一场景设计指南，统一维护分层职责、总设计和场景模板、十二方面、节拍编排、迭代与对应检查。阅读路由 MUST 保留场景设计入口并拒绝缺少或误指；不得在各阶段复制完整模板、另建问题清单或增加阶段审批。

#### Scenario: 开发或修订一个场景
- **WHEN** 助手准备设计、开发或实质修订场景
- **THEN** 助手 MUST 可从当前阶段到达同一场景设计规则，沿有效研究、总设计和当前场景进入局部循环，不重开无关探索。

### Requirement: 创作指导归并与技术边界
讲解机制 MUST 由场景指南维护，视觉诊断归视觉复核，技术排错和经实现核实的字体/参考令牌边界归运行契约，字幕规则归字幕契约；外部项目通用借鉴规则归参考分析，固定来源和许可归相关示例。归并完成后 MUST 删除重复旧页并修正活动引用，不留跳转空壳，不删除有效运行能力、来源或测试覆盖。阶段入口 MUST 维持现有阅读预算，按实际问题读取技术专题。

#### Scenario: 旧页归并
- **WHEN** 删除已归并的旧参考页
- **THEN** 有效内容 MUST 在对应权威位置可查，导航、示例和源码注释 MUST 指向有效归宿；历史归档不改写。
