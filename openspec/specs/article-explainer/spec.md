# article-explainer Specification

## Purpose
为道理说明与观点讲解提供旁白驱动的全画布代码讲解制作契约，定义分镜结构、真实语音时间、字幕几何与可读性量测，使通用作品在十分钟内完整表达并可重复渲染。

当前 general 的材料、创作与评审以本规格为准。历史动画的导演简报、原语树、状态轨道、单世界连续性和审美量表仅描述仍被内部工具使用的旧动画模块，不约束 v8 代码场景。

## Requirements

### Requirement: 讲解评审及版本绑定
系统 MUST 保留 article 输入语义审查和当前指纹完整候选验收，不依赖预演，topic 输入不要求源文审查；人工画面评审 MUST 为可选工具，MUST NOT 阻断导出。源文、分镜、画幅、代码、资源、媒体记录、音轨或渲染实现变化 MUST 使依赖的准备与候选失效；可选评审不得沿用过期依据。正式输出 MUST 技术验收后替换并保留溯源，旧嵌入材料 MUST 拒绝。

#### Scenario: 输入未评审
- **WHEN** article 输入没有当前有效审查
- **THEN** 准备拒绝并提示审查

#### Scenario: 材料变化
- **WHEN** 已准备作品从横屏改为竖屏
- **THEN** 旧准备和候选失效，必须重新设计、准备并生成当前候选

#### Scenario: 自动预演门禁
- **WHEN** 当前准备有效且没有预演
- **THEN** 旧完整预演门禁不再生效，允许生成候选，验收后交付同一文件，不重复编码

#### Scenario: 完整嵌入
- **WHEN** 尝试引用完整作品作为场景
- **THEN** 拒绝旧嵌入契约，要求 v8 本地代码重新制作

### Requirement: 默认旁白画面字幕
general MUST 无需额外配置即可从旁白原文和真实配音帧边界生成字幕，并烧录至预演和成片；外置字幕不代替画面交付。字幕 MUST 开始帧显示、结束帧隐藏，无讲话的停顿与阅读尾段不显示。两种画幅 MUST 使用各自的字幕几何和换行宽度，字幕样式 MUST 独立于作品背景保持可读，SDK 与合成层 MUST 共用安全区。作品重要文字与主体 MUST 避让安全区，背景可延伸至该区。系统 MUST NOT 宣称能够自动识别录制片段内全部正文或主体遮挡。

#### Scenario: 未配置字幕选项
- **WHEN** 有旁白作品未声明字幕配置并完成制作
- **THEN** 预演和成片均包含自动烧录的字幕

#### Scenario: 字幕边界和静音区间
- **WHEN** 播放至开始帧、结束帧或无讲话区间
- **THEN** 仅在对应讲话边界内显示字幕

#### Scenario: 深浅主题与嵌入
- **WHEN** 代码自行绘制深浅背景，或输入旧主题/完整嵌入材料
- **THEN** 有效代码场景字幕保持可读；旧主题和嵌入被拒绝

#### Scenario: 横竖屏字幕
- **WHEN** 分别准备有旁白的横屏和竖屏作品
- **THEN** 两者均烧录同步字幕，容器和换行在对应画布内，安全区与 SDK 一致

### Requirement: 画面字幕可见性验收
系统 MUST 将文章字幕绘制在场景背景和正文之上；正式生成前的浏览器字幕量测 MUST 检查讲话区间字幕的实际可见性，字幕文字存在但被场景覆盖时 MUST 拒绝。

#### Scenario: 场景覆盖字幕
- **WHEN** 讲话帧中的字幕被场景背景覆盖
- **THEN** 字幕量测失败，明确报告字幕遮挡而非接受仅有文字节点的画面

### Requirement: v8 横竖屏代码分镜
系统 MUST 只接受 version/schemaVersion 均为 8 的 general 分镜，60 fps，支持 1920×1080 横屏与 1080×1920 竖屏；width/height 均省略 MUST 默认横屏，半指定、非整数及其他尺寸 MUST 拒绝。全片 MUST 使用同一画幅，不自动裁切或重新排版。每幕 MUST 声明唯一 ID、template: code、本地 content.entry、可选 title/JSON 对象 props 及旁白数组；title 只作元数据。场景及旁白 ID MUST 全片唯一。原文输入 MUST 绑定非空源文并审查，主题输入 MUST 声明非空主题与逐幕关键词且不要求原文审查。代码幕 MUST 允许无旁白，未知字段及旧准备 MUST 拒绝。

每幕 MAY 声明 `leadInFrames`、`tailFrames`（0–1800 帧）与 `readingHoldFrames`（0–360 帧）；旁白段 MAY 声明 `claims` 字符串数组与 `holdFrames`（0–1800 帧，本段结束后、下一段前的静默，最后一段不得非零）；`content.props` MAY 声明 `shots` 与 `look` 对象。未声明时 MUST 保持当前时间轴、阅读停留与画面行为。字段类型、范围或时间窗非法时 MUST 拒绝并定位到具体幕、镜头或旁白段。镜头时间窗 MUST 落在所属幕内且不得重叠；`tier` 只能是 hero、major 或 minor；cinematic 作品的 hero 镜头 MUST 不少于 3 个。

真正的一镜到底 MUST 写成单幕内多个首尾相接的镜头：所有镜头窗口 MUST 从 0 起严格相接并覆盖整幕，相邻镜头路径的末点与首点 MUST 完全相同，MUST NOT 声明 `cut: true`，全部镜头 MUST 使用 linear 缓动。`post` 参数 SHOULD 在全部镜头间保持一致，因为后期不在镜头边界混合。

#### Scenario: 默认与显式尺寸
- **WHEN** 尺寸均省略、显式横屏或显式竖屏
- **THEN** 分别按 1920×1080、1920×1080、1080×1920 规范化并贯穿制作

#### Scenario: 非法尺寸
- **WHEN** 只提供一边尺寸，或尺寸为布尔值、字符串、方屏或其他组合
- **THEN** 校验拒绝并定位字段

#### Scenario: 旧分镜
- **WHEN** 输入 v7 或更早分镜
- **THEN** 要求重新编排 v8，不自动迁移

#### Scenario: 主题输入
- **WHEN** topic 作品的代码幕旁白为空且声明有效关键词与 durationFrames
- **THEN** 按声明长度准备镜头，不要求原文审查；缺少关键词则拒绝

#### Scenario: 非法绑定
- **WHEN** 旧展示元素尝试用 segmentId 绑定旁白
- **THEN** 按未知字段拒绝；v8 代码改用实际 segmentWindows

#### Scenario: 代码模板
- **WHEN** 输入有效 code 场景
- **THEN** 本地录制片段参与统一音轨、字幕和转场合成

#### Scenario: 静音前后段
- **WHEN** 某幕声明有效的 leadInFrames 或 tailFrames
- **THEN** 旁白前后出现对应静音，时间轴与字幕整体后移，不截断或重叠旁白；未声明时行为与当前一致

#### Scenario: 非法电影字段
- **WHEN** shots 的时间窗越界或重叠、tier 非法，或 look/claims 字段类型错误
- **THEN** 校验拒绝并指出具体幕、镜头或旁白段

### Requirement: 实际语音时间与十分钟上限
系统 MUST 复用项目 TTS 配置与缓存，根据每段实际音频计算展示和字幕时间；每幕结束保留默认 24 帧阅读时间，可由 `readingHoldFrames` 覆盖。`leadInFrames` 与 `tailFrames` MUST 在旁白前后增加静音，不截断、不重叠旁白。同一幕内的 `holdFrames` MUST 在相邻旁白之间增加静音，计入幕最小长度，且 MUST NOT 出现在最后一段。默认硬切，可选 fade/crossfade 并按声明帧数重叠，旁白不得重叠。默认目标 60 秒，全片 MUST 不超过 36000 帧；无旁白幕 MUST 支持声明固定帧数或均分目标剩余时长，超限要求调整文本或语速，不截断声音。

#### Scenario: 时长边界
- **WHEN** 准备结果为 36000 帧或 36001 帧
- **THEN** 前者通过，后者拒绝

#### Scenario: 无旁白镜头分配
- **WHEN** 某幕声明 `durationFrames`，另一幕没有旁白也没有声明帧数
- **THEN** 前者按声明帧数、后者按目标剩余时长分配，两者都不截断口播

#### Scenario: 淡化
- **WHEN** 两幕使用淡化衔接
- **THEN** 画面淡化期间两幕旁白不重叠，前幕保持完整阅读尾段

#### Scenario: 自定义阅读停留
- **WHEN** 某幕声明 `readingHoldFrames` 为 90
- **THEN** 该幕旁白结束后保留 90 帧阅读时间，其余幕仍取默认 24 帧或各自声明值

#### Scenario: 片头片尾留白
- **WHEN** 首幕声明 `leadInFrames` 且末幕声明 `tailFrames`
- **THEN** 成片在首句旁白前和末句旁白后保留对应静音，总帧数包含这两段留白

### Requirement: 换站必须有空间过渡
太阳系一镜到底作品的每个站点镜头 MUST 从远处抵达特写，再在旁白结束后拉远；旁白开始时相机 MUST 已抵达特写。站点之间的过场 MUST 升到黄道面上方，从上一站远出点穿过两星之间的空间再下降到下一站远入点，MUST NOT 只靠短位移加朝向混合完成换站。站点镜头首末点到目标天体的距离与镜头内最近距离之比 MUST 不小于 1.35；独立过场的最大高度 MUST 高于 1.5 个世界单位且超过自身弧长的 10%。原始站点与过场路径 MUST 首尾相接；实际相机 MUST 使用跨边界的连续位置求值和覆盖过场的视线承接，MUST 检查镜头内部的速度峰值、加减速、转向及主体屏幕尺度，MUST NOT 仅用端点或边界速度比证明自然运动。依赖特定视角的 hero MUST 保留其验证过的轨道形状，不为了统一公式牺牲构图。

#### Scenario: 太阳到水星
- **WHEN** 太阳站结束进入水星站
- **THEN** 相机先拉远太阳并升到水星轨道上方，水星从远处持续变大；旁白开始时已在特写，随后再拉远离开

#### Scenario: 地球到月球
- **WHEN** 地球 hero 结束进入月球站
- **THEN** 相机从地球上方经过近垂直的空间弧接近月球远入点，再下降到月球特写；两个天体都不被穿模

#### Scenario: 土星 hero
- **WHEN** 播放土星 hero
- **THEN** 相机按跨环平面的连续轨道呈现光环，进出方向按当前旅程设计，环在旁白期间可辨；轨道与构图须由当前版本风险材料复核，不能直接沿用旧版结论

#### Scenario: 只做朝向混合的换站
- **WHEN** 站点镜头首末点仍贴着天体、过场只做短位移与朝向混合
- **THEN** 相机测试按接近/拉远比与过场抬升判定失败，并要求重做路径

#### Scenario: 镜头内部急冲与短促转向
- **WHEN** 原始路径相接但中段位移集中或短促转向破坏连续旅程
- **THEN** 实际相机调整速度分配与覆盖过场的视线承接，并用完整运动过程证据复查，技术检查不自动关闭该问题

### Requirement: 固定示例的内容驱动演示
仓库 MUST 仅分发 buffer-smoothing、darts-trial-and-error、solar-system-journey 三个固定示例；前后两者使用 1920×1080，试错使用 1080×1920，均为 v8、60 fps。缓冲与试错实际时长 MUST 为 120～180 秒，太阳系之旅 MUST 在 120～600 秒内按动态粗预演确定预算，均含中文旁白和烧录字幕。核心演示 MUST 按实际旁白时间窗推进，合计覆盖 Motion、ECharts、GSAP、Three.js、React Three Fiber 与 Drei。示例 MUST 提供可编辑材料、设计说明、素材来源和旁白与画面的对应关系，生成媒体 MUST NOT 入库。

太阳系之旅 MUST 使用 cinematic 档位：单幕、按动态粗预演核定时长、15 段旁白、3 个 hero 镜头（地球、土星、奥尔特云）、覆盖整幕且首尾相接的镜头；开场 MUST 从太阳系上方连续俯冲到太阳，全片 MUST 无切换、无叠化、无硬切。MUST 提供 4K look-dev 静帧、20–30 秒有声样片、hero 实看记录、配乐与音效，以及普通 H.264 MP4 交付。缓冲与试错 MUST 保持 standard 档位，作为现有快速链路的回归。

#### Scenario: 三片完整制作
- **WHEN** 使用三个固定示例通过统一入口完成准备、完整候选与导出
- **THEN** 成片具有对应画幅、60 fps、实际配音和烧录字幕，保存到各自 videos/examples/<slug>/outputs，时长满足各自范围

#### Scenario: 覆盖检查
- **WHEN** 检查固定示例分镜与源码
- **THEN** 只有三个指定示例，合计覆盖批准组件，核心代码场景包含按时间窗推进的旁白，并明确标注示意内容

#### Scenario: 太阳系向外旅行
- **WHEN** 播放太阳系之旅
- **THEN** 成片按已验证的镜头预算确定时长，镜头从太阳系上方连续俯冲到太阳，再沿向外螺旋经过 15 个站点；全片单幕、镜头窗口连续覆盖，无切换/叠化/硬切，相邻镜头位置、方向与速度连续；地球、土星与奥尔特云为 hero；全片在同一个完整三维太阳系模型中保留太阳、行星、卫星和轨道；标注大小距离非同比例，并区分日球层顶与推测性奥尔特云

#### Scenario: 写实画面验收
- **WHEN** 完成太阳系示例的交付验证
- **THEN** 提供 3 个 hero 的 4K 静帧与 20–30 秒有声样片，实际观看并记录时间码、问题与复查；提供配乐/音效、QA 报告与普通 MP4 交付；不将艺术示意表述为实拍或精确历算

#### Scenario: 标准档回归
- **WHEN** 缓冲或试错完成准备、完整候选与导出
- **THEN** 不因 cinematic 字段或后期依赖改变时间轴、编码参数或现有画面行为

### Requirement: 字幕阅读速度报告
准备阶段 MUST 逐条量算字幕的阅读速度并写入作品 `outputs/` 下的独立报告，报告 MUST 标注它对应的准备指纹。字数 MUST 采用项目既定的字数口径（排除标点与空白），MUST NOT 另立算法。报告 MUST 记录取值出处与所用上限。

该报告 MUST NOT 参与准备产物指纹与完整候选验收，MUST NOT 阻断准备、完整候选或正式导出；超过上限时 MUST 在准备命令的输出中给出可定位到具体字幕的提示。

#### Scenario: 存在超限字幕
- **WHEN** 某条字幕的阅读速度超过报告所用上限
- **THEN** 准备照常完成并写出报告，超限条目被单独列出，命令输出给出提示

#### Scenario: 全部在限内
- **WHEN** 全部字幕的阅读速度不超过上限
- **THEN** 报告状态为通过，命令输出不产生超限提示

#### Scenario: 报告不影响验收
- **WHEN** 报告缺失、损坏或被删除后重新准备
- **THEN** 准备产物指纹与既有预演的有效性不受影响，正式导出仍按既有门禁判定
