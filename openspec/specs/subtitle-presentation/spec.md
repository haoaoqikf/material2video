# subtitle-presentation Specification

## Purpose
使中英双行字幕、字体与样式、自适应柔光、翻译配对、片尾来源与双行量测在同一渲染契约中可验证、可追溯，并允许旧作品继续使用原有底板路径。

## Requirements

### Requirement: 中文主行与英文次行字幕

字幕 MUST 支持一条中文主行与其下方的英文次行，二者同属一个字幕块，保持开始包含、结束不包含的时间区间。英文 MUST 来自分镜旁白的显式翻译，不得在渲染时机器翻译或按字数估算。存在翻译时，prepare MUST 按与中文相同的标点规则把翻译拆成与中文 cue 相同数量的片段；缺少翻译时该段不显示英文；翻译存在但条数不符时 MUST 失败并指出段 ID。阅读速度仍按中文计算。

#### Scenario: 双语配对成功
- **WHEN** 一段旁白有中文和带匹配标点的英文翻译
- **THEN** prepare 生成相同数量的中文 cue 与英文次行，并写入准备记录

#### Scenario: 翻译条数不符
- **WHEN** 英文翻译的标点切分数量与中文 cue 数量不同
- **THEN** prepare 在写时间轴前失败，指出段 ID，不估算或截断英文

### Requirement: 自适应柔光替代不透明底板

字幕 MUST NOT 使用不透明矩形底板作为默认样式。启用自适应柔光时，prepare MUST 按每条字幕的中点时间从该幕画面采样字幕区域的平均颜色与亮度，生成柔光颜色、透明度和背景参考色，并写入该 cue；渲染 MUST 只绘制无硬边的径向柔光。柔光透明度 MUST 随背景亮度增加，暗画面接近不可见；文字颜色 MUST 与柔光合成后的背景保持可读对比。采样值 MUST 参与准备指纹，同一素材与时间点 MUST 得到相同结果。

#### Scenario: 暗画面
- **WHEN** 字幕所在区域平均亮度较低
- **THEN** 柔光透明度保持低值，字幕背后不出现可见矩形

#### Scenario: 亮画面
- **WHEN** 字幕所在区域明显变亮
- **THEN** 柔光适度加深或文字切换深色，合成后的对比度仍满足量测门槛

### Requirement: 字幕字体与样式单一来源

字幕与标题的中文字体、主次字号、行高、颜色、柔光参数 MUST 在作品 `frames.json` 中声明，prepare MUST 原样写入准备记录，渲染 MUST 使用该记录，不得在组件内另写一套默认值。使用的外部字体 MUST 在作品 `fonts/registry.json` 登记来源、版本、摘要与许可，并由作品入口恢复与校验；字体缺失或摘要不符 MUST 失败，不得静默回退系统字体。

#### Scenario: 字体缺失
- **WHEN** 作品声明了字幕字体但字体文件未恢复
- **THEN** 构建或准备失败并给出作品内恢复命令

#### Scenario: 样式来源
- **WHEN** 检查准备记录与渲染 DOM 的字幕字号/字体
- **THEN** 二者与作品 `frames.json` 的声明一致，组件没有隐藏默认值

### Requirement: 片尾只保留画面来源

作品片尾 MUST 只显示画面素材来源平台（如“画面素材来自 Pixabay”），MUST NOT 显示作者、许可说明、作品说明或其他制作信息。完整作者、链接与许可 MUST 保留在素材台账、来源表与发布说明中。来源行 MUST 使用小字、低透明度与必要的底部渐变或阴影，保证在亮画面上可读且不争夺主体焦点。

#### Scenario: 片尾出现
- **WHEN** 最后一幕显示来源行
- **THEN** 画面只出现平台来源，不出现作者或许可解释，完整信息仍可在作品材料中查到

### Requirement: 双行字幕与柔光的量测

布局量测 MUST 把中文主行与英文次行作为同一个字幕块检查安全区、换行与溢出；英文不得超出安全区。技术 QA MUST 在自适应模式下按每条 cue 的柔光透明度与采样背景计算文字与合成背景的对比度，并报告最差 cue 的比值；不得用配置里的单一底色代替实际采样结果。

#### Scenario: 英文溢出
- **WHEN** 某条英文在 393 宽度下换行后超出字幕安全区
- **THEN** 布局量测失败并指出帧与文本，要求精简翻译

#### Scenario: 柔光对比度
- **WHEN** 自适应柔光启用
- **THEN** QA 报告逐 cue 采样合成后的最小对比度，低于门槛时判定失败
