# native-design-samples Specification

## Purpose

让研究与设计试制能够在没有完整分镜和配音时，使用正式网页场景能力生成可复现静帧与过程视频，并且只有同源、当前、独立审核通过的样品可以交付，防止概念图或失效证据替代实际实现。

## Requirements

### Requirement: 最小原生样品采集

采集与网页播放 MUST 调用作品自身的构建、宿主、受控时钟和资源解析；作品本地入口 MUST 可不安装主项目直接执行。主项目继续管理独立评审和已评媒体交付，MUST NOT 复制第二条采集实现。

原生样品 MUST 使用 v2，拒绝旧格式，不提供兼容与迁移。系统 MUST 提供`sample capture`，从作品内场景入口、有限JSON参数、时长、静态／动态用途及取帧位置采集网页和静帧，动态用途另采集同源视频，不要求完整分镜、配音或全片准备。场景 MUST 使用正式构建、资源就绪、受控时钟、画幅帧率及适用视频编码能力，非法入口、参数或运行失败 MUST 明确失败且不发布有效样品。

#### Scenario: 没有完整分镜时试制
- **WHEN** 作品只有project和一个有效代码场景
- **THEN** 系统 MUST 生成实际网页预览与指定帧；纯静态用途 MUST NOT 调用视频编码，动态用途 MUST 生成覆盖该局部时长的视频，并记录源码、资源、配置与产物绑定。

#### Scenario: 采集失败
- **WHEN** 入口越界、资源未就绪、运行错误或编码不完整
- **THEN** 系统 MUST 拒绝发布有效采集，不把临时或缺失产物当作可审核样品。

### Requirement: 样品可复现与可播放

采集与网页播放 MUST 调用作品自身的构建、宿主、受控时钟和资源解析；作品本地入口 MUST 可不安装主项目直接执行。主项目继续管理独立评审和已评媒体交付，MUST NOT 复制第二条采集实现。

系统 MUST 提供`sample serve`按已记录的网页bundle、资源与录制时钟播放样品，控制界面不进入采集画面。样品的来源与产物摘要 MUST 能检查，任一绑定输入或产物改变后 MUST 失效；不以网页包含图片或视频播放器代替核心实现验证。

#### Scenario: 来源变化
- **WHEN** 场景源码、依赖登记、素材、字体、配置或已记录产物改变
- **THEN** 系统 MUST 拒绝把旧样品作为当前有效结果使用。

### Requirement: 评审通过后交付同一样品
系统 MUST 提供`sample deliver`，仅交付当前有效采集、同源关键帧已获得独立盲看与实际目标对照 pass、动态用途已经总代理依据有序帧、完整解码及适用信号核对完整过程、且无当前适用必改项的样品。有效的完整观察等价收据可把原同轮独立双通过绑定到当前采集，但 MUST 重新验证当前技术来源，不冒充重新评审或消除未关闭失败。交付 MUST 记录具体选案依据和证据ID，复用已有媒体，不重复编码。未通过、证据不足、缺失、过期或非独立报告 MUST 拒绝交付。

#### Scenario: 概念图片不能代替样品
- **WHEN** 只有AI图片、任意外部图片或其通用媒体评审pass而没有有效原生采集
- **THEN** 系统 MUST 拒绝样品交付，不能凭作者填写来源说明或改名为探索稿获得完成资格。

#### Scenario: 报告范围或周期不符
- **WHEN** 关键帧报告来自另一采集且没有有效完整观察等价收据、漏看区别性关键状态、未做实际参考对照、来自旧周期或仍有当前适用必改项
- **THEN** 系统 MUST 拒绝交付，内部采集与后续复查仍可进行。

#### Scenario: 修复重采集的失败闭环
- **WHEN** 样品独立失败后修改实现并以新ID采集复查
- **THEN** 系统 MUST 以稳定的入口、帧率与画幅身份检查同范围复查，同时保留各采集的实际摘要绑定；关键帧职责、来源和显示范围不得降低。未登记用户目标变更时原条件与目标 MUST 保持一致；用户明确变更并有效登记时只可采用登记替代目标，仍须变更后的对应用途独立通过及适用目标对照关闭必改。当前必改未关闭或历史损坏时 MUST 拒绝重开周期规避。

#### Scenario: 当前技术与视觉分别有效
- **WHEN** 当前采集技术验证通过且原双通过由有效完整观察等价收据绑定
- **THEN** 系统 MUST 允许交付并同时列出当前采集、原报告和等价收据；收据损坏、媒体变化或未解决冲突 MUST 拒绝。

#### Scenario: 动态试制完整过程由总代理核验
- **WHEN** 采集和验证研究试制阶段的原生动态样品
- **THEN** 工具 MUST 只生成关键帧的评审请求。总代理 MUST 核对完整过程的有序帧、完整解码及适用信号；样品交付 MUST 保留关键帧独立盲审及同轮目标对照。旧动态试制过程报告作为历史保留，其失败不参与当前审核门禁。
