## Purpose

本能力面向公司股价与指数历史演变的无声视频制作，允许用户以自然语言指定单个标的和年份范围，由 AI 编程工具准备可追溯的价格及事件资料，并编排横屏折线动画。仓库提供独立材料初始化、校验和离线渲染入口；网络资料搜索由 AI 在准备阶段完成。

## Requirements

### Requirement: 自然语言请求与标的识别

专题流程 MUST 接受公司或指数名称及起止年份，默认展开为起始年一月一日至结束年十二月三十一日；允许补充代码、市场和视频时长。首期 MUST 覆盖 A 股、港股、美股及对应指数，制作前记录唯一标的的名称、代码、市场、币种或点位单位、上市或指数起始日期。

#### Scenario: 明确的公司或指数请求
- **WHEN** 用户指定可唯一识别的公司或指数及有效年份区间
- **THEN** 流程记录解析后的标的和完整日期范围，进入数据准备

#### Scenario: 标的歧义或无效区间
- **WHEN** 名称对应多个标的、多地上市证券，或起始年份晚于结束年份
- **THEN** 流程要求澄清，不自行选择证券或交换起止年份

### Requirement: 免费数据与价格口径

流程 MUST 使用无需账号或付费密钥的公开免费来源和交易日日线收盘数据。股票默认 MUST 采用仅调整拆股、合股且不计分红再投资的价格；指数 MUST 使用来源明确的官方指数点位并标明指数类型。流程 MUST 区分前复权、后复权、含分红调整收盘价与仅拆合股调整价，不得静默混用。

新版价格材料 MUST 使用 schemaVersion 3，日线点只包含 date 和 close；仅使用来源明确的真实收盘价。

#### Scenario: 可获得可靠的拆合股调整数据
- **WHEN** 来源提供符合口径的价格，或原始收盘价及拆合股资料足以可靠推导
- **THEN** 流程记录调整定义及必要的推导依据，画面显示价格口径和币种

#### Scenario: 只有不符口径的调整数据
- **WHEN** 来源只有含分红调整价、定义不明的 adjusted close 或其他不符口径序列
- **THEN** 流程说明差异并请求用户选择替代口径，未确认前不继续制作

#### Scenario: 指数数据
- **WHEN** 用户指定指数且其序列与发布机构定义可核对
- **THEN** 画面使用点位单位，资料记录价格指数或其他指数类型，不将其当成股票报价

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 3 折线材料
- **THEN** 按统一日收盘价折线、全貌收尾及完整预演评审规则验收；旧材料必须显式迁移

### Requirement: 数据完整性与范围确认

流程 MUST 核验日期顺序、重复记录、异常缺测和请求范围。非交易日不得伪造价格；异常缺测不得静默连线、补零或插值。请求范围超出上市、指数起始或可获取范围时，MUST 披露实际覆盖范围并在用户确认后才缩短。

#### Scenario: 正常休市
- **WHEN** 时间轴经过周末或已核实的休市日期
- **THEN** 日历时间继续推进，价格读数沿用最近已揭示有效收盘价并标明其交易日期，不生成新的报价记录

#### Scenario: 异常缺测或重复冲突
- **WHEN** 应有交易数据缺失或同日记录冲突且无法核实
- **THEN** 流程披露问题并阻断数据验收，不用视觉连线掩盖缺口

#### Scenario: 上市前区间或来源失效
- **WHEN** 请求区间包含上市前日期、尚未发生的日期或公开来源无法覆盖的部分
- **THEN** 流程告知实际范围或不可获取状态，不编造数据、不静默更换标的或缩短范围

### Requirement: 来源留存与离线复现

流程 MUST 保存原始数据、标准化数据、来源链接、获取时间、覆盖范围与调整定义；如有本地推导，MUST 留存推导依据。数据获取 MUST 发生在准备阶段，渲染阶段仅读取固定本地材料，不联网获取行情。画面 MUST 显示来源摘要，作品材料保留完整来源记录。

#### Scenario: 同一份材料重渲染
- **WHEN** 使用相同价格、事件、编排、渲染资产及工具链重渲染或随机寻帧
- **THEN** 同一帧的日期、报价、曲线及事件状态一致，不因实时网络返回而变化

### Requirement: AI 自动筛选可核查事件

AI MUST 自动搜索、核实和筛选事件，无需用户逐条确认，优先公司公告、交易所披露、指数发布机构或政府资料，必要时使用可信媒体。事件 MUST 包含实际发生日期、简短事实标题和来源链接；公司事件优先，重大市场事件可以补充，同类重复事件合并，默认每片最多八个。不可靠或未解决日期冲突的事件 MUST 排除，不得根据涨跌反向编造事件或直接断言事件造成涨跌。

#### Scenario: 事件过密
- **WHEN** 候选事件多于八个或多个事件集中在邻近日期
- **THEN** AI 按与标的关联、重要性、来源可信度和时间覆盖筛选，合并重复事件，记录入选与排除理由，不用股价涨跌单独证明因果

#### Scenario: 日期冲突或没有可靠事件
- **WHEN** 无法核实事件日期或没有足够可靠事件
- **THEN** 冲突事件不采用，允许少于八个乃至零个事件，并记录资料不足，不编造标注

#### Scenario: 非交易日事件
- **WHEN** 事件发生于休市日
- **THEN** 标注保留真实日历日期，不移动到相邻交易日，不捏造事件当天价格

### Requirement: 横屏持续折线场景

所有金融视频 MUST 使用 1920×1080、30 fps 的单标的持续场景，显示稳定标题、折线、日期、当前价格或点位、事件标注和来源摘要。完整数据范围与纵轴策略 MUST 在制作前声明；纵轴 MUST 根据当前可见窗口的有效价格自适应，且画面说明纵轴范围随窗口变化。折线 MUST 仅显示当前播放日期之前、位于滚动视窗内的交易日有效点；相邻有效点只作视觉连线，不把插值位置作为真实报价。每帧 MUST 仅显示最近已揭示有效交易点的单一价格与其真实交易日期，不为逐日价格点重复显示数字。未到达的事件不得提前出现；只在滚动视窗内保留已到达事件的时间轴标记，邻近事件说明依次展示且不重叠。

系统 MUST 只渲染折线，不提供 K 线。横轴位置按帧连续移动，纵轴采用仅使用已到达数据的确定性平滑过渡；报价不插值。结尾在数据全部到达后 MUST 用两秒展开至完整历史，横纵轴和标记同步变化，再停留四秒；全貌使用线性纵轴、稀疏年份刻度和事件编号。

#### Scenario: 长跨度采用滚动近期视窗
- **WHEN** 用户请求多年历史价格视频，编排声明最近十二个月的滚动窗口
- **THEN** 横轴显示当前日期及此前最近十二个月（数据起始处不足十二个月时从数据起始日开始），更早日期的价格和事件标记滚出画面，全量历史仍按时间推进

#### Scenario: 窗口内显示最新价格
- **WHEN** 播放日期在有效交易日之间或到达新的有效交易日
- **THEN** 画面只显示不晚于当前播放日期的最近有效收盘价和它所属的交易日；休市日期继续推进而不伪造报价，也不显示窗口中其他日期的数字报价

#### Scenario: 滚动纵轴适配价格
- **WHEN** 可见窗口包含多个不同价格、单个价格或相同价格
- **THEN** 纵轴按窗口内有效值确定且具有可读留白，退化区间仍保持严格递增，不以零值或全历史极值压扁局部波动

#### Scenario: 事件随窗口滚动
- **WHEN** 事件日期到达、显示期间或之后继续推进
- **THEN** 事件说明不早于事件日期出现；标记只在真实日期到来后可见，并在日期滚出当前窗口后离开画面

#### Scenario: 播放中段与事件前后
- **WHEN** 抽检事件发生前、发生时及发生后的画面
- **THEN** 曲线不泄露未来有效点，事件只在日期到达后显示，报价对应已揭示交易日数据，窗口中的已出现事件标记持续可见

#### Scenario: 展开全历史
- **WHEN** 时间轴到达终日并进入最后六秒
- **THEN** 前两秒将近期窗口连续展开至完整数据范围，后四秒保持完整历史曲线和最终真实收盘价，不泄露尚未播放的数据

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 3 折线材料
- **THEN** 按统一日收盘价折线、全貌收尾及完整预演评审规则验收；旧材料必须显式迁移

### Requirement: AI 编排日期与视频时间

AI MUST 在分镜前根据跨度、事件数量及阅读需求确定总时长、速度分段、滚动窗口长度和事件停留，并记录完整数据日期到视频帧的映射。默认滚动窗口为最近十二个日历月；日期 MUST 单调不减，窗口起点按播放日期向前推相同日历月数并处理月末截短，超出数据起点时钳制到数据起始日。纵轴按窗口自适应，必须可由当前帧与本地价格数据确定。开头 MUST 交代标的、范围与口径，结尾 MUST 用两秒展开至全历史并停留四秒；用户指定时长不足以满足阅读与停留要求时，MUST 说明冲突并澄清，不静默忽略要求。

开场与每条事件 MUST 各停留三秒；其余推进帧按事件之间的日历跨度确定性分配，正跨度至少两帧。预算不足 MUST 阻断并说明增加时长，不能忽略事件或缩短数据范围。

#### Scenario: 60 秒快速推进并保留终幕
- **WHEN** 折线作品编排为 60 秒、最近十二个月视窗
- **THEN** 时间轴在 1800 帧内确定性推进至数据终日，事件停留不重叠，最后 180 帧保持终日，前 60 帧展开全历史，后 120 帧保持全貌

#### Scenario: 月末与数据起点边界
- **WHEN** 播放日期从一个较长月份的月底滚动到较短月份，或播放日期距数据起点不足窗口长度
- **THEN** 窗口起点截短至目标月有效末日或数据起始日，不因日期溢出跳月、倒退或越过完整展示范围

#### Scenario: 分段变速与事件暂停
- **WHEN** AI 编排包含加速、减速和暂停的时间轴
- **THEN** 所有分段覆盖完整演变区间且边界连续，日期不倒退，事件停留与日期映射一致，最后六秒展示终日并展开全貌

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 3 折线材料
- **THEN** 按统一日收盘价折线、全貌收尾及完整预演评审规则验收；旧材料必须显式迁移

### Requirement: 独立无声制作与交付验收

专题 MUST 使用独立的数据输入和无声验收规则，不套用文章字数、口播和有声评审门禁；这不构成现有文章入口的门禁豁免。流程 MUST 经解析需求、确认标的、搜索与核验数据、搜索与筛选事件、保存资料、编排时间轴、静音预演、数据与视觉验收，再导出 MP4。最终 MP4 MUST 不包含配音、音乐、音效或任何音轨。

所有正式导出 MUST 具有绑定四类材料、渲染构建输入和金融 Python 代码的完整静音预演通过记录，包含预演文件及 SHA-256、全时长、抽检时间码、标签可读、滚动可跟随、坐标稳定、事件无重叠及全貌收尾结论。缺失、未通过或过期记录 MUST 阻断正式导出；预演产物不得覆盖正式成片。

#### Scenario: 正式导出
- **WHEN** 标的、数据、事件、时间映射、价格显示、标签可读性及重叠检查均通过
- **THEN** 输出完整终帧可见的无音轨 MP4，验收记录明确数据与视觉结果

#### Scenario: 专题材料与文章入口隔离
- **WHEN** 用户将专题材料提交给文章流程入口
- **THEN** 专题仍使用独立的材料校验和无声门禁，文章流程不会因此绕过文章审查、字数或有声评审要求

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 3 折线材料
- **THEN** 按统一日收盘价折线、全貌收尾及完整预演评审规则验收；旧材料必须显式迁移

### Requirement: 作品材料与版本管理

规范 MUST 定义需求记录、价格序列、事件清单和动画编排四类作品材料；价格序列至少包含日期和数值，事件至少包含实际日期、标题和来源，编排至少包含总时长、日期到视频时间映射与事件停留。方法与规范 MUST 纳入 Git，真实行情、事件资料和生成媒体不得入库，现有三个示例不得新增、删除或替换。

request.json 与 events.json MUST 保持 version 1，prices.json 与 animation-plan.json MUST 同为 version 3；价格点为 date/close，动画记录 chartType=line、日历窗口及展开时间段。旧 version 1/2 材料 MUST 在渲染和计划入口拒绝，并提示显式 migrate-line；迁移 MUST 备份原材料，仅提取已有 close 并保留口径、来源、交易日及原始快照，重新编排并使旧评审失效；不得覆盖已有成片。

#### Scenario: 保存作品与专题规范
- **WHEN** 准备实际作品材料并提交制作方法
- **THEN** 作品保存在已忽略的内容目录或外部内容根，只有规范及共享方法进入版本控制，不强制添加被忽略内容

#### Scenario: 显式迁移旧材料
- **WHEN** 用户调用 migrate-line 迁移旧折线或 OHLC 材料
- **THEN** 保存备份和来源，原有收盘价与日期逐项不变，生成 version 3 折线计划，旧评审不再有效

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 3 折线材料
- **THEN** 按统一日收盘价折线、全貌收尾及完整预演评审规则验收；旧材料必须显式迁移
