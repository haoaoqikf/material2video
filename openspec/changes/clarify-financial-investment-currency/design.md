## Context

见 `proposal.md`。价格材料记录行情币种，投资本金是用于缩放的数值基数；画面金额按统一规则加“元”，不代表已发生实际换汇。

## Goals / Non-Goals

**Goals:** 让金融视频读者能区分价格回报倍数与实际汇兑后的账户余额。

**Non-Goals:** 不改计算代码、本金字段、行情材料、画面文案或视频输出。

## Decisions

- 在金融能力规格中新增一项解释口径，而不改写大段价格或画面要求；这是对现有模型边界的可验证说明。
- Skill 说明用 `本金 × 当前价格 ÷ 买入价格` 表达缩放关系，并明确股票价格使用同一拆股调整价格序列。
- README 保留短提示并链接到金融专题 Skill，避免复制完整计算契约。

## Risks / Trade-offs

- 读者可能仍把“元”理解成按汇率换算后的人民币 → 在 README 与专题说明中同时写明不含汇率变化，也不代表实际人民币结算余额。

## Migration Plan

无材料迁移；更新文档、验证链接和 OpenSpec 后提交并归档。
