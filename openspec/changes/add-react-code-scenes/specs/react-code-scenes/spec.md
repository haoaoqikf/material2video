## ADDED Requirements

### Requirement: 本地代码场景
系统 MUST 接受作品 scenes 目录下 TSX 默认导出的 React 组件及 JSON 对象参数，提供 fps、时长、本幕旁白时间窗和录制进度。系统 MUST 拒绝路径越界与未批准的依赖，不安装作品依赖。代码场景 MAY 无旁白，声音 MUST 由统一音轨处理。

#### Scenario: 有效入口
- **WHEN** 分镜引用有效本地 TSX 入口与参数
- **THEN** prepare 编译并录制组件，标题和字幕由共享外壳绘制

#### Scenario: 无效导入
- **WHEN** 入口或依赖越过作品路径、引用未批准的包或远程模块
- **THEN** 构建拒绝并报告错误

### Requirement: 实时录制及复用
系统 MUST 等待字体、组件和显式资源就绪后录制，加载超时、外网请求或运行异常 MUST 失败。录制 MUST 标准化为精确时长、30 fps 的无声视频。系统 MUST 将源码、资源、参数、时间窗、依赖及实现绑定缓存；完整预演和正式导出 MUST 复用同一片段，MUST NOT 在导出重新执行作品代码。自由动画不保证逐像素复现。

#### Scenario: 输入变化
- **WHEN** 准备后源码、资源或片段变化
- **THEN** 旧准备失效，要求重新准备和完整预演

#### Scenario: 运行失败
- **WHEN** 场景抛错、请求外网或未按时就绪
- **THEN** prepare 失败，不保存有效准备记录

#### Scenario: 正式导出
- **WHEN** 当前准备和完整预演有效
- **THEN** 复用已验收片段完成合成，不重新录制
