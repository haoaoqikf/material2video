## ADDED Requirements

### Requirement: 有限采样预算跨全片覆盖

系统 MUST 将有限采样预算分配到完整可用时间轴，而非从片头截取前若干帧；OCR 和视觉索引采用更小预算时 MUST 同样分布选择。结果 MUST 披露采样策略、实际范围及预算不足，不声称未采样动作已经排除；策略变化 MUST 进入索引身份。

#### Scenario: 目标位于长视频后段
- **WHEN** 素材候选帧超过预算且目标出现在后段
- **THEN** 采样仍覆盖前、中、后段，末段不因排序截断被全部丢弃

#### Scenario: 单帧预算
- **WHEN** 用户只允许采样一帧
- **THEN** 系统选择中部代表点并披露单帧局限，不宣称全片已检查

### Requirement: 来源文本与正负例校准

文本语义索引 MUST 能在无字幕时使用原来源标题与描述，并将其标记为元数据证据而非逐句字幕。语义筛选 MUST 有固定正例、无关负例、动作近邻和跨语言查询评测，校准与验证范围 MUST 清楚。结果 MUST 可以为空，不为凑足 Top-K 而返回低于证据标准的项目；动作、身份和事实仍保持待观察状态。

#### Scenario: 无字幕英文标题与中文查询
- **WHEN** 具有英文标题和描述的媒体没有字幕或 OCR，且已建立来源文本索引
- **THEN** 中文语义查询可以命中其原文，并标记其来自来源元数据，不伪造对应画面时间

#### Scenario: 明显无关的视觉负例
- **WHEN** 对厨房备餐的查询同时遇到相关厨房照片和无关测试画面
- **THEN** 校准后的检索保留厨房正例并排除已评测的无关测试负例，不将分数解释为身份或动作确认

### Requirement: 查询编码在请求内复用

同一次查找 MUST 按模型、预处理、查询文本生成查询向量，不随媒体数量重复编码相同查询；不兼容索引 MUST 先排除，不能混用向量空间。性能记录 MUST 区分冷启动、编码次数和检索范围。

#### Scenario: 同一查询检索多件媒体
- **WHEN** 同一通道查询多件使用同一有效模型的媒体
- **THEN** 查询只编码一次且结果仍保留每件媒体的独立依据
