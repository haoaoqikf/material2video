## Why

现有导演层已经能声明镜头、风格包与跨幕关系，但运行时仍以整幕单段镜头、五种节点入场和透明度 / 缩放近似转场为主，复杂分镜容易呈现模板化且缺少连续的空间叙事。现在需要把导演语义落实为可复用、可量测的帧驱动动画编排，使“高级感”来自稳定的镜头节奏、状态演进与共享对象连续性，而不是作品级临场代码。

## What Changes

- **BREAKING**：为所有场景树作品启用新的默认动画语言；旧 schema v2 分镜继续可解析和渲染，但不再承诺与旧成片视觉一致，也不提供 legacy 回退开关。
- 把镜头从整幕单段运动扩展为与 beat 或稳定阅读阶段绑定的多段轨迹，支持停留、推进、拉远、平移、重构图与收束。
- 扩展节点动效为语义阶段编排，支持单节点或编组目标，以及顺序、反向、中心扩散和路径传播四类错峰策略；旧五种 recipe 保留为输入并使用新版默认曲线与节奏解释。
- 为场景树原语建立不依赖 DOM 测量的稳定几何描述，让继承、变形、拆解和重组可以连续插值位置、尺寸与受控外观。
- 保留 `rest` / `focus` / `muted` / `done` 语义终态，同时增加逐帧视觉混合，消除焦点与状态交接的瞬跳。
- 固定基础布局、beat 状态、节点动效、跨幕连续性和镜头轨迹的合成顺序，并隔离各层变换通道，避免样式互相覆盖。
- 场景树获得完整自动编排；代码场景获得统一的 beat、镜头与连续性上下文，节点级动画仍由作品实现，只有暴露稳定探针节点时才参与共享元素转场。
- 扩展动画与审美评审，量测持续漂移、过密错峰、状态瞬跳、共享元素连续性和稳定收尾；语义审美仍由人工裁决。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `frame-driven-motion`：增加多阶段轨迹、编组错峰、连续状态插值、几何连续性和固定变换合成契约。
- `semantic-motion-timeline`：让动画编排默认绑定语义 beat，并保证结果态与稳定阅读阶段。
- `cinematic-directing`：把镜头语言升级为 beat 驱动的多段轨迹，并规定共享元素连续变换。
- `code-driven-scenes`：向代码场景暴露统一镜头与连续性上下文，规定参与节点级连续性的探针边界。
- `article-to-storyboard`：新分镜优先声明语义阶段和编组关系，减少手写绝对帧编排。

## Impact

- 影响 TypeScript 分镜 schema、场景树运行时、镜头与连续性运行时、组件注册表和 Remotion composition。
- 影响 Python 分镜校验、动画 / 审美评审报告、article2video Skill 参考文档和仓库内示例。
- 现有分镜无需批量重写，但重新渲染时会采用新版默认曲线与节奏，因此已有视觉快照和基准成片需要更新。
- 不引入背景音乐、粒子系统、截图纹理变形、运行时 DOM 几何测量或视觉模型自动评分。
