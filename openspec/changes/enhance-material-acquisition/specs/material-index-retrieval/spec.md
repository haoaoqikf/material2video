## Purpose

为已取得的本地媒体建立字幕、语音、画面文字、镜头与视觉内容的可追溯索引，支持中文及跨语言素材查找，分别披露各类召回依据、模型身份和观察限制，使助手能缩小长视频检查范围而不把语言命中、视觉相似或切镜量测误当作可直接入片的事实结论。

## ADDED Requirements

### Requirement: 索引与检索职责分离

系统 MUST 提供 `m2v author assets index` 与 `m2v author assets find`。`index` MUST 仅消费显式选定且已校验的本地媒体和本地模型，支持选择索引种类与范围，不隐式联网取得视频、字幕或模型；`find` MUST 只查询显式工作区及素材库范围的有效索引，不隐式获取媒体、重建索引或启动模型恢复。索引和查询 MUST 输出可机读的输入范围、状态与限制，失败索引 MUST 不被当作成功空结果。

#### Scenario: 检索未建立索引的媒体
- **WHEN** 仅执行 find 而指定媒体尚无所需有效索引
- **THEN** 系统报告缺失索引及可执行的准备步骤，不自行下载、转录或把缺失情况写成零命中

#### Scenario: 离线建立已准备能力的索引
- **WHEN** 媒体、字幕和所需模型均已在本地准备并禁用网络
- **THEN** index 完成对应本地索引，不访问远端服务，结果绑定实际输入摘要和处理身份

### Requirement: 字幕章节与语音时间索引

索引 MUST 支持已取得的平台字幕、本地 SRT/VTT/ASS 和章节，保留语言、人工或自动字幕来源、原文、时间区间及其与媒体版本的对齐状态。无可用字幕时 MUST 提供按需语音转录，支持中文、英文及混合语音，并保存分段时间码和可用的词级时间信息、推理配置及不确定性。字幕重叠、空语音、背景音乐、专名和异常时间戳 MUST 有明确处理与提示；字幕和转录命中 MUST 不被等同于真实画面命中或精确裁切真值。

#### Scenario: 无字幕的中文演示视频
- **WHEN** 本地视频没有可用字幕且显式启用已准备的转录能力
- **THEN** 系统生成带时间关系与模型身份的中文语音索引，保留不确定性，不宣称原文或字词时间绝对准确

#### Scenario: 有字幕但版本关系未确认
- **WHEN** 导入字幕的内容或时间轴不能确认与当前媒体版本一致
- **THEN** 索引标记对齐未验证，查询仍能显示文字依据和限制，不将字幕时间冒充已验证源片选段

### Requirement: 画面文字索引

系统 MUST 提供按需画面文字识别，支持关键帧或指定区域的中文与英文烧录字幕、标题和产品字样，保存文字、位置、媒体时间与识别置信信息。默认 MUST 避免不受限逐帧识别，并允许按需求补充采样。OCR 结果 MUST 标明识别来源和可能错误，不被当作原始字幕轨、事实证据或已经核实的产品身份。

#### Scenario: 只有烧录字幕的视频
- **WHEN** 媒体没有可提取字幕轨但关键帧存在中文或英文文字，且启用 OCR
- **THEN** 系统建立可按时间查找的识别文字索引，保留文字框和不确定性，不虚称已下载原字幕

### Requirement: 镜头边界关键帧与质量信号

系统 MUST 提供镜头变化、黑场、冻结等候选信号及带时间码关键帧，并支持按需采用适合快速运镜或复杂转场的检测方式。长镜头 MUST 支持间隔补充帧，不仅保留单个代表帧。检测参数、范围和工具身份 MUST 可追溯；闪光、快速运动、字幕变化和淡变引起的不确定边界 MUST 保持候选性质，不得自动认定为动作起止或完整过程。

#### Scenario: 单个长镜头包含多个动作
- **WHEN** 一个长镜头内部包含多个对象状态变化但没有明显切镜
- **THEN** 系统仍能通过间隔采样提供多帧索引，不以没有切镜推断没有动作

#### Scenario: 摇镜触发强画面变化
- **WHEN** 运镜或闪光被检测为候选边界
- **THEN** 结果标注检测依据并允许按需调整或复查，不直接将该点作为动作完整的剪辑边界

### Requirement: 中文词面与跨语言文本语义检索

系统 MUST 支持中文及英文词面检索，并提供按需跨语言文本语义召回，覆盖字幕、转录、OCR、标题和描述。文本语义结果 MUST 保留具体命中的内容、所在时间或元数据位置、语言及模型身份；查询改写存在时 MUST 同时保留原查询和改写，不能悄悄改变对象或动作。精确人物、公司、年代和事件限定 MUST 不因语义相似自动判定满足。

#### Scenario: 中文查询对应英文字幕
- **WHEN** 使用中文对象动作查询已建立跨语言索引的英文字幕
- **THEN** 系统返回相关候选与英文原文、时间关系和语义召回依据，不将译文冒充来源原文

#### Scenario: 相似行业但不是指定企业
- **WHEN** 查询要求某家公司的真实生产过程，而语义候选仅描述同类行业
- **THEN** 系统不把语义相似写成企业身份已匹配，保留身份未知或不匹配状态

### Requirement: 多帧视觉语义与以图查找

系统 MUST 提供按需视觉语义检索，支持中文、英文画面描述和参考图片查询，并以镜头多个有效帧及长镜头间隔帧形成召回依据。结果 MUST 可追溯到实际关键帧和媒体区间，披露模型身份和采样覆盖范围；单帧图文相似 MUST 不被解释为完整动作、先后因果、人物身份或真实事件证明。不同视觉模型、预处理或向量空间 MUST 不直接混查。

#### Scenario: 字幕未提及但画面有目标对象
- **WHEN** 目标对象出现在已采样画面中但未出现在字幕，使用中文或英文视觉描述查询
- **THEN** 系统能够通过视觉通道返回相应关键帧和区间，并明确该结果由视觉相似召回而非字幕命中

#### Scenario: 火箭画面不含发射过程
- **WHEN** 检索发射动作时召回静止火箭画面
- **THEN** 结果不自动标记发射动作可见或完整，保留需实际查看的动作观察状态

### Requirement: 多通道融合与观察未知状态

find MUST 支持词面、文本语义、视觉语义和元数据条件的独立或混合检索，融合排序 MUST 不把不同通道原始分数直接解释为统一命中概率。候选 MUST 显示每个召回通道、原始依据、必要限定状态和实际观察范围；对象匹配、动作可见、动作完整、裁切可用及事实身份 MUST 区分已观察符合、已观察不符合和未知，缺观察 MUST 默认为未知。系统 MUST 支持合并同源相邻候选及可调上下文，但不得合并身份、版本或源时间关系不可信的媒体。

#### Scenario: 同一区间同时命中字幕和画面
- **WHEN** 一个媒体区间被多个检索通道召回
- **THEN** 系统返回可比较的融合候选并保留各通道依据，不以融合分数宣称动作已经验证

#### Scenario: 仅有标题匹配
- **WHEN** 页面标题命中需求但尚未查看实际画面
- **THEN** 候选明确列出标题依据，对象、动作和事实身份观察保持未知，而非自动通过或自动否定

### Requirement: 显式模型准备与能力诊断

系统 MUST 提供 `m2v author assets models` 与 `m2v author assets doctor`，分别管理模型显式准备和校验，以及工具、后端、模型、运行库、凭据配置与来源能力的诊断。模型准备 MUST 固定可恢复的版本、权重摘要、许可与来源；模型缺失、摘要漂移或后端不兼容 MUST 明确失败并给出恢复方式，不自动下载、替换模型或静默切换为另一种检索能力。诊断 MUST 不泄露凭据，也不得以配置存在代替真实平台可用性验证。

#### Scenario: 离线索引时缺视觉模型
- **WHEN** index 请求视觉索引但模型未准备
- **THEN** 系统报告模型缺失和显式准备入口，不联网恢复，也不把词面结果冒充视觉索引

#### Scenario: doctor 检查到平台凭据变量
- **WHEN** 来源配置中存在凭据但尚未真实验证目标平台
- **THEN** doctor 仅披露配置状态和验证范围，不输出密钥值或宣称下载已通过

### Requirement: 版本化增量索引与资源控制

索引 MUST 绑定实际媒体摘要、字幕或其他输入摘要、时间映射、工具版本、模型权重身份、预处理和有效参数；上述任一变化 MUST 使对应索引过期。相同有效输入和配置 MUST 复用已有索引，不重复转录、识别或编码；中断 MUST 可恢复且不把半成品当作有效索引。索引 MUST 提供有限范围、采样、内存、并发及时间预算，查询 MUST 能排除损坏、过期或不兼容的索引并说明原因。

#### Scenario: 同参数重复建立索引
- **WHEN** 媒体、模型、参数和输入材料均未变化再次执行 index
- **THEN** 系统复用已校验索引，不重复下载模型或执行已有推理，并报告复用情况

#### Scenario: 模型版本或源文件变化
- **WHEN** 权重身份、预处理、源媒体摘要或时间映射发生变化
- **THEN** 对应旧索引不再被作为当前有效结果混用，系统要求重建受影响部分并保留无关有效索引
