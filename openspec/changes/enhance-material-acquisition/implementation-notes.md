### 实现与复用边界

- HTTP 使用 Python 标准库的解析、TLS、流与 gzip；不是重新实现 HTTP 协议。现有图库 urllib 路径不能保证解析结果直接绑定连接、逐跳重验和 worker 单一请求后端，因此新制作期边界使用数值 sockaddr 连接并保留原始 HTTPS SNI/证书校验，不改变旧图库/ref 行为。
- 每跳拒绝私网、CGNAT、metadata、受限映射和过渡 IPv6、内嵌凭据、非 HTTP(S) 端口；跨源只保留明确的无会话头，不把任意自定义 token 头转发到新域名。
- 有界请求数、总/单响应字节、解压展开、等待、Retry-After、取消和磁盘；恢复需本地摘要及强 ETag 或 Last-Modified+总长，开放式 Range 必须覆盖到原总长末尾，拒绝错误长度和远端版本串接。
- DNS 使用最多四个 daemon 槽位与调用方时限/取消检查；OS 解析可能在调用取消后继续，但不会积累无界线程或继续建立媒体连接。隔离 worker 另有父进程硬时限及进程树取消。
- yt-dlp 精确固定为 2026.10.26，唯一 PublicOnlyUrllib handler 复用同一受控流；禁止代理、插件、外部 JS、任意选项和联网 FFmpeg 回退。原生分片受网络与本地文件进度预算约束，跨分片不能绕开单个输出限制；父层以后负责本地分轨合并与精裁。
- 独立 worker 输出固定 UTF-8、有界 JSON；显式会话文件只读，不回写或回显。进程审计拒绝 spawn/exec/startfile，已有平台元数据不持久化签名媒体地址。
- 实际路径检查抽到共享轻量模块，存储、HTTP、worker、探测复用同一 lstat 祖先规则；现在也拒绝 dangling junction，恢复文件另外拒绝硬链接。
- 媒体用 Pillow 与 FFprobe 实测，只准本地 file 协议和明确容器，不接受 HLS/DASH/concat/image2 清单。限制探测流数、单次分配和图像像素，仅取必要 JSON 字段，首帧按真实 PTS 而非名义 FPS 定位。FFprobe 作为明确外部依赖，缺失时提示安装，不伪造时基。

### 自审发现与已修正项

1. 接管状态的默认 resolver 为 None，原调用会 TypeError；改为在请求时捕获已安装 socket 守卫的解析器，补真实默认路径与 DNS 超时/取消测试。
2. 分片只有总流量限制，缺单输出/磁盘进度护栏；补本地预算和下载进度检查。
3. 恢复端点/Content-Length 校验不完整、弱 ETag 回退不正确、已有硬链接可能被截断；补齐并验证原文件不受损。
4. NASA 公开 API 返回含普通空格的媒体路径，最初被拒绝；只对路径/查询作百分号规范化，保留控制字符与主机校验，真实下载随后成功。
5. VFR 的 avg_frame_rate 为 0/0 时不能依靠字符串 truthiness 回退；改为解析后回退，并用真实变帧率文件验证。
6. flat 搜索结果不能把临时 media URL 当来源，但也不能丢失已知规范平台页；加窄范围页形状判断，拒绝相似域名与 videoplayback。
7. Windows 捕获环境曾暂时拒绝原子替换；保持同一次原子替换、仅限次重试，不修改权限或退化为覆盖复制；注入永久失败验证上限和 .part 保留。具体 OS 短暂拒绝机制未确证，不把推测写为根因。
8. 清理未使用的参数透传式 FFmpeg helper，避免把尚未实现的精裁路径误当安全执行器；进程审计补 exec/startfile，并以真实隔离进程验证。
