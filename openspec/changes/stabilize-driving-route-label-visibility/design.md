## Context

上一轮已把跟随相机平移对齐到整像素，标签与底图的相对位置逐像素稳定。剩余观感问题不在位置，而在可见性：碰撞透明度按 120 px 距离映射并与 0.6 秒平滑叠加，使标签在车辆/里程牌经过时长时间停在 0.2～0.8 的透明度；屏幕边缘钳位又让标签先停住再移动。实测跟随段 70% 的屏内标签帧透明度低于 0.95，进入和离开画面几乎各占生命周期的 0.6 秒。

## Goals / Non-Goals

**Goals:**

- 跟随段屏内标签始终全不透明，除非被更高优先级标签完整隐藏。
- 标签随地图连续滑入滑出画面，不在边缘停住。
- 标签重叠仍按稳定优先级处理，状态变化保持连续，不逐帧闪烁。
- 保持开场/结尾变焦淡出与最终总览仅市级标签的既有规则。

**Non-Goals:**

- 不改变标签字号、颜色、描边、地理锚点或相机倍率。
- 不为标签增加独立缓动、位移补偿或屏幕固定策略。
- 不改变底图、路线、里程或视频时长。

## Decisions

- **不做边缘收拢**：标签的 x 直接取 `place.center` 投影后的屏幕坐标，由 SVG 视口裁切。旧实现把中心钳制到 `halfWidth + 10`，标签会在边缘停留数十像素的位移后才开始移动，形成停顿感。
- **不做边缘淡出**：标签进入/离开只由视口裁切决定，透明度保持 1。这样每个标签的可见期内不再有约一半时间处于半透明。
- **两态可见性**：标签与已放置的更高优先级标签或端点文字的包围盒间距小于 4 px 时记为不可见，反之完全可见。跟随段各标签都锚定在同一相机上，相对位置固定，因此状态不会逐帧翻转；只在路线切换或端点文字移动时发生一次状态变化，由既有 ±0.6 秒居中时间平滑形成连续淡出/淡入。
- **覆盖物不再驱动标签透明度**：车辆、里程牌、署名和标题带绘制在标签之上并允许短暂遮挡。让它们调暗标签会让标签在整段接近时间里半透明，是本次反馈的主要来源。
- **保留变焦可见性系数**：开场与结尾拉远期间仍使用 `cameraMotionLabelOpacity` 平滑隐藏自绘标签。
- 以真实路线 1800 帧统计与合成路线单测验证：跟随段屏内标签透明度只能为 0 或 1；标签离开画面时 x 单调越过零且不钳位。

## Risks / Trade-offs

- **车辆或里程牌可能短暂遮住标签局部** → 遮挡时间等于覆盖物宽度除以屏幕速度，通常 < 1 秒；相比整个标签持续发灰，局部遮挡更易读，也更接近真实地图。
- **重叠时低优先级标签直接消失** → 相对位置在跟随段固定，不会反复闪烁；城市优先、县/县级市在结尾渐隐的规则不变。
- **标签在屏幕边缘被裁切** → 与地图注记的常规表现一致；不再为了保证完整字形而牺牲连续运动。
