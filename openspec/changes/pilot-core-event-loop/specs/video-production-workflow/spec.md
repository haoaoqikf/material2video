## MODIFIED Requirements

### Requirement: 通用作品必须先完成整片粗预演并优先验证风险
制作助手 MUST 在全片精制前制作覆盖所有章节的低成本动态粗预演，包含目标画幅、主体、粗略运镜、镜头预算、临时配音及按设计需要的音乐，记录整体内容、节奏和情绪结构问题。粗预演 MUST 标明临时状态及版本，MUST NOT 替代最终参数样片、完整预演或授权导出。助手 MUST 登记高风险段落及验证依据，优先解决复杂转场、多主体、跨尺度移动及声音交接等风险，关闭必改项后再扩展精制全片。

若核心表达依赖尚未验证的动态事件，制作流程 MUST 在扩展全片动态制作前，每次先试制一个最能代表核心表达且失败代价最高的完整事件窗口。试制前 MUST 声明事件初态、原因、变化、结果、完整观察窗口、手机显示尺寸、理解条件、表现条件和失败现象。低成本粗样 MUST 覆盖初态、关键变化、揭示（适用时）与结果，并保持判断所需的主体、比例、运动和观察时间；MUST NOT 因试制而扩展其他段落或投入全片精修。静态表达或不存在实质核心风险时，可记录不适用理由，不得为满足流程制造动态事件。

独立评审 MUST 先盲看绑定同一候选的完整事件窗口并记录实际观察，再核对预先声明的中性条件；评审材料 MUST NOT 包含设计理由、预期答案或旧结论。理解与表现 MUST 分开判断。两者均成立且证据充分之前 MUST NOT 扩展其他段落。理解成立而表现不足时按原条件针对性返工；理解不成立时回到事件因果或导演顺序；证据不足或存在实质分歧时 MUST 补证或复核。相同核心问题连续两轮无改善时 MUST 停止同类微调并匿名比较不同表达机制。该短循环 MUST 作为现有粗片验证阶段内的活动，不新增阶段、CLI 门禁、运行时字段或评分；一个事件通过 MUST NOT 被解释为其他段落或全片已通过。

#### Scenario: 局部精美但整体节奏失衡
- **WHEN** 关键画面成立，但完整粗预演显示中段拥挤或收束仓促
- **THEN** 助手先重排内容、镜头与音乐时间线并复查，再开展全片精制

#### Scenario: 临时粗预演已通过
- **WHEN** 简化资产和临时配音的粗预演通过
- **THEN** 仅支持创作阶段推进，最终材料仍重新准备、生成完整预演并按当前契约验收

#### Scenario: 核心动态事件仍有风险
- **WHEN** 全片动态扩展前存在尚未验证且影响核心表达的动态事件
- **THEN** 先完成一个最高风险代表事件的完整低成本粗样，并分别取得理解、表现和证据充分性判断

#### Scenario: 理解成立但表现不足
- **WHEN** 独立评审能复述关系，但关键变化、尺度或结果没有被画面突出
- **THEN** 依据原表现条件局部返工与复查，不以理解通过替代表现通过

#### Scenario: 连续两轮修复无改善
- **WHEN** 同一个核心问题连续两轮修复没有改善
- **THEN** 停止同类微调，匿名比较不同表达机制；证据不足时保持未完成

#### Scenario: 动态粗样不适用
- **WHEN** 作品采用静态观察表达且不存在待验证的核心动态风险
- **THEN** 记录不适用理由和适用的替代验证，不制造动态样片
