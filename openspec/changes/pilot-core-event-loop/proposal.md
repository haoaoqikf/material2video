## 为什么

通用视频流程已经要求在扩展全片前试制核心动态事件，但“核心”选择、通过条件、独立观察和继续/返工决策分散在不同参考页。实际制作容易先铺开多个段落，再发现核心表达或表现不成立，造成重复实现和评审。

## 变更内容

- 在现有粗片验证阶段内定义一个核心事件短循环：逐次只试制一个最高风险且代表核心表达的完整窗口。
- 试制前分别声明理解条件、表现条件、显示尺寸和失败现象；低成本粗样覆盖完整事件过程。
- 独立评审先盲看并记录观察，再核对中性条件；区分理解通过、表现通过和证据充分性。
- 明确通过、局部返工、回到事件设计、两轮无改善后换机制、补证等决策路径。
- 静态表达或无实质核心风险时记录不适用，不强造动态样片。

不新增制作阶段、CLI 门禁、运行时字段或评分；不涉及具体作品素材、场景代码与视频产物。

## 能力影响

### 修改能力

- `video-production-workflow`：为现有粗片验证增加可执行的核心动态事件短循环及决策条件。

## 影响范围

更新 material2video 的制作流程与视觉创意参考文档，以及本变更的 OpenSpec 规格。不会修改正在制作的示例源码、分镜、评审材料或生成媒体。
