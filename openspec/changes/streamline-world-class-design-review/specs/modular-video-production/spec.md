## MODIFIED Requirements

### Requirement: 准备及评审版本绑定（当前媒体流程）

制作命令 MUST 通过作品本地执行入口运行；初始化 MUST 生成依赖锁文件、本地配置、资源恢复及完整预览导出实现。外部检查器实现与作品渲染输入 MUST 分别记录，检查器更新不得自动使无关媒体过期。独立评审、问题关闭及候选生成与制作完成的区别保持原规则。

系统 MUST 在准备后记录输入、资产、源码与准备指纹。render MUST 只读取当前准备材料；缺少或过期须重新 prepare。正式导出只验证材料与技术要求，不要求预演或独立评审。视觉评审 MUST 使用 version=3 媒体包绑定周期、当前媒体、来源与观察范围，并明确关键帧／过程／终审用途及采用结论，不使用可选模板或检查点合同。

#### Scenario: 材料变化
- **WHEN** 源码、数据、字体、声音或候选变化
- **THEN** 受影响准备与评审证据失效，无关局部评审按实际依赖保留。

#### Scenario: 技术导出与独立完成
- **WHEN** 没有独立评审但当前材料有效
- **THEN** 允许生成并技术交付候选，不得报告制作完成。
