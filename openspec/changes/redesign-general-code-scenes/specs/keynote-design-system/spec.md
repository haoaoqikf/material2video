## MODIFIED Requirements

### Requirement: 亮度序与单一强调色
金融与住宅等使用共享设计令牌的画面 SHALL 保留单一深色令牌集、背景表面描边的亮度序和单一强调色；通用 v8 作品 MUST 自行设计配色，不受该令牌集或单一强调色限制。共享半透明令牌 MUST 按合成后对比度验证用途下限：数据描边和图形内文本 4.5:1、边界描边 3:1、纯装饰分隔线 1.5:1。

#### Scenario: 引用语义令牌而不是颜色值
- **WHEN** 金融住宅画面引用语义令牌
- **THEN** 继续使用原有深色层次与强调色，不因通用重构改变

#### Scenario: 半透明令牌按合成后的对比度选值
- **WHEN** 新增或修改共享半透明描边与墨色
- **THEN** 按合成到底色后的用途下限检查；通用作品自由配色不改变该检查

### Requirement: 设计令牌是画面取值的唯一真源
仍由共享画面消费的字体、专用类型颜色、字阶、间距、形状和图形令牌 MUST 继续由单一令牌层提供；MUST NOT 新增按属性切换的主题作用域。general v8 的背景、正文排版、构图与动效 MUST 由作品代码决定，MUST NOT 读取 themes.json 或要求 palette.ts 主题解析。共享字幕几何 MUST 按画幅集中提供，SDK、合成和检查 MUST 消费同一数据，不复制互相独立的常量。删除通用主题 MUST NOT 删除金融住宅仍依赖的令牌。

#### Scenario: 令牌是唯一真源
- **WHEN** 修改仍被金融住宅使用的共享令牌
- **THEN** 引用画面同步变化，不要求逐场景修改

#### Scenario: 两类取值同名但不等
- **WHEN** 为横屏或竖屏提供字幕安全区
- **THEN** SDK、合成层和检查取得相同矩形和文字布局参数，作品正文同名尺寸不视为字幕配置别名

#### Scenario: 新增图形颜色令牌必须归类
- **WHEN** 新增共享图形颜色令牌
- **THEN** 按既有对比度分类检查，不以通用自由配色为由跳过专用类型验证

#### Scenario: 新增主题
- **WHEN** 通用作品需要新的视觉风格
- **THEN** 在作品代码和设计稿表达，不新增预设主题或令牌切换作用域

#### Scenario: 按主题变化的取值
- **WHEN** 旧材料仍声明 visual.theme
- **THEN** 拒绝该字段，不加载旧主题；v8 配色与动效由作品控制
