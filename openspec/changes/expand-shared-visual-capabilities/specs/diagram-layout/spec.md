## Purpose

为通用讲解提供结构化关系图的自动布局和逐帧安全绘制能力，使作品复用成熟布局算法完成节点与连线路由，同时保留项目风格、文本与运动进度的自主控制，避免每个镜头重新计算布局。

## ADDED Requirements

### Requirement: 稳定布局与纯时间图示

SDK MUST 提供可异步求值的有向图布局与消费布局结果的图示组件。布局 MUST 固定种子与输入顺序，不修改调用方输入；MUST 拒绝重复 ID、未知节点引用、非正或非有限尺寸。绘制 MUST 只依赖布局、样式与显式进度，不启动自走动画；布局结果 MUST 可序列化复用。

#### Scenario: 相同结构求值
- **WHEN** 相同节点、边与配置重复布局
- **THEN** 位置与连线路径一致，输入内容保持不变

#### Scenario: 帧顺序变化
- **WHEN** 图示按正序或随机顺序绘制同一进度
- **THEN** 图形一致，不重新执行布局
