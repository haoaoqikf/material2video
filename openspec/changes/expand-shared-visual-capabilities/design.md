## Context

代码场景在普通 React 页面录制，再由 Remotion 回放片段。现有 D3 与 paths 已承担部分几何；风格另有 Catmull-Rom 平滑代码。SDK 通过受限打包器暴露能力；公式字体须服从二进制不入库规则。

## Goals / Non-Goals

**Goals:** 五项能力可被作品实际调用，保持离线、纯时间与来源边界。布局 50 节点争取 1 秒内；新增库不因仅使用简单组件而进入每个场景；验证短样片不跑全量。

**Non-Goals:** 不新增编辑器、通用动画引擎或模型资产类型，不重写金融类型特有的轴切换与相机策略。

## Decisions

- 使用已有 D3 统一点列路径函数，支持 linear/monotone/step/catmull-rom；共享图表、dark-proof 风格与金融折线几何复用；金融采用 D3 单调曲线维持不过冲语义，精确控制点不承诺与原 Fritsch–Carlson 相同，业务轴/时序不变。
- ELK 0.12.1 提供独立异步布局函数；排序输入、固定随机种子、复制输入并校验尺寸/引用。布局结果可序列化；图示绘制只读取布局、progress、样式。不在每帧重新求布局。
- KaTeX 0.19.1 关闭 trust 并明确报告公式错误。CSS 排版规则随精确版本读取，字体使用登记的 WOFF2；源包字体与 Web 恢复目标同时登记，复用 fonts/fetch.py 的既有候选路径恢复，无新下载器。公式加载函数先等待字体与样式，调用方随后 ready。
- Lucide React 1.68.0 采用 SDK 子入口静态导出，保留按需 tree-shaking，不提供按字符串索引的整库图标字典。
- @remotion/transitions 固定 4.0.526，在合成层使用官方 TransitionSeries。共享 JSON 登记转场名称、展示类型与方向，Python 与 Web 消费同一来源；保留 cut/fade/crossfade，新增左右滑动/擦除、iris、clock-wipe。转场仍消耗两幕重叠窗口，字幕保持最上层且时间不变。支持 1 帧端点与局部回放偏移。
- 外部库来源与许可登记在专题文档；数学/布局与图标经 SDK 入口使用，作品不能绕过依赖边界。ELK 的较大布局引擎与 KaTeX 仅在实际使用时打包，实测构建大小与准备成本。

## Risks / Trade-offs

- ELK 包较大、字体增加 → 按入口/引用裁剪，登记真实体积与短样片耗时，不承诺未经测量的性能。
- 官方转场重叠计时与当前材料不一致 → 复用现有编排窗口，测试精确总帧数、首末帧、局部预演与字幕；无行为需求不保留旧实现分支。
- 局部媒体验证发现默认 LocalServer 不使用已有 Range handler，Chromium 的 seekable=[0,0]、视频一直停在首帧 → 默认同源服务也复用既有范围处理，仅在 cors=True 时发跨域头；不新写媒体服务。
- KaTeX 内部 CSS 与字体版本不匹配 → 精确版本、摘要核验、字体恢复失败即明确失败。
- 异步布局影响 ready → 文档与示例显式等待布局和公式字体，纯时间帧只消费固定结果。
- 制作依赖识别新增 SDK 子入口，并沿已选风格组件的 TS/TSX/JS/JSX 引用跟踪至公式实现、字体与登记；入口映射由 entries.json 共享，G4/G3 不因间接引用漏掉字体漂移。合法无 tokens 风格继续可用，其他风格示例子树不放开。
