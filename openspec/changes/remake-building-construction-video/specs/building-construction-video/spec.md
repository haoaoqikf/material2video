## MODIFIED Requirements

### Requirement: 独立类型与统一入口

系统 MUST 登记 building-construction 类型，通过统一 init、validate、prepare、preview、render 和制作状态/评审入口操作；首版 MUST 支持 1920×1080、30 fps，拒绝不支持的材料版本或输出组合，保持其他类型行为不变。

#### Scenario: 初始化建筑作品

- **WHEN** 用户通过统一入口初始化 building-construction 作品
- **THEN** 系统在类型所属内容目录创建 building.json v2、construction.json v2 与 manifest.json 模板，可独立准备和渲染而无需改用 general

#### Scenario: 不支持的配置

- **WHEN** 作品声明未知建筑材料版本或不支持的画幅帧率
- **THEN** 系统在准备前拒绝并定位错误

### Requirement: 稳定构件与完整建筑材料

系统 MUST 根据 `building.json` v2 生成场地、开挖、基础、主体、楼梯与梯井、墙体开口、屋顶、门窗、饰面与简化庭院；构件 MUST 有唯一稳定 ID、类别、楼层和最终几何位置，重复准备相同材料 MUST 保持身份与几何一致。`building.json` v2 MUST 声明画布、开间、层高、屋顶类型与高度、墙厚、基础深度、场地留白、楼梯位置、门窗洞口的所属墙面/层号/偏移/宽高/窗台高度。系统 MUST 用真实洞口几何生成墙体，MUST NOT 用贴在墙面的薄片冒充门窗洞。系统 MUST 拒绝无效尺寸、越界或超高洞口、重复 ID、非法屋顶/楼梯参数和不受支持的参数组合，不伪称任意建筑模型生成。`building.json` v1 MUST 被明确拒绝并提示升级，不提供兼容分支或迁移工具。

#### Scenario: 重复生成

- **WHEN** 对同一建筑材料重复准备
- **THEN** 相同构件保持相同 ID 与最终几何，墙体洞口不会被实体墙封闭

#### Scenario: 非法几何参数

- **WHEN** 尺寸非正、洞口超出所属墙面、窗台加洞高超过层高、重复 ID、屋顶或楼梯参数非法
- **THEN** 校验失败并报告相关构件，不继续生成候选

#### Scenario: v1 材料

- **WHEN** `building.json` 或 `construction.json` 仍为 schemaVersion 1
- **THEN** 校验明确失败并指出需升级到 v2，不进入准备

### Requirement: 建造阶段与可见性分离

系统 MUST 以 `construction.json` v2 的阶段、镜头与构件级步骤定义建造顺序。`stages` MUST 从 0 开始、首尾相接并完整覆盖声明时长；`shots` MUST 完整覆盖全片且不重叠；`steps` MUST 用构件选择器引用生成后的构件，声明动作、时间窗、所属阶段与前置步骤。每个非初始构件 MUST 恰好被一个步骤建成一次；未知选择器、未匹配构件、重复建成、选择器重叠、依赖环、步骤早于依赖完成或步骤越出所属阶段 MUST 使校验失败，不静默调整施工顺序。步骤动作 MUST 在时间窗内改变所选构件的可见状态，MUST NOT 让未选中的构件在同一时刻一起出现。

镜头 MAY 声明只影响取景的隐藏构件（剖切/移墙），用于观察内部连接；隐藏 MUST NOT 回退构件建成状态，最终镜头 MUST 恢复应见构件。

#### Scenario: 依赖与轨道错误

- **WHEN** 存在未知构件选择器、循环依赖、重复建成事件、选择器重叠、先于依赖完成的动作或步骤越出阶段
- **THEN** 校验失败并定位问题，不静默调整施工顺序

#### Scenario: 观察内部结构

- **WHEN** 镜头临时隐藏已建墙体或剖开场地
- **THEN** 结构保持原位置和完成状态，恢复视图后无需重新建造且完工外观完整

#### Scenario: 整阶段一起出现

- **WHEN** 某阶段的所有构件在同一时刻出现，没有按步骤区分先后与动作
- **THEN** 视为未实现构件级建造顺序，须拆成有依赖关系的步骤

### Requirement: 确定性镜头与离线成片

系统 MUST 直接按帧求取构件、材质、镜头、灯光、标注与环境状态，不依赖用户交互、上一帧或挂钟。镜头区间 MUST 完整覆盖全片且不重叠。同帧在重复、正序与倒序采集下 MUST 保持一致，探针帧图像 PSNR MUST 至少 60 dB。画面 MUST 使用仓库既有的渲染底座，MUST NOT 引入第二套渲染引擎。准备与渲染 MUST 仅使用已登记本地资产，缺失资源、摘要不符或未就绪时明确失败。外部资源 MUST 保存来源、作者、许可依据和摘要；纯程序材质允许空清单。作品、媒体和产物 MUST 不进入版本控制。

#### Scenario: 同帧重复与乱序采集

- **WHEN** 对同一准备记录重复、正序和倒序取样探针帧
- **THEN** 对应同帧图像 PSNR 至少 60 dB，构件显现、镜头、阴影与标注不会因取样历史漂移

#### Scenario: 离线资源校验

- **WHEN** 已登记素材缺失或摘要变化，或镜头覆盖有空隙/重叠
- **THEN** 系统明确拒绝准备，不依赖在线补取或静默降级

### Requirement: 准备绑定与技术验收

系统 MUST 将材料、生成实现、资产和声音绑定准备指纹，变化后拒绝过期准备；输出 MUST 验证帧数、尺寸、帧率、时长和音轨，并保留溯源及性能记录。无声音声明时 MUST 输出无音轨；预览 MUST 不替代完整候选验收。

#### Scenario: 修改建筑后导出

- **WHEN** 准备后修改构件、时间轴、外部资源或生成实现
- **THEN** 系统拒绝过期准备并要求重新 prepare

#### Scenario: 首例无声输出

- **WHEN** 首例声明 60 秒、30 fps 且无声音
- **THEN** 输出 1800 帧、1920×1080、30 fps 的无音轨候选并验收技术参数

### Requirement: 住宅首例与表达边界

首例 MUST 展示同一栋两层框架住宅，从场地与开挖、基础、一层和二层主体到墙体与屋顶、门窗饰面与庭院完工，成片 60 秒、1800 帧。首例 MUST 使用 `building.json` v2 与 `construction.json` v2，MUST 在默认机位可见的立面上安排入口与主要门窗，MUST 使用可辨识的坡屋顶或带女儿墙的平屋顶，MUST 展示楼梯与梯井的真实空间关系。施工表达 MUST 有可追溯依据并说明省略范围，必要画面边界标记遵循现有小字规范，不把组装动画当作完整真实工序。制作完成 MUST 具备当前候选技术证据、按现有审核策略派生的适用独立评审及问题复查，不能仅因成功导出宣布通过。

#### Scenario: 首例从结构扩展到全片

- **WHEN** 基础、一层框架、墙体与屋顶代表片段进入扩展判断
- **THEN** 复核阶段可理解性、支承连接、洞口、遮挡、完整动作与观察窗口，并按现有风险策略完成适用核心评审后才扩展

#### Scenario: 当前候选完成判断

- **WHEN** 住宅首例申请制作完成
- **THEN** 核查全过程身份连贯、错误穿插/悬浮、主体取景、阶段衔接和完工外观，缺少适用独立证据或必改项未关闭时不得标记制作完成

## ADDED Requirements

### Requirement: 建造过程可读与画面质量

影片 MUST 让未读设计材料的观众看出建造顺序、构件连接和完工结果。每一阶段 MUST 至少有一次镜头切换或明确的取景变化，使观众看到该阶段构件的连接部位；基础、一层框架、二层框架、墙体与屋顶 MUST 各有一个能看清构件交接的近景或剖切镜头。画面 MUST 提供常驻阶段轨与当前构件的小字名称，名称 MUST 用引线指向对应构件，MUST NOT 遮挡构件、连接点或关键动作。开场至主体完成前 MAY 显示完工体量的幽灵轮廓，使观众知道正在建造的目标；轮廓 MUST 在完工镜头消失。画面 MUST 保持稳定的比例参照：近景镜头的主体可见高度 MUST 不低于画高的 35%，全景镜头 MUST 不低于 25%。

画面质量 MUST 满足：混凝土、木材、玻璃、屋面与地面有可区分的材质与明度；主体与地面有方向和软硬一致的接触阴影；构件 MUST NOT 悬浮、穿插、抖动或出现 z-fighting；完工镜头 MUST 恢复所有应见墙体、门窗与庭院；小字标注与示意边界 MUST NOT 遮挡主体、连接点或关键动作。

#### Scenario: 独立观察者复述

- **WHEN** 一名未读设计材料的独立观察者（人或按独立子代理评审隔离投喂的子代理）观看成片后复述建造顺序
- **THEN** 能按场地/基础、一层框架、二层框架、墙体/屋顶、门窗/完工的顺序说明，并能指出柱、梁、板、墙、屋顶与门窗的连接关系；不能复述时不得标记制作完成

#### Scenario: 构件级动作不可见

- **WHEN** 某阶段只看到整组构件淡入，观众无法判断先立柱还是先架梁，或无法看到梁柱/板墙的交接
- **THEN** 视为建造过程不可读，须补步骤动作、近景或剖切，不得以阶段标签替代

#### Scenario: 画面缺陷

- **WHEN** 出现构件悬浮、墙体盖住楼板、门窗贴片浮在墙外、阴影方向冲突、z-fighting 或完工镜头缺构件
- **THEN** 候选验收失败，须修复几何、遮挡或取景后重渲染

#### Scenario: 标注遮挡

- **WHEN** 构件名称、阶段轨或示意边界遮住连接点、洞口或关键动作
- **THEN** 视觉复核判定不合格，须缩小、移位或改为引线
