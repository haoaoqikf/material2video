## Context

现有素材导入支持 Pexels 直链、Pixabay API 和任意合格公开媒体。独立作品与主工具各有语音解析入口，默认逻辑需要同步。

## Goals / Non-Goals

以旁白相关性决定镜头，在既有选材、留证和独立评审链路中完成十五秒样片。使用现有类型、分镜字段、素材导入和音色登记。

## Decisions

- 纪实口播作品的后端默认在共享配置解析中按 `documentary-edit` 选择 Kokoro。缓存、重试和底层调用继续依据实际后端。命令行与作品的显式后端优先。其余类型沿用既有默认。
- 对象、动作和过程能在素材中被确认时优先采用。图库检索优先 Pexels 和 Pixabay，证据镜头仍先追查原件。风景、固定机位、图片或抽象画面按实际叙事职责选择。
- 样片用手冲咖啡检验具体动作匹配，由自拟中文口播与可核查的实拍素材组成。按实测词边界组织镜头、保留十五秒总长度并执行技术 QA 和独立终审。
- 首次直接准备时，在计算采集指纹之前同步公开字体副本。新工程随后直接渲染时，字体副本已经就位。

## Risks / Trade-offs

已有纪实口播配置如果省略后端并填写 Edge 音色，需显式声明 `edge-tts`。首次合成需要恢复固定模型与所选音色。图库候选数量和相关性由实际检索与筛选确认。
