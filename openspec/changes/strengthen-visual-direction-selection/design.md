## Context

动机见 proposal.md。现有 trial 支持多个媒体 item，盲看之后同评审者对照已绑定的 references/conditions；报告已有 observations。现行指南与包内提示仍可能让采用特征清单取代整体品质判断，且“关闭必改项后进入设计”缺少选案区分。

## Goals / Non-Goals

**Goals:** 让研究、候选制作、独立观察和作者取舍连接到可见画面与下一次行动；降低过早展开和精修陪跑成本。

**Non-Goals:** 不增加阶段、候选数量、分数、自动审美、审批、机器预算或报告字段；不修改渲染/分镜契约、不迁移历史报告、不在本变更重做作品。

## Decisions

1. **按现有权威分工更新。** stage-research 管同内容候选、投入和收敛；reference-video-analysis 管整体目标；review-contract 与 visual-review-rubric 管判断责任；stage-design 管展开范围。SKILL/README 只摘要和路由。相比另建选案手册，这可避免平行权威和重复门禁。
2. **选案结论保持人读。** 在现有 observations/DESIGN 中分别说明候选优劣与能否展开。三种结论是决策语义，不新增枚举或机器解析；现有 pass/fail/insufficient 继续表示对应观察范围，status 不判断创作阶段。
3. **先结构，再补足影响判断的精度。** 同一核心内容用实质不同表达粗试；材质/运动是吸引力关键时先验证它，选择不受影响的落后路线及时停止。概念图可探索，正式视觉基线须由拟用链路重现，精确文字和数据单独核验。
4. **实际隔离包同步提示。** reviews.py 生成的 questions.md 提醒整体品质与特征区别，并仅在 trial 提供选案判断；保留包内隔离与摘要规则，不读取作者设计或泄露盲包外目标。final 仍评当前完整成片。
5. **证据驱动返工。** 每轮围绕主问题保留前后媒体，不把评审意见逐条堆成装饰任务；两轮无改善按原规则比较新路线。资源停止保持未达标状态。材料留在作品的既有 RESEARCH/DESIGN/visual-notes，不加台账。
6. **区分比较参照与待验证范围。** 正式包的 items 全部受失败闭环约束，没有“淘汰候选”角色。默认作者先比较，正式 trial 只验证拟作基线的范围，必要备选/历史媒体放 references 并中性说明用途；它们在同轮对照才显示，不声称所有候选独立盲看过。确有选案分歧时按需独立匿名观察全部候选，保存探索观察而不冒充导入通过；看过目标者不能充当后续正式新盲看者。额外观察成本如实记录，不设每次必经的新轮次。已有正式失败不得改放 references 或重开周期消除。

## Risks / Trade-offs

- [文字变多而决策不变] → 用独立新上下文行为演练，输入真实任务和最少原始材料，观察选案/展开决定；不向代理提示预设答案。记录失败和限制，不以背诵规则证明审美进步。
- [追求相近精度导致无效投入] → 只补妨碍判断的差异；粗稿排除与重点打磨分开。
- [过度拒绝或无限探索] → 允许具体优势成立且主要差距处理后收敛，复用有效局部基线，资源到点如实交付。
- [人读判断主观] → 具体媒体、原目标、独立观察和作者责任并存；不把自动测试声称为审美检测。

## Validation / Rollout

先完成规划，再修改指南和包内提示。运行技能结构校验、文档离线链接/JSON/预算检查及受影响的媒体评审测试，不全仓测试。用本次已有静态稿与参考作隔离决策演练，并检查局部文字修订不会重开选案；作品和媒体不入库，仅保留方法、观察结果及覆盖边界。独立审查修改后提交，再同步主规格、自动归档并提交。现有示例的媒体/格式不变，以文档和既有契约检查确认路由与格式仍有效，不为本次流程改动重渲染示例。
