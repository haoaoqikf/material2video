## Context

问题及范围见 proposal.md。现有三阶段、RESEARCH/DESIGN/唯一问题记录、version=2媒体包和先盲后对照可复用。阶段正文限制3000字符、入口2000字符，细分研究方法应留在reference-video-analysis而非复制到各入口。用户已经明确授权按已讨论方案实施，本次规划完成后继续apply，不再次请求许可。

## Goals / Non-Goals

**Goals:** 将可观察的深入研究与转化要求写进唯一权威，明确实际美术完成条件及目标对照输入；复用既有评审与导航检查形成可验证的小范围保障。

**Non-Goals:** 不重制投资视频，不补造示例研究或评审，不增加风格注册、材料字段、报告版本、审核人数、第三类评审或固定审美分数；不引入外部组件、依赖或新命令。

## Decisions

1. stage-research维护循环及完成条件，reference-video-analysis维护具体标杆、拆解和转化方法；SKILL、创作总纲及其他阶段引用其结论。研究深度与当前问题匹配，保留及时小试验和原创融合。
2. 研究记录区分观察/解释/应用推断，DESIGN只引用并保存本片采用及已验证实际画面。正式设计前验证最能代表目标的画面，完整过程按未知选择，不固定数量和时长；用户只要求方案图片时尊重交付边界。
3. 现有references保存实际目标媒体、conditions保存中性采用特征。校验只添加references非空时conditions也必须非空；条件而无参考仍合法。打包问题提示区分盲看自身表现与对照目标兑现，不改报告格式或在机器中猜测风格语义。
4. 阅读路由沿用reference/design-research ID，校验必备入口及权威去向，防止研究拆解路径静默丢失。保留正文预算，不新增平行导航或通用风格模板。
5. 七示例集合保持不变，在examples/README补充适用演练，明确演练不代表历史已完成；仅修复受引用入口已失效的当前链接，不重写历史创作事实。
6. 沿用现有打包器生成摘要及路径；不新增报告生成命令。用户不必审批每个环节，独立评审先盲后对照及终审资格按现有策略。

## Risks / Trade-offs

- 过度研究拖延创作 → 依据当前关键未知决定深度，允许研究与试制往返，以能指导画面和解释差距收敛。
- 参考变成机械临摹 → 明确采用范围、适应性调整及原创融合，按效果评判，参考像素和授权边界照旧。
- 条件校验无法发现隐瞒的目标 → 明确机器只能核对已声明输入，助手与独立对照承担语义责任；前向行为演练检查是否主动附参考。
- 旧reference-only请求被拒绝 → 保留v2结构，明确补充中性条件后重建受影响包，历史已绑定证据不迁移、不改写。
- 文档变长与重复 → 细节集中在唯一参考指南，其余入口只保留影响当前决策的增量。
