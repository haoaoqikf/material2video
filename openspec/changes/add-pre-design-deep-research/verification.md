## 文档判断演练

以下为逐项对照指南和规格的文档检查，不是实际视频研究、受众实验、成片或独立制作审核。

| 情况 | 复核结论 |
|---|---|
| 新制作准备写正式设计或 HTML 草稿 | 先完成研究，再进入设计，仍在 plan 阶段内 |
| 只有链接或静帧 | 链接不足以完成研究；静帧不得推出运动或声音结论 |
| 受众认识缺乏证据 | 标为假设，记录验证办法 |
| 出现相反证据或机制限制 | 保留冲突与边界，补查或调整判断 |
| 关键素材或事实未核实 | 阻止依赖它的设计；与其无关的整理仍可继续 |
| 有效旧研究或用户已有方案 | 按覆盖引用与缺口补查，不抄写历史或重开无关选案 |
| 裁切、错字、已验证方案内的实现修复 | 沿用研究，不重新调研整套风格 |
| 研究与设计记录 | RESEARCH 保存问题与依据，DESIGN 引用并记录最终采用，不维护平行证据表 |
