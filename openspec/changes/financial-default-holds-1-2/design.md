## Context

金融 v8 计划把开场和结尾帧长硬编码在生成器及校验器中。日期推进锚点依赖推进区间边界，因此新默认值和旧计划兼容需要同时处理。

## Goals / Non-Goals

**Goals:** 新生成计划采用 30 帧开场、60 帧结尾；20 年内默认 60 秒、超过 20 年默认 90 秒。保留已有 v8 分段的可读性及真实项目文件不变。

**Non-Goals:** 不迁移或重导出现有作品，不改变行情映射算法、画面内容或 v7 兼容规则。

## Decisions

- 生成器按展示日期跨度选择默认总时长，再以新的固定帧数和 `total_frames - ending_frames` 推导推进区间。
- v8 校验按各计划自身的三段连续区间与推进锚点校验，不再强制固定开场/结尾帧长；新默认由计划生成测试锁定。
- 由于两秒开场加两秒终幕占四秒，最低时长设为四秒；其余帧留给推进。
- 规格、README 和金融 Skill 参考同步声明仅影响新生成计划。

## Risks / Trade-offs

两秒静止终幕比原先更短。变更只影响新生成计划，旧项目继续保留其原有节奏；修改现有作品仍须显式重新生成计划并重新准备和评审。
