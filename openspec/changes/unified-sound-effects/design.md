## Context

现有 general soundtrack 支持 builtin/sourceRef、场景与旁白段时间偏移；audio.mix 将全部输入转为单声道。动机见 proposal.md。

## Goals / Non-Goals

目标：双来源落盘、统一 ID、动作帧同步和立体声处理；原有有效字段继续有效，本次是增量功能，未升级分镜版本。第三方搜索供应商接入不在本轮，按已确认方案先提供直链与本地导入。

## Decisions

- 新增 sound_library 管理 assets/sound-sources.json 与 assets/sound/<sha>.wav；合成器单独模块维护目录与配方，避免声音业务塞进 CLI 或混音引擎。
- 第三方保留原始摘要，解码为统一 PCM16/24kHz/立体声 WAV，最长 600 秒、输入最多 256MiB。复用现有有界 HTTP 下载器，不引入网络依赖。所有素材先暂存，整批通过才交付，记录最后原子替换。
- 声音统一 ID 使用 assetId；现有 builtin/sourceRef 是独立有效入口，不引入旧版适配器。记录摘要与全部文件摘要进入准备输入。
- 合成器使用确定性噪声与共振、瞬态、包络叠加，连续打字配方可显式给定按键时间点，也可用种子产生自然间隔；时间点支持精确同步，随机不发生在渲染阶段。
- 播放设置为 offsetFrames、trimStartMs、durationMs、loop、fadeInMs、fadeOutMs、pan；循环先裁素材入点再重复，显式时长封顶。声像采用单声道等功率定位；默认保留导入立体声。
- audio.normalize 保持旁白单声道，混音与最终 master 保留立体声，避免影响依赖单声道的旁白节奏分析。
- 第一轮验证用独立测试及固定示例附属的音效演练配方，不给现有无声示例添加声音。性能目标：单条 10 秒合成低于 5 秒，内存按单条最长 30 秒合成上限约束；第三方解码流式写盘。

## Risks / Trade-offs

- 合成自然度有限 → 目录明确属于拟音／风格化合成，实录通过第三方导入补充，自动信号测试不声称完成听感验收。
- 第三方许可声明并非法律保证 → 强制保留可核验来源与许可文本，不猜测授权。
- 立体声被后续环节折叠 → 测试覆盖混音、master 和实际 prepare 产物。
