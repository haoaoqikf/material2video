## MODIFIED Requirements

### Requirement: 参考分析按用户需求记录采用范围

创作或实质性视听修订 MUST 建立具体可查看的视觉标杆，区分整体品质、专项表现和信息表达参考。研究 MUST 按观众要理解的内容及表达难点确定搜索词、来源和筛选依据。入选案例 MUST 标明来源、用途和实际查看范围，动态案例 MUST 查看支持结论所需的关键变化过程。研究 MUST 按当前问题深入拆解构图比例、排版、色彩层次、图形空间、适用材质光影及运动声音，区分实际观察、效果解释、本片应用推断与限制；不机械要求全部维度。参考只有静帧或局部片段时，MUST 针对本片实际采用、承诺或影响判断的过程，从可见证据推导必要的运动、声音与转场方向，并标注为假设、置信度与验证指标，不得写成已实际观看或听见。研究问题、来源、证据观察与综合发现 SHALL 统一保存在 RESEARCH.md。用于当前镜头的结论 MUST 将实际观察、效果解释、可借鉴的设计方法、本片关键状态与动作安排和验证预期串联起来；DESIGN.md SHALL 引用研究并记录全片采用范围、共同语言和实际基线；场景文档 SHALL 记录本场落点、适应性调整、详细编排及验证办法。采用分析过长时可使用既有 reference-analysis 附件，但不得复制研究报告或强制独立风格报告。拆解步骤按实际问题选择，不设固定候选数量、采用数量、共同规律出现率、八项指标或统一采样数；仅分析外观也可以成立。

#### Scenario: 只借配色与构图
- **WHEN** 用户只要求外观相似
- **THEN** 助手 MUST 在对应维度深入解释具体效果及本片转化，并进行实际外观对照，不额外强制分析底层机制、声音或全部维度。

#### Scenario: 只有静帧
- **WHEN** 参考仅有静帧或局部片段
- **THEN** 限定已观察范围，同时 MUST 针对实际采用、承诺或影响判断的过程从静帧证据推导必要假设，写明依据、置信度和验证指标；所推导内容用过程样片的帧/信号证据核对，不写成已观察事实，也不因缺少完整参考而跳过设计。

#### Scenario: 自主选择标杆
- **WHEN** 用户没有指定参考或作品采用原创融合方向
- **THEN** 助手 MUST 自主选择并说明具体参考用途，借相关及跨题材证据建立视觉目标；风格名称、图表规范和搜索摘要不得替代深入研究。

#### Scenario: 五维按实际问题展开
- **WHEN** 当前任务只采用部分五维特征或有意使用静止、无声和硬切
- **THEN** 研究 MUST 深入实际采用、承诺或影响判断的部分，不要求五维逐项填表；未验证过程不得借此宣称已兑现。

#### Scenario: 视频可查看
- **WHEN** 需要从可查看的视频借鉴动作、镜头或节奏
- **THEN** 助手 MUST 查看并记录能覆盖关键变化的实际时间窗，把具体处理及其表达作用转成本片镜头方案，并给出试制时要观察的状态或过程。

#### Scenario: 来源无法访问
- **WHEN** 搜索结果只提供不可访问的页面、缩略图或二手摘要
- **THEN** 助手 MUST 优先查可实际查看的创作者原页、官方发布或可替代案例。仍无可用证据时 MUST 标明缺口，不能把摘要登记为动作观察。
