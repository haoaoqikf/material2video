## Context

动机见 proposal.md。现有 cameraAt/project、全局时间、幕内事件、Painter 量测、lookdev 和隔离评审已足够承载本方案。fold 已有生成器和运行时布局检查，pigeon 已有事件化声音；不能把这些能力再次计为新增成果。

## Goals / Non-Goals

目标是用两个现有示例证明六项方法可执行、可修改、可观察。制作说明复用 DESIGN.md 正文，机器断言复用 v2 合同，观感结论复用既有报告正文。

本轮不增加 CLI、JSON 字段、通用仪表或几何 DSL，不扩大固定 examples 集合。风格包公开组件保留；示例去掉无依据的使用方式。包若因 GUIDE 调整导致指纹变化，按现有机制重新 prepare，不借此升级契约版本。

## Decisions

### 1. 镜头连接：在完整窗口里验收

在 explainer-design.md 的既有逐场表补充填写示范：前态、后态、保留锚点、切镜理由、观众新增认识。fold 选择“珠链→细胞→珠链”与结果回场；pigeon 选择“计时器→角色→计时器”并保留刻度状态。先比较当前窗口与一次重排粗样，再选方案。硬切可因注意力或叙事成立而保留。

替代方案是新增转场组件；暂不采用，因为组件不能判断推理关系。验收观察对象认回和关系获得，而不是规定必须溶解。

### 2. 时间预算：以帧区间记录注意力

在上述同一张设计表内记录建立、阅读／聆听、观察、消化窗口，允许阅读与次要动作重叠。以 storyboard、事件和代码中的实际时间回填，关键接合或揭示应有可观察时间。先删冗余句，再调动作或延长停留；有旁白时同时检查听觉负担。

不新增阅读速度硬校验、不照搬外部无字幕比例；这些数值无法证明观众看清了关系。

### 3. 共同尺度：先核依据再设计外观

pigeon 删除 32→142 的本能读数及相关量测声明，检查画面、README、GUIDE 和现有断言，保留有来源的 15 秒周期与两次喂食。相同时间和坐标的数据由现有全局状态派生。跨例子尺子的方法写入指导，当前示例只证明同一时间尺子跨镜头稳定，不声称已验证多案例迁移。

不增加另一个通用 Gauge；现有组件能承担有依据的未来需求。心理强度没有依据时采用定性表述，不把示意强度伪装数据。

### 4. 几何生成：扩展现有生成器的约束反馈

保留 tools/gen_layout.py 与 scenes/layout.json 的既有职责，先检查已覆盖的数量、索引、邻接与接合约束，仅补缺失断言及失败信息。练习调整布局种子或布局间距等实际可安全开放的参数，146 和第 6 位固定。若当前参数不可安全开放，实施时选择显示间距练习，不放宽约束。

有效输入保证确定性；无解或约束错误明确失败，禁止覆盖有效布局。测试包含确定性、非法输入和生成结果与场景读入一致性。暂不抽取共享算法，避免将示例特有形状变成公共接口。

### 5. 示例教学：四个小练习覆盖修改路径

两个示例各增加 HOWTO.md 并从 README 链接：pigeon 移动一次非事实约束的转圈事件及修改一段取景；fold 修改一段相机路径及修改允许的几何布局参数。每个练习写出精确修改位置、预期影响、不会自动联动的字幕／常量、validate/prepare/lookdev/render 命令及恢复步骤。练习在临时目录执行，不把变体或媒体纳入 Git。

事件尽量单源，但不承诺事件表自动控制所有文字。若 fold 原有帧常量使练习容易漂移，只将练习涉及的画面和声音改为已有 eventId 查询，不扩大为新调度器。

### 6. 表达验收：复用审核策略

按 checkpoint-gates.md 和 subagent-review.md 为两个示例建立实际适用的合同和证据。核心窗先独立盲看并记录对象、变化、结果，再对照中性目标；字幕遮蔽仅作为视觉承诺的补充诊断，正常观看仍覆盖文字与声音。时间／次数与几何断言属于技术证据，认回、理解与回场属于观察证据。

轮次、人数与终审资格从既有策略派生；不新增报告字段或固定轮次。报告绑定当前候选，修改后重新准备并使相关旧证据失效。产物位于忽略目录，只提交不含媒体的验证摘要；若独立评审失败或不可执行，相关任务保持未完成。

## Risks / Trade-offs

- 教学说明变成额外表单负担 → 只补现有正文和练习，不新增作品必交文档。
- 几何约束通过但接触仍不可辨 → 保留完整动态窗口评审，必要时重设计形状。
- 为调时练习改变实验事实 → 固定喂食周期，仅移动非事实动作且保证叙事窗口有效。
- 现有示例可能需要实质返工 → 先完成核心窗，未通过不扩展精修，不降低既有门禁。
- 与 add-vibe-night-style-pack 重叠 → 本变更只负责两个 styles/examples 与通用指导；其独立作品及未完成审核保持原状态，实施前再次核对共享文件。

## Migration Plan

按“规范与断言→两个示例核心窗→教学练习→完整评审与回归”实施。无材料格式迁移。回退时按提交撤回本次示例和指导改动，重新准备受影响示例；不复用已失效证据。
