## MODIFIED Requirements

### Requirement: 最小设计记录与持续反馈

RESEARCH.md MUST 保存全片案例与全片组件调研的证据及方向比较。DESIGN.md 首版 MUST 引用研究并保存全片共同目标、采用范围、选案理由、实际视觉基线、叙事结构、场景索引与关键未知，以便判断场次贡献、信息顺序、衔接和结尾回报。对象变化、视听协同和本场验证办法 MUST 在逐场开发中按机制深化于场景文档。设计 SHALL 使用现有文档与证据入口。候选优劣与足以展开 MUST 分别判断，正式采用结论 MUST 明确通过或不通过，fail 与 insufficient 均不得采用。三阶段 MUST 允许设计、实现、观察往返。正式展开 MUST 核对新内容和完整作品的目标兑现。有效结论在成为后续标准或评审依据前 MUST 回写，局部结论归场景，影响相邻场的决定须联查衔接，跨场共用变化归总设计。每轮 MUST 聚焦主要差距，用前后实际媒体检查收益。问题沿唯一记录闭环。事实、来源、许可与用户硬约束 MUST 保留。

正式设计和制作 MUST 共用逐场循环。制作片段 MUST 以既有场景、镜头或事件定位，先核对本场目标、已有依据及关键未知，仅对改变决定的缺口补查。片段按粗排、关键过程、精修与接回上下文逐步验证。粗排 MUST 核对信息顺序、注意力、时间与衔接；关键过程 MUST 核对实际中间状态、对象关系及适用文字、字幕和声画时点；精修 MUST 逐项解决可观察的品质差距，按原条件用同一帧位或等价窗口比较，并保住已经成立的核心效果。会决定表达或选案的细节 MUST 提前采到足以判断的精度。简单片段可合并检查，观察只覆盖适用内容；不要求固定数量的候选、产物、评审轮次或新的材料字段。

#### Scenario: 全片设计与制作
- **WHEN** 展开完整设计或逐段制作
- **THEN** 助手 MUST 先组织全片骨架并优先深化可能改变全片方向或跨场组织的关键场景，其他场景随开发细化。用覆盖相关段落的全片预演核对结构、衔接及风格迁移；密集口播或紧凑阅读使用实际旁白和字幕取得适用证据。材料变化后重新准备，已确认的局部结果汇总到整片候选。

#### Scenario: 局部修订复用
- **WHEN** 只修改局部文字或数据且表达与视觉目标未变
- **THEN** 助手 MUST 复用有效研究和基线，只更新受影响场景及必要共同设计；从实际受影响的最早一层进入，按依赖复查相邻窗口、实际时间轴及适用信号；新缺口补查，不重开无关选案或补造旧记录。

#### Scenario: 复杂片段及相邻衔接
- **WHEN** 片段依赖连续动作、数据关系、身份交接或跨场配合
- **THEN** 助手 MUST 优先用足以看清关系的粗排确认核心动作与进入、退出，用覆盖高风险中间状态和相邻衔接的实际有序帧及适用信号验证，再按差距精修。结果接回实际上下文核对节奏与阅读，正式判定仍沿现有评审政策。

#### Scenario: 简明片段合并检查
- **WHEN** 片段的表达依赖已验证方案或单一简单变化
- **THEN** 助手 MUST 核对本片内容和实际观察条件，允许一次检查覆盖适用的构图、变化、阅读和衔接。现有短片在全片工程中验证核心效果，沿用适用的正式取证要求。

#### Scenario: 最佳候选仍有关键差距
- **WHEN** 相对最好候选的整体品质或实现证据不足
- **THEN** 助手 MUST 只安排主要差距的打磨或验证，不能凭排名或独立 pass 展开；均无潜力时允许全部淘汰。

#### Scenario: 无收益或资源边界
- **WHEN** 同一问题两轮修复无改善，或遇到被动中断和外部阻塞
- **THEN** 助手 MUST 换实质路线，或保留未完成并说明阻塞。试制关键帧按暂停和恢复规则执行；不得设置主动总上限、交付未通过样品，或把记录与重复评审当成通过。
