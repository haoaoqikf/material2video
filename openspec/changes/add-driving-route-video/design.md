## Context

动机和首版范围见 [proposal.md](proposal.md)。仓库已有目录驱动的类型身份、独立适配器、共享无声生命周期及渲染管线，尚无地图路线模块。新增行为依赖 core/engine，Web 只消费准备后的数据，不承担定位、取数或材料校验。

本变更已实现类型、取数客户端、离线生命周期与画面；真实取数与首例仍待授权后制作。下述接口、材料与画面为当前契约。首例不属于注册风格示例，不能新增第六个固定示例或把作品内容加入仓库。

## Goals / Non-Goals

**Goals:** 独立类型可换端点；在线取得有使用依据的真实高速优先路线后离线复现；首例验证小车贴路、平滑转向与稳定镜头。固定横屏60 fps并共享已有候选、溯源和媒体验收能力。

**Non-Goals:** 不实现 general 分镜适配、本地GPX/坐标导入、多提供方、卫星或三维地图、完整在线底图、实时路况播放、真实驾驶速度模拟、配音和音乐。本轮未核验授权，因此未真实取数、未制作首例，也未修改主规格或归档。

## Decisions

### 1. 类型与命令

- 类型 ID `driving-route`，中文名“自驾路线动画”，composition ID `DrivingRoute`。在类型目录和行为注册中登记，复用 `SilentTypeSpec` / `SilentRenderSpec`；不从 general 导入实现。
- 统一入口沿用 `init / validate / prepare / preview / render / status / review-template / review`；新增唯一辅助命令 `m2v driving-route fetch --project <目录>`，仅它允许访问高德服务。可选人工评审不变为 CLI 导出门禁；首例独立视觉评审属于制作完成条件。
- 初始化仅写模板，不发起网络请求；默认1920×1080、60 fps、30秒。`durationSeconds` 支持大于6的整数，前后各3秒，中段为剩余时长；显式输出参数冲突报错。渲染输出 `outputs/driving-route.mp4`，预演在 `outputs/previews/`，与正式成片隔离。

### 2. 两份材料与输入绑定

材料版本均从 `schemaVersion: 1` 开始；未知字段、布尔冒充数字、非有限坐标与缺少必填内容明确拒绝。共享类型目录提供模板，正式作品补齐占位后才能通过校验。

| 材料 | 最小内容 |
|---|---|
| `request.json` | `origin` / `destination`（各含 `city`、`address`、`label`），`strategy: highway-first`，`durationSeconds`，`sourceUsage` |
| `route.json` | 当前请求规范化SHA-256摘要，提供方与采集时间、`coordinateSystem: GCJ-02`，定位结果、实际路线首尾坐标，按顺序的 `steps`（道路名、分段坐标）、API总距离与来源记录 |

`sourceUsage` 是制作助手核验的使用依据记录：核验日期、政策/授权文档引用、适用账号与用途范围、是否覆盖离线保存和视频发布、署名要求。不得写入Key、账号登录凭据或授权文件中的个人敏感信息；敏感授权原件保存在仓库外，仅留非敏感引用和摘要。核验不是由API调用成功或勾选布尔值自动推定。初始化将该记录留待核验，未落实时 fetch 明确失败。

请求摘要覆盖上述全部请求内容，包括画面名称、时长及来源使用记录；不含Key。任何请求变化均按用户已确认规则要求重新 fetch，不静默重新绑定旧路线。prepare 的输入摘要覆盖两份材料和全部被引用的本地来源证据；渲染实现、字体和参数继续使用共享绑定。已保存路线能在无Key、断网环境制作，凭据不进入准备或渲染指纹。

### 3. 高德采集与使用条件

- 端点使用结构化地址及城市约束调用地理编码；仅接受与具体地点和城市一致的唯一结果，城市中心级粗匹配、歧义和无结果报错，不拿首项冒充确认。
- 驾车规划使用 v5 `strategy=34`，显式请求 `polyline`；按服务顺序保存第一条高速优先有效方案，不把“高速优先”解释为全程高速。来源记录包含API版本、策略、请求时间及不含凭据的请求参数，实际经过的高速名称以响应为准。
- HTTP设置超时，检查HTTP状态、业务状态及数据结构；失败不发布部分结果。先在临时文件校验完整结果，再原子替换 `route.json`，原路线在失败时保持不变。日志仅记录操作阶段与脱敏错误码，不回显请求URL、Key或原始异常正文；响应只保存允许且必要的数据，不保存凭据。
- 高德公开协议对存储、缓存及衍生使用存在限制；不能把普通Web服务Key视作离线视频用途已获授权。先落实当前账号/用途的适用书面授权或明确许可依据；未取得时不得真实取数和交付首例，可继续完成不依赖真实数据的代码和合成测试，相关真实验收任务保持未完成。不得通过截图、换提供方或虚构坐标绕过此条件。

参考依据（2026-10-30核查）：[驾车路径规划2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)、[地理编码](https://lbs.amap.com/api/webservice/guide/api/georegeo)、[平台服务协议](https://lbs.amap.com/pages/terms/)、[技术服务使用许可协议](https://lbs.amap.com/pages/authorization/)。接口文档仅支持技术选型，不作为离线保存与发布授权证明。本提案未验证任何具体账号授权，也未获取真实路线。

### 4. 几何、运动与相机

- 全部空间对象使用同一来源GCJ-02坐标，经一致的Web Mercator局部投影绘制；不混入WGS84底图或行政边界。首版图层只含真实路线、端点、道路标签与必要署名，不补造真实城市路网。
- 校验经纬度范围、坐标数量与正路线长度，去除连续重复点；相邻step端点允许25米以内的服务采样差异，超出时报段号并拒绝，不插入长跨接线。每个真实路线端点须距对应定位点不超过1公里，否则拒绝。保留定位坐标与实际吸附端点，车与端点标记使用实际路线首尾，不画虚构的接驳线。
- 准备累计地表距离数组；按帧计算中段进度和目标距离，二分定位线段再插值。沿行驶阶段使用匀距离推进，进出阶段平滑起停；显示距离仅使用API返回值，不把投影长度冒充实际公里数。首版不简化路线，避免简化造成切弯；必要时后续基于性能证据再设计。
- 位置始终在路线折线上；朝向由沿线前后取样方向计算，使用单位向量平滑方向，避免角度跨越±180度跳转。方向取样窗口为总长度的0.1%，限制在20～200米；取样方向相消时使用当前非零线段切向，不能依赖上一帧。只平滑朝向，不平滑位置。已走路径与小车共用同一插值终点。
- 深蓝底、灰蓝未行驶路线、青色已行驶路线、浅色矢量小车。地点和道路使用中文，主要道路标签按连续道路段合并，并避让车辆与端点；普通道路名不冒充高速名。字体沿用仓库登记字体，不回退系统字体。
- t=0～3秒全程视图；行驶段相机保持北向，目标取车辆前方沿线位置，缩放为全程视图的2.5倍，前1秒由全程平滑进入跟随；最后3秒车辆停在终点，前2秒平滑回全程、最后1秒稳定保持。相机、车、标签与进度均为当前帧的纯函数，不累积上一帧状态。全程取景为路线包围盒加标签安全边距，开场和收束完整显示路线及两端；跟随时车始终可见，当前视域内承担信息的道路与地名不得被不合理裁切，不要求远处端点一直留在画内。

### 5. 首例、验证与完成边界

首例制作时初始化 `videos/driving-route/shanghai-to-zhengzhou/`，上海端为“上海市黄浦区人民广场”、郑州端为“河南省郑州市二七区二七广场”，分别显示“上海”“郑州”。地址用于真实定位，提案不预填猜测坐标、具体经过高速或里程。默认总1800帧，首尾各180帧、中段1440帧；帧区间采用半开区间，最后行驶帧须已到达终点，以防终幕出现补跳。

Python用脱敏合成服务响应测试采集、失效与错误；前端用明确标为合成的测试轨迹验证距离推进、转向、镜头与随机帧重现，合成数据不写入首例。接入后运行相关金融/general回归、前端类型检查与构建。真实首例先准备及局部预演，再生成一个完整候选，技术验收后按当前候选安排独立视觉评审；静帧/时间标注帧序列不覆盖的动态问题补充窗口证据，不声称看过未查内容。

验收分别报告“能力实现与自动测试”“真实采集前置条件”“首例制作通过”；Key或使用依据缺失时后两项不得关闭，也不得归档整个变更。授权满足后保存发布说明及适用署名，闭环必改项。作品内容与媒体不入库，五个风格示例仅作回归，不重制。

## Risks / Trade-offs

- [接口可用但离线用途授权不明确] → 在真实采集前核验并留证；条件不满足保留未完成任务，不改选案冒充已满足。
- [城市级定位或路线吸附造成端点误解] → 采用明确地点与城市约束，保留定位及实际端点，粗匹配/过远吸附失败。
- [急弯、密集路点与跟随视角抖动] → 距离求值、位置贴线、朝向向量平滑、纯时间相机与局部高密度时序复核。
- [长路线性能] → 准备一次累计数组，逐帧二分定位；SVG路线复用，避免每帧重投影全部坐标。用真实首例量测，再决定是否有必要另提简化方案。
- [声称新能力已落地或误扩大首版] → README、ARCHITECTURE 与指南只描述已实现链路；真实授权、取数与首例状态分开报告，不用合成首例关闭验收。

## Migration Plan

这是增量类型，不迁移金融、general或已退役住宅材料。apply 已完成实现与共享入口接线；真实取数与首例仍须先落实来源依据。全部任务完成且验证与提交通过后自动同步主规格并归档。回退移除新增注册和专用实现，保留用户作品，不引入旧契约兼容层。
