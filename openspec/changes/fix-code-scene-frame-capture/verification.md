# 验证与审查记录

## 核心结论

共享录制已切换到顺序帧推进，删除实时 screencast、concat 时间戳重采样和尾帧补齐。React 上下文由帧号推导，动画库和 R3F 使用受控时钟；CSS 与本地视频在截图前同步。旧录制缓存因采集标识和实现指纹变化失效。

## 已核实的行为

- 真实浏览器逐帧检查匀速 DOM 位移、R3F 网格位置、Motion 透明度、GSAP 位移及 CSS 动画；人为等待 180 ms 后截图保持一致。
- ECharts 三个时间点画面不同，定时器执行次数正确；视频入点、倍速、循环、暂停和恢复均按受控时间定位。
- 重复或跳跃帧号被拒绝，缺失 PNG 不编码；真实绘制超时不依赖冻结的作品时钟。原有外网、异常、就绪失败和缓存复用测试通过。
- 三个固定示例完成代表片段采集，缓冲和试错各 180 帧，太阳系 1080 帧；抽帧检查布局，太阳系连续序列覆盖近景拉回总览。
- 重复帧判据：把片段缩到 192×104 灰度，统计相邻帧平均像素差 ≤ 1e-6 的**最长连续段**。同一 174.6 秒太阳系场景，旧实时 screencast 片段 591 对重复、最长 207 帧（3.45 秒）；受控逐帧采集片段 506 对、最长 85 帧（1.42 秒）。先前记录的「0.04 阈值」在同一窗口对两支片段都判为几乎全部低于阈值（各 47/47），无法区分慢速运镜与重复帧，已不再作为判据。
- 完整交付：太阳系示例按受控逐帧采集实现重新执行 prepare、完整 preview 与正式 render（退出码 0），交付 `videos/examples/solar-system-journey/outputs/video.mp4` 及 `video.provenance.json`、`video.performance.json`。成片 60 fps、10476 帧、174.6 秒、1920×1080，准备指纹与当前准备记录一致，渲染 3154.9 秒，画面解码帧数、尺寸、帧率、时长与音轨时长（174.6 对 174.6 秒）均在验收容差内。
- 交付成片技术检查：重复帧最长连续 1.63 秒（重复帧对占比 5.55%）、暗部无量化色带、字幕对比度 19.43:1、母版 −17.3 LUFS/−1.1 dBTP、音画时长零差；检查项全部通过。

## 逻辑、性能与影响

公开 CLI、v8 分镜与作品上下文接口保持不变；改变录制实现与内部顺序推进接口。动态时间由受控时钟推进，机器负载只增加采集耗时；预演和正式导出继续复用同一录制片段。视频服务器启用原有 Range 支持，确保 seek 不被浏览器钳到零。

PNG 每帧落盘并在工作目录生命周期结束后清理，内存不累计全片图像。新增成本是每帧绘制屏障、PNG 采集与编码后解码计数；空间与耗时随帧数线性增长，优先保证运动完整性。采用快速 PNG 压缩和单次异步推进，减少压缩与轮询开销。

## 剩余边界

不支持倒序或任意跳帧，不承诺任意异步、随机作品的逐像素重现。抽帧与连续画面序列检查不能替代全片人工播放或音色试听；本次不把技术验收写成完整试听通过。

重复帧判据只对「同一素材、同一时间窗」的前后对比有意义：慢速运镜与刻意停顿同样会压低相邻帧差值，因此它不能单独判定某支成片的镜头是否静止。

审查未发现当前验证范围内的阻断问题；最终出片数据与验证命令结果已在本文件补记。
