## Context

动机见 [proposal.md](proposal.md)。现有示例集合与画幅、字体检查包含旧例的硬编码引用；固定示例规格还约定三片合计覆盖 Motion、ECharts、GSAP、Three.js、React Three Fiber 与 Drei。本次跨示例、文档和测试调整，需要先核定轨迹表达与制作验收设计。

## Goals / Non-Goals

**Goals:** 用连续车辆运动解释一个现象；实现同一数据驱动的画面与图表、确定性录制、真实旁白同步和可复核的运动证据。

**Non-Goals:** 不建设交通仿真产品、真实城市路网、驾驶建议或普遍治堵方案，不改变公共接口、依赖和共享录制契约。

## Decisions

### 1. 内容与证据

采用 topic 输入，以杉山等人2008年论文为核心依据，在 SOURCES.md 保存论点、原文位置、来源及使用边界：[论文](https://ir.library.osaka-u.ac.jp/repo/ouka/all/93262/NewJPhys_10_033001.pdf)。画面采用原创示意，不直接复现论文数值。文案强调在一定车流条件下扰动可能放大；标题以城市提问切入，正文明确只解释一种机制。

### 2. 镜头和美术

沿用1080×1920竖屏，以浅色路面、深色车辆、红色制动灯和蓝色传播箭头构成主要识别。道路为纵向椭圆，标记车用独立描边。先提出浅色实验台与深色夜路两个方向，选浅色实验台作为正式方向，夜路仅作设计比较，不制作双版本。

| 参考秒数 | 内容和动作 |
|---|---|
| 0～5 | 走走停停的车流直接入场，提出无事故为何堵车 |
| 5～15 | 拉远至完整环路，交代无红灯、事故和瓶颈 |
| 15～32 | 明示回放到初始状态，跟随一次减速，局部放大车距 |
| 32～50 | 返回整体视角，跟踪编号车并显示拥堵反向传播 |
| 50～65 | 上下并列两种密度，同一扰动条件下比较演化 |
| 65～75 | 回扣限定结论，短暂停留，唯一片尾署名 |

上述为预算，不硬编码旁白秒数；最终60～90秒由实际TTS窗口核定。开场、局部放大、方向分离、结尾各生成关键画面。重要主体和自绘文字避开共享字幕区域，不靠重复信息卡片推进。

### 3. 确定性示意数据

使用作品内离线生成的轨迹关键帧，记录时间、车辆ID、沿路累计位移、速度和制动状态；数据与生成脚本随示例入库。环路映射采用累计弧长，避免椭圆参数角速度造成假的加减速。画面按录制时钟与 segmentWindows 采样，禁止实时计时和随机运动。

轨迹使用按车序延迟的平滑减速脉冲构造；高密度组下游响应逐步放大后恢复，低密度组逐步衰减。两组固定道路、车长、初始速度、首车减速幅度和持续时间，仅车辆数量与由此产生的响应不同；响应是说明现象的预设，不作为模型预测。车距不足或出现负速度时生成失败，不以穿车或瞬移掩盖问题。所有插值区间检查安全间距，不只检查关键帧端点。

局部车距与速度图表直接派生自同一采样结果，制动灯对应速度下降；不独立编造另一套图表曲线。相机回放与布局变化不改变车辆身份。制动区域依车辆相继减速自然后移，箭头跟随该区域，不以箭头替代真正的传播运动。

使用SVG绘制道路车辆，GSAP承担聚焦与方向标记，ECharts承担密度对照中的示意速度曲线；Motion承担必要的标注进出。实现前审计其余两例的实际覆盖，避免只靠导入或注释满足库覆盖。

### 4. 声音与制作复核

按完整中文旁白及当前音色服务元数据选择音色并保存理由与摘要，不继承旧例音色选择记录；无配乐，仅在扰动开始和方向揭示时使用少量内置提示音。字幕沿用共享烧录链路。

先做四张关键画面、整片动态粗预演及局部减速和双组对照风险样片，再精修全片。复核车辆无追尾、编号连续、制动灯与减速同步、车辆与波方向分离；最终按时间标注帧序列、运动量测、字幕与自动音频信号检查记录时间码和问题关闭证据。无需播放或连续收听，明确采样间运动与主观听感覆盖限制。

## Risks / Trade-offs

- 预设轨迹容易被误认为实验数据 → 场内标注示意，来源材料说明构造方法与科学结论边界。
- 密度对照被解读为严格控制实验 → 明确为同扰动条件的原理示意，文案不宣称因果定量验证。
- 环路交界、插值或放大导致穿车 → 检查环回车距与插值区间，风险样片覆盖最小车距和镜头切换。
- 信息过密 → 同屏优先展示一个解释层，双组对照减少文字并保留字幕空间。
