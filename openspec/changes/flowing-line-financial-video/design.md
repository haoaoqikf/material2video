## Context

共享组件目前按 prices.schemaVersion 分支为折线和 K 线。金融材料独立于文章流程，原始行情和作品产物被 Git 忽略。动机见 proposal.md。

## Goals / Non-Goals

目标：唯一折线契约、连续滚动、可追溯迁移和全貌收尾。保持横屏无声与事件事实含义，不更新英伟达数据截止日，不更动文章示例结构。

## Decisions

- 价格和动画升级至 version 3，需求和事件保留 version 1。拒绝旧版渲染，显式 migrate-line 备份后仅取 date/close，避免降级为旧折线而绕过新门禁。
- 计划默认 60 秒、12 月视窗；开场 90 帧、每事件 90 帧，末尾 60 帧 overview 和 120 帧 ending；其余推进按日历跨度分配，采用最大余数分配保证覆盖总帧数，同日事件不产生空推进段。
- 横轴使用连续日历位置，读数使用向下取整的实际日期；纵轴以最近六帧的已揭示窗口范围加权平滑，始终包含当前窗口极值及边缘连线几何；边缘几何不作为历史报价。全貌展开的纵轴同时包含当前可见曲线包络，避免早期低价被裁出。随机寻帧不依赖播放历史。全貌以 smoothstep 展开起点及纵轴至全历史范围，避免硬切。
- 渲染只接受 version 3；新增 preview 子命令写入 previews，完整预演文件摘要与材料/资产摘要共同绑定评审。预演不授予正式成片资格，完整评审通过后再 render。
- 每帧滚动阶段二分定位后处理窗口内点；全貌最多处理完整本地序列。约七千点不引入额外图表库或随机抽样。

## Risks / Trade-offs

- 27 年压缩至 60 秒，无法逐日阅读 → 价格读数来自真实点、保留事件暂停并通过完整预演评审。
- 线性全貌压缩早期波动 → 主体用近期自适应轴，结尾真实展示长期幅度。
- 旧材料不能直接渲染 → 提供备份及迁移；旧成片仍可查看。

## Migration Plan

先验证和备份四份材料，再写入 version 3 价格及新计划；失败恢复原材料。旧评审保留在备份，新评审模板保持 pending。英伟达输出独立命名，验证后提交共享实现并归档规格。
