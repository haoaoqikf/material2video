# 实施审查与验证（2026-10-18，替代验收版）

范围：`qa_inspection` 全片采样/音频候选、`qa` 报告整合、CLI/清理文案、字幕 40px、太阳系示例返工与音频前导留白修复，以及配套测试和文档。本文取代修订前的审查记录，不能把修订前结论当作新检测已完成的依据。

## 主要结论

- 替代验收已接线：`m2v qa` 对交付文件生成逐秒、逐镜头起中末、交界与异常/hero 加密采样，分页接触表覆盖片尾；视频侧登记黑场/突变候选，音频侧登记静音/削波/旁白越界候选。报告明确 `scope=technical-only`、`observation=not-evaluated`，候选不参与 CLI 门禁。
- 真实太阳系成片 QA 通过：531 采样、34 页，0.00–63.72 秒；无黑场/突变候选；音频仅片尾 63.10–63.74 秒静音（收尾留白）；响度 −14.6 LUFS / −3.6 dBTP；claims 时间窗覆盖通过。`m2v qa` 用时约 13 秒（检测本身 7.9 秒），低于 60 秒性能目标。
- 全片复查发现并关闭的必改问题：
  1. `水星几乎没有大气` 与 `天王星几乎侧躺着自转` 的旁白窗口内主体从未入画。两段连续镜头改为先经过对应天体再拉焦到金星/海王星，标签与信息卡随旁白切换，保留单一连续路径。
  2. 第 1675 帧（27.92 秒）单帧整帧白闪。QA 的突变候选准确定位；在代码片段缓存内同帧复现；逐一排除 DOF、小行星带种子/数量、smoothstep 反向边界与地球法线贴图后，确认关闭木星镜头 Bloom 即消失。现以该镜头 `bloom: 0` 交付，其余镜头保留原后期。
  3. 旁白整体比字幕/画面提前 5 秒：`leadInFrames=300` 只写进了镜头与字幕账本，拼接音轨时没有写入前导留白，导致结尾两句听感上像缺声。已在 `explainer_prepare` 中为每幕前导留白写入真实静音，并新增 `test_narration_audio_starts_after_lead_in_frames`；新母版首句从 5.0 秒开始，`edge-0` 三句回到 50.5–56.7 秒。
- 清理证据例外按记录中的直接文件链接保留当前 `visual-notes.md`、风险窗/前后对照与参考图；未链接的历史大体积产物仍按原规则清理，清理不越出作品输出目录。
- 文档与校验器同步替代验收口径：Skill、制作流程、cinematic、视觉复核模板、README、字幕 40px 与示例说明均改为帧序列/自动音频；旧完整播放/试听记录标为历史，未写成规划已实现。

## 逻辑与性能影响

新增报告字段与候选不改变既有技术判定、退出码或导出门禁。QA 增加三次流式解码（候选、音频、采样），不把全片音频/全分辨率帧累积在内存；音频只保留半秒块，采样图像落盘，接触表分页。`leadInFrames` 修复只改变音轨前导静音，不改变镜头、字幕或成片时长。示例返工只改运动/后期与两处动态焦点函数；性能仍由 60 fps 录制与编码主导。

## 剩余风险与未完成

- 单帧白闪的根因没有完全定位到具体像素/着色器，只确认由木星镜头 Bloom 触发；关闭 Bloom 是可复现的消除方式，但同源的极亮像素若出现在其他镜头仍可能复发，后续应以 QA 突变候选继续监控。
- 未连续播放、未实际试听：配音自然度、口播误读、音乐感染力与采样间瞬时缺陷仍属于覆盖有限项。
- 抖音公开页面未提供可读取的横屏遮挡尺寸，平台遮挡未实测；手机可读性按 390/480px 宽预览检查。
- 冥王星心形出现偏晚、大红斑位置偏侧、远景细节与奥尔特云软边界作为可选/待观察项披露。

本次代码质量评分：92/100。扣分来自白闪根因未完全定位、跨 GPU/播放器实测有限，以及视觉复查仍依赖采样覆盖。
