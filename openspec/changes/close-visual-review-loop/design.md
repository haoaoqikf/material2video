## Context

动机见 [proposal.md](proposal.md)。当前技术 QA 能判定冻结、字幕配色对比度、响度及时间窗等机械条件，画面测量不构成审美判定；观看记录和 CLI 导出本来就分离。相关主规格还存在旧评审阻断规则与现行无人工导出门禁规则并存的问题，本变更仅消除与 general 视觉闭环直接冲突的要求。

## Goals / Non-Goals

**Goals:** 以最少新增机制落实助手自主评审，统一默认抖音横屏语境，建立有效版本上的问题复查和完成依据。

**Non-Goals:** 不增加平台发布能力、外部视觉模型、视觉评分卡或用户审批；不把抖音语境写成金融/住宅画幅默认值；不改变分镜版本、渲染器与素材导入契约。

## Decisions

### 1. 平台属于创作约定，画幅沿用现有契约

general 未指定平台时在 DESIGN.md 记录抖音，未指定画幅时采用 1920×1080、60 fps；显式配置优先。不为平台新增 project.json 字段或 CLI 参数。实施时查阅当时可访问的平台官方资料，记录日期与来源；界面遮挡以有来源的观看示意检查，不编造固定像素安全区。资料不可得时披露不确定性，不能宣称已完成平台实测。开场及时表达主题，时长按内容决定，不统一强制 60 秒。

### 2. 风险驱动样片，由助手自主搜集参考

DESIGN.md 记录受众、观看尺寸、表达目标、风险列表和参考来源。每条参考注明用途（事实或视觉）、具体维度、访问日期；参考不能直接视为入片授权。优先可靠原始资料；未找到合适材料时扩大检索或调整方案，记录缺失，不能虚构已参考。声音和运动参考无法播放时不能声称已试听或观看。

standard 至少覆盖开场、核心难点和结尾，可合并为一段；cinematic 保留现有 3–5 张原生 4K 静帧、20–30 秒有声样片和至少 3 个 8–12 秒连续 hero。单段样片未覆盖的高风险章节补独立短片。静帧用于材质/构图，动态片段用于运动，试听用于声音；最终参数的片段用于交付判断，4K 静帧不替代 1080p 动态检查。

### 3. 复用 Markdown 记录，不新建审批系统

沿用 outputs/visual-notes.md。每次检查记录准备指纹、检查对象与 SHA-256、时间范围、方式（静帧/连续播放/试听）及结论。问题包含稳定 ID、时间码或范围、维度、严重度、现象、参考差距、修改措施、状态与复查依据。严重度分必改与可选：影响理解、主体识别、文字阅读、旁白主张可见性或存在明显视听异常为必改。状态为未解决、待复查、已关闭；重新渲染不得自动关闭。

准备指纹变化时，当前通过结论失效；可以复用历史问题描述，但必须对受影响范围重新复查。最终完整复核同时绑定交付 MP4 的 SHA-256，文件被替换即失效。全局材质、运镜、字幕或混音变化后重新全片看听。没有可用的连续播放或试听能力时报告未完成，不以抽帧/响度替代。

不新增机器可执行的视觉通过字段或用户确认文件。现有 status 的“可导出”只表达技术就绪，不表达助手已经完成视觉复核；相关文案需消除歧义。

### 4. 完成判定属于助手工作流，不改变导出门禁

流程为目标/参考 → 风险样片 → 返工复查 → 全片 → 最终完整复核 → 自主交付。样片必改项关闭后才铺全片；缺失检查能力时允许生成诊断/检查产物，但不能宣称阶段通过。最终技术验收通过、观看记录有效、必改项全部关闭且完成全片看听后，可自主标记完成。可选项可携说明交付。

同一问题连续两次修改复查均无明显改善，必须变更素材或实现方法，并记录依据；替代方案仍失败时停止无效循环，报告未完成和限制。不要求用户批准继续。该约束不移除用户主动反馈渠道，也不取消业务输入本身的真实性核验。

### 5. QA 明确区分可证明的事实

沿用 qa.json 的现有技术检查键及退出码语义，补充报告级范围说明和各检查的判定/测量性质；不依赖视觉观察控制 CLI 退出码。claims 现有键仅表示时间窗覆盖，不改写为识别成功；实际特征可见性进入观看记录。banding/aliasing 等测量无可靠内容通用阈值时保持测量项，不能列为自动通过。字幕颜色对比度和音轨时长一致不等同实际可读性和语义音画同步。报告及文档均明确这些限制。

## Risks / Trade-offs

- 模型可能误判美感 → 使用具体参考、同位置前后对照和问题证据；不承诺流程能消除能力限制。
- 完整观看能力不可用 → 如实保留未完成状态，不虚构观看；可交付检查产物和限制说明。
- 增加制作耗时 → standard 使用少量风险样片，cinematic 保持专项检查，连续两轮无改善时改变方法。
- 输出清理可能删除依据 → 实施时核对清理规则；保留当前 visual-notes、当前检查依据及前后对照在作品忽略目录，历史大体积检查产物按原清理规则处理。

## Migration Plan

先更新制作规则、QA 范围说明与相关检查，再同步 README、参考文档及示例说明。旧用户确认仅作为历史，不再授权新版本完成；旧观看记录缺少指纹或摘要时按过期处理，不编写迁移工具。当前材料版本不升级。回退使用针对本变更的 Git revert，不覆盖作品媒体。

太阳系作品保持横屏，先保存基线和时间码，再针对地球/土星材质、外行星可见性、手机文字及结尾制作风险样片；完整重制后以实际前后对照和全片复核验证。只更新既有三个示例，不新增示例。内容和媒体不入库。
