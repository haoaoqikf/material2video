## Context

动机见 [proposal.md](proposal.md)。当前技术 QA 能判定冻结、字幕配色对比度、响度及时间窗等机械条件，画面测量不构成审美判定；观看记录和 CLI 导出本来就分离。相关主规格还存在旧评审阻断规则与现行无人工导出门禁规则并存的问题，本变更仅消除与 general 视觉闭环直接冲突的要求。

## Goals / Non-Goals

**Goals:** 以最少新增机制落实助手自主评审，统一默认抖音横屏语境，建立有效版本上的问题复查和完成依据。

**Non-Goals:** 不增加平台发布能力、外部视觉模型、视觉评分卡或用户审批；不把抖音语境写成金融/住宅画幅默认值；不改变分镜版本、渲染器与素材导入契约。

## Decisions

### 1. 平台属于创作约定，画幅沿用现有契约

general 未指定平台时在 DESIGN.md 记录抖音，未指定画幅时采用 1920×1080、60 fps；显式配置优先。不为平台新增 project.json 字段或 CLI 参数。实施时查阅当时可访问的平台官方资料，记录日期与来源；界面遮挡以有来源的观看示意检查，不编造固定像素安全区。资料不可得时披露不确定性，不能宣称已完成平台实测。开场及时表达主题，时长按内容决定，不统一强制 60 秒。

### 2. 风险驱动样片，由助手自主搜集参考

DESIGN.md 记录受众、观看尺寸、表达目标、风险列表和参考来源。每条参考注明用途（事实或视觉）、具体维度、访问日期；参考不能直接视为入片授权。优先可靠原始资料；未找到合适材料时扩大检索或调整方案，记录缺失，不能虚构已参考。运动参考可使用来源提供的帧序列辅助构图与轨迹对照；不能声称实际试听。未实际检查的参考只记录来源，不写成对照通过。

standard 至少覆盖开场、核心难点和结尾，可合并为一段；cinematic 保留现有 3–5 张原生 4K 静帧、20–30 秒有声样片和至少 3 个 8–12 秒连续 hero。单段样片未覆盖的高风险章节补独立短片。静帧用于材质/构图，帧序列用于检查位置、尺度、朝向、曝光与转场变化；声音使用自动信号检测和现有旁白时间戳。最终交付文件的采样用于完成判断，4K 静帧不替代交付分辨率的帧序列检查。

### 3. 复用 Markdown 记录，不新建审批系统

沿用 outputs/visual-notes.md。每次检查记录准备指纹、检查对象与 SHA-256、时间范围、方式（静帧/帧序列/自动音频检测）及结论。问题包含稳定 ID、时间码或范围、维度、严重度、现象、参考差距、修改措施、状态与复查依据。严重度分必改与可选：影响理解、主体识别、文字阅读、旁白主张可见性或存在明显视听异常为必改。状态为未解决、待复查、已关闭；重新渲染不得自动关闭。

准备指纹变化时，当前通过结论失效；可以复用历史问题描述，但必须对受影响范围重新复查。最终替代验收绑定交付 MP4 的 SHA-256，文件被替换即失效。全局材质、运镜、字幕或混音变化后重跑全片替代验收；局部改动复查受影响范围。取消连续播放与实际试听前置要求，缺少播放接口不再阻碍完成；采样或自动检测缺失、异常未复查仍不能宣称完成。

不新增机器可执行的视觉通过字段或用户确认文件。现有 status 的“可导出”只表达技术就绪，不表达助手已经完成视觉复核；相关文案需消除歧义。

### 4. 完成判定属于助手工作流，不改变导出门禁

流程为目标/参考 → 风险样片 → 返工复查 → 全片 → 最终完整复核 → 自主交付。样片必改项关闭后才铺全片；缺失检查能力时允许生成诊断/检查产物，但不能宣称阶段通过。最终技术验收通过、替代检查覆盖全片且记录有效、异常候选已逐项复查、必改项全部关闭后，可自主标记完成。交付准确表述为“通过帧序列与自动音频检查”，不声称连续观看、试听或配音自然度达标。可选项可携说明交付。

同一问题连续两次修改复查均无明显改善，必须变更素材或实现方法，并记录依据；替代方案仍失败时停止无效循环，报告未完成和限制。不要求用户批准继续。该约束不移除用户主动反馈渠道，也不取消业务输入本身的真实性核验。

### 5. QA 明确区分可证明的事实

沿用 qa.json 的现有技术检查键及退出码语义，补充报告级范围说明和各检查的判定/测量性质；不依赖视觉观察控制 CLI 退出码。claims 现有键仅表示时间窗覆盖，不改写为识别成功；实际特征可见性进入观看记录。banding/aliasing 等测量无可靠内容通用阈值时保持测量项，不能列为自动通过。字幕颜色对比度和音轨时长一致不等同实际可读性和语义音画同步。报告及文档均明确这些限制。

### 6. 帧序列与自动音频替代验收

复用 ffmpeg、本地准备时间轴和 qa 入口，不新增服务、外部识别模型、用户确认、平台字段或 CLI 导出门禁。QA 继续输出技术结论与测量/异常候选；助手查看图像并关闭问题。原 observation 未执行的结论不会自动升级成审美通过。新增检查使用当前成片，而非仅检查合成前母版音轨。

- **逐镜头覆盖**：全片每秒一帧，补首尾帧和每个镜头的起/中/末帧；镜头交界前后各 0.5 秒按 0.1 秒加密。风险样片及自动异常附近同样按 0.1 秒补帧。时间戳去重并限制在实际帧范围内，长片按时间段分页接触表，不丢弃尾段。全部登记采样时间及图像路径。
- **可视复核**：查看接触表及必要的交付分辨率原帧，与参考和同时间码旧版对照。检查主体大小、位置、朝向、曝光及镜头承接；手机尺寸预览检查文字。只能得出采样覆盖范围内的连续性结论，不保证每帧流畅。
- **异常候选**：复用冻结检测；用 ffmpeg blackdetect 与帧间突变测量定位候选。初始黑帧参数 d=0.1、pix_th=0.10、pic_th=0.98，突变参考阈值 scene=0.3；这些仅用于定位，加密抽帧后结合预期镜头和深空背景判断。正常黑底、静止、淡入淡出或计划硬切可记为符合设计，不因候选直接判失败；检测执行失败不得写成零异常。
- **音频检测**：对交付音轨读取响度/真峰值、削波候选、静音区间和时长。静音候选使用 silencedetect 的 -45 dB、持续 0.5 秒，削波候选统计绝对幅值达到 0.9999 的样本；不能将候选等同确定失真。结合准备记录的旁白区间、词时间戳和设计停顿复查首尾/分段，发现时间戳越界、语音区间缺声或截断风险时生成必改项。没有音轨且契约允许时明确不适用；有声作品检测不到音轨即失败。
- **报告与证据**：qa.json 补充全片检查范围、采样清单和带时间区间的图像/音频候选。保留原技术键及退出码含义，新增候选不直接作为 CLI 门禁；已存在的响度、冻结等硬判定继续生效。visual-notes.md 逐项记录候选处置及前后对照，直接链接需要保留的图像/检测报告文件，不能只链接目录。覆盖、采样与音轨分析可以由工具证明；图像含义由助手实际查看，完成结论不由脚本自动填充。

验收必须覆盖构图/材质、逐镜头轨迹、手机文字、claims 和上述音频信号项。配音误读、自然度、音乐感染力以及采样间瞬时异常属于覆盖有限项，交付披露，不能虚构已听取或将其重新设成播放门禁。缺少旁白词时间戳时按可用分段边界做信号复核并披露粒度，不能宣称已经验证口播文字。

## Risks / Trade-offs

- 模型可能误判美感 → 使用具体参考、同位置前后对照和问题证据；不承诺流程能消除能力限制。
- 采样无法覆盖所有瞬时缺陷，自动检测无法判断配音自然度/音乐感染力 → 交界与异常位置加密，披露覆盖限制；主观听感不作为本次完成门禁，不能因此要求用户确认。
- 增加制作耗时 → standard 使用少量风险样片，cinematic 保持专项检查，连续两轮无改善时改变方法。
- 输出清理可能删除依据 → 实施时核对清理规则；保留当前 visual-notes、当前检查依据及前后对照在作品忽略目录，历史大体积检查产物按原清理规则处理。

## Migration Plan

先更新制作规则、QA 范围说明与相关检查，再同步 README、参考文档及示例说明。旧用户确认仅作为历史，不再授权新版本完成；旧观看记录缺少指纹或摘要时按过期处理，不编写迁移工具。当前材料版本不升级。回退使用针对本变更的 Git revert，不覆盖作品媒体。

太阳系作品保持横屏，先保存基线和时间码，再针对地球/土星材质、外行星可见性、手机文字及结尾制作风险样片；重制后以同时间码前后对照、全片帧序列与自动音频检测验证。只更新既有三个示例，不新增示例。内容和媒体不入库。
