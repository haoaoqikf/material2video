## MODIFIED Requirements

### Requirement: 免费数据与价格口径
流程 MUST 使用无需账号或付费密钥的公开免费来源和交易日日线收盘数据。股票默认 MUST 采用仅拆股、合股调整且不计分红再投资的价格；指数 MUST 使用来源明确的官方点位并标明指数类型。流程 MUST 区分前复权、后复权、含分红调整收盘价与仅拆合股调整价，不得静默混用。价格材料 MUST 使用 schemaVersion 3，日线点只包含 date 和 close。请求 MUST 记录投资年份和正数本金；缺省投资年份为实际展示范围首年，缺省本金为 1,000,000 标的计价单位。投资年份 MUST 在展示范围内且必须存在至少一个真实交易日收盘价。

#### Scenario: 可获得可靠的拆合股调整数据
- **WHEN** 来源提供符合口径的价格，或原始收盘价及拆合股资料足以可靠推导
- **THEN** 流程记录调整定义和推导依据，并将真实收盘价作为组合市值计算依据

#### Scenario: 只有不符口径的调整数据
- **WHEN** 来源只有含分红调整价、定义不明的 adjusted close 或其他不符口径序列
- **THEN** 流程说明差异并请求用户选择替代口径，未确认前不继续制作

#### Scenario: 指数数据
- **WHEN** 用户指定指数且其序列与发布机构定义可核对
- **THEN** 画面以指数点位比例模拟价值，并在统计口径中说明指数不能直接持有

#### Scenario: 投资参数缺省或无效
- **WHEN** 请求未声明投资参数，或投资年份、本金无效及该年没有有效交易日
- **THEN** 未声明时采用展示范围首年和 1,000,000 计价单位；无效设置则指出字段并阻断材料校验

#### Scenario: v6 动画计划生效
- **WHEN** 制作仍使用 v6 折线计划
- **THEN** 阻断并提示显式备份迁移到 v7，再重新完成手机缩放评审

#### Scenario: v7 动画计划生效
- **WHEN** 制作使用 v3 价格和 v7 折线计划
- **THEN** 按连续推进的假设投资价值折线、分阶段扩展横轴及动态纵轴和完整预演评审规则验收

#### Scenario: v4 动画计划生效
- **WHEN** 制作仍使用旧 v4/v5/v6 折线计划
- **THEN** 阻断并提示显式迁移到 v7 后重新完成完整预演

### Requirement: 竖屏持续折线场景
所有金融视频 MUST 使用 1080×1920、30 fps 单标的持续场景，显示标的、完整日期范围、当前日期及假设投资指标；MUST 不展示股价数值、股价折线或事件与 K 线。投资年份首个有效交易日收盘价 MUST 作为买入价，持仓比例为本金除以买入价。投资起点之前 MUST 隐藏组合价值曲线及收益指标；之后 MUST 以最近已揭示的真实收盘价计算组合市值、收益金额（市值减本金）与收益率（收益金额除以本金）。折线及纵轴 MUST 使用已揭示的组合市值；不插值报价、不使用未来价格。横轴 MUST 从开头展示首阶段范围，左边界固定，右边界分阶段平滑扩展；历史曲线持续保留。纵轴 MUST 根据已展示的组合市值极值自适应，上下各留白 8%；单点或恒定组合价值使用其绝对值 1%（至少 0.01）作为半跨度，轴下限不得低于零。纵轴使用因果确定性平滑且不因未来数据改变。当前市值标注 MUST 与最新真实数据点同步更新并定位在该折线端点附近。休市日沿用最近真实收盘价所推导的组合价值。

#### Scenario: 年度买入及动态投资指标
- **WHEN** 时间轴到达投资年份首个交易日及其后各有效交易日
- **THEN** 使用该年首个真实收盘价作为买入价，按已到达的真实价格更新组合价值曲线、市值、收益金额和收益率

#### Scenario: 投资起点之前
- **WHEN** 播放日期早于买入日或尚未到达买入日收盘
- **THEN** 不显示投资价值曲线、市值、收益金额或收益率

#### Scenario: 休市日及任意寻帧
- **WHEN** 播放日期为休市日或跳转到任意帧
- **THEN** 沿用最近有效收盘价计算组合值，同帧结果与顺序播放一致且不读取未来价格

#### Scenario: 组合价值新高与回落
- **WHEN** 已揭示组合价值出现新高、新低或明显回落
- **THEN** 纵轴及时容纳全部已揭示的组合价值，历史曲线不被裁切且范围不读取未来值

#### Scenario: 固定横轴逐步揭示
- **WHEN** 播放多年历史投资视频
- **THEN** 第一阶段范围从首帧可见，左边界不变，同一日期横坐标随扩展平滑变化，历史点保留且未来点不提前出现

#### Scenario: 新极值与回落
- **WHEN** 已揭示组合价值出现新高、新低或明显回落
- **THEN** 纵轴及时容纳新极值并保留全部历史曲线，不缩到仅容纳近期价值

#### Scenario: 恒定与低价
- **WHEN** 只有单点、相同价格或低价序列
- **THEN** 派生组合价值纵轴严格递增、有留白且刻度不重复

#### Scenario: 休市与空起点
- **WHEN** 尚无已到达买入日收盘或当前日期为休市日
- **THEN** 起投前不显示收益数据；起投后休市日沿用上一真实收盘价推导的组合价值

#### Scenario: v4 计划规则
- **WHEN** 尝试直接渲染 v4/v5/v6 计划
- **THEN** 拒绝并提示先备份迁移到 v7

#### Scenario: 事件随窗口滚动
- **WHEN** 旧作品包含事件材料
- **THEN** 必须显式迁移并备份旧事件，活动 v7 画面不显示事件或滚动窗口

#### Scenario: 价格画面内容
- **WHEN** 渲染任一推进帧或终幕帧
- **THEN** 只展示投资价值、日期、来源和统计口径，不出现股价读数或事件图层

#### Scenario: 展开全历史
- **WHEN** 新版时间轴进入终幕
- **THEN** 完整历史及横轴扩展在最后推进帧前完成，随后稳定停留四秒

#### Scenario: 播放中段与事件前后
- **WHEN** 抽检旧事件日期附近的新版画面
- **THEN** 只按播放日期揭示投资价值，不读取事件或提前显示未来行情

#### Scenario: 新版本规则生效
- **WHEN** 采用 v7 金融工作流
- **THEN** 使用分阶段扩展日期横轴和已展示组合价值自适应纵轴，通过完整静音预演评审后才可正式导出；旧计划需显式迁移

#### Scenario: 滚动纵轴适配价格
- **WHEN** 旧滚动计划迁移到 v7 后揭示价格
- **THEN** 纵轴使用全部已揭示组合价值极值和留白，不使用近期窗口或未来数据

#### Scenario: 窗口内显示最新价格
- **WHEN** 播放日期位于交易日之间或到达新交易日
- **THEN** 当前组合价值使用最近已到达真实收盘价推导，不生成插值报价

#### Scenario: 长跨度采用滚动近期视窗
- **WHEN** 旧材料声明多年范围及滚动近期视窗
- **THEN** 必须显式迁移；v7 分阶段扩展年份横轴并持续保留历史价值曲线

#### Scenario: 手机屏幕注释
- **WHEN** 渲染任意推进帧或终幕帧
- **THEN** 底部只展示来源摘要和统计口径，不出现股价或坐标说明

### Requirement: 手机可读布局与统一说明
画面 MUST 将短名称及证券代码、完整日期范围、假设投资年份和本金、当前日期、当前市值、收益金额与收益率集中在顶部，中部为组合价值曲线，下方为唯一说明区域。标题 MUST 至少 64 px、当前市值至少 64 px、收益指标至少 42 px、当前日期至少 48 px，区间和说明至少 36 px；MUST 不通过缩小字号容纳长文字。核心内容及其实际边界 MUST 位于 x=64～900、y=180～1500 安全区内。底部说明 MUST 仅包含去重后的来源主机名和统计口径；口径 MUST 标明股票价格仅拆合股调整且不计分红再投资、持仓按比例计算、不计手续费及税费；指数 MUST 说明按点位比例模拟且指数不可直接持有。完整来源信息 MUST 保存在作品材料。

#### Scenario: 手机播放假设投资视频
- **WHEN** 在 360×640 缩放下检查竖屏视频
- **THEN** 标的、投资年份/本金、日期、市值、收益金额、收益率、曲线及来源口径清晰可读且位于安全区

#### Scenario: 英伟达手机播放
- **WHEN** 使用 displayName 为“英伟达”的 NVDA 材料制作视频
- **THEN** 顶部显示“英伟达 · NVDA”及动态投资指标，360×640 缩放画面可读

#### Scenario: 来源和口径超出说明容量
- **WHEN** 来源摘要或统计口径超出说明区域
- **THEN** 保持最低字号并阻断验收，指出超限内容，不缩小或裁切

#### Scenario: 长名称与多来源
- **WHEN** 名称、来源摘要或统计口径超出可用宽度
- **THEN** 保持最低字号并换行；超出区域容量时阻断验收且不裁切

#### Scenario: 交易日期去重
- **WHEN** 当前日期与最近有效收盘日期相同或不同
- **THEN** 顶部日期不重复；休市日期不展示合成报价

#### Scenario: 手机安全区检查
- **WHEN** 检查原尺寸和 360×640 缩放画面
- **THEN** 文字及曲线端点不越界，右侧与底部预留区不承载必要信息
