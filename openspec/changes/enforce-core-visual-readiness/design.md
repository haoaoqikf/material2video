## Context

已有四阶段及 G0–G6，不缺检查入口。缺口在于核心盲审的通过不必提供分别的理解/表现判断，同轮目标对照仅在 G6 汇总要求，问题关闭只验证文件摘要。

## Goals / Non-Goals

目标：让核心失败、证据不足和缺少目标对照实际影响扩展状态；评审发现的问题凭当前独立复查关闭。非目标：自动审美评分、阻断 render、替用户改变创意、重制作品、升级分镜或制作合同版本。

## Decisions

1. 沿用六类风险。参考采用项通过现有 reason/requiredEvidence 引用，不用关键词猜测用户要求，不新增风格风险类型。
2. 核心盲审风险覆盖项新增 assessment：understanding、presentation、representativeness，各含 status（pass/fail/insufficient）和 observations。全部通过才允许该覆盖项通过；缺少字段的历史报告不授权新扩展。判断仍由独立评审者完成。
3. G4 的风险检查点与 static-expression 范围相交时要求同轮对照；G2 的目标图盲审不等于实际实现对照。G6 保留已有要求。配对要求独立同一评审者、同轮同检查及有效摘要，覆盖实际适用检查点。
4. 新建小模块派生扩展状态，区分全局准备门与逐风险 G4 自身结果，避免一个风险未完成阻塞无关工作；全片制作完成仍要求全部门 ready。
5. REVIEW- 自动登记必改项不得被降级、改范围或删除后覆盖；关闭时须引用匹配当前上游、同范围的独立通过复查报告。目标变化使旧报告失效，不消除问题；量测问题仍可使用确定性证据。
6. 保留 stage/candidate 技术语义，另加明确 summary 和 production.complete；不把 delivered 改成审美通过。

## Risks / Trade-offs

机器只能验证凭据与一致性，不能辨认伪造的审美观察或自动检测尚未登记的风格要求；文档必须明确这个边界。旧核心记录缺少维度时显示待评审，不补造历史。增加的计算复用状态中已读取事件、摘要缓存，不增加浏览器、全片编码或网络请求。

## Migration Plan

不迁移作品材料、不修改旧报告。新报告与后续重新评审按新要求填写，已有不适用场景不增造型、动作或对照要求。

## Open Questions

无；用户已授权执行前述六项流程修改。
