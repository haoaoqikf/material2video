## ADDED Requirements

### Requirement: 核心实际片段必须完成适用的同轮目标对照

G4 核心风险窗涉及 static-expression 目标时 MUST 先保存独立盲审，再由同一评审者完成同轮目标对照；缺少有效配对不得授权扩展。对照 MUST 覆盖当前适用检查点并绑定同一检查事件、轮次与当前证据，不增加固定轮次或人数。G2 目标图本身通过不能替代实际片段对照；G6 保留终审对照。

#### Scenario: 只有核心盲审通过
- **WHEN** 有适用目标的 G4 核心窗仅有盲审通过
- **THEN** 状态显示待评审与缺少同轮设计对照，不能扩展该风险

#### Scenario: 对照不独立或对应其他观察者
- **WHEN** 对照为自审、对应其他轮次或未与该通过盲审绑定
- **THEN** 不计有效对照

### Requirement: 独立评审缺陷必须由当前独立复查闭环

自动登记的 REVIEW- 必改项 MUST 保留原范围与必改性质。关闭 MUST 引用同范围、绑定当前上游且证据有效的独立通过复查报告；制作解释、目标修改、降级自审或其他范围报告不得关闭。改变目标后仍 MUST 重新验证并保留失败历史。

#### Scenario: 修改目标后引用旧复查
- **WHEN** 合同或实际实现变化后尝试用旧独立报告关闭问题
- **THEN** 关闭被拒绝，问题保持未完成

#### Scenario: 用制作说明或量测替代独立复查
- **WHEN** REVIEW- 必改项仅附自写说明或自动量测报告
- **THEN** 不能关闭；普通确定性量测问题仍按原规则复查
