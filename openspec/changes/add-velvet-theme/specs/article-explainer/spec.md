## MODIFIED Requirements

### Requirement: 默认旁白画面字幕
general MUST 无需额外配置即可根据旁白原文生成字幕，并将字幕烧录到预演和正式成片画面；仅生成外置字幕文件 MUST NOT 视为满足交付要求。字幕 MUST 使用真实配音派生的帧边界，在开始帧显示、结束帧隐藏，停顿与阅读尾段无对应讲话时 MUST 不显示字幕。各主题均 MUST 保证字幕可读，正文 MUST 预留字幕安全区。通用作品的字幕 MUST 与逐段真实配音的本地时间轴一致。

#### Scenario: 未配置字幕选项
- **WHEN** 有效文章作品未声明任何字幕选项并完成准备、预演和正式导出
- **THEN** 根据旁白原文自动生成字幕，预演和正式成片均包含画面字幕

#### Scenario: 字幕边界和静音区间
- **WHEN** 播放到字幕开始帧、结束帧或无讲话的停顿及阅读尾段
- **THEN** 开始帧显示对应字幕，结束帧及无对应讲话的区间不显示字幕

#### Scenario: 深浅主题与嵌入
- **WHEN** 通用讲解使用深色或浅色主题，或尝试旧完整片段嵌入
- **THEN** 有效讲解的字幕保持可读且不与正文重叠，并按旁白帧边界显示；旧嵌入材料被拒绝

### Requirement: 六种受控画面
系统 MUST 提供观点卡、左右对比、步骤卡、因果图、图片配文与视频镜头，支持主题清单中的各套主题、关键词强调及按旁白逐项展示。因果图最多六节点且不得循环；图片来自作品本地，默认完整显示，可选居中裁切与推拉；视频按声明入点裁切并校验素材剩余时长。系统 MUST 检查文字溢出及字幕遮挡，发现问题阻断完整预演。

#### Scenario: 模板渲染
- **WHEN** 输入六种模板的有效内容
- **THEN** 每种按指定布局和语音顺序展示，帧求值顺序不改变画面

#### Scenario: 素材或图关系无效
- **WHEN** 素材缺失、视频剩余时长不足或因果图有循环
- **THEN** 校验拒绝，不静默隐藏、替换或截断

## ADDED Requirements

### Requirement: 视觉主题
系统 MUST 以 `web/src/themes.json` 作为视觉主题的唯一真源，由它派生主题名单与默认主题；前端画面实现与准备阶段的实现 MUST 读同一份，MUST NOT 各自另存主题取值。分镜的 `visual.theme` MUST 取自该清单，取值不在清单内时 MUST 拒绝并在错误中列出可选主题。

主题 MUST 承载颜色、排版与动效三类取值。主题声明的转场时长 MUST 覆盖每幕声明的 `transitionFrames`，未声明时 MUST 沿用分镜声明与契约默认值；转场类型 MUST 仍由分镜决定。主题声明的阅读停留 MUST 参与准备阶段的最小幕长判据。动效 MUST 以帧数表达，MUST NOT 依赖 CSS 动画或计时器。

主题可在项目既有的对比度预算内改编外部风格，改编项 MUST 在参考文档中逐条标注，MUST NOT 表述为原值照搬。

#### Scenario: 主题接管节奏
- **WHEN** 主题声明了转场时长或阅读停留
- **THEN** 准备阶段按主题的帧数编译时间轴与最小幕长，成片按该节奏渲染

#### Scenario: 未声明转场的主题
- **WHEN** 主题未声明 `transitionFrames`
- **THEN** 每幕沿用自己声明的转场时长，未声明时用契约默认值，既有作品行为不变

#### Scenario: 未登记的主题
- **WHEN** 分镜声明的 `visual.theme` 不在主题清单里
- **THEN** 校验失败并列出可选主题，不静默回退到某个主题

#### Scenario: 主题数据不可读
- **WHEN** 主题清单缺失、不是合法 JSON、缺少 `themes` 或默认主题不在清单内
- **THEN** 校验与准备阶段明确失败，MUST NOT 用内置默认值继续制作
