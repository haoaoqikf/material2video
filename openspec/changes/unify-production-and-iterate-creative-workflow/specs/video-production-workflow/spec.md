## MODIFIED Requirements

### Requirement: 通用作品视觉设计与替代复核
制作助手 MUST 在编写场景前记录受众、观看设备、表达重点、视觉风险及作品设计。general 未指定发布平台时 MUST 面向抖音，未指定画幅时 MUST 使用 1920×1080 横屏、60 fps；用户显式平台或画幅 MUST 优先。金融和住宅专用画幅 MUST NOT 因此改变。设计 MUST 包含视觉隐喻、字体配色、开场/核心/结尾构图、镜头承接与声音意图，时长 MUST 按内容目标确定，不统一强制 60 秒。通用横屏与竖屏共享字幕 MUST 均使用40px，安全区位置与尺寸保持各自现行契约；不得把横屏字幕随高度缩至23px。

助手 MUST 自行搜索事实资料和视觉参考，记录来源、访问日期、用途及具体参考维度，不要求用户提供。直接进入成片的素材 MUST 另行按素材导入契约核验许可并留证；参考用途 MUST NOT 等同于入片授权。资料不可访问时 MUST 如实记录，MUST NOT 虚构搜索、观看或许可结论。

所有 general 作品 MUST 先以最终交付参数验证覆盖开场、核心难点、结尾及主要风险的片段，必改项关闭后再扩展全片。general MUST 提供有来源的参考依据、美术基准与镜头设计，并保留 按实际风险选择尺寸的代表静帧和 按风险确定长度的有声样片；未被样片覆盖的高风险章节 MUST 补查。参考与实际画面 MUST 按具体维度对照，MUST NOT 只写形容词。

静帧 MUST 用于构图、材质和明暗检查；覆盖全片的帧序列及交界/异常加密帧 MUST 用于镜头连续性复核；交付音轨的自动检测及旁白时间戳 MUST 用于信号和时序复核。最终文件 MUST 执行帧序列与自动音频替代验收，并按手机观看尺寸检查文字、主体和平台界面遮挡风险；平台依据 MUST 注明来源和日期，不可核实时 MUST 披露限制。全流程 MUST NOT 要求播放视频或连续收听声音；助手 MUST 如实说明覆盖范围，MUST NOT 虚构已播放、已收听或配音自然度通过。

所有 general MUST 均由助手自主执行，不要求任何制作阶段的用户确认。设计、参考与帧序列/量测复核记录 MUST NOT 成为 CLI 导出门禁。

#### Scenario: 未指定画幅
- **WHEN** 用户只提供 general 内容
- **THEN** 助手自行搜索参考，以抖音、1920×1080 横屏、60 fps 设计，记录手机观看目标

#### Scenario: 显式竖屏
- **WHEN** 用户明确要求竖屏或其他受支持平台
- **THEN** 采用显式要求，且不改变其他类型的专用画幅

#### Scenario: 替代验收覆盖不足
- **WHEN** 助手仅检查少量关键帧，尚未完成全片采样、异常候选复查及自动音频检查
- **THEN** 只报告已执行范围，不标记替代验收通过；无需以实际播放或试听补齐，应补齐规定的替代检查

#### Scenario: 纯 CLI
- **WHEN** 有效材料通过当前完整预演和既有技术门禁但没有复核记录
- **THEN** CLI 可正常导出，助手不能据此宣称视觉复核或制作完成

#### Scenario: 高风险遗漏
- **WHEN** 样片仅覆盖地球与土星，未覆盖有明显暗景风险的外行星和结尾
- **THEN** 助手补查遗漏风险片段，解决必改项后再扩展全片

#### Scenario: 替代复核发现问题
- **WHEN** 静帧、时间标注帧序列、量测或自动音频信号检查发现节奏、构图或声音技术问题
- **THEN** 记录具体时间位置，修改相关材料后重新准备并复查，必改项关闭前不标记阶段通过

#### Scenario: 电影级缺 look-dev 产物
- **WHEN** 尚未产出要求的代表静帧或有声样片
- **THEN** CLI 不因缺失产物阻断导出，但助手不能标记样片通过或铺全片阶段完成，应补齐产物并完成相应的静帧、帧序列、量测与自动音频信号复核

### Requirement: 电影级制作档位与质量门禁

系统 MUST 对 general 使用唯一制作契约并拒绝 productionProfile 与 --profile，不保留双档位分支。助手 MUST 执行创作目标、方案循环、核心动态试制、整片粗预演、美术声音定稿、精制及复核回退。关键画面与核心试制必做；镜头数量、时长、二维或三维、声音与后期按内容决定，不统一强制4K或固定长度样片。技术检查 MUST 区分自动判定与测量提示，不替代可读性、语义同步和视觉质量。技术通过、当前全片帧序列与自动音频证据齐全、候选处置完成且必改项关闭后，助手 MUST 自主交付；缺证据或存在必改项 MUST 报告未完成，不新增用户审批和CLI人工门禁。

#### Scenario: 自主完成
- **WHEN** general 技术检查通过、当前最终文件已完成帧序列及自动音频检查且必改项关闭
- **THEN** 助手自主交付并标记完成，不询问用户是否通过

#### Scenario: 严重问题未解决
- **WHEN** 技术 QA 通过但存在主体不可识别或字幕无法阅读的必改项
- **THEN** 助手继续返工或如实报告未完成，不以技术通过标记完成

#### Scenario: 使用非播放式替代检查
- **WHEN** 助手使用时间标注帧序列、量测和本地媒体检测完成复核
- **THEN** 按帧序列、自动音频和逐镜头证据完成替代检查；满足条件即可自主完成，披露主观听感与采样限制，不要求用户确认

#### Scenario: 标准档不受影响
- **WHEN** general 未声明旧档位
- **THEN** 采用统一流程，保持普通H.264交付，按内容选择表现成本，不强制三维资产

#### Scenario: 用户要求电影级
- **WHEN** 用户要求惊艳或发布级成片
- **THEN** 在统一流程中将体验转为可观察目标，循环试制并返工，不以档位名或特效配额证明完成

#### Scenario: 用户未通过
- **WHEN** 用户主动指出已交付成片存在问题
- **THEN** 助手记录具体位置并按严重度返工复查，不将用户反馈设为必须等待的审批阶段

### Requirement: 旁白主张与画面可见性
系统 MUST 接受旁白段可选 claims，记录旁白声称的画面特征。现有 claims 自动检查 MUST 仅承诺旁白时间窗是否被镜头覆盖，并明确报告检查范围；MUST NOT 将覆盖通过描述为特征实际可见。

助手 MUST 在当前时间窗提取并实际查看多帧中的声明特征，记录时间码、观察结果及版本；不可见时 MUST 形成必改项，调整镜头、材质、朝向或旁白后复查。无法判定时 MUST 记录待复核，MUST NOT 静默通过或依赖图像识别模型作唯一依据。作品未声明 claims 时 MUST 保持时间轴、准备记录和既有技术验收行为。

#### Scenario: 旁白声称大红斑
- **WHEN** claims 大红斑有对应覆盖镜头，但实际画面不能辨认大红斑
- **THEN** 技术报告只记录覆盖通过，助手记录可见性必改项，解决前不标记制作完成

#### Scenario: 自动无法判定
- **WHEN** 尚未实际查看特征所在时间窗
- **THEN** 可见性保持待复核，不以元数据覆盖结论代替

#### Scenario: 标准作品未声明 claims
- **WHEN** 作品没有 claims
- **THEN** 时间轴、准备记录和既有技术验收保持不变

### Requirement: 美术方向必须比较并执行独立复核
general 制作助手 MUST 在扩展全片前比较至少两个美术方向并记录采用理由。助手可用简短方向说明和关键构图，但仍 MUST 用参考板与关键帧体现构图、光影、色彩、材质、文字层级及留白选择。助手 MUST 在扩展全片前提供开场、核心、结尾三张代表画面，检查构图、主体大小、留白、光影、材质、色彩及文字层级，作为全片对照基准；同时保留按实际风险选择尺寸的代表静帧要求。方向比较 MUST 明确受众、情绪和视觉重点。助手 MUST 以实际画面对照设计，MUST NOT 把启用后期效果或技术 QA 通过作为审美通过依据。记录不新增 CLI 门禁或用户确认。

#### Scenario: 后期效果齐全但主体不突出
- **WHEN** 场景已有 Bloom、景深等效果，但主体轮廓、细节或视觉层级仍不清楚
- **THEN** 助手调整构图、光影和效果强度，记录前后依据，复查后再关闭问题

### Requirement: 声音设计必须随分镜规划并验证音乐层级
制作助手 MUST 对需要音乐的 general 作品在分镜阶段记录声音意图及音乐段落表，明确音乐时间窗、情绪、旁白与观察窗口中的层级变化、淡入淡出和关键音效。收到音乐不明显的反馈时 MUST 先排查最终文件中的实际混入、覆盖、增益和旁白压低音乐及恢复行为，MUST NOT 未核查即认定根因或只提高总音量。代表样片 MUST 包含实际配音及音乐，检查讲话清晰与观察留白中的音乐展开；音乐和音效 MUST 有来源及许可依据，环境声音的艺术示意 MUST 明确。按作品需要采用音乐，保持现行声音与混音要求；MUST NOT 强加所有 general 使用多层音乐。

#### Scenario: 有音乐配置但成片几乎听不到
- **WHEN** 用户反馈音乐不明显
- **THEN** 助手对照独立音轨与最终混音，排查实际混入、覆盖、增益、压低与恢复，记录依据后调整并复查

#### Scenario: 旁白结束进入观察窗口
- **WHEN** 设计安排无旁白观察且该段需要音乐承接
- **THEN** 音乐平缓恢复或抬升，避免跳变及遮蔽下一段介绍；设计中的安静段落单独注明

### Requirement: 制作阶段必须有明确完成条件与有效证据

助手 MUST 为内容设计、整片粗预演、关键画面与风险样片、全片精制和交付分别记录产出、待检查/返工/通过状态、版本及未解决问题。每阶段必改项 MUST 在有效版本复查关闭后才能标记通过；重新渲染或技术 QA 通过 MUST NOT 自动关闭问题。与用户核心体验冲突的已知缺陷 MUST 作为必改项，MUST NOT 仅改列为可选项或覆盖限制后放行；已观察缺陷与尚未覆盖的检查范围 MUST 分别记录。所有阶段 MUST 由助手自主推进，MUST NOT 新增用户审批或 CLI 人工门禁。

#### Scenario: 前一阶段问题尚未关闭
- **WHEN** 风险样片主体辨识必改项仍待复查
- **THEN** 助手保持阶段返工状态，不标记通过或扩展精制全片；可以继续生成修复与检查材料

#### Scenario: 已记录偏快却准备交付
- **WHEN** 复核已经发现与连续自然体验冲突的快速接近、急转或短暂停留
- **THEN** 助手保持该必改项未关闭，不以技术通过或限制披露代替修复与当前版本复查

### Requirement: 参考比较与四张基准必须指导实际画面

general 制作助手 MUST 以同一内容片段比较两个美术方向，拆解构图、光影、色彩、字体、运动及材质，并记录采用理由和具体画面决策。MUST 形成开场、核心、普通信息镜头和结尾四张基准，使用实际素材及正式文案；有旁白作品 MUST 带真实字幕检查，无旁白作品 MUST 检查所有实际画面文字。MUST 在原始尺寸、声明的手机观看尺寸及缩略图尺寸检查，记录尺寸、具体差距与修改，参考来源及授权沿用现有规则。

#### Scenario: 重点镜头精致但普通镜头拥挤
- **WHEN** 普通信息镜头在手机尺寸下文字竞争或主体不突出
- **THEN** 助手调整信息量与构图并复查，不以核心镜头通过代替普通镜头基准

#### Scenario: 参考没有转化为决策
- **WHEN** 参考记录只有链接和风格形容词
- **THEN** 补充逐维度差距及对应构图、资产、排版或运动决策后再完成方向选择

### Requirement: cinematic 风险样片必须遵循声音意图

look-dev MUST 按作品的声音意图生成风险样片：有声作品合并对应声音，无声作品输出无音轨样片。

#### Scenario: 无声作品生成风险样片
- **WHEN** 作品没有旁白、配乐、音效或素材原声
- **THEN** look-dev 样片保持无音轨，不读取或混入静音母版

## ADDED Requirements

### Requirement: 创作必须允许多轮方案淘汰与阶段回退
制作助手 MUST 在完整旁白和精制前明确受众、原有认识、新认识与观看理由，每轮默认提出3个叙事不同的候选，写出开场、悬念、核心事件、递进与结尾。候选全部不成立时 MUST 全部淘汰并继续，不设固定轮数上限，不强制凑轮次。下一轮 MUST 改变造成失败的叙事角度、事件或表现方法。核心试制 MUST 使用低成本动态片段验证手机尺寸下的事件、因果及注意力，失败可退回选案；整片动态粗预演 MUST 检查每段的新发现、观看动机、强弱和结尾兑现，失败可退回选案或试制。精制发现结构问题 MUST 返回对应阶段，同一问题连续两轮无改善 MUST 更换方法或方案。记录 MUST 复用 DESIGN.md 和 visual-notes.md，包含轮次、淘汰理由、保留内容、下一轮改变、版本和证据；不新增审美评分、运行时字段或人工审批。

#### Scenario: 候选全部淘汰
- **WHEN** 一轮候选都只有解释而缺少观看事件
- **THEN** 记录失败原因并提出下一轮不同讲法，不强行选优

#### Scenario: 试制失败回退
- **WHEN** 核心片段在手机尺寸不可辨或只靠长文解释
- **THEN** 调整表现或退回构思，不继续精制

#### Scenario: 预演失败回退
- **WHEN** 局部精彩但中段无推进或结尾未兑现
- **THEN** 重组整片结构并重新预演，必要时退回选案

#### Scenario: 连续两轮无改善
- **WHEN** 同一问题连续两轮修改仍无改善
- **THEN** 更换方法或方案，保留前后依据，不继续微调凑轮次

#### Scenario: 专用类型保持契约
- **WHEN** 金融或住宅采用循环比较
- **THEN** 按趋势、转折和图表表达迭代，保留类型画幅和声音，不强制讲解镜头结构
