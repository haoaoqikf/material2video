## Context

见 proposal.md。现有档位贯穿CLI、准备指纹、素材审计、采集缓存、混音和溯源；创作要求由助手执行，非机器审美门禁。

## Goals / Non-Goals

统一当前契约并通过作品验证多轮淘汰与回退；不新增类型、示例、分镜版本或审美评分，不保留旧档位兼容工具。

## Decisions

- 删除生产档位接口，旧字段明确报错。移除分支而非将两种值映射成第三种档位；look.profile仅代表美术名字，予以保留。
- 统一有声输出−14 LUFS/−1 dBTP，静音不归一化成噪声；所有登记媒体许可未知阻断。尺寸按实际显示用途人工复核，技术报告记录原生尺寸与告警，不用固定4K和贴图齐全度替代可读性。
- 保留hero/major/minor、shots/look、确定性超采样和运动模糊，取消镜头数量及时长配额，保留边界与时间窗校验。
- lookdev允许按片长与风险选择样片长度和采样尺度；整片复核不降低0.5秒基线和边界加密要求。
- 循环记录放现有设计与复核文档。候选可以全部淘汰，连续两轮同问题无改善换方法；不能伪造失败轮次来证明执行。
- 重制保留旧版哈希与代表帧，实际比较候选、试制核心、整片粗预演后精制。仅当前固定示例源码与方法入库，输出不入库。

## Risks / Trade-offs

- 创作判断有主观性 → 给出可观察证据和未覆盖范围，不承诺流量。
- 更多试制增加耗时 → 简化资产、优先核心风险、复用未失效证据，停止无效微调。
- 删除档位使旧材料失效 → 明确拒绝并同步三示例，准备实现与采集契约纳入指纹。

## Migration Plan

更新主契约、测试及示例后重新prepare；不提供迁移工具。用户原片保留对照，不覆盖为新版本证据。通过验证和提交后同步规格并归档。
