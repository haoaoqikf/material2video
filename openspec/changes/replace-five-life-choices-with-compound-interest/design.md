## Context

用户授权以30秒《复利》原位替换 `examples/five-life-choices`，并在实施中给出 v3 设计：颜色改为资金状态机、金额改为圆片面积编码、时间轴改为 S1–S7、声音改为8秒进入的环境床加事件音。用户确认 −14 LUFS / −1 dBTP，并明确选择直接采用圆片机制。本变更按该方案实施；旧五选择与 v2 色带版不保留兼容分支。作品级逐镜表、导演卡和视觉力量记录见 `examples/five-life-choices/DESIGN.md`，本文只保留跨实现的关键决策与验收边界。

## Goals / Non-Goals

**Goals:** 用1枚=1,000元的圆片让金额可数；用金/米白/暗金三态让“金色最后去哪”成为唯一问题；在30秒内完成等起点、来源因果、取出/再投入分叉、30年规模与首尾回扣；成片在852/393宽可读。

**Non-Goals:** 不推荐产品、不承诺收益、不新增公共 API/CLI/schema/示例；不声称做过三机制比较、真实观众留存测试或听过用户主观 A/B。

## Decisions

### 直接采用圆片机制

用户 v3 方案已确定核心机制、颜色、七段时间和声音结构。按制作流程的“用户详细方案直接采用”路径实施，**不做三机制匿名比较**；这是用户明确选择，不是比较胜出。替代验证照常执行：K01 独立目标静帧（S3/S5）、R06 两名隔离评审、最终两名隔离评审、颜色流向与 S3 机制无字测试、新片对 v2 匿名帧包比较、音频8秒 A/B（主观由用户完成）。任何文档不得写成“已比较”或“圆片胜出”。

### 颜色状态机

| 颜色 | 含义 | 去向 |
|---|---|---|
| 金 | 本轮刚赚到、尚未再投入的收益 | 变米白（继续生息）或变暗金（已取走） |
| 米白 | 已进入下一轮、会继续生息的资本 | 30年后成为丘的主体 |
| 暗金 | 已取走、离开增长系统的收益 | 左侧留存架 |

颜色不表示材质分类，不固定“本金/收益”身份；同一枚金色在 S3 变米白、在 S4 左侧变暗金，是资金状态变化。

### 圆片编码与数学

1枚=1,000元；直径 `d=42*√(金额/1000)` 画布像素。小数部分 ≥0.25 单独画，<0.25 丢弃不并入整枚；S3 用 `discFractions(1.1,.1)` 保留0.1金片。852宽最小直径 ≥14px；S3 0.1片在2.5×下约14.7px，S5 的0.631/0.863约14.8/15.4px。

本金10,000、固定年收益率10%、无追加、按年结算，只在显示时舍入。第30年再投入：158,631米白 + 15,863金 = 174,494；取出：10,000米白 + 30,000暗金 = 40,000。圆片表示为159枚米白（含0.631）+ 16枚金（含0.863）= 175枚；不得漏掉0.631。

### 七段时间结构

| 段 | 时间／帧 | 事件 | 信息 |
|---|---|---|---|
| S1 | 0–3.5／0–105 | 两柱各10枚落入；两柱标签淡入 | 同样一万，两种做法；三十年后差多少？ |
| S2 | 3.5–8／105–240 | 第一枚金收益挤出、上浮、落定 | 第1年；10,000×10%=1,000 |
| S3 | 8–13／240–390 | 金回吸变米白；柱10→11；顶部1.0+0.1金 | 第2年；11,000×10%=1,100 |
| S4 | 13–19／390–570 | 分屏；左金→暗金入架；右金→米白；只演第3年；15.2起右组算式；17.2–19.0停留 | 收益取走／拿走，不再生息；收益再投入／留在里面，继续生息；12,100×10%=1,210 |
| S5 | 19–24／570–720 | 丘铺开、左柱上移成组；19.0–21.5标题“从第3年，到第30年”、年份计数器暂隐；21.4切换总额/第30年并落定两个数字 | 40,000左·合计、174,494右·合计；约174.5枚·1枚=1,000元 |
| S6 | 24–27／720–810 | 第一年那枚浮出、回金、回推、变米白 | 让收益，也成为本金。 |
| S7 | 27–30／810–900 | 慢拉回、扫光、尘埃 | 复利 |

S2/S3 跟随最终成为 S4 右侧“再投入”的柱，保证回吸因果连续；S4 只演示第3年一次分流（右12.1→13.31，左12→13），不逐年演到30年。这是对规格“推近左柱顶”字面的消解，记录在案。

### 用户反馈修订

- S1 标题“同样一万，两种做法”；1.35–1.7秒两柱标签；2.2秒问题。解决“开头不知道在对比什么”。
- S4 两行“拿走，不再生息／留在里面，继续生息”；延长到13–19，17.2–19.0纯停留。解决“取出/再投入看不懂、停留太短”。
- S5 19.0–21.5用“从第3年，到第30年”说明时间快进并暂隐年份计数器，避免与“30年累计总额”矛盾；21.5切换“30年累计总额（元）”、第30年，并落定40,000/174,494，保持到24.0。组名加“合计”，单位定义为“约174.5枚·1枚=1,000元”。

### 镜头与文字

单世界坐标 + SVG 相机；关键帧0/3.65（960,540,1）→4.65–12.2（1420,740,2.5）→13.4–18.8（960,540,1.05）→19.6–24.0（960,540,1）→24.8–27.0（1360,702,2.4）→29.6（960,540,1）→30.0（960,540,.985）；scale 对数插值。全片无硬切、无叠化。

黑底；米白/金/暗金三态；圆片只用平面圆+高光弧+暗椭圆，无 filter。字体 `M2V Sans`。主金额84–96px、标签44–52px；S4辅助文字/底部方法说明放大到52/54px；S4算式64px；S5标题60px、单位说明两行66px，满足393宽复核。文字只承担主题、对象名、数字、年份、结论与方法边界；S4两行解释是用户明确要求的例外。

### 声音

30.0秒 `bed.wav`：前8秒数字静音、8.0秒起0.8秒淡入、29–30秒淡出；无旋律/节拍/和声。28个事件音按 `offsetFrames` 绑定；S5金属流5秒资产从570帧起。含 music 时走 `audio.master(-14)`；交付 −14 LUFS / −1 dBTP。8秒 A/B 自动信号记录；主观盲听从用户，代理不声称听过。

### 评审与验收

- K01：S3/S5 独立目标静帧，路径 `outputs/design/keyframes/`，只投喂中性静帧包；393必改项修复后复核。
- R06：完整粗片三组帧（opening/full/comparison），两名新建上下文子代理，报告互不读取，绑定视频 SHA。
- 最终：结构/节奏/颜色流向 + 视觉文案/手机/声音时序，两名隔离代理；另做颜色流向与机制无字测试、新片对 v2 帧包比较。
- QA：frozen 无>3秒硬冻结；S7有可测运动；响度 −14±2 LUFS、true peak ≤−1 dBTP；audioSync pass；claims/picture/subtitleContrast。
- 所有结论绑定同一最终视频 SHA-256、preparedFingerprint、manifest SHA；旧R01–R05只属v2，不授权v3。

## Risks / Trade-offs

- 0.1金片在S3拉远后低于14px：必须保持微距，K01与机制测试核对。
- 175枚圆片性能：无GPU约1帧/秒，只用平面图元，不加 filter。
- S7冻结：扫光+慢拉远+尘埃，避开1秒采样混叠。
- 字体落错：统一 `M2V Sans`；852/393目视复核。
- 环境床被听成音乐：无旋律/节拍，8秒进入；自动信号+用户A/B。
- 直接采用例外：不得写成已比较；替代验证见上。
- 圆片零头：0.631必须真实画出；S5用159个位置并以 `discFractions` 生成。
- 文字碰撞：S5标签/数字/说明分层；393复核。
