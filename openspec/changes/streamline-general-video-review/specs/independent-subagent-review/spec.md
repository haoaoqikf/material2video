## MODIFIED Requirements

### Requirement: A/B 级评审必须由独立子代理执行

适用核心样片、全片粗片与最终综合终审 MUST 由新建上下文、只接收评审包的独立子代理执行；A/B 表示职责，不表示必须分派两个代理。默认每轮一名，最终代理 MUST 未参与该作品前期评审。split-final 触发时最终 MUST 两名新代理分别覆盖结构与视觉文案且互不读报告。候选数量、镜头等级、第一次重要返工 MUST NOT 自身触发额外代理；substantive-dispute 与 repeated-failure 按计划升级。代理 MUST NOT 接收制作理由、预期答案、源码或旧结论；作者不得代写独立观察。环境降级 MUST 显著披露且不得关闭独立项。

#### Scenario: 精简审核的适用判断

- **WHEN** 普通 general 的最终综合审查覆盖充分且无升级触发
- **THEN** 一名新的独立代理即可，系统不得要求固定第二人


#### Scenario: A 级完成
- **WHEN** 冷观众评审使用新建上下文，只读取前 3 秒评审包，报告由子代理写出
- **THEN** 该评审可记为「已独立评审」，结论可作为阶段证据

#### Scenario: 同一助手切换角色
- **WHEN** 制作助手在同一会话里换一个角色提示后写「独立子代理已通过」
- **THEN** 只能记为「角色分离自审」，不得关闭评审项

#### Scenario: 子代理读取设计文档
- **WHEN** 评审包或任务书包含 `DESIGN.md`、风格契约或旧结论
- **THEN** 该评审无效，重新打包并分配新评审 ID
### Requirement: 分门评审包必须绑定门与检查点

评审包 MUST 记录轮次、门和覆盖场景/检查点/窗口、证据类型、尺寸、摘要与被排除文件。同轮报告 MUST 能引用多个门的检查事件，完整校验后幂等登记，不要求重复报告。blind 包 MUST 排除设计、分镜、源码、旧结论与预期答案；consistency 包 MUST 只在 blind 观察落盘后提供，且只能给目标图与中性条件。两阶段可同一代理执行，一致性不得替代盲审。

#### Scenario: 精简审核的适用判断

- **WHEN** 核心轮同时观察目标图与动态风险
- **THEN** 分步提供净化证据，同一轮覆盖多个适用门，不能将目标条件提前泄露给动态盲看


#### Scenario: 场景评审包

- **WHEN** 生成 G4 场景单元评审包
- **THEN** manifest 记录门 `G4`、检查点 ID、场景窗口时间码、显示尺寸和证据摘要

#### Scenario: animatic 盲审包

- **WHEN** 生成 G3 animatic 盲审包
- **THEN** 包内只有 animatic 证据和中性问题，不含设计合同、分镜或制作理由

#### Scenario: 一致性审查读取合同

- **WHEN** 对合同与分镜做设计→实现一致性审查
- **THEN** 评审者可读取合同和分镜，但结论只能记录自洽性或结构问题，不能替代盲审美评审
### Requirement: 批量评审与全片评审必须声明覆盖范围

每轮 MUST 提供一份覆盖表，列明范围、时间窗、具体观察、结果、证据引用及问题 ID。普通场景 MUST 合并在全片粗片和最终报告中覆盖，不逐 G4 复制独立报告；缺失覆盖 MUST 显示待评审。G5 MUST 隔离复制播放所需媒体与依赖；不能播放时提供有序分场和跨场完整窗口，证据不足不得通过，不额外编码整片。

#### Scenario: 精简审核的适用判断

- **WHEN** 粗片报告遗漏一个场景
- **THEN** G5 保持覆盖不足，已通过的普通场景自动检查不退回为缺独立报告


#### Scenario: 批量评审漏掉一个场景

- **WHEN** G5全片报告漏掉一个普通场景
- **THEN** G5保持覆盖不足，不把该场景已通过的自动G4改成缺单独评审
### Requirement: 评审必须区分缺陷风险偏好并限定否决依据

独立报告 MUST 先盲看完整窗口落盘，再核对预先声明的中性条件，记录时间码、尺寸和观察。实际缺陷 MUST 指出现象、受影响目标和上下文；风险补证、偏好不自动否决、证据不足不等于通过。事实、许可、技术和关键可读性不得放宽。缩略图、去文字、静音、减法两问、传播判断 MUST 作为按风险选择的诊断工具，不因未逐项回答而阻断完成。实质争议 MUST 新代理复核，不用作者意图覆盖。终审人数 MUST 按审核计划而非固定两人。

#### Scenario: 精简审核的适用判断

- **WHEN** 作品依赖文字表达且没有去文字诊断需求
- **THEN** 不以未提交去文字测试否决，仍须完整检查文字理解与手机可读性


#### Scenario: 静止形成回报
- **WHEN** 镜头停留超过 1.5 秒但完整段落建立期待并兑现
- **THEN** 不因静止时长失败，记录实际作用

#### Scenario: 延迟揭示成功
- **WHEN** 开场局部难辨，完整表达窗口揭示主体与关系
- **THEN** 区分疑问和误读，不以开场截帧否决

#### Scenario: 作者解释替代作品
- **WHEN** 看完完整窗口仍形成核心误解，作者声称故意留白
- **THEN** 记为实际缺陷，设计意图不能豁免

#### Scenario: 偏好与证据不足
- **WHEN** 评审不喜欢文字风格或证据不足以判断听感
- **THEN** 分别记录偏好或覆盖限制，不自动变为已证实缺陷或通过
### Requirement: 评审结论必须按门记录并可追溯

独立报告 MUST 记录轮次、门及覆盖范围、来源/评审包/报告摘要、身份与隔离方式，引用检查事件及问题ID。同轮一份报告可绑定多门，不重复写观察；降级不得计为独立通过。新制作周期不得继承旧周期通过，来源不符或缺失不得支持完成。

#### Scenario: 按当前计划追溯

- **WHEN** 本轮证据来源与实际覆盖有效
- **THEN** 按该轮范围判定并保留问题重开权，不要求重复报告

#### Scenario: 报告缺少门绑定

- **WHEN** 评审报告没有记录所属门或检查点 ID
- **THEN** 该报告不能用于对应门的通过判定，需重新打包并分配新的评审 ID

#### Scenario: 独立评审可追溯

- **WHEN** 某次 G4 A 级评审使用新建上下文子代理完成
- **THEN** 台账记录门、检查点、manifest 摘要、报告摘要和隔离方式，状态层可据此显示通过

#### Scenario: 降级评审

- **WHEN** G4 评审因环境限制降级为角色分离自审
- **THEN** 状态显示降级旗标，不得把该评审计为独立通过或关闭计划要求的独立项

### Requirement: 评审者身份与证据必须可核验

评审记录 MUST 写明执行方式，只允许「独立子代理」「外部评审」「角色分离自审（降级）」三种。记录 MUST 包含评审者标识或调用记录、开始与结束时间、投喂文件清单、隔离方式、评审包 manifest SHA-256、报告 SHA-256 与 invocation 摘要。最终轮的 reviewerId MUST 未参与该作品前期评审；同一调用 MUST NOT 作为多个评审者；`split-final` 的两名评审者 MUST 互不读取对方报告。无法提供独立调用证据时 MUST 记为「未独立评审（证据不足）」，按降级处理。

#### Scenario: 同一调用冒充第二名终审

- **WHEN** 同一 invocation 被用于两个 reviewerId 的最终报告
- **THEN** 拒绝导入，不产生通过事件

#### Scenario: 只有角色标签

- **WHEN** 记录写「独立子代理」但没有投喂文件清单与隔离条件
- **THEN** 视为未完成，补做独立评审或改记降级自审

#### Scenario: 外部评审

- **WHEN** 用户或另一个独立会话按同一评审包完成评审
- **THEN** 可记为「外部评审」，但不得声称真实观众测试或外部导演评审

### Requirement: 降级必须披露且不得关闭评审项

只有环境确实不具备独立子代理能力时才可降级；成本、时间与排期 MUST NOT 作为降级理由。降级时 MUST 先尝试独立方式并记录失败原因，再按角色分离自审执行：先只读评审包落盘观察，再对照设计。

降级项 MUST 记为「未独立评审（降级）」，MUST NOT 写成「通过」「冷审通过」「同族」或「像作品」；MUST NOT 计入已解决；MUST 写入交付的覆盖限制。能力恢复后 MUST 重新评审并保留旧记录。

#### Scenario: 无子代理工具

- **WHEN** 当前环境没有可用的独立子代理调用能力
- **THEN** 允许降级继续制作与交付，但评审项标「未独立评审（降级）」并披露

#### Scenario: 降级后写通过

- **WHEN** 记录把降级自审写成「冷审通过」
- **THEN** 视为违反门禁，改为未独立评审并写入覆盖限制

#### Scenario: 未执行

- **WHEN** 计划要求的某一轮没有评审记录
- **THEN** 对应阶段未完成
