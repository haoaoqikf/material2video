## Context
科学示例已有获取配方；太阳系包含下载图像、TIFF 转换和程序化材质。来源清单包含当前内容摘要和实测信息。

## Goals / Non-Goals
恢复全部当前媒体且不修改登记；保留本地媒体与字体。不引入 LFS，不改作品渲染契约。

## Decisions
共享恢复逻辑，示例提供配方和生成器。临时目录中下载、转换并校验全部缺失项后才安装；现有正确文件跳过。严格匹配固定摘要，不自动接受源站变化。转换工具必须核对版本。
完整恢复验收通过后才解除跟踪。仓库外 bundle 与素材备份先完成，独立镜像过滤历史示例媒体路径，精确 lease 推送 main；租约失败不覆盖远端。

## Risks / Trade-offs
源站失效或编码差异可能阻止精确恢复；遇到该情况保留媒体跟踪与历史，报告证据，不降低摘要要求。历史改写需要其他副本重新对齐；外部旧引用和 GitHub 缓存无法保证立即回收。

## Migration Plan
备份、实现恢复、空目录验收、解除跟踪、提交和归档、过滤与验证、租约推送、对齐工作副本。
