## Context

当前 composition 将所有价格点映射到固定的全区间横轴，校验器要求 `axis.valueRange` 覆盖整段历史。多年跨度下，这会压缩局部起伏。产品决策已确定默认窗口三个月、视窗内线性自适应纵轴，NVIDIA 成片 60 秒。

## Goals / Non-Goals

**Goals:**
- 在不裁掉数据覆盖范围的前提下，渲染只显示当前日期附近的滚动窗口。
- 让窗口内波动填充主要绘图区，按帧确定当前价格、事件可见性和坐标刻度。
- 校验新动画编排并保留离线重现及无声导出约束。

**Non-Goals:**
- 不更改行情获取源、价格口径、事件来源或文章视频流程。
- 不显示全历史概览小图、不增加对数轴、音频或额外场景。

## Decisions

1. **将可视范围放入动画编排。** `axis.dateRange` 继续表示完整数据范围；新增 `axis.visibleWindowMonths`（正整数，当前默认 3）和 `axis.valueScale: "rolling-linear"`，删除固定 `valueRange`。校验器拒绝缺失或不支持的策略，并要求窗口长度有效。
2. **按 UTC 日历日期构造视窗。** 窗口终点是当前帧日期，起点是向前减去指定日历月并将月底截短到目标月有效末日；早于完整窗口的数据起点钳制到起点。横轴月刻度由窗口计算。
3. **只处理窗口内数据。** 用价格序列的二分查找定位窗口首尾，路径仅由窗口内且不晚于当前日期的真实交易点生成，避免每帧遍历全历史。最新已揭示交易点仍是唯一显示数值和价格圆点。
4. **按可见价格自适应线性纵轴。** 当前窗口可见点的最小最大值加 8% 区间留白；当跨度为零时以价格绝对值的 1%（至少 0.01 个单位）作为半跨度，保证上下界严格递增。网格标签的小数精度随刻度间距增加（至少两位、最多六位），避免低价区间显示重复刻度；画面固定提示“纵轴随近三个月视窗自适应”。
5. **事件遵循真实日期和视窗边界。** 事件卡仍由帧编排单独顺序停留；标记只有事件已到达且日期在 `[windowStart, currentDate]` 时可见。滚出视窗后不再显示标记。60 秒编排预留 2 秒开场、事件卡所需暂停和至少 3 秒结尾。
6. **计划字段为必填新契约。** 旧动画材料缺少滚动字段时校验报清晰错误，需重新编排，不能静默退回全跨度展示。仓库内无需要迁移的金融视频示例；本地 NVIDIA 作品材料会一并更新。

## Risks / Trade-offs

- **视窗自适应纵轴会改变视觉比例** → 固定展示刻度提示，并使用窗口极值和确定留白；不把窗口曲线误认为全历史同一比例。
- **月末截短可能产生边界错误** → 将纯日历函数抽出并对月末、闰年、数据起点编写测试。
- **窄窗口 event marker 易拥挤** → 保留真实事件卡顺序，marker 仅保留窗口内，预演抽查事件前后与连续事件。

## Migration Plan

1. 更新 validator、renderer、测试和专题文档。
2. 刷新 NVIDIA 全历史日线至重新制作时的最新已完成 NASDAQ 交易日，重编 60 秒动画材料。
3. 离线校验、完整静音预演和视觉验收通过后导出正式 MP4；作品文件维持 Git 忽略。

回滚时恢复旧 component/validator 契约和规格，并可从本地原始快照重生成先前制式成片；不需要迁移已提交作品数据。
