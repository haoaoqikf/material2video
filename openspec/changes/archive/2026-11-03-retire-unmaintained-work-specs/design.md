## Context

三个逐作品规格没有对应的仓库内作品或维护中的交付记录。项目约定作品内容不入库，但不能据此把历史规格继续当作现行能力。

## 决策

1. **退役而不是删除记录**：通过 OpenSpec 移除能力，归档变更保留原说明与迁移理由；不删除任何本地作品、视频或验证记录。
2. **只退役三部**：其余逐作品规格仍有仓库内作品或规范示例，保持现状。
3. **不建立替代规格**：这些作品不再作为当前能力维护；若日后重启，按新作品重新建规格。

## 风险与边界

- 仓库外若仍存在这些作品的维护工作，本变更不会删除其内容，但不再有主规格约束；重启时需新建变更。
- 不影响共享字体、动效、渲染或审核契约。

## 验证

1. `openspec validate retire-unmaintained-work-specs --strict` 通过。
2. 归档后 `openspec validate --specs --strict` 通过。
3. `grep` 确认三个能力不再出现在 `openspec/specs/`。
4. `uv run pytest -q` 默认层通过。
