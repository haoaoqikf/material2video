## Context

仓库已通过 `stage-guidance-routing` 规定条件阅读、权威规则归属、迁移记录与活动引用维护。本次执行既有文档精简约定，不改变行为契约。完整逐文件迁移表见 `migration.md`。

## Decisions

- 目标为 29 份。把模板并回规则所有者、案例合成按需示例、外部项目登记与专题指引并页；保留独立类型/运行时/渲染/素材/风格契约及阶段主线。
- `article-to-storyboard.md` 的有效输入规则并入 `stage-plan.md`；创作次序与分镜细节继续由 `production-workflow.md`、`storyboard-schema.md` 承担。短篇 `input-review.md` 命令说明合并至方案入口。
- `cinematic-video.md` 仅保留当前仍有效的工具或契约事实，并迁至 README、媒体声音和场景/分镜权威文档；退役 profile 说明删除。
- 代码场景排错迁入 `code-scene-runtime.md`；推进/回退、参考分析、评审模板各迁入自身权威文档。
- 全片导演审查与传播评估共享独立按需页；形象诊断并入讲解设计。保留 `visual-review-rubric.md` 为视觉复核主契约，避免膨胀成全能大文档。
- `reference-style.md` 删除重复门禁表，评审时点、人员和完成条件改由审核风险计划决定；保留用户要求参考时的指标与证据契约，不增轮次。
- 字体页明确系统字体为 CSS 最后回退不等于制作允许静默回退；未消费字幕安全区令牌标为遗留，不再说本轮待定。运行时代码不变。
- 不改写归档 OpenSpec 历史；活动引用须有效，归档中的旧路径保持原样。

## Risks / Trade-offs

- 合并遗漏条件 → 按逐文件迁移表核对模板、适用范围、证据、排除项和链接。
- 单页过长 → 近邻内容才合并，创作方法、全片导演审查、复核合同各有独立边界。
- 历史归档含旧路径 → 以活动入口及现存活动文件链接有效为准。
