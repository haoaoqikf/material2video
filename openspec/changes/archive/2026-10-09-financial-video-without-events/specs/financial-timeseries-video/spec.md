## MODIFIED Requirements

### Requirement: 免费数据与价格口径

流程 MUST 使用无需账号或付费密钥的公开免费来源和交易日日线收盘数据。股票默认 MUST 采用仅调整拆股、合股且不计分红再投资的价格；指数 MUST 使用来源明确的官方指数点位并标明指数类型。流程 MUST 区分前复权、后复权、含分红调整收盘价与仅拆合股调整价，不得静默混用。

价格材料 MUST 使用 schemaVersion 3，日线点只包含 date 和 close；仅使用来源明确的真实收盘价。

#### Scenario: 可获得可靠的拆合股调整数据
- **WHEN** 来源提供符合口径的价格，或原始收盘价及拆合股资料足以可靠推导
- **THEN** 流程记录调整定义及必要的推导依据，画面显示价格口径和币种

#### Scenario: 只有不符口径的调整数据
- **WHEN** 来源只有含分红调整价、定义不明的 adjusted close 或其他不符口径序列
- **THEN** 流程说明差异并请求用户选择替代口径，未确认前不继续制作

#### Scenario: 指数数据
- **WHEN** 用户指定指数且其序列与发布机构定义可核对
- **THEN** 画面使用点位单位，资料记录价格指数或其他指数类型，不将其当成股票报价

#### Scenario: v4 动画计划生效
- **WHEN** 制作使用 v3 价格和 v4 折线计划
- **THEN** 按连续推进的真实日收盘价折线、全貌收尾及完整预演评审规则验收

### Requirement: 来源留存与离线复现

流程 MUST 保存原始价格数据、标准化数据、来源链接、获取时间、覆盖范围与调整定义；如有本地推导，MUST 留存推导依据。数据获取 MUST 发生在准备阶段，渲染阶段仅读取固定本地材料，不联网获取行情。画面 MUST 显示价格来源摘要，作品材料保留完整价格来源记录。

#### Scenario: 同一份材料重渲染
- **WHEN** 使用相同价格、编排、渲染资产及工具链重渲染或随机寻帧
- **THEN** 同一帧的日期、报价和曲线一致，不因实时网络返回而变化


## MODIFIED Requirements

### Requirement: 横屏持续折线场景

所有金融视频 MUST 使用 1920×1080、30 fps 的单标的持续场景，显示稳定标题、折线、日期、最近有效收盘价或点位、价格口径和来源摘要。画面 MUST 不包含事件标记、事件编号、事件说明卡或事件列表。完整数据范围与纵轴策略 MUST 在制作前声明；纵轴 MUST 根据当前可见窗口的有效价格自适应，且画面说明纵轴范围随窗口变化。折线 MUST 仅显示当前播放日期之前、位于滚动视窗内的交易日有效点；相邻有效点只作视觉连线，不把插值位置作为真实报价。每帧 MUST 仅显示最近已揭示有效交易点的单一价格与其真实交易日期，不为逐日价格点重复显示数字。

系统 MUST 只渲染折线，不提供 K 线。横轴位置按帧连续移动，纵轴采用仅使用已到达数据的确定性平滑过渡；报价不插值。结尾在数据全部到达后 MUST 用两秒展开至完整历史，横纵轴和曲线同步变化，再停留四秒；全貌使用线性纵轴和稀疏年份刻度。

#### Scenario: 长跨度采用滚动近期视窗
- **WHEN** 用户请求多年历史价格视频，编排声明最近十二个月的滚动窗口
- **THEN** 横轴显示当前日期及此前最近十二个月（数据起始处不足十二个月时从数据起始日开始），更早价格滚出画面，全量历史仍按时间推进

#### Scenario: 窗口内显示最新价格
- **WHEN** 播放日期在有效交易日之间或到达新的有效交易日
- **THEN** 画面只显示不晚于当前播放日期的最近有效收盘价和它所属的交易日；休市日期继续推进而不伪造报价，也不显示窗口中其他日期的数字报价

#### Scenario: 滚动纵轴适配价格
- **WHEN** 可见窗口包含多个不同价格、单个价格或相同价格
- **THEN** 纵轴按窗口内有效值确定且具有可读留白，退化区间仍保持严格递增，不以零值或全历史极值压扁局部波动

#### Scenario: 价格画面内容
- **WHEN** 渲染任一滚动帧或全历史帧
- **THEN** 画面只呈现价格、日期、价格口径和来源信息，不出现价格、日期、口径和来源以外的其他图层

#### Scenario: 事件随窗口滚动
- **WHEN** 旧作品含有事件材料并请求进入滚动窗口
- **THEN** v3 计划必须先显式迁移；新窗口只滚动行情，只按播放时间加载行情

#### Scenario: 播放中段与事件前后
- **WHEN** 检查旧事件日期前后对应的新版本播放画面
- **THEN** 曲线只显示已到达的有效价格，仅按播放时间显示已到达的价格点

#### Scenario: 展开全历史
- **WHEN** 时间轴到达终日并进入最后六秒
- **THEN** 前两秒将近期窗口连续展开至完整数据范围，后四秒保持完整历史曲线和最终真实收盘价，不泄露尚未播放的数据

#### Scenario: v4 计划规则
- **WHEN** 制作显式使用 v4 折线计划
- **THEN** 使用连续日收盘价折线；旧计划必须显式迁移

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 4 折线计划
- **THEN** 按全貌收尾及完整预演评审规则验收；旧计划必须显式迁移

### Requirement: AI 编排日期与视频时间

AI MUST 根据日期跨度、阅读需求确定总时长、滚动窗口长度和日期到视频帧的映射。默认滚动窗口为最近十二个日历月；日期 MUST 单调不减，窗口起点按播放日期向前推相同日历月数并处理月末截短，超出数据起点时钳制到数据起始日。纵轴按窗口自适应，必须可由当前帧与本地价格数据确定。开头 MUST 交代标的、范围与口径，结尾 MUST 用两秒展开至全历史并停留四秒；用户指定时长不足十秒时，MUST 说明冲突并澄清，不静默忽略要求。

60 秒计划 MUST 由 opening 90 帧、advance 1530 帧、overview 60 帧和 ending 120 帧连续组成。advance MUST 从展示起始日连续推进到终日，连续推进；其他时长 MUST 以开场 90 帧和结尾固定 180 帧计算连续推进预算。单日范围允许 advance 日期保持不变。

#### Scenario: 60 秒连续推进并保留终幕
- **WHEN** 折线作品编排为 60 秒、最近十二个月视窗
- **THEN** 1800 帧依次为开场 90 帧、连续行情推进 1530 帧、全貌展开 60 帧及全貌停留 120 帧，日期覆盖起点至终日

#### Scenario: 60 秒快速推进并保留终幕
- **WHEN** 使用标准 60 秒金融视频计划
- **THEN** opening、advance、overview 和 ending 连续覆盖 1800 帧，advance 独自承担 51 秒行情推进

#### Scenario: 月末与数据起点边界
- **WHEN** 播放日期从一个较长月份的月底滚动到较短月份，或播放日期距数据起点不足窗口长度
- **THEN** 窗口起点截短至目标月有效末日或数据起始日，不因日期溢出跳月、倒退或越过完整展示范围

#### Scenario: 日期单调与逐帧推进
- **WHEN** 随机寻帧或顺序渲染 advance 段
- **THEN** 日期由帧号和本地计划确定、单调不减；多日范围连续推进至终日，单日范围保持该日期

#### Scenario: 分段变速与事件暂停
- **WHEN** 旧计划含有旧式停留段 并显式迁移到 v4
- **THEN** 旧停留段被清除，单一连续 advance 段覆盖日期范围且最终六秒仍按全貌规则播放

#### Scenario: 新版本规则生效
- **WHEN** 制作显式使用 version 4 动画计划
- **THEN** 连续推进且不读取事件材料；旧计划须显式迁移

#### Scenario: v4 计划迁移
- **WHEN** 用户显式迁移旧 v1/v2 价格材料或 v3 折线计划
- **THEN** 仅保留真实 date/close 价格点，生成v4 计划并使旧评审失效

### Requirement: 独立无声制作与交付验收

专题 MUST 使用独立的数据输入和无声验收规则，不套用文章字数、口播和有声评审门禁；这不构成现有文章入口的门禁豁免。流程 MUST 经解析请求、确认标的、搜索与核验价格、保存价格资料、编排时间轴、静音预演、数据与视觉验收，再导出 MP4。最终 MP4 MUST 不包含配音、音乐、音效或任何音轨。

所有正式导出 MUST 具有绑定三类活动材料、渲染构建输入和金融 Python 代码的完整静音预演通过记录，包含预演文件及 SHA-256、全时长、抽检时间码、标签可读、滚动可跟随、坐标稳定及全貌收尾结论。缺失、未通过或过期记录 MUST 阻断正式导出；预演产物不得覆盖正式成片。

#### Scenario: 正式导出
- **WHEN** 标的、价格、时间映射、价格显示、标签可读性和全貌检查均通过
- **THEN** 输出完整终帧可见的无音轨 MP4，验收记录明确价格与视觉结果

#### Scenario: 专题材料与文章入口隔离
- **WHEN** 用户将金融专题材料提交给文章流程入口
- **THEN** 专题仍使用独立材料校验和无声门禁，文章流程不会因此绕过文章审查、字数或有声评审要求

#### Scenario: 旧评审失效
- **WHEN** 动画计划迁移到 v4 或任一活动材料、渲染资产发生变化
- **THEN** 旧评审不得用于正式导出，必须重新生成并评审完整预演

#### Scenario: 新版本规则生效
- **WHEN** 正式导出使用三类 v4 工作流材料
- **THEN** 完整静音预演评审只检查价格标签、滚动、坐标及全貌，仅检查价格标签、滚动、坐标及全貌

### Requirement: 作品材料与版本管理

规范 MUST 定义需求记录、价格序列和动画编排三类作品材料；价格序列至少包含日期和真实收盘值，编排至少包含总时长、日期到视频帧映射、滚动窗口及结尾展开。方法与规范 MUST 纳入 Git，真实行情与生成媒体不得入库，现有三个示例不得新增、删除或替换。

request.json MUST 保持 version 1，prices.json MUST 使用 version 3，animation-plan.json MUST 使用 version 4；价格点为 date/close，计划记录 chartType=line、日历窗口及展开时间段。金融流程 MUST 不创建或要求 旧材料文件。旧 v1/v2 价格材料或 v3 计划在渲染与计划入口 MUST 被拒绝并提示显式 migrate-line。迁移 MUST 保留请求、价格口径、来源、交易日及原始快照，仅提取已有 close，生成v4 计划并使旧评审失效；成功迁移后活动作品不得保留 旧材料文件 或过期评审材料。

#### Scenario: 保存作品与专题规范
- **WHEN** 准备实际作品材料并提交制作方法
- **THEN** 作品保存在已忽略的内容目录或外部内容根，只有规范及共享方法进入版本控制，不强制添加被忽略内容

#### Scenario: 显式迁移旧材料
- **WHEN** 用户调用 migrate-line 迁移 OHLC 价格或 v3 计划
- **THEN** 价格日期、close、来源及快照保持一致，生成 v4 无事件计划，活动目录不保留事件文件或旧事件评审

#### Scenario: 新版初始化
- **WHEN** 用户初始化新的金融视频作品
- **THEN** 仅创建 request、prices 和 animation-plan 三类材料，计划模板为 version 4 且没有事件字段

#### Scenario: 新版本规则生效
- **WHEN** 用户初始化或迁移至 v4 计划
- **THEN** 活动工作流仅接受三类材料，v3 动画计划和过期评审不能直接用于渲染

## REMOVED Requirements

### Requirement: AI 自动筛选可核查事件
**Reason**: 金融视频仅呈现真实日收盘价折线，不再收集、保存或展示事件。
**Migration**: 迁移时删除活动事件材料及其历史副本，并使旧计划和评审失效；保留请求、价格日期、收盘价、来源、行情快照和交易日清单。
