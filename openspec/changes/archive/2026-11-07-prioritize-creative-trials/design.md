## Context

参见 proposal.md。现有 production 将合同、门、采集、评审和状态耦合，必须整体替换。

## Goals / Non-Goals

目标是媒体优先、两类独立评审、局部证据可复用；不改变场景运行时、五类材料或导出门禁，不新增依赖。

## Decisions

- 周期 version=2，review start 显式创建新周期，当前指针保存于 outputs/production/workflow.json；事件放在独立周期目录，不读取旧门历史授权。
- 包和报告 version=2，round 为 trial/final；请求指定 scope（场景可选）、完整窗口、媒体与源码依赖、显示尺寸、必要动态/声音与分工依据。最终包强制绑定当前候选及有效 QA。
- 中性原条件和目标媒体先保存在私有绑定，盲看落盘后进入同轮对照；条件、目标摘要、职责和显示尺寸共同约束问题复查。
- 无机器画面合同。报告保存包摘要、观察、覆盖、调用与同轮对照引用；问题通过报告 ID 关联失败和独立复查，保存原范围。
- 复用现有依赖摘要、安全路径、原子写盘、锁、媒体探测、图像派生与全片播放器；删除仅服务声明量测的模块。
- status 展示有效证据，制作助手依据指南判断阶段；不新建阶段状态机。
- DESIGN.md 作为人读制作依据；完整记录不复制研究与评审。

## Risks / Trade-offs

- 删除数量/布局自动断言后部分错误依赖视觉评审发现：通过完整过程与手机帧证据、独立复查降低漏检。
- 试制依赖必须真实覆盖：包内固定来源摘要，动态引用按既有依赖逻辑保守扩大。
- 新旧不兼容：显式开启新周期，旧目录不删除；不提供适配层。

## Migration Plan

更新七部示例的人读设计及文档，不伪造评审；删除旧命令及合同专属测试，保留独特安全行为回归。定向验证、实施提交后同步规格并自动归档。
