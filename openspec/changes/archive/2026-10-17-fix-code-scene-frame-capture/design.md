## Context

general v8 在 prepare 中录制全画布，再由 composition 回放。现有 CDP PNG 实时采集和 concat 时间戳标准化无法保证每个 1/60 秒都取得新状态。

## Goals / Non-Goals

**Goals:** 逐帧时间精确、动画同步、机器负载不影响运动、既有资源隔离与缓存语义保留。

**Non-Goals:** 修改太阳系镜头或配音、倒序随机 seek、任意异步作品逐像素确定性保证。

## Decisions

- 场景加载前注入受控时间源、RAF 与定时器调度；ready 阶段顺序推进挂载绘制与布局 debounce，开始录制时取当前时间为原点，场景口播时钟仍从零开始。真实资源加载独立进行，超时使用注入前保留的原生真实定时器。
- 内部接口 start/advanceToFrame 只接受连续帧号；上下文时间直接使用帧号/fps，React 同步提交后泵送动画回调与三维绘制，异步任务落定后同时间刷新一次，再截图。
- CSS animation/transition 暂停并定位受控时间；视频拦截 play/pause 与入点，按受控时间 seek 并等待解码。素材无音轨进入片段。
- 逐帧 PNG 序列直接按指定输入帧率编码；输入数量、输出解码帧数均须精确，不使用 fps 补帧或 tpad。
- 缓存键包含全部时钟实现及新采集标识。就绪、逐帧推进和编码错误均不得发布有效缓存。

## Risks / Trade-offs

- 每帧需要绘制屏障与截图，耗时和临时磁盘增长；逐帧落盘控制内存，并记录进度及总耗时。
- 多套动画调度可能有提交顺序差异，必须以真实浏览器验证库动画与 DOM/三维一致性。
- 仅对受控时钟和登记素材提供同步，网络与任意随机源不构成确定性承诺。
