# 设计：面填充的量级该怎么判

## 决策 1：结论来自实测帧，不是来自数字

开放项提出的疑问是「要不要给实心物体的填充单独定一档」。查的顺序：

1. **看帧**（全分辨率，不看缩略联系表）：
   - `freedom`（台阶柱，深色）：柱体读作「细描边 + 耳语填充」，形状毫无歧义，
     标签与轴线下方的基线一起把它钉住；没有「像线框图」的观感。
   - `attention`（冰山，深色）：水上尖端是耳语填充 + 亮描边，水下主体是冷色实心 +
     虚线描边。**这个差就是这张图的语义**——「看得见的一角与看不见的主体
     不是一回事」。给实心物体加重填充会把这个语义抹平。
2. **核对令牌**：三档面已经是按**性质**分家的，不是按数值大小：
   `--fig-surface` 取该主题的亮度阶（中性）、`--fig-water` 是唯一的冷色透明面、
   `--fig-hollow` 是耳语级。浅色主题的实心面 `#ffffff` 正是跟着它自己的面阶走。

所以「单独定一档」这件事实现上早有答案；缺的是把它写成**可机检的不变量**，
以及把「为什么不设数值下限」从注释变成有证据的结论。

## 决策 2：判「同不同」，不判「差多少」

数值大小不能作判据——浅色主题自己的面阶（`--a2v-bg-0` → `--a2v-surface-1`）
就只有 1.13:1，`--fig-surface` 取白色正是跟着它走；设下限等于要求把正确的
白色面阶改成灰色。所以机检只判**关系**：

| 不变量 | 判据 | 抓的是 |
| --- | --- | --- |
| 实心面看得见 | `--fig-surface` ≠ 该主题画布 | 物体在背景上没有面、只剩描边 |
| 三档不塌 | 实心面 / 次级面 / 空壳两两不同 | 层级消失，只剩线型之差 |
| 次级面带冷色 | 色相跨度 ≥ 20（且是透明面） | 水体退成中性灰，「水下是另一回事」丢掉 |

色相那一条是「是不是这一类」的判定，不是幅度阈值：深色实测跨度 128、
浅色 68，离 20 有 3–6 倍余量；退成灰时跨度直接是 0。

## 决策 3：三条都做变异测试

一个只在正确取值上跑过的闸门，分不清「取值是对的」与「闸门量不到」。
所以三条都验过：

- 把水体改成 `var(--fig-surface)` → 「塌成同一个取值：`--fig-surface`、`--fig-water`」；
- 把实心面改成画布色 → 「与画布同色，实心物体在背景上没有面」；
- 把水体改成 `rgba(150,150,150,0.22)` → 「色相跨度只有 0，已经接近中性灰」。

## 决策 4：接受一条已知边界，并且写下来

浅色主题的 `--fig-surface` 正好等于抬升面 `--a2v-bg-2`（都是 `#ffffff`）；
深色主题两者只差 **1.01:1**（`#171e2b` vs `#161c26`）。也就是说：
画在面板**上**的实心物体，两套主题里都没有面阶，识别只能靠描边。

这是接受的取舍：面板本身已经与画布分开，物体不需要再叠一层阶；而且「设下限」
既救不了这一处（它量的是对画布的关系），又会误伤浅色主题。写进文档，
避免下一轮把它当成新发现再查一遍。

## 取舍与边界

- 机检只看令牌层的关系，不看「这个物体到底该不该有面」——那是构图判断。
- 三档的**幅度**仍然不设判据：这是刻意的，理由如上。
