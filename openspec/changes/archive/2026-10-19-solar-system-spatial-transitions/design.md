## Context

当前 28 镜用 `stationArc` 的近天体三点和 2 个单位离开点连接，过场端点直接是相邻站点的近距离点。太阳站结束时相机距水星 2.88，过场 2.30；水星站起点距水星 2.45。位置连续但缺少“从空间上挪过去”的过程。用户要求所有站点统一改成远→近→远，过场升到黄道面上方，且旁白开始前到达特写。

## Goals / Non-Goals

**目标**：每个站点有明显远入/拉远，过场穿过两星之间的空间，旁白开口时已在特写；总 8100 帧、15 段旁白、28 镜不变。

**非目标**：不改旁白/TTS/配乐/字幕层；不改渲染管线；不把站点拆成多个带 segment 的镜头（每段旁白仍只有一个覆盖镜头）。

## Decisions

### 1. 远点：三维距离固定，水平分量受限，其余转垂直

```
D_gap = |相邻站 anchor - 本站 anchor|
H = min(k*d, 0.12*D_gap)
V = sqrt(max(0, (k*d)^2 - H^2)) + 0.15*d
F = P + H*dir_h + 0.15*H*侧向 + V*ŷ
```

`k_in=1.6`、`k_out=2.0`。水平分量压小（0.12 倍站距）让远点几乎在本星正上方，过场因此真正跨越两星之间的水平距离，而不是两个远点都落在中点上导致过场几乎静止。碰撞不足时把水平方向绕 ŷ 向外旋转并每次缩小 H 6%，最多 8 次；禁止进入太阳禁区。

太阳的出站点单独定义：`12.5 * normalize((P_mercury - P_sun) + 0.9*|P_mercury|*ŷ)`，避免沿切线外冲越过水星再折返。

### 2. 过场：显式顶点 + Catmull-Rom

```
apex = midpoint + lift*ŷ + bow*n_t
lift = clamp(0.12L, 1.0, 0.35*min(r_from, r_to))
bow  = 0.08L（水平弦 > 0.25L 时）
```

形状为 `[F_out, 1/3, 2/3, apex, 1/3, 2/3, F_in]`。去掉极坐标对数螺线，避免太阳正上方或短弦时的角度奇点；近垂直过场（地球→月球）走 `bow=0` 分支。

### 3. 方向连续：M 点用实际过场切线反推

`T0 = 过场首段方向`、`T1 = 过场末段方向`；`M_out = F_out - clamp(0.4*dot(F_out-C,T0), 0.25|F_out-C|, 0.6|F_out-C|)*T0`，`M_in` 同理。站点出口/入口与过场首末段同向。

### 4. 时间轴：180 = 120 过场 + 60 接近

- 非 hero 站点镜头：`[旁白开始-60, 旁白结束]`；让出 60 帧给下一个站点的接近，前一段过场因此为 120 帧。
- hero：仍从前一段旁白结束开始，内部拆成 `120 前置过场 + 60 接近 + 绕行 + 60–90 拉远`；地球 hero 的 30 帧尾留白保留。
- 太阳站从特写开始（开场承担接近），只有绕行 + 拉远。
- 总帧数、hold、旁白窗口不变；每段旁白仍只有一个覆盖镜头。

### 5. 速度：分段闭式积分 + 首末平台

每个 phase 的速度形状 `v(f) = v0 + (v1-v0)f/T + P*sin²(π * (x-FLAT)/(1-2FLAT))`，首末各 30% 为平台（速度为 v0/v1），中间隆起补齐距离。`P = (L/T - (v0+v1)/2)/(0.5-FLAT)`；`D(f)` 用分段闭式积分，保证 `D(T)=L` 且端点速度精确。控制点在全局等帧间隔上取（stride 8，最多 64 点）。

端点速度：站点绕行 `S=L_orbit/T_orbit`；过场两端 `clamp(1.25–1.30S, 0.35V, 0.80V)`，再用入口/出口长度封顶。实测边界速度比 1.06。

### 6. 土星 hero 保留旧版 4 点弧

土星环的展开依赖相机跨越环平面并从低处抬升；通用三点弧从统一方位看过去会让环一直半开或反合。使用旧版验证过的相对路径：

```
[(8.334,0.396,-15.195), (11.420,0.792,-10.745),
 (15.670,2.624,0.474), (10.742,4.455,11.411)]
```

站点出口取轨道形状的最后一点，而不是固定第 3 点。

## Risks / Trade-offs

- 固定帧数下，远距离接近/拉远的速度较高（外行星出口峰值约 1–2 单位/帧）；样帧显示连续但偏快，若观感不可接受可缩短远点或延长出口到 90 帧。
- 远点/过场的 Catmull-Rom 过冲可能贴到卫星或土星环；生成器与测试使用同一碰撞口径并迭代方向。
- `storyboard.json` 必须用 `--merge` 合并后再测试，否则测试仍验证旧路径；新增深比较测试兜底。
- 土星 4 点弧的方位依赖世界坐标；若后续调整环的倾斜轴，需要重新验证展开方向。
