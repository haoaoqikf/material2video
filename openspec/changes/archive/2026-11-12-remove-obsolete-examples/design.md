## Context

动机见 proposal.md。两个作品均为完整独立工程，目录内包含被忽略的依赖、缓存和媒体；测试通过 `tests/helpers/examples.py` 集中枚举作品。历史 OpenSpec 混合保存通用能力和作品专属设计。

## Goals / Non-Goals

- 删除完整本地作品及专属内容，保持五部剩余作品可校验与打包。
- 保留五类视频、通用 Painter、字体与声音参考；删除示例不等于删除视频类型。
- 不重写 Git 历史，不将删除行为说成既有历史验证失败的关闭依据。

## Decisions

1. 先确认绝对路径位于当前仓库的指定示例内，再用 PowerShell 原生文件操作递归删除；同时清除被忽略的本地产物，不留下空壳工程。
2. 测试清单保留图文动效的空元组，准确表示类型仍支持但没有随附作品；初始化测试继续覆盖全部五类。
3. 当前导航和命令示范改为仍存在的示例。制作手册删除专属教学与链接，保留通用绘制约束。
4. 历史归档删除专属段落、要求、表行和 JSON 作品条目；混合档案保留其他能力与真实历史结论，并标明经过本轮内容清理。历史统计不改写为本轮的验证结果。
5. 无新增组件或依赖，无需外部方案选型。共享 API 不因删除演示消费者而默认移除。

## Risks / Trade-offs

- 历史材料可能含多行专属内容 → 以完整 Markdown 段落、章节、要求和 JSON 对象清理，复查差异和残余引用。
- 忽略目录删除可能触及外部链接 → 删除前检查目标路径和目录链接，不跟随重解析点清理外部位置。
- 示例枚举变化可能影响动态参数化测试 → 定向验证示例、直接调用方、文档和五类初始化；不运行全仓回归，不重制成片。
