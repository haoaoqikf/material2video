## ADDED Requirements

### Requirement: 评审包内复用原生尺寸 PNG

新建关键帧和过程评审包 MUST 对每个采样帧保留包内净化 PNG，并在请求的展示宽度与原图宽度相同时以同一文件作为原生尺寸展示证据。清单 MUST 维持请求顺序、帧顺序和采样窗口，其他展示宽度继续按原图比例派生。实际证据文件 MUST 在文件清单中登记摘要并由收据绑定。既有评审包的文件、清单和收据 MUST 保持原样。

#### Scenario: 新建关键帧或过程评审包

- **WHEN** 请求尺寸包含某帧的原生宽度和一个不同宽度
- **THEN** 原生尺寸的展示路径指向该帧的净化 PNG，其他尺寸有单独的展示路径，原生 PNG 在文件清单中只登记一次

#### Scenario: 从已封存的旧盲包生成同轮对照

- **WHEN** 新建同轮对照包，且已通过完整性校验的盲包中存在与某帧净化原图摘要一致的展示副本
- **THEN** 新包的对应展示路径指向新包内独立复制的同帧原图，仍登记并核对其实际摘要，其他尺寸保持独立证据文件，原盲包保持原样

#### Scenario: 复用的净化 PNG 丢失或损坏

- **WHEN** 评审包中由原图和原生展示路径共同指向的 PNG 缺失或与封存摘要不符
- **THEN** 评审包证据校验失败
