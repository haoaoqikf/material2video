## Context

见 proposal.md。现有 composition 是确定性帧渲染，不能直接正确捕获自由运行的动画。

## Goals / Non-Goals

支持可信本地 TSX 的自由动画，不承诺逐像素复现，不建设不可信代码沙箱、GLB 导入或第二套声明式 3D 协议。

## Decisions

- 在 prepare 的真实旁白编译之后，使用 esbuild 打包并限制导入范围；批准共享依赖，不安装作品依赖。
- 在独立页面加载组件并等待显式就绪；使用 Playwright CDP screencast 从就绪后采集带真实时间戳的浏览器画面，经 FFmpeg 转成固定尺寸、帧率、帧数的无声视频。组件通过 running 信号启动原生动画。
- 录制正文区域为 864×920，固定在标题下方，标题与字幕由共享外壳绘制，避免作品代码覆盖字幕。
- 缓存键包含构建可达输入摘要、场景参数和本地时间窗、共享实现、锁文件、浏览器与编码配置；准备记录保存原始输入和片段摘要。
- 正式导出仅验证准备与缓存，不运行作品代码。确定性 composition 的源码闸门保持不变。

## Risks / Trade-offs

- 实时录制可能掉帧、重复帧 → 明确文档限制，并保证预演和导出复用片段。
- 作品代码可执行任意浏览器逻辑 → 只用于可信代码，构建限制路径及包，运行阻断外网，超时/异常失败。
- 录制耗时随时长增长 → 内容寻址缓存复用，进度记录场景与状态。
