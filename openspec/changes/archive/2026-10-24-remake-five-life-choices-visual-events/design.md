## Goals / Non-Goals

目标：七段均有清楚事件与强弱分工，行业、学习、结尾形成可辨认回报；连续运动、主体身份、分叉关系与文字时序可靠；最终文件较旧版有具体证据支持的改善。

## Decisions

### 1. 重制约束与记录

采用用户已确认的「保留风格、重构表达」：无声、1920×1080、30fps、深黑蓝白、城市→行业→伴侣→投资→学习，以及连续人生时间轴。允许短暂停镜、文案改写与段内重组；约60秒是创作目标，实际时长由粗样核定并说明偏差原因，仍遵守600秒总上限，不引入新的任意硬区间。

先更新作品重制启动说明与唯一问题表，再实施。保留旧版及直接文件链接，引用真实证据而非复制设计自检结论。当前七段结构作为内容组织基础，不强制沿用旧秒数、旧句子与旧shots划分。仅维护当前新契约，不保留旧实现兼容层。

### 2. 选案与事件试制

三案在硬约束内改变讲述机制：跟随主体经历后果、局部与全貌的认知递进、同一路径不同结果的对照；这三者是候选构造起点，独立观察后可全部淘汰。两个美术方向在同一深黑蓝白体系内比较明暗层级、主体体量与空间构成，不能只换色。按现有规则由隔离子代理执行A/B评审，只提供评审包，不泄露本设计、旧结论或预期答案。

| 段落 | 事件实现方向 | 粗样与最终必须回答 |
|---|---|---|
| 开场 | 尽早发生选择导致的变化，删泛泛铺垫 | 手机前两秒能辨认主体、主题或有意义动作，并有继续观看理由 |
| 城市 | 环境连接开启主体原本不可到达的路线或机会 | 能指出环境改变了什么，而非只有城市名和网络 |
| 行业 | 局部建立相近进展，延迟公开整体差距 | 揭示新增信息，同速可感知且无固定行业优劣排名误导 |
| 伴侣 | 两个主体协调、牵制或互相支持，影响后续状态 | 关系通过行为成立，不只用左右标签宣布好坏 |
| 投资 | 以时间积累形成有边界的示意结果，作为节奏缓冲 | 与行业图区分，不暗示确定收益，不以风险小字补救误导图形 |
| 学习 | 先前积累形成连接，主体进入、经过、换路并继续 | 全过程同一主体，不能只有连接点亮 |
| 结尾 | 熟悉主路仍可认回，逐层公开分支与全貌 | 分叉来源和层级可读，结果观察后才出现收束文字 |

先试制行业、学习、结尾完整窗口，普通段也覆盖逐场验收；关键机制未通过不扩展精制。四张关键构图与完整动态粗片沿用现有阶段，片段试制不替代全片粗片及第一次导演审查。

### 3. 几何、运动与显隐

- 将离散索引定位改成连续插值；用于等世界速度的轨迹预计算弧长表，再按累计距离采样，避免每帧重建。零长度段与端点钳制有明确处理，测试数值行为而非源码字符串。
- 叙事年龄仅作意义定位；主体运动进度和相机路径分别由同一elapsedSeconds确定。学习事件有独立的连续路径窗口，不能被年龄平台期冻结；仍可选择有目的的停留。
- 分支采用共享节点、父子关系和连续路径，主路与前段对应；优先清楚的层级与投影间距，替代100条随机偏移线。预计算静态几何，不在帧循环中重建整棵树。
- 相机的取景、遮挡与公开信息服务事件，不以连续移动本身为质量目标。分支展示、全貌观察与结论文字使用同一时间安排，遮罩避让核心图形；未建立结果观察前不大幅淡出。
- 保留单个life-timeline代码场景，内部镜头和props随新方案更新；不新增渲染器自动运镜或分镜字段。仅试制证明共享链路有阻碍时才提出具体底座变更及范围，不预先实现。

### 4. 验证与共享流程改进

手机主基准沿用852×479，辅以393宽缩略显示；同速、揭示、换轨、分支按已有最小动态证据采样与量测。关键过程不足先补证，不把限制披露当通过。

新增可复用检查应基于本轮真实样例：连续取样是否出现不必要阶梯、世界条件如何投影为可见过程、文字遮罩是否与揭示竞争。共同方法写回视觉事件与复核参考；作品阈值、镜头秒数、树形布局留在本例，不推广为所有题材门禁。若检查发现问题，当轮改进并回归三个示例；确实超范围项登记OpenSpec或PROJECT_PLAN并说明，不拖欠本片核心缺陷。

Python验证示例契约、帧窗、文案与安全区；几何真实行为以可执行的TypeScript测试验证，沿用现有Web Vitest配置并显式覆盖示例模块，避免只检查floor是否消失。Web typecheck/build加上prepare/片段实际录制共同覆盖作品源码，不能只用Web构建声称示例TSX已验证。性能检查预计算复用与代表窗口逐帧成本，和旧版同条件比较，不凭主观宣布性能提升。

### 5. 规格与历史关系

article-explainer中修改完整的固定示例要求，保留美国与太阳系的现有场景，将交通专属场景改为退役边界检查并删除两条退役拥堵波重制要求；既有场景标识保留以满足完整替换校验，不保留交通运行时能力。组件覆盖以现有批准集合为准，移除仅服务旧例的GSAP义务，不借机引入新组件。主规格只在后续实施完成时同步。

旧替换变更保留未完成状态，明确本次接管当前示例重制及列出的规格修正；不将其60fps要求重新应用，也不补勾、归档或虚构旧评审。相对链接写法同时考虑本变更归档后的可访问性，归档时复查。

## Risks / Trade-offs

- 更清楚却仍平淡 → 理解、表现、相对改善分开比较，最终精制候选仍与保留基线核对。
- 行业示意被当固定排名、投资被当承诺 → 审查图形本身与文案边界，不只依赖注释；不伪造统计证据。
- 更多分支损害手机辨认和录制性能 → 以层级、取景和预计算解决，不用数量验收。
- 独立评审不可用 → 显著披露降级，制作可继续但相关项不关闭、不声称制作复核完成。
- 结构变化牵动旧测试 → 新方案确定后同步断言，保留类型、画幅、声音、确定性及内容边界回归。
