## Context

动机见 [proposal.md](proposal.md)。金融场景的 Python 常量、计划校验、React SVG 与注册默认尺寸均为横屏；已有 v6 英伟达材料和成片可用于迁移验收。此次规划不更改它们。

## Goals / Non-Goals

**Goals:** 建立统一竖屏契约、手机可读文字层级、集中说明和可追溯迁移；复用现有金融时间轴与价格算法。

**Non-Goals:** 横屏切换、行情刷新、事件、配音、文章分镜改造、抖音上传。固定三个文章示例不新增、删除或替换；本变更不改变其文章渲染契约。

## Decisions

### 1. 统一 v7 竖屏契约

请求维持 v1、价格维持 v3，计划 v7 固定 1080×1920、30 fps。同步 Python 尺寸校验、props、输出验收、TypeScript 类型、SVG 和 composition 注册默认值；元数据由已校验计划推导。选择明确升级而非在 v6 下静默改变画布，防止旧材料和评审被误用。不维护双布局。

### 2. 布局与字体

安全区 x=64～900、y=180～1500，为项目内保守布局约束。顶部 y=180～540：名称64 px、区间36 px、日期48 px、价格80 px、条件收盘日期36 px。图表绘图区 x=200～880、y=620～1170，纵轴标签右对齐至 x=182，横轴标签区 y=1188～1240。说明区 x=64～900、y=1280～1500，36 px、44 px 行距，最多五行。文字按实际字体宽度折行，所有文字边界和端点光圈必须在安全区内。

标题允许两行，其余顶部信息依次排布；需要超过区域容量则给出字段错误，不缩字或截断。价格文字允许两行。先验收实际布局再固定发布，不以原横屏等比缩放实现。图表曲线使用6 px线宽，端点半径10 px，保持暗色背景与高对比文字。

### 3. 显示名称和说明单一来源

`instrument.displayName` 为可选非空字符串；CLI init 增加 `--display-name`，未提供回退正式名称，不在组件里硬编码证券名称。英伟达作品后续填写“英伟达”，正式名称不变。

说明从现有市场、单位、来源URL主机名、价格口径或指数类型派生；主机名去重。默认三条：市场/单位/来源；价格口径；横纵轴说明。换行总计最多五行，溢出阻断并报告字段，完整URL和资料仍在材料中。移除分散的重复说明和通用核实/休市段落。当前日期与最近收盘日期相同时只显示一次；不同时增加“收盘日期 YYYY-MM-DD”，不改变休市价格逻辑。

### 4. 刻度避让与验收

保持年度边界、15帧平滑扩展、六帧因果纵轴及8%留白算法。稳态按当前区间生成最多四个主要标签，过渡时合并同日期候选，按透明度降序、日期升序确定保留优先级，以实际标签边界加12 px间距执行确定性避让并限制四个；隐藏标签不改变曲线或网格映射。终幕使用冻结后的稀疏刻度。

正式评审继续使用五项结论；`labelsReadable` 证据必须包含360×640缩放检查和安全区检查。评审 metrics 增加画布尺寸、手机检查尺寸和安全区，摘要继续绑定材料与资产，旧记录失效。自动检查边界、最低字号及标签碰撞，人工实际查看缩放画面判断可读性，不凭字号宣称通过。

## Risks / Trade-offs

- 竖屏图表宽度有限 → 稀疏刻度、宽度避让，并抽检扩展过渡前中后与最终全貌。
- 长名称、多个来源或大数字可能超出固定区域 → 实际字体量测、固定字号折行，无法容纳时阻断，要求缩短显示名称或重新安排材料，而非自动省略信息。
- 播放界面随设备变化 → 明确安全区是项目约束，使用360×640画面和遮罩辅助评审，不承诺所有平台界面均无遮挡。

## Migration Plan

1. 扩展 `migrate-line` 支持旧价格v1/v2、计划v3/v4/v5/v6到v7；沿用原材料核验和原子回滚。v6材料只改计划画布、版本与必要说明，行情、日期、来源及快照不变。
2. 完整备份请求、价格、计划、旧事件、评审及预演记录；清除活动过期评审和旧事件，拒绝v7重复迁移。渲染或plan面对旧版仍阻断并提示显式迁移。
3. 旧MP4保留，新竖屏英伟达成片使用独立名称 `financial-line-portrait.mp4`；失败时从备份恢复材料，重新完整预演前不得正式输出。
4. 实施时同步README当前状态、金融技能文档以及主规格中遗留的横屏Purpose（提案阶段不修改主规格）。通过测试、手机评审和渲染验收后提交代码，再按项目约定同步规格并归档。
