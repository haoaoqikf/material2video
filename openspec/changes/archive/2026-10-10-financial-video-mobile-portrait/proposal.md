## Why

现有金融视频采用横屏，字号最小为 15～18 px，在手机竖持观看时难以阅读。标题、来源、口径和坐标说明分散在多个位置，需要改为适合抖音观看的竖屏布局并整合文字。

## What Changes

- **BREAKING**：金融视频采用 1080×1920、30 fps，动画计划升级为 v7；不新增横屏切换选项。
- 顶部集中显示短名称、完整区间、当前日期与收盘价，中部展示持续折线，下方统一显示市场、单位、来源、价格口径与坐标说明。
- 提高字号并约束手机安全区，增加 360×640 缩放画面验收与刻度避让。
- 请求增加可选 `instrument.displayName`；保留正式名称和完整来源材料。
- 显式备份迁移旧计划，保持行情不变，作废旧评审并保留已有成片。
- 后续实施验收使用英伟达现有材料重新制作竖屏视频。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `financial-timeseries-video`：竖屏场景、手机文字可读性、统一说明、v7 材料与显式迁移、完整预演验收。

## Impact

涉及金融 Python CLI、材料校验与渲染验收、共享 React composition 及其元数据和测试；实施时同步 README 和金融专题技能参考文档，不增加外部依赖。保持真实行情、分阶段横轴、因果自适应纵轴、静音与现有来源核验机制。
