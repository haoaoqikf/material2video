## Context

`prepare()` 把每一幕分别交给 `code_scenes.record()`，用 Playwright 逐帧录成独立 mp4；合成层只回放片段并按 `transitionFrames` 做透明度交叉。跨幕的三维场景各自从第 0 帧开始，所以相机位置、焦点和粒子相位都不可跨幕连续。旧 63.73 秒版本已经用「单幕 + 11 镜、路径首尾相接」验证过单幕路径；本次把它恢复为默认做法并扩展到 28 镜。

## Goals / Non-Goals

**目标**：单幕 8100 帧、15 段旁白之间各 3 秒静默、28 个镜头位置/方向/速度连续，开场从太阳系上方连续俯冲到太阳。

**非目标**：不改变 TTS 文本、音色、语速与配乐；不改变天体资产与压缩坐标的轨道半径；不引入跨幕状态共享；不新增用户确认或 CLI 门禁。

## Decisions

### 1. 单幕而不是「15 幕 + 叠化」

单幕是唯一能让三维场景状态跨站持续的路径。代价是同一幕内旁白首尾相接，无法逐幕声明留白，因此增加 `holdFrames`。

### 2. `holdFrames` 而不是幕级段间留白

逐段声明可以按旅程长度分配静默（本片统一 180 帧，但木星→土星等长过场可单独加长）。它只改变 `explainer_prepare` 的拼接与 `minimum` 计算：在每段音频后追加 `(None, hold)`，`speech_start` 后移；`segmentWindows` 仍只表示发声窗口，字幕、音效定位、QA 与 TTS 缓存语义不变。最后一段不得声明，收尾由 `tailFrames` 负责，避免歧义。

### 3. 全部镜头 `linear` 缓动

`CameraRig` 把 `easing` 作用在单镜头局部进度上。`sineInOut` / `quintInOut` 在两端导数为 0，会让相机在 28 个镜头边界全部停顿。`linear` + 等帧间隔控制点才能让速度只由路径形状决定。

### 4. 全局速度曲线采样控制点

每个镜头按目标速度曲线积分出「帧 → 弧长」映射，再在等帧间隔上取控制点：

- 站点镜头：匀速绕行，速度 = 站点弧长 / 旁白帧数；
- 独立过场：两端速度分别接住相邻站点，中段用 `sin²` 隆起；
- hero：前置过场从上一站速度加速到本站站点速度，到站后匀速；
- 开场：`sin²` 俯冲，最后 90 帧匀速贴近日面。

`CatmullRomCurve3.getPoint()` 按段均匀参数化，等帧间隔控制点因此近似这条速度曲线。生成器用运行时相同的曲线采样检查边界速度比（本片最大 1.65）。

### 5. 离开点与方向连续

站点路径末尾追加一个离开点：沿「本站 C → 下一站 A」的螺线最多走 2 个单位。站点最后一小段与过场第一段同向，过场镜头再以同一焦点继续，镜头边界只剩速度变化。

### 6. 螺旋布局

主序天体方位角随轨道半径单调递增（0.30→4.45 rad）。相机因此只向外、不折返，过场长度与旅程顺序一致。卫星角度是世界方向角（`positionOf` 把它当相对母星的偏移方向），必须落在相机一侧且不进入母星→下一站的路径。

### 7. 后期参数统一

`PostFX` 只在镜头内读取 `post`，不做边界混合。28 个镜头写同一组 `post`，否则每个边界都会跳变；木星不再单独关闭 Bloom。

## Risks / Trade-offs

- 单幕 8100 帧仍要逐帧录制，时间与磁盘占用与旧版相同；缓存键变化会重新录制整幕。
- CatmullRom 过冲可能擦过天体或土星环：生成器按 240 点采样检查，最近余量 0.85。
- 太阳站近景中远处天体仍可见（压缩坐标结果）：保留，不通过隐藏天体制造跳变。
- TTS 变长会挤占 8100 帧：`prepare` 在录制前失败；先吃 669 帧尾留白，再均摊减少 hold，绝不截断口播。
- 段间静默可能被 QA 标为静音候选；配乐仍在播放，按设计静默复核。

## Migration

storyboard 升到单幕结构，旧 15 幕分镜不再保留。准备指纹、片段缓存与主规格同步更新；旧成片作为历史记录留档，不参与新版本验收。
