## Context

现有制作合同 v2 和整场细节指导已覆盖六部分编排、独立评审与返工。当前问题在具体设计与取样：luck-on-stage 的四类数据场景未逐一对应原参考，解释文字仍采用辅助字幕层级。动机见 proposal.md。

## Goals / Non-Goals

目标是在现有记录和轮次中，使每场采用目标、实际证据与表现结论能互相对应。保持渲染、分镜与制作合同的现有结构，不新增机器审美判断、表单或强制实时试听要求。

## Decisions

1. 以 scene-detail-design.md 维护操作顺序，stage-plan/stage-iterate 仅导航，visual-review-rubric 补观察边界；不复制审核人数策略。
2. 用本场变化与注意力路径取代泛化效果清单。颜色、字号和动作仍由题材/画幅决定，不设置全局阈值。
3. 参考按观看任务配对，未直接对应时明确迁移范围；旧版只证明相对收益，不替代参考兑现。
4. 规范示例只补核对过源码的说明，不追溯重制。无运行时或格式变化，因此不改校验器和媒体；既有文档链接/路由测试与示例校验足以检查技术边界。
5. 用户已授权连续实施；流程验证提交与归档完成后，在忽略的作品目录保留旧版并重做45秒视频。作品实现复用已有纯时间SVG、D3几何和风格光效；新增表现前核对成熟方案，避免自走动画和不必要依赖。

## Risks / Trade-offs

- 指导继续泛化 → 使用规范示例真实代码与本轮具体场景演练核对。
- 大字挤占主体 → 先减文案与重复标签，再在原生和手机尺寸观察。
- 把审美意见当新门禁 → 明确沿用既有风险、轮次、独立隔离与问题规则。
- 文档更新被当作成片完成 → 流程与作品各自保留验证证据；作品单独重新试制、终审及交付。
