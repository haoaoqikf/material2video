## MODIFIED Requirements

### Requirement: 共享动效组件兼容代码场景

作品 MUST 在作品本地保存所采用的组件和资源，构建器 MUST 从作品自身安装和锁文件解析实际依赖。主项目参考未被作品采用时 MUST NOT 成为其运行或指纹输入。

已采用的组件 MUST 由受控时间和显式进度、数据、缓动或种子驱动。普通代码场景内 MUST NOT 使用依赖 Remotion composition 上下文的组件。顺序和纯时间采集沿用相同的作品组件，纯时间采集 MUST 通过静态源码闸门与重复采样验证。

#### Scenario: 顺序录制
- **WHEN** 顺序录制场景使用作品本地动效
- **THEN** 组件随受控场景时间逐帧更新。

#### Scenario: 纯时间录制
- **WHEN** 声明 pure-time 的场景使用作品本地动效
- **THEN** 静态源码闸门通过，正倒序同一帧的 PSNR ≥ 60 dB。

#### Scenario: 文本与图表
- **WHEN** 纯时间场景使用本地排版和图表
- **THEN** 在字体就绪后，相同帧的文字度量与图形映射可重复求值。

#### Scenario: 构建边界
- **WHEN** 场景导入已采用的本地组件或直接依赖
- **THEN** 依赖按作品的声明及锁文件解析。
