# 验证与交付审查

## 范围

本轮只修改设计方法、审核指导、规格与示例的后续应用说明，没有修改运行时代码、分镜 JSON、媒体、CLI 或旧作品评审。检查 `src/m2v/` 与 Skill 脚本后，运动静止阈值仅用于 QA 测量，没有对应的审美否决实现；金融日期等单调约束属于数据契约，保留。无需为这次指导修订改写校验器，也不新增自动审美判断。

## 规则情景推演

按视觉复核的[成对演练](../../../../.agents/skills/material2video/references/visual-review-rubric.md#创意保护判断演练非成片评审)逐项静态推导，共10组、20种情形：

| 组别 | 保护条件的推导 | 真实失败条件的推导 |
|---|---|---|
| 静止 | 有观察／消化作用，不按时长否决 | 无用途等待仍返工 |
| 延迟揭示 | 按完整窗口核对回报 | 完整窗口后核心误读仍必改 |
| 动态文字 | 文字承担表达不受去文字测试否决 | 机械替换且无推进仍处理 |
| 声画协作 | 静音不完整不等于失败 | 缺声／时序错误核实修复；主观听感证据不足如实披露 |
| 母题 | 语境改变含义可成立 | 无新作用不能靠作者解释放行 |
| 信息图 | 形式标签不产生必改 | 关系误导仍属缺陷 |
| 缩略图 | 缩略图看重心，正文按手机尺寸 | 手机关键字不可读须修复 |
| 减法 | 保留有证据的情绪收束 | 无理解与体验用途的重复删短 |
| 重要返工 | 同时检查收益与表达损失 | 核心缺陷不因保留创意而豁免 |
| 抽象表达 | 不强制唯一感受或答案 | 缺证和目标失败不能改名为通过 |

各组的规则推导能区分两类情形；这是制作者的文档逻辑检查，不是独立子代理评审、实际样片测试或观众验证。
