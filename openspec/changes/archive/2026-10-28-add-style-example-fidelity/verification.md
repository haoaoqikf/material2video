## 三、独立冷审

- 执行方式：独立子代理，**只读并排图**，不读源码、文档、规格、README 或本记录。
- 投喂：6 张并排图（C 夜曲 3 组、B 寓言 3 组）。
- 结论摘要：
  - **C 夜曲**：骨架同构，可读作同一部片的不同章节；`fold` 那组最接近「是」。
    「同一系统的另一个渲染档位」而非同一卷胶片。
  - **B 寓言**：材质、色彩、造型同一个世界，但镜头语言（景别、信息层、标题）此前换了一整套，
    尤其 wander 一格余量已接近边界。
- 指出的前三问题与处理：

| 冷审指出 | 处理 |
|---|---|
| C：底部字幕缺英文斜体副句，顶部标题字号偏大 | 顶部标题压到 40px 并加一行小字 caption；英文副句**不补**（项目「装饰英文从紧」），写入已知偏离 |
| C：景深与光晕衰减消失，画面像平面发光点 | 珠子改为四段径向渐变、加 `blobHalo` 底光；未引入真实景深（2D 绘制层无 DOF），登记为能力边界 |
| C：红球实体块过大，色重心从「青点+一点红」变成「一大块红」 | 反相处理：珠子为青、红细胞为深红，两者分幕出现，不再同屏抢焦点 |
| B：左上 HUD 读数卡是参考中不存在的新元件 | **保留**：它是风格包定义的「一把尺子」（`tokens.gauge`、GUIDE §5）。参考的这 33 秒没用它是选段差异，不是错误。写入已知偏离 |
| B：主体景别差 3–4 倍，鸽子只占 10–15% | **已修**：重设六幕镜头表并把鸽子本体放大到 1.5 倍，现占画面高度三成以上 |
| B：顶部标题与底部字幕双句，参考只有一句 | **保留**：`top-line` 是风格包的组件，承载「这一场要让人记住的一句」；与字幕语义不重复（`top-line` 写结论、字幕写叙述）。写入已知偏离 |

## 四、未解决与后续项

1. **C 夜曲缺真实景深**。2D 绘制层没有 DOF，只能靠暗边与底光模拟；要真正实现需三维或后期能力，
   属新增能力，另走评估。
2. **B 寓言缺「计时器特写」幕**。参考第 2 镜是 `r=260` 的计时器大特写；补这一幕要改分镜结构
   （多一幕或少一幕），本轮未做。
3. **风格示例的 `style-reference.md` 与并排图不入库**，证据只在本机。与 `videos/` 的既有规则一致。
4. **全量 pytest 的本机编码问题**未修，属环境而非代码；已在上面记录绕过方式。

## 五、结论

两个示例从「深色底/浅色底上的排版页」改为「有质量感的实物在演」：fold 重建了单一世界坐标与
一条连续相机，pigeon 重建了六幕镜头表与分层鸽子，两者都补上了与画面动作对齐的合成音效，
亮度、饱和度与主体占比回到参考量级。材料齐全（八项指标、并排基准、独立冷审、逐幕代表帧），
按「过程完备即可」的验收口径，本变更的还原度验收完成。

冷审判定的残余差异（英文副句、HUD 卡、顶部标题、景深）均已在第 4 节与示例 README 的
「已知偏离」中披露，不以作者解释替代观察。
