## MODIFIED Requirements

### Requirement: 双来源音效库

系统 MUST 通过作品内的 `assets/sound-recipe.json` 和本地 `setup` 生成或导入音效。合成目录 MUST 可查询，并覆盖键盘、连续打字、鼠标、火花、电流、掠过、碰撞和提示音。合成 MUST 记录作品本地生成器版本、参数和种子，相同配方产生相同文件。第三方 MUST 支持 HTTP(S) 直链与作品内本地文件导入，记录来源、作者、许可、原始及落盘文件摘要和实测音频信息。未知许可、空音频、损坏文件 MUST 拒绝，批次失败 MUST 不更新已有记录。

#### Scenario: 合成可复现
- **WHEN** 使用相同作品配方恢复键盘或火花音效
- **THEN** 得到同摘要的本地音频及作品本地生成器记录，目录说明适用场景、时长与循环能力。

#### Scenario: 第三方导入失败
- **WHEN** 批次中有未知许可或不可解码音频
- **THEN** 不发布该批记录，不改变已有文件和记录。

### Requirement: 本地登记复核

分镜 MUST 可以通过音效 ID 引用统一登记素材。准备 MUST 离线复核全部登记文件、来源记录、摘要及音频参数并绑定输入指纹，变更后旧准备 MUST 失效。主项目创作命令读取音效登记时 MUST 接受有效的作品本地生成器记录，并拒绝旧共享生成器记录。导入素材 MUST 不暴露给画面素材服务器。

#### Scenario: 替换文件
- **WHEN** 登记音效在导入后被替换
- **THEN** 准备拒绝，已有准备指纹也因文件变化失效。

#### Scenario: 本地生成器身份
- **WHEN** 本地 `setup` 生成音效且分镜以 ID 引用
- **THEN** 本地校验与主项目读取分镜的创作操作均接受生成记录，旧共享生成器记录不能作为当前来源。
