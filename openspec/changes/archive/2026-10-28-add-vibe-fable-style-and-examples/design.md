## Goals / Non-Goals

非目标：不新增视频类型、CLI 命令、分镜字段、制作门或审核轮次；不改 `examples/` 的三个固定示例与数量上限；不为示例补造核心样片、粗片与终审记录。

## Decisions

- **示例放 `styles/examples/<style-id>/<slug>/`。** 风格包指纹覆盖包内**所有**文件；示例若放进 `styles/<id>/` 内，改示例会让所有选了该风格的作品准备失效。单独一层保留目录后，示例改动只影响自己。
- **风格发现跳过保留目录。** `RESERVED_DIRECTORIES = {"examples"}`；其余直接子目录仍必须是有效包，既有「非法包明确失败」的行为不变。按 `examples` 直接加载风格明确失败。
- **B 寓言不携带字体。** 扁平外观采用无衬线；仓库已注册 `M2V Sans` 与 `M2V Inter`，复用比再造一份字体子集更简单，也避免增加一次字体恢复步骤。代价是包内不做严格缺字检查（沿用全局字体审计）。

## Risks / Trade-offs

- 保留目录被误当作风格包 → 注册逻辑与测试同时覆盖；`load_style("examples")` 明确失败。
- 与 `examples/` 的三例产生职责重叠 → `examples/` 演示共享能力（档案、复利、太阳系），`styles/examples/` 只演示风格包；文档写明分界。

## Migration Plan

新增包与示例；修改注册逻辑、测试与文档。运行风格、示例、文档路由相关回归与 slow 用例；提交后同步 `style-registry` 主规格与新增 `vibe-fable-style` 主规格，归档变更。既有作品不受影响：未选择风格的作品不会读取新包，`examples/` 三例行为不变。
