## Context

Painter 已有 Canvas 绘制、相机求值、绘制图层合成和量测代理；通用声音已有本地音床、音效、旁白闪避和母版归一；制作流程使用逐场表与 DESIGN.md。

## Goals / Non-Goals

**Goals:**

- 让复杂对象能先整体合成，再参与外层变换和透明度。
- 提供无状态、确定性的数值关键帧求值和预计算模拟范例。
- 让开发者能预览并查找真实运行时能力。
- 在全片时间轴上描述声音层级和主动静音。
- 让长片按悬念、实验、定义、应用和回扣形成递进。

**Non-Goals:**

- 不建设通用物理或角色动画引擎，不允许逐帧累积状态。
- 不把开发货架注册成作品或新增固定视频示例。
- 不自动生成音乐、不引入第三方音乐服务、不改变音频声道或响度目标。
- 不为长片规定固定章节数和统一时间配额。

## Decisions

- Painter 新增离屏 `layer` 绘制原语：子绘制在临时画布完成，整体 alpha/变换/混合在合成时应用；资源按尺寸复用，异常时通过 `finally` 恢复绘制状态。量测代理仍报告子对象的原始绘制项，并明确整体变换后的可见边界仍由像素复核。
- 数值关键帧使用 `{at, value}`，输入严格递增，端点外保持端点；支持线性、保持和 Catmull-Rom 平滑模式。平滑值不自动夹断，调用方若表达有界量须显式夹断。相机仍用相机专用求值器。
- 模拟范例预计算固定种子数据，每帧纯函数读取进度对应样本；不添加持久状态模拟器。
- 开发货架采用 Web 开发预览入口，不导入生产 Composition，也不改变合同页入口或打包运行时。
- 声音扩展采用全片帧定位的 gain envelope 段和显式静音段；将包络离线采样成全片控制曲线，应用于现有混音轨。未声明字段时保持当前行为；静音优先级最高，最终响度处理后检查静音区残余和边界点击。
- 长片结构只作为可选制作方法，写入 DESIGN.md 和现有逐场表，不新增章节字段、门禁或审核轮次。

## Risks / Trade-offs

- 离屏画布提高内存与合成开销 → 临时画布按缓冲尺寸复用，测试嵌套和生命周期。
- Catmull-Rom 在极端间距可能过冲 → 文档说明且不隐式夹断，由场景显式约束。
- 声音包络增加混音复杂度 → 先解析为单一全片增益曲线，再应用到轨道；验证帧边界转换和静音优先级。
- 开发货架可能误成第二运行时 → 只挂真实 Painter API 的演示，构建中排除开发入口。
