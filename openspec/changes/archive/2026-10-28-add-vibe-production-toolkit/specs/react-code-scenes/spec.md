## MODIFIED Requirements

### Requirement: 代码场景必须使用确定性的纯绘制原语

代码场景 MUST 可使用离屏分组和数值关键帧原语。原语 MUST 只依赖明确输入，不读取挂钟、随机源或上一帧状态。离屏分组 MUST 将子绘制作为一个整体参与透明度与变换合成；数值轨道 MUST 对严格递增关键帧作纯求值。

#### Scenario: 整组半透明绘制
- **WHEN** 场景将多个重叠图形作为一个整体淡入或变换
- **THEN** 分组先绘制到离屏层，再统一合成，使重叠区域保持正确的整体透明度语义

#### Scenario: 数值关键帧求值
- **WHEN** 场景用关键帧轨道求某个时间点的数值
- **THEN** 相同输入返回相同值，端点外保持首末值，非法排序被明确拒绝

### Requirement: 开发者必须能预览共享绘制能力

开发环境 MUST 提供组件货架，按能力展示实际共享绘制 API 的最小调用与动态结果；该入口 MUST NOT 成为正式作品 composition 或改变生产输出。

#### Scenario: 浏览和检查演示
- **WHEN** 开发者打开货架并选择一项能力
- **THEN** 可观察其动态效果、控制播放进度并查看对应最小调用
