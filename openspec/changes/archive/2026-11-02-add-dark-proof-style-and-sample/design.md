## Context

参考片《重复》为 1920×1080、30 fps、62.03 秒；实测整体响度 −14.1 LUFS、真峰值 −1.3 dBFS、LRA 3.1 LU，`scene>0.25` 的硬切只有 40.47 秒一处，其余均为溶解、重影与原地形变。画面主体约占画高 25%–55%，内容像素仅占全帧 2%–12%，底色接近 `#0C0C0E`，米白、金、朱红承担固定语义。完整拆解、时间轴、十五条可迁移规则与八项指标见 [reference-analysis.md](reference-analysis.md)。

仓库现有五套风格：`vibe-fable`、`vibe-night`、`doc-archive`、`count-ledger`、`deep-journey`。风格注册、指纹剪枝、组件导入与 v8 录制链路均已存在；新增风格不需要改类型或渲染器，只需新增包、示例、测试与文档名单。用户已确认新增独立风格包、示例选题《样本》、1920×1080 横屏无旁白。

## Goals / Non-Goals

**Goals:**

- 用一套可安装的包承载参考片的论证语法，而不是把参考片当模板复制。
- 《样本》在 58 秒内完成“钩子 → 证据 → 转折 → 文化锚点 → 数学收口 → 回扣”，并能在手机横屏读清。
- 示例可 `validate`、`prepare`、渲染，具备原创声音、素材配方、风格契约与独立冷审证据。
- 六风格/六示例的代码、测试与文档保持一致。

**Non-Goals:**

- 不新增视频类型、CLI 命令、v8 字段、制作门或审核轮次。
- 不修改现有五套风格包或其示例；不重制参考片；不把参考音轨复用到成片。
- 不提供通用图表库、3D 场景、角色表演或真实档案素材；不把风格包做成自动换肤。
- 不在本变更内实现竖屏版、旁白版或长片版《样本》。

## Decisions

### 1. 新增 `dark-proof`，不扩展 `count-ledger`

`count-ledger` 的核心是“一枚 = 一个单位”的圆片、世界坐标相机与资金状态，适合数量累积；参考片的语法是“一个巨型数字 + 一个可数总体 + 一条论证”，需要点阵、曲线、柱列、双语论证字幕与手绘描线。把两套机制并入一个包会让 `count-ledger` 的 tokens、组件与现有示例指纹同时变化，也会让“可数物证”的语义边界变模糊。因此新增独立包，旧包零改动。

备选：扩展现有 `count-ledger`；因会改变其指纹、示例与文档契约，且两套运动人格不同，放弃。

### 2. 自带语义色板，不照搬参考片色值

参考片实测约为底 `#0C0C0E`、米白 `#F0E8D8`、金 `#E8C058`、朱红 `#C81830`。本包取同一色彩关系但使用自己的值：`ink #0A0B0D`、`ivory #F3EDDC`、`gold #E6BE55`、`ember #C43B2E`、`muted #8B8981`、`line #3A3A3C`。语义比色值重要：金色只给“被强调的样本/累积结果/揭示”，朱红只给“失败/噪声/被证伪”，米白给“已知/中性”，不引入第四种强调色。这样既保留参考片的观看方式，又避免把某条作品的成品配色当成方法。

### 3. 组件按“论证动作”拆分，不按题材拆分

包内提供舞台、巨型数字、点阵场、论证图表、计数器、双语标题、屏幕字幕、手绘描线、确定性工具。组件只接收数量、状态、几何、缓动与文字，不内置题材数学、文案或事件时刻。示例的《样本》数学与分镜留在作品目录。这样后续作品可以换题，风格包不变。

图表与点阵用 SVG/Canvas 绘制，不引入 ECharts 等运行时依赖；点阵在 1000 点规模下只画圆，不加滤镜。手绘描线接受外部 path，示例自己提供大象轮廓，包内不内置角色。

### 4. 《样本》采用一条“样本 vs 总体”的视觉母题

全片只问一件事：**你看到的是样本，还是总体？** 3 个金点、1000 个点、点阵上的线、盲人摸象的三个取样窗，都是同一母题的不同尺度。结尾回到 1000 点中的 3 个金点，观众获得的是“同一画面、不同理解”，而不是新增一个结论卡。

八拍时间表（30 fps，1740 帧，58 秒）：

| 时间 | 帧 | 画面 | 文案/结论 | 作用 |
|---|---:|---|---|---|
| 0.0–6.0 | 0–180 | 巨大“3”落定，随后拉出 1000 点阵，3 个金点 | 3 条评价，能定义一个人吗？ | 钩子；先给数字，再给比例 |
| 6.0–13.0 | 180–390 | 3 点中逐个翻红/翻金，均值 100→67→33→67 | 样本越小，结论越跳。 | 让“一条差评”产生可见的 33 点摆动 |
| 13.0–20.0 | 390–600 | n=3/10/100/1000 四列点云，带宽度收窄 | 样本越大，均值越稳。 | 用同一分布展示样本量 |
| 20.0–28.0 | 600–840 | **全片唯一硬切**：3 点连成手绘线；24 秒 1000 点浮现，线溶解 | 三个点，也能连成一条线。／但线，是人画上去的。 | 论点转折；线失去权威 |
| 28.0–35.0 | 840–1050 | 极端观测第二次靠近均值；上下两组箭头 | 第一次的极端，第二次多半靠近平均。／不是退步，是回归。 | 引入均值回归，防止“只看大样本”变口号 |
| 35.0–43.0 | 1050–1290 | 手绘大象轮廓 + 三个取样窗；局部纹理各自成立，随后拉回全象 | 盲人摸象：局部是真的，整体不是。 | 文化锚点；说明小样本不是假，是不全 |
| 43.0–51.0 | 1290–1530 | SE = σ/√n 曲线；n=3→1000，标记“≈18×”；n×4 箭头 | 误差减半，样本要翻四倍。 | 数学收口；给可执行规则 |
| 51.0–58.0 | 1530–1740 | 回到 1000 点阵与 3 个金点，点阵全显；片名《样本》 | 样本越小，故事越大。／先把样本做大，再下结论。 | 回扣开场；不设 CTA |

### 5. 全片只保留一次硬切，放在 20 秒的论点转折

参考片的唯一硬切在 40.47 秒，从“试得越多越近”的柱状图切到“放弃 vs 坚持”的对比页，承担论证转折。本片把唯一的硬切放在 20.0 秒：从“样本量四列”切到“三点连线”的空场。前一段是“证据在增加”，后一段是“证据其实没增加，只是人画了一条线”；硬切让观众感到判断被重置。其余六处转场全部用 0.5–0.8 秒溶解。

### 6. 无旁白，声音承担“前轻—中抬—尾收”

示例无旁白，全部文案由屏幕字幕承担；这也让风格包可以被有声作品复用（`requires` 不限制旁白）。声音沿用参考片的动态机制而非素材：0–6 秒低频环境床轻入，6–20 秒随点阵密度增加而抬升，20 秒硬切处用短促低频撞击 + 半拍留白，43 秒公式段再抬一次，51–58 秒收束。环境床与事件音由作品内确定性合成脚本生成，24 kHz PCM16 单声道，CC0-1.0，配方固定摘要；母版目标 −14 LUFS / −1 dBTP。

### 7. 固定示例集合五改六，作为本变更的显式契约变更

`AGENTS.md` 的“风格示例集合固定”当前列五个。新增第六个会改变这条项目约定，因此本变更把它作为显式变更处理：同步 `tests/helpers/examples.py`、`styles/README.md`、README、[风格接入契约](../../../../.agents/skills/material2video/references/style-pack.md)、`AGENTS.md`，并把 `style-registry`、`article-explainer`、`vibe-fable-style` 与 `video-frame-rate` 中写死的“五个”改为“六个”。现有五套风格包内容与指纹不变。

### 8. 参考拆解作为本变更的独立证据文件

完整拆解放在 `reference-analysis.md`，包含证据类型、时间轴、强视觉事件、导演设计、视觉语法、母题、声音、表面风格/底层机制两栏、十五条规则、采用规则与八项指标。示例实施时把摘要与采用结论转入 `styles/dark-proof/examples/sample/DESIGN.md` 的“参考拆解”区块，并按需把八项指标回填到 `outputs/style-reference.md`。参考片文件、截图与音轨不进入成片、风格包或渲染输入。

## Risks / Trade-offs

- [参考片的气质被误读成“黑底 + 金色”] → 以八项指标与十五条规则约束，不只对齐色值；冷审只看并排图，先描述再判断。
- [巨型数字与点阵在手机横屏不可读] → 关键数字 ≥220 px、点阵关键点放大、在 393 宽复核；点阵只作纹理，不作唯一信息源。
- [58 秒塞入四个概念（样本量、回归、盲人摸象、标准误）造成堆砌] → 每拍只回答一个问题；概念之间用同一母题连接；先压缩解释文字、缩短转场与重复画面，不静默删除 spec 要求的概念；若确需删减，回到提案与规格调整后再实施。
- [数学示例被误读为现实统计结论] → 小字方法说明写明随机、独立、同分布；文案使用“在这样的假设下”，不指向真实人群或产品。
- [新增第六示例使既有“五示例”规格与测试失真] → 本变更显式更新名单与四处主规格；测试以 `STYLE_EXAMPLES` 单一来源派生，不新增第二份硬编码。
- [示例声音与画面事件脱钩] → 事件音引用 `eventId`，`outputs/events.json` 复用同一事件帧；`SOUND.md` 登记角色、assetId、参数与作用。
- [风格包组件增长为“万能图表库”] → 只保留论证动作需要的组件；题材专属形状、数学与文案留在作品内。

## Migration Plan

1. 新增 `styles/dark-proof/` 与 `styles/dark-proof/examples/sample/`，不改现有风格包。
2. 更新 `tests/helpers/examples.py` 的 `STYLE_EXAMPLES`，跑六示例校验与风格注册回归。
3. 同步文档与 `AGENTS.md` 的固定名单；确认现有五套风格指纹不变。
4. 渲染前恢复字体与示例声音；示例产物写入 `outputs/`，不提交生成媒体。
5. 若实施中发现风格加载器或构建边界缺口，先在本变更补任务与规格，再改 `src/m2v/`；否则不改核心代码。
6. 回滚：删除新风格包、示例与名单项，恢复四处规格原文；现有风格与作品不受影响。
