## Context

见 proposal.md。当前前端布局和 Python 评审报告分别保存边界，需要同步。

## Goals / Non-Goals

保证金融视频文字及端点处于统一安全区，不改变材料格式、价格口径、时间轴及其他类型。

## Decisions

重新布局而非整体缩放，保持字体与线宽。标题居中显示且按自然字宽排版，避免短标题被拉伸。文字边界为 140～940，绘图区为 220～928。市值预算扣除年份的测量宽度和 32 px 间隔。风险提示使用现有文字换行函数，20 px、28 px 行距、最多两行，首行基线仍为 1460。

保留报告中的 valueAxisSafeArea 字段以兼容调用方，但边界与 safeArea 相同；由 Python 公共金融常量提供报告边界。标题本金调用既有格式并加“元”，标的优先 displayName。

## Risks / Trade-offs

收窄可能令长标题或多来源超容量 → 保留字号和容量门禁，浏览器验证真实文字边界。留白不保证适配所有平台界面 → 以手机比例遮挡叠加检查，实机效果仍需观察。

## Migration Plan

已有材料无需迁移；构建指纹变化使旧准备及评审过期，重新准备、预演、评审后渲染。回退代码即可恢复旧布局，仍需重新制作。
