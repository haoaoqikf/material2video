## MODIFIED Requirements

### Requirement: 门状态必须由证据派生

系统 MUST 使用追加式事件日志记录门事件，并 MAY 从中派生当前状态快照。状态 MUST 使用统一词汇：未开始、进行中、待评审、阻断、通过、过期、不适用、等待前置。

`通过` MUST 同时满足：证据文件存在且摘要匹配、上游摘要未变化、所需独立评审证据存在、没有未关闭必改。缺少证据时 MUST 显示为未开始、进行中、待评审或过期，MUST NOT 显示为通过。降级评审 MUST 以旗标显示，MUST NOT 计为独立通过。

#### Scenario: 缺少检查点报告

- **WHEN** 某个门没有对应的证据文件或证据文件已损坏
- **THEN** 该门显示为未开始或待评审，不能根据目录中存在其他文件推断通过

#### Scenario: 上游变化

- **WHEN** 分镜或场景源码摘要发生变化
- **THEN** 依赖的下游门自动显示为过期，旧结论只保留为历史

#### Scenario: 降级评审

- **WHEN** 某个 A 级评审由角色分离自审完成
- **THEN** 状态显示降级旗标，不得显示为独立通过或计入已解决


自身证据与评审结果 MUST 由 evidenceStatus 保留；prerequisites MUST 列出未完成前置门，ready MUST 仅在自身通过／不适用且前置齐全时为真。本门自身通过但前置未完成 MUST 显示等待前置，MUST NOT 标成自身证据过期。

#### Scenario: 有效证据等待前置

- **WHEN** G1 自身有效而 G0 未完成
- **THEN** G1 显示等待前置且 evidenceStatus 为通过，补齐 G0 后可就绪，无需重做 G1

### Requirement: 每个门必须有确定的证据与适用条件

系统 MUST 按下表判定门完成，所有门都 MUST 无本范围未关闭必改、证据摘要匹配且上游有效；不适用 MUST 有可核验理由，MUST NOT 等同缺失证据。

| 门 | 必需证据与完成条件 |
| --- | --- |
| G0 | 当前输入、事实与许可审查；不适用项说明 |
| G1 | 合同解析、设计声明 ID/帧窗/文字状态/定量主张一致性报告，不依赖源码 |
| G2 | A 级或核心段落的独立关键帧、来源核验及所需独立盲审；无适用段落时可不适用 |
| G3 | 实际分镜映射、时间线一致性报告；存在 A 级或结构风险时另需 animatic 及独立结构时序评审，否则仅 animatic 子项不适用 |
| G4 | 逐场检查点断言、适用量测、人工替代核验及所需独立评审；B/C 评审可在 G5 批量执行并回绑 |
| G5 | 当前粗片的跨场结构与首次导演独立评审，以及回绑的 B/C 报告 |
| G6 | 当前成片技术 QA、全片完整证据、既有两名隔离代理终审、交付与来源检查 |

G4 MUST 分列检查与评审状态；B/C 检查通过但待批量评审时，G4 总状态为待评审且允许开展 G5。状态优先级 MUST 为：当前依赖变化导致过期优先，其次当前有效证据中的未关闭必改导致阻断，其次待评审、进行中、未开始；满足完整通过条件或不适用条件时分别显示通过或不适用。当前门 MUST 是最早未关闭适用门；下一步 MUST 考虑允许在 G5 完成的 B/C 评审，避免要求等待自身。自身通过但前置未完成时 MUST 显示等待前置，保留自身 evidenceStatus，不按证据过期处理。启用 acceptanceChecks 的 G4/G6 MUST 另满足检查点规格规定的视觉事件／设计兑现完整凭据，缺项保持待评审。阶段映射按工作流规格执行。

#### Scenario: B/C 批量评审尚未完成

- **WHEN** A 级 G4 已通过且全部 B/C 检查通过，B/C 仅缺独立评审
- **THEN** 当前门显示 G4 待评审，下一步是生成 G5 包进行批量评审，MUST NOT 阻止 G5 活动

#### Scenario: 没有 A 级或结构风险

- **WHEN** 作品没有 A 级、核心段落或结构风险，且记录已核验的适用性判断
- **THEN** G2 可不适用，G3 仍须完成分镜一致性，仅 animatic 子项不适用
