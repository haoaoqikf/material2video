## MODIFIED Requirements

### Requirement: 本地执行与可选制作管理

作品 MUST 提供直接调用的准备、预览、构建、导出、原生样品与技术检查入口。主项目命令 MUST 委托作品声明的本地入口，MUST NOT 注入主项目运行时。接入制作管理的作品 MUST 以版本化结果记录声明输入、产物、失败及环境，管理工具 MUST 复核文件与摘要。独立运行 MUST NOT 要求接入主项目管理协议。

作品 MUST 使用 v3 项目清单和独立版本化的参考绑定。本地及委托入口 MUST 使用同一绑定，现有准备输入映射 MUST 记录并核验绑定文件的摘要。旧材料及漏绑旧准备不得作为当前输入。历史报告保留原结论及适用范围。作品可使用本地快照离线核验参考，渲染使用作品本地代码、时序和资源。

#### Scenario: 两种调用同源

- **WHEN** 同一作品直接使用本地入口，或由主项目委托
- **THEN** 工程配置、参考修订、清单摘要与检查结果一致，采集及合成条件一致。

#### Scenario: 参考绑定变化使证据过期

- **WHEN** 已准备工程的参考清单摘要或生效授权范围发生变化
- **THEN** 须重新准备，旧风格结论不得授权当前完成。

### Requirement: 随附示例全部独立

系统 MUST 在 `examples/<type>/<slug>/` 保留 `data-evolution/compound-after-20`、`data-evolution/global-market-cap-race-portrait`、`spatial-3d/solar-system-journey` 三部示例。每部 MUST 包含独立工程、恢复说明及生效的类型默认参考绑定，保持原片主题、场景身份、数学或事实口径、必要视听目标及音轨要求。复利 MUST 保留原克隆音色，由使用者本地提供同一参考 WAV 和音色档案。版本控制 MUST NOT 包含参考录音、参考文本或本地来源路径。每例 MUST 提供脱库构建、真实预演、完整导出的技术证据，逐部执行适用的实际参考对照并复核代表画面和过程，按观察到的差距调整。禁止以空场景、占位或缩减内容替代示例。图文动效继续可独立初始化并制作。

#### Scenario: 独立示例矩阵

- **WHEN** 逐一复制三例到仓库外并恢复运行
- **THEN** 每例可预览与完整导出，按实际使用范围验证三维异步、公式字体、真实媒体、事件音效、旁白、转场及当前参考对照。

#### Scenario: 示例集合与类型独立

- **WHEN** 枚举分发示例并初始化图文动效
- **THEN** 分发目录和示例验证仅包含上述三例，图文动效初始化生成含默认参考绑定的完整独立工程。

#### Scenario: 本地恢复复利示例旁白

- **WHEN** 在仓库外示例副本恢复登记参考 WAV、音色档案、公开权重和字体
- **THEN** 以原音色生成四幕双语字幕成片，媒体属性按示例的作品清单和分镜核验。参考缺失或摘要不符时明确拒绝，并保留已有有效文件。

#### Scenario: 竖屏市值榜独立导出

- **WHEN** 恢复竖屏市值榜示例并完整导出
- **THEN** 使用随附历史快照呈现完整排名及榜首交接，并保留平台叠加窗口的深底隔离和静音要求，媒体属性按示例的作品清单和分镜核验。
