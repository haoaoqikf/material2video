## Context

动机与范围见 [proposal.md](proposal.md)。当前仓库已有 Three.js、React Three Fiber、后期处理和逐帧采集底座，但尚无汽车展示类型。本次仅规划，未做构建或实际渲染验证。

前期只读检查发现，上游 `alphardex/su7-replica` 包含 glTF、二进制、贴图和展厅效果；汽车约 16.9 万三角面，无内置动画或骨骼，Wheel 组下为两个网格，尚未确认能独立控制四轮。模型要求 Meshopt 解码。源码依赖逐次累加旋转、实时 GSAP、等待和随机噪声，不满足直接逐帧 seek。代码及资产授权尚未确认，公开可读不作为发布授权。

## Goals / Non-Goals

**Goals:** 在独立类型内形成资产、车辆节点、镜头、效果、音轨的最小契约；将指定仓库的表现层改造成可重复采集的视频；用 SU7 首例验证。

**Non-Goals:** 不整体嵌入交互网页，不引入 Blender 等第二渲染引擎，不将既有 general 制作工具自动宣称适配新类型，不扩展到真实驾驶物理或建筑动画。

## Decisions

### 1. 独立类型接入现有底座

在类型目录登记 `vehicle-showcase`，实现类型适配器与专用 React/R3F composition；复用共享准备指纹、浏览器采集、编码和溯源。相比仅做 general 作品，这能显式校验车辆材料；相比整体搬入上游网页，避免独立时钟、音频与交互框架控制导出。需要抽取的采集能力须保持依赖方向，不让新类型导入 general 私有实现。

### 2. 固定首版材料

作品使用 `project.json`、版本为 1 的 `showcase.json` 和 `assets/manifest.json`。showcase 声明画幅、帧率、总帧数、模型 ID、车身/车轮节点及各自局部旋转轴、镜头段、速度和效果轨道、可选声音。轨道以帧定位，区间采用左闭右开，首尾有确定值；镜头段覆盖全片且不得重叠。节点使用名称或明确路径，不使用上游展开数组下标。素材清单记录来源、上游提交、作者、许可依据、路径、摘要和关联文件；具体 JSON 字段在实施中形成校验器、模板和文档的一致定义。

### 3. 先落实资源与授权，再扩展正式制作

固定上游提交，核对 glTF 外部依赖和所有引用文件；确认代码及模型、环境、贴图各自的权利来源，不把复刻作者的代码许可推定为素材许可。授权未落实时不得导入生产材料或发布；可以继续不依赖其资源的类型工作。未经用户重新指定，不改用其他仓库替代。上游音乐和芙宁娜角色不进入首片，声音用另有依据的本地素材或程序化音效。作品源材料、模型及产物留在忽略的内容目录，共享代码中不打包媒体。

### 4. 时间驱动替代交互驱动

用 `t = frame / fps` 求镜头、灯光、流光与反射参数；车轮角度由累计行程与有效半径计算，或以明确的视觉速度轨道求值。禁止依赖上一次截图、挂钟和非固定随机数；抖动改为固定种子的时间函数。离线解码器、纹理、着色器与反射预热完成后才采集。先做基础车漆与反射，再逐项加入动态环境和后期，以实际性能决定效果强度，不设未经实测的吞吐承诺。

### 5. SU7 首例导演方案

30 秒、1920×1080、30 fps、900 帧，暗色展厅与冷白灯光，无旁白，无非必要文字。原仓库视觉疾驰不代表真实道路运动。

| 时间 | 内容与镜头 |
| --- | --- |
| 0–4 秒 | 暗场亮灯，车头斜前方缓慢推近 |
| 4–16 秒 | 镜头绕静止车辆完整一圈，整车保持可见 |
| 16–19 秒 | 侧前方停留，平滑衔接启动 |
| 19–26 秒 | 车轮加速，展厅灯光淡出，流光与反射形成疾驰感 |
| 26–30 秒 | 保持车辆清晰并淡出收束 |

先做覆盖静态、镜头和启动过渡的短样片，再扩展全片。声音以有来源的风噪等为可选项；没有有效素材时允许无声版本，不擅用仓库 BGM。

### 6. 验证与评审

技术检查覆盖资源缺失/摘要变化、节点和轨道错误、顺逆序取帧一致性、离线加载、缓存失效、输出参数和音轨；性能记录至少包含实际硬件、分辨率、效果配置和采集耗时。视觉检查覆盖车身裁切、车轮偏心、地面接触、玻璃车漆、反射跳变、曝光与转场连续性。独立评审的风险、人数与轮次沿用现有审核策略，不另建一套；实施时明确新类型接入点，技术 render 与制作完成状态分开。

## Risks / Trade-offs

- 授权未明 → 作为首例资源使用和发布的前置阻塞；记录凭据，不能凭公开仓库推定允许复用。
- 两个车轮网格不足以独立转向 → 首版只做视觉直行；检查轴心并按需整理，不伪称四轮绑定。
- 上游版本较旧、自定义反射与着色器可能失效 → 在当前依赖上先做代表片段，逐项比较；不并存旧渲染栈。
- 动态反射成本高 → 试渲染记录性能，优化采样和质量，视觉复核后才固定参数。
- 多类型回归 → 不动已有材料契约；按影响跑单元、媒体与慢速浏览器测试。

## Migration Plan

新增类型不迁移现有作品，不保留旧汽车材料兼容层。先完成授权与短样片，再完成注册、契约和全片验证；任一步失败保留问题记录，不宣布交付完成。实现完成并验证提交后按项目约定归档；本轮仅提案，不归档或实施。
