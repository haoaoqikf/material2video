## Context

动机见 proposal.md。源材料在 examples，预演与成片在 videos/examples；v7 SDK 已提供实际时间窗与录制时钟。

## Goals / Non-Goals

目标：演示文章推理，覆盖现有组件并可重渲。非目标：新增公共接口、依赖或兼容层。

## Decisions

- 三篇先扩写再分镜，核心演示采用实际 segmentWindows 与 elapsedSeconds；不用固定几秒的孤立技术末幕。
- 缓冲用 Motion 水位和 ECharts 输入/输出/积压；试错用 GSAP 落点修正及原创反馈图片；选择用 Three/R3F/Drei 路径筛选和原创筛选视频。展示数据均为示意。
- 保持七种模板原契约，代码正文限制 864×920，标题与字幕交由共享外壳。按主题配色，等待自有资源就绪后 ready。
- 逐片全流程验证；所有材料稳定后再准备，防止共享实现变动令录制缓存失效。

## Risks / Trade-offs

- 实际 TTS 时长偏差 → 准备后检查 120～180 秒，通过改写内容调整。
- 实时录制开销 → 限制三维对象数，复用已验收录制片段；检查关键帧。
- 原创媒体需要更新留证 → 通过统一导入入口计算摘要与来源，删除已替代的未引用固定素材。
