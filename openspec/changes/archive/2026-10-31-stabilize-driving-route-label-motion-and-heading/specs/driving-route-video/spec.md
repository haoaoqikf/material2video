## MODIFIED Requirements

### Requirement: 二维地图镜头与信息呈现

道路底图版本 MUST 使用北向浅色普通道路地图，显示路网和城市注记；MUST NOT 使用卫星影像、三维地形或未授权底图。卫星底图版本按「卫星底图变体」要求执行，镜头与标签要求不变。开场 2 秒 MUST 停在起点近景并从 9 倍全程比例以 ease-out 快速推到 16 倍，MUST NOT 展示整体路线；开场结束 MUST 立即进入 16 倍跟随并开始行驶，不设独立交接段；最后 2 秒 MUST 用 1 秒平滑拉远到全程、再用 1 秒保持，且全程视图 MUST 适配标题带以下的内容区。跟随相机中心 MUST 对目标点前后等距折线点做对称平均以抑制逐帧抖动；跟随段缩放固定时，相机平移 MUST 对齐到整像素，使底图瓦片、路线与屏幕空间标签共享同一重采样相位，避免文字在地图移动中闪烁；视野前瞻与折线平滑 MUST 随已行驶距离从零渐入，MUST NOT 在开场结束帧把相机瞬移到路线前方数公里处。车辆位置 MUST 仍取原始路线。显式时长只调整中段行驶时间。镜头 MUST 平稳跟随并为前进方向留视野，收束时完整呈现全程及起终点，到达状态可辨。顶部 MUST 叠加两行居中标题：小字“模拟行程”与大字“X → Y”；已行驶公里数 MUST 显示在车辆旁的屏幕空间标签中并随车移动，MUST NOT 显示“全程”或底部数据面板。必要来源署名 MUST 按来源要求显示并避免遮挡主体；其他文字只承担主题、地点、道路名称和结果，不添加制作说明。视频压缩行程 MUST NOT 冒充实时车速、实时路况或实时导航。

#### Scenario: 上海到郑州首例
- **WHEN** 制作上海人民广场至郑州二七广场首例
- **THEN** 画面标上海与郑州，显示所获真实高速路线与普通道路瓦片底图，小车从上海端驶至郑州端，片末展示完整已行驶路线

#### Scenario: 跟随与拉远
- **WHEN** 从开场近景进入 16 倍平滑跟随并在到达后收束
- **THEN** 镜头连续过渡，地图保持北向、小车始终可见；当前视域内承担信息的道路和地名不被不合理裁切或重叠遮挡，全程及两端完整呈现要求适用于开场与收束

#### Scenario: 开场结束进入跟随
- **WHEN** 第 2 秒推近结束、车辆开始沿路线行驶
- **THEN** 相机从起点视图连续过渡到跟随视图，相邻帧平移连续，地图与车辆不发生一次数十至上百像素的位置突跳

#### Scenario: 竖屏满屏与顶部标题
- **WHEN** 以 1080×1920 竖屏渲染并显示起终点
- **THEN** 普通道路地图铺满画面，顶部两行标题居中放大，车辆旁里程标签不遮挡车辆、路线与主要城市名；不出现底部数据面板

### Requirement: 普通道路底图与城市标注

系统 MUST 允许 `driving-route` 使用已授权的高德普通道路底图。`request.json` v2 的 `sourceUsage` MUST 包含 `mapTiles` 布尔字段；`route.json` v3 MUST 包含 `cost`、`cities`（含 `name`、`adcode`、`location`）与 `administrativePlaces`（市/县行政区中心点；市辖区不单独列出）；v1 请求与 v2 路线 MUST 被明确拒绝，提示重新 fetch，不提供静默兼容。`fetch` MUST 为沿线城市请求 `/v3/config/district` 并记录不含凭据的行政区请求；行政区请求失败 MUST 使整次 fetch 失败并保留旧路线。`mapTiles=true` 时 MUST 包含 `basemap`，缺失 MUST 使 validate/prepare/render 明确失败并提示先运行 basemap；`mapTiles=false` 是允许矢量例外的最小范围。`cost` MUST 保留并校验，但当前 MUST NOT 在画面渲染。`m2v driving-route basemap --project <目录>` MUST 只在来源使用依据与 `mapTiles` 均落实时取图，使用 GCJ-02 Web Mercator 的高德普通道路瓦片（style=8，含路网与城市注记）；卫星变体使用 style=6，MUST NOT 使用 WGS84 影像或其他提供方。底图 MUST 提供 z8 概览拼接影像与 z12 跟随瓦片走廊；概览常驻底层，跟随瓦片按当前相机视口绘制并在结尾 1 秒内淡出到概览。跟随瓦片 MUST 使用内容寻址目录 `follow-tiles-*`，并记录计划摘要、清单摘要与逐块摘要。取图失败 MUST 保留旧路线与旧影像，MUST NOT 发布半份材料。成功结果 MUST 记录布局版本、提供方、缩放、包围盒、瓦片数、概览影像 SHA-256/宽高/投影矩形、跟随瓦片的计划摘要、清单摘要、逐块路径/SHA-256/投影矩形、采集时间、署名与不含凭据的请求参数。

城市与县级行政区叠加标签 MUST 保持行政区中心点锚定，并与底图共用同一相机平移；跟随段相机缩放固定，平移 MUST 对齐到整像素，使瓦片与标签拥有相同的重采样相位，不得单独对标签取整、单独平滑或施加额外缓动。市名与县/县级市名以 30 px、字重 700、8 px 白色描边绘制，固定在中心点上方。市辖区（名称以“区”结尾）不单独标注。标签靠近边缘时向内收，避让车辆、端点、标题带、车辆旁里程、道路名与彼此重叠；跟随时只显示当前视域内行政区。标签与避让对象的相对距离变化时 MUST 连续淡入淡出，透明度 MUST 按相机平滑时长（当前 0.6 秒）做确定性时间平滑；不得逐帧按碰撞阈值硬切，标签冲突 MUST 按城市优先、再按行政区代码的稳定顺序处理。开场推近与结尾拉远时，自绘市/县标签 MUST 随镜头变焦平滑淡出，并在稳定跟随或最终总览阶段平滑淡入。结尾拉远时县/县级市叠加标签 MUST 渐隐；最终全程保持段 MUST 只显示市级叠加标签。

开场推近期间车辆朝向 MUST 保持起点处沿路线前进的方向；开场 2 秒结束后 MUST 立即开始行驶并进入跟随镜头，不执行掉头或随早期弯道摆头。MUST NOT 设置独立的 0.5 秒镜头交接段；该时长用于路线行驶，且不改变总片长。

#### Scenario: 取得并绑定普通道路底图
- **WHEN** 授权已落实、`mapTiles=true`、路线 v2 有效且瓦片服务返回完整路网影像
- **THEN** 概览与跟随瓦片保存在作品忽略目录并原子写入 `route.json`，准备与候选绑定概览及全部瓦片摘要；渲染离线读取，不访问网络或 Key

#### Scenario: 取图条件不满足
- **WHEN** 授权或 `mapTiles` 未落实、路线 v1、瓦片超时/缺块或影像摘要漂移
- **THEN** 命令明确失败，保留旧路线和旧底图，不拼接缺块，不写入半份材料

#### Scenario: 跟随走廊超限
- **WHEN** 相机视口并集超过 2200 块瓦片
- **THEN** 命令明确报告实际块数并失败，不静默降低 z 级或裁剪路线

#### Scenario: 重复取图
- **WHEN** 布局版本、时长、帧率、路线与瓦片摘要均未变化再次执行 basemap
- **THEN** 复用现有概览与走廊，不重复请求瓦片

#### Scenario: 城市标注
- **WHEN** 路线包含有效 `administrativePlaces` 并执行渲染
- **THEN** 市名与县/县级市名统一以 30 px、字重 700、8 px 白色描边按行政区中心点绘制，标签固定上方并与底图共用同一相机平移；跟随段平移对齐整像素，标签不得相对底图漂移或逐帧重采样；市辖区（名称以“区”结尾）不单独标注；边缘标签向内收，避让车辆、端点、标题带、车辆旁里程、道路名与彼此重叠；跟随时只显示当前视域内行政区

#### Scenario: 避让状态平滑变化
- **WHEN** 跟随过程中城市标签接近或离开车辆、端点、里程、道路名、其他标签或可视区域边界
- **THEN** 标签透明度按相机平滑时长连续变化，不因相邻帧跨越硬阈值而突然出现或消失

#### Scenario: 重叠标签保持稳定顺序
- **WHEN** 同一画面中的多个行政区标签发生重叠竞争
- **THEN** 每帧均按稳定优先级绘制或淡出标签，微小相机移动不会交换优先级并造成闪烁

#### Scenario: 变焦期间隐藏自绘行政区标签
- **WHEN** 镜头进行开场推近或结尾拉远
- **THEN** 自绘市/县标签平滑淡出，镜头稳定后平滑淡入，不随快速缩放持续移动

#### Scenario: 最终全程视图只显示市级叠加标签
- **WHEN** 结尾相机完成拉远并进入全程保持段
- **THEN** 所有县/县级市自绘标签均已渐隐，只显示市级自绘标签

#### Scenario: 开场推近时车辆保持前进朝向
- **WHEN** 开场推近尚未结束
- **THEN** 小车保持起点沿路线前进的朝向，不执行掉头或随早期弯道摆头

#### Scenario: 开场结束立即开始行驶
- **WHEN** 开场 2 秒推近结束
- **THEN** 小车立即开始沿路线行驶并进入跟随镜头，原 0.5 秒交接时间用于行驶且不延长总片长

#### Scenario: 数据缺失或非法
- **WHEN** cost 字段缺失、为负或非整数，cities 重复、缺少 location 或 adcode 非法，administrativePlaces 重复、缺少 center 或市政中心不匹配，或跟随瓦片集合与逐帧覆盖计划不一致
- **THEN** 校验失败并指出字段，不渲染不一致的行政区标注或空白瓦片；cost 仍须合法但不进入画面

## ADDED Requirements

### Requirement: 城市间行程从大路开始

城市间路线画面 MUST 从起点 5 公里范围内首条可识别的大路开始。大路按明确的高速、快速路、国道、省道、大道、高架或环路名称识别；无明确名称时，单个道路段达到 1 公里可作为主路线索。画面 MUST 省略该路之前的小路接驳段，并从画面里程中扣除接驳段里程；`route.json` MUST 保留完整 API 原始路线。若 5 公里内未找到大路，`prepare` MUST 明确失败并提示调整起点，不得静默从小路起步。

#### Scenario: 起点先经过城区小路再接主干道

- **WHEN** 城市间 API 路线以多段短城区道路开头，随后进入大路
- **THEN** 画面路线、车头初始位置、底图取景与显示里程都从首条大路开始，原始路线材料仍保留全部道路段

#### Scenario: 搜索范围内没有大路

- **WHEN** 起点后 5 公里内没有符合名称或路段长度条件的大路
- **THEN** 准备明确失败并要求调整起点，不生成从小路出发的行程

### Requirement: 车头方向应沿局部道路切线连续变化

车辆 MUST 沿真实路线行驶并面向局部行驶方向。起点朝向 MUST 等于第一条非零路线线段的方向；方向估算 MUST 只取局部路线样本，不得因长路线总长度而把远处弯道合并进起点朝向。

#### Scenario: 起点位于城市街区回弯前

- **WHEN** 路线起点之后的街区道路在短距离内发生回弯
- **THEN** 开场车头仍朝向起点第一段道路，并在开始行驶时沿局部道路方向自然转向，不出现先朝错误方向再掉头的动作
