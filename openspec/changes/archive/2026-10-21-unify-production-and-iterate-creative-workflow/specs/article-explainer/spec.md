## MODIFIED Requirements

### Requirement: v8 横竖屏代码分镜
系统 MUST 只接受 version/schemaVersion 均为 8 的 general 分镜，60 fps，支持 1920×1080 横屏与 1080×1920 竖屏；width/height 均省略 MUST 默认横屏，半指定、非整数及其他尺寸 MUST 拒绝。全片 MUST 使用同一画幅，不自动裁切或重新排版。每幕 MUST 声明唯一 ID、template: code、本地 content.entry、可选 title/JSON 对象 props 及旁白数组；title 只作元数据。场景及旁白 ID MUST 全片唯一。原文输入 MUST 绑定非空源文并审查，主题输入 MUST 声明非空主题与逐幕关键词且不要求原文审查。代码幕 MUST 允许无旁白，未知字段及旧准备 MUST 拒绝。

每幕 MAY 声明 `leadInFrames`、`tailFrames`（0–1800 帧）与 `readingHoldFrames`（0–360 帧）；旁白段 MAY 声明 `claims` 字符串数组与 `holdFrames`（0–1800 帧，本段结束后、下一段前的静默，最后一段不得非零）；`content.props` MAY 声明 `shots` 与 `look` 对象。未声明时 MUST 保持当前时间轴、阅读停留与画面行为。字段类型、范围或时间窗非法时 MUST 拒绝并定位到具体幕、镜头或旁白段。镜头时间窗 MUST 落在所属幕内且不得重叠；`tier` 只能是 hero、major 或 minor；hero 镜头数量和时长 MUST 按内容决定，不设固定配额。

真正的一镜到底 MUST 写成单幕内多个首尾相接的镜头：所有镜头窗口 MUST 从 0 起严格相接并覆盖整幕，相邻镜头路径的末点与首点 MUST 完全相同，MUST NOT 声明 `cut: true`，全部镜头 MUST 使用 linear 缓动。`post` 参数 SHOULD 在全部镜头间保持一致，因为后期不在镜头边界混合。

#### Scenario: 默认与显式尺寸
- **WHEN** 尺寸均省略、显式横屏或显式竖屏
- **THEN** 分别按 1920×1080、1920×1080、1080×1920 规范化并贯穿制作

#### Scenario: 非法尺寸
- **WHEN** 只提供一边尺寸，或尺寸为布尔值、字符串、方屏或其他组合
- **THEN** 校验拒绝并定位字段

#### Scenario: 旧分镜
- **WHEN** 输入 v7 或更早分镜
- **THEN** 要求重新编排 v8，不自动迁移

#### Scenario: 主题输入
- **WHEN** topic 作品的代码幕旁白为空且声明有效关键词与 durationFrames
- **THEN** 按声明长度准备镜头，不要求原文审查；缺少关键词则拒绝

#### Scenario: 非法绑定
- **WHEN** 旧展示元素尝试用 segmentId 绑定旁白
- **THEN** 按未知字段拒绝；v8 代码改用实际 segmentWindows

#### Scenario: 代码模板
- **WHEN** 输入有效 code 场景
- **THEN** 本地录制片段参与统一音轨、字幕和转场合成

#### Scenario: 静音前后段
- **WHEN** 某幕声明有效的 leadInFrames 或 tailFrames
- **THEN** 旁白前后出现对应静音，时间轴与字幕整体后移，不截断或重叠旁白；未声明时行为与当前一致

#### Scenario: 非法电影字段
- **WHEN** shots 的时间窗越界或重叠、tier 非法，或 look/claims 字段类型错误
- **THEN** 校验拒绝并指出具体幕、镜头或旁白段

### Requirement: 固定示例的内容驱动演示
仓库 MUST 仅分发 american-science-milestones、traffic-jam-wave、solar-system-journey 三个固定示例；前后两者使用 1920×1080，交通拥堵波使用 1080×1920，均为 v8、60 fps。美国科学里程碑实际时长 MUST 为约30秒、统一标准、全程数字静音或无音轨；交通拥堵波实际时长 MUST 按核心试制与整片粗预演确定，太阳系之旅 MUST 在 120～600 秒内按动态粗预演确定预算，除美国科学里程碑无声示例外，均含中文旁白和烧录字幕。有旁白核心演示 MUST 按实际旁白时间窗推进，无声示例 MUST 按帧数预算推进并以中文文字讲解，合计覆盖 Motion、ECharts、GSAP、Three.js、React Three Fiber 与 Drei。示例 MUST 提供可编辑材料、设计说明、素材来源和旁白与画面的对应关系，生成媒体 MUST NOT 入库。

太阳系之旅 MUST 使用 统一制作流程：单幕、按动态粗预演核定时长、15 段旁白、3 个 hero 镜头（地球、土星、奥尔特云）、覆盖整幕且首尾相接的镜头；开场 MUST 从太阳系上方连续俯冲到太阳，全片 MUST 无切换、无叠化、无硬切。MUST 提供 4K look-dev 静帧、按风险确定长度的有声样片、hero 的帧序列与量测记录、配乐与音效，以及普通 H.264 MP4 交付；MUST NOT 要求播放视频或连续收听声音。交通拥堵波 MUST 用统一循环流程重制并保留旧版对照。美国科学里程碑 MUST 按素材特征改变构图与运动，MUST NOT 以反复替换年份、标题和说明的同构静态卡片主导全片；观众可见文案 MUST NOT 出现仓库文件名、路径或制作文档指引，作者、素材署名与版权/许可说明 MUST 只在片尾集中出现一次。

#### Scenario: 三片完整制作
- **WHEN** 使用三个固定示例通过统一入口完成准备、完整候选与导出
- **THEN** 成片具有对应画幅、60 fps、符合各自声音约定的音轨及画面文字，保存到各自 videos/examples/<slug>/outputs，时长满足各自范围

#### Scenario: 覆盖检查
- **WHEN** 检查固定示例分镜与源码
- **THEN** 只有三个指定示例，合计覆盖批准组件，有声核心代码场景包含按时间窗推进的旁白，无声场景包含明确帧数，并明确标注示意内容

#### Scenario: 太阳系向外旅行
- **WHEN** 播放太阳系之旅
- **THEN** 成片按已验证的镜头预算确定时长，镜头从太阳系上方连续俯冲到太阳，再沿向外螺旋经过 15 个站点；全片单幕、镜头窗口连续覆盖，无切换/叠化/硬切，相邻镜头位置、方向与速度连续；地球、土星与奥尔特云为 hero；全片在同一个完整三维太阳系模型中保留太阳、行星、卫星和轨道；标注大小距离非同比例，并区分日球层顶与推测性奥尔特云

#### Scenario: 写实画面验收
- **WHEN** 完成太阳系示例的交付验证
- **THEN** 提供 3 个 hero 的 4K 静帧与 按风险确定长度的有声样片，完成时间标注帧序列、路径/构图量测和自动音频信号检查并记录问题与复查；提供配乐/音效、QA 报告与普通 MP4 交付；无需播放或连续收听；不将艺术示意表述为实拍或精确历算

#### Scenario: 标准档回归
- **WHEN** 交通拥堵波完成准备、完整候选与导出
- **THEN** 使用统一循环流程、中文旁白和烧录字幕，核心演示按真实旁白窗口推进

#### Scenario: 美国科学里程碑
- **WHEN** 制作 american-science-milestones
- **THEN** 使用 统一制作流程、横屏约30秒，依次呈现电报、电话、动力飞行、三位一体核试验、ENIAC、晶体管、登月、ARPANET、基因组与大语言模型；历史素材优先、缺失时标注动画示意，明确国际合作与贡献边界；逐幕按素材特征变化画面结构与运动，不以同构信息卡片逐页替换；全程无声，中文名称和贡献说明优先，前两秒直接建立主题，观众可见文案无内部文档引用，片尾只有一份署名与版权说明；提供绑定最终版本的全片帧序列及手机横屏审美复核证据

交通拥堵波示例 MUST 以俯视椭圆环路解释无事故、无道路变窄情况下的拥堵形成，MUST 显示车辆编号、与减速一致的制动灯、局部车距变化和独立的拥堵传播方向。MUST 以同一减速扰动对照两种车流密度，并限定为特定条件下的扰动放大；MUST NOT 将所有城市拥堵归因于单次刹车。轨迹与图表 MUST 来自一致的确定性示意数据，MUST 明确标注“示意”，MUST NOT 冒充真实测量或经过标定的交通预测。全片 MUST 无配乐，允许少量提示音，署名与来源 MUST 集中为唯一简短片尾。

#### Scenario: 车辆与拥堵波方向不同
- **WHEN** 展示拥堵波传播段落
- **THEN** 同一编号车辆持续向前，低速区域沿车队向后传播；独立方向标记与实际运动一致，车辆无追尾、编号无跳变，制动灯与减速对应

#### Scenario: 同扰动密度对照
- **WHEN** 并列展示两种车流密度
- **THEN** 两组采用相同初始速度、道路、减速幅度与持续时间，仅密度不同；展示扰动消散与放大的示意差异，不将密度视为任意条件下的唯一决定因素

#### Scenario: 可重复制作与内容留证
- **WHEN** 重复采样相同准备版本的相同时间点
- **THEN** 车辆位置、速度、制动状态和图表相同；示例材料提供论点与研究来源对应关系，交付复核包含全片时间标注帧序列、手机可读性和自动音频信号证据，生成媒体不入库

### Requirement: 科学里程碑重制必须验证审美流程改进
american-science-milestones MUST 在现有三个固定示例中原位重制，保留现有十项内容、顺序及贡献边界，使用 统一标准、1920×1080、60 fps、约30秒；开场2秒、十项主体26秒、片尾署名2秒。中文名称与贡献说明 MUST 为主信息；陌生英文缩写仅在首次出现时作为辅助识别，不得成为理解前提。MUST 全程无旁白、配乐、音效及素材原声，交付无音轨或全程数字静音。MUST 面向手机横屏播放完成字号、主体占比及遮挡风险复核，并针对前两秒复核主题建立、视觉钩子及手机尺寸下的辨识情况；不得声称测得真实平台跳出率。MUST 在全片及所有观众可见文字中禁止仓库内部文件名、路径和材料查阅提示；署名和版权说明仅以一份简短片尾内容出现，满足所用素材许可的作者、来源、许可和改动标识要求，详细来源记录仍留在作品材料中。MUST 保留素材留证及生成媒体不入库要求。

作品 MUST 以档案纪录方向组织视觉承接，历史影像与实物优先，原理动画明确标注示意；MUST NOT 暗示未经证实的直接历史因果。四张基准 MUST 覆盖开场、登月、晶体管普通信息镜头及片尾。各项 MUST 围绕一个主要视觉变化组织，减轻年份、英文装饰与说明的竞争，MUST NOT 以照片缓慢缩放作为全片主要动画手段。

大语言模型镜头 MUST 以中文为主、明确标注为示意的 ChatGPT 交互呈现具体产品实例，并使用未经改动的官方图标及 `ChatGPT / OpenAI` 名称；画面 MUST NOT 暗示 OpenAI 为作品背书，或将大语言模型研究与发展归功于单一机构。该镜头 MUST 为4.5秒。片尾署名 MUST 为2秒，仅出现一次，去除重复小标题，手机横屏尺寸下必要的署名文字 MUST 清晰可读。完整来源和许可记录 MUST 保存在作品材料中，ChatGPT 商标素材 MUST 有官方来源记录且不得误称为开放许可。

重制 MUST 保留同时间码、同显示尺寸的新旧对照，说明视觉重心、信息层级、叙事变化与一致性的具体改进。最终全片帧序列、交界与风险加密检查、素材审计及静音检查 MUST 绑定新候选准备指纹和最终文件摘要，不得沿用旧版通过结论。共享流程与实际重制 MUST 均完成并关闭必改项后，才可标记整体变更完成。

助手 MUST 完成开场、登月、晶体管普通信息镜头及片尾四张基准复核；登月镜头已精制但晶体管普通镜头缺少正式文案或手机尺寸检查时，四张基准仍未完成。若新旧对照及全片帧序列显示各段仍以照片缩放和文字替换主导，助手 MUST 重构主体变化与镜头承接并在新版本复查，MUST NOT 以更新设计稿代替重制。仅更新共享指导而没有经过完整复核的新成片时，实际重制任务 MUST 保持未完成。

#### Scenario: 重制保持硬约束
- **WHEN** 生成并验收新版本科学里程碑示例
- **THEN** 片长约30秒、约1800帧，画幅与帧率正确，十项次序及贡献边界不变，全程无声；中文优先且缩写非理解前提；手机横屏与前两秒开场检查完成，观众可见文案无内部引用，且只有一份满足许可要求的简短片尾署名

#### Scenario: 大语言模型以具体产品建立识别
- **WHEN** 观众观看4.5秒的大语言模型段落
- **THEN** 可辨认中文 ChatGPT 示意交互及原样官方图标，理解其为全球研究积累中的具体产品实例，且不会被画面引导为 OpenAI 背书或单一创造

#### Scenario: 片尾署名压缩后仍可读
- **WHEN** 观众在横屏手机尺寸观看2秒片尾
- **THEN** 不出现重复小标题，只出现一份片尾署名，必要作者、许可、改动及本片许可信息清晰可读，详细出处不要求观众查阅内部文件

#### Scenario: 只优化重点镜头
- **WHEN** 登月镜头已精制但晶体管普通镜头缺少正式文案与手机尺寸检查
- **THEN** 四张基准尚未完成，助手补齐普通镜头复核后再标记该阶段完成

#### Scenario: 新版本仍主要靠照片缩放
- **WHEN** 新旧对照及全片帧序列显示各段仍以照片缩放和文字替换主导
- **THEN** 助手登记表现问题，重构主体变化与镜头承接并在新版本复查，不能以更新设计稿代替重制

#### Scenario: 仅完成流程文档
- **WHEN** 共享指导已更新但没有经过完整复核的新成片
- **THEN** 实际重制任务保持未完成，不归档整体变更

#### Scenario: 开场首两秒未建立主题
- **WHEN** 前两秒的画面无法迅速让目标观众辨认主题，或没有可辨认主体/有意义动作
- **THEN** 作为审美问题重构开场并复核；不使用虚构的平台跳出率或分数作为验收
