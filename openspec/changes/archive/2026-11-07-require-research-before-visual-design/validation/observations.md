# 技能行为演练：独立决策观察

本记录仅按七个题面作模拟决策，不代表已开展研究、形成设计或完成真实评审。未联网、未设计画面、未修改技能或作品；未读取 `openspec/changes/`、既往聊天或作者结论。各情境独立，不把其中一个情境的证据带入另一个。

## 实际读取与路由

- `.agents/skills/material2video/SKILL.md`：定位新制作、修订与条件阅读；创作或视听表达修订前完整阅读灵感文档；展示型 HTML 同样适用设计前研究。
- `references/visual-expression-inspiration.md`：已完整阅读；阅读和研究必做，风格采用自选，不以风格符合性验收。
- `references/stage-plan.md`：新制作及实质性重设计的研究前置、实际查看、留证、复用补查、失败停止边界。
- `references/video-revision.md`：C、D 的修改影响与最短路径；实质性重设计补查，纯实现修复沿用有效方案。
- `references/reference-video-analysis.md`：研究与借鉴时的实际查看范围、静态／运动／声音证据边界及采用记录。
- `references/stage-iterate.md`：D 的局部修复与效果复查路径，以及后续实际试制与证据边界。
- `references/guidance-routes.json`：核对任务与条件路由，未递归读取全部链接。上述 `references/` 均相对技能目录。

## A：自创风格，先用 HTML 展示两张图片

**接下来动作**：先定位新作品类型与内容根，整理主题、数据、受众、画幅和硬约束，明确两张草样要解决的问题；随后针对这些问题外部搜索、访问来源并实际查看分析，在现有 `DESIGN.md` 简记证据，之后才形成并展示 HTML 方案。

**可开展／暂不能开展**：可整理题面、核对数据、界定研究问题；当前没有研究，暂不能直接制作展示方案的 HTML 或两张视觉草样。用户允许自创风格，并没有要求跳过阅读或研究；也不必采用灵感文档中的风格。

**所需证据**：来源地址、访问日期、实际查看范围、具体观察与本次设计启发，覆盖当前构图、信息编码等实际问题；够用即停，不设案例数。研究完成只允许继续设计，不等于设计或制作通过。

**依据**：`SKILL.md` 的新制作路由和设计前强制要求；`stage-plan.md#设计前搜索研究` 明确涵盖展示型 HTML 与低成本原型；`visual-expression-inspiration.md` 区分强制研究和自选风格；`reference-video-analysis.md#证据边界`。

## B：同一风格的下一张比较页，既有研究已覆盖

**接下来动作**：核对同一任务 `DESIGN.md` 中来源与观察确实覆盖该比较页的对象、比较问题和当前设计维度，简述覆盖依据后复用既有研究，沿用已确定方向继续设计该页。

**可开展／暂不能开展**：按题面可以继续本页设计，无需为了“下一张”重做研究或重开选案；若实际核对发现新对象或新问题超出覆盖，再先补查相应部分。不能把既有研究有效写成新页面视觉效果已经通过。

**所需证据**：题面列出的真实来源、日期、查看范围、配色／布局／数据编码观察与该页问题之间的对应关系；后续还需实际页面效果与适用制作检查证据。已完整阅读的灵感文档同一任务不重复阅读；若尚未读过，仍需先完整读。

**依据**：`stage-plan.md#设计前搜索研究` 的“复用与补查”；`SKILL.md` 与 `visual-expression-inspiration.md` 的同一任务免重复阅读规则。

## C：球体不协调，要求换材质重新设计

**接下来动作**：按修订入口定位作品、现有材料、球体所在画面和保留约束；把材质、光影及其与整体画面的协调性作为新问题，补充相应外部研究与实际查看分析，再决定材质重设计。实施前保护旧版与受影响材料，保留对照基线。

**可开展／暂不能开展**：可核对现有球体代码及当前实现、整理问题与影响范围；已有代码可作为之后的实现资源，不能充当材质研究。当前旧研究仅覆盖文字、网格与轴线，暂不能凭这些研究直接形成新球体材质方案。此次不是已验证方案的纯实现修复。

**所需证据**：当前球体与全画面的实际状态；针对材质、光影、协调性而实际查看的外部材料及简短观察记录；之后的局部效果与旧版对照。是否需过程材料取决于要判断的问题是否含运动，静图不能证明运动效果。

**依据**：`video-revision.md#按影响选择最短路径` 明确用户反馈暴露的新问题不能以“只改材质／颜色”跳过研究；`stage-plan.md#设计前搜索研究` 的新问题补查与已有代码不能替代研究；`reference-video-analysis.md#证据边界`。

## D：错字与标签裁切，恢复到已验证设计

**接下来动作**：定位对应作品与第三页可编辑材料，核对当前交付及有效设计，按局部修订保留旧候选和受影响材料；修正数字文字与标签布局实现后重新 prepare，实际查看本场完整窗口、手机尺寸和相邻衔接，在原问题记录中复查效果。后续完整候选与收口按当前合同执行。

**可开展／暂不能开展**：可以直接开展局部实现修复，沿用有效设计与研究，不必重新搜索整套风格、不重开无关选案。局部预览不能证明全片最终完成；若修复过程中发现目标本身需要重设计，则重新判断影响并补查。

**所需证据**：有效设计与修复目标、旧版基线、实际修改后的文字与完整标签可见状态、阅读窗口及衔接检查；工具判定受影响或过期的证据按实际绑定补取，不能复制旧通过。

**依据**：`stage-plan.md#设计前搜索研究` 明确错字、裁切和已验证方案实现偏差不重做整套研究；`video-revision.md` 的纯实现修复、基线、prepare 和局部检查步骤；`stage-iterate.md` 的实际查看与问题复查要求。

## E：新作品封面，只有搜索摘要与链接

**接下来动作**：先明确封面目标与硬约束，再打开相关来源并实际查看对应图片，围绕当前封面问题作具体分析并留证，达到足以支持判断的程度后开始设计。打不开时换来源或检索词。

**可开展／暂不能开展**：可整理候选来源与待研究问题；摘要和链接仅能作为检索线索，不能记作完成研究，也暂不能据此形成封面视觉方案。静态封面研究按实际需要选择维度，无需机械补齐运动和声音研究。

**所需证据**：实际访问与查看的图片／页面、来源地址和日期、查看范围、针对封面问题的观察与启发。若只看静图，结论限于外观与构图。

**依据**：`stage-plan.md#设计前搜索研究` 的“实际查看”和“简短留证”；`reference-video-analysis.md#证据边界`；`SKILL.md` 新制作路由。

## F：新视觉方向，换词换来源后仍无法查看

**接下来动作**：如实记录已尝试获取材料、仍无法实际查看、无有效既有覆盖，明确设计前置尚未满足，停止依赖这些研究的新视觉方向设计；等待可访问参考或其他能满足实际查看条件的来源后再继续。

**可开展／暂不能开展**：可继续无关的事实与素材清单整理、检查用户约束、归纳待研究问题等不预先决定视觉方向的工作；不能靠经验、风格名称或仓库代码豁免前置，不能以“先做一版”制作新方向草样。无需无限重复相同失败尝试，也不按固定检索次数判断研究完成。

**所需证据**：当前不可访问与无覆盖的真实状态、未满足的具体研究问题；恢复设计前需要可追溯且实际查看过、足以支持当前判断的材料及观察，不能补写访问或观看记录。

**依据**：`stage-plan.md#设计前搜索研究` 的“停止与失败”；`reference-video-analysis.md#证据边界` 的未访问部分如实说明。

## G：参考静态海报，设计含运动和音效的新开场

**接下来动作**：核对海报记录具体覆盖的外观、构图等静态目标，记录用户要求与实际采用范围；明确运动、节奏和音效需要解决的问题，为这些尚未覆盖的维度补充实际过程查看及对应音频依据，然后形成完整新开场方案。未来真正开始运动实现、声音搜集或入片时，再按技能路由展开运行时及素材声音契约。

**可开展／暂不能开展**：可分析和复用已观察到的海报外观与构图，整理运动和声音目标；静态研究充分覆盖且可独立推进的静态部分可继续，但不能把它写成完整视听开场方案的研究已完成。当前不能声称从海报观察出运动曲线、节奏或音效，也不能仅据静态证据完成依赖这些判断的新运动／声音设计。用户明确要音效，不能自行用无声替代要求。

**所需证据**：海报来源、查看范围与外观采用落点；覆盖拟研究运动问题的完整过程窗口及位置／范围说明；支持声音判断的实际音频材料及试听范围。未获取过程和声音部分保持未观察，不扩大海报结论。参考研究也不等于允许把海报图片或参考音频直接入片。

**依据**：`stage-plan.md#设计前搜索研究` 规定研究按当前问题选择维度，运动看过程、声音有对应依据；`reference-video-analysis.md#证据边界` 及“素材使用边界”；`visual-expression-inspiration.md` 规定用户明确声音要求仍须遵守。

**歧义处理**：题面没有说明运动、声音是否另有有效研究，按给定条件视为没有；若实际存在覆盖充分的真实记录，可依据复用规则核对后使用。静态海报可启发自主运动创意，但启发不等于已经实际观察或满足该维度的研究前置。
