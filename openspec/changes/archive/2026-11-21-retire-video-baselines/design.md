## Context

基线模块保存完整媒体和评审记录副本。主项目导出清理保护评审证据，运行时已经有候选生成、核验和当前交付替换机制。

## Goals / Non-Goals

**Goals** 退役旧基线写入，清理旧版本的整组副本，确保独立评审原件和当前版仍可使用。

**Non-Goals** 当前交付、原始素材、现行评审门禁和退役示例维持原有边界。

## Decisions

- 移除旧命令、保留模块和基线数量状态。修订直接使用当前工程，沿用现成的交付替换机制。
- 普通导出继续保护当前用途证据。一次性清理以精确路径清单执行，可处理旧类型、人工目录和 Windows 深路径。
- 先核对源记录、问题和比较引用。已有同摘要独立评审原件按原处保留，只有基线中存在的评审原件按原字节转存到评审记录目录。独立报告和失败结论保持原样，旧媒体不可用时以维护说明记录影响。
- 每个清理目标逐级确认路径归属、链接状态和 Git 跟踪情况。用实际删除前后的同卷可用空间测量释放量。

## Risks / Trade-offs

- 旧版完整媒体清理后将无法复放。原报告、来源摘要和无法复放的事实继续可追溯。
- 一个旧快照可能包含历史问题或评审原件，清理前按摘要核验，未知或无法核实的当前依赖需先解决。
