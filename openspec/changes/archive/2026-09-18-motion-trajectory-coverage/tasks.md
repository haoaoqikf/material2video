# 任务：把入场轨迹机检扩到全片每一个入场元素

## 1. 扫描本身要可信

- [x] 1.1 进入每一幕**之后**再逐帧收集元素（第一版在 seek 之前取集合，后面的幕 DOM 还是空的，导致只覆盖第 0 幕却报「全部通过」）。
- [x] 1.2 用元素引用本身做身份，不用 `className`（SVG 的 `className` 是 `SVGAnimatedString`，`String()` 之后所有 SVG 元素塌成一个 key，量出「两幕零入场元素」的假结论）。
- [x] 1.3 逐帧循环整个放在浏览器里（一次 `evaluate` 跑完一幕），不逐帧往返：整片两遍扫描各约 2 秒。
- [x] 1.4 覆盖度断言：每一幕都必须扫到入场元素；有位移的元素数量不得低于下限（防止位移读取悄悄退化）。

## 2. 判据

- [x] 2.1 判据量在不透明度上：位移里混着常驻呼吸，第一版把 `title-sub-line` 的呼吸摆动误报成「入场回退」。
- [x] 2.2 速度判据只适用于有位移的入场：实测 90 个入场元素里 9 个有位移、81 个是纯淡入（逐字揭示单字符 2 帧、小标注 2–5 帧），一刀切会把刻意做法判成缺陷。
- [x] 2.3 有位移的入场：首帧不透明度 ≤ 25%（真实最大 0.095、旧实现 0.438）、到 0.9 至少 6 帧（真实最少 7 帧）。
