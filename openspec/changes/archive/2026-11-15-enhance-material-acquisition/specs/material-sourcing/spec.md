## ADDED Requirements

### Requirement: 完整素材工作层操作指导

素材操作手册 MUST 提供从镜头需求、来源发现、受控获取、索引、检索、候选预览、选择精裁到既有导入和本地复用的连续指导，并能从主 Skill 与阅读路由到达。指导 MUST 明确 `discover`、`fetch`、`index`、`find`、`preview`、`select`、`library`、`models` 和 `doctor` 的职责、输入输出及失败下一步，区分制作期工作材料与正式作品材料；不得将工作工具另立为制作阶段、审核职责、成片完成条件或授权前置。

#### Scenario: 助手从口播镜头需求开始工作
- **WHEN** 制作助手尚未写完分镜但已明确对象、动作、身份限定和所需连续窗口
- **THEN** 手册指引其使用独立需求和多来源工作流，随后按现有导入和制作流程推进，不要求新增阶段或表单审批

### Requirement: 多源发现与可得性反馈

制作助手 MUST 按证据、对象识别、过程、解释或情绪等镜头职责组织需求，保留必要身份、年代地点、动作窗口和可替代范围，允许多语言、多查询及按缺口扩展来源。操作指导 MUST 区分图库、原始发布者、官方账号、新闻行业、开放档案、平台已知链接和本地材料的适用任务，并说明平台支持仅按实际验证范围披露。关键素材不可得时 MUST 将缺口反馈到现有文案和场景设计，调整表达或来源，不用无关动态冒充证据，不以固定检索次数或搜遍全部来源作为推进条件。

#### Scenario: 图库无法支撑具体企业事实
- **WHEN** 需求要求某企业真实工序，而图库只返回同类产业画面
- **THEN** 助手沿原始企业或可追溯来源补查，无法取得时收窄主张或改为明确示意，不把同类画面写成该企业实录

#### Scenario: 平台仅通过已知链接验证
- **WHEN** 某平台仅验证了有限分享链接获取，未验证全站发现或其他内容类型
- **THEN** 指导与交付说明仅披露相应范围，并给出站内检索词、链接登记或本地文件替代路径，不宣称稳定全平台覆盖

### Requirement: 召回观察与制作结论分开记录

制作指导 MUST 明确字幕提及不等于画面出现、画面相似不等于动作发生、切镜不等于过程完整。助手 MUST 依据当前实际媒体窗口检查对象、动作、裁切和事实关系，把召回依据、已观察结果和未知分别记录在既有研究、设计、来源及问题记录职责内，不复制一套成片审核台账。工具量测、模型分数和素材选择 MUST 不冒充独立视觉终审，源时间不明 MUST 保留未知，不以请求起点猜测。

#### Scenario: 字幕命中但画面是采访
- **WHEN** 字幕谈到生产动作，而实际候选窗口只有采访者或主持人
- **THEN** 助手将其标为语言命中而非动作已兑现，并换片段、补解释画面或调整表达，不由字幕分数直接采用为过程证据

### Requirement: 能力准备和真实性披露

操作指导 MUST 说明凭据、工具与模型是不同前提，模型恢复为显式动作，索引与检索不隐式联网取模型或媒体。文档 MUST 区分已实现、已配置、实际验证、受限和未验证，真实调用受网络、凭据或平台限制时 MUST 记录具体范围。外部媒体和模型二进制 MUST 不因操作示例而进入版本控制；恢复依据、版本和许可记录 MUST 可追溯，不将 mock、接口存在或搜索摘要当成获取与入片质量已验证。

#### Scenario: 只有离线模拟测试通过
- **WHEN** 某来源或模型尚未真实执行但离线契约测试已通过
- **THEN** 文档与交付说明分别报告模拟覆盖和未完成实测，不把该来源下载或模型检索列为真实通过

### Requirement: 素材工作层保持既有权威与采用政策

新操作指导 MUST 继续引用既有载体、来源采用、导入、声音及评审权威，不新增人物限制、引用时长比例限制、逐件授权或用户确认。Pexels API 停用、既有 `search`/`import`/`ref` 职责和参考素材边界 MUST 保持；工作层凭据和候选 MUST 不修改正式 project、分镜或媒体登记 schema，不把 `usableSegment` 描述为自动裁切指令。第一部分口播剪辑指南 MUST 只在第二部分能力实际交付后同步更新当前工具说明。

#### Scenario: 接入新素材工具后的文档同步
- **WHEN** 通用素材工作层实际实现并完成相应验证
- **THEN** 手册和口播指南更新真实可用入口及限制，载体、采用与成片审核继续指向原权威，不引入平行规则或虚构通过状态
