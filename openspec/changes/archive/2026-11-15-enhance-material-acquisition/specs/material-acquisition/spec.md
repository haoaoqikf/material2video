## Purpose

为五类视频制作提供不依赖完整分镜的素材需求、多来源发现与受控获取能力，把公开来源或显式本地文件转为可校验、可追溯的本地媒体，同时如实表达平台限制、资源开销、失败状态与源时间关系，避免获取过程破坏现有作品离线运行边界。

## ADDED Requirements

### Requirement: 独立素材需求与工作材料契约

系统 MUST 接受独立于完整作品和分镜的素材需求，至少描述稳定需求 ID、镜头职责、对象、动作、必要身份及年代地点限定、多语言查询、期望连续窗口、画幅偏好和可替代范围；场景关联 MUST 为可选。一项需求 MUST 支持多次查询和多个来源，不要求查询数等于幕数。需求、来源、已取媒体、索引、候选、选择和获取凭据等新工作材料 MUST 明确区分材料种类，并使用各自的 `schemaVersion: 1`；未知版本、非法结构、非有限数值和越界时间区间 MUST 在产生副作用前明确拒绝。

#### Scenario: 尚无完整分镜时寻找过程镜头
- **WHEN** 提供机械臂抓取零件的对象、动作、连续窗口和中英文查询，但没有作品或场景 ID
- **THEN** 系统接受需求并允许多来源发现，不要求补全分镜或为每个查询创建一幕

#### Scenario: 工作材料版本未知
- **WHEN** 发现、获取或后续工作流收到未知版本或类型不符的工作材料
- **THEN** 系统指出材料种类和版本错误，不下载媒体、不改写已有有效记录

### Requirement: 多来源发现入口与能力披露

系统 MUST 提供 `m2v author assets discover`，接受需求清单或重复查询，输出来源候选、实际查询、分页与来源覆盖情况，不自动将发现结果当作已获取或可入片媒体。发现 MUST 覆盖现有 Pixabay、Wikimedia Commons、Internet Archive、NASA、具备搜索支持的平台，以及显式登记的网页与本地来源；各来源 MUST 披露搜索、元数据、获取、字幕、分页及凭据能力。公司、人物、事件和具体产品需求 MUST 保留原始发布及身份限定，不能仅因标题或画面相似即声明事实匹配。画幅 MUST 只作排序偏好，不硬性排除其他比例。

#### Scenario: 多个来源和查询发现候选
- **WHEN** 同一需求提交中文别名、英文动作描述和多个来源
- **THEN** 系统返回聚合且可追溯到原查询和来源的候选，并披露实际覆盖的来源与分页范围

#### Scenario: 仅取得网页候选
- **WHEN** 某来源只能提供页面或检索入口，尚未取得媒体文件
- **THEN** 系统保留页面候选及待获取状态，不编造媒体摘要、动作观察或下载成功状态

### Requirement: 既有素材入口语义保持

新增素材工作流 MUST 不改变现有 `search`、`import` 和 `ref` 的既定职责。Pexels API MUST 保持停用，不因提供密钥或启用多来源发现而恢复；Pexels 网页候选及公开媒体文件 MUST 仍可按既有导入契约使用。参考获取 MUST 继续区分研究参考与正式素材，新流程 MUST 不自动采用参考画面或扩大既有参考音轨例外。

#### Scenario: 多来源发现配置包含 Pexels
- **WHEN** 使用者希望将 Pexels 纳入素材来源并提供 API 密钥
- **THEN** 系统不调用被停用的 Pexels API，明确说明网页候选和公开直链路径，不将配置密钥解释为恢复 API 的授权

#### Scenario: 已取得抖音参考作品
- **WHEN** 参考分析目录已有一条完整参考作品
- **THEN** 新素材工作流不自动将其画面登记为正式素材，正式采用仍须走现有导入路径

### Requirement: 已知链接与本地媒体获取

系统 MUST 提供 `m2v author assets fetch`，接收来源候选、显式页面或分享链接、公开媒体地址以及本地文件，返回可校验的已取媒体或明确失败。系统 MUST 支持公开文件、可处理的无 DRM 非直播分段媒体、音视频分轨合并、章节和可提取字幕，允许显式整片或区间获取；直播和 DRM 内容 MUST 明确报告不在自动获取范围。平台获取 MUST 按实际适配和验证范围披露；已知链接的尽力处理 MUST 不被描述为全站搜索、匿名稳定下载或全平台支持。获取失败 MUST 允许换来源或使用本地文件，不要求修改作品契约。

#### Scenario: 从发布页面取得媒体
- **WHEN** 输入受支持的公开发布页面而不是媒体直链
- **THEN** 系统解析并获取可用媒体及来源元数据，探测实际类型、尺寸和时长后发布本地结果

#### Scenario: 国内平台链接需要会话
- **WHEN** 已知分享链接因会话、登录、验证码、付费权限或不支持而无法自动取得
- **THEN** 系统返回对应状态和可执行的替代建议，不宣称平台已稳定支持，也不自动读取日常浏览器凭据或绕过访问控制

### Requirement: 来源身份与实际媒体身份分离

系统 MUST 分别记录来源页或平台条目身份、所选规格、实际取得文件的摘要与大小、获取时间和工具身份；同一来源内容更新 MUST 不覆盖仍被引用的旧媒体身份。仅取得区间时 MUST 只声明实际区间文件的摘要，完整上游文件摘要未知时 MUST 保持未知。临时媒体地址 MUST 不充当稳定来源 ID；未知作者、许可、规格和发布时间 MUST 不补造。

#### Scenario: 区间下载没有完整源文件
- **WHEN** 只取得一段视频且未下载完整上游文件
- **THEN** 记录片段文件的实测摘要与覆盖范围，完整上游摘要保持未知，不把片段摘要写成整片摘要

#### Scenario: 同一链接返回新字节
- **WHEN** 重新获取同一发布条目得到不同媒体字节
- **THEN** 新结果有独立媒体身份，既有候选与选择仍绑定原字节，不静默漂移

### Requirement: 源时间关系诚实记录

系统 MUST 区分请求区间、本地媒体区间、可证明的源视频区间和原始媒体时间戳，使用无歧义的单位及半开区间。源时间映射 MUST 标注已验证、估计或未知及其依据与误差；MUST NOT 仅以请求起点、文件名、名义帧率或本地归零时间戳推定精确源起点。可变帧率、非零起始时间戳及重新封装的媒体 MUST 保留实际时间关系；未知映射 MUST 将 `sourceRange` 保持为 null，不输出伪精确源区间。

#### Scenario: 请求起点不同于实际取得起点
- **WHEN** 请求从源视频某时刻获取，但实际文件从更早的可定位点开始或时间关系不足以证明
- **THEN** 系统分别保存请求和已知覆盖信息，映射为估计或未知，不将请求起点写成已验证映射

#### Scenario: 局部零秒不等于源片零秒
- **WHEN** 区间媒体或预览从局部零秒开始播放
- **THEN** 后续候选能区分局部坐标和有依据的源坐标，未知源坐标保持未知

### Requirement: 有限资源预算与获取策略

获取 MUST 支持元数据与预览先行、选中后取合适画质，并允许显式整片获取。单文件大小、总流量、磁盘余量、缓存、并发、时限、重试和列表数量 MUST 有有限且可配置的预算；预算耗尽 MUST 停止新增开销并保留已校验结果。源长视频预算 MUST 与正式素材现有导入大小限制分开，不得因源文件过大而悄悄放宽正式导入契约。系统 MUST 报告实际流量和耗时，不保证区间请求必然仅传输目标区间字节。

#### Scenario: 长视频超出本轮预算
- **WHEN** 获取过程中达到已声明字节或磁盘预算
- **THEN** 系统停止该项并报告资源限制，不写满磁盘、不发布未校验文件，也不改变正式片段导入限制

#### Scenario: 页面包含大量列表条目
- **WHEN** 输入合集、账号列表或可继续分页的来源
- **THEN** 仅在显式列表数量和分页预算内发现或获取，不无人值守镜像整个账号

### Requirement: 部分失败与可恢复操作

批量发现和获取 MUST 区分成功结果、零候选、失败项和部分完成，失败项 MUST 至少指出阶段、脱敏原因、是否适合重试与下一步。单来源缺凭据、超时或限流 MUST 不阻断其他独立来源。重试 MUST 有界并尊重服务端等待信号；过期临时地址 MUST 重新解析来源，不无限重试旧地址。续传 MUST 验证远端身份，取消和崩溃恢复 MUST 不破坏既有有效媒体或把不同版本拼接成同一文件。

#### Scenario: 一处限流但其他来源成功
- **WHEN** 一个来源限流而其他来源返回候选或取得媒体
- **THEN** 返回成功结果和独立失败说明并标明部分完成，不把失败伪装为该来源零候选

#### Scenario: 续传时远端内容变化
- **WHEN** 中断后的临时文件对应的远端身份已变化
- **THEN** 系统不直接拼接续传，重新取得或明确要求重试，旧有效媒体保持不变

### Requirement: 全阶段网络与外部媒体安全

新获取层 MUST 对初始链接、每次重定向、页面派生媒体、字幕、缩略图、分段清单和分片地址执行同一受控网络政策，拒绝非 HTTP(S)、URL 内嵌用户名密码、私网、本机、链路本地、云元数据及其他非公开目标。连接 MUST 受已校验解析结果约束，不能因二次解析或 DNS 变化连接到被禁止地址。外部工具的后续请求 MUST 受相同政策约束；无法受控的下载或协议 MUST 默认拒绝，不得以仅检查入口 URL 冒充完整防护。新 fetch MUST 不自动回退到尚无同等出站约束的旧参考浏览器路径；当区间或分段获取将启用无法受控的联网媒体工具时，MUST 拒绝该路径，允许预算内完整获取后本地精裁或报告本地文件替代，不得静默放开网络协议。跨源重定向 MUST 不转发敏感会话头；本地索引和精裁 MUST 不因伪装播放列表触发网络访问。

#### Scenario: 公开页面重定向至私网
- **WHEN** 初始公开地址重定向到本机或私网地址
- **THEN** 系统在连接受限目标前拒绝请求，报告脱敏的安全原因

#### Scenario: 分段清单含受限分片
- **WHEN** 公开媒体清单包含指向内网、云元数据或 DNS 解析变为受限地址的分片
- **THEN** 系统拒绝该分片及依赖它的获取，不让媒体工具绕过网络政策继续访问

#### Scenario: 区间获取需要无法受控的联网工具
- **WHEN** 平台区间或分段获取将回退到无法执行同等网络政策的下载器或浏览器
- **THEN** fetch 拒绝该路径，改用预算内受控完整获取后本地精裁或报告本地文件替代，不自动借用旧 ref 浏览器放开出站限制

### Requirement: 凭据与外部内容隐私

系统 MUST 只使用显式配置的环境凭据、会话文件或专用 profile，不自动扫描个人浏览器、账号或目录。cookie、授权头、签名地址中的敏感信息和密钥 MUST 不进入普通日志、可发布工作材料、候选页、获取凭据或版本控制。错误与元数据 MUST 脱敏；外部文本和地址 MUST 作为数据处理，不能变为执行命令、任意路径写入或页面脚本。访问限制 MUST 记录为技术状态或风险，不被虚构为权利人已禁止或已授权。

#### Scenario: 分享链接和响应包含令牌
- **WHEN** 获取使用带敏感参数的分享链接或服务端响应回显凭据
- **THEN** 运行过程仅在必要范围内使用，持久材料和日志保留公开可追溯来源及脱敏信息，不泄露令牌

#### Scenario: 来源文本包含命令或脚本
- **WHEN** 标题、描述、字幕或网页字段包含脚本、shell 片段或越界路径
- **THEN** 系统按文本展示或拒绝无效字段，不执行、不产生越界文件，也不注入候选页面
