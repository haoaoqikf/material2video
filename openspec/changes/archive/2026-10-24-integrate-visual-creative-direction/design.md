## Context

动机见 [proposal.md](proposal.md)。运行时和 CLI 不消费这些主观创作判断；问题集中在 Skill 指导、主规格、逐场模板、评审语言与示例设计说明，须统一修订，而不是新增机器审美门禁。

## Goals / Non-Goals

- 把视觉创意导演方法落成方案确定阶段的必答问题与可填写模板。
- 让逐场设计、视觉复核与导演审查能核对设计是否在成片兑现。
- 保持既有创意保护取舍，不重制视频，不改运行时。

## Decisions

1. **新建独立参考文档，不继续膨胀现有文档**：`creative-production.md` 已承载节奏、美术、声音与阶段；新方法有独立步骤、模板和自检，单列一页更易检索。`production-workflow.md` 只加阶段入口与映射，不复制全文。
2. **七段式放在选定方案后**：三案阶段各案只提出核心表达与母题候选，避免在候选比较前锁死整片母题，保持「三个候选讲述机制实质不同」的现有要求。
3. **必答 + 例外留痕，保持 2026-10-23 的创意保护取舍**：归档变更 `2026-10-23-strengthen-design-and-protect-creative-intent` 已去掉强制母题、固定高潮与硬测试。本次不恢复硬门禁：母题问题必答，但可以回答「不采用母题，改用 ___ 组织」；高潮标出实际强度分布，克制时记录替代记忆点；关声可读只作设计诊断。
4. **文字预算按镜头/信息单元，而非 scene**：一个 `scene` 可以包含多个镜头和多段信息（如太阳系单幕 31 镜头），按 scene 限制会误伤。标签、轴、数据、事实边界、口径、许可与示意标注不计入；文字主导、信息图、档案与静止构图不因形式被否决。
5. **禁止项是默认模板清单，不是形式否决清单**：沿用现有「版式重复」判据，只有完整段落缺少信息、关系或体验推进时才必改；采用例外须记录理由与替代做法。
6. **转场与镜头尊重现行运行时**：幕间只有 `cut`/`fade`/`crossfade`，形态变换在代码场景内部完成；`shots[].camera` 由作品代码消费，不新增自动运镜或转场字段。
7. **导演审查增加「设计兑现」检查**：否则七段式只是 DESIGN 里的文字。审查仍先盲看，设计文档不作为成片成立证据；七段式也不进入独立评审包。
8. **示例只写非重制记录**：沿用既有「后续设计与评审应用」先例，三个示例补写七段与自检，不改写交付结论，不声称成片已按新方法重制。
9. **通过 catalog + sync_docs 更新导航**：`general.skillGuide` 加入新文档，避免手改生成区与测试漂移。

## Risks / Trade-offs

- 「必答」可能被误读为新硬门禁 → 明确它不是评分、用户确认、运行时字段或 CLI 导出条件；不适用时记录原因与替代做法。
- 默认清单可能被误用为形式否决 → 每条加限定（无信息推进、无关系变化、无信息增量），并保留现有母题/版式判据。
- 关声自查可能被写成拆声门禁 → 明确它只作设计诊断，有声作品仍按完整声画验收。
- 新增独立文档可能与现有文档重复 → 新文档负责方法与模板，现有文档只加入口、映射或一句引用；共享规则只写一次。
- 示例补写可能被读成重制 → 每节明确「非重制记录」，不修改分镜、场景、音频或视频产物。

## Migration Plan

后续启动任务采用新指导；既有作品与评审历史不迁移、不倒填。实施完成后运行测试、`sync_docs.py --check` 与 OpenSpec 严格校验；同步主规格后归档并提交。
