## Context

现有流程能稳定产出高质量单帧，但把“动态”留在实现阶段：分镜事件主要驱动声音，场景只在离散状态间换图，转场默认 cut。灵感文档已有视觉、表达、动态、音效、转场五类参考，但研究与设计只记录视觉风格，其他四维没有决策字段，评审也没有可量测的运动/转场/声音指标。

AI 评审没有播放器和听觉，能用的证据是：有序帧/静帧、完整解码与帧数/时长、帧差与场景切分、主体区域 bbox/质心/面积/颜色、音频响度/真峰值/静音/起音/频谱/同步。评审必须以这些证据得出结论，而不是等待“看过、听过”。

## Goals / Non-Goals

- 让五维进入 RESEARCH.md 与 DESIGN.md，而不是停留在灵感文档。
- 允许只有静态图时推导其余四维，但推导必须标为假设并落到可量测验证。
- 让评审可完全由帧与信号证据完成，删除播放/试听前提。
- 不新增命令、材料字段、分镜字段、渲染契约或音频引擎；不改变现有混音、许可、摘要绑定与交付权限。
- 不要求每个维度选用列表项；允许自创或明确不用。

## Decisions

1. **五维决策记录**：RESEARCH.md 增加“视听推导”小节，固定写五维：视觉风格、表达模式、动态风格、音效风格、转场风格。每维包含“选择/不用/自创、依据、置信度、验证办法”。DESIGN.md 引用这些结论，不复制研究全文。
2. **静态图推导**：从静帧提取材质厚度、曲率、光向、阴影软硬、主体尺度、层间空气、色彩层级、字体重量、留白；按固定映射提出运动速度/缓动、镜头、转场类型、声音材质与节拍。推导必须写“依据 → 推断 → 置信度 → 验证指标”，不得写成已观察事实。
3. **可量测预期**：DESIGN.md 的逐场表增加“可量测预期”列，至少覆盖：状态切换帧、最长无变化窗口、非 cut 转场的重叠帧数与类型、匹配剪辑的主体位置/颜色容差、声音事件帧与起音偏差、响度/峰值/静音段。没有可量测预期的场景视为未设计。
4. **评审证据**：评审报告只引用帧号、时间、帧差、切分、主体量测和音频信号值。motion/transition/sound 的 verdict 按设计阈值判定；缺指标写 insufficient，指标不达预期写 fail。报告标注“证据类型：帧序列 + 信号量测”，不再写“未实时播放/未听音”作为通过前提。
5. **转场语法**：非 cut 转场必须声明语义（时间流逝、对比、同一对象、层间关系）与帧数；cut 只在需要硬对比时使用。匹配剪辑须核对跨切点的主体位置、尺度、颜色与构图关系。
6. **变化密度**：每场至少一个视觉节拍；超过设计声明的静止上限必须写“为什么静止”（阅读、情绪、对比）。评审用主画面区域的帧差曲线测最长静止，字幕变化不计入主体变化。
7. **文档清理**：删除“必须播放/试听/实际观看才能评审”的表述，改为“有序帧 + 解码 + 帧差/切分 + 音频信号”。保留现有技术校验、许可与摘要绑定；不引入人工检测步骤。

## Risks / Trade-offs

- 帧差与信号量测不能完全代表主观质感 → 结论限定在可量测范围，不写“自然、动人、听感好”等无法量测的判断；设计阈值按当前作品声明。
- 静态推导可能错 → 必须用过程样片的帧/信号证据核对，修正推导，不把假设写成通过。
- 五维记录可能变成填表 → 允许“明确不用/自创”，只要求决策与验证指标，不要求选满或使用列表项。
- 指标可能鼓励机械变化 → 阈值由设计声明，静止可以是有效表达，但必须有理由。
- 删除播放/试听前提可能被误读为降低要求 → 明确评审仍须覆盖过程、转场、声音同步与可量测质量，只是证据形式改变。

## Migration Plan

先完成文档与规格调整、针对性验证和提交；再同步主规格并归档。作品 RESEARCH.md/DESIGN.md 的回填与试制片在后续任务执行；不重制历史作品，不改写旧报告。
