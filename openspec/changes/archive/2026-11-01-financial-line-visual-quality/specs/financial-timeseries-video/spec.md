## MODIFIED Requirements

### Requirement: 手机可读布局与统一说明

画面 MUST 保留完整单行假设投资标题，按“假如你＋年份＋买入＋本金（含元）＋标的”顺序说明投资假设，指数采用按比例投资表述。顶部 MUST 左侧突出 64px 年份，右侧显示“当前市值”及最大 56px 金额，并以 24px 辅助字显示最近真实收盘日期；金额过长时 MUST 按固定字号档位适配右侧宽度，不得逐帧按当前字符串反推字号。年份采用最新已揭示收盘日期，尚无报价时采用展示起始年份；投资起点前 MUST 隐藏市值、完整日期、端点和曲线。推进阶段 MUST 不显示收益金额及收益率。结尾 MUST 冻结完整曲线和坐标，并与最后推进帧保持相同的年份、当前市值及实际收盘日期，期间画面静止，不显示本金到最终市值总结或收益率，也不进行淡入。金额 MUST 使用中文数量级并以“元”结尾，数字与单位之间 MUST NOT 插入空格，金额与纵轴刻度 MUST NOT 使用千分位分隔；底层保持原计价单位不换汇。正收益的市值及曲线 MUST 为红色，负收益 MUST 为绿色，持平 MUST 使用中性浅灰，且市值与曲线同色。绘图区 MUST 为 x=224～924、y=490～1260。纵轴 MUST 使用 22px 刻度并右对齐于 x=208，数量级单位 MUST 只在轴顶标注一次，刻度数字 MUST 按刻度间距决定小数位且不得出现重复值。折线 MUST 使用双层绘制，端点半径 8px 并配外环。底部说明 MUST 位于绘图区与横轴标签之下。未配置法律地位说明的请求 MUST 显示既有统计口径和固定风险提示；crypto 请求配置 `investment.legalStatusNotice` 时 MUST 显示起点说明（若有）及该法律地位说明，并 MUST 隐藏估值口径和通用风险提示。标题、指标、坐标轴、折线、端点及底部说明 MUST 作为统一内容组，根据实际可视元素包围盒自动平移，使整体垂直中心对齐画布中线 y=960；当内容高度超过纵向布局可用高度时 MUST 阻断，不缩字或裁切。画布与背景保持不变，背景 MUST 使用低对比渐变而不是单一纯色。统一项目布局边界 MUST 为 x=140～940、y=180～1740，纵轴刻度使用同一布局边界；边界检查 MUST 以变换后的实际边界为准。标题过长无法维持 26px 或底部说明超过四行 MUST 阻断。底部说明不大于 24px，风险提示最多两行，画面不显示来源标签或来源网站名称，股票注明仅拆合股调整、不计分红、手续费及税费，指数注明比例模拟且不可直接持有。核心内容 MUST 通过 360×640 手机缩放及实际字体边界检查；纵轴刻度在该缩放下 MUST NOT 低于约 7px 实际高度。

#### Scenario: 扩展绘图区并保留其他文字边界

- **THEN** 市值可用宽度根据年份占位和间隔计算，不与年份重叠

### Requirement: 竖屏持续折线场景

所有金融视频 MUST 使用 1080×1920、30 fps 单标的持续场景，显示单行投资假设标题以及年份、当前市值和实际收盘日期；日期对应最近实际收盘数据，不单独显示完整日期范围或动画日历日期。MUST 不展示股价数值、股价折线或事件与 K 线。投资年份首个有效交易日收盘价 MUST 作为买入价，持仓比例为本金除以买入价。投资起点之前 MUST 隐藏组合价值曲线及收益指标；之后 MUST 以最近已揭示的真实收盘价计算组合市值、收益金额（市值减本金）与收益率（收益金额除以本金）。折线及纵轴 MUST 使用已揭示的组合市值；不插值报价、不使用未来价格。横轴 MUST 从开头展示首阶段范围，左边界固定，右边界分阶段平滑扩展；历史曲线持续保留。纵轴 MUST 根据已展示的组合市值极值自适应，上下各留白 8%；单点或恒定组合价值使用其绝对值 1%（至少 0.01）作为半跨度，轴下限不得低于零。纵轴使用因果确定性平滑且不因未来数据改变。当前市值金额和日期 MUST 与最新真实数据点同步更新并显示在画面顶部；图表内仅显示跟随最新真实数据点的端点圆点，不重复显示金额标签或底板。历史折线 MUST 始终完整可见，不得被其他标注遮盖；绘制探针 MUST 检查端点圆点在折线之上。休市日沿用最近真实收盘价所推导的组合价值。

#### Scenario: 年度买入及动态投资指标
- **WHEN** 时间轴到达投资年份首个交易日及其后各有效交易日
- **THEN** 使用该年首个真实收盘价作为买入价，按已到达的真实价格更新组合价值曲线和市值；收益率用于内部计算，但不作为画面指标显示

#### Scenario: 投资起点之前
- **WHEN** 播放日期早于买入日或尚未到达买入日收盘
- **THEN** 不显示投资价值曲线、市值、收益金额或收益率

#### Scenario: 休市日及任意寻帧
- **WHEN** 播放日期为休市日或跳转到任意帧
- **THEN** 沿用最近有效收盘价计算组合值，同帧结果与顺序播放一致且不读取未来价格

#### Scenario: 组合价值新高与回落
- **WHEN** 已揭示组合价值出现新高、新低或明显回落
- **THEN** 纵轴及时容纳全部已揭示的组合价值，历史曲线不被裁切且范围不读取未来值

#### Scenario: 固定横轴逐步揭示
- **WHEN** 播放多年历史投资视频
- **THEN** 第一阶段范围从首帧可见，左边界不变，同一日期横坐标随扩展平滑变化，历史点保留且未来点不提前出现

### Requirement: 独立无声制作与交付验收

专题 MUST 使用独立的数据输入和无声验收，不套用文章字数、口播和有声门禁。制作 MUST 经请求解析、价格核验、资料保存和编排后一次生成完整静音候选，MUST NOT 先完整预演再完整导出。正式生成 MUST 不依赖预演，生成候选后 MUST 要求当前准备记录及完整候选绑定当前三类材料、渲染构建输入和金融 Python 代码，并验证候选摘要与完整帧数；MUST NOT 要求或生成金融人工评审结论或证据。候选生成 MUST 通过逐帧布局、字体边界与历史折线裁剪探针，并通过 MP4 解码、帧数、画布尺寸、帧率、时长和无音轨验收。缺少或过期准备/候选、摘要不匹配、自动探针失败或媒体验收失败时 MUST 阻断，且不得覆盖先前有效成片。预演不得覆盖正式成片。成功交付 MUST 输出 1080×1920、30 fps、无音轨 MP4，并保留当前候选与 delivery.json。

#### Scenario: 完整评审
- **WHEN** 金融作品具有当前有效材料、准备记录及绑定其材料与渲染资产的完整候选
- **THEN** 逐帧画面探针和媒体验收通过后可正式输出 1080×1920、30 fps、无音轨 MP4，无需人工评审文件

#### Scenario: 正式导出
- **WHEN** 行情校验和完整候选自动验收全部通过
- **THEN** 输出 1080×1920、30 fps、无音轨 MP4，最终曲线完整

## ADDED Requirements

### Requirement: 趋势材质、本金基准与背景氛围

主曲线下方 MUST 绘制到绘图区底部的低透明度渐变面积，主曲线 MUST 带有低透明度外描边形成光晕；端点 MUST 在实心圆外增加 12px 同心外环，并在当前收盘位置绘制一条淡竖向参考线。本金落在当前纵轴范围内时，MUST 绘制一条虚线基准线并在右侧空间允许时以小于主体文字的字号标注“本金”；距离绘图区底部过近时只保留虚线；该线 MUST NOT 显示收益金额、收益率或额外数字。背景 MUST 使用低对比径向渐变，网格、轴线、面积、日线、主曲线和端点 MUST 按由弱到强的明度分层，不得让网格或面积压过主曲线。以上元素 MUST 位于绘图区裁剪或布局边界之内，并参与既有裁剪与安全区探针。

#### Scenario: 本金位于当前范围
- **WHEN** 纵轴范围包含投资本金
- **THEN** 画面显示一条淡虚线基准线，空间允许时显示小字“本金”，不显示收益金额或收益率

#### Scenario: 本金不在当前范围
- **WHEN** 纵轴范围不包含投资本金
- **THEN** 不绘制本金线，也不显示相关文字，其余元素保持不变

#### Scenario: 曲线材质与背景
- **WHEN** 查看任意推进帧
- **THEN** 主曲线下方有渐变面积与外描边光晕，端点有外环与竖向参考线，背景为低对比渐变，网格不压过主曲线

#### Scenario: 历史完整性
- **WHEN** 逐帧检查完整候选
- **THEN** 主曲线与日线的完整历史包围盒均位于有效裁剪范围内，端点绘制在两条曲线之上
