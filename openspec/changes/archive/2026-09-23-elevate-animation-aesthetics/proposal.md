## Why

当前流水线已经能够稳定产出可复现、可校验、不过界的竖屏信息视频，但“通过机检”与“值得欣赏”之间仍有明显差距：分镜偏向信息组件编排，缺少贯穿全片的视觉母题、镜头连续性、情绪曲线与声音层设计，动画也容易退化为元素依次入场。现在需要把审美和导演决策提升为一等产物，使质量提升不再依赖每次临场发挥。

## What Changes

- 为文章到分镜流程增加创作简报、核心认知转折、情绪曲线、视觉母题和风格包选择。
- 扩展分镜声明，使每幕能够声明镜头构图、景别、景深、焦点、镜头运动、前后状态以及与前后幕的视觉转场关系。
- 将动效节拍从“按时间入场”提升为“状态或关系变化”，支持跨幕视觉对象连续、变形、拆解、重组和焦点转移。
- 增加作品级视觉风格包，统一色彩、排版、表面、线条、动效和转场语言；保留现有 `keynote` 兼容性。
- 增加分镜静帧 / 缩略图审美评审环节，在完整渲染前暴露构图重复、视觉母题缺失、节奏单一和文字主导等问题。
- 为媒体时间轴预留背景音乐、音效、静音与混音层接口；本变更先完成可扩展契约和最小渲染支持，不强制引入具体音乐资源。
- 更新校验器、视觉评审、示例与 article2video 参考文档；现有分镜在未声明新字段时保持兼容。

## Capabilities

### New Capabilities

- `cinematic-directing`: 创作简报、情绪曲线、视觉母题、镜头声明和跨幕转场契约。
- `storyboard-aesthetic-review`: 分镜静帧 / 缩略图审美评审及发布前阻断条件。

### Modified Capabilities

- `visual-direction-pipeline`: 视觉方向从单幕意图扩展为全片导演策略和风格包。
- `semantic-motion-timeline`: beat 增加前后状态、关系变化和跨幕连续性。
- `keynote-design-system`: 风格令牌与动效 / 转场语言扩展为可复用作品级风格包。
- `article-to-storyboard`: 文章拆分流程增加认知转折、情绪曲线与视觉隐喻阶段。

## Impact

- 影响 Python 分镜 schema / 校验器 / 评审脚本、媒体清单，以及 React 场景树运行时和动效解析。
- 影响 `storyboard.json` 的可选字段与严格校验；旧分镜保持可渲染，新分镜在启用新导演能力时接受额外校验。
- 需要新增或扩展通用原语的连续变形、跨幕状态和镜头变换能力，但不为单支视频写专属实现。
- 需要同步更新 `openspec/specs/` 对应主规格、skill 参考文档和至少一个端到端示例。
- 不在本变更内实现平台发布、模型自动审美裁决或自动生成背景音乐素材。
