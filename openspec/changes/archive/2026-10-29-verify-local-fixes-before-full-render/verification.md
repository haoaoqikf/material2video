## 场景演练

| 情境 | 核对结果 |
|---|---|
| 前期打磨接触或拉远揭示失败 | 回写受影响设计与实现，查看完整事件窗并完成适用复查，相关风险关闭后再扩展 |
| 全片发现文字裁切、动作不自然等多处缺陷 | 集中登记，分别查看当前静帧与动作窗口并复查衔接，汇总后生成下一候选 |
| 源码已改、预览已生成但尚未查看 | 正文写已修改待复查，机器状态保持 open，不能据此确认修复 |
| 局部效果改善但原问题须独立复查 | 正文记录实际观察和证据，机器状态仍为 open，沿原独立关闭规则处理 |
| 修改总时长、结构、全局风格或混音 | 按影响扩大完整时间线及正式文件验证，记录局部无法确认的范围和再次生成原因 |
| 仅重试有效候选的 QA 或交付 | 复用原文件，不重新编码 |
| 无法播放动态证据 | 按既有要求补有序时间码帧，仍不足则保留未验证，不用单张截图放行运动问题 |
| 新候选产生、首次生成或其他视频类型 | 新候选仍完整 QA/G6；首次生成沿用阶段条件；金融和住宅专用契约不变 |
