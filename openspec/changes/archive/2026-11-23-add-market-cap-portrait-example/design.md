## Context

竖屏作品由一个 3,214 帧场景呈现。该场景和归一化后的数据在本地独立工程中运行，原作品曾登记一套仅旧试制使用的本机字体。随附示例必须脱库恢复、预演及导出。

## Goals

- 用第 5 部随附示例分发完整竖屏作品，保留舞台视觉、榜首交接、数据和无音轨规格。
- 提供能随实例复制的运行环境、可恢复资源及研究和场景说明。

## Decisions

- 复制正式渲染依赖和项目自有运行时，使用单独的示例标识。保留正式场景、数据与分镜帧序，以便将重新导出的结果和原片逐帧比对。
- 示例内仍按场景入口与单幕无声完整画布的条件使用直接交付编码。这样在复制示例或变更工程标识时，原有的色彩转换和编码路径继续生效。
- 登记正式舞台实际采用的 Inter 与 Noto Sans SC，保留字节数、摘要、许可证和公共恢复方式。结构化市值数据作为普通源码附件入库。
- 扩充索引和既有参数化验证，并从仓库外副本重走正式本地入口。生成文件留在本地输出目录。

## Risks / Trade-offs

- 脱库可能暴露遗漏的源码、外部字体或环境依赖。用 Git 索引导出的副本恢复、构建和渲染，覆盖常规入口。
- 历史数据采样间隔不均。同步记录时点、来源和插值规则，明确视频能表达的范围。
