## 1 共享动效原语

- 实现：`web/src/code-scene/primitives.ts` 提供数字滚动、数据曲线与柱状生长、列表滚屏、
  主体状态插值、签名粒子；`sdk.tsx` 统一导出，作品从 `m2v/code-scene` 导入。
- 原语只接受 `progress` 与调用方参数，不读取挂钟、帧号、上一帧状态或外部计时器；
  不返回颜色、字体或线宽；粒子随机性只来自显式种子（缺省固定）。
- `implementation_inputs()` 递归收集 `web/src/code-scene/` 下的 `.tsx`、`.ts` 与 `.js`，
  修改原语会使引用作品的片段缓存与准备指纹失效。

验证结果：

- `pnpm -C web test`：5 个测试文件、83 项通过，覆盖重复求值、跳帧采样、种子、
  0 与 1 边界及非法参数。
- `pnpm -C web typecheck`：通过。
- `pnpm -C web build`：通过。
- `uv run pytest tests/test_motion_primitives.py`：3 项通过（实现指纹、确定性源码闸门、SDK 导出）。
- 源码闸门未发现挂钟、隐式随机源、计时器或未适配的 CSS 动画。

## 2 参考短片立意回归演练

- 参考：一条 62.03 秒的公开抖音短片（本地参考素材，不入库；本次只导出 13 张 5 秒间隔采样帧
  到仓库外临时目录）。
- 执行：新建上下文的独立子代理，只接收采样帧与公开标题/标签，不接收 `DESIGN.md`、
  设计理由、旧结论或本变更文档。采样帧不含声音，未播放连续视频。
- 产出：子代理独立写出了六项：
  1. 一句话命题：单次 1% 的成功率，重复次数足够多时至少成功一次的概率趋近 100%，
     失败只说明次数还不够。
  2. 视觉母题：金色水滴/金点与大片失败记号之间的数量关系，跨文字卡、图表与插画出现。
  3. 母题演进：开场是红叉阵列中的单个金点；中点是概率曲线上的数据点/拖尾光点；
     收束时水滴角色回归、石头从完整到裂开、时间单位从“次”变为“日”。
  4. 看穿时刻：0–5 秒即呈幻灯片式文字堆叠；依靠数字体量、1%→99% 的反转与 12 秒首次
     非文字画面留人。子代理同时披露：采样帧看不到数字跳动动效与声音，无法确认真正的留人手段。
  5. 可验算骨架：`P = 1 − 0.99^n`；验算 35 次→29.7%、10 次→9.6% 成立，并发现
     「50 次→18.3%」「459 次→37.1%」与公式不符，指出标签与数值错配。
  6. 赌注：12–17 秒与 47–52 秒的水滴角色与石头开裂插画，约 10–12 秒；删除后定量链条
     不缺，理解损失接近零，估算工时 6–12 小时（工时无法从帧验证）。
- 与原片五个动手前决策对照：单一画面主角、数字必须真算、结尾收在数学上均被独立产出；
  「用成语作骨架」只被部分产出（识别出水滴与石头，但未把成语本身命名为骨架）；
  「不做旁白」无法从采样帧推断，子代理如实标注为不可确认。
- 结论：六项能在不看原答案的情况下产出主要关键决策，也能暴露数字错标这类问题；
  涉及声音与连续运动的决策需要额外证据。参考素材未入库。

## 3 三个固定示例的母题判别

判别口径：取同一构图首次与末次出现的实际帧，按同一显示尺寸比对；主体以外区域变化率低于
5%，且主体状态至少一项参数单调变化时，视为母题重复；任一条件不成立不得按母题重复处理。

| 示例 | 实际帧 | 测量 | 结论 |
| --- | --- | --- | --- |
| `traffic-jam-wave` | 00:02 与 01:00、01:04、01:08（540×960） | 道路、后视镜与标题位置相同；主体以外的背景区（x 0–270、y 200–350）变化 0.46%–0.58%；道路带红色慢区像素 221→30→0→0，单调不增 | 母题重复：同一构图、状态单调演进、每次携带新信息；不得判为版式重复 |
| `american-science-milestones` | 00:04 与 00:14 | 两幕使用不同档案/实物素材与不同机制示意，构图与信息关系不同 | 不适用母题例外，也不是版式重复 |
| `solar-system-journey` | 00:30 与 02:00 | 金星特写与柯伊伯带尺度画面，主体、尺度与构图均变化 | 不适用母题例外，也不是版式重复 |

- 三个示例均没有由逐页替换模板主导全片的段落；既有判断演练「十个段落都使用相同静态信息卡，
  只替换年份、标题和说明」仍必须判为版式重复必改。该判定未放宽。
- 限制：以上取样自动画成片，不是新增的自动检测器；背景区选取与采样时刻已在表中披露，
  结论只覆盖所检查的帧。母题判别仍是复核方法，不进入 CLI 或导出门禁。
