## MODIFIED Requirements

### Requirement: 手机可读布局与统一说明

画面 MUST 使用注册字体 `M2V Inter` 与 `M2V Sans`，数字 MUST 使用等宽数字样式。顶部 MUST NOT 再显示独立的 64px 大年份。投资假设标题 MUST 使用 40px、字重 700、字距约 -0.02em、左对齐，无法在安全区保持 26px 时阻断。当前市值 MUST 作为右对齐 hero 金额，字号从 72px 起，按 72/64/56 固定档位适配右侧宽度；其下方 MUST 使用 24px 次文字显示“当前市值 · 最近实际收盘日期”。投资起点前 MUST 隐藏金额与日期。推进阶段 MUST 不显示收益金额或收益率。结尾 MUST 冻结完整曲线与坐标，并与最后推进帧保持相同的金额与日期，期间静止且不淡入。金额 MUST 使用中文数量级并以“元”结尾，数字与单位之间无空格、无千分位。正收益 MUST 为红色 `#FF5A4E`，负收益 MUST 为绿色 `#4BD39A`，持平 MUST 为中性暖白 `#D8D4CC`，市值与曲线同色。绘图区 MUST 为 x=200～920、y=500～1280。纵轴 MUST 只显示 3 个刻度（底、中、顶），字号 24px，右对齐于 x=188，数量级单位 MUST 只在轴顶标注一次，刻度小数位 MUST 按间距决定且不得重复。网格 MUST 只保留 3 条约 9% 透明度的横线，MUST NOT 绘制竖网格或坐标轴线。横轴 MUST 只显示已到达的年份，字号 28px。底部说明 MUST 位于横轴之下，统计口径字号不大于 24px，风险提示不大于 22px。背景 MUST 使用近黑 `#0A0A0B` 径向渐变并叠加极细噪点。标题、金额、图表、端点与底部说明 MUST 作为统一内容组垂直居中于画布 y=960，越界或内容超高 MUST 阻断。统一项目布局边界 MUST 仍为 x=140～940、y=180～1740。核心内容 MUST 通过 360×640 手机缩放检查，纵轴刻度实际高度 MUST NOT 低于约 7px。

#### Scenario: 顶部编辑式层级
- **WHEN** 查看任意推进帧
- **THEN** 顶部只有左对齐投资标题与右对齐 hero 金额，没有独立大年份；金额下方一行小字显示当前市值与日期

#### Scenario: 金额档位与颜色
- **WHEN** 当前市值位数变化或收益为正、负、零
- **THEN** 金额在 72/64/56 档位间切换且不逐帧抖动；正收益红、负收益绿、持平中性暖白，曲线同色

#### Scenario: 去轴化后的可读性
- **WHEN** 在 360×640 缩放下检查
- **THEN** 3 个纵轴刻度、单位、横轴年份与底部说明均可辨，纵轴刻度不低于约 7px

#### Scenario: 结尾冻结
- **WHEN** 进入结尾
- **THEN** 曲线、金额与日期冻结，端点呼吸停止，画面静止且不淡入

#### Scenario: 安全区与居中
- **WHEN** 逐帧检查画面
- **THEN** 标题、金额、图表、端点与说明位于 x=140～940、y=180～1740，整体包围盒垂直中心对齐 y=960，越界时阻断

### Requirement: 左侧绘图区空间与折线视觉重量

金融时间序列画面的绘图区 MUST 为 x=200～920、y=500～1280。所有文字 MUST 位于 x=140～940、y=180～1740 的统一布局边界。纵轴刻度 MUST 使用 22px 字号并右对齐于 x=188，超宽标签 MUST 在保持字号的情况下水平压缩。投资价值 MUST 以主曲线与日线双层呈现：主曲线 MUST 按月取真实收盘点并用单调插值连接，线宽 3px；日线 MUST 保留全部真实交易日并以 2px、0.26 透明度绘制。端点半径 MUST 为 7px，外侧增加 14px 同心外环；外环与端点的组合不得越过布局边界。该留白为项目保守默认值，不声明为抖音官方规范。

#### Scenario: 绘图区与端点
- **WHEN** 渲染任意推进帧
- **THEN** 绘图区为 x=200～920、y=500～1280，端点在绘图区右缘内完整显示

#### Scenario: 双层曲线
- **WHEN** 曲线显示已揭示的投资价值
- **THEN** 平滑主曲线与全量日线同时可见，主曲线末点与顶部金额对应同一真实收盘日

### Requirement: 趋势材质、本金基准与背景氛围

主曲线 MUST 叠加低透明度外描边形成光晕，MUST NOT 绘制面积填充，避免被误读为收益或回撤区域。端点 MUST 在实心圆外增加 14px 同心外环，并在当前收盘位置绘制一条淡竖向参考线。本金落在当前纵轴范围内时，MUST 绘制一条虚线基准线并在右侧空间允许时以 20px 小字标注“本金”；距离绘图区底部过近时只保留虚线；该线 MUST NOT 显示收益金额、收益率或额外数字。背景 MUST 使用近黑径向渐变并叠加极细噪点，网格、日线、主曲线和端点 MUST 按由弱到强的明度分层。推进阶段端点 MAY 做轻微呼吸；结尾冻结段 MUST NOT 移动。背景光晕位置 MAY 随帧缓慢移动。以上元素 MUST 位于绘图区裁剪或布局边界之内，并参与既有裁剪与安全区探针。

#### Scenario: 端点与光晕
- **WHEN** 查看推进帧
- **THEN** 端点为 7px 亮点与 14px 外环，背景光晕位置随进度轻微变化，网格不压过主曲线

#### Scenario: 无面积填充
- **WHEN** 查看任意帧
- **THEN** 曲线与基线之间没有填充色块，不被误读为收益或回撤面积

#### Scenario: 结尾呼吸停止
- **WHEN** 进入结尾冻结段
- **THEN** 端点停止呼吸，画面保持静止

#### Scenario: 本金基准
- **WHEN** 纵轴范围包含投资本金
- **THEN** 显示淡虚线基准线，空间允许时显示小字“本金”，不显示收益金额或收益率

#### Scenario: 历史完整性
- **WHEN** 逐帧检查完整候选
- **THEN** 日线历史包围盒位于有效裁剪范围内，端点绘制在曲线之上
