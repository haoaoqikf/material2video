## Context

参见 proposal.md。现行策略由 src/m2v/production/policy.py 与 workflow.py 派生，最新规格已明确不固定候选数量、G5 内部检查、核心风险前置独立观察和 G6 当前候选终审。

## Goals / Non-Goals

消除同一当前契约内的相反要求；保留方法、强制证据及风险升级。不恢复旧流程，不重做视频或补写历史评审，不改变运行时行为。

## Decisions

- 以最新已归档决策和当前实现核定预期；旧条款不得通过更严格措辞重新增加门槛。
- 区分通用选案与 repeated-failure 的至少两个实质不同候选，后者保持不变。
- 全片时间标注帧序列、风险加密与实际查看继续必需；qa 等检查工具不是编码前置条件，也不是取证的唯一入口。
- G5 记录内部观察；独立隔离和身份凭据只要求于适用核心轮及 G6。
- 无旁白屏幕字幕按其单行上限；有旁白共享字幕按现有字幕契约，不能套用屏幕字幕限制。
- 教学示例允许已登记自有样片的选题与机制重写，不允许直接复制外部媒体或整段实现；普通作品仍须重新设计。
- 主规格仅用完整 MODIFIED requirement 块修订，过时标题用 RENAMED 明确记录，保留其余场景及历史作品专属约定。

## Risks / Trade-offs

- 误删证据要求 → 保留高密度采样与覆盖不足不通过；只消除命令唯一性。
- 将历史要求误当矛盾 → 核对适用范围，保留复利和 traffic-jam-wave 等专属契约。
- 文档检查无法证明语义一致 → 另留冲突核对表与六类场景人工复核，不添加措辞黑名单测试。

## Migration Plan

仅更新后续阅读的当前文档；验证并提交实施结果后同步主规格，再归档与提交。无需迁移作品材料。
