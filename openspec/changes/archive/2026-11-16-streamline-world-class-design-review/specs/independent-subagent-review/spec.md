## ADDED Requirements

### Requirement: 世界级风格开放品质与明确采用
关键帧正式评审 MUST 按所选风格的世界级创意、整体形象、构图注意力、排版色彩、实现细节、风格一致性及实际标杆差距判断，MUST NOT 强制苹果或其他固定品牌风格。工具 MUST 要求每个观察项及整体给出明确采用结论；仅 pass 可采用，fail 与 insufficient 均不可采用，不用排名、平均分或“基本达到”放行。评审 MUST 写出具体位置、显示条件、实际现象、目标和阻断影响；通过可保留非阻断打磨建议，偏好不得冒充缺陷。工具校验一致性，不自动认证审美。

#### Scenario: 证据不足
- **WHEN** 关键帧表现或代表性证据不足
- **THEN** 系统 MUST 明确不可采用及缺证范围，补证后再评审。

#### Scenario: 其他风格达到高水准
- **WHEN** 手绘、纪实或极繁作品达到其所选标杆的实际品质
- **THEN** 评审 MUST 按该风格判断，不因缺少苹果式材质、留白或字体否决。

### Requirement: 总代理实际审查与选案责任
总代理 MUST 送审前查看并初筛实际媒体，核对独立观察覆盖、美术判断及真实目标对照，明确采用／修复／淘汰和依据，交付前确认当前媒体与有效报告一致。只有可读、无遮挡、技术正常的报告 MUST NOT 作为高品质美术通过。独立 pass 不免除已知问题；实质争议按原目标复核，不挑宽松评审，不单方关闭独立失败。决定 MUST 写入既有设计和唯一问题记录，不增加审批或平行台账。

#### Scenario: 报告只核对技术
- **WHEN** 报告判 pass 却没有实际美术表现及参考差距观察
- **THEN** 总代理 MUST 补足真实独立观察，不据此采用或交付。

## MODIFIED Requirements

### Requirement: 媒体范围独立评审
试制与终审 MUST 使用独立新上下文，终审者不得参与该作品前期试制。关键帧和终审 MUST 先盲看落盘后对照；关键片段默认使用独立过程对照，不要求例行盲审。核心表达依赖悬念、错觉、连续变形或剪辑反转时可登记具体依据执行过程盲审。媒体、时间窗、显示条件与实际限制 MUST 绑定当前周期。按明确风险支持分工终审、争议复核及匿名比较；自审 MUST 显著披露且不得关闭独立项。试制选案 SHALL 复用既有 trial 的盲看与同轮对照，评审不得接收作者推荐、解释或制作成本作为品质依据。评审 SHALL 在现有 observations 中分别说明具体吸引力、普通之处、与目标的主要差距及继续打磨或作为后续标准的依据，允许全部淘汰，不强制选赢家、不以总分或投票替代观察。主代理 MUST 依据原目标负责选案与下一试验，不能将独立 pass 等同阶段完成；实质争议按原目标复核，不反复换评审者挑选宽松结果。

#### Scenario: 独立失败复查
- **WHEN** 执行本场景
- **THEN** 失败 MUST 登记必改，只有当前对应范围、同类观察的有效独立通过才可关闭；改目标、重渲染或技术通过不得代替。

#### Scenario: 候选都不足
- **WHEN** 独立观察没有发现足以继续的候选
- **THEN** 评审 MUST 可以明确全部淘汰并给出具体依据，不因提供了多个方案而被迫选优；助手据此调整表达或构图。

#### Scenario: 推荐打磨与正式展开分离
- **WHEN** 某方案有吸引力但仍有整体品质差距或关键实现未知
- **THEN** 评审 MUST 明确当前不通过，并可推荐继续打磨而不支持展开；作者安排相应试验，结论沿既有报告和设计记录保存，不新增轮次、审批或机器 verdict。

#### Scenario: 正式候选与比较参照
- **WHEN** 正式 trial 需要同时比较备选或历史画面
- **THEN** 待验证范围 MUST 放入 items 并全部受失败闭环约束；只作比较的媒体放 references 且说明用途，在对照时展示，不得称其已独立盲看通过，也不得以此解除已导入失败。

#### Scenario: 按需探索性匿名观察
- **WHEN** 方向分歧需要独立同时观察全部早期候选
- **THEN** 助手 SHALL 隔离保存盲看和随后对照的真实探索观察，不冒充正式导入通过、不授权展开；后续正式基线验证使用未看过目标与探索结论的新上下文，保留具体缺陷与额外观察成本，不将此活动变成例行新门禁。

### Requirement: 交付样品验证当前原生实现
设计样品的独立评审 MUST 观察由同一原生场景采集的静帧及适用完整过程，关键帧先盲看再同轮实际目标对照，动态用途完整过程另行独立目标对照；纯静态样品无需视频。AI概念图或外部媒体可以用于参考、比较和内部探索，但其pass MUST NOT 转换为原生样品通过。代表性 MUST 按当前单张或局部窗口中主体、字体、材质光影及合成是否实际完成判断，其他镜头、全片与声音未覆盖写入限制，不擅自扩张或缩小当前范围。技术来源检查不进入视觉盲包。

#### Scenario: 静态代表性范围
- **WHEN** 评审单张实际网页静帧或适用局部样片
- **THEN** 评审 MUST 判断本范围的实际完成度，不以缺少全片否定静态，也不以静态通过覆盖尚未验证的核心运动。

#### Scenario: 失败后继续复查
- **WHEN** 当前样品未通过或证据不足
- **THEN** 助手 MUST 按原目标和适用范围持续修订，保留失败及真实调用，不挑选宽松评审或用探索观察关闭独立项。
