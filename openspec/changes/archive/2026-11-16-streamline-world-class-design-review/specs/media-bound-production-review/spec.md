## ADDED Requirements

### Requirement: 评审机械操作自动派生
工具 MUST 从封存隔离包生成绑定版本、用途、窗口、路径、摘要和未完成观察项的报告模板与任务说明。模板 MUST 默认不可采用，不预填 pass 或伪造调用。工具 MUST 从有效当前盲报告自动派生同轮对照，保持原媒体、来源、参考、条件与范围，拒绝目标、帧率、显示尺寸或采样步长漂移；相同媒体 MUST 独立复制既有净化证据并逐文件核验摘要，不重复编码或取帧，也不共享可写文件。评审者、实际读取文件、时间与观察 MUST 来自真实执行。

#### Scenario: 自动对照
- **WHEN** 操作者提供当前盲报告 ID 请求同轮对照
- **THEN** 工具 MUST 自动复用封存请求创建净化目标包，不要求手工复制 JSON。

#### Scenario: 空白模板
- **WHEN** 生成结构化报告模板
- **THEN** 模板 MUST 不包含通过结论，未完成真实调用与观察前不能导入为独立通过。

## MODIFIED Requirements

### Requirement: 独立媒体契约与显式周期
系统 MUST 提供 review start/pack/import/timeline、自动派生对照与结构化报告模板，拒绝旧检查点合同和旧报告；周期、请求、报告、包 MUST 使用 v3；请求 MUST 指定 keyframe/process/final 用途，旧历史保留不迁移且不能授权当前通过；当前周期有开放必改或损坏历史 MUST 拒绝重开，不以是否存在原生采集为条件。历史升级 MUST 核对工作流与原周期身份，不接受篡改或未知版本。关键帧只接受图片，过程只接受视频，终审使用当前完整候选。过程默认直接独立目标对照；例外盲审 MUST 提供具体风险依据。试制包 MUST 不依赖 DESIGN.md、prepared 或全片分镜；本地媒体、来源依赖和观察窗口须摘要绑定。全片播放器 MUST 使用有效准备材料且无视觉门前置。

#### Scenario: 局部试制
- **WHEN** 只有代表性关键帧或核心片段
- **THEN** 可以建立隔离试制包；修改相关依赖使其过期，无关场景不无故使其过期。

### Requirement: 目标参考与可观察特征配套对照
评审请求提供非空 references 时 MUST 同时提供非空 conditions 描述中性可观察目标；缺失或空目标条件 MUST 在创建评审包之前明确拒绝。目标媒体与条件 MUST 在盲包外摘要绑定，在关键帧／终审盲看导入后的同轮对照包中才展示；过程直接对照包 MUST 提供实际参考及中性条件，MUST NOT 伪造盲报告身份；中性条件无参考媒体时仍允许用于事实和表达核对。独立对照 MUST 观察实际目标效果与差距，理解、可读性或技术无错不能替代表现与代表性判断。工具只校验材料与记录完整性，不自动评判风格研究、审美或阶段完成。

#### Scenario: 只有参考媒体
- **WHEN** 请求带有参考媒体但缺少或清空中性采用特征
- **THEN** 请求 MUST 明确失败且不创建媒体包，不把任何图片当成没有范围的默认审美标准。

#### Scenario: 有参考的同轮对照
- **WHEN** 请求同时提供目标媒体和中性采用特征
- **THEN** 盲包 MUST 不泄露目标或特征，对照包 MUST 包含实际净化目标媒体和原条件，并要求观察兑现情况及具体差距。

#### Scenario: 事实条件没有风格参考
- **WHEN** 请求只有中性事实条件而没有参考媒体
- **THEN** 仍可进行同轮事实对照，但助手不得据此声称已验证未提供的风格目标。

#### Scenario: 盲看后追加目标
- **WHEN** 对照请求向原本未登记参考的盲看请求追加目标媒体
- **THEN** 工具 MUST 拒绝绑定不同的同轮对照，助手需重新建立适用盲看与对照，不修改旧包或旧报告。
