## Context

动机见 [proposal.md](proposal.md)。现有复利作品位于 `videos/compound-interest-leverage/`，十幕均为场景树；运行时已有 beat、镜头段、连续对象和代码场景接入。作品目录被 Git 忽略，规范当前将代码场景限定为原语无法表达的个别幕。本设计改变制作选择与动态评审，不重建动画引擎。

## Goals / Non-Goals

**Goals:** 实现可见的图形推理、不同幕的节奏变化、首尾母题延续；以真实播放证明效果，并保持声音和画面同步。

**Non-Goals:** 不升级 schema，不构建批量模板库、可视化动画编辑器或素材生成服务，不修改旧版分镜拒绝策略。

## Decisions

### 1. 优先作品级 SVG/React 编排

核心图形幕用现有 renderer.code，简单文字幕保留场景树。相比继续堆叠通用入场配方，作品级路径和对象组织能直接表达内容；相比先扩展原语库，能更快验证用户选择的定制质量。共享辅助函数仅在实现需要且有明确调用时引入，不预建新框架。

分镜 data 保存文案与数值；动作脚本放在作品目录的 `motion-design.md`，引用场景和 beat，不复制完整口播。组件读取 beats.plan 的解析区间，以纯函数计算预备、执行、反馈与停顿；不按整幕 progress 均匀切分口播动作。保留至少现有 12 帧稳定窗口，按阅读需要延长；样片评审决定是否调整时长。

### 2. 先验证三幕，再完成十幕

首先实现 profit、referral、curve，覆盖回流、分支、曲线揭示。样片使用最终渲染链路，采用已有配音准备结果；若文本或时长变化，重新准备媒体并复核实际 beat。五项动态评分均至少 4 分后扩展全片。评分由人工或视觉模型根据播放材料给出，并写明证据；机检不推断审美。

| 场景 | 主动作与构图 |
| --- | --- |
| opening | 小单元进入示意放大结构，建立视觉悬念 |
| pages | 十页成组、重复堆积，拉远揭示全年规模 |
| profit | 收益产生、回流、并入本金，下一轮从扩大后的本金出发 |
| referral | 单客户扩展为分支，新客户继续产生关系，局部到整体 |
| attempts | 尝试留下经验单元，逐步组成判断结构，不绘制虚构成功概率 |
| curve | 先观察前期小变化，再推进和拉远揭示后期差距 |
| burst | 一次投入停止与持续投入推进对照，明确示意条件 |
| gold | 汇总已有小单元为增长核心，显示积累可参与下一轮 |
| thousand | 压缩重复轮次为时间序列，拉开距离后停顿 |
| closing | 回到开场对象与结构，收束并留出阅读时间 |

统一圆角小单元、强调色与线条语言，根据段落变化为书页、利润、客户或经验。避免每幕复用同一入场次序。镜头只用于交接焦点或揭示规模；代码内对象运动和外层镜头不重复承担相同位移。跨幕共享元素必须提供现有几何探针并显式映射，无法满足时使用有意切换，不宣称无缝连续。

### 3. 动态评审接入现有发布结论

用现有渲染命令产生三段样片和最终整片，不新增独立播放器或生成接口。将逐幕五项评分与证据作为 `review.md` 的必填动态评审章节；评审结果解析与 publishable 判定增加对应检查。为避免改变全部旧作品的发布规则，通过该章节明确声明启用定制动态评审；动作脚本和制作规范要求定制作品必须声明。缺章、缺评分的定制流程必须记录待评审，不能作为完成交付。

沿用现有机检字段，不把主观评分写成 A 系列运动事实。评审报告区分“未评审”“未达标”和“通过”。用匿名合成记录验证评分解析和发布阻断，不把文章内容写进测试。

### 4. 保留基线与内容边界

改写前把原分镜、基线成片、字幕、媒体清单及溯源文件复制到作品 outputs 下独立 baseline 目录，升级材料使用独立输出名，禁止覆盖基线。文字论点不增强：删除“唯一杠杆”等原文不支持的绝对化说法；无来源数值与增长模型明确示意，不制造收益率或成功概率。

作品动作脚本、TSX 和产物均留在忽略目录。共享规范、评审代码及合成测试入库；如需可运行契约示例，在 examples 中补充最小合成场景，不复制文章。实施后更新 README 当前事实和相关 Skill 参考文档；本次 propose 不更新这些实现说明。

## Risks / Trade-offs

- [Risk] 定制提高制作与维护成本 → 把计算限制为局部纯函数，固定依赖；本轮以作品质量优先，不承诺全自动批量化。
- [Risk] 自定义画面绕开既有观感或同步检查 → 保留探针，覆盖真实配音边界与随机寻帧；静音动态评审补充语义检查。
- [Risk] 动作丰富但妨碍阅读 → 主动作优先，辅助动作错峰；检查收尾、安全区和字幕遮挡。
- [Risk] 示意图被理解为事实数据 → 数据来源核对与示意标记同时纳入逐幕验收。
- [Risk] 源码静态检查或探针限制妨碍定制 → 在三幕样片阶段解决具体问题；仅修改必要共享接缝，保持公共接口不变。

## Migration Plan

先保留作品基线并修订制作与动态评审规则，再验证三幕样片，最后完成十幕和完整有声渲染。共享修改通过相关测试和文档一致性检查后提交；作品文件不强制加入 Git。验收失败保留基线和返工记录，不标记完成、不归档。实施任务全部完成且验证与提交通过后，再按项目约定同步主规格、归档并提交归档结果。
