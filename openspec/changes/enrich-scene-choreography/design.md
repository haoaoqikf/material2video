## Context

动机见proposal。现有单份DESIGN、帧驱动事件源及G4/G5/G6可承载整场细节；运行时已有路径形变、关键值、光轨、局部粒子、整屏Impact与图标路径能力。现状主要是设计覆盖和风格限制，不需要新运行时或分镜字段。

## Goals / Non-Goals

**Goals:** 将文字、图标、点缀与主体放进同一事件编排，并用当前片段验证表现提升；按叙事选择硬切和释放密度。

**Non-Goals:** 不新增固定效果配额、审美自动打分或审核轮次，不给所有字幕逐字加碰撞，不改tokens格式或通用采集接口。

## Decisions

1. 多层编排方法维护在motion-design中文适配，流程参考只维护记录与证据，模板引用同一小节。保留单份事件参数源，避免增加独立效果表。
2. dark-proof GUIDE取消固定硬切与整屏释放次数，增加文字/图标触发及强弱变化方法。保留当前组件preset、色板与运行时；指纹正常变化，不通过改算法规避旧准备失效。
3. 沿用独立盲看后中性条件对照，在既有轮次比较当前同用途片段、用户参考和基线；先检查理解，再单列丰富度、重复与节拍。机器继续检查导航、风格身份及确定性，不按“丰富”关键词判审美。
4. 规范示例仅补写现有R5的取舍与适用边界，不虚构翻转图标或重制通过。新效果首先在当前作品6–8秒核心试制中实现，通过后原位扩展。
5. 内部成熟能力优先复用；图标使用现有登记路径/图标方案，翻转以纯帧几何实现，粒子与光轨沿SDK。若内部不足再检索外部方案，不引入自走时间线。

## Risks / Trade-offs

- [取消次数限制后光效堆叠] → 逐拍记录强弱、源点、落定与阅读，完整动态检查焦点竞争。
- [所有句子重复同一敲击] → 设计敲击、翻正、牵引等有语义差异的方式，G5检查相邻配方重复。
- [指南变化使旧示例准备过期] → 明确指纹失效，重新准备并验证相关场景构建；不把旧媒体写成新版验收。
- [新增设计记录过重] → 普通场景简写，复杂时序才展开；不另建参数文件。

## Migration Plan

同步方法、阶段入口/模板、风格GUIDE、README、规范示例和主规格；相关文档与风格测试通过后提交，自动归档。当前作品保留旧成片与源码，启用新制作周期并重新prepare、试制、评审和生成候选；旧报告只作历史。
