## MODIFIED Requirements

### Requirement: 最小设计记录与持续反馈
RESEARCH.md MUST 保存研究证据、解释、应用推断及方向比较；DESIGN.md MUST 引用研究并保存全片共同目标、采用范围、选案理由、实际视觉基线和场景索引；详细编排与本场验证办法 MUST 放在对应场景文档。设计不含机器检查点合同。候选优劣与足以展开 MUST 分别判断，三种人读结论沿现有观察与设计保留，不新增机器状态。三阶段 MUST 允许设计、实现、观察往返，不先写满全片细节锁定首稿。正式展开 MUST 核对新内容和完整作品的目标兑现；有效结论在成为后续标准或评审依据前回写。每轮 MUST 聚焦主要差距，用前后实际媒体检查收益；问题沿唯一记录闭环。事实、来源、许可与用户硬约束 MUST 保留。

#### Scenario: 全片设计与制作
- **WHEN** 展开完整设计或逐段制作
- **THEN** 助手 MUST 先组织全片骨架并优先深化关键未知场景，随试制细化其他场景；预演和粗片为内部活动，检查结构、衔接及风格迁移，一个样片不授权未覆盖机制，材料变化后重新准备，局部修复先查看再汇总全片。

#### Scenario: 局部修订复用
- **WHEN** 只修改局部文字或数据且表达与视觉目标未变
- **THEN** 助手 MUST 复用有效研究和基线，只更新受影响场景及必要共同设计；新缺口补查，不重开无关选案或补造旧记录。

#### Scenario: 最佳候选仍有关键差距
- **WHEN** 相对最好候选的整体品质或实现证据不足
- **THEN** 助手 MUST 只安排主要差距的打磨或验证，不能凭排名或独立 pass 展开；均无潜力时允许全部淘汰。

#### Scenario: 无收益或资源边界
- **WHEN** 同一问题两轮修复无改善，或遇到被动中断和外部阻塞
- **THEN** 助手 MUST 换实质路线继续，或保留未完成说明阻塞；不得设置主动总上限、交付未通过样品，或把记录与重复评审当成通过。

### Requirement: 视听五维与可量测预期
RESEARCH.md MUST 记录五维研究依据与假设；DESIGN.md MUST 确定全片视觉、表达、动态、声音、转场共同语言，场景文档 MUST 具体落实注意力、主体/辅助对象、动作配合、镜头、材质光影、文字、声音及衔接。只有静帧时 MUST 标明推导依据、置信度与验证办法。适用关键目标 MUST 有对应观察窗口与可验证预期；量测按机制选择，可包含状态切换、静止窗口、转场、主体区域和声画同步等，不强制所有场景填写全部指标。静止、无声和 cut 可明确采用，不设逐场动作/特效配额。评审 MUST 依据帧序列、完整解码和适用信号量测核对，不要求播放或试听；适用关键证据缺失记 insufficient，未达目标记 fail，指标通过不代替整体品质。

#### Scenario: 只有静态参考
- **WHEN** 设计只有静态参考图
- **THEN** 助手 MUST 将必要的表达、运动、声音和转场推导标为假设，按实际采用机制用过程验证；不冒充外部观察，不省略必要设计。

#### Scenario: 场景没有可量测预期
- **WHEN** 关键采用效果没有可验证预期或证据
- **THEN** 助手 MUST 保持该效果未验证，允许内部试制解决未知，但不能作为正式有效基线或通过；不适用的运动、声音或转场指标不阻断静态或无声设计。

#### Scenario: 只有帧与信号证据
- **WHEN** 评审只能读取帧序列与信号量测
- **THEN** 评审 MUST 按适用目标引用帧号、窗口和量测结果，不因缺播放器自动不足，也不扩写为无法量测的主观听感。
