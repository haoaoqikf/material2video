

## MODIFIED Requirements

### Requirement: 抽象表达按实际信息职责评审
助手与独立评审 MUST 按完整画面的实际信息职责判断抽象意象和精确事实，允许形体、空间、运动与清晰辅助文字/读数协作。抽象主体 MUST NOT 被默认要求逐层字形可读或逐物具象可辨。必要职责分配 MUST 在既有设计与对照条件中说明并核对用户原要求；作者声明 MUST NOT 替代实际表达或事后解除原有精确信息职责。不新增运行时角色字段或审核轮次；影响判断的对象职责归场景设计，中性必要条件归既有对照。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 抽象意象配清晰读数
- **WHEN** 主体以抽象形体或叠层表达关系与风格，独立读数使关键金额、单位、组别和结论清楚，整体形象成立
- **THEN** 评审 MUST NOT 仅因抽象局部难逐字辨认而 fail；可见的次要读取代价 MUST 作为打磨限制，不以具象信息图的逐字标准强制返工。

#### Scenario: 抽象声明不能掩盖关键缺陷
- **WHEN** 唯一必要读数被遮挡、表达造成关键误读或因果不明、核心形象失效或偏离用户选定整体风格
- **THEN** 评审 MUST 根据具体窗口、显示条件及实际影响阻断，不因抽象标签或辅助文字存在而自动通过。

#### Scenario: 用户放宽已失败的抽象目标
- **WHEN** 用户明确允许适当放宽抽象载体的局部辨认要求
- **THEN** 助手 MUST 沿既有 retarget 登记真实指令及受影响失败，保留旧结论，并在登记后重新独立盲看及同轮对照；不得复用旧通过自动关闭，不免除事实、QA及全片验收。


### Requirement: 当前候选与完整证据

终审 MUST 绑定当前有效完整候选和技术 QA。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列、帧差/场景切分与适用主体区域量测；声音 MUST 有响度、真峰值、静音、起音、频谱与同步等信号量测；不要求播放或试听。评审结论 MUST 引用具体帧号、时间窗和量测值；适用运动、转场或声音目标的关键指标/证据缺失 MUST 记 insufficient，不达预期 MUST 记 fail。静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。trial 完整观察等价复用仅允许旧来源文件当前内容不同，不得忽略封存请求、原来源摘要记录、包 manifest、全部包内观察媒体与参考、条件、报告、调用及账本身份的完整性；任何封存证据缺失或改写 MUST 拒绝。复用授权当前媒体的视觉结论，不恢复旧技术绑定的有效性。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 终审候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得直接授权新片；无关试制证据按实际依赖保留。trial 可通过完整观察等价收据另行授权当前有效采集，终审仍须当前完整候选实际独立观察。

#### Scenario: 历史封存损坏
- **WHEN** 旧来源当前内容改变但封存身份完整，或封存请求、报告、包内文件任一损坏
- **THEN** 前者可继续核验显式 trial 复用，其当前技术绑定仍失效；后者 MUST 拒绝复用，不以旧来源变化为由跳过历史完整性验证。

#### Scenario: 帧与信号评审
- **WHEN** 当前候选只有有序帧、完整解码和音频信号量测可供评审
- **THEN** 评审 MUST 据此核对状态切换、转场、静止窗口、主体量测与声音事件，按设计指标给出结论；MUST NOT 因缺少播放或试听把该范围判为未验证。
