## MODIFIED Requirements

### Requirement: 逐帧录制及复用
系统 MUST 等待字体、组件及显式资源就绪后录制；超时、外网请求或运行异常 MUST 失败且不保存有效准备。录制 MUST 按顺序在第 n/fps 秒完成动画更新和绘制后逐帧采集，截图与磁盘等待 MUST NOT 推进动画；系统 MUST 同步上下文、动画库、三维绘制、CSS 动画和本地视频。录制 MUST 标准化为实际画幅、精确帧数、作品实际30或60 fps 的无声视频，并恢复落盘目录继承权限。缓存 MUST 绑定源码、资源、参数、时间窗、依赖、实现、实际帧率、画幅、字幕安全区配置及素材导入映射和摘要。完整预演及正式导出 MUST 复用同一已验收片段，不在导出执行作品代码；自由动画不承诺逐像素复现。

#### Scenario: 输入变化
- **WHEN** 仅改变画幅、安全区配置、登记媒体内容或作品帧率
- **THEN** 旧缓存及准备失效，帧率变化时按新帧率重新录制

#### Scenario: 两种帧率的场景缓存隔离
- **WHEN** 相同代码、帧预算与素材分别按30 fps和60 fps录制
- **THEN** 相同时间点画面保持相同，片长保持相同，帧数按帧率变化，缓存互不复用

#### Scenario: 运行失败
- **WHEN** 代码异常、请求外网或未及时 ready
- **THEN** prepare 失败且不发布有效准备记录

#### Scenario: 正式导出
- **WHEN** 输入完全一致且片段完整，或当前准备和预演有效后正式导出
- **THEN** 复用相同片段，不重新录制，片段可按目录继承权限直接打开

#### Scenario: 片段可直接打开
- **WHEN** 录制片段从临时目录落盘
- **THEN** 恢复目标目录继承权限，用户可直接播放

#### Scenario: 采集变慢
- **WHEN** 截图或磁盘写入延迟
- **THEN** 下一帧仍对应下一固定时间点，不跳过运动状态或补重复帧

#### Scenario: 精确采集
- **WHEN** 顺序录制 N 帧并编码
- **THEN** 采集和解码均为 N 帧，缺帧或推进异常明确失败，不发布缓存；旧实时缓存不能复用
