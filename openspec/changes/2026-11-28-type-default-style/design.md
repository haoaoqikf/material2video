## 背景

现有类型目录集中维护三类身份，作品已持有独立材料和准备指纹。现有评审支持盲审封存、同轮对照、显式改靶和当前候选的摘要绑定。类型默认风格通过这些入口固定外部参考和观察条件。[参考清单与取舍](research.md)

## 1. 默认值和数据形状

类型目录记录三个默认参考集的 `id`、`revision` 和清单来源。已发布修订保持不可变，更新发布新的修订。初始化按选定类型将完整清单复制到作品内，通过受控路径 `design/style-binding.json` 保存绑定。该文件按自己的 `schemaVersion` 演进，保存 `projectId`、`type`、`visualStyle`、`referenceDigest` 和 `overrides`。其中 `visualStyle` 只承载 `{id, revision, references[], snapshot?}`。默认引用的 `id` 和 `revision` 与随作品固化的目录记录一致。目录后续更新仅用于新工程，既有作品继续使用固化清单。

每条 `references[]` 记录 `id`、`role`（整体／专项／规范）、`url`、`scope`、`observed`、`evidence` 和 `accessedAt`。证据定位到成片、官方文档章节、截图或视频时间窗。可保存的媒体或文档快照以 `snapshot` 登记本地相对路径及 `sha256`，按参考 ID 关联。类型发布时记录网址实际探测结果，证据地址与原页分开记录。正式证据只需要覆盖条目所声明的观察用途。

`referenceDigest` 为 `visualStyle` 的规范化 JSON 摘要，使用 UTF-8、固定对象键顺序及标准紧凑编码，保留清单顺序。摘要覆盖参考条目、用途、证据定位及所登记的快照摘要。工具同时核验引用的文件字节，拒绝绝对路径、越界路径及符号链接逃逸。随工程保存的目录修订和摘要用于离线核对默认来源，整份绑定文件的字节摘要进入准备指纹。

`visualStyle` 当前不渲染。画面取值继续由作品本地代码、共享令牌和场景编排提供。现有令牌作用域与字体恢复契约继续适用。

## 2. 显式覆盖和基准

授权应明确指定目标参考、已有参考集或对具名且说明范围的提议表示同意。覆盖记录放在绑定文件的 `overrides[]`，每条保存以下信息。

- `target` 为同形参考集，附独立 `referenceDigest`。可采纳已发布参考或将用户指定原页整理为可复核条目。仅授权某项表达机制时，在该用途采用对应参考，其余用途和整体目标继续按默认集。
- `scope` 声明全片或既有场景 ID 集合，并声明整体替换或受影响的参考用途。未限定范围的整体指令适用于全片。全片与逐场覆盖互斥，逐场集合互不重叠。跨场窗口观察两端与接续。
- `authorization` 登记用户原话、带时区的授权时间及可复查来源。程序检查必填项、来源引用及范围。总代理核对授权原件与转化的对应关系。

一般打磨沿用已绑定目标。镜头方案不适合题材时，在生效风格内调整构图、载体或动作。DESIGN.md 引用已登记的覆盖授权及其原件，记录本片采用范围，无需再抄原话。有已绑定评审的目标经用户授权发生变化时，沿现有 `m2v review retarget --file` 保留原范围、历史结论和授权，重建当前对照绑定。盲审包隔离参考、授权与作者理由。封存后，同一评审者获得生效参考集、实际参考证据与中性观察条件。

## 3. 机器检查与独立评审

| 入口 | 核验内容 |
| --- | --- |
| 初始化、校验、准备 | 绑定必填及完整，项目身份、修订及本地摘要一致，覆盖有明确授权且范围有效，旧材料及无效绑定明确拒绝 |
| 参考取证、对照包生成 | 核对公开网址可达或同一证据可由本地快照取得，快照按字节核验摘要，记录缺口和受影响用途 |
| 正式评审导入与完成状态 | 核对当前候选、目标修订、参考集摘要、实际参考证据摘要及授权范围一致，沿用既有评审与技术 QA 的完成条件 |

渲染、预演与离线本地校验无需实时访问外站。取证阶段仅网页可开、实际参考或观察条件缺失时，受影响评审项保持 `insufficient`。本地快照失效时可从同一来源恢复并复核摘要。只有用户明确授权才能更改已绑定目标。

独立评审在适用的目标对照中，以整体标杆判断视觉语言、信息组织和制作完成度，以专项判断所登记机制的实际效果，以官方规范理解图表语义或可读性工艺。按各帧职责、实际观看尺寸及适用的过程窗口核验。没有可机检的审美阈值，数值合规不存在，因此评审不得以缺参数为由放行。已有实证表明核心职责受损时记 `fail`，缺少参考媒体或可观察条件时记 `insufficient`。两者均阻断正式完成。

## 4. 运行、评审与版本边界

保留 `project.json` v3、`storyboard.json` v9、目录结构及准备记录 v3。初始化和当前校验通过固定路径发现独立版本化绑定。准备在现有输入摘要映射登记绑定文件，消费端要求该条目存在且当前字节一致，旧准备即使版本号相同也须重新生成。当前评审请求和包沿用既有版本，当前风格结论必须绑定生效目标修订、清单摘要、实际对照证据及候选身份。试制阶段可用作品绑定和已登记的试制范围建立对照，无需等待正式准备。历史准备及评审可按原口径查看。首次补绑前已有实物参考的失败项，在当前独立复查中保留原参考、条件、尺寸及窗口，并一并核验新增默认参考。旧项目身份、旧风格字段、旧材料版本、缺失或旧版绑定，以及漏绑的当前完成证据明确拒绝。正式导入复用本地绑定校验，素材登记照旧。

### 备选及取舍

| 备选 | 取舍 |
| --- | --- |
| 只在 Skill 或 DESIGN.md 记风格名称 | 作品起步、用户授权和评审无法核对是否使用同一修订 |
| 每次执行实时读取类型目录和网站 | 目录或网页变化会改写既有目标，作品在脱库环境无法复核 |
| 把绑定嵌入项目清单并升级 v4 | 已有输入摘要映射可绑定独立文件。升级会额外改动独立消费者、导入与存量清单 |
| 由程序评判视觉相似程度 | 题材、画幅及叙事职责不同。独立对照可以说明具体借鉴机制及完成差距 |

## 5. 一次性迁移

- 先复查默认参考、可恢复证据及本地绑定，再逐部盘点编辑源、交付记录、已有授权和可复核的代表性证据。本轮本地盘点见 [research.md](research.md)。
- 三个固定示例分别核对。复利复核读数层级、共享基线及柱到结果的讲解接续，保留数学口径、原克隆音色和双语字幕。竖屏市值榜复核标记、读数和交接在实际观看与平台叠加条件下的表现，保留排名口径及静音契约。太阳系复核全景与近景的空间锚点、关系和标签职责，保留题材及科学口径。图文用独立初始化检查默认绑定。
- 现役作品以现有画面为起点，逐部追加绑定、重新准备及补齐适用的参考、关键帧、过程和整片证据。已有画面达到目标时，直接进入当前轮次复核，有实际差距再调整。只有确认现役且可编辑的作品进入本轮切换。历史、重复、缺源及外部内容根待清册核实。
- 工时以登记与复核为固定项，视觉修订按各片发现的差距分档。本次盘点确定三部固定示例和五部现役作品，其中一部现役作品仅为已有局部试制，按其试制范围复核。十一部旧契约作品和一部历史工具验证仅登记。示例迁移的读数、图表交接或空间锚点直接纳入同一当前候选的适用评审窗口；一次独立观察可同时支撑题材要求与脱库验收。现有证据充分的工程成本主要在补绑定、重新准备与评审，需改构图或动作的工程另计制作与复查。缺少逐部观察前，无法估算需要重做的场景数。确需替换成片时，按既有交付验证和旧基线清理流程办理。
