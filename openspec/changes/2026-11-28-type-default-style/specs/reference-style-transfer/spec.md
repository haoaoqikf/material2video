## REMOVED Requirements

### Requirement: 参考分析按用户需求记录采用范围

**Reason**: 现行规则授权助手自主选择整体标杆，和按类型固定默认的要求冲突。
**Migration**: 使用「生效风格与专项参考的分析」记录固定整体依据及专项用途。

### Requirement: 关键参考目标沿既有风险与证据契约验证

**Reason**: 现行场景允许助手自主融合风格，且整体基准缺少固定来源。
**Migration**: 使用「生效整体与专项参考的证据验证」执行风险判定、盲审、对照与问题复查。

## ADDED Requirements

### Requirement: 生效风格与专项参考的分析

创作或实质性视听修订 MUST 从生效风格的固定整体参考出发，区分整体品质、专项表现和信息表达参考。研究 MUST 按要理解的内容及表达难点选择专项证据，记录来源、用途和时间范围。动态结论 MUST 有覆盖实际变化的有序帧、时间轴或适用信号，无需播放观看或试听。按实际问题拆解构图、排版、色彩、图形空间及适用材质、光影、运动和声音。实际观察、效果解释、本片推断和限制 MUST 分开记录。静帧或局部材料只承载所覆盖的结论，过程推断 MUST 写明依据、置信度和验证办法。研究保存于 RESEARCH.md，总设计引用研究并记录共同语言、采用范围与实际基线，场景记录适用参考、关键状态和验证预期。可引用既有研究附件，不设固定候选数、采用数或采样数。

#### Scenario: 只借配色与构图
- **WHEN** 用户明确只指定配色与构图参考
- **THEN** 在用户明确的维度和空间范围采用该参考，其他规则与固定整体品质目标继续按生效规范执行。

#### Scenario: 只有静帧
- **WHEN** 参考只提供静帧
- **THEN** 记录可见处理。必要的过程推断保留为待验证假设。

#### Scenario: 读取类型固定标杆
- **WHEN** 用户未明确覆盖风格或整体参考
- **THEN** 助手 MUST 使用对应类型固定的整体参考，只围绕具体专项寻找补充证据。专项 MUST NOT 改变风格族、放宽目标或替换整体标杆。

#### Scenario: 五维按实际问题展开
- **WHEN** 只采用部分视听特征或有意静止、无声、硬切
- **THEN** 深入实际采用、承诺或影响判断的部分，未验证过程保留为未验证。

#### Scenario: 视频可查看
- **WHEN** 借鉴可取得视频的动作、镜头或节奏
- **THEN** 取得覆盖关键变化的实际窗口，将具体处理、表达作用及待验证状态写入本片方案。

#### Scenario: 来源无法访问
- **WHEN** 仅有不可访问页面、缩略图或二手摘要
- **THEN** 优先查同一固定案例的创作者原页或官方发布。专项可用等证据补齐。固定整体参考仍缺证据时登记缺口，不用摘要代替过程观察，也不自行改靶。

### Requirement: 生效整体与专项参考的证据验证

用户明确指定、类型默认以及已承诺的专项参考 SHALL 写入适用风险和中性可观察条件。适用盲审先封存再同轮对照，作者理由不得进入盲包。对照 MUST 提供实际参考及采用范围，区分整体品质、专项表现与信息表达。整体目标持续生效，局部特征拆解不缩窄整体验收。量测、并排图及动态窗口按原问题选择，沿现有关键帧及风险过程策略。技术通过、相对旧版改善和纯偏好均不代替目标验证。关键失败保留原目标与证据，只有用户明确授权的变更可按既有改靶流程重建适用证据。

#### Scenario: 关键采用项失败
- **WHEN** 候选未兑现生效的核心视觉或表达目标
- **THEN** 记录具体差距并按原范围复查，不能靠只修读数或弱化目标关闭。

#### Scenario: 默认框架内有专项参考
- **WHEN** 场景借鉴其他来源的物体机制、镜头或素材
- **THEN** 同轮对照仍以生效的固定整体参考判断风格和完成度，专项材料只证明登记的用途。

#### Scenario: 对照缺少目标媒体
- **WHEN** 已绑定风格目标且对照缺少实际参考
- **THEN** 保留未验证。普通静态通过不授权风格目标通过。

#### Scenario: 局部特征齐全而整体普通
- **WHEN** 局部形状、颜色、光影符合规则而整体焦点、组织或完成度明显不足
- **THEN** 指出实质差距，保留阻断，依据本片表达判断整体完成度。
