## ADDED Requirements

### Requirement: 生效风格与专项参考的分析

创作或实质性视听修订 MUST 从生效参考集出发。整体标杆提供视觉语言与完成度，专项解决具体表达难点，官方规范提供语义和工艺依据。研究 MUST 按观众要理解的内容及表达难点选取观察项，记录来源、筛选依据、用途及证据定位，并说明可借鉴的处理和表达作用。动态结论 MUST 有覆盖实际变化的有序帧、时间轴或适用信号。实际观察、作用解释、本片推断和适用边界 MUST 各自有据。静态证据上的过程推断须标为待验证，记录依据、置信度和可验证现象。研究保存于 RESEARCH.md，总设计引用研究并记录采用范围与基线，场景记录具体落点、关键状态与验证预期。

#### Scenario: 默认框架内补充专项

- **WHEN** 用户未明确覆盖整体风格，而场景需要补充物体机制、排版节奏或镜头证据
- **THEN** 按场景问题登记专项用途，整体目标仍由生效参考集确定。

#### Scenario: 用户限定参考用途

- **WHEN** 用户明确只指定参考的某个用途及适用范围
- **THEN** 在该范围对照对应机制，其他用途与整体目标沿用默认参考。

#### Scenario: 只有静帧

- **WHEN** 参考只提供静帧
- **THEN** 记录可见处理，必要的过程推断保留为待验证假设。

#### Scenario: 来源无法访问

- **WHEN** 生效参考的网址不可访问或可用内容只剩二手摘要
- **THEN** 优先恢复同一来源的有效本地快照或原始证据，记录剩余缺口。缺少可观察证据的项保持 `insufficient`。

### Requirement: 生效整体与专项参考的证据验证

用户明确指定、类型默认及已承诺的专项参考 SHALL 纳入适用风险和中性可观察条件。适用盲审先封存，再按生效修订向同一评审者提供实际证据与采用范围。整体标杆用于判断完成度，专项证据用于核对所登记的机制，官方规范用于理解语义与工艺。关键帧和适用过程按现有风险策略取证。适用阶段的技术通过、相对旧版改善和纯偏好均不能取代生效目标的实际对照。关键失败保留原目标与证据，只有明确授权可按既有改靶流程重建受影响证据。

#### Scenario: 缺少同轮证据

- **WHEN** 对照缺少实际参考媒体或所需观察条件
- **THEN** 受影响项保持 `insufficient`，补证后重新评审。

#### Scenario: 机制成立而整体不足

- **WHEN** 专项机制已成立，整体焦点、阅读组织或工艺仍有实质差距
- **THEN** 按整体标杆记录差距和阻断影响，保留未通过状态。

#### Scenario: 关键采用项失败

- **WHEN** 候选未兑现生效参考所规定范围内的核心表达目标
- **THEN** 记录具体差距与可复查条件，按原目标复查。
