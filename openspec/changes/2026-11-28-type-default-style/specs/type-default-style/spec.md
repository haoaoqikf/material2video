## Purpose

为三类作品固定可复核的视觉参考，让创作者和独立评审者共同使用已登记的观察依据。作品能在目录更新后复现原目标，也能追溯用户明示的变更。

## ADDED Requirements

### Requirement: 类型指定唯一默认风格

系统 MUST 为每个当前类型发布恰好一个带修订号的参考集。每组 MUST 包含真实成片或官方演示作为整体标杆、用于具体机制的专项参考，以及提供语义和工艺依据的官方规范。条目 MUST 记录 `id`、`role`、`url`、`scope`、`observed`、`evidence` 和 `accessedAt`，并登记发布时的探测结果。具备快照时 MUST 登记本地定位和 SHA-256。官方规范用于解释语义和工艺。

| 类型 | 默认参考集 | 风格 |
| --- | --- | --- |
| `text-motion` | `ibm-2x-kinetic-type@1` | IBM 2x Grid Kinetic Typography |
| `data-evolution` | `apple-keynote-presentation@1` | Apple Keynote Presentation Style |
| `spatial-3d` | `nasa-svs-scientific-visualization@1` | NASA SVS Scientific Visualization |

初始化 MUST 在作品本地版本化绑定文件固化默认参考集及清单摘要。`visualStyle` MUST 只承载 `{id, revision, references[], snapshot?}`。目录发布新修订 MUST NOT 静默改变已有工程的视觉目标。助手 MUST 使用生效参考集判定整体方向，并可围绕实际机制补充专项证据。

#### Scenario: 按类型初始化

- **WHEN** 初始化任一当前类型且无已登记的用户覆盖
- **THEN** 工程固化该类型的默认参考集及摘要，`m2v types` 可查看其映射，工程脱库后仍可核对同一绑定。

#### Scenario: 目录发布新修订

- **WHEN** 类型目录新增默认参考修订
- **THEN** 后续初始化使用新修订，已初始化工程继续使用原清单及摘要。

### Requirement: 用户显式覆盖及有效范围

覆盖 MUST 有用户明确指定或对具名提议的确认，保存原话、来源、带时区时间、目标参考集及其摘要、全片或已有场景 ID 范围，以及受影响的参考用途。未限定范围的整体指定适用于全片。没有明确授权、范围重叠、场景不存在或目标摘要不符时 MUST 拒绝该覆盖。授权范围外继续使用默认参考。

#### Scenario: 有效单场覆盖

- **WHEN** 用户明确指定某一场景只采用另一参考的揭示机制且相关证据有效
- **THEN** 该场按授权对照这一机制，整体品质和其他用途继续使用默认依据，跨场窗口核对两端职责与接续。

#### Scenario: 模糊意见或失败后换目标

- **WHEN** 用户只要求更精致，或候选尚未达到当前目标
- **THEN** 保持原目标。用户明确授权变化后，按既有改靶契约保留历史并对受影响范围重新验证。

### Requirement: 参考真实性与实际对照门禁

工程及验收入口 MUST 检查必填绑定和条目完整性、参考公开可达或有效本地快照、快照及清单摘要、覆盖授权和范围、当前候选与评审目标修订绑定的一致性。旧材料、旧绑定契约及缺绑的当前证据 MUST 被拒绝作为当前输入。参考可达性在取证阶段核验。本地预演可先生成候选，外部参考不可达且无有效快照时记录适用缺口。

视觉结论 MUST 来自适用的独立盲审及同轮实际参考对照。对照提供生效参考清单、实际证据、参考用途及可观察条件，用整体标杆判断完成度，用专项参考核对实际机制。没有可机检的审美阈值，数值合规不存在，因此评审不得以缺参数为由放行。

#### Scenario: 缺少可观察证据

- **WHEN** 网页不可达且无有效快照，或同轮对照缺少实际参考媒体或必要的观察条件
- **THEN** 受影响项保持 `insufficient`，记录缺口，阻断正式完成，且不得自行替换整体目标。

#### Scenario: 绑定证据完整而画面存在实质差距

- **WHEN** 机器检查通过但独立评审发现焦点、机制、阅读或工艺有实质差距
- **THEN** 评审按原目标记录画面位置、观察条件和阻断影响，作品不得报告正式完成。

#### Scenario: 视觉证据过期

- **WHEN** 生效参考修订、清单摘要、证据摘要、授权范围或候选来源变化
- **THEN** 旧报告保留原结论及适用范围，当前验收须重新取得匹配的实际证据。
