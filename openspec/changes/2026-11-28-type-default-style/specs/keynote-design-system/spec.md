## MODIFIED Requirements

### Requirement: 设计令牌是画面取值的唯一真源

作品 MUST 使用本地单一来源保存实际取值。三类 v9 场景的构图、排版、底色和运动由作品本地代码实现。Apple Keynote Presentation Style 默认参考集提供演示语言、图表语义与制作工艺的判断依据。参考绑定用于研究和评审，当前不渲染，也不生成主题或令牌。

仍被本地场景消费的共享字体、颜色、间距、形状和图形令牌 MUST 由作品内单一 `@theme static` 层提供，使用 `var(--m2v-*)` 或 `var(--fig-*)` 读取。场景固有图稿坐标可留在本地场景，字幕几何由本地运行、合成与检查复用画幅定义。仍有消费者的基础令牌 MUST 保留。系统 MUST NOT 使用 `themes.json`、`palette.ts` 主题解析或按 `data-m2v-preset`、`data-m2v-theme`、`data-m2v-style-pack` 属性变换作用域。

#### Scenario: 令牌是唯一真源

- **WHEN** 修改当前消费中的本地共享令牌
- **THEN** 引用画面同步变化。

#### Scenario: 两类取值同名但不等

- **WHEN** 为横屏或竖屏提供字幕显示区域
- **THEN** 本地运行时、合成层与检查取得同一几何与排版定义。

#### Scenario: 新增图形颜色令牌必须归类

- **WHEN** 本地场景新增共享图形颜色令牌
- **THEN** 记录令牌的图形语义和实际用途，供场景使用与复核。

#### Scenario: 新增主题

- **WHEN** 工程收到用户授权并登记了单场或全片覆盖
- **THEN** 创作者按实际使用范围在本地实现，独立评审依据已登记的参考及观察条件核验效果。运行时不加载参考作为主题。

#### Scenario: 按主题变化的取值

- **WHEN** 旧材料声明 `visual.theme`，或作用域依赖已禁用的属性
- **THEN** 拒绝该声明，不加载旧主题。
