## MODIFIED Requirements

### Requirement: 设计令牌是画面取值的唯一真源

作品 MUST 使用本地单一来源保存实际设计参数，不依赖主项目令牌、主题或字体。三类 v9 场景的实际构图、排版、底色和运动由本地代码实现，受 v4 作品生效风格的约束。风格规范约束实际取值与证据，不作为渲染时主题选择器。仍被来源场景消费的字体、颜色、字阶、间距、形状和图形令牌 MUST 保持本地单一 `@theme static` 层，并用 `var(--m2v-*)` 或 `var(--fig-*)` 读取。作品共享参数集中一次，场景固有图稿坐标可留在该场。

系统 MUST NOT 使用 `themes.json`、`palette.ts` 主题解析或按 `data-m2v-preset`、`data-m2v-theme`、`data-m2v-style-pack` 等属性切换令牌作用域。应用取值 MUST 无条件可解析。作品字幕几何按画幅集中提供，运行、合成与检查使用同一数据。仍有消费者的基础令牌 MUST 保留。

#### Scenario: 令牌是唯一真源
- **WHEN** 修改仍被金融使用的来源场景本地共享令牌
- **THEN** 引用画面同步变化，无需逐场修改。

#### Scenario: 两类取值同名但不等
- **WHEN** 为横屏或竖屏提供字幕安全区
- **THEN** 本地运行时、合成与检查取得相同矩形及排版，正文同名尺寸不充当字幕别名。

#### Scenario: 新增图形颜色令牌必须归类
- **WHEN** 新增共享图形颜色令牌
- **THEN** 按现有对比度分类规则验证来源场景。

#### Scenario: 新增主题
- **WHEN** 工程收到用户授权并登记了单场或全片覆盖
- **THEN** 修改对应本地作品参数与代码并检验预期效果，不生成属性切换作用域。

#### Scenario: 按主题变化的取值
- **WHEN** 旧材料声明 `visual.theme`，或作用域依赖被禁用属性
- **THEN** 拒绝该声明，不加载旧主题。
