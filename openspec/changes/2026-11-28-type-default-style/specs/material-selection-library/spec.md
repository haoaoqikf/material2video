## MODIFIED Requirements

### Requirement: 既有导入衔接与作品内复制

选中素材进入作品 MUST 先以独立文件复制到目标作品内受控暂存区，再生成并通过现有 `import` 清单及校验登记，不得让作品运行时直接读取共享库绝对路径、链接或未登记候选。正式导入使用当前 project v4 和分镜 v9。媒体登记 schema、单文件与批次限制沿用既有契约，风格授权和规范绑定 MUST 独立于导入记录。导入 MUST 与目标作品既有写操作互斥，并复核来源、采用状态、摘要及实测信息；只有权利人明确禁止当前用途或现有契约规定的技术无效 MUST 按既有行为阻断，不新增授权前置。

#### Scenario: 从共享素材库导入选中片段
- **WHEN** 选中媒体原本位于作品外的显式素材库
- **THEN** 片段被复制到目标作品内并经现有导入登记，正式记录不包含运行时共享库依赖，也不要求导入功能新增项目或媒体字段

#### Scenario: 选中片段仍超过正式导入限制
- **WHEN** 源长视频允许获取但最终片段仍超过现有正式导入大小限制
- **THEN** 系统明确要求重新选段或编码，或报告限制失败，不悄悄放宽正式限制
