## MODIFIED Requirements

### Requirement: 既有导入衔接与作品内复制

选中素材进入作品 MUST 先以独立文件复制到目标作品内受控暂存区，再生成并通过现有 `import` 清单及校验登记，不得让作品运行时直接读取共享库绝对路径、链接或未登记候选。正式导入使用当前 project v3 与分镜 v9，并复用当前工程的参考绑定校验。媒体登记格式、单文件及批次限制沿用既有契约。参考绑定和风格授权随作品独立保存。导入 MUST 与目标作品既有写操作互斥，并复核来源、采用状态、摘要及实测信息，按既有规则阻断权利人明确禁止的用途或技术无效输入。

#### Scenario: 从共享素材库导入选中片段

- **WHEN** 选中媒体位于目标作品外的显式素材库，且目标作品的参考绑定有效
- **THEN** 片段被复制到目标作品内并经现有登记导入，登记沿用现有格式，运行时从作品内读取。

#### Scenario: 选中片段仍超过正式导入限制

- **WHEN** 源长视频允许获取但最终片段仍超过现有正式导入限制
- **THEN** 明确要求重新选段或编码，或报告限制失败。

#### Scenario: 目标作品参考绑定缺失

- **WHEN** 目标作品未补齐当前制作契约所需的参考绑定
- **THEN** 正式导入报告缺项，保留原素材候选和目标作品的既有登记。
