## Context

见 proposal.md。1321 个用例中有 373 个媒体、64 个慢测；路径选择绕过成本过滤，CI 目前执行全部非 slow 用例。pytest 已有严格标记，无需额外依赖或新调度框架。

## Goals / Non-Goals

**Goals:** 减少真实构建与重复断言；日常定向快测争取 30 秒内，CI 快层争取 1–2 分钟（目标而非既有实测）。

**Non-Goals:** 不移除关键失败保护，不重新实现媒体校验器，不改视频契约，不用全量回归验收本轮。

## Decisions

- 文件/目录仍过滤；通过 pytest 已解析的节点参数匹配具体 item，支持参数化节点与混合选择，避免简单“出现 :: 就全放开”。使用原生 pytest 选择机制，不新增调度依赖。
- 文档固定句子、已删除文件、风格 token 副本直接删除；链接、路由、同步生成、字体许可、恢复与指纹由共享测试负责。
- general 真实成片保留 none/narration；none 合并 jobs=2 分段断言。effect 音频由音效媒体测试负责，完整渲染缓存由 single_pass_delivery 负责。
- 按实际媒体调用拆混合模块标记；可复用的媒体夹具在同一模块一次生成后复制，避免每个解析测试建文件。
- 只删已证实不可达的 rough 独立审核路径；保留 rounds 的 rough=0 公共统计与历史记录读取。
- CI 普通事件使用默认层，正式发布由人工在依赖、字体已准备好的环境中执行全量（字体登记未提供直接下载地址，CI 不新增不可用的自动恢复步骤）。规则置于 AGENTS，README 提供操作入口，规格定义行为。

## Risks / Trade-offs

- 删除断言可能遗漏独特行为 → 用 coverage-map.md 记录删留对应，独立审查检查覆盖空洞。
- 移动标记可能把真实编解码带入快层 → 静态调用核查和针对性默认选择验证。
- 没有执行全集 → 记录相关验证与未覆盖范围，遵守已授权的全量限制。

## Migration Plan

先建立删留清单，实施选择器与清理，同步文档和 CI，执行定向验证并独立审查；实现提交后同步主规格归档并提交。回退可直接还原本次提交。
