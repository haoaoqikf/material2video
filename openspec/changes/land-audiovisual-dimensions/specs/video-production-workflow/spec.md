## ADDED Requirements

### Requirement: 视听五维与可量测预期

RESEARCH.md MUST 对视觉风格、表达模式、动态风格、音效风格与转场风格分别记录采用、自创或明确不用；参考只有静帧时 MUST 从静帧的构图、材质、光影、尺度与层次推导其余四维，并标注假设、置信度与验证指标。DESIGN.md MUST 在逐场组织中写明时间节拍、镜头/运动、入出转场、声音事件及可量测预期，可量测预期至少覆盖状态切换帧、最长无变化窗口、非 cut 转场帧数与类型、匹配剪辑的主体位置/颜色容差、声音事件与起音容差、响度/真峰值/静音段。没有可量测预期的场景 MUST 视为未设计。评审 MUST 按帧序列、解码与帧差/场景切分、主体区域量测和音频信号量测核对实际兑现，不要求播放或试听；缺指标 MUST 记 insufficient，指标不达设计预期 MUST 记 fail。

#### Scenario: 只有静态参考
- **WHEN** 研究与设计只有静态参考图
- **THEN** 助手 MUST 完成五维推导并写入 RESEARCH.md，标明依据、假设、置信度与验证指标，再用过程样片核对；不能因为不能播放参考而跳过运动、声音与转场设计。

#### Scenario: 场景没有可量测预期
- **WHEN** DESIGN.md 的某场没有状态帧、静止上限、转场或声音事件的可量测描述
- **THEN** 该场 MUST 被视为未完成设计，不得进入正式制作或终审。

#### Scenario: 只有帧与信号证据
- **WHEN** 评审只能读取帧序列、帧差/切分和音频信号量测
- **THEN** 评审 MUST 按设计声明的指标给出 pass/fail/insufficient，并引用具体帧号、时间窗与量测值；不得把缺少播放或试听能力作为自动 insufficient，也不得扩写为主观观感结论。
