## ADDED Requirements

### Requirement: 全片内部检查以帧与信号为证据

全片内部检查 MUST 使用已有场景片段、缓存或有序窗口覆盖全片，并按帧差/场景切分、主体区域量测和音频信号核对状态切换、转场、声音事件、静止窗口与设计声明的可量测预期。检查 MUST NOT 要求播放、试看或试听，MUST NOT 因缺少播放能力把运动、转场或声音记为未验证；缺失指标 MUST 记 insufficient，不达预期 MUST 记 fail。检查结论 MUST 引用具体帧号、时间窗和量测值。

#### Scenario: 缓存片段与帧序列
- **WHEN** 场景片段已录制并缓存
- **THEN** 全片内部检查 MUST 复用缓存抽取有序帧与音频信号，核对转场、声音事件和可量测预期，不额外触发全片渲染或要求播放。

#### Scenario: 指标不足
- **WHEN** 某场的状态切换、转场或声音事件缺少可量测证据
- **THEN** 该项 MUST 记 insufficient 并指出缺少的窗口和指标，不能以“已查看过”概括。
