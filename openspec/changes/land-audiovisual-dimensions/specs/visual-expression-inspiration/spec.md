## MODIFIED Requirements

### Requirement: 视觉与表达参考必读且采用自选（当前媒体流程）

项目 MUST 提供顶级视觉创意与设计指导，强调探索、审美判断、具体视觉决策及实际效果验证；风格与五组灵感列表可自由采用、融合、自创或跳出，列表名称仅作为探索入口。创作或实质性视听修订前 MUST 完整阅读，同一任务无需重读；自主风格同样须围绕具体作品深入研究、转化和实际验证。研究 MUST 足以支撑当前试验，未知触发补查，不等待所有研究完成才试制。参考只有静帧时，MUST 从静帧的构图、材质、光影、尺度与层次推导表达模式、动态风格、音效风格和转场方向，标明为假设、置信度与验证指标；不得把推导写成已观察事实。评审 MUST 以有序帧、解码校验、帧差/场景切分、主体区域量测与音频信号量测为证据，不要求播放或试听。不得设对风格列表的符合性门禁、候选数量、样片时长或审美评分，不降低事实、许可和用户硬约束；已选视觉目标须按实际参考对照验证。

#### Scenario: 自由创作并及时试制
- **WHEN** 当前关键前提已有依据
- **THEN** 可以局部设计和实际试制，并用真实画面选择、修订或淘汰方向，研究不足的问题继续补查；不能仅用暗底、强调色或大字体代替目标效果的深入研究。

#### Scenario: 只有静态参考
- **WHEN** 研究与设计只有一张或一组静态参考图
- **THEN** 助手 MUST 完成表达模式、动态风格、音效风格和转场方向的推导，标注假设、置信度与验证指标，并用过程样片的帧序列与音频信号量测核对；不能以“未观看”替代设计，也不能把推导写成已观察事实。

#### Scenario: 五维决策
- **WHEN** 形成完整设计或实质性视听修订
- **THEN** 研究与设计 MUST 对视觉风格、表达模式、动态风格、音效风格、转场风格分别记录采用、自创或明确不用；不要求选用列表项，但不得没有决策记录。
