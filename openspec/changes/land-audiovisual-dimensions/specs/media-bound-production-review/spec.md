## MODIFIED Requirements

### Requirement: 当前候选与完整证据

终审 MUST 绑定当前有效完整候选和技术 QA。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列、帧差/场景切分与适用主体区域量测；声音 MUST 有响度、真峰值、静音、起音、频谱与同步等信号量测；不要求播放或试听。评审结论 MUST 引用具体帧号、时间窗和量测值；设计声明的运动、转场或声音指标缺失 MUST 记 insufficient，不达预期 MUST 记 fail。静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。trial 完整观察等价复用仅允许旧来源文件当前内容不同，不得忽略封存请求、原来源摘要记录、包 manifest、全部包内观察媒体与参考、条件、报告、调用及账本身份的完整性；任何封存证据缺失或改写 MUST 拒绝。复用授权当前媒体的视觉结论，不恢复旧技术绑定的有效性。

#### Scenario: 终审候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得直接授权新片；无关试制证据按实际依赖保留。trial 可通过完整观察等价收据另行授权当前有效采集，终审仍须当前完整候选实际独立观察。

#### Scenario: 历史封存损坏
- **WHEN** 旧来源当前内容改变但封存身份完整，或封存请求、报告、包内文件任一损坏
- **THEN** 前者可继续核验显式 trial 复用，其当前技术绑定仍失效；后者 MUST 拒绝复用，不以旧来源变化为由跳过历史完整性验证。

#### Scenario: 帧与信号评审
- **WHEN** 当前候选只有有序帧、完整解码和音频信号量测可供评审
- **THEN** 评审 MUST 据此核对状态切换、转场、静止窗口、主体量测与声音事件，按设计指标给出结论；MUST NOT 因缺少播放或试听把该范围判为未验证。
