## Context

当前金融 composition 使用固定 18px 平移，安全区为 x=140～940、y=180～1500。底部说明内容会换行，因此固定坐标不能反映整个实际内容组的视觉中心。

## Goals / Non-Goals

**Goals:** 按浏览器实测的前景整体包围盒，将内容中心对齐安全区中心 y=840；前端检查应用变换后的整体、文字和端点边界；更新英伟达成片。

**Non-Goals:** 不以整张 1920px 画布中心作为锚点；不改变安全区、字号、画布、背景、数据或投资计算。

## Decisions

- 使用 SVG 前景 `<g>` 的 `getBBox()` 量取文字和图形的实际联合范围，计算 `offsetY = 840 - (bounds.y + bounds.height / 2)`；clip 区和前景组使用同一偏移。
- 按变换矩阵再次量测完整包围盒并检查安全区；内容超高或任何元素越界时硬失败，不压缩字号、不裁切。
- 布局在浏览器完成首次绘制测量后设置确定性变换；内容结构和来源换行变化时重新测量。评审记录报告安全区与“safe-area-center”对齐策略，不再记录固定位移数值。

## Risks / Trade-offs

- [初次绘制发生状态更新] → 在同步 layout effect 内完成测量和变换，再检查边界；完整预演验证没有首帧闪动。
- [风险说明行数改变中心] → 这是按真实内容包围盒居中的预期行为；手机评审复核首帧、长来源及终幕。

## Migration Plan

更新布局与评审元数据后，重新 prepare、生成完整 preview、查看手机缩放和遮挡叠层、更新评审并重新渲染英伟达视频。既有成片不自动更新。
