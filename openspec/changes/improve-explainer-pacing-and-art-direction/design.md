## Context

见 [提案](proposal.md)。现有太阳系 targetSeconds 为 64，内行星镜头约 4.7 秒、冰巨星约 4.9 秒，单个镜头承担多个主体与移动。DESIGN 声称全片平滑连接，而分镜备注仍含硬切描述；实施时须以运行行为和当前成片为依据消除矛盾。本次未实际播放视频，用户体验反馈是问题依据，分镜只支持预算层面的判断。

## Goals / Non-Goals

目标：让观众知道眼前是什么、看清它，再自然前往下一个对象；让审美成为设计和复核的一部分。
边界：不增加新的示例、平台、视频类型或用户审批阶段；不以慢放旧片完成返工，不默认升级全项目分镜版本。

## Decisions

### 1. 太阳系按约 135 秒编排

建议预算如下，总计 135 秒，实际 TTS 和样片复核后在 120–150 秒范围内调整：

| 段落 | 秒数 |
|---|---:|
| 开场与太阳 | 12 |
| 水星、金星 | 16 |
| 地球、月球 | 17 |
| 火星、小行星带 | 13 |
| 木星 | 12 |
| 土星 | 14 |
| 天王星、海王星 | 18 |
| 冥王星与柯伊伯带 | 12 |
| 日球层、奥尔特云与收束 | 21 |

普通单体初始预算 7–9 秒，重点 10–14 秒；根据对象认知难度调整，不把全局最低时长硬编码为通用审美标准。镜头基本节拍为入场定位 → 短介绍 → 无旁白观察 → 离场。转场计入上表，不额外无上限叠加。日球层与奥尔特云必须区分。

只拉长原文案仍会造成信息堆叠；只删文案而保持短镜头仍无法看清，因此同时降低信息密度、增加视觉时间。

### 2. 用具体印象形成导览口吻

文案先写身份，再选一个看得见的印象；以带路人的语气串联。示意语气稿：开场“如果从地球出发，一路向外，我们会遇见怎样的世界？”；地球“这一颗，你一定认识。蓝色的地球，是我们的家。”；土星“土星到了。先别急着走，看看它展开的光环。”这些仅是语气示例，最终事实、原文语义和画面主张仍须核验。信息卡只保留名称及短提示，不和字幕重复铺满。

### 3. 美术方向先比较，再统一

比较“深空旅行纪录片”与“明亮天文图鉴”，本片采用前者，定位为“安静而壮阔的深空旅行”：深色背景、自然天体色、克制侧逆光、少量暖色导航。先明确受众、希望传达的情绪与视觉重点，再围绕主体大小、留白、明暗层级、材质和标注做选择。先制作开场、核心、结尾三张代表画面，逐张检查构图、主体大小、留白、光影、材质、色彩及文字层级，形成后续全片对照基准。standard 使用轻量方向比较与关键构图；cinematic 使用完整参考板、关键帧与动态样片。地球、土星、外层空间承担不同视觉高潮，中间保留安静画面。后期效果逐项说明用途，不强行全部加强；以手机尺寸也能辨认主体为底线。

### 4. 先解决两段连续旅程，再铺全片

制作“水星→金星→地球”与“木星→土星”的代表性动态样片，覆盖普通主体切换和重点镜头。20–30 秒仍是 cinematic 样片指导长度，必要时分段。检查减速、到达、停留、离场与注意力分配，避免运镜、字幕和标签同时争抢主体；连续运镜在可读时使用，跨尺度过远时允许有方向依据的剪辑或尺度示意。位置、朝向、FOV 和速度分别核查。

### 5. 全片审美修订与独立完成判断

扩展全片后单独执行审美修订：删减重复运动、调整效果强度与镜头长短、安排视觉高潮和安静段落、统一色彩及文字。每个问题记录时间码、版本、修改和复查依据；文案、节奏、连续性、审美、声音与技术分别记录结论，技术通过不自动关闭其他维度的问题。同一问题连续两轮无改善时更换构图、素材或实现方法，不继续盲调参数。以当前版本证据关闭必改项后自主交付，不增加用户确认或 CLI 人工门禁。

### 6. 流程与实现落点

新顺序：受众与目标 → 信息取舍和导览文案 → 两个美术方向比较 → 逐镜头时间预算与音乐段落表 → 关键画面 → 含实际配音与音乐的连续性样片 → TTS 实测及声音时间表回填 → 扩展全片 → 全片审美修订 → 文案、节奏、连续性、审美、声音与技术分别复核 → 交付。

先验证 v8 既有 leadInFrames、tailFrames、readingHoldFrames、无旁白时长与 shot 时间映射的实际作用，选用可明确表达逐主体留白的编排方式。修复太阳系硬编码标签切换帧，绑定当前语义时间窗。若契约不足，先更新本变更规划，再实施当前唯一契约并同步校验器与三个示例；尚未渲染字段明确标注。共享制作指导落在 Skill，README 只在功能实施后更新当前能力。

### 7. 声音设计与音乐可感知性

用户反馈几乎听不到音乐，尚未检查最终音轨，不能预先认定是增益或素材问题。实施先核对音乐来源及许可、是否实际混入、覆盖区间、循环和淡入淡出、增益及旁白压低音乐的幅度与恢复时间，并对照最终成片和独立音乐/旁白轨。检查低频占比、单声道折叠及小扬声器条件下的损失，不能只提高整条音轨响度。

分镜阶段记录声音意图和音乐段落表，包含时间窗、情绪、音乐角色、旁白和观察留白、音量变化及关键音效。太阳系优先采用同一音乐主题的变化：开场与太阳缓慢展开；内行星与地球轻盈温暖；木星与土星层次丰富并形成高潮；外行星疏朗空旷；结尾收束留韵。开场先留几秒让音乐建立气氛，讲话时平缓降低音乐，旁白结束后的观察窗口再平缓抬升，避免明显抽吸或突然跳变。音乐需可感知且不遮蔽介绍，具体增益依据素材和混音结果确定，不把统一固定分贝差当成听感保证。

配音负责介绍、音乐负责情绪、少量环境底声提供空间感、音效只强调重要到达或尺度变化；不为每次转场叠加同一种音效。宇宙环境声作为艺术设计说明。standard 按作品需要采用音乐，不强加 cinematic 多层声音成本；本片沿用 cinematic，执行音乐、环境、音效及混音设计，沿用现行 −14 LUFS / −1 dBTP 目标，不引入新的全局编码标准。

两段代表样片均包含实际配音及音乐，覆盖讲话时的层级、无旁白观察时的音乐展开和重点天体的情绪抬升。TTS 实测后同时回填声音时间表，全片复核音乐覆盖、衔接和结尾。技术检查记录音乐独立轨及混音信号证据，能定位缺失或异常衰减；总混音响度正常不等于音乐存在或听得见。有实际试听条件时分别记录耳机和手机外放结果；无条件时按现有自动音频替代验收继续，明确未验证音乐感染力、配音自然度及设备听感，不虚构试听，不增加用户确认或 CLI 人工门禁。

## Risks / Trade-offs

- 时长与渲染成本增加 → 先做低成本代表片段，保留纹理缓存，正式验收仍采用最终参数。
- 留白变成拖沓 → 留白中保留有目的的缓慢运动，按主体识别与新信息节奏复查。
- 帧序列无法完整还原节奏体验 → 加密轨迹与交界检查，披露覆盖限制，不虚构播放或试听。
- 审美趋于模板化 → 每片比较方向，太阳系风格不强加给其他主题。

## 接口与验收边界

本提案不预设新 CLI、分镜版本或公共字段。时间轴验证至少覆盖配音变长后观察窗口仍保留、相邻对象各有可辨认窗口、镜头连接时视线及速度自然、字幕标签不抢主体、重点特征在介绍期间可见。自动时间覆盖只证明时间对齐，不能代替实际图像复核。

声音验收另覆盖音乐未混入、覆盖不足、讲话段压低后未恢复、淡入淡出突变及手机可感知性限制，排除设计中的安静段落。

最终成片执行完整预演、技术 QA、全片帧序列、交界加密帧及自动音频检查；未连续播放或实际试听时披露节奏体验和听感覆盖限制。所有新复核要求写入 Skill 与参考文档，不增加人工 CLI 门禁。

## Migration Plan

先落制作指导和时间预算验证，再重编太阳系，检查其他两个固定示例的契约一致性。正式片验收前保留旧有效产物；失败不覆盖。实施验证与提交通过后按仓库约定自动同步主规格、归档并提交。

本轮先完成四类规划文件的一致性、相对链接、OpenSpec 严格校验与暂存检查，再单独提交规划修订。此时任务不勾选、不归档；只有后续实施、验证与提交完成后才执行自动归档。
