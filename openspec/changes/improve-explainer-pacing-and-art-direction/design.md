## Context

见 [提案](proposal.md)。现有太阳系 targetSeconds 为 64，内行星镜头约 4.7 秒、冰巨星约 4.9 秒，单个镜头承担多个主体与移动。DESIGN 声称全片平滑连接，而分镜备注仍含硬切描述；实施时须以运行行为和当前成片为依据消除矛盾。本次未实际播放视频，用户体验反馈是问题依据，分镜只支持预算层面的判断。

## Goals / Non-Goals

目标：让观众知道眼前是什么、看清它，再自然前往下一个对象；让审美成为设计和复核的一部分。
边界：不增加新的示例、平台、视频类型或用户审批阶段；不以慢放旧片完成返工，不默认升级全项目分镜版本。

## Decisions

### 1. 太阳系按约 135 秒编排

建议预算如下，总计 135 秒，实际 TTS 和样片复核后在 120–150 秒范围内调整：

| 段落 | 秒数 |
|---|---:|
| 开场与太阳 | 12 |
| 水星、金星 | 16 |
| 地球、月球 | 17 |
| 火星、小行星带 | 13 |
| 木星 | 12 |
| 土星 | 14 |
| 天王星、海王星 | 18 |
| 冥王星与柯伊伯带 | 12 |
| 日球层、奥尔特云与收束 | 21 |

普通单体初始预算 7–9 秒，重点 10–14 秒；根据对象认知难度调整，不把全局最低时长硬编码为通用审美标准。镜头基本节拍为入场定位 → 短介绍 → 无旁白观察 → 离场。转场计入上表，不额外无上限叠加。日球层与奥尔特云必须区分。

只拉长原文案仍会造成信息堆叠；只删文案而保持短镜头仍无法看清，因此同时降低信息密度、增加视觉时间。

### 2. 用具体印象形成导览口吻

文案先写身份，再选一个看得见的印象；以带路人的语气串联。示意语气稿：开场“如果从地球出发，一路向外，我们会遇见怎样的世界？”；地球“这一颗，你一定认识。蓝色的地球，是我们的家。”；土星“土星到了。先别急着走，看看它展开的光环。”这些仅是语气示例，最终事实、原文语义和画面主张仍须核验。信息卡只保留名称及短提示，不和字幕重复铺满。

### 3. 美术方向先比较，再统一

比较“深空旅行纪录片”与“明亮天文图鉴”，建议采用前者：深色背景、自然天体色、克制侧逆光、少量暖色导航。围绕主体大小、留白、明暗层级、材质和标注做选择。地球、土星、外层空间承担不同视觉高潮，中间保留安静画面。后期效果逐项说明用途，不强行全部加强；以手机尺寸也能辨认主体为底线。

### 4. 先解决两段连续旅程，再铺全片

制作“水星→金星→地球”与“木星→土星”的代表性动态样片，覆盖普通主体切换和重点镜头。20–30 秒仍是 cinematic 样片指导长度，必要时分段。检查减速、到达、停留和离场；连续运镜在可读时使用，跨尺度过远时允许有方向依据的剪辑或尺度示意。位置、朝向、FOV 和速度分别核查。

### 5. 流程与实现落点

新顺序：受众与目标 → 信息取舍和导览文案 → 两个美术方向比较 → 逐镜头时间预算 → 关键画面 → 连续性样片 → TTS 实测回填 → 扩展全片 → 技术、文案、审美及连续性分别复核 → 交付。

先验证 v8 既有 leadInFrames、tailFrames、readingHoldFrames、无旁白时长与 shot 时间映射的实际作用，选用可明确表达逐主体留白的编排方式。修复太阳系硬编码标签切换帧，绑定当前语义时间窗。若契约不足，先更新本变更规划，再实施当前唯一契约并同步校验器与三个示例；尚未渲染字段明确标注。共享制作指导落在 Skill，README 只在功能实施后更新当前能力。

## Risks / Trade-offs

- 时长与渲染成本增加 → 先做低成本代表片段，保留纹理缓存，正式验收仍采用最终参数。
- 留白变成拖沓 → 留白中保留有目的的缓慢运动，按主体识别与新信息节奏复查。
- 帧序列无法完整还原节奏体验 → 加密轨迹与交界检查，披露覆盖限制，不虚构播放或试听。
- 审美趋于模板化 → 每片比较方向，太阳系风格不强加给其他主题。

## Migration Plan

先落制作指导和时间预算验证，再重编太阳系，检查其他两个固定示例的契约一致性。正式片验收前保留旧有效产物；失败不覆盖。实施验证与提交通过后按仓库约定自动同步主规格、归档并提交。
