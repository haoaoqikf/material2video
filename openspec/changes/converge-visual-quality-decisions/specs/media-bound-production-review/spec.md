## ADDED Requirements

### Requirement: 采用边界与阻断依据
助手 MUST 在评审条件中明确参考的采用范围，用户选择 MUST 进入作品决策依据。独立评审 MUST 根据实际整体效果及已采用目标判断；fail MUST 指出具体窗口、显示条件、违反目标和阻断影响。无阻断缺陷时，进一步改善 MUST 作为 pass 的 limitations 保留；不能仅因仍可改善、未复制未采用特征或个人偏好而 fail。证据缺失 MUST 保持 insufficient。作者 MUST 明确保留项、必修项和打磨项，不能把独立观察代替选案责任。

#### Scenario: 参考局部特征未采用
- **WHEN** 本片只采用参考的纸质与光照，未采用其品牌色和字形
- **THEN** 评审 MUST 观察实际整体品质，但不能以未复制品牌色或字形单独否决；纸质与光照目标明确失败仍 MUST 阻断。

#### Scenario: 好方案仍有优化空间
- **WHEN** 核心表达、整体美术与已采用目标成立，仅有不影响关键读取的次要层间亮度建议
- **THEN** 评审 MUST 保留具体建议并允许 pass；作者 MUST 记录选用与后续打磨决策，不默认重开风格探索。

#### Scenario: 原失败仍有效
- **WHEN** 历史独立 fail 已导入
- **THEN** 作者 MUST 保留必改状态，不能自行改成建议；真实用户目标变化 MUST 按既有 retarget 登记，再独立复查。

### Requirement: 完整观察相同的视觉结论复用
系统 MUST 允许将历史 trial 独立视觉结论显式绑定到重新验证的当前媒体，同时保留原报告身份、导入与观察时间，不冒充新独立调用。复用 MUST 验证完整源媒体文件字节摘要、全部观察窗口、帧率、显示尺寸、职责、条件及参考均相同，包括视频完整容器及适用音轨；不同编码或容器即使近似相同也 MUST 拒绝。当前采集来源、数据、许可、运行及产物绑定 MUST 单独有效。等价证明 MUST 可追溯并能失效，不能用单帧、缩略图或作者声明替代完整等价。复用 MUST 限于同周期 trial，不转换阶段、不替代当前完整候选由合格新代理实际执行的 final。关闭失败 MUST 使用原报告导入与原调用时间核验晚于原失败及适用 retarget，收据登记时间不得替代。

#### Scenario: 源码变化但观察媒体完全相同
- **WHEN** 当前技术绑定有效，全部观察媒体及目标相同且无未解决的相反结论
- **THEN** 系统 MUST 允许复用原独立视觉结论，重新核验技术证据，原报告本身仍保留原来源绑定。

#### Scenario: 新运动或目标变化
- **WHEN** 任一观察帧、时间、声音覆盖、目标、窗口或显示条件改变
- **THEN** 系统 MUST 拒绝等价复用，要求受影响范围的新独立观察；静态通过不得授权新运动。

#### Scenario: 相同媒体存在相反结论
- **WHEN** 同目标相同媒体已有未解决的独立 pass 与 fail
- **THEN** 系统 MUST 拒绝自动挑选 pass；保留冲突。只有关联 fail 按既有独立关闭规则由晚于失败的新代理实质争议复查关闭，或真实用户变更目标后完成登记及新独立复查关闭，才视为解决；关闭证据失效 MUST 重新阻断，单纯追加 pass 不算解决。

#### Scenario: 收据不能刷新观察时间
- **WHEN** 旧 pass 早于新 fail 或适用 retarget，之后才登记复用收据
- **THEN** 系统 MUST 拒绝用该旧 pass 关闭问题；trial 复用也 MUST 拒绝用于 final。

## MODIFIED Requirements

### Requirement: 当前候选与完整证据
终审 MUST 绑定当前有效完整候选和技术 QA。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列及显示条件；静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。trial 完整观察等价复用仅允许旧来源文件当前内容不同，不得忽略封存请求、原来源摘要记录、包 manifest、全部包内观察媒体与参考、条件、报告、调用及账本身份的完整性；任何封存证据缺失或改写 MUST 拒绝。复用授权当前媒体的视觉结论，不恢复旧技术绑定的有效性。

#### Scenario: 终审候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得直接授权新片；无关试制证据按实际依赖保留。trial 可通过完整观察等价收据另行授权当前有效采集，终审仍须当前完整候选实际独立观察。

#### Scenario: 历史封存损坏
- **WHEN** 旧来源当前内容改变但封存身份完整，或封存请求、报告、包内文件任一损坏
- **THEN** 前者可继续核验显式 trial 复用，其当前技术绑定仍失效；后者 MUST 拒绝复用，不以旧来源变化为由跳过历史完整性验证。
