## MODIFIED Requirements

### Requirement: 实时录制及复用
系统 MUST 等待字体、组件和显式资源就绪后录制，加载超时、外网请求或运行异常 MUST 失败。录制 MUST 标准化为精确时长、30 fps 的无声视频。录制片段 MUST 在落盘后交回所在目录的继承权限，与成片一样可以直接打开。系统 MUST 将源码、资源、参数、时间窗、依赖及实现绑定缓存；完整预演和正式导出 MUST 复用同一片段，MUST NOT 在导出重新执行作品代码。自由动画不保证逐像素复现。

#### Scenario: 输入变化
- **WHEN** 准备后源码、资源或片段变化
- **THEN** 旧准备失效，要求重新准备和完整预演

#### Scenario: 运行失败
- **WHEN** 场景抛错、请求外网或未按时就绪
- **THEN** prepare 失败，不保存有效准备记录

#### Scenario: 正式导出
- **WHEN** 当前准备和完整预演有效
- **THEN** 复用已验收片段完成合成，不重新录制

#### Scenario: 片段可直接打开
- **WHEN** 缓存目录里的录制片段从临时目录落地
- **THEN** 片段继承所在目录权限，用户无需人工修复即可播放
