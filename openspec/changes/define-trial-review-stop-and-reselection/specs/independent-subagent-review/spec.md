## MODIFIED Requirements

### Requirement: 世界级风格开放品质与明确采用

关键帧评审 MUST 先观察实际整体艺术效果，包括视线、主体形象、创意与表达，以及构图、排版、色彩和适用材质光影如何协作。试制 MUST 判断必要信息和核心形象在实际观看条件下成立，已实现的整体艺术效果有吸引力且代表画面足以指导后续制作。正式关键帧 MUST 达到所选风格的世界级创意、整体形象、构图注意力、排版色彩、实现细节、风格一致性与制作完成度。同轮对照 MUST 按事先登记的各帧职责、参考采用范围和相关观看尺寸下可观察的通过效果，核对用户的整体目标与专项表达。盲审封存后由同一评审者获得这些目标信息；不强制苹果或其他固定品牌风格。

工具 MUST 要求每个观察项及整体给出明确采用结论。仅 pass 可采用，fail 与 insufficient 均不可采用，不用排名、平均分或“基本达到”放行。只有必要信息、核心形象或适用阶段的整体艺术效果实质受损，或违反已确认的目标，才可因视觉表现判 fail。报告 MUST 写出具体位置、实际显示条件、现象、目标与阻断影响。画面已经承担职责时，局部完善建议和偏好不得成为 fail。工具校验记录一致性。

#### Scenario: 证据不足
- **WHEN** 关键帧表现或代表性证据不足
- **THEN** 系统 MUST 明确不可采用及缺证范围，补证后再评审。

#### Scenario: 其他风格达到高水准
- **WHEN** 手绘、纪实或极繁作品达到其所选标杆的实际品质
- **THEN** 评审 MUST 按该风格判断，不因缺少苹果式材质、留白或字体否决。

#### Scenario: 试制与正式分别生成关键帧提问
- **WHEN** 系统生成试制或正式的关键帧盲审或同轮对照包
- **THEN** 包内 MUST 提示对应阶段的品质判据、整体艺术观察和视觉问题的阻断影响。盲审保持目标隔离，对照包使用已登记的职责和参考范围。试制对照 MUST 区分已成立效果、影响通过的差距和后续精修。

#### Scenario: 试制已经建立艺术方向
- **WHEN** 已验证的必要信息和核心形象成立，整体艺术效果足以作为制作基线，局部反光或纹理仍可完善
- **THEN** 评审 MUST 判该项 pass 并记录具体打磨建议。若反光遮蔽主体形象或引发必要读数误读，则 MUST 阻断并记录具体影响。

#### Scenario: 不同尺寸承担不同观看任务
- **WHEN** 关键帧登记了不同观看尺寸及各自应保住的效果
- **THEN** 评审 MUST 按所登记效果判定，并以每个相应尺寸的完整画面作证；局部裁图可用于定位原因。
