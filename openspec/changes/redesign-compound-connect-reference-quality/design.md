## Context

动机见 [proposal.md](proposal.md)。本方案只修改 `dark-proof` 的规范示例及受影响的表现规范，不改变共享审核策略。现有《接》成片、源码与历史冷审不作为新版的通过证据；实施前保留旧成片与材料摘要作为基线。

2026-11-04用户采用方案后要求执行，随后明确取消旁白，只需要音效。本版采用64秒、30fps、屏幕短句与必要事件音；无旁白、无配乐，旧TTS方案撤销。

## Goals / Non-Goals

**Goals:**

- 主张：复利的关键是“把结果接回下一轮”；观众能认出同一个产出包返回、合并并参与后续产出。
- 主角始终是同一组抽象资源及其流向。共享同一轮数、同一初始投入、同一产出率，以完整总量口径比较。
- 接近参考的视觉家族与观看方式：有重量的主体、清楚的轮廓、局部自发光、元素驱动的连续关系、先看见机制后总结公式、安静与释放的对比。
- 超过参考是努力方向，具体争取在回流因果可见、两组核算完整、首尾动作一致这三处改善；不能用方案或代理观察宣称已超过参考或有真实观众效果。

**Non-Goals:**

- 不继续凿木、水滴、月球、棋盘、概念网络等并列案例；不新增理财、个人能力增长或成功概率的现实结论。
- 不复制参考的角色、文案、镜头序列、音轨、贴图或概率设定；参考仅进入设计与隔离对照证据。
- 不新增通用组件系统、3D世界、粒子引擎、视频类型或审核门。现有可用组件先复用。

## Decisions

### 1. 一条实验、一个悬念

片名保留《接》，开场问“重复，就会复利吗？”。两组同样从100单位开始，每轮产出为该轮有效投入的10%；白色组产出取走并保存、有效投入一直为100，金色焦点组把产出并回投入。只有产出去向改变。

不能声称“同样努力／同样成本”，因为两组后续有效投入确实不同。画面短句说“同样起点，同样30轮”；随后明确不同来自积累的产出是否参与下一轮。

替代方案比较：保留十案例会继续增加认知重置；一粒种子长树有物种／生长条件的额外解释；纯公式片缺少可追踪动作。本方案选择资源回流，以最少假设直接表现作品命题。

### 2. 资源编码与公平核算

| 轮数n | 取走组：投入100 + 已取产出10n | 接回组：100×1.1^n |
|---|---:|---:|
| 0 | 100 | 100 |
| 1 | 110 | 110 |
| 2 | 120 | 121 |
| 3 | 130 | 133.1 |
| 10 | 200 | 259.37 |
| 20 | 300 | 672.75 |
| 30 | 400 | 1,744.94 |

全片模型真值只来自同一状态计算。界面整数显示1,745时明确四舍五入，精确核对保留1,744.94；4.36是后者与前者的比值，禁止“多4.36倍／相差4.36倍”的歧义表述。

早段10单位为一个完整圆片，首次出现时用“每片10单位”的对象标签建立编码：初始10片、首轮新增1片，合并后11片；后续不足一片的部分按面积编码、精确读数补足。单个圆片始终沿路径移动，不瞬移、不因换幕丢失。白组已取产出位于系统外的收集区，在总量比较时并入400，不能只比留在机器内的100。资源圆片承载数量，发光尘粒只承载运动与强调，二者不混算；最大资源数约175片，复用既有二维原语，不让辉光或粒子数量随数学数值无限增长。

模型建立窗口最终显示“示意：100起步，每轮10%，忽略损耗。”，规则由同窗主句说明；原长灰字在393宽证据不足，改为52px单行并由独立观察者不放大准确抄读。完整假设留在SOURCES与发布说明中。10%不是现实经验或收益承诺，必要口径放次要位置，不做全片常驻脚注。

### 3. 逐场导演表与屏幕短句

| 段／预算 | 可见事件与认识 | 镜头、运动与转场 | 屏幕短句方向 |
|---|---|---|---|
| S1 0–4s／A | 中央巨型“30次”，30段弧只点亮少量；提出疑问，暂不命名机制 | 固定机位；数字落定后允许0.5秒安静；弧上的光点进入下一段起点 | 重复，就会复利吗？ |
| S2 4–10s／B | 建立两组各100单位资源，每组10个圆片；先展示取走组首轮产生10，接回组保持在自己的第0轮 | 镜头固定；对象名区分两组；新产出从明确出口出现；两组在分段演示时各有轮数，正式比较才同步n | 每轮产出＝当轮投入的10%。 |
| S3 10–17s／B | 产出逐次离开，系统内100不变，系统外累积300；合计400 | 开头一轮完整，再压缩重复；已取产出持续在场；取走路径定向退出，末轮结果保留 | 每轮取走，30轮合计400。 |
| S4 17–24s／A | 转向仍在第0轮的接回组100；取走组400作为已完成实验的参照保留，不把其产出重置或挪用。新10通过开关进入回路，并入100，成为110 | 取走组缩为安静的参照，接回组成为唯一主角；包体与尾迹分离，抵达减速，合并时局部环与光释放；开关变化可见 | 把这10，接回下一轮。 |
| S5 24–31s／A | 第二轮从110产生11，再合并为121；第三轮121产生12.1，结果133.1。新加入部分也参与产出 | 两轮完整因果，不把总数当连续进度条；资源包落位、输入更新、下一轮启动严格有先后 | 110，再产生11，合计121。 |
| S6 31–41s／A | 共享n=0起点、同一线性纵轴，两条总量曲线由资源账本展开；n=1接近，10、20、30逐次拉开 | 资源位置生成采样点与曲线；轮次与端点／读数同源；1–3轮读清后加速，不用全片统一ease-out覆盖数学 | 第10轮、第20轮、第30轮…… |
| S7 41–48s／A | n=30定格，400与1,744.94；先核对两端再给4.36倍 | 候选唯一硬切：从同一曲线终态切到同一两组总量，大数字重置注意力而不换模型；至少保留2秒结果消化，硬切只局部单环 | 同样30轮，400 对 1,745。 |
| S8 48–56s／B | 返回首次分流开关：取走／接回两条去向；同一光包解释全部差别，再出现100+10n与100×1.1^n | 精确公式晚于回流与曲线；只保留必要符号，不新增计算案例；公式退场后光包沿原路径继续 | 接回，每次都带着上一次。 |
| S9 56–64s／A | 开场弧上的同一光点再次抵达“接点”；片名《接》与完整回路同时落定，回扣最早动作 | 不伪称“粒子变成字”：先完成回路与金色落点，再让字的竖笔与接点对齐；末段逐渐安静，结论保持 | 让结果，成为下一次的起点。 |

无旁白，字幕使用现有ScreenSubtitle并遵守宿主subtitleSafeArea；中文每条不超过30字，字号60px、较重字重，英文只作开场／片名标签。画面文字承担对象、读数和结论，不增加同义说明。

17秒切换的是组别，不是把400悄悄重置为100；保留两组身份与各自轮数。核心样片须包含前后文，避免把已完成的30轮与另一组第1轮当作同步比较。31秒数据段回放两组共同n轴的完整历史，最终统一在n=30比较。

### 4. 美术目标：强轮廓、强字重、单点光源

| 维度 | 制作起点与观察方式 |
|---|---|
| 基础色 | ink #0A0B0D、ivory #F3EDDC、gold #E6BE55、muted #8B8981、line #3A3A3C；暖白内核属于米白到金色的明度层级。朱红仅在真实失败／证伪需要时使用，本片通常不用 |
| 字体 | 继续用已登记M2V Sans和M2V Inter；主数字700–800字重、约260–340px，主结论60–76px，英文22–26px；最终以原生与393宽画面复核，不把字号本身当美术通过 |
| 构图 | 数字与回流主体居中；对比图随论证切换两栏；避免常驻左信息柱。主要对象约占画高30%–55%，单独量其包围盒，不把标签／刻度拼成主体 |
| 线条 | 关键资源轮廓6–10px，主曲线5–6px，轴线3–5px；次要线可细，但不能承担关键理解。393宽时需认出返回路径与资源轮廓 |
| 光 | 可见源点、暖白亮核、金色短尾迹、短暂少量尾尘；光包到达／30轮结果／接点闭合三个事件允许重点释放，其余安静；不以常驻星点填空 |
| 镜头 | 默认固定二维舞台；主要变化由对象、数量与曲线发生；不做全片推近、无理由摇移或3D镜头炫技 |
| 运动 | 路径转向用easeInOutSine，抵达用easeOutCubic，无过冲；沿路径匀速的局部段可显式linear并记录用途；数值真值由整数轮次计算，缓动只影响两状态之间的可视过渡 |
| 留白 | 普通信息帧约88%–96%负空间作为起点，结果释放帧允许亮部增多；同时观察主体是否强、空白是否支持焦点，不以像素占比独立判定 |

参考八项指标沿用既有格式，实施时重新从原片首中尾不少于8帧、关键1秒连续帧采样，记录参考值、目标值、实际值和差值；本方案表不是伪造的实际值。

四格图位于示例 `outputs/redesign-plan/concept-board-v1.png`、`concept-board-v2.png` 与本轮展示版 `concept-board-v3.png`（不入Git），仅是ImageGen美术概念。v1缺少轴刻度且倍数表述存在歧义；v2补轴／组别身份；v3进一步去掉前后者指代，明确写“接回总量，是取走总量的4.36倍。”。这些图都没有连续回流证据，生成曲线也不能作精确数学坐标证据；最终代码图表须使用真实n和值、相同线性纵轴与清楚的初始100位置。原始和修订概念均保留，不覆盖，最终编辑提示记录在同目录 `image-prompts.md`。

隔离静帧观察已实际查看概念板及两张参考图，记录在示例 `outputs/review-pack/redesign-plan-concept/observation.md`。初次观察认为视觉语言接近，同时指出轴标、两线身份和单次加法到多轮回接的解释缺口；v2补读又指出前后者指代不稳，v3已改为直接点名两组。静态图形修订只处理静态差距，其余仍须完整动态窗口验证；不把v1／v2观察当作v3重新独立通过。此观察不是当前成片或正式制作门通过。

### 5. 参考采用项与“超过”的落点

关键采用项：大尺度／重字重的唯一主角、主体与字幕清楚分层、局部自发光的事件性、元素级连续关系、先机制后公式、关键结果前的停顿与之后的消化、首尾对象回场。允许偏离：题材、色值微差、九段时间预算、约64秒、事件音色、片名字形、硬切具体秒数；不以容许这些差别豁免关键项。

期望改善的三处：直接追踪同一个产出包到下一轮；在白组总量里保留所有已取产出；结尾回到那一次明确的“接”，让片名成为已理解动作的总结。改善须由当前媒体证实，不以更复杂／更亮／更贵作为“超过”。

### 6. 声音与文案分工

用户最新要求优先：无旁白、无配乐，仅保留必要音效。删除TTS选择、旁白时窗与music输入；不以环境床或持续节拍替代配乐。短句与核心动作同窗，阅读窗口包含展开、完整显示和结果观察。

输出、经过回路、并入投入三类事件用固定音色关系；30轮结果与结尾接点只各给一次收束音。音效按同一命名事件定位，保持大段安静。全部事件音由现有原创合成能力生成并登记CC0、规格与摘要，不含参考音轨。

实施中的局部缺陷修复：既有母带动态归一对本片稀疏事件音输出为−18.5 LUFS，未达到现有目标。归一后按实际真峰值余量有限校正，保留0.5dB编码余量；不改变声音材料、事件、渲染接口或既有QA阈值。此项按已有预期行为明确的简单缺陷修复处理，并以连续音频、欠响度边界、瞬态峰值、静音及立体声回归验证。

### 8. 核心试制与独立观察

首个动态试制只做17–31秒完整窗口，附10–17秒取走组的前后文。必须看清：两组身份、接回组起点100、首轮新增10、返回路径、合并为110、第二轮新增11、合并为121。图形和数字先建立，屏幕短句补足命题；去掉结论句后仍能认出返回改变下一轮。

三个实际风险映射现有reviewPlan种类：

- `static-expression`：轮廓／字重／光材质与参考接近；原生、393宽及200px缩略图观察。
- `structure-timing`：组别交接与返回的先后、110落定之后下一轮才启动、结果有消化时间；检查整个17–31秒。
- `core-event`：同一产出包返回、并入、再产出；不能用一条孤立光轨替代资源转移。

沿用[审核策略](../../../.agents/skills/material2video/references/checkpoint-gates.md#审核计划与风险触发)与[隔离方法](../../../.agents/skills/material2video/references/subagent-review.md)，本方案不新增审核人数、门或打分。概念静帧不计正式通过；实施后的当前核心与全片观察、失败修订和限制见[实施验证](verification.md)及示例VERIFICATION。正式终审由未参与前期评审的新代理看当前全片；相关直接测试、技术QA、完整过程证据和适用独立观察齐备才报告完成。

## Risks / Trade-offs

- [抽象资源像金融回报承诺] → 只用“单位／轮”，小字声明理想示意模型；不把增长率投射到现实技能或市场。
- [取走组总量漏算，夸大差距] → 系统内100与系统外300持续有位置，结果合计400；同轴图全程比较总量。
- [分段演示被当作不同轮次比较] → 两组身份与轮数明确，400不消失；正式数据段回到共同n轴，最终都在第30轮比较。
- [生成图漂亮但运行时无法复现] → 图像仅定方向，核心14秒在真实链路验证；失败退回机制／造型，不用概念帧宣称通过。
- [尾迹与粒子抢走资源身份] → 资源包为实体，尾迹为从属层；抹掉光效仍能判断位置与数量。
- [短句过满／结果过短] → 在60–68秒内按动作与阅读调整窗口；先删重复解释，不加速吞掉“110→121”和对比停留。
- [全片反复展示同一回路显得单调] → 依次切换对象追踪、轮次压缩、数据投影、总量对比、回场；变化围绕同一状态，避免换题材补新鲜感。
- [共享风格改动影响其他类型] → 本片几何与数学留在作品目录；共享改动仅为真实复用缺口，测试按直接影响文件／节点选择，不跑全仓回归。
