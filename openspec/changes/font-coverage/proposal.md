# 提案：缺字机检（字体覆盖）

## Why

字体覆盖是**唯一一种静默失败**：网页声明的字体里没有某个字时，浏览器不报错、
不警告，直接用系统字体顶上——字宽、字重、基线全变了，而所有现有门禁都照过
（K4 对齐量的是元素框、K7 溢出量的是元素框，都不看具体字形来自哪个字体）。

这条也因此是 webfont 子集化的前置条件：不做「逐字查 cmap」的机检就切字体，
等于把上面那种漂移变成常态。

## What Changes

- 新增字体覆盖机检：读字体文件自己的 `cmap`，逐个字符判断是否真有字形；
  缺字报错并列出**具体是哪些字**、出现在哪一段文本里。
- 覆盖范围 = 分镜里所有会渲染的文本（`text`/`title`/`subtitle`/`label`/`quote`/
  `caption`/`value`/`unit`）＋ 预设层的固定字串。
- 零依赖：不引入 fonttools，自己读 TTF/OTF 的 `cmap`（格式 4 与格式 12）。

## Impact

- 不改画面、不改渲染契约。
- 现有作品若本来就全覆盖，结论是「通过」——它防的是将来（换字体、切子集、加生僻字）。
- 反例必须真的能报出来：拿一个字体里没有的汉字去查，必须报缺字。
