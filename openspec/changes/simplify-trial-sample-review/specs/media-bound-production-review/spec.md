## MODIFIED Requirements

### Requirement: 独立媒体契约与显式周期
系统 MUST 提供 review start/pack/import/timeline、自动派生对照与结构化报告模板，拒绝旧检查点合同和旧报告；周期、请求、报告、包 MUST 使用 v4；请求 MUST 指定 keyframe 或 process 用途，旧历史保留不迁移且不能授权当前通过；当前 v4 周期有开放必改或损坏历史 MUST 拒绝重开。历史升级 MUST 核对工作流、原周期身份和历史问题，承接未解决的必改，不接受篡改或未知版本。关键帧只展示静态图像，过程只展示完整视频窗口。正式过程默认直接独立目标对照；例外盲审 MUST 提供具体风险依据。试制包 MUST 不依赖 DESIGN.md、prepared 或全片分镜；本地媒体、来源依赖和观察窗口须摘要绑定。全片播放器 MUST 使用有效准备材料且无视觉门前置。

#### Scenario: 局部试制
- **WHEN** 只有代表性关键帧或核心片段
- **THEN** 可以建立隔离试制包；修改相关依赖使其过期，无关场景不无故使其过期。

#### Scenario: 研究试制完整过程退出独立评审
- **WHEN** 过程请求指向原生试制采集或其动态媒体
- **THEN** 工具 MUST 拒绝为该过程生成独立包或提交新报告。已封存记录保留。原生关键帧继续独立盲审及同轮对照。
