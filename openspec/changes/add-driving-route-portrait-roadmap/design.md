## Context

现有 `driving-route` 已归档为 1920×1080 横屏矢量版；用户要求改为普通道路地图、竖屏满屏、60 秒，顶部叠加“模拟行程 X → Y”。用户进一步要求：顶部标题居中放大；删除底部数据面板；开头不展示全程；跟随镜头更近；已行驶公里数移到车辆旁；结尾仍拉远到全程。当前未提交的卫星实现与“全程开场 + 底部面板”方案需要替换；瓦片采集、拼接与离线绑定可以保留。

## Goals / Non-Goals

**Goals:** 1080×1920 竖屏满屏普通道路地图；路网与城市标注；两行居中标题；车辆旁里程；6 倍跟随；收束拉远到标题下方全程；60 秒首例；离线确定性渲染；材料、底图与候选绑定；失败不破坏旧材料。

**Non-Goals:** 不使用卫星、三维地形、Google/Bing/Esri 或其他影像源；不混用 WGS84；不提供实时路况、实时车速或导航指令；不改变 60 fps 与无音轨契约；不做在线底图运行时。

## Decisions

### 1. 画幅、时长与共享布局

- 类型固定为 1080×1920、60 fps、无音轨；旧 1920×1080 材料明确拒绝。
- 首例 `durationSeconds=60`；类型初始化默认仍为 30，显式时长只改变中段行驶时间。
- 新增 `web/src/compositions/driving/layout.json` 作为画面与底图计算的唯一常量源：画幅、标题高度/字号、内容区、相机时序/倍率、标签字号。前端 `layout.ts` 与 Python `driving_route/layout.py` 读取同一文件；布局版本写入 basemap，布局变化使旧底图失效。布局 JSON 必须进入构建指纹。

### 2. 相机时间轴

- 全程相机使用标题以下内容区：路线 bbox 四角必须落在内容区 inner 矩形内，标题带不遮端点。
- 开场 3 秒停在起点，从约 5 倍全程比例缓慢推到 6 倍，不展示整体路线；随后 1 秒平滑进入跟随（短时长按可用帧压缩）。
- 中段跟随 6 倍，目标取车辆前方沿线点；前瞻以米制换算，不把投影长度直接与米制路线长度比较。
- 最后 3 秒前 2 秒从跟随平滑拉远到内容区全程，最后 1 秒保持；终点到达状态可辨。
- 概览底图常驻底层；跟随底图按相机比例淡入（1→0，2→1），避免过渡期露出背景。

### 3. 普通道路底图与覆盖

- 底图只使用已授权的高德普通道路瓦片（`style=8`，含路网与城市注记），GCJ-02 Web Mercator。
- 概览/跟随包围盒由共享布局常量与相机视口计算，不再写死 1.25/1.5 比例：概览覆盖收束内容区；跟随覆盖开场最宽视野（5×）、任意跟随位置与前瞻偏移。
- zoom 先按屏幕像素/投影米的目标分辨率计算，再受瓦片数、宽高上限逐级回退；材料记录实际 zoom 与 `layoutVersion`，文档不把 z8/z10 写成绝对。
- 取图失败、缺块或摘要漂移时中止并保留旧路线与旧影像；失败只清理本次新建且旧 route 未引用的文件；成功写盘后才按旧 route 引用清理旧图。写盘前复核请求与 route 是否在取图期间变化。
- `mapTiles=true` 时 `basemap` 缺失为材料错误，validate/prepare/render 明确提示先运行 basemap；`mapTiles=false` 是允许矢量例外的最小范围。`fetch` 重写 route 后须重跑 basemap。

### 4. 画面与信息层级

- 地图铺满 1080×1920；顶部半透明白色标题带，两行居中：小字“模拟行程”约 30px，大字“X → Y”约 88px；长标题缩字号或截断；不显示左侧蓝条。
- 删除底部整个数据面板：不显示 cost、耗时、过路费、红绿灯、途经城市或底部距离。`cost` 仍保留在材料中但不渲染；`cities` 继续用于地图城市标签。
- 车辆旁里程 pill：屏幕空间圆角白底 + 深色文字“已行驶 X 公里”，随车移动、不随车旋转；在右上/左上/下方候选中避让端点、标题带与边缘；参与标签避让并最后绘制。
- 城市名与高速名固定在屏幕空间，使用估算宽度判断越界与重叠；避让车辆、端点、里程 pill、标题带、署名与彼此。城市按路线顺序、重叠时换边/跳过；设计文档不承诺“路线中点优先”。
- 署名统一使用 `sourceUsage.attribution`，只出现一次，位于右下小 pill，不遮挡路线与城市名。

### 5. 材料 v2 与验证

- `request.json.sourceUsage` 增加必填布尔 `mapTiles`；`route.json` v2 增加 `cost`、`cities`（含 `location`）与 `basemap`；v1 拒绝。
- 测试覆盖：布局常量/跨语言一致性、开场推近与无全程、6 倍跟随、收束内容区、两级底图覆盖视口、刷新失败保留旧图、取图期间请求变化、`mapTiles=true` 无底图失败、城市/里程/长标签避让、60 秒时间轴、离线准备/渲染。
- 首例重新取底图、prepare、预览开场/中段/收尾、完整渲染，并由独立子代理执行当前候选视觉评审；关闭必改项后才算完成。
- 材料、瓦片、拼接影像与成片留在忽略目录，不入库。

## Risks / Trade-offs

- [6 倍跟随在较低 zoom 下略软] → 按实际分辨率选择 zoom；必要时提高瓦片/宽高预算并实测内存与 prepared 体积。
- [概览/跟随 bbox 扩大导致瓦片数上升] → 保留预算与逐级降 zoom，失败明确提示。
- [标题 300px/88px 压缩地图] → 视觉评审后只改 layout.json 下调标题高度或字号。
- [pill 遮挡路线或标签] → 多候选位置 + 内容区 clamp + 参与避让，测试边缘场景。
- [短时长转场重叠] → 按可用帧压缩 transition，补最短时长测试。
- [布局 JSON 未进入候选指纹] → 测试构建输入包含 layout.json。
