## Context

动机见 proposal.md。现有 v8 场景在 prepare 阶段实时录制，作品可使用 Three.js/R3F/Drei，纹理只能来自登记的本地媒体。另一个已有变更正在重构通用场景，本变更只替换示例及其固定名单，不修改该变更记录。

## Goals / Non-Goals

**Goals:** 三维体积、真实材质、中文科普、从太阳逐级向外的镜头，复用现有制作链路。

**Non-Goals:** 精确历算、交互网页、新视频类型或公共 SDK 扩展。

## Decisions

- 采用单一连续三维场景，太阳、八大行星、卫星、轨道、小天体带及外层边界始终位于同一组稳定的压缩坐标。每段旁白控制相机从总览飞近目标、环绕观察，再返回总览或转向下一目标；不得通过卸载旧天体、加载新天体模拟旅行。
- 采用本地高分辨率球面纹理与程序化日冕、大气辉光、稀疏小天体带；不以平面行星图片替代球体。岩质表面凹凸为视觉近似，来源与处理如实说明。
- 将录制上下文时间传入 R3F 内部，不依赖跨 React 渲染器的 context；纹理上传、字体及首帧就绪后才 ready。
- 太阳、地球、土星先形成关键画面与 15～20 秒代表片段；根据实际观看调整，再录制其余场景。
- 天体大小和轨道半径分别压缩；镜头以全局录制时钟计算平滑轨迹，不在旁白段边界重置相机。
- 由真实配音决定时长，目标 165～180 秒；必要时调整语速并重新准备与预演。选择服务返回的专业可靠音色。

## Risks / Trade-offs

- 无头浏览器实时录制存在掉帧风险：限制球面细分、纹理内存与粒子数量，实测运动效果，避免堆叠后处理。
- 纹理存在色彩增强或观测空白：来源记录和画面明确艺术示意，不用于科学测量。
- 单一太阳光无法同时强调所有细节：使用少量环境补光保留暗部，但维持清晰昼夜分界。
