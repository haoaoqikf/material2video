## MODIFIED Requirements

### Requirement: 作品完整独立运行

作品 MUST 拥有依赖声明与锁文件、构建配置、运行宿主、数据准备、资源恢复、预览、采集、成片合成、视频导出及技术检查入口。使用本地 TTS 后端的作品 MUST 在自身依赖与恢复入口中声明模型、音色与许可，并能脱离主项目恢复与准备。完成声明的环境和资源恢复后，作品 MUST 在主项目未安装且路径不可访问时执行上述操作。运行、编译及类型检查 MUST NOT 读取主项目源码、依赖目录、字体、补丁或缓存；MUST NOT 使用指向主项目的软链接、workspace、file/link依赖或隐式父目录解析。

#### Scenario: 干净目录脱库运行
- **WHEN** 将完整作品源码复制到任意干净目录，主项目不可访问，清空作品构建缓存并按作品说明恢复依赖和资源
- **THEN** 作品独立校验、构建、预览并导出有效完整视频，产物只位于作品输出目录。

#### Scenario: 本地 TTS 模型恢复
- **WHEN** 作品使用 `backend=kokoro` 且模型文件尚未恢复
- **THEN** 校验与准备明确失败并给出作品内恢复入口；恢复后断网仍可准备、预览与导出

#### Scenario: 移动与依赖隔离
- **WHEN** 作品更名、移动到含空格路径，或与使用另一依赖版本的作品同机运行
- **THEN** 各自按本地锁文件解析，互不改变依赖或执行结果。
