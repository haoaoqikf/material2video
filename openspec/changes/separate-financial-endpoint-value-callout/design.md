## Context

端点金额当前仅根据端点坐标使用固定偏移；在曲线高波动区域，文字会紧贴曲线且没有背景隔离。金额字符串随市值长度变化，端点也可能靠近绘图区左右边缘，因此固定单一方向不能满足完整性和可读性。

## Goals / Non-Goals

- 金额保持跟随最新已揭示点，计算与市值格式不变。
- 标签有暗色不透明底板、边距和端点净距。
- 在项目布局范围内比较右、左、上、下候选位置，优先选不与折线相交的位置。
- 在 DOM 几何探针中验证底板、文字、端点边界和间距。
- 不调整画布、纵向居中、安全区、折线数据或金融计算。

## Decisions

- 使用 SVG 背景矩形包住金额文字，并以同一 transform 随前景整体居中。
- 用真实文字宽度估算加水平内边距形成候选矩形，固定高度覆盖 24px 字体并留出上下内边距。
- 以线段与矩形相交检测每个候选区域；候选矩形均避开端点半径与净距。先按固定优先级取首个无折线相交位置；若无完全空闲位置，选相交数最少者，依靠不透明底板保持文字清晰。
- 对绘图区附近全部可见线段执行纯几何检查；候选范围有限，成本可控且确定。
- DOM 探针会检查文字实际包围盒完整处于底板内、底板位于布局边界内，且其到端点圆的距离满足间隔。

## Risks / Trade-offs

- 标签附近的折线可能被底板短暂遮住；这是有限局部遮挡，用于避免数据线与关键数值混为一体。
- 字宽通过现有确定性字体度量估算；运行时 DOM 探针仍使用真实 SVG 包围盒检查文字和底板。
- 图表平移后布局坐标整体变化，但标签和底板处于同一前景组，几何关系保持不变。

## Validation

- 单元测试覆盖常规避让、边缘候选、密集折线回退、超长金额的边界约束及端点净距。
- 前端完整测试和生产构建。
- 特斯拉完整预演抽查开场、中段、高波动和终幕的 360×640 画面，完成专用与通用评审后渲染。
