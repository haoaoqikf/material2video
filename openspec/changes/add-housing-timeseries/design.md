## Context

见 [proposal.md](proposal.md) 与 [housing-timeseries 规格](specs/housing-timeseries/spec.md)。项目已有共享作品生命周期和 Remotion 渲染器；专用类型由目录材料契约与适配器组合注册。年度统计值与金融日行情的时间尺度和业务语义不同，不复用投资估值逻辑。

## Goals / Non-Goals

**Goals:** 增加单材料年度住房价格类型；复用统一准备、完整预演指纹和 Remotion 媒体验收；渲染可解释的逐年曲线。

**Non-Goals:** 月度或二手房价格指数、在线数据抓取、旁白或字幕、跨城市数据集、通用图表框架。

## Decisions

- 新建 `housing-timeseries` 适配器和专用 Remotion composition；该实现只依赖本地材料，避免金融投资语义渗入房价视频。
- 单一 `series.json` 保存序列定义、年度金额面积、计算价、来源快照及口径断点。统一生命周期指纹覆盖该文件与 composition 构建输入。
- 均价由材料提供并在校验时复算确认：亿元 ÷ 万平方米 × 10000 = 元/平方米。官方汇总值仅精确至 0.1 亿元与 0.1 万平方米，均价因此为基于公布精度计算的估算值；序列要求连续年份，首个郑州作品为 2002—2024 年。
- 动画默认 60 秒、30 fps、1080×1920：1 秒开场、57 秒逐年推进、2 秒静止终幕；年份进度以帧数确定性映射至年度点，终幕冻结全曲线。
- 采用 reveal-only 线性纵轴，根据已揭示的均价数据确定显示范围；2005 年口径事件作为材料驱动画面标记，不把来源网站或原始表格逐项绘入画面。
- 类型使用统一手工评审门禁，评审须检查完整预演中的数据对应、断点说明、版面与无声输出。

## Risks / Trade-offs

- 统计局表列出销售额与面积但不直接列均价 → 保存原始值与公式，复算并记录来源，避免依赖第三方均价序列。
- 2005 年起统计口径改变，跨期比较有限 → 在材料、画面和说明中标示断点，不将序列描述为完全同口径。
- 紧凑竖屏可能令年度标签重叠 → 横轴只显示稀疏固定年份刻度，当前年份与价格置于顶部醒目标识。

## Migration Plan

无既有作品迁移。新增类型只影响新初始化作品；郑州作品放入仓库 `videos/` 忽略目录。实现完成、相关验证和提交通过后归档规格。
