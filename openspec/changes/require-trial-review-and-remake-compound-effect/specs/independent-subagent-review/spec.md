## MODIFIED Requirements

### Requirement: 适用审核轮必须由独立子代理执行

审核计划触发的核心样片和最终综合终审 MUST 由新建上下文、只接收评审包的独立子代理执行；轮次表示职责，不表示必须分派多个代理。G5 全片粗片为制作助手内部检查，不属于独立评审轮次。普通 general 新启动制作周期固定要求一次完整试制 core 盲审和一次 G6 独立终审；风险证据合入试制 core 轮。核心风险在相关高投入实现扩展前按计划评审，当前候选另做 G6 终审。最终代理 MUST 未参与该作品前期评审；split-final 触发时最终 MUST 两名新代理分别覆盖结构与视觉文案且互不读报告。候选数量、镜头等级、第一次重要返工 MUST NOT 自身触发额外代理；substantive-dispute 与 repeated-failure 按计划升级。代理 MUST NOT 接收制作理由、预期答案、源码或旧结论；作者不得代写独立观察。环境降级 MUST 显著披露且不得关闭适用的独立评审项。

#### Scenario: 低风险作品的独立评审

- **WHEN** 普通 general 没有未验证核心风险或风险升级条件
- **THEN** 先由独立代理盲看完整试制窗口，再于 G5 内部检查后由未参与前期评审的新代理执行当前候选综合终审

#### Scenario: 精简审核的适用判断

- **WHEN** 普通 general 的最终综合审查覆盖充分且无升级触发
- **THEN** 一名新的独立代理即可，系统不得要求固定第二人

#### Scenario: A 级完成

- **WHEN** 冷观众评审使用新建上下文，只读取前 3 秒评审包，报告由子代理写出
- **THEN** 该评审可记为开场范围的独立观察；前3秒结论不能替代完整试制窗口或全片终审

#### Scenario: 核心风险触发早期评审

- **WHEN** 审核计划登记了未验证核心风险
- **THEN** 由独立代理观察该风险的适用完整窗口，满足放行条件后再扩展对应实现，最终仍执行当前候选终审

#### Scenario: 同一助手切换角色

- **WHEN** 制作助手在同一会话里换一个角色提示后写“独立子代理已通过”
- **THEN** 只能记为“角色分离自审”，不得关闭适用独立评审项

#### Scenario: 子代理读取设计文档

- **WHEN** 评审包或任务书包含 `DESIGN.md`、风格契约或旧结论
- **THEN** 该评审无效，重新打包并分配新评审 ID
