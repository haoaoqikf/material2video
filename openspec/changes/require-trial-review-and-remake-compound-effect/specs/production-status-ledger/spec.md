## MODIFIED Requirements

### Requirement: 状态必须区分候选交付制作完成与可扩展范围

状态 MUST 保留 stage/candidate 技术语义，并分别报告 production.complete、每个检查点的扩展资格及原因。技术已交付而制作门未完成时 MUST 明示候选已生成且制作未完成。核心扩展资格 MUST 使用当前全局准备门、当前 G4 自身证据、适用独立覆盖和同轮目标对照，不因另一检查点未完成一律阻塞无关工作。查询 MUST 只读，不额外编码、联网或采集画面。

#### Scenario: 技术交付但核心风险未关闭
- **WHEN** candidate 为 delivered 但核心窗缺少有效审核或目标对照
- **THEN** 摘要显示候选已生成、制作未完成，相关检查点不可扩展并给出原因

#### Scenario: 一个核心风险失败
- **WHEN** 一个风险未关闭，另一个检查点已具备有效证据且全局准备门通过
- **THEN** 只限制未关闭范围；全部门完成前仍不宣称全片制作完成


## ADDED Requirements

### Requirement: 试制独立盲审不得被空风险绕过

新启动 general 制作周期 MUST 固定包含至少一个完整试制检查窗的独立 core 盲审。显式核心镜头及核心风险的检查点 MUST 共同构成试制范围；两者都未声明时 MUST 选择首个检查点作为最低范围。空风险 MUST NOT 使独立试制调用数变为零。实际制作 MUST 用能代表最难关系的完整段落明确范围。状态 MUST 列出未通过试制的检查点及扩展受限原因；不阻断无关素材整理或 CLI 导出。

#### Scenario: 无核心风险
- **WHEN** 新周期审核计划的风险列表为空且未标记核心镜头
- **THEN** 首个检查点仍要求一次独立试制盲审，另要求当前完整候选终审

#### Scenario: 一个普通检查点已经通过
- **WHEN** 普通检查点证据通过但全片所选试制范围尚未通过
- **THEN** 状态仍说明依赖试制的扩展未获放行，不以该普通检查点代替试制

### Requirement: 新独立失败必须完成原因定位后关闭

新独立失败问题 MUST 初始标为待定位，MUST 支持实现、设计、混合及待定位四种归因；归因是制作记录，当前不渲染。待定位问题 MUST NOT 关闭，未知枚举 MUST 被拒绝。关闭仍 MUST 满足同范围、当前有效的独立复查；分类本身不能授权通过。

#### Scenario: 未定位就关闭
- **WHEN** 新独立失败问题仍为待定位且请求关闭
- **THEN** 更新被拒绝并要求先定位原因

#### Scenario: 设计失败只补说明
- **WHEN** 制作者将问题归因为设计但未提供有效独立复查
- **THEN** 问题不能关闭，制作完成保持 false
