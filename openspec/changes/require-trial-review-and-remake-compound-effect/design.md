## Context

参见 proposal.md。现有 v2 合同已经具备 `shot.core`、core/final 报告、完整窗口与三维 assessment、独立失败必改和版本失效；无需新增审核轮枚举或生产版本。现版示例为64秒金融式数学回流，用户目标已明确改为复利效应。

## Goals / Non-Goals

目标：在正式扩展前真实验证最难关系；最终失败能定位设计与实现；重制作品用具体、原创的可见过程讲清复利效应。仅修改 general 的制作策略及本风格示例，不改变其他类型导出，不引入播放／试听前置，不新增审批。

## Decisions

1. **复用 core 轮。** `shot.core=true` 对应的全部检查点与风险检查点构成试制范围；未声明任何范围时首个检查点为最低默认。风险仍派生 G2/G3 的附加证据；G4 固定至少一个真实试制盲审。选择复杂试制时显式标记 core，不让默认首镜冒充最难关系。每次状态查询同时检查试制范围是否通过，避免其他已通过检查点错误显示可扩展。
2. **归因在盲看之后。** 问题增加可选 `cause`，枚举 implementation/design/mixed/undetermined，当前不渲染。新独立失败初始化 undetermined；关闭前必须定位，原始盲审观察不改写。设计与混合问题先改相应设计再改实现；核心方案更换重走试制；用户目标与硬约束不变时不逐次询问。
3. **先保留基线。** 用已有 baseline create 和源码副本保护旧64秒候选。新 cycle 不继承旧通过，也不补造旧终审。新片复用 slug，工作片名《让积累生长》，以实际效果调整方案。
4. **原创种子叙事。** 开场一颗种子触地、扎根、长成树；树结种、种子成树、新树再结种；重点是新增部分成为后续增长来源。未出发的种子保留在枝上，以机制示意边界限定，不推演现实存活率或保证成功。学习应用用同一可见解题方法再次使用说明，不标固定现实倍率或收益。全片约68秒，具体预算经试制验证后调整。
5. **运动采用已有成熟能力。** 上轮已查 GSAP SplitText（https://gsap.com/docs/v3/Plugins/SplitText/）、Remotion spring（https://www.remotion.dev/docs/spring）、Pixi filters。现有 Remotion4.0.526、GSAP3.15.0 与共享路径／粒子能力足够；保留现有许可边界，不新增依赖和独立动画时钟。字幕按绝对帧偏移错峰，复用现有组件；落定回弹用现有命名曲线／帧函数。主体种子、树木的原创几何是题材绘制，不自研替代动画引擎；复用手绘路径、遮罩与粒子。保留 pure-time、可任意 seek 与顺逆序一致性。
6. **目标与参考。** 采用原参考的完整动作、单字揭示、数字／字形落定确认、源点扩环与整屏释放、早期对象最终回报；不借角色／文案／画面。静态高风险使用独立概念目标，动态用实际核心完整窗。参考八项指标回填实际差异，指标不代替独立判断。

## Risks / Trade-offs

- 种子只表现生长或数量增加 → 两轮完整展示新植株再次结种；试制盲审可直接打回设计。
- 学习应用在短窗内太抽象 → 先设计具体题面与可重复使用的方法，必要时调整时长或删除重复段落，不以书本图标增加冒充知识复用。
- 整屏光效遮挡原因 → 关键对象变化先完成，再释放；字幕保持独立安全区。
- 默认试制增加一次独立调用 → 复用已有 core 报告结构与实际片段，不逐镜派代理，G5 仍内部检查。
- 本地代理无法实时播放 → 提供从实际编码片段提取的完整有序帧，关键运动逐帧；声音技术检查单列，不虚构听感。

## Migration Plan

先完成策略与直接测试、文档生成并提交，再启动新制作周期。旧生成物留在本地基线。最终以当前候选 QA、有效试制与新代理终审、全部必改闭环为交付依据；完工自动归档规格并提交。
