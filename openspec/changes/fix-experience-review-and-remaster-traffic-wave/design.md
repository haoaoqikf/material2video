## Context

动机见 [proposal.md](proposal.md)。现有 QA 明确为 technical-only，静音分析仅生成候选，字幕阅读报告只检查上限；时间轴还叠加段间留白、阅读停留与幕尾。现有技能已要求双向节奏检查，但本片用不对应原问题的依据关闭风险，且最终只查看部分序列页。

## Goals / Non-Goals

**Goals:** 建立能追溯原条件的问题闭环，补齐客观节奏测量，并以同片重制验证；规范见 [增量规格](specs/video-production-workflow/spec.md)。

**Non-Goals:** 不自动评分审美，不强制试听或增加人工门禁；不新增类型、CLI、分镜版本、依赖或兼容层。本轮仅规划，后续 apply 才实施。

## Decisions

### 1. 原问题与证据保持一一对应

更新既有技能参考中的设计表、问题表、导演审查表，保留唯一规则来源，入口只链接。记录目标、显示尺寸、原条件、失败现象、影响、状态、改动、复查条件与有效版本。影响核心理解或用户明确提出的核心缺陷必须修复；非核心保留必须记录未消失的影响，不能计为关闭。

不采用统一主体尺寸或时长阈值，因为不同事件的辨认成本不同。对车辆动作应检查完整事件在 393×852 等比例画面中的可见变化，而非仅检查标签。对结尾分别检查闭合、增量信息和等待用途，不互相替代。

### 2. 测量进入现有 QA，结论仍由作品证据支持

在共享 engine 中分离纯区间聚合与报告生成，general 适配器从当前 prepared 的文本、分段及场景窗口提供输入；其他类型缺少对应时序时明确不适用，不猜测。读取已完成的最终音轨检测结果，避免再次解码或生成全片媒体。

在 qa.json 的 inspection 下新增 rhythm 测量对象，包含 kind=measurement、status、全片 summary、按 sceneId 的 scenes、静音 intervals 与 limitations。指标单位显式使用 seconds、characters、charactersPerSecond、ratio；字数复用现有排除标点与空白的口径。包含旁白窗口内停顿的平均字速=字数/旁白窗口并集时长，零分母用空值及原因。

区间采用半开区间，先裁到实际音轨范围、排序合并，计算全片并集；再与各场、旁白窗口和可确认的额外留白窗口求交。原始候选数与合并区间数分别报告。旁白窗口内静音只代表位置，不声称是服务标点造成；无法确定来源的剩余部分记 unknown。外加留白分别报告 segmentHold、readingHold、tail、leadIn，测量静音与声明留白不是互斥可相加的分类。

无自身旁白时字速不适用，但有音轨仍可报告静音。音频检测失败沿用显式失败路径，不输出伪零值；测量对象不参与审美 pass/fail，也不改变既有技术 QA 判定范围。

### 3. 审查先执行再记录完成

完整粗预演后、精制前保存第一次观察与比较，再查看设计理由；最终候选后执行第二次。逐页查看序列并记录页码、时间范围、显示尺寸与异常处置；高密度序列仍不能替代路径量测或证明听感。事后补录缺少阶段证据时重做相应审查，不能倒填通过。

### 4. 重制以比较解决问题

沿用既有示例与竖屏参数。保存旧版摘要和同尺寸对照，放大主体并调整布局；密度场按车流差异、曲线结果分步展开。先制作开场、制动接力、环路、结尾代表片段，关闭尺度风险后铺全片。

语音对照使用同一音色及同一代表旁白：A 当前参数；B 默认语速且 headPad=0.08、comma=0.15、period=0.45、paragraph=0.50 秒；C 使用 B 停顿并设 rate=+15%。保留未整形原始缓存，比较窗口时长、静音分布、字幕负荷和动作观察预算；选择满足理解条件且无冗余等待的方案，必要时继续微调，不以最短自动获胜，不声称试听。

精简结尾重复解释，移除来源口播，唯一片尾画面保留必要来源和非实测说明。重写材料后重新 prepare；按新时间轴回归字幕、音效和场景边界，再生成完整候选与最终复验。视频不设固定目标时长，不新增配乐或示例。

## Risks / Trade-offs

- 停顿被配乐遮蔽或来源无法确认 → 报告交付混音的信号事实与未知归因，不推算纯口播停顿。
- 加速压缩观察时间 → 调整或删减文案，保留关键机制窗口；回归字幕负荷和动作可见性。
- 全片逐页检查增加工作量 → 接触表作有序导航，异常加密复核，不用重复编码代替检查。
- 自审偏向已有方案 → 先保存观察再读理由，保留真实删减比较与接受保留状态，不宣称外部试映。

## Migration Plan

后续先落地测量与测试，再同步技能契约及当前能力说明，最后执行试制、重制和复验。旧问题需按新原条件重开，历史通过不自动继承；不提供材料迁移或兼容分支。失败保留旧有效交付和候选，不清理证据。实施任务与验证完成并提交后，按项目约定同步主规格、归档并单独提交；本次提案不执行上述步骤。
