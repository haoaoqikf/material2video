## MODIFIED Requirements

### Requirement: 统一运动语言与签名动作

独立化 MUST 保持本部作品既有数学、视觉、声音、事件及节奏要求，只改变运行所有权；主项目更新不得自动改变该作品画面。


作品 MUST 声明一种运动人格与一个签名动作，并 MUST 通过 作品本地动效模块 的命名缓动曲线实现帧驱动运动；MUST NOT 在作品内复制近似曲线。空间运动 MUST NOT 缺省使用线性缓动；入场 MUST 使用减速家族，离场 MUST 使用加速家族，相机 MUST 使用 `easeInOutSine`。签名动作“落定一沉” MUST 在 S1 落片、S2 金币落定、S5 金雨与 S6 金片归队中一致复现。所有运动 MUST 只由帧号、秒数、事件帧与 props 推导，满足 `pure-time` 与并行渲染。

#### Scenario: 运动一致性核对
- **WHEN** 检查场景源码与 S1、S2、S5、S6 的有序帧
- **THEN** 场景从 作品本地动效模块 导入命名曲线，入场减速、相机平滑、金雨加速，落定动作在四处一致；无挂钟、随机源或 CSS 动画参与
