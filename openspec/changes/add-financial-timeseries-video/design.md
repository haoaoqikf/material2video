## Context

动机见 [提案](proposal.md)。现有工程已有 Remotion 按帧渲染、折线图和 ECharts 适配基础，但文章审查、时长约束和有声评审耦合于当前流程。专题行为见 [专题规格](specs/financial-timeseries-video/spec.md)，本文记录已实现的接口和渲染决策。

## Goals / Non-Goals

**Goals:** 定义并实现数据、事件、时间编排和无声验收；与文章流程并列、复用确定性渲染基础。

**Non-Goals:** 不在项目内建设行情抓取器或模型调用服务；不改变 v4，不建设实时行情、K 线、多标的对比、收益分析、音频或付费数据集成。

## Decisions

### 独立专题入口，复用表现层

数据视频使用独立输入与验收流程，后续才设计明确的程序接口和 v4 接入方式。复用现有按帧渲染基础能保留确定性；把金融资料伪装成文章会引入无意义字数与口播要求，而另起完整工程会重复渲染基础。文章门禁继续原样生效，不能以专题文档绕过。

### AI 搜索，固定材料渲染

Codex 等具备搜索能力的 AI 编程工具负责准备资料，项目不因此内置模型调用或行情服务。准备后保存原始材料和来源，再用固定材料渲染。相比渲染时访问网络，这能保留来源、复查价格和随机寻帧一致性。具体免费站点不写成固定依赖；每次制作核验其可用性及实际口径，公开网页可读不等于历史序列完整。

### 四类材料与独立 Python 入口

将四类材料固定为作品目录下的 `request.json`、`prices.json`、`events.json`、`animation-plan.json`，用 Python 标准库单一验证器集中校验跨文件一致性；Remotion composition 同时做窄的运行时结构解析，避免坏 props 渲染。入口 `.agents/skills/article2video/scripts/financial_video.py` 提供 `init`（初始化内容模板）、`validate`（离线校验）和 `render`（只读材料并输出视频）三个命令，不在脚本中调用搜索服务、行情 API 或模型。

AI 制作流程按专题 Skill 指引搜索公开来源、解析并确认标的、整理事件，填充这些材料；无法唯一识别标的或价格口径不符时先向用户澄清。这样兼容 Codex 等不同工具，不需要账号、密钥或维护专有行情后端。材料目录采用标准作品位置 `videos/<slug>/` / 外部内容根；数据来源快照与成片落在被忽略的内容目录。

价格材料增加覆盖区间内经核实的 `expectedTradingDates`，确保校验器能区分休市与应有数据的缺口；其日期清单来源一并注明。规范价格按拆合股因子换算到 `adjustmentBaseDate` 的股份单位，不使用分红调整因子。事件清单分别记录候选、入选及排除原因；采用本地日期，不推断因果。

### 真实日历与确定性播放

横屏视频以独立 Remotion composition `FinancialTimeSeries` 渲染，不加入文章 v4 world/stages 或输入审查、口播和有声门禁。Python 从四份已通过校验的材料生成只读 Remotion props，并调用共享构建与媒体编码边界；Remotion CLI 选择 composition 的参数增加可选 id，默认仍为 `A2V`，保持旧调用兼容。专题输出经本地 ffmpeg 完整解码和 `imageio-ffmpeg` 元数据核对，明确拒绝任何音频流。

动画计划每段用半开帧区间 `[startFrame, endFrame)`，首段从 0 开始，相邻区间连续且完整覆盖成片；日期端点连续。推进段把两个端点映射到段内首、尾帧，中间帧按日历日线性插值后向下取整；单日停留段要求起止日期相同。事件可见区间必须落在全片范围内，开始帧对应日期不得早于事件日期；标签区间相互不重叠。推进段至少两帧，结尾停留至少 90 帧。

React composition 静态绘制全量曲线后以确定性 clip 区域揭示至当前日期，按二分查找当前交易点并只显示其收盘价与交易日期，时间推进不制造价格点。时间映射查询 O(段数)，当前价格查询 O(log 交易日数)，曲线绘制规模为 O(全片交易日数)；每帧不重建所有点的路径。

### 事件是可核查事实标记

默认最多八个事件，由 AI 自动筛选。候选与入选理由保存在材料中，日期采用标的市场当地日历；区分发生日、公告日和报道日。日期无法确定的候选排除。休市日标记锚定时间轴，不给它伪造价格坐标；标记保留，详细说明顺序展开，避免标签堆积。

### 文档职责与交付状态

专题 Skill 章节指导 AI 搜索/核实，不声称仓库工具能代替 AI 联网搜索。制作参考文档维护材料格式和创作规则，Python 验证器是材料结构、时间映射和口径声明的机器校验真源，Remotion 层仅消费验证后的 props。README 与项目规划标记首版已实现；本变更归档后主规格反映已实现行为。

## Risks / Trade-offs

- 免费来源可能只有含分红调整数据或覆盖不足 → 记录口径与实际范围，不静默换用；需要替代口径或缩短时请求确认。
- 多地上市、同名指数及日期含义容易混淆 → 标的不唯一先澄清，记录市场当地日期和来源日期含义。
- 已知缺测可能被折线掩盖 → 数据验收先阻断，不用插值或视觉连线代替修复。
- 变速视频可能夸大某段持续时间 → 日期持续可见，保存分段映射与编排依据，固定坐标范围。
- 邻近事件可能被误读为涨跌原因 → 采用事实标题，不自动添加因果表述，留存来源。
- AI 资料准备与离线渲染职责混淆 → Skill 明确联网搜索发生在准备阶段，命令只验证和渲染固定本地材料。

## Migration Plan

不迁移现有作品或示例。使用合成测试夹具，不增加 examples 目录；交付前验证文章流程无回归。全部实现任务及验证完成后，同步主规格并归档。
