## Context

动机见 [提案](proposal.md)。现有工程已有 Remotion 按帧渲染、折线图和 ECharts 适配基础，但文章审查、时长约束和有声评审耦合于当前流程。专题的目标行为见 [专题规格](specs/financial-timeseries-video/spec.md)；本轮只完成规范，不能据此宣称现有渲染入口兼容。

## Goals / Non-Goals

**Goals:** 定义数据、事件、时间编排和无声验收的制作边界，让后续实现有可核验目标；与文章流程并列、复用确定性渲染基础。

**Non-Goals:** 本轮不实现数据抓取器、CLI、schema、composition 或门禁；不改变 v4，不运行真实数据采集或视频生成。不建设行情服务、实时行情、K 线、多标的对比、收益分析、音频或付费数据集成。

## Decisions

### 独立专题入口，复用表现层

数据视频使用独立输入与验收流程，后续才设计明确的程序接口和 v4 接入方式。复用现有按帧渲染基础能保留确定性；把金融资料伪装成文章会引入无意义字数与口播要求，而另起完整工程会重复渲染基础。文章门禁继续原样生效，不能以专题文档绕过。

### AI 搜索，固定材料渲染

Codex 等具备搜索能力的 AI 编程工具负责准备资料，项目不因此内置模型调用或行情服务。准备后保存原始材料和来源，再用固定材料渲染。相比渲染时访问网络，这能保留来源、复查价格和随机寻帧一致性。具体免费站点不写成固定依赖；每次制作核验其可用性及实际口径，公开网页可读不等于历史序列完整。

### 四类材料与附属来源

制作参考文档定义需求记录、价格序列、事件清单、动画编排的最小字段含义，原始下载和来源清单作为附属材料。它们是文档层建议文件，不是当前 schema 或 CLI 支持的接口。价格默认采用区间末端单位基准的仅拆合股调整序列；推导时记录基准日期、已核实拆合股比例和步骤，不使用包含分红的调整字段冒充。

### 真实日历与确定性播放

时间映射使用真实日历日期，按分段计划映射到固定帧号；日历时间与视频时间分开记录。暂停段保持日期，价格取最近已揭示有效交易点并显示其日期，非交易日不产生报价。纵轴基于完整有效序列固定，标签只在事件实际日期到达后出现。与固定匀速方案相比，AI 编排能适配事件阅读，但必须保存速度和停留理由，不让渲染器临时决定节奏。

### 事件是可核查事实标记

默认最多八个事件，由 AI 自动筛选。候选与入选理由保存在材料中，日期采用标的市场当地日历；区分发生日、公告日和报道日。日期无法确定的候选排除。休市日标记锚定时间轴，不给它伪造价格坐标；标记保留，详细说明顺序展开，避免标签堆积。

### 文档职责与交付状态

规格是待实现行为的权威来源；制作参考文档说明 AI 准备和验收方式，README 只做状态导航，项目规划只登记未来路线。制作参考文档不修改既有文章 Skill 主流程。任务清单区分本轮规范交付与未授权的后续实现，只有后者实施并验证完成后才考虑归档。

## Risks / Trade-offs

- 免费来源可能只有含分红调整数据或覆盖不足 → 记录口径与实际范围，不静默换用；需要替代口径或缩短时请求确认。
- 多地上市、同名指数及日期含义容易混淆 → 标的不唯一先澄清，记录市场当地日期和来源日期含义。
- 已知缺测可能被折线掩盖 → 数据验收先阻断，不用插值或视觉连线代替修复。
- 变速视频可能夸大某段持续时间 → 日期持续可见，保存分段映射与编排依据，固定坐标范围。
- 邻近事件可能被误读为涨跌原因 → 采用事实标题，不自动添加因果表述，留存来源。
- 专题资料被误认为当前入口支持 → 所有入口文档标明“规范阶段，尚未实现”，后续设计单独接入和门禁。

## Migration Plan

本轮只发布规范，不迁移现有作品或主规格。后续获得实现授权后，先补充程序接口与门禁接入设计，再实施任务并同步受影响的制作契约、校验和测试；使用合成测试夹具而不增加 examples 目录。交付前验证文章流程无回归；实现任务与验证全部完成后再按项目规则提交、同步主规格和归档。
