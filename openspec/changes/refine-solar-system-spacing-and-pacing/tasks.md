## 1. 流程规则与反馈基线

- [ ] 1.1 登记独立行星看似紧挨、换站拖沓两项必改反馈，绑定旧版摘要与典型时间码；核查记录区分事实、推断与待定位原因。
- [ ] 1.2 在制作阶段和视觉复核参考文档补齐空间关系、双向节奏与逐段预算要求，并同步必要入口摘要；对照增量规格检查无遗漏、无重复权威来源。
- [ ] 1.3 修订证据模板和问题关闭规则，明确连续节奏例外优先于一般替代验收完成规则；检查不新增CLI门禁、用户审批或虚构播放能力。
- [ ] 1.4 演练路径安全但挤靠、运动平滑但拖沓、只有接触表、QA通过但体验未验证四种情形，记录预期与实际判定，确认均不能误判体验通过。

## 2. 布局、路径与预算

- [ ] 2.1 调整独立行星布局与相机进出方向、视线和构图，重点木星→土星；全量查看独立行星过场及卫星关系，记录空间分离证据和未关闭项。
- [ ] 2.2 将统一九秒预算改为逐段离场、跨站、接近和观察预算，清除重复拉远与无信息等待；生成完整低成本动态粗预演并连续复核整体节奏，记录核定时长与前后差异。
- [ ] 2.3 回归相机安全、内部与边界连续性、速度与转向风险、三个重点镜头；运行相关相机与场景测试，确认无掠过、甩头、瞬移、穿模和构图退化。
- [ ] 2.4 同步分镜、声音覆盖、字幕、音效与主体显示时序，重新准备并核对窗口；通过相关声音测试和示例严格校验，确认现有旁白及有效音色选择保持一致。

- [ ] 3.1 按cinematic契约生成关键静帧和风险样片，全量覆盖独立行星过场并重点比较木星→土星；记录空间关系与连续节奏的不同证据，必改项关闭后再扩展精制。

- [ ] 3.3 按当前制作链路生成一次完整候选并执行技术QA、最终文件全片帧序列与自动音频检查；实际连续观看完整文件及重点过场，绑定准备指纹、摘要和时间码，缺观看证据时保持节奏待验证且不标记整体完成。
