## Context

动机见 [proposal.md](proposal.md)。当前示例为220.5秒，14次段间运动与观察均为9秒；复核记录主要依据接触表、加密帧和运动量测。现有主规格允许替代检查自主完成，因此本变更需要明确连续节奏问题的例外，不能仅追加一条相互冲突的规则。

## Goals / Non-Goals

目标是让独立行星的空间关系清楚、过场简洁且连续，并通过同一作品验证流程修订。保留现有旁白、15站、三个重点镜头、单幕及科学示意边界。不追求真实比例，不新增共享相机框架、公共接口、自动审美评分或用户确认流程。

## Decisions

### 空间布局与构图联合调整

先登记独立行星过场的空间关系与失败时间段，重点木星→土星；联合调整布局、进出站方向和视线，使离开的行星退入远景后再突出下一主体。排查全部独立行星过场，卫星仍依附母星。仅拉大世界坐标距离不足以保证屏幕观感，不能用无碰撞或单一距离阈值代替视觉检查。

### 每段预算由信息和运动共同决定

路径生成器改为逐段预算，分别核定离场、跨站、接近和必要观察。先消除重复拉远与无信息等待，再用完整动态粗预演确定时长，不预设统一秒数或全片加速比例。布局变远后同步修订路径与时长，避免以更高速度制造新的掠过。保持相机连续性和三个重点镜头的可读构图。

### 证据按结论分工

在 creative-production.md 与 visual-review-rubric.md 集中维护空间关系和双向节奏要求，其余 Skill 入口、README 与相关契约按需同步。记录须区分静帧、全片时间标注帧序列、风险加密帧和运动/音频量测，并注明版本、范围、时间码与结论。静帧用于空间关系，时间标注帧序列与量测用于动态节奏，服务元数据和旁白文本用于选音，自动信号用于声音技术复核；工作流不要求播放视频、连续收听声音或试听音色。

全片帧序列和量测覆盖不足时继续补采样；采样不能证明的瞬时运动、主观听感作为限制披露，但不因此要求播放或用户接手。证据齐全时可依据替代检查关闭对应问题；不新增 CLI 门禁。自动音频替代验收保持技术边界。

### 分阶段实施与版本一致性

实施顺序为修订共享指导并登记两项反馈，再调整布局和时间预算、生成完整低成本粗预演、采集风险帧，最后生成完整候选并复核同一最终文件的帧序列与量测。当前共享规则、布局/运镜、逐段时长和配乐时序已有改动，当前准备窗口及粗预演、风险帧已生成；高密度风险帧的全量审核和最终候选复核尚未完成。布局、运镜和时长变化后重新准备，更新配乐覆盖、字幕、音效及身份显示；旁白与音色选择保持不变，除非现有契约要求更新摘要。

新版证据绑定准备指纹和文件摘要；历史验证保留且标明旧版本。更新示例设计、说明及验证记录，不覆盖历史归档，不增加第四个示例，生成媒体不入库。整体完成须包含流程修订与作品重制两项交付。

## Risks / Trade-offs

- 布局变远可能造成高速掠过或构图变化 → 联合核定路径与预算，回归相机安全和三个重点镜头。
- 帧间连续运动不能由稀疏采样完全证明 → 对全片提高采样密度并在转场/速度峰值加密，披露剩余采样风险，不要求播放或增加用户审批。
- 帧序列能暴露空间关系但不能独立证明节奏 → 分开记录证据与结论，技术 QA 不代替体验验收。
- 缩短全片可能影响声音与字幕 → 依当前准备窗口重排并执行相关验证；不对旧成片整体变速。

## Verification

演练路径安全但行星挤靠、运动平滑但拖沓、只有接触表、QA通过但体验未验证四种情形。作品全量检查独立行星换站，连续复核粗预演与最终文件，重点木星→土星，并回归卫星关系、掠过、甩头、穿模、重点构图与声音时序。相关代码测试、前端检查、示例严格校验与既有制作 QA 按实际改动执行；不把技术通过描述为审美自动通过。
