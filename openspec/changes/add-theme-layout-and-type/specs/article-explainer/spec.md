## MODIFIED Requirements

### Requirement: 视觉主题
系统 MUST 以 `web/src/themes.json` 作为视觉主题的唯一真源，由它派生主题名单与默认主题；前端画面实现与准备阶段的实现 MUST 读同一份，MUST NOT 各自另存主题取值。分镜的 `visual.theme` MUST 取自该清单，取值不在清单内时 MUST 拒绝并在错误中列出可选主题。

主题 MUST 承载**颜色、排版、取形、间距、构图与动效**六类取值。取形 MUST 覆盖面板、卡片、节点与媒体框的圆角以及面板与卡片的描边宽度；间距 MUST 覆盖幕外壳的上下留白、标题与内容的间距、各模板的内边距与元素间距，以及因果图、媒体框与代码框的尺寸；构图 MUST 覆盖水平对齐与垂直对齐；字阶 MUST 覆盖标题、正文各角色的字号。画面实现 MUST 从主题读取这些取值，MUST NOT 在场景内写死。

主题声明的转场时长 MUST 覆盖每幕声明的 `transitionFrames`，未声明时 MUST 沿用分镜声明与契约默认值；转场类型 MUST 仍由分镜决定。主题声明的阅读停留 MUST 参与准备阶段的最小幕长判据。动效 MUST 以帧数表达，MUST NOT 依赖 CSS 动画或计时器；入场缓动 MUST 由主题以三次贝塞尔控制点声明并逐帧求值，控制点为 `[0,0,1,1]` 时等价于线性。

幕外壳的下留白 MUST 保证正文包围盒不越出 `--m2v-measure-content-bottom`，任何主题 MUST NOT 通过缩小该留白来换取留白感。

主题可在项目既有的对比度预算内改编外部风格，改编项 MUST 在参考文档中逐条标注，MUST NOT 表述为原值照搬。

#### Scenario: 主题接管节奏
- **WHEN** 主题声明了转场时长或阅读停留
- **THEN** 准备阶段按主题的帧数编译时间轴与最小幕长，成片按该节奏渲染

#### Scenario: 未声明转场的主题
- **WHEN** 主题未声明 `transitionFrames`
- **THEN** 每幕沿用自己声明的转场时长，未声明时用契约默认值，既有作品行为不变

#### Scenario: 未登记的主题
- **WHEN** 分镜声明的 `visual.theme` 不在主题清单里
- **THEN** 校验失败并列出可选主题，不静默回退到某个主题

#### Scenario: 主题数据不可读
- **WHEN** 主题清单缺失、不是合法 JSON、缺少 `themes` 或默认主题不在清单内
- **THEN** 校验与准备阶段明确失败，MUST NOT 用内置默认值继续制作

#### Scenario: 主题决定取形与间距
- **WHEN** 主题声明了圆角、描边宽度或内边距
- **THEN** 六个模板按该取值绘制，画面里 MUST NOT 残留组件内写死的同一个数值

#### Scenario: 构图模式
- **WHEN** 主题声明垂直对齐为居中
- **THEN** 标题与内容作为一个整体在幕内垂直居中，且正文包围盒仍在内容下边界之内

#### Scenario: 按主题的字阶
- **WHEN** 主题声明标题字号大于正文
- **THEN** 标题按该字号绘制，标题折行后内容 MUST 仍在内容下边界之内，必要时由主题一并声明图形尺寸

#### Scenario: 逐帧缓动
- **WHEN** 主题声明非线性的入场缓动控制点
- **THEN** 元素入场进度按该曲线求值，同一帧的求值结果 MUST 与 seek 历史无关

#### Scenario: 既有主题画面不变
- **WHEN** 主题的六类取值与其历史取值逐字相等
- **THEN** 成片画面 MUST 与扩展前逐像素一致

## ADDED Requirements

### Requirement: 主题字段的完整性
主题的六类取值 MUST 每类齐全：缺失任何一类 MUST 在校验阶段明确失败并指出缺失项，MUST NOT 用内置默认值补齐。取值 MUST 为有限数值或受控枚举；构图对齐 MUST 限定在允许的枚举内。

#### Scenario: 主题缺少某一类
- **WHEN** 主题记录缺少取形、间距、构图或字阶中的任意一类
- **THEN** 校验与前端加载明确失败，指出缺失的类别，不静默采用其他主题或内置默认值

#### Scenario: 取值非法
- **WHEN** 主题的尺寸类取值不是正有限数值，或对齐枚举超出允许范围
- **THEN** 明确失败并指出字段名与非法取值
