## Context

动机见proposal。现有作品是独立工程v3、分镜v9、单场solar-journey；旧片10473帧，旁白75.85秒，声明留白98.65秒，其中跨站51秒。既有路径生成器独立维护实测旁白帧数，场景复用无状态相机求值器。当前输出缺新制式制作周期，先保护旧版再建立新周期，不继承历史通过。

## Goals / Non-Goals

目标是兑现已确认120秒编排和三个重点体验；准确预算依实际TTS和局部动态验证闭合，允许115–125秒。全部场景专属变化留在示例，沿现有渲染和评审接口制作；不升级共享契约、不新增视频类型，也不新增完整天文模拟引擎。

## Decisions

1. 时间预算以作品内单一可编辑行程为来源：每站旁白、实测长度、接近/观察/离场、过场和镜头类型关联，生成器拒绝与实际旁白不一致的预算。短普通站提早在可辨接近阶段开始讲述；重点站保留关系揭示与观察，不对旧视频整体倍速。
2. 保持同一个三维世界与无状态逐帧运镜。按世界布局、取景及主体尺度改善非当前行星主次，不通过隐藏切换替代旅行。地月合并为连续关系段，土星环几何不生长；奥尔特云外层结构采用清晰分层且明确推测性质。
3. 复用Three.js/R3F/Drei及现有地球材质、环遮挡、后期，先校验实际成像再调参数。前轮已调研Takram大气库（MIT、Beta、渲染API迁移中），本轮若现有实现达到目标则不新增依赖；若试制证明不足再针对缺口评估。新增组件不得未经检索实现。
4. 具体视觉参考采用NASA Cassini PIA17172的环带/暗面/逆光层次与Twin Blue Marbles的云海陆/昼夜/薄大气层次。只将真实读取媒体用于同轮目标对照，参考不是素材导入授权；运动与声音推导需实际过程和信号验证。
5. UI保留名称和核心结论、字幕及克制导航，必要声明低层级出现，完整署名保留来源台账和发布说明。原创配乐按新站点和重点窗口重排，恢复配方同步实际文件摘要。
6. 原生试制覆盖木星→土星完整揭示，地月与外层未知按实际需要补采集；独立代理先盲看后目标对照。全片技术QA后由未参加试制的新代理综合终审。源码变动使旧证据失效时按当前绑定重取，不手改指纹或伪造通过。

## Risks / Trade-offs

- 缩时使转向与辨认不足 → 按完整窗口量测和观察调整路径与预算，保持总长范围。
- 同场背景天体过大 → 先布局/取景/光照解决，检查所有站点及母星卫星，不只修单帧。
- 逆光过暗或大气过厚 → 对照实际参考与手机尺寸，重点保主体辨识和真实层次。
- 历史脚本/配方硬编码旧时点 → 搜索直接调用方，改为行程或分镜派生，并专项验证。
- 重渲染成本 → 局部原生采集确认再生成全片，保留有效候选并复用同摘要媒体；不以低清或缺证据冒充最终。

## Migration Plan

制作期发现并纳入的局部修复：管理侧把可达SDK的useMediaAsset函数声明误算为动态调用，误绑定无关声音/缓存而拒绝真实样品；排除声明但保留实际动态调用的保守绑定。静态贴图在管理侧重复调用ffmpeg探测，在真实8K图片上发生30秒超时；改用已有Pillow校验结构并完整解码，拒绝损坏/非支持图片，视频路径不变，同步本作品与独立工程模板。两者是既有预期行为与性能修复，专项保护来源和失败边界。

原生完整解码另发现单帧白闪：归一化点积的浮点舍入可能使小数次幂底数为负。实际网页单表达式受控试验定位后，在本作品大气和亮缘约束输入域；新环透光核对实际几何法线，透明轨道参照线关闭深度写入，避免遮断透明材质。以上属本作品的确定性与成像修复，不更改共享渲染或独立门禁。修后以真实WebGL编译、原生邻帧及完整窗口重新验证，保留原失败。

核验并保存旧片、旁车、可编辑材料；用现有review start建立本轮周期；逐步试制并更新分镜、场景和声音；通过当前技术与独立审核后交付同一候选；同步README、研究、设计和验证，专项检查与代码审查通过后提交，按项目约定同步主规格并归档再提交。旧版通过仅保留在历史记录。

全片终审另发现41–44.8秒谷神星规则棋格：现有程序表面的高频正弦乘积形成可见交叉纹。按已采用的自然岩质表面目标局部修复，先研究并试用已安装Three.js的ImprovedNoise，但原生表现仍过于简化；最终采用许可明确的NASA官方Ceres模型内4K表面及2K法线原图，正式导入并登记固定原包/成员/摘要恢复，删除临时噪声分支；不改变目标、行程或评审门禁。重采参数从原capture.json的时长、帧率与stills派生，保留全部原帧位；来源变化按既有规则刷新绑定，不能把未通过的完整候选当作交付。

随后同轮土星对照指出球体暗面近黑、全周亮缘和高亮灰白环仍未兑现Cassini整体材质目标。保留该失败，局部调整既有Three材质：增加源纹理驱动的微弱暖色反照近似、减低环透光增益与白色混合、薄大气使用同一世界太阳方向；不升全局环境光、不新增依赖。NASA/JPL的PIA10476仅用于核对环反照可照亮夜侧云带的机制，不替换原PIA17172视觉目标；展示权重不是物理辐射测量。实际网页对比多个实质不同曝光组合，选克制暖色版本后重新完整原生采集与独立盲看/对照，未通过则继续返工。


暖色折中版仍独立失败后，按原目标完成匿名两机制探索，均未定案；继续采用NASA Saturn原生云带图集与配对扁球数值几何。几何作为本例`scenes/data/`第三方源数据入库，固定GLB提取器可复现；原PNG不入库并由既有素材恢复入口严格恢复，不引入共享模型格式或GLTF运行时。移除土星三张程序化微表面/发光图，改用几何法线和固定粗糙度，避免专属UV错配。环保留完整可见基底、有界HG形状和源图细层；固定环面内低亮尘层只作多尺度艺术转化，随实际机位平滑LOD。木星系靠近土星时仅降低光量，不改可见性或用跳切替代旅程。审查发现负底数pow后改显式平方，旧采集不沿用。完整当前证据和独立通过之前仍不得声明完成。

当前完整候选的独立终审另检出f6889（114.8167秒）单帧全画面白闪，原生代码场景缓存同帧已异常，合成没有新增该缺陷。该问题与前述早期可重复的pow失效分开记录；目前直接seek及按30帧预热均未复现，不能把星场点尺寸等未证实线索当作根因。保留失败原字节与旁车，按实际完整运行状态继续隔离，修复后重新完整采集、逐帧量测和独立双评，不替换单帧或修改原证据。

完整逐帧预热亦未复现后，采用本例RGBA16F输出边界防御：复用已安装postprocessing的独立ShaderPass，在RenderPass之后、Bloom之前逐像素读取，只将非有限RGB置零，正常有限HDR原值不改。独立注入NaN、正/负无穷值均在同一后期链形成全白，保护后非有限通道归零；有限输入逐位无差异、最终画面字节相同。此证据证明传播机制与边界修复有效，不足以反推原失败现场唯一源表达式；该限制保留。显式使用HalfFloat缓冲，65504仅对应其有限上界，不宣称适用于任意Float32 HDR。新增pass限本例，不改变共享渲染或评审契约。

实际收口出现单次问题读取重复展开相同报告/包/复用依赖，十四项关闭的复核长时间占用CPU。沿用已有ledger只读查询缓存，仅让带闭环校验的issues.load在没有外层只读查询时建立一个独立查询，已有查询则共享；无闭环的递归原始读取不另开查询。读取返回即销毁自己创建的缓存，所有更新、导入和发布仍在其外执行，发布前源重读保留。原报告身份、条件、循环复用检测及失败重开逻辑不变，不添加新门禁或放宽完成条件；以真实失效和循环边界测试证明等价，不将缓存跨写入。
