## Context

动机见 [proposal](proposal.md)。本例已是独立工程 project v3，场景只依赖本作品源码和精确锁定的依赖；旧成片已通过 `baseline create` 留存。用户在看过六项变化后授权执行，保留29秒、无旁白、无旋律、三色状态与简洁结果。

## Goals / Non-Goals

**Goals:** 实体圆片在近景与全景统一；同一枚第一年收益能够被追踪；比较同基线同尺度；年度金额驱动增长；声音与可见接触共用事件；新证据绑定实际媒体。

**Non-Goals:** 不引入投资建议、追加本金、年龄比较、收益承诺；不新增共享渲染接口或视频类型；不以换皮或平面渐变代替厚度与接触关系。

## Decisions

1. 实体表现优先评估 Three.js 的倒角几何、金属粗糙度材质与环境光。复用本地受控帧时钟与命名缓动；不使用自主动画循环或实时物理。外部方案、精确版本、许可和成本结论进入作品 RESEARCH.md。若新依赖适用则在本工程独立安装，不借用其他示例目录。
2. 帧状态与绘制分离：纯函数计算圆片身份、金额单位、位置、状态与相机；渲染层只消费该帧状态。近景可转动主体展示厚度，最终比较保持统一正面正交投影，面积仍按金额平方根编码。
3. 代表性试制先覆盖第2年因果与结果规模两种内容。研究与原生画面独立对照成立后再展开其余镜头；试制失败继续修复，不以技术通过代替视觉通过。
4. 第一年的收益保留稳定身份，归队后单独产生0.1单位收益；原始10单位产生1单位，两者来源以空间邻接、运动和必要对象文字说明。加速段依年度余额求新增量，不用随机金雨填充终态。
5. 声音使用作品已有原创合成体系，新增本轮命名资产，独立登记配方与摘要，不改旧资产摘要接受漂移；所有接触与声音引用同一分镜事件。必要口径两行小字，避开关键动作并给予完整读取窗口。
6. 仅本例的旧镜头和表现契约被替换。审核职责沿现行 review-contract，不复活过时G0–G6流程；历史失败保留原件与原范围，新版用当前周期独立试制和新代理终审验证。

## Risks / Trade-offs

- [金属在黑底消失或高光过曝] → 参考静帧实际对照，使用大面积柔光反射和暗部填光，检查米白/金/暗金的明暗分离。
- [透视改变金额尺度] → 比较采用同一正交相机、同向圆片、共同基线；特写不承担跨组体量比较。
- [增长太快无法逐枚追踪] → 完整演示前两年与分流，随后明确时间压缩；年度状态及终值测试与过程帧共同核验。
- [GPU及采集成本] → 复用几何/材质，限制阴影开销，先验证浏览器可重复采集与局部成本，再生成全片。
- [模型与可绘制尾数不一致] → 保留精确金额模型，分数片不强行凑整，不把175个绘制对象说成175,000元。
