## Context

动机见 [proposal.md](proposal.md)，作品行为见 [规格](specs/earth-night-lights-video/spec.md)。现有 general v8 支持作品本地 TSX 场景、素材 ID、无旁白时按帧定长及 soundtrack。太阳系示例已有地球材质实现，可参考方法；本次不修改示例。三维构图、夜灯显示与地域标签存在需要提前锁定的设计歧义，因此保留本设计文档。

## Goals / Non-Goals

**Goals:** 以连续运动建立全球地域关系，并让手机观众看清城市灯光结构；所有可编辑材料与证据保存在 `videos/general/earth-night-lights/` 被忽略目录中。

**Non-Goals:** 不做昼夜交替、逐年变化或辐亮度统计，不新增通用接口、共享依赖、类型或示例。本次 propose 不执行素材下载和制作；README 的当前能力与主规格不改。

## Decisions

- **作品级场景**：使用现有 Three.js 能力构建一个连续地球场景，通过 general v8 无旁白帧数与 soundtrack 编排。相比新增类型或共享模板，作品级实现足以满足单部影片需求且不扩大项目契约。
- **真实纹理**：优先选用 NASA Black Marble 2016 全球夜间合成图，实施时核实原始下载、实际尺寸、年份、署名和使用条件，通过既有素材导入入口登记并按 ID 解析。来源入口为 https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/ 。不使用程序化灯点；来源或许可无法确认时停在素材阶段，不虚构数据或来源。
- **夜面巡游**：把夜灯作为球面自发光纹理，以统一曝光及适量辉光呈现，不设置随太阳移动的昼夜遮罩。这可让每个转向镜头的大陆都可比较；它是全球夜景合成展示，不是同时发生的全球黑夜。颜色与辉光属于视觉呈现，不输出定量亮度结论。
- **时间与方向**：0—2秒直接展示东亚及“地球之夜”标题；2—27秒按帧驱动完成自西向东360度自转，从镜头中看到亚洲、欧洲与非洲、美洲、太平洋再返回东亚；27—30秒停留收尾并显示一次署名和合成声明。起止采用平滑缓动，按世界地理坐标验证方向，避免靠贴图左右方向猜测。
- **构图与文字**：固定镜头、黑色不透明背景，地球直径约画幅宽度85%，保留完整轮廓及轻微蓝色大气辉光。标签选“亚洲、欧洲、非洲、美洲、太平洋”，绑定经纬度并作背面隐藏和遮挡避让；360×640是手机复核尺寸。字幕安全区继续保留，虽然本片无讲话字幕。
- **声音**：选择有可核验许可、无歌声的舒缓电子氛围音乐，使用现有 soundtrack 定位及淡入淡出，不新增 TTS。成片按既有有声作品目标−14 LUFS / −1 dBTP检查，音乐长度覆盖30秒。
- **制作证据**：沿用 material2video 创作流程，先比较三个叙事构图草案和两个美术方向，再生成开场、欧洲、美洲、片尾四张关键画面与完整低成本动态粗预演。优先试制接缝、密集灯区、标签遮挡及旋转方向；逐场与全片导演复核后再生成最终完整候选，验收后交付同一文件。保留全片逐页帧序列复核、自动音频分析及传播潜力报告，明确未播放和未试听的证据边界。

## Risks / Trade-offs

- [强辉光或过曝吞没城市结构] → 固定曝光，先用东亚和欧洲密集区域试制，降低辉光后复核源图结构。
- [纹理接缝、经纬翻转或地名脱离地表] → 核对多个已知地理位置，检查接缝经过正面及标签进出窗口。
- [30秒内海洋段缺少信息推进] → 粗预演检查观看节奏，以太平洋标签解释暗区，不额外虚构城市灯光。
- [合成图被误认实时或定量观测] → 片尾声明合成性质，材料记录年份和处理方式，不展示排名与数值。
- [源图或音乐许可不可用] → 阻断相关制作任务并报告；不以未经核验素材绕过资产审计。

## Migration Plan

无公共接口或数据迁移。后续仅初始化独立作品并依次 validate、prepare、按需片段 preview、render 和 QA。失败保留证据与已有有效交付，不覆盖成合格状态；本提案阶段不运行上述制作步骤。实施完成后的归档遵循仓库约定，本次不归档。
