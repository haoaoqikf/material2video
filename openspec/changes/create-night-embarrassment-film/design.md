## Context

动机与范围见 [proposal.md](proposal.md)。本次保留设计文档，因为主观聚光灯到客观空间的转译、手部动作和再次尝试的表达存在需要先解决的实现歧义。作品使用现有 general v8 本地 React 场景和受控时钟；横屏 1920×1080、30fps、目标 35 秒，无旁白，字幕沿用共享层。制作开始时重新读取现行契约，不能把其他在制变更当作已生效能力。

## Goals / Non-Goals

**Goals:**
- 观众能辨认同一次积木失误、主观注视感的解除以及主动重试，首尾同机位形成对照。
- C 夜曲的深黑蓝光池、宋体主体、低速镜头与克制辉光服务实体动作。
- 用完整动态窗口验证揭示和因果动作，按手机尺寸复核字幕与细节。

**Non-Goals:**
- 不证明所有羞耻都没有现实后果，不暗示公开冒犯或伤害他人可以忽略。
- 不新增心理学统计或未经核验的普遍性断言，不混入另两个选题。
- 不移植外部 Canvas 引擎、样片、字体或外部字幕系统。

## Decisions

### 1. 以连续空间揭示承载核心反转

采用“积木桌面—主观聚光灯—拉远看见多张桌子—回到原桌重试”的单一空间。相比切到独立围观蒙太奇，持续保留原桌位置和散落积木，能减少观众把前后看成两个现实的风险。主体使用明确桌面、积木、简化手部轮廓，不使用抽象光点替代动作。

节奏按七个事件窗口规划：0–5 秒失误；5–10 秒主观聚光灯；10–16 秒空间揭示；16–21 秒停顿与心理回放；21–27 秒检查底座并重试；27–31 秒无字幕继续搭建；31–35 秒首尾回场与结论。具体字幕与逐帧分镜在作品目录编写，随阅读速度调整窗口，保持约 35 秒和上述因果顺序。

### 2. 重试必须展示具体调整

选择底座不平这一可视原因，执行“发现—调平—放回—稳定”的动作。相比直接出现完美高塔，这个局部改善保留试错感，也不会把勇气表达为立刻成功。无字幕段保留轻微摇晃、手部修正和稳定后的停留。

### 3. 外观与实现

采用 C 夜曲登记中的近黑底 `#010104`、中央深蓝 `#0B1830`、主体白 `#F8F9F8`；冰蓝用于正常行动，玫红用于主观紧张，暖金用于发现与调整。调整后的颜色语义明确写入作品风格参考记录。实体积木保留厚度、接触阴影与遮挡，辉光仅落在强调边缘；装饰星点不抢主体。

实现选本地 TSX/SVG 代码动画，使用受控进度确定手、积木和摄影机的状态，以保证重复回放的一致性。真实素材难以保持同机位和相同积木状态，故此过程采用代码示意；不加入物理引擎依赖。手部以可读的侧面简化轮廓表现，先验证拿取和放置，必要时简化手部细节但保留接触动作。

外观采纳等级与八项指标按现有参考风格契约登记到作品 `outputs/style-reference.md`，在作品 DESIGN.md 写明来源固定提交、采用项和不借清单。共享字幕层优先，不借外部逐字字幕。代码、字体和音效来源在作品内留证。

### 4. 声音与评审

低频长音、近距离积木碰撞、空间揭示后的轻微环境声、重试落稳声构成声音推进；只使用有来源许可的声音或原创合成。声音不能成为理解反转的唯一证据。

按制作合同 v2 编排 G0–G6。失误与揭示为 A 级，其余 B/C 级服务理解。审核计划声明主体/手部可辨认的 static-expression 风险、10–16 秒主客观揭示的 structure-timing 风险、掉落与接触动作的 core-event 风险。先比较至少三种核心揭示机制（连续拉远、光域扩展、桌面阵列显影），以连续拉远为首选，经核心样片验证后扩展。

适用核心样片与全片粗片各由一名独立子代理评审，最终由未参加前期评审的新代理检查同一最终候选。只提供评审包，先盲看后同轮对照；规划阶段不启动审核。无具体证据不预设 split-final。工具环境不支持独立评审时披露降级，相关评审项保持未关闭。

## Risks / Trade-offs

- [主观注视被误读为真实全场嘲笑] → 不加入笑声、指点或嘲讽表情；连续保留原桌定位，揭示时其他人自然转回各自动作；核心冷审检查理解。
- [拉远后桌面和人物过小] → 主桌保留亮度与空间锚点，完整环境只短暂展示，随后回近景；393 宽图检查。
- [手部和积木像漂浮图标] → 验证抓握、重力加速、碰撞、接触阴影和停稳窗口，不以辉光掩盖动作。
- [心理回放被误读成再次实际掉落] → 回放保持玫红半透明残影，真实积木位置不变；如盲审仍误读，删去重复残影，保留手部停顿。
- [字幕替代画面解释] → 以去字幕样片检查失误、揭示与重试，字幕只补充主题；不添加装饰英文、小字或制作说明。
- [把继续行动讲成所有羞耻都无害] → 限定日常学习试错，使用温和且有条件的文案，结尾落在允许自己继续。
