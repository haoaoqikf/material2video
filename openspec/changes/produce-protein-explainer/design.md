## Context

动机见 [proposal.md](proposal.md)。用户已确认约 60 秒、夜曲风格、横屏、无旁白的方向。现有 general v8 与 vibe-night 足以承载本片；风格包仅提供表现组件，专属分子对象与动作仍需在作品中设计。本设计保留实现前需要验证的视觉决策，正式逐场表与唯一 v2 合同在 apply 阶段进入作品 DESIGN.md。

## Goals / Non-Goals

**Goals:** 让普通观众看懂食物提供原料、身体重新合成及蛋白质实际工作的联系；用对象追踪连接微观过程，以持续更新回答为何需要摄入。

**Non-Goals:** 不讲完整消化生理、生物化学反应路径或全部蛋白质功能；不做疾病诊断、摄入量与补剂建议；不修改共享风格、分镜版本、渲染或审核规则。

## Decisions

### 1. 夜曲的微观机制演示

使用近黑背景、冷白主体、克制冷光及结论处少量金色，遵守现有风格颜色语义；分子必须有实体形状与连接关系。主字幕按一镜一个信息单元拆句。相比寓言角色叙事，这一方式更直接呈现机制；相比深空旅程，不需要引入宇宙舞台与持续尺度巡游。

采用 1920×1080、30 fps，总目标 1800 帧；58–62 秒容差仅用于制作后节奏微调。无旁白，轻音乐铺底，连接、断开、结合事件配少量音效，声音来源须先核许可。屏幕字幕由作品按现有风格约定绘制，禁止同时引入旁白字幕层。

### 2. 以原料身份连接过程

从一枚有稳定形状与视觉标记的氨基酸追踪至新链，颜色不代表实测分子性质。消化先显示短链再显示氨基酸，避免一次爆散；合成先按顺序连接再折叠，给结果停留。追踪是教学示意，不承诺真实分子命运，不能暗示蛋白质用途由食物来源决定。省略核糖体等具体机器时，在材料记录简化边界，不画出错误合成场所。

### 3. 时间预算与事件职责

以下为制作预算，不是最终字幕稿；逐场字幕和导演卡保存在被忽略的作品目录。

| 时间 | 事件与观看职责 | 关键检验 |
|---|---|---|
| 0–6 秒 | 人体至细胞，提出用途问题 | 人体与微观切入关系可辨 |
| 6–18 秒 | 食物蛋白质拆为短链与原料，建立跟踪对象 | 拆解可见，不是整条链搬入肌肉 |
| 18–30 秒 | 原料按顺序连接、折叠成形 | 同一原料可认回，形成过程与结果完整 |
| 30–45 秒 | 三个约 5 秒窗口：结构形成、酶促反应、运输 | 每个窗口有初态、作用与结果，不以图标亮起代替 |
| 45–54 秒 | 旧蛋白质拆解、回收及外来原料补入 | 回收与补充同时成立，无“身体原料全部外来”误读 |
| 54–60 秒 | 拉回人体，回扣持续更新 | 收束有观察时间，不添加新知识分支 |

功能镜头用具体实例：纤维结构、酶结合底物后释放产物且酶保留、血红蛋白结合氧并随红细胞移动。实例准确性、形态简化与运输表达在制作时核验；不把酶画成被消耗的原料，不把红细胞与血红蛋白混为一体。

### 4. 科学来源与画面边界

主题输入使用 input.kind 为 topic，按幕登记检索关键词；不伪造源文采用记录。已有科学核查入口为 [MedlinePlus 氨基酸](https://www.medlineplus.gov/ency/article/002222.htm)、[NHGRI 蛋白质](https://www.genome.gov/genetics-glossary/Protein) 与 [NIGMS 酶](https://www.nigms.nih.gov/biobeat/2024/03/science-snippet-examining-enzymes)。apply 时重新核验并登记访问日期、具体主张、功能实例依据和简化边界；网页可用于事实核查不等于可直接复制其媒体。必要示意标记依项目小字规范执行，主字幕及对象名称保持手机可读。

### 5. 先验证高风险完整事件

初始风险为 core-event：拆解与重新合成的身份连续性，以及三种功能的因果表达。先做拆解至折叠的最小完整试制，再验证各功能窗口；一个窗口的通过不授权其他风险。若形体辨认或信息时序仍有实质未决问题，再按唯一策略登记 static-expression 或 structure-timing 并补证，不为凑轮次添加风险。

独立审核计划和人数由[审核策略](../../../.agents/skills/material2video/references/checkpoint-gates.md#审核计划与风险触发)派生；隔离按[独立评审](../../../.agents/skills/material2video/references/subagent-review.md)执行。当前预计适用核心独立评审与由新代理执行的全片终审；G5 为内部检查。风险窗可在同一核心轮分批覆盖，必须保留各自完整证据，不把评审者对代表片段的理解推广为全片通过。

### 6. 内容与共享改进分离

作品暂放 videos/general/why-protein/，project、storyboard、DESIGN、场景源码、素材与证据均不入库。发现可优化环节时在本轮修复并验证；共享修改需纳入 Git，契约变化先扩充规划，实际使用变更时同步权威文档、校验器和示例并回归。无法合理落地的优化登记项目规划或独立变更并说明原因。当前没有已确认的共享缺陷，不预设重构。

## Risks / Trade-offs

- [一分钟内容过密] → 三种功能各保留完整短事件，压缩过渡与重复解释，核心动作不靠提速塞入。
- [深色小分子在手机上丢失] → 主体占据主要构图，以实体轮廓、遮挡和亮度建立层级；检查原尺寸、852 与 393 像素宽派生证据，不用辉光掩盖形体。
- [连续追踪造成生理误读] → 跟踪只跨原料与重组教学段，避免将指定食物与指定功能直接绑定；材料说明示意边界。
- [更新与营养需要被简化过头] → 保留原料回收，并明确部分氨基酸须来自食物，不宣称所有原料每日全部替换。
- [候选通过被误当完成] → 当前版本技术与制作证据分别记录，独立评审不足时明确保持未完成。
