## Context

现有制作指导已有多方案比较、逐场验收、声音意图和独立评审。此次以增量方式明确这些环节的判断顺序和记录要点，不引入新阶段、新工具或新运行时字段。

## Goals / Non-Goals

**Goals:**

- 让参考研究聚焦可迁移的叙事与视听方法，并区分真实成片证据和静态示意。
- 让候选方案的差异体现为讲述机制。
- 让逐场事件、理解结果、镜头承接与声音作用可被评审核对。
- 限定指导只适用于后续启动的制作任务。

**Non-Goals:**

- 重做、预演或修改任何现有视频。
- 改变渲染、分镜字段、视觉强制规范、评审隔离或导出门禁。
- 规定每个镜头都须运动、配音效或使用某类美术风格。

## Decisions

- 将参考分析卡嵌入现有参考搜索与设计记录，不创建新产物类型或命令。
- 使用“叙事机制不同”作为三案差异标准，可从主体跟随、因果展开、尺度/认知反转等角度选择，题材不适用时自行设计。
- 在既有逐场表增加承接字段；声音意图继续使用现有栏位和作品声音表。
- 评审先盲看并记录所见事件与理解，再对照中性验收条件；保持现有独立评审职责。
- 在共享指导中说明新规则只应用于启动时采用新流程的后续任务，活跃任务不迁移。

## Risks / Trade-offs

- [风险] 新字段可能增加记录负担 → 只补充一列，并允许共享规则引用，避免重复抄写。
- [风险] “视觉揭示”被误读成每条作品都必须设置戏剧反转 → 将其作为候选思路，允许平静、数据驱动或无声作品采用适合自身的表达。
- [风险] 共享指导在活跃任务期间更新造成切换 → 明确生效边界为后续新任务，不要求当前作品中途采用。
