## Context

初始化器直接写入本金，金额有效性由现有材料校验负责。画面格式化和投资组合计算均读取 request 中的本金。

## Goals / Non-Goals

**Goals:** 统一初始化器与文档中的默认金额，并验证新初始化材料使用该值。

**Non-Goals:** 改变显式本金、价格材料、组合计算或画面格式规则。

## Decisions

- 只调整 `financial_video.py` 初始化模板中的默认值，并以初始化器单元测试覆盖股票和指数两种请求。这样复用现有本金字段，避免新增配置入口。
- 将金融作品本金改为 100,000 后，使用现有完整预演、手机缩放评审和正式渲染门禁重新生成视频；不改行情数据。

## Risks / Trade-offs

- `[默认值只影响新作品]` → 已有作品材料不会自动变化；本次明确更新 NVIDIA 请求并重制视频。
