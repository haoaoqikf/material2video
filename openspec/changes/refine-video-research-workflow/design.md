## Context

制作已有三个主阶段，案例拆解、组件使用和媒体证据分别有在用入口。两份旧指南通过 Skill、通用参考和阅读 JSON 同时可达。口播固定音色保存在将删除的指南中，合成依赖作品内已登记的音色，而离线文档工具负责导航与结构检查。

## Goals / Non-Goals

研究主指南负责调研顺序、最低有效产出与试制交接。技术指导分别放在具体案例与组件入口，作品仍使用原有分镜、配音配置和评审契约。

## Decisions

1. 在同一个研究阶段串起两个子阶段。实际看到的案例提供效果和试制预期，有了初步目标即可并行查组件。沿用 RESEARCH.md，避免研究与实现各写一套报告。
2. 组件入口先给出内部查找路径，遇到缺口再按 Remotion 合成、React 场景、特定开源动画等需求分流。候选都在本片真实内容下验证，避免使用库演示决定创意。
3. 删除灵感和营销号指南及旧路由。把原适用口播作品的固定默认音色移动到配音权威文档，使用作品显式配置。把当前文案、素材和剪辑规则接到相应通用入口。
4. 离线校验复用现有必需路由表与结构测试。阶段指南内只写行动和转接，详细研究步骤归专题。场景结构检查的说明改为通用设计语义边界。

## Risks / Trade-offs

- 内部实现可能只能完成部分目标。先用实际关键状态验证复用范围，对其余需求继续外查。
- 旧指南承载唯一的固定音色说明。删除时同时移动音色 ID、适用范围、用户覆盖和登记要求，核对作品级配置入口。
- 删除旧主题页可能留下失效链接和冲突义务。对活动文档、主规格、示例引用、路由校验和测试进行核查，历史归档据实保存在原位置。

## Migration Plan

完成制作指导与离线路由更新，验证新作、局部修订、内部复用和适用口播的路径。提交实施，然后同步主规格并归档。
