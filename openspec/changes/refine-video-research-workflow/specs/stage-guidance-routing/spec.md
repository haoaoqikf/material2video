## MODIFIED Requirements

### Requirement: 三阶段唯一阅读入口
阅读路由 MUST 使用 research/design/production 三个唯一主指南；研究主指南 MUST 提供优秀案例调研和成熟组件调研的顺序、输入、产出与试制衔接，并分别接入具体案例与组件选型指南。隔离评审按适用活动展开。离线校验 MUST 拒绝缺少或误指研究和两项调研路由的导航。重复阶段指南及跳转页 MUST 删除，活动链接和 JSON 示例 MUST 有效；保持渐进阅读及现有正文预算。日常主线 MUST 说明动作、输入、结果与回退；审核政策、隔离执行、工具格式各有唯一权威位置，技术协议按需读取，不跨文档复制整套规则。

#### Scenario: 读取当前阶段
- **WHEN** 开始创作、实质性视听修订或已有有效基线的局部修改
- **THEN** 入口 MUST 指向对应阶段与当前问题的研究深度，不要求递归阅读所有参考或重开无关风格选案。

#### Scenario: 研究路由丢失
- **WHEN** 导航缺少研究主入口、优秀案例调研或成熟组件调研入口，或者将其误指其他指南
- **THEN** 文档离线检查 MUST 明确失败，而不是只凭目标文件存在就通过。
