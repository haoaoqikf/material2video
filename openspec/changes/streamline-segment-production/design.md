## Context

动机见 proposal.md。用户已确认方案并要求实施。现有 production-workflow.md 管理阶段内顺序，stage-plan/stage-iterate 为短入口，explainer-design 和逐场表管理分镜表达；保持各自权威边界。

## Goals / Non-Goals

让同一段材料持续完善，减少重复试制和无关取证；不增加阶段、审核、表单或视频生成次数要求。不移除独立静态目标、核心未覆盖风险或全片检查。

## Decisions

- 在 production-workflow.md 增加完整段落试制与逐段扩展的唯一流程；阶段指南只摘要并转介，避免再建立第二套循环。
- 连续构图草图沿用 DESIGN.md 逐场表、导演卡的图或引用，说明对象尺度、认识顺序与承接，不新增固定数量或 JSON 字段。不能替代 static-expression 所需的独立目标关键帧。
- 试制兼顾开场和核心风险是减少重复的优先选择，不能用共同素材覆盖未验证风险。必要时分别试制，审核仍按计划和隔离包派生。
- 阅读、动作、结果观察可以合理重叠，按题材安排，不建立所有作品通用的停留数值。无字幕、无声或纯文字段落按原用途，不强加不存在的活动。
- lookdev 是定位预览，不直接成为 G4 合同证据；只有版本、依赖、范围、隔离、合同绑定均满足时才复用有效材料，独立目标图与盲审隔离不因复用而取消。

## Risks / Trade-offs

同段复用被理解成一个风险通过授权全片 → 明确按覆盖扩展，各段及全片仍检查。
逐段做到可交付被理解成先打磨装饰 → 先验证最难关系，核心未通过不扩展高投入实现，保留回退规则。

## Migration Plan

更新当前指导与索引，运行文档及制作契约回归，独立检查规则保全，提交后同步主规格归档；不追溯补造已有作品的试制或评审证据。
