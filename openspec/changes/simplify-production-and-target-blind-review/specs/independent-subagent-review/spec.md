## MODIFIED Requirements

### Requirement: A/B 级评审必须由独立子代理执行

以下 A 级职责 MUST 由独立子代理覆盖，但不要求每项单独调用：冷观众/前 3 秒、文案复述关、三个叙事候选淘汰、两个美术方向比较、风格同族判定、逐场观察复述、第一次与第二次导演审查、扩展全片前核心表达复述、重要返工匿名比较和实质争议独立复核。

以下 B 级职责可分栏合并在阶段报告，MUST 由独立子代理量取或复核：传播潜力反面依据、画面可见文案清单核对、手机尺寸可读性、节奏与等待判断、风格八项指标量取。

独立子代理 MUST 使用新建上下文，MUST NOT 使用继承制作上下文的 fork；MUST 只读取评审包，MUST NOT 读取 `DESIGN.md`、风格契约、分镜、场景源码、旧评审结论与制作理由；盲看阶段 MUST NOT 接收验收条件，观察落盘后仅可提供中性可观察条件以核对原问题。制作助手 MUST NOT 代替子代理撰写观察或判定。

#### Scenario: A 级完成
- **WHEN** 冷观众评审使用新建上下文，只读取前 3 秒评审包，报告由子代理写出
- **THEN** 该评审可记为「已独立评审」，结论可作为阶段证据

#### Scenario: 同一助手切换角色
- **WHEN** 制作助手在同一会话里换一个角色提示后写「独立子代理已通过」
- **THEN** 只能记为「角色分离自审」，不得关闭评审项

#### Scenario: 子代理读取设计文档
- **WHEN** 评审包或任务书包含 `DESIGN.md`、风格契约或旧结论
- **THEN** 该评审无效，重新打包并分配新评审 ID

### Requirement: 评审包必须隔离设计信息并匿名化

评审包 MUST 固定放在 `outputs/review-pack/<review-id>/`，包含 `manifest`、证据文件、中性任务书与空白判定表。`manifest` MUST 记录评审 ID、级别、环节、时间码、显示尺寸、证据文件 SHA-256 与被排除文件。

评审包 MUST NOT 包含设计文档、分镜、场景源码、预期答案、旧评审结论、作者与轮次信息、匿名映射 key。验收条件 MUST 在盲看观察保存后单独提供，不含设计理由；共用证据 MUST 只读、绑定摘要，匿名任务仅暴露中性索引和净化后的证据，MUST NOT 暴露映射与主记录。候选比较 MUST 匿名并使用随机顺序；映射 key MUST 放在评审包外，评审完成后才可打开。

#### Scenario: 候选比较匿名
- **WHEN** 比较三个叙事候选
- **THEN** 候选标为 A/B/C 并随机排序，评审者看不到作者、轮次与采用偏好

#### Scenario: 缺少 manifest
- **WHEN** 评审包没有 manifest 或没有证据摘要
- **THEN** 评审不能作为阶段证据

#### Scenario: 污染检查失败
- **WHEN** 目录中出现作者、方向名、推荐标记或映射 key
- **THEN** 重新打包，旧评审作废，不得局部修补后继续使用

### Requirement: 评审结果必须写入 visual-notes 并绑定版本

评审结论 MUST 写入作品 `outputs/visual-notes.md` 的「独立评审记录」区块，包含评审 ID、环节、级别、执行方式、评审者、投喂文件、隔离条件、结论、差异项与时间。发现问题 MUST 进入原有问题表。

记录 MUST 绑定准备指纹、成片或候选 SHA-256、评审包 manifest SHA-256 与报告 SHA-256；依赖变化后相关结论失效；未受影响观察仅可附依赖证明与旧版本来源后引用，不得伪装新版本实查。最终全片结论 MUST 重新绑定当前交付文件与完整检查。`visual-notes.md` MUST 直接链接评审报告与需要保留的证据文件。

#### Scenario: 报告未链接
- **WHEN** 记录只写结论，没有链接评审包与报告
- **THEN** 阶段未完成

#### Scenario: 版本变化
- **WHEN** 准备指纹或成片摘要变化
- **THEN** 复查受影响范围，未变观察可证明依赖后引用，最终全片检查仍须绑定当前文件
