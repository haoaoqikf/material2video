## Context

金融画面由共享 React composition 按帧渲染，投资金额已由最近实际收盘点推导。现有组件使用多行标题、独立英文金额格式化函数和左侧收益行；安全区边界量测在 SVG 文本上执行。

## Goals / Non-Goals

**Goals:** 单行自适应标题、原币中文金额格式、靠右的实际收盘日指标组，以及底部一行风险提示。

**Non-Goals:** 不增加外汇数据或币种转换，不调整投资价值计算、价格材料 schema、图表动画或真实行情。

## Decisions

- 使用一套中文数量级格式化逻辑，按数值大小选择万、亿、万亿，并追加标的原币中文名称；低于一万仍显示币种，避免纯数字产生单位歧义。
- 投入本金标题复用数量级转换但省略币种；标题测量后按安全区宽度缩放，单行宽度铺满标题行。
- 指标日期取当前已揭示序列中的 `latest.date`，指标组右对齐，避免休市日显示尚无对应收盘价的日期。
- 风险提示使用指定文案，放在来源与统计口径下方的单行小字区域，并参与现有 SVG 安全区边界校验。

## Risks / Trade-offs

- 原币数量级在不同币种间不能直接比较；画面同时保留币种名称，不引入未经指定的汇率转换。
- 极长标的名称可能要求较小标题字号；通过安全区量测和长标题测试保证内容不换行、不裁切。
- 底部新增一行会压缩注释区余量；保留说明容量校验并验证免责声明处于手机安全区。
