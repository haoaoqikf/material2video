## MODIFIED Requirements

### Requirement: 独立媒体契约与显式周期
系统 MUST 提供 review start/pack/import/timeline、自动派生对照与结构化报告模板，拒绝旧检查点合同和旧报告；周期、请求、报告、包 MUST 使用 v4；请求 MUST 指定 keyframe 或 process 用途，旧历史保留不迁移且不能授权当前通过；当前 v4 周期有开放必改或损坏历史 MUST 拒绝重开。历史升级 MUST 核对工作流、原周期身份和历史问题，承接未解决的必改，不接受篡改或未知版本。关键帧只展示静态图像，过程只展示完整视频窗口。过程默认直接独立目标对照；例外盲审 MUST 提供具体风险依据。试制包 MUST 不依赖 DESIGN.md、prepared 或全片分镜；本地媒体、来源依赖和观察窗口须摘要绑定。全片播放器 MUST 使用有效准备材料且无视觉门前置。

#### Scenario: 局部试制
- **WHEN** 只有代表性关键帧或核心片段
- **THEN** 可以建立隔离试制包；修改相关依赖使其过期，无关场景不无故使其过期。

### Requirement: 当前候选与完整证据

整片复核记录 MUST 绑定当前完整候选摘要、准备指纹和有效技术 QA，并记录总代理实际看听及高风险回看结论。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列、帧差/场景切分与适用主体区域量测；声音 MUST 有响度、真峰值、静音、起音、频谱与同步等信号量测；不要求播放或试听。评审结论 MUST 引用具体帧号、时间窗和量测值；适用运动、转场或声音目标的关键指标/证据缺失 MUST 记 insufficient，不达预期 MUST 记 fail。静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。trial 完整观察等价复用仅允许旧来源文件当前内容不同，不得忽略封存请求、原来源摘要记录、包 manifest、全部包内观察媒体与参考、条件、报告、调用及账本身份的完整性；任何封存证据缺失或改写 MUST 拒绝。复用授权当前媒体的视觉结论，不恢复旧技术绑定的有效性。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 终审候选变化
- **WHEN** 旧独立终审的候选由新流程的当前候选取代
- **THEN** 原终审结论和引用保留为历史，不能授权新流程完成，尚未解决的必改继续跟踪。

#### Scenario: 当前候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得直接授权新片；无关试制证据按实际依赖保留。可通过完整观察等价收据另行授权当前有效采集。候选变化 MUST 重新完成总代理整片复核。

#### Scenario: 历史封存损坏
- **WHEN** 旧来源当前内容改变但封存身份完整，或封存请求、报告、包内文件任一损坏
- **THEN** 前者可继续核验显式 trial 复用，其当前技术绑定仍失效；后者 MUST 拒绝复用，不以旧来源变化为由跳过历史完整性验证。

#### Scenario: 帧与信号评审
- **WHEN** 待审关键样片只有有序帧、完整解码和音频信号量测可供评审
- **THEN** 评审 MUST 据此核对状态切换、转场、静止窗口、主体量测与声音事件，按设计指标给出结论；MUST NOT 因缺少播放或试听把该范围判为未验证。

### Requirement: 目标参考与可观察特征配套对照
评审请求提供非空 references 时 MUST 同时提供非空 conditions 描述中性可观察目标；缺失或空目标条件 MUST 在创建评审包之前明确拒绝。目标媒体与条件 MUST 在盲包外摘要绑定，在关键帧或适用过程盲看导入后的同轮对照包中才展示；过程直接对照包 MUST 提供实际参考及中性条件，MUST NOT 伪造盲报告身份；中性条件无参考媒体时仍允许用于事实和表达核对。独立对照 MUST 观察实际目标效果与差距，理解、可读性或技术无错不能替代表现与代表性判断。工具只校验材料与记录完整性，不自动评判风格研究、审美或阶段完成。

#### Scenario: 只有参考媒体
- **WHEN** 请求带有参考媒体但缺少或清空中性采用特征
- **THEN** 请求 MUST 明确失败且不创建媒体包，不把任何图片当成没有范围的默认审美标准。

#### Scenario: 有参考的同轮对照
- **WHEN** 请求同时提供目标媒体和中性采用特征
- **THEN** 盲包 MUST 不泄露目标或特征，对照包 MUST 包含实际净化目标媒体和原条件，并要求观察兑现情况及具体差距。

#### Scenario: 事实条件没有风格参考
- **WHEN** 请求只有中性事实条件而没有参考媒体
- **THEN** 仍可进行同轮事实对照，但助手不得据此声称已验证未提供的风格目标。

#### Scenario: 盲看后追加目标
- **WHEN** 对照请求向原本未登记参考的盲看请求追加目标媒体
- **THEN** 工具 MUST 拒绝绑定不同的同轮对照，助手需重新建立适用盲看与对照，不修改旧包或旧报告。

### Requirement: 用户明确变更目标的登记与重新评审
系统 MUST 提供 `review retarget --file`，在当前周期保存 source=user 的用户原指令、指定独立失败身份和当前有效新盲包目标的不可改写摘要收据。登记 MUST 保留旧周期、问题范围与失败结论，只替换指定问题后续复查使用的参考媒体和中性条件；不自动关闭问题。目标登记 MUST 保持来源、场景、观察项身份与窗口覆盖。助手 MUST 仅在用户明确允许改目标时使用，工具不声称能认证自然语言授权。

#### Scenario: 用户明确重选视觉基准
- **WHEN** 用户明确允许更换基准，新的封存盲包覆盖相同职责、显示尺寸、来源与原窗口
- **THEN** 系统 MUST 登记新目标，保留旧失败；只有变更登记后的当前独立盲看和适用同轮对照通过才能关闭指定问题。

#### Scenario: 无有效授权或缩小复查范围
- **WHEN** 缺少用户指令声明、报告不是当前周期的独立失败、新包过期、目标没有变化或新包缩小结构范围
- **THEN** 系统 MUST 拒绝登记，不改问题和历史。

#### Scenario: 变更记录失效或借用原通过
- **WHEN** 记录摘要损坏、跨周期，或者关闭依据早于目标变更
- **THEN** 系统 MUST 拒绝授权关闭；未登记的问题 MUST 继续按原目标严格匹配。

### Requirement: 完整观察相同的视觉结论复用
系统 MUST 允许将历史 trial 独立视觉结论显式绑定到重新验证的当前媒体，同时保留原报告身份、导入与观察时间，不冒充新独立调用。复用 MUST 验证完整源媒体文件字节摘要、全部观察窗口、帧率、显示尺寸、职责、条件及参考均相同，包括视频完整容器及适用音轨；不同编码或容器即使近似相同也 MUST 拒绝。当前采集来源、数据、许可、运行及产物绑定 MUST 单独有效。等价证明 MUST 可追溯并能失效，不能用单帧、缩略图或作者声明替代完整等价。复用 MUST 限于同一周期和同一用途，整片复核须由总代理对当前完整候选实际完成。关闭失败 MUST 使用原报告导入与原调用时间核验晚于原失败及适用 retarget，收据登记时间不得替代。

#### Scenario: 源码变化但观察媒体完全相同
- **WHEN** 当前技术绑定有效，全部观察媒体及目标相同且无未解决的相反结论
- **THEN** 系统 MUST 允许复用原独立视觉结论，重新核验技术证据，原报告本身仍保留原来源绑定。

#### Scenario: 新运动或目标变化
- **WHEN** 任一观察帧、时间、声音覆盖、目标、窗口或显示条件改变
- **THEN** 系统 MUST 拒绝等价复用，要求受影响范围的新独立观察；静态通过不得授权新运动。

#### Scenario: 相同媒体存在相反结论
- **WHEN** 同目标相同媒体已有未解决的独立 pass 与 fail
- **THEN** 系统 MUST 拒绝自动挑选 pass；保留冲突。只有关联 fail 按既有独立关闭规则由晚于失败的新代理实质争议复查关闭，或真实用户变更目标后完成登记及新独立复查关闭，才视为解决；关闭证据失效 MUST 重新阻断，单纯追加 pass 不算解决。

#### Scenario: 收据不能刷新观察时间
- **WHEN** 旧 pass 早于新 fail 或适用 retarget，之后才登记复用收据
- **THEN** 系统 MUST 拒绝用该旧 pass 关闭问题。

## ADDED Requirements

### Requirement: 正式窗口与合成证据
系统 MUST 支持登记实际时间轴上的必审样片窗口，并复用当前正式合成的局部预演或完整候选取证。报告 MUST 可核对窗口身份、实际帧窗和来源。早期原生样品可先验证机制，正式结论须验证实际合成和适用的字幕、转场与音轨。关键帧 MUST 审真实合成图像中的字号、断行、层级、位置、小屏和明暗背景可读性。关键样片 MUST 审实际字幕同步、停留、换句、切镜与运动中的遮挡和对比。无字幕时按实际机制评审。

#### Scenario: 正式样片覆盖不足
- **WHEN** 只通过一个必审窗口，其他窗口缺证，或证据窗口、目标、有关来源已经变动
- **THEN** 系统 MUST 将相应窗口记为缺失或过期。未受影响的有效窗口保持覆盖。

#### Scenario: 真实合成
- **WHEN** 正式窗口取自已合成预演或候选
- **THEN** 工具 MUST 校验来源摘要与时间映射，使用实际合成画面和适用音轨。关键帧评审只接收静态证据。
