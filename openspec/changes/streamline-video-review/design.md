## Context

现有隔离评审、实际媒体摘要、失败闭环、局部预演和成片 QA 均可复用。当前整片 QA 验证位于独立终审的绑定函数中，完成状态通过终审分工投影。作品运行时负责合成，主项目负责制作证据。

## Goals / Non-Goals

用同一个制作周期关联关键帧、需要的样片窗口和当前候选交付检查。沿用现有分镜、字幕合成、技术 QA 与隔离证据格式的主体结构。

## Decisions

1. 用当前准备记录的整数总帧数和帧率判定时长。研究用目标时长规划，待准备后定案。30 秒及以下的动态风险由总代理在整片复核中回看。
2. 必审动态窗口由制作方按具体问题登记，使用中性 ID、成片半开帧窗与验证目标。工具核对窗口清单和有效报告覆盖，选窗合理性由总代理核对，代表性由独立观察确认。多个窗口可分包复查。
3. 沿用原生采集制作前的设计验证。正式样片可从已合成的局部预演或候选取证，绑定视频旁车、源文件摘要及对应时间轴。必要字幕证据必须来自实际合成。跟踪局部窗口涉及的场景、切换、字幕和声音输入。仅局部变化时复用有效的其他窗口，来源或观察范围不明时重新采证。
4. 总代理看听整片并复查高风险窗口后，在现有账本确认，绑定当前完整候选的文件摘要、准备指纹和通过的 QA。状态独立投影确认是否有效。技术导出不受视觉记录阻断。
5. 评审协议 v4 保留 keyframe 与 process。删除 final 打包、导入、分工和资格判断。旧周期原件保留供历史追溯，旧报告不授权当前版本。当前待跟进的历史必改应有明确承接和对应实际复查证据。
6. 评审策略集中维护职责。总设计写字幕共同规则，场景文档在已有四问记录字幕让位、阅读窗口和与动作的配合。实际参数及时间仍保存在原配置与准备记录。

## Risks / Trade-offs

- 仅抽查局部容易遗漏整片节奏与字幕问题。总代理须按正常速度看听全片，再回看高风险位置。
- 缩小、替换窗口可能丢掉失败。保留稳定中性 ID 和原记录，独立问题仍须按对应范围复查。
- 预演局部合成与最终编码会有差别。复用已绑定的实际窗口，当前正式成片另做 QA 和整片复核。

## Migration Plan

显式开启新版周期。历史材料保持原字节，证据不得冒充新版通过。未解决的历史问题纳入新周期跟进并保留原报告引用。
