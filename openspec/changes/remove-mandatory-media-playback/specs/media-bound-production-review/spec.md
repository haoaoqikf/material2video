## MODIFIED Requirements

### Requirement: 当前候选与完整证据

整片复核记录 MUST 绑定当前完整候选摘要、准备指纹和有效技术 QA，并记录总代理用当前候选的抽帧、有序帧、适用信号和时间轴证据得出的全片结论及高风险窗口。制作全程 MUST NOT 要求播放视频观看或实际试听。动态观察 MUST 有完整可解码过程片段、有序时间码帧序列、帧差/场景切分与适用主体区域量测；声音 MUST 有响度、真峰值、静音、起音、频谱与同步等信号量测；不要求播放或试听。评审结论 MUST 引用具体帧号、时间窗和量测值；适用运动、转场或声音目标的关键指标/证据缺失 MUST 记 insufficient，不达预期 MUST 记 fail。静态可按实际范围观察。包外路径、摘要失配、范围不足和无效独立调用 MUST 拒绝。独立报告须具体区分理解、表现与代表性，不能用占位授权正式效果。trial 完整观察等价复用仅允许旧来源文件当前内容不同，不得忽略封存请求、原来源摘要记录、包 manifest、全部包内观察媒体与参考、条件、报告、调用及账本身份的完整性；任何封存证据缺失或改写 MUST 拒绝。复用授权当前媒体的视觉结论，不恢复旧技术绑定的有效性。 指标与量测 MUST 按实际采用机制选择，不强制静态、无声或直接切换填写无关指标。

#### Scenario: 终审候选变化
- **WHEN** 旧独立终审的候选由新流程的当前候选取代
- **THEN** 原终审结论和引用保留为历史，不能授权新流程完成，尚未解决的必改继续跟踪。

#### Scenario: 当前候选变化
- **WHEN** 源码、媒体、准备材料或候选变化
- **THEN** 受影响报告失效，旧通过不得直接授权新片；无关试制证据按实际依赖保留。可通过完整观察等价收据另行授权当前有效采集。候选变化 MUST 重新完成总代理整片复核。

#### Scenario: 历史封存损坏
- **WHEN** 旧来源当前内容改变但封存身份完整，或封存请求、报告、包内文件任一损坏
- **THEN** 前者可继续核验显式 trial 复用，其当前技术绑定仍失效；后者 MUST 拒绝复用，不以旧来源变化为由跳过历史完整性验证。

#### Scenario: 帧与信号评审
- **WHEN** 待审关键样片只有有序帧、完整解码和音频信号量测可供评审
- **THEN** 评审 MUST 据此核对状态切换、转场、静止窗口、主体量测与声音事件，按设计指标给出结论；MUST NOT 因缺少播放或试听把该范围判为未验证。

### Requirement: 完整观察相同的视觉结论复用
系统 MUST 允许将历史 trial 独立视觉结论显式绑定到重新验证的当前媒体，同时保留原报告身份、导入与观察时间，不冒充新独立调用。复用 MUST 验证完整源媒体文件字节摘要、全部观察窗口、帧率、显示尺寸、职责、条件及参考均相同，包括视频完整容器及适用音轨；不同编码或容器即使近似相同也 MUST 拒绝。当前采集来源、数据、许可、运行及产物绑定 MUST 单独有效。等价证明 MUST 可追溯并能失效，不能用单帧、缩略图或作者声明替代完整等价。复用 MUST 限于同一周期和同一用途，整片证据复核须由总代理从当前完整候选取证并完成。关闭失败 MUST 使用原报告导入与原调用时间核验晚于原失败及适用 retarget，收据登记时间不得替代。

#### Scenario: 源码变化但观察媒体完全相同
- **WHEN** 当前技术绑定有效，全部观察媒体及目标相同且无未解决的相反结论
- **THEN** 系统 MUST 允许复用原独立视觉结论，重新核验技术证据，原报告本身仍保留原来源绑定。

#### Scenario: 新运动或目标变化
- **WHEN** 任一观察帧、时间、声音覆盖、目标、窗口或显示条件改变
- **THEN** 系统 MUST 拒绝等价复用，要求受影响范围的新独立观察；静态通过不得授权新运动。

#### Scenario: 相同媒体存在相反结论
- **WHEN** 同目标相同媒体已有未解决的独立 pass 与 fail
- **THEN** 系统 MUST 拒绝自动挑选 pass；保留冲突。只有关联 fail 按既有独立关闭规则由晚于失败的新代理实质争议复查关闭，或真实用户变更目标后完成登记及新独立复查关闭，才视为解决；关闭证据失效 MUST 重新阻断，单纯追加 pass 不算解决。

#### Scenario: 收据不能刷新观察时间
- **WHEN** 旧 pass 早于新 fail 或适用 retarget，之后才登记复用收据
- **THEN** 系统 MUST 拒绝用该旧 pass 关闭问题。
