## Context

动机见 [proposal.md](proposal.md)。现有共享底座提供类型注册、准备、采集、编码与溯源，前端具备三维和后期依赖。建筑首例尚未建模或试渲染；本设计不把技术可行性等同于制作通过。设计涉及新材料及跨模块接入，因此保留独立设计文档。

## Goals / Non-Goals

**Goals:** 一套稳定部件模型贯穿各阶段；用独立材料表达建筑与时间；先验证基础和结构的核心动态，再扩展完整住宅。

**Non-Goals:** 不整体模拟施工现场，不读取 BIM/CAD，不提供承载力或施工安全结论，不另建渲染引擎，不依赖尚未实施的汽车展示类型。

## Decisions

### 1. 类型与渲染边界

新增 building-construction 适配器和专用 composition，通过目录注册接入统一入口；复用现有 React/R3F、采集、编码与音轨基础设施。相较于仅做 general 作品，独立类型能校验部件和施工阶段；相较于 Blender，当前底座便于稳定按帧求值且无需第二套生产链路。共享层不导入建筑业务；若需提取已有采集能力，保持依赖方向，不直接引用 general 私有模块。

### 2. 程序化部件模型

首例采用规则轴网的两层钢筋混凝土框架住宅：简化独立基础及基础梁、柱、梁、楼板、楼梯、填充墙、轻型坡屋顶、门窗与庭院。基础形式和屋顶支承关系在制作前依据可靠资料核对，仅说明构成，不做工程适用性判断。

采用米制右手坐标，前端 y 轴向上；部件具有稳定 ID、类别、楼层、最终变换、几何尺寸、材质和阶段。相同参数重复生成保留相同 ID，不依赖数组下标。墙体按门窗洞口拆成实体块，避免用门窗覆盖整墙；柱梁、楼板、楼梯和屋顶应有可核对的支承位置。

选择程序生成而非购买房屋外壳，便于获得地下与内部结构并控制动画分组。首版生成器只覆盖该两层框架住宅族，尺寸参数在声明的有效范围内可调，不声称任意建筑自动生成。

### 3. 材料与动画契约

作品包含 project.json、building.json、construction.json 和 assets/manifest.json，后三者均明确版本 1。building 定义轴网、层高、构件、开口及材质；construction 定义总帧数、阶段、先后依赖、部件 ID 引用、动画、镜头和可选声音；清单登记外部资源路径、来源、作者、许可和摘要，纯程序材质时允许空清单。具体字段由实施中的校验器、模板和文档同步固定。

全部区间使用全片帧号、左闭右开；镜头覆盖全片且不重叠。每个必建构件有且仅有一个建成事件，饰面与显隐是独立效果轨道，不覆盖建成状态。同一构件同一属性轨道不能冲突。施工依赖构成无环图：依赖构件建成后方可开始被依赖动作；首例进一步核对基础到柱梁、楼板、围护与安装的关系。

每帧直接计算部件最终变换和阶段进度，支持落位、铺展、分段显现与饰面完成。落位和生长表达组装示意，不描绘混凝土预制或浇筑事实；局部显现保持结果几何不变。镜头隐藏墙体只改变取景可见性，不回退完成状态；完工视图恢复全部应见部件。禁止依赖上一帧、真实时钟或非固定随机数。

### 4. 首例导演方案

40 秒、1920×1080、30 fps、1200 帧；精致建筑沙盘，暖白墙面、混凝土结构、木色装饰，简洁背景。正常画面仅按需显示阶段名称；必要的“建造过程示意”边界标记遵循现有小字规范，不增加制作说明。无旁白，音效可选；无声明时无音轨。

| 时间 | 画面与镜头 |
| --- | --- |
| 0–4 秒 | 空地斜俯视推近，基坑局部打开 |
| 4–10 秒 | 基础与基础梁形成，剖开场地展示地下连接 |
| 10–16 秒 | 一层柱梁楼板依次搭建，保留结果观察窗口 |
| 16–22 秒 | 二层结构与楼梯完成，镜头升高展示上下连接 |
| 22–29 秒 | 墙体分段形成，洞口保留，屋顶落位 |
| 29–34 秒 | 门窗安装、饰面完成 |
| 34–40 秒 | 回填/庭院完成，恢复整体外观并环绕收束 |

此表为表达阶段，并非完整工程进度表；会遮蔽地下构件的地面恢复为取景设计，不据此暗示实际回填时点。制作前以来源记录核对工序简化，正文材料说明省略范围。先制作“基础 → 一层框架 → 墙体”的代表片段，实际观察完成动作、支承关系和停留时间后再扩展。

### 5. 校验、准备与制作证据

校验正尺寸、层高与开口合法性、ID 唯一性、引用存在性、依赖无环和时序、轨道边界/冲突、镜头覆盖及资产完整性。不以静态校验承诺工程正确性或消除所有三维穿插；结合几何关系测试与实际画面复核。

prepare 将材料、生成器、前端实现、外部素材和声音绑定指纹，产出可离线渲染的清单；模型、纹理和着色器预热就绪才采集。取样验证重复和顺逆序同帧 PSNR ≥ 60 dB。输出检查帧数、尺寸、帧率、时长和音轨，记录硬件、画质、采集耗时和摘要，不预设性能承诺。

制作记录与评审通过注册接入现有机制，不将 general 私有工具直接当作新类型已支持。风险、人数与轮次只引用 [审核策略](../../../.agents/skills/material2video/references/checkpoint-gates.md#审核计划与风险触发)；隔离按 [独立子代理评审](../../../.agents/skills/material2video/references/subagent-review.md)，观感按 [视觉复核](../../../.agents/skills/material2video/references/visual-review-rubric.md)。阶段理解和部件组装的核心未决风险应如实登记并在扩展前评审，终审绑定当前完整候选。技术导出不新增人工硬门禁，但缺少适用独立证据不得宣布制作完成。

## Risks / Trade-offs

- 简化结构或工序产生误解 → 制作前核对来源，标明示意边界与省略内容；不能用模型自动校验代替事实核对。
- 构件相交、悬空、洞口封死 → 最终几何关系测试、边界帧和动态片段实看；区分正常结构连接与错误穿插。
- 外墙/地面遮挡关键结构 → 按阶段控制剖开和可见性，镜头取景后再封闭，不改变建筑身份或已建状态。
- 参数组合无效 → 明确首版住宅族和参数边界，不静默接受任意造型。
- 后期和部件数量影响采集 → 先短样片量测，再优化共享材质与实例化；不可用降低关键可见性换速度。
- 新类型影响现有底座 → 测试已有类型与资源缓存边界，不修改它们的材料契约。

## Migration Plan

新增类型，不迁移既有作品、不维护旧建筑材料版本。实施先建立契约和最小可见模型，再通过代表片段验证并完成统一链路与全片；结果不成立时回退设计，不批量扩展。内容存放忽略的类型目录或外部内容根，媒体不入库；必要规范模板不新增风格示例。实施验证提交后按项目约定归档，本轮不实施、不归档。
