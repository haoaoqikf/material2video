## Context

动机见 [proposal.md](proposal.md)，行为契约见 [增量规格](specs/article-explainer/spec.md)。当前示例为65秒无声三维场景；本轮用户已批准30秒二维剪纸方案，因此直接采用，不重新发起选案。风格、声音与终幕关系均有变化，需要先固定实现与验收边界。

## Goals / Non-Goals

**Goals:** 用清晰的实体轮廓、少量图形变化和三个重点动作兑现画面，建立可在手机尺寸辨认的30秒样例；所有状态由录制帧推导，可重复生成。

**Non-Goals:** 不重建三维世界，不做全片一镜到底、复杂角色绑定、真实物理模拟、生成视频或新引擎；不增加旁白，不新增示例目录，不把本片风格升级为所有general作品的强制规范。

## Decisions

### 1. 原生二维图形承担剪纸视觉

复用general v8本地React场景，用SVG实体轮廓、少量层叠阴影与纸张色块呈现人物、门、桥、积木和书。统一人物比例、地面高度与强调色，避免细线网格、霓虹、空心线稿和装饰粒子。采用矢量而非生成图片，便于精确折叠、接合及资产复用；采用二维而非继续三维，减少材质、透视和灯光调试。

暖白、深墨色与偏暖橙色作为初始美术方案；正式色值通过独立目标关键帧确定。阴影只用于纸片层次，主体须有清楚接地关系。关键帧独立于动画源码制作，不用场景截图充当目标图。

### 2. 七段固定预算，剪辑承担连接

| 时间 / 帧区间（左闭右开） | 可见事件 | 主文案 |
|---|---|---|
| 0–3 / 0–90 | 两个相同人物同起点并肩出发 | 同样的起点 |
| 3–8 / 90–240 | 街区出口条件不同，主角选门并穿过 | 城市，改变机会 |
| 8–13 / 240–390 | 两人步行动作相同，一侧道路传送造成位移差 | 行业，改变速度 |
| 13–18 / 390–540 | 两人各持桥的一部分，接合后共同通过 | 伴侣，影响方向 |
| 18–23 / 540–690 | 留下一块积木，时间经过，积木逐层形成稳定台阶 | 投资，积累未来 |
| 23–27 / 690–810 | 障碍前展开书页为阶梯，同一人物踏上并通过 | 学习，打开可能 |
| 27–30 / 810–900 | 五段道路剪影依次闪回，定格人物向前 | 每次选择，都在塑造以后 |

每段仅一个主动作，动作完成后争取约1秒观察结果；学习段建议0.5秒建立障碍、1.5秒展开、1秒通过、1秒观察。行业同速仅指相对道路的行走动作一致，不声称屏幕位移相同。投资用日夜明暗等简洁时间线索区别即时魔法增长，不引入收益率或真实时间刻度。

段间用人物出入画、道路横移或直接切换，横移须有明确方向。采用多个本地代码场景或单入口内部时间段均可，实施按复用成本选择；分镜总预算必须900帧。结尾只回收已有形象，不增加巨大地图。片名用于材料标题，画面不额外叠加片头。

### 3. 音乐与动作音走现有素材链

无旁白，轻节奏器乐覆盖全片并做短淡入淡出，开门、桥板落位、翻书各一个重点动作音。优先使用许可明确且可恢复的音频，记录来源、许可、摘要与时长，按现有素材ID及音轨契约接入；不绕过素材登记直接引用本机路径。外部示例媒体放入忽略的 `assets/media/`，通过 `assets/recipe.json` 和 `assets/fetch.py` 恢复，不随Git提交。优先无强制片尾署名的许可；如许可要求署名，仅在片尾集中一份简短署名，不增加时长。无法取得可合法恢复素材时报告阻塞，不擅自交付静音版。

### 4. 用短循环约束执行质量

保留旧片及摘要作为本地对照。先做七张独立目标关键帧和集合检查，分别评价关系理解、构图、层次、主体尺度与记忆点；再试制学习段完整4秒，通过书到阶梯的形变、人物身份和通过动作验证后扩展全片。开门、桥板接合与书变阶梯是重点，其余段落以清晰、节制形成节奏差异。用户方案已明确，机制比较只在具体执行风险需要时局部进行，不重开整片三案。

A/B级评审按项目要求由独立子代理只读取中性评审包；方案理由、章节预期答案与旧结论不投喂。先记录盲看观察，再核对独立提供的中性条件。最终由两名隔离代理分别复核结构节奏与视觉文案。相同显示尺寸比较新旧对应事件，并记录两版时长、声音与美术不同，避免虚称单变量改善。

### 5. 复用契约，改进只解决本轮实际问题

不修改v8格式或共享渲染行为。实施中发现的可复用问题在本轮修复并验证，若涉及共享契约，再同步Skill参考文档、校验器、适用示例和本变更任务；超范围事项记录原因。删除退役三维实现及其专属断言，补充有意义的900帧、五段顺序、声音配置和关键动作状态检查，不通过断言源码字符串替代视觉复核。

## Risks / Trade-offs

- [书到阶梯的变化像突然替换图标] → 保留共同折痕与轮廓，先验证4秒窗口，必要时简化折叠层数。
- [30秒内动作与读字竞争] → 文案采用已批准短句、较早出现并稳定停留；全片852及393宽复核，文案不遮主动作。
- [投资累积被读成稳赚承诺] → 仅使用抽象积木与时间线索，不出现收益数据、排名或必然成功文案。
- [五段剪纸仅换标签] → 门的开合、道路传送、双人接桥、积木累积、书页折叠采用不同动作机制，集合检查关注重复。
- [风格简洁却显得粗糙] → 通过独立目标帧确定轮廓、层次、留白和接地关系，理解正确不能替代美术完成。

## Migration Plan

先保全旧交付文件、准备指纹与证据索引于本地基线，再原位替换材料与源码；不提供旧版适配或迁移入口。更新示例README、DESIGN、SOURCES、VERIFICATION与根README当前示例描述，保持其他两个示例不回归。验证通过并审查暂存后提交实施；任务全部完成后同步主规格、自动归档并另行提交。若实施失败保持变更未完成，必要时通过Git恢复本轮改动，不覆盖用户其他修改。
