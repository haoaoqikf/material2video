## MODIFIED Requirements

### Requirement: 免费数据与价格口径
流程 MUST 使用无需账号或付费密钥的公开免费来源和交易日日线收盘数据。股票默认 MUST 采用仅拆股、合股调整且不计分红再投资的价格；指数 MUST 使用来源明确的官方点位并标明指数类型。流程 MUST 区分前复权、后复权、含分红调整收盘价与仅拆合股调整价，不得静默混用。价格材料 MUST 使用 schemaVersion 3，日线点只包含 date 和 close。请求 MUST 记录投资年份和正数本金；缺省投资年份为实际展示范围首年，缺省本金为 100,000 标的计价单位。投资年份 MUST 在展示范围内且必须存在至少一个真实交易日收盘价。

#### Scenario: 可获得可靠的拆合股调整数据
- **WHEN** 来源提供符合口径的价格，或原始收盘价及拆合股资料足以可靠推导
- **THEN** 流程记录调整定义和推导依据，并将真实收盘价作为组合市值计算依据

#### Scenario: 只有不符口径的调整数据
- **WHEN** 来源只有含分红调整价、定义不明的 adjusted close 或其他不符口径序列
- **THEN** 流程说明差异并请求用户选择替代口径，未确认前不继续制作

#### Scenario: 指数数据
- **WHEN** 用户指定指数且其序列与发布机构定义可核对
- **THEN** 画面以指数点位比例模拟价值，并在统计口径中说明指数不能直接持有

#### Scenario: 投资参数缺省或无效
- **WHEN** 请求未声明投资参数，或投资年份、本金无效及该年没有有效交易日
- **THEN** 未声明时采用展示范围首年和 100,000 计价单位；无效设置则指出字段并阻断材料校验

#### Scenario: 用户指定本金
- **WHEN** 请求明确提供正数本金
- **THEN** 材料保留用户指定金额

#### Scenario: v6 动画计划生效
- **WHEN** 制作仍使用 v6 折线计划
- **THEN** 阻断并提示显式备份迁移到 v7，再重新完成完整候选自动验收

#### Scenario: v7 动画计划生效
- **WHEN** 制作使用 v3 价格和 v7 折线计划
- **THEN** 按连续推进的假设投资价值折线、分阶段扩展横轴及动态纵轴和完整候选自动验收规则验收

#### Scenario: v4 动画计划生效
- **WHEN** 制作仍使用旧 v4/v5/v6 折线计划
- **THEN** 阻断并提示显式迁移到 v7 后重新完成完整候选

### Requirement: AI 编排日期与视频时间

AI MUST 记录总时长和完整日期到视频帧映射，日期单调不减且仅由当前帧和本地材料确定。所有新生成计划 MUST 为 v8，默认总长统一为 60 秒，开场固定 60 帧、advance 3420 帧、结尾固定 120 帧，连续覆盖 3600 帧；显式指定时长至少四秒，以确保推进段可用。校验器 MUST 接受此前已生成且结构有效的 v8 分段，不得因默认时长变化要求自动修改旧计划。v7 MUST 保留原来的匀速日期映射及 120 帧结尾。v8 MUST 保存节奏模式及绝对帧—日期锚点，锚点帧严格递增、日期单调，精确覆盖推进首末帧和展示起止日；相邻锚点线性推进。默认波动模式 MUST 按自然月的相对涨跌与市值变化分配时间，权重限制在 1～3，平盘退化为匀速。投资起点前无组合变化权重。报价和纵轴 MUST 仅使用已经揭示的真实数据，不插值报价，不包含事件暂停。

#### Scenario: 标准时长
- **WHEN** 为任意日期跨度生成新 v8 计划
- **THEN** 默认总长 60 秒，三段为 [0,60)、[60,3480)、[3480,3600)，终幕停留两秒

#### Scenario: 长跨度默认时长
- **WHEN** 为超过 20 年的日期跨度生成新 v8 计划
- **THEN** 仍默认总长 60 秒，三段为 [0,60)、[60,3480)、[3480,3600)

#### Scenario: 显式时长覆盖默认值
- **WHEN** 为任意日期跨度显式指定不小于四秒的时长
- **THEN** 使用所指定时长并保留 60 帧开场、120 帧结尾，推进占据剩余帧数

#### Scenario: 既有 v8 分段兼容
- **WHEN** 读取此前生成且分段有效的 v8 计划
- **THEN** 按原有开场、推进与结尾帧区间继续校验和渲染，不自动修改计划

#### Scenario: 波动节奏与寻帧
- **WHEN** 使用波动模式播放或随机寻帧
- **THEN** 高波动月份获得更多时间，同帧日期一致且单调，首末日期精确，未来报价不提前出现

#### Scenario: 平盘、单日与短范围
- **WHEN** 行情平盘、只有单交易日或范围很短
- **THEN** 锚点有效、帧完整覆盖，平盘匀速，单日保持真实日期

#### Scenario: 无效锚点或时长
- **WHEN** 锚点重复帧、日期倒退、边界不符或总长少于四秒
- **THEN** 校验阻断并指出字段

#### Scenario: 兼容与显式迁移
- **WHEN** 读取 v7 或显式升级旧计划
- **THEN** v7 可继续按原映射渲染；升级先备份并保留行情和来源，生成 v8 并要求重新准备并通过完整候选自动验收

#### Scenario: 寻帧与单日范围
- **WHEN** 随机寻帧、顺序播放或制作单日范围
- **THEN** 同帧日期和画面一致，日期单调，单日范围保持真实日期

#### Scenario: 时长不足
- **WHEN** 显式指定少于四秒
- **THEN** 阻断并明确说明最低时长

#### Scenario: 60 秒快速推进并保留终幕
- **WHEN** 使用标准 60 秒 v8 计划
- **THEN** advance 承担 57 秒推进，完整曲线及最终年份、当前市值和实际收盘日期静止停留两秒

#### Scenario: v8 静止结尾兼容
- **WHEN** 读取旧 v8 计划或生成新 v8 计划
- **THEN** 旧计划可保留 180/360 帧开场与结尾，新计划使用 60/120 帧开场与结尾并保持静止

#### Scenario: v7 连续推进并保留终幕
- **WHEN** 读取既有 v7 折线计划
- **THEN** 保留开场 90 帧、推进 570 帧、终幕 120 帧连续覆盖 780 帧（1.5/9.5/2 秒），匀速日期映射不变

#### Scenario: v6 计划迁移
- **WHEN** 显式迁移旧 v1/v2 价格或 v3～v7 计划
- **THEN** 完整备份，保留真实 date/close 及来源，生成 v8 并使旧评审失效

#### Scenario: 分段变速与事件暂停
- **WHEN** 旧计划有事件暂停并迁移到 v8
- **THEN** 清除事件暂停，采用一个连续 advance 和月波动锚点，最后两秒静止保留完整曲线

#### Scenario: 新版本规则生效
- **WHEN** 采用 v8 金融工作流
- **THEN** 采用月波动锚点、分阶段横轴及因果纵轴，通过完整静音候选自动验收后导出

#### Scenario: 日期单调与逐帧推进
- **WHEN** 随机寻帧或顺序渲染 advance
- **THEN** 日期仅由帧和本地计划确定且单调不减，多日覆盖到终日，单日保持不变

#### Scenario: 月末与数据起点边界
- **WHEN** 播放跨月末或起始日期尚无真实收盘价
- **THEN** 横轴左边界不移动，右边界仅按年度阶段扩展，当前日期单调推进，无数据时不显示报价

### Requirement: 独立无声制作与交付验收

专题 MUST 使用独立的数据输入和无声验收，不套用文章字数、口播和有声门禁。制作 MUST 经请求解析、价格核验、资料保存和编排后一次生成完整静音候选，MUST NOT 先完整预演再完整导出。正式生成 MUST 不依赖预演，生成候选后 MUST 要求当前准备记录及完整候选绑定当前三类材料、渲染构建输入和金融 Python 代码，并验证候选摘要与完整帧数；MUST NOT 要求或生成金融人工评审结论或证据。候选生成 MUST 通过逐帧布局、字体边界与历史折线裁剪探针，并通过 MP4 解码、帧数、画布尺寸、帧率、时长和无音轨验收。缺少或过期准备/候选、摘要不匹配、自动探针失败或媒体验收失败时 MUST 阻断，且不得覆盖先前有效成片。预演不得覆盖正式成片。

金融作品的评审模板、评审和状态命令 MUST 明确显示无需人工评审；评审命令可检查当前自动验收条件，但 MUST NOT 写入虚构的人工结论。所有其他类型采用完整候选自动验收与可选人工画面评审，人工结论不再阻断导出。

三类型成功交付后 MUST 保留当前候选与 delivery.json，状态报告候选验收或交付状态；失败保留候选并允许重试验收而不重渲染。交付的成片与预演 MUST 在落盘后重新继承所在目录的访问权限，使以标准权限运行的播放器可以打开。权限修复 MUST 在文件搬运到最终位置之后执行，不得在收紧权限的临时目录内执行；预演 MUST 与成片同等修复。

#### Scenario: 完整评审
- **WHEN** 金融作品具有当前有效材料、准备记录及绑定其材料与渲染资产的完整候选
- **THEN** 逐帧画面探针和媒体验收通过后可正式输出 1080×1920、60 fps、无音轨 MP4，无需人工评审文件

#### Scenario: 预演缺失或过期
- **WHEN** 当前准备有效但没有预演
- **THEN** 允许一次生成候选，检查通过后交付；候选摘要或帧数不匹配时拒绝复用

#### Scenario: 自动画面或媒体验收失败
- **WHEN** 布局/字体/裁剪探针失败，或视频解码、帧数、画布、帧率、时长、无音轨检查未通过
- **THEN** 正式导出失败且先前有效成片保持不变

#### Scenario: 迁移与输入变化
- **WHEN** 材料或渲染资产变化
- **THEN** 旧准备记录或预演无法通过绑定校验，重新准备并生成完整候选后方可正式导出

#### Scenario: 新版本规则生效
- **WHEN** 采用 v7 或 v8 金融工作流
- **THEN** 新版节奏、分阶段横轴和因果纵轴通过完整静音候选自动验收后可正式导出，无需人工评审

#### Scenario: 旧评审失效
- **WHEN** 计划迁移或材料、资产、预演文件变化
- **THEN** 旧候选绑定自动失效并要求重新准备和完整候选；旧人工评审文件不参与导出判定

#### Scenario: 正式导出
- **WHEN** 行情校验和完整候选自动验收全部通过
- **THEN** 输出 1080×1920、60 fps、无音轨 MP4，最终曲线完整

#### Scenario: 金融评审命令无需人工结论
- **WHEN** 对金融作品运行评审模板、评审或状态命令
- **THEN** 明确显示人工评审不适用；评审命令仅报告自动预演验收结果，不生成人工证据

#### Scenario: 专题材料与文章入口隔离
- **WHEN** 金融材料提交文章入口
- **THEN** 仍使用独立专题入口，不豁免文章字数、审查或有声要求

#### Scenario: 交付文件可被标准权限播放器打开
- **WHEN** 成片或预演完成渲染并落到作品目录
- **THEN** 文件继承所在目录的访问权限并含面向普通用户的授权条目，无需人工修复即可打开

#### Scenario: 在临时目录内修复无效
- **WHEN** 渲染产物仍位于收紧权限的临时目录
- **THEN** 权限修复在此处不生效，必须在搬运到最终位置之后执行

### Requirement: 左侧绘图区空间与折线视觉重量
金融时间序列画面的绘图区 MUST 为 x=220～928。所有文字 MUST 位于 x=140～940、y=180～1740 的统一布局边界。纵轴刻度 MUST 使用 14 px 字号并右对齐于 x=206，超宽标签 MUST 在保持字号的情况下水平压缩至可用宽度。投资价值折线 MUST 为 3 px，端点半径保持 8 px。该留白为项目保守默认值，不声明为抖音官方规范。

#### Scenario: 扩展绘图区并保留其他文字边界
- **WHEN** 渲染金融时间序列视频
- **THEN** 绘图区为 x=220～928，纵轴刻度不越过 x=140，其他文字使用同一布局边界

#### Scenario: 细化折线并保留端点
- **WHEN** 曲线显示已揭示的投资价值
- **THEN** 折线宽度为 3 px，端点半径保持 8 px

#### Scenario: 评审报告两种横向安全边界
- **WHEN** 金融完整候选逐帧检查画面布局
- **THEN** 通用安全区和纵轴刻度均在 x=140～940、y=180～1740 范围内，越界时自动阻断

#### Scenario: 年份与市值避免重叠
- **WHEN** 在收窄的画面显示大额当前市值
- **THEN** 市值可用宽度根据年份占位和间隔计算，不与年份重叠

### Requirement: 金融统一制作入口

金融视频 MUST 通过 m2v 的 financial-timeseries 类型制作，支持 v3 价格、v7/v8 计划，保留投资计算、逐帧布局与裁剪探针、完整静音候选自动验收、共享缓存、单会话渲染、性能和溯源。更新材料或构建资产后 MUST 重新准备并生成完整候选；正式导出 MUST 绑定并自动验收当前准备版本及完整候选，不得要求人工评审。

#### Scenario: 新入口导出金融作品
- **WHEN** 使用统一入口准备、预演和导出金融作品
- **THEN** 行情校验、逐帧画面探针及媒体验收通过后输出正式成片和性能/溯源记录，无需人工评审

#### Scenario: 其他视频类型保留人工评审
- **WHEN** 文章或通用作品使用统一入口导出
- **THEN** 验证当前完整候选及类型自动门禁，不要求人工画面评审

#### Scenario: 所有类型无需人工画面评审
- **WHEN** 文章、通用或住宅作品的当前完整候选自动验收通过
- **THEN** MUST 允许正式导出而无需人工评审，金融专用自动探针保持有效
