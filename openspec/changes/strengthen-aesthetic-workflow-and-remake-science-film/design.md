## Context

动机见 [proposal.md](proposal.md)。当前 general 使用 v8 本地代码场景、区间录制缓存及完整候选交付；制作已有两方向、三张关键画面、粗预演、风险样片和全片替代复核。科学里程碑现有60秒无声档案版可作比较基线；不能在未查看旧文件时预填观感结论。

本变更跨共享制作指导、类型参考及既有示例，保留设计文档以明确分类执行、视觉方案与证据边界。

## Goals / Non-Goals

**Goals:** 将审美判断落实到阶段产物、可观察差距和前后对照；以实际重制证明方法可用，保持现有技术底座。

**Non-Goals:** 不新增设计运行时模型、分镜字段、评分器、人工审批、第二套渲染引擎或素材服务；不重制另外两片，不重设金融和住宅的图表契约，不为现有版本增加兼容层。

## Decisions

### 1. 共用原则，分类落地

共用创作目标、参考对照、趋势/整片节奏、分层精修。general 使用完整镜头叙事及四张基准；金融、住宅以整体趋势、关键转折、常规图表和收尾等代表画面复核，不要求额外构造代码场景。这样避免所有类型套用电影镜头流程而破坏专用表达。

standard 使用轻量方向比较、四张基准和精修记录；cinematic 继续满足原有原生4K、风险样片、资产审计和技术QA要求。四张基准可同时满足原有3–5张关键帧要求，无需重复生产。

### 2. 记录沿用现有文件，不进入渲染接口

在 DESIGN.md 记录核心体验、两个方向的同内容比较、四张基准、逐镜六项叙事、强度编排及声音意图；在 outputs/visual-notes.md 记录实际证据、尺寸、问题和精修复查。强度采用低/中/高及文字理由，不引入机器分数。三种检查尺寸记录实际显示宽高，手机方向与作品画幅一致。

五遍精修按视觉重心、信息层级、色彩材质、运动、细节依次检查，优先处理每遍最重要的至多三项；没有问题时记依据。相关修改可合并准备和渲染，仍遵循有效区间缓存与同版本完整候选复用，不因检查次数重复编码。

替代方案是新增 JSON 设计契约与审美门禁；本次不采用，因为它不能证明美术质量且会扩大运行时范围。校验器仅覆盖客观结构与硬约束，审美结论保留真实人工式判断及证据。

### 3. 档案纪录重制方案

保持现有十项顺序与时间窗，视觉线索从信号跨越距离，延伸到机器能力、探索连接及信息处理；这些线索只组织观看，不表达直接历史因果。墨黑、暖白、早期铜色与后期冷青作为统一基础，保留档案固有层次，优先通过裁切、主体关系、图形与运动改善画面，不依赖辉光和颗粒堆叠。

| 时间 | 内容 | 主要视觉变化与承接 |
|---|---|---|
| 0–3秒 | 开场 | 以档案主体及精简标题建立主题，年代线只作次级线索 |
| 3–7秒 | 电报 | 实物与摩尔斯信号传播形成一次明确动作 |
| 7–11秒 | 电话 | 将脉冲节奏转为波形，保持实物主导 |
| 11–19秒 | 飞机 | 展开完整档案空间，保留人、飞机及地平线的关系 |
| 19–23秒 | 原子弹 | 克制呈现档案，保留警示与贡献边界，不使用庆典化效果 |
| 23–27秒 | ENIAC | 机柜与人物形成尺度，局部活动说明机器运行 |
| 27–31秒 | 晶体管 | 从实物细节连接到清楚标注的结构示意 |
| 31–39秒 | 登月 | 保留连续档案运动，不叠加二次推拉抢夺注意 |
| 39–43秒 | ARPANET | 节点与连接逐步形成，区分档案和示意 |
| 43–47秒 | 基因组 | 将读取线索与结构示意建立对应，减少长说明 |
| 47–55秒 | 大模型 | 信息在网络层间推进，避免无目的粒子活动 |
| 55–60秒 | 片尾 | 动作与信息收束，唯一署名满足许可并留足阅读时间 |

四张基准采用开场、登月、晶体管、片尾。每镜先确定一个主动作，年号和英文装饰降为次级，删掉与画面重复的说明；事实限定及必要署名不得因精简丢失。继续使用现有组件能力，保持三个示例合计组件覆盖。

### 4. 证据与验证

实施先确认旧交付及摘要，保存四张基准和代表普通镜头的新旧同时间码、同尺寸比较。旧成片不可用时，优先从旧提交材料重建基线；仍无法取得时如实登记比较未完成，不编造提升结论。

按统一入口完成校验、准备、素材审计、覆盖全片的低成本动态粗预演、四张基准与20–30秒无声风险样片，完成精修后生成新完整候选并验收交付。静帧和样片可复用已满足的基准证据，素材许可或质量不足时先替换并更新留证。

最终以现有QA生成至少每0.5秒一帧的全片基线、交界前后0.5秒按0.1秒加密及风险采样，检查至片尾。执行运动/构图量测及静音检查，验证3600帧、60 fps、1920×1080；数字静音轨峰值应为0，无音轨则记录契约允许。记录新准备指纹、最终SHA-256、问题处置及覆盖限制，不声称已播放或试听。

## Risks / Trade-offs

- [60秒内容密集] → 保留固定预算，删重复文字、降低装饰权重并重组镜头，不擅自延长或加速塞入。
- [历史素材低清] → 按实际质量留边、局部呈现或调整构图，不把4K静帧当成原生素材质量证明。
- [片尾署名空间有限] → 优先简化非必要文案；无法满足署名义务时更换素材，不删除必要许可信息。
- [流程形式化] → 每项记录落到具体画面差距或无需修改的证据，不以文档存在代替审美复核。
- [采样与音频信号覆盖有限] → 披露采样间异常及主观听感边界，不增加播放确认门禁。

## Migration Plan

propose 阶段仅提交规划文件。后续 apply 先更新共享方法与分类参考，再完成示例重制，最后更新 README 当前能力与示例交付说明；仅在路线事实需要调整时修改项目规划。核对设计令牌动效换算为60 fps（240/360/560ms约14/22/34帧），不顺带清理无关历史规格。

实施验证包括示例严格测试、相关源码及字体检查、前端测试与构建、文档同步和链接一致性；改动校验器时增加对应行为测试。检查暂存后提交，全部任务和新片验收通过才同步主规格并自动归档、提交归档结果。失败保留旧有效交付与未完成任务，修复后重试；回退通过撤销本次相关提交恢复材料，重新准备后再用有效候选交付。
