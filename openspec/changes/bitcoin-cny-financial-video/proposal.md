## Why

金融时间序列目前只支持股票和指数，且把本金按单一行情价格比缩放，无法忠实表达以人民币买入美元报价的比特币并按汇率折算期末价值。为制作 2011 年 5 月起点的视频，需要补上可核验的加密货币日线、汇率换算和起点说明能力，同时保持既有作品兼容。

## What Changes

- 金融材料支持加密货币日线、指定买入日期、投资本金币种及带来源快照的 USD/CNY 日汇率；无汇率报价的日期使用此前最近可用观测。
- 金融计算和画面支持按汇率变化折算人民币组合价值，并渲染作品自带的起点说明及既有风险提示。
- 制作 BTC 示例作品：以 2011-05-01 收盘价买入、人民币 100,000 元本金，使用截至 2026-10-12 的完整 UTC 日线；输出仅留在忽略的作品目录。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `financial-timeseries-video`: 扩展支持加密货币、实际汇率计算、日期级投资起点及补充说明。

## Impact

- 影响金融材料校验与计划生成、Python 投资序列和波动节奏计算、Remotion 金融折线画面、金融规格与 Skill 参考文档。
- 新增币种与汇率点的版本化材料约定；现有 request v1 / prices v3 股票和指数作品继续可读。
- 作品材料、行情快照、预演和成片均位于被 Git 忽略的 `videos/` 内容目录。
