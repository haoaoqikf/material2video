## Context

参见 proposal.md。现有示例由作品本地 React 全画布场景绘制，大语言模型段目前只有生成式网络示意；所有媒体素材经作品素材目录与台账留证。十项分镜合计30秒，现有大语言模型段3.5秒、片尾3秒。素材署名须集中在片尾，生成媒体位于忽略目录。

## Goals / Non-Goals

**Goals:**

- 将当前抽象网络段升级为以产品交互作为视觉锚点、以动态图形补足研究主题的镜头。
- 让2秒片尾在699×393手机显示尺寸仍能辨读所有必要署名信息。
- 复核新候选的画面、静音、时长、素材记录，并保存可追溯证据。

**Non-Goals:**

- 不新增通用渲染能力、分镜字段、机器评分或平台数据接入。
- 不把示意对话描述成历史对话或真实模型生成记录。
- 不重排其余九项里程碑，也不更改视频总时长与格式。

## Decisions

1. **界面在作品代码中重绘，标注“示意界面”**：中文短提问与逐字显现的短答可让观众立即识别交互。比截取真实产品截图更易控制可读性、避免用户数据和界面版本过时；同时保留 ChatGPT 品牌标记作为产品识别线索。问答内容用示例性科普表达，不暗示真实生成或特定模型能力。
2. **官方图标走已留证素材路径**：仅从 OpenAI 官方品牌资源取得原文件，原样作为小尺寸 UI 标识使用；记录官方来源、摘要和商标归属，不标注 CC 等开放许可。片中同时显示 ChatGPT / OpenAI 和“示意界面”，不放置背书性措辞，也不把标志做为本片品牌。
3. **由片尾挪出一秒给 LLM**：将 LLM 改为270帧、片尾改为120帧，保持1800帧总长与其它镜头预算；这使交互有时间完成输入和回答，同时把唯一片尾信息压缩在两秒内。
4. **片尾使用两行高字号文字而不设标题**：保留晶体管与阿帕网作者/来源、各自许可、裁切调色改动及本片许可；去掉“署名与版权”标签和装饰段落。按真实手机等比缩图调整排版，并以采样帧检查可读性。
5. **回归证据跟随新时间码**：更新示例帧数断言、基准采集的 LLM 和片尾目标帧、设计时间线、来源材料与复核记录；旧成片和旧摘要不用于新结论。

## Risks / Trade-offs

- [商标规则或官方资源链接变化] → 采用官方品牌指南指向的原始下载文件并记录来源；若官方源无法验证或素材无法按原样使用，停止将该标志嵌入，改用文字标注并记录偏差。
- [两秒内许可文字过密] → 去标题、压缩分隔符、两行横向编排并放大字号；从最终片采集699×393图检查实际可读性，必要时精简非必需装饰而不删义务信息。
- [界面被误认作真实截图或背书] → 加入持续可见“示意界面”标记，标签明确 ChatGPT / OpenAI 归属，避免仿制真实登录、账号或当前界面细节。
- [总时长回归或旧缓存污染] → 时长断言锁定各段帧数，重新 prepare 并生成新候选；复核记录绑定新指纹与文件摘要。

## Migration Plan

1. 新建本次 OpenSpec change 并先验证规格增量。
2. 更新官方图标素材及来源记录、场景和分镜，再更新示例设计、README、帧数断言与采集脚本。
3. 运行分镜/示例测试与素材审计，prepare 并 render 新候选；通过技术 QA 后从最终片抽帧及手机尺寸图，检查关键段、前后连接和片尾。
4. 若视觉或技术复核未通过，修订示例代码并重新准备/渲染；交付前检查当前成片与记录都对应同一指纹。
5. 本地示例回滚可通过 Git 恢复场景、分镜、素材清单与文档；已生成媒体为可重建产物，不入 Git。
