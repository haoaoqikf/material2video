## Context

金融 composition 在每帧按当前可见跨度重新计算刻度间隔，并按标签宽度筛选。即使日期单调扩展，候选集和空间排序改变仍会移除旧标签，后续又可能选择回来。

## Goals / Non-Goals

**Goals:** 让同一标签在全片最多进入一次并持续显示，同时保持标签数和横向间距约束。

**Non-Goals:** 改变时间轴扩展、日期横坐标映射、曲线推进或投资价值计算。

## Decisions

- 使用完整请求日期范围一次性生成不超过四个横轴锚点；每帧只按可见日期过滤这些固定标签。刻度间隔和避让选择不再随每帧的横轴宽度重算。
- 在完整帧范围内跟踪各标签的可见状态，断言没有标签在消失后重新出现；通过终幕年份和现有安全间距断言覆盖兼容要求。

## Risks / Trade-offs

- `[前段可能只显示一个年份标签]` → 固定锚点优先保证全片一致和不重叠；随着日期范围扩展，后续标签会逐个进入。
