## Context

动机见proposal.md。现有事件五段式、两方向美术比较与相对改善检查已有可复用入口，本次细化核心画面的表现决策，而不增加制作阶段或平行报告。

## Goals / Non-Goals

目标是分开验证事件与表现，并使未达到预先声明表现目标的核心镜头回到方案或试制。非目标是自动判审美、保证观众记忆、重制当前视频或扩展渲染能力。

## Decisions

- 完整方法只在新增visual-impact-design.md维护，各入口引用；DESIGN沿用核心事件说明，visual-notes沿用唯一问题表与评审链接。
- 同一核心图形事件至少三种视觉机制，可复用已有三案与美术候选但不能以不同事件偷换比较；试制代码允许，选案后才扩展正式实现。
- 八项维度只写观察与收益损失，不设分数、总分或阈值；记忆潜力只能是设计判断。
- 3—6秒、约850px宽是起点或示例，完整事件与作品手机基准优先；不要求每幕3D、反转或高潮。
- 验收按预先声明目标与当前版本证据，风险、偏好与实际缺陷继续区分；灰度、遮结论等不是所有题材通用否决条件。
- 测试只保护文件、链接、模板结构与关键契约边界，不锁定示范数量、日期或完整中文段落。

## Risks / Trade-offs

- 变成另一张填表任务 → 合入已有事件说明，候选图与动态证据才支持选案。
- 追求冲击牺牲理解或事实 → 事实、关键理解与必要可读性不豁免。
- 静态题材被强制加特效 → 明确适用性，安静、文字与颜色语义允许替代方式。
- 作者写预期即判成立 → 隔离代理先观察，后核对中性条件，不能读设计答案。

## Migration Plan

用于后续制作或明确启动的重制，示例补写标为指导、不改写旧交付结论。本轮验证与实施提交后同步主规格、归档并另行提交；不更改既有活动视频变更。
