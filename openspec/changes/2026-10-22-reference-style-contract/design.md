## 背景

参考素材在仓库里一直有清晰的获取与边界规则，但没有「风格如何转译」的规则。结果是执行者只能按形容词理解风格，最容易被复制的是配色，最容易被忽略的是尺度、光源、运动和文字层级。

本变更只补创作流程，不新增代码，原因是：

- 风格是否成立是审美判断，不能做成自动阈值门禁；现有原则明确反对代理评分。
- 可量测的部分（占比、面积、位置、帧差）用文档规定测量方法即可，不需要新增工具就能执行。
- 当前正在进行的作品制作不能被流程改造阻塞，文档改动不触发重新准备或重渲染。

## 决策

### 1. 用「契约」而不是「指南」

只写「注意借鉴风格」不会改变行为。契约要求四列必须填：参考值、目标值、实际值、差值。没有实际值和差值，契约只是愿望清单。这是对第一次失败的直接修正。

### 2. 借鉴分三层，最多选三项

「风格」同时可能指视觉语言、节奏结构、情绪调性。不分层时，执行者会把三层混成一句「气质一致」，无法验收。分层后每一层都有对应证据：视觉语言对应八项指标，节奏对应剪辑点与段落长度，情绪对应冷审描述。

### 3. 八项指标按「最终手机显示尺寸」折算

参考是 1920×1080 横屏、成片是 1080×1920 竖屏时，按源画幅比例照搬会失真。统一折算到 393 宽手机显示尺寸后比较：横屏 1920 缩放到 393 是 0.205 倍，竖屏 1080 缩放到 393 是 0.364 倍。同一源线宽在两种画幅下的最终像素不同，必须按显示后的观感对齐，而不是按源文件像素对齐。

### 4. 八项而不是更多

只保留对「像不像」贡献最大、且能稳定量取的指标：主体尺度、空场率、线宽、光源数量与面积、背景质感、机位与运动、剪辑节奏、文字层级与位置。材质细节、色彩微差、字体选择归入 L3 冷审描述，不做数值契约。

### 5. 三张风格基准先于全片

现有四张基准是叙事基准，保证「看得懂」，不保证「像谁」。风格基准与叙事基准并列，任何一组不通过都不得进入全片精制。基准必须并排到同一显示宽度，避免拿原尺寸大图自我说服。

### 6. 同族判定用冷审，不用自评

复用 `visual-review-rubric.md` 的冷审原则：先不看设计文档，先描述两张图的主体尺度、光源方向、画面密度，再判断是否同一视觉族。不同族必须写出具体差异项，不能写「感觉不像」。制作者不参与判定。

### 7. 与版权边界分开表述

参考画面不得进入成片是素材边界；参考的视觉语言必须被拆解和转译是创作边界。两句话写在同一个文档里，但分开成两节，避免再次把「画面原创」执行成「画面不参考」。

## 风险与取舍

| 风险 | 取舍 |
| --- | --- |
| 契约变成填表，画面没变好 | 门禁要求三张基准与 2 秒样片必须实际查看并写同族结论；只有表格没有并排图和冷审结论，视为未完成 |
| 量化过度，作品失去原创性 | 八项只描述观看方式，不规定符号、题材和具体分镜；「不借」清单强制列出符号边界 |
| 竖屏作品为凑指标牺牲可读性 | 允许例外，但必须在契约中写理由与补偿措施；例外不能用于核心理解问题 |
| 与正在进行的作品制作冲突 | 本次不改 `videos/`、不新增运行时字段、不触发重新准备 |
| 与冷审文档重复 | 不重复定义三道冷审，只引用并补充「参考对照」这一具体用法 |

## 未纳入本变更

- 不新增 `m2v ref style` 或 `m2v ref compare` 命令。先把方法固化并跑通一次，再评估工具化收益。
- 不修改自动 QA 与验收阈值。
- 不为历史作品补做契约；仅对之后明确要求借鉴风格的作品生效。
